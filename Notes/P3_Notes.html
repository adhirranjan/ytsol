L-1

Vectors, Position & Unit Vectors

  • Scalar — fully described by a single number (magnitude), can be +, − or 0: length, volume, speed, temperature.
  • Vector — needs magnitude + direction and follows the law of vector addition: velocity, displacement, momentum.

Types of vectors

  • Equal / equivalent: same magnitude & same direction.
  • Opposite / negative: same magnitude, opposite direction — AB = −CD.
  • Coinitial: same initial point. Collinear: parallel to the same line (any magnitude/direction).
  • Parallel (same direction) vs antiparallel (180° apart); orthogonal = perpendicular.
position vectorr = x î + y ĵ + z k̂  ·  |OP| = √(x² + y² + z²)
displacement / unit vectorPP′ = OP′ − OP  ·  â = A / |A|
Displacement is a free vector, position is fixed
A position vector is tied to the origin as its initial point — it is a fixed vector. A displacement vector PP′ only records the change from one point to another, so it can be slid anywhere without a fixed tail — it is a free vector. Numerically PP′ = OP′ − OP, i.e. (final coordinates) − (initial coordinates).
💡 Unit vector checkIf 0.5î + 0.8ĵ + c k̂ is a unit vector, then 0.25 + 0.64 + c² = 1, so it must satisfy |Â| = 1.

L-2

Addition of Vectors

  • Triangle law: if two vectors are the two sides of a triangle taken in the same order, the resultant is the third side taken in the opposite order (AB + BC = AC).
  • Parallelogram law: two vectors along adjacent sides of a parallelogram — their sum is the diagonal through the common point.
resultantR = √(A² + B² + 2AB cosθ)
directiontanα = B sinθ / (A + B cosθ)  ·  tanβ = A sinθ / (B + A cosθ)
★ ExtremesMaximum resultant A + B at θ = 0°; minimum |A − B| at θ = 180°. Vector addition is commutative.
Two equal vectors — the bisector result
For two equal vectors of magnitude A at angle θ: R = √(A² + A² + 2A·A cosθ) = √(2A²(1 + cosθ)) = 2A cos(θ/2). The direction tanα = sinθ/(1 + cosθ) = tan(θ/2), so α = θ/2 — the resultant of two equal vectors bisects the angle between them.

L-3 & 4

Polygon Law & Subtraction of Vectors

  • Polygon law: to add several vectors, place them head-to-tail; the resultant is the closing side from the first tail to the last head. R = A + B + C + …
  • Properties: commutative A + B = B + A · associative (A + B) + C = A + (B + C) · additive identity A + 0 = A.
  • Subtraction: A − B = A + (−B) — reverse B and add.
difference|A − B| = √(A² + B² − 2AB cosθ)   (θ = angle between A and B)
directiontanα = B sinθ / (A − B cosθ)
💡 Component methodResolve every vector into î, ĵ (and k̂), add components separately, then recombine: R = √(Rx² + Ry²), φ = tan⁻¹(Ry/Rx).
When |A + B| = |A − B|
Square both: A² + B² + 2AB cosθ = A² + B² − 2AB cosθ ⇒ 4AB cosθ = 0 ⇒ cosθ = 0 ⇒ θ = 90°. So the sum and difference have equal magnitude only for perpendicular vectors (this is why a rectangle's two diagonals are equal).

L-5

Resolution of Vectors & Direction Cosines

  • A force F at angle θ to an axis is resolved into two perpendicular components — F cosθ (along the axis) and F sinθ (perpendicular). Only mutually perpendicular components are unique & independent (rectangular resolution).
  • 3D components: Ax = A cosα, Ay = A cosβ, Az = A cosγ.
2D resolutionVx = V cosθ  ·  Vy = V sinθ  ·  V = Vx î + Vy ĵ
direction cosinescosα = Ax/A, cosβ = Ay/A, cosγ = Az/A  ·  l² + m² + n² = 1
⚠ TrapWatch which axis the angle is measured from: the component along that axis uses cos, the perpendicular one uses sin. "37° with the vertical" ⇒ vertical component = A cos37°.
Why cos²α + cos²β + cos²γ = 1
With l = cosα = Ax/A, m = Ay/A, n = Az/A, and A² = Ax² + Ay² + Az², dividing through by A² gives l² + m² + n² = (Ax² + Ay² + Az²)/A² = 1. So the three direction cosines are never independent — knowing two fixes the third (up to sign).

L-6 & 7

Dot & Cross Product (Scalar & Vector)

Dot (scalar) product

dot productA·B = AB cosθ = a₁b₁ + a₂b₂ + a₃b₃   (a scalar)
angle · projection · workcosθ = A·B/AB  ·  proj of B on A = (A·B)/|A|  ·  W = F·s
  • Commutative A·B = B·A · distributive A·(B + C) = A·B + A·C · A·A = A².
  • A·B = 0 ⇒ perpendicular; A·B = +AB at θ = 0, −AB at θ = 180°.

Cross (vector) product

cross productA×B = AB sinθ n̂ ; A×B = î(a₂b₃ − a₃b₂) − ĵ(a₁b₃ − a₃b₁) + k̂(a₁b₂ − a₂b₁)
applicationsArea △ = ½|A×B| · Area ▱ = |A×B| · τ = r×F · L = r×p
  • Anticommutative A×B = −B×A · A×A = 0 · A×B = 0 ⇒ parallel. Result is ⊥ to both A and B (right-hand rule).
Angle from the resultant, and the sin/cos split
If magnitudes A, B and the magnitude of the resultant R = |A + B| are known: R² = A² + B² + 2AB cosθ ⇒ cosθ = (R² − A² − B²)/(2AB). The dot product carries the cosθ (parallel-ness), the cross product carries the sinθ (perpendicular-ness); together |A·B|² + |A×B|² = A²B².

JEE PYQ · Main 2026
When r = xî + yĵ + zk̂ changes sign to −r, which vector will not flip sign? (a) Linear momentum (b) Velocity (c) Acceleration (d) Angular momentum
Under inversion r → −r, polar (true) vectors — velocity, momentum, acceleration — reverse. Angular momentum L = r × p is an axial (pseudo) vector: both r and p flip, so their cross product is unchanged.
(d) Angular momentum
JEE PYQ · Main 2025
A = 2î + 3nĵ + 2k̂ and B = 2î − 2ĵ + 4pk̂ are at equal distance from the origin and at right angles. Find n⁻¹.
Equal magnitude: 4 + 9n² + 4 = 4 + 4 + 16p² ⇒ 9n² = 16p². Perpendicular: A·B = 4 − 6n + 8p = 0.
Take 3n = −4p ⇒ p = −3n/4 ⇒ 4 − 6n − 6n = 0 ⇒ n = 1/3 (check: A = 2î+ĵ+2k̂, B = 2î−2ĵ−k̂, both |·| = 3, A·B = 0 ✓).
n⁻¹ = 3
JEE PYQ · Main 2024
The resultant of A and B is perpendicular to A and its magnitude is half that of B. Find the angle between A and B.
R ⊥ A ⇒ A·(A + B) = 0 ⇒ A² + AB cosθ = 0 ⇒ cosθ = −A/B.
|R|² = A² + B² + 2AB cosθ = B² − A² = (B/2)² ⇒ A² = 3B²/4 ⇒ cosθ = −√3/2.
θ = 150°
JEE PYQ · Main 2024
a and b make an angle cos⁻¹(5/9). If |a + b| = √2 |a − b| and |a| = n|b|, find the integer n.
Square: a² + b² + 2ab cosθ = 2(a² + b² − 2ab cosθ) ⇒ 6ab cosθ = a² + b².
cosθ = 5/9 ⇒ (10/3)ab = a² + b². With a = nb: 3n² − 10n + 3 = 0 ⇒ n = 3 or 1/3.
n = 3 (integer)
JEE PYQ · Main 2024
For A = −xî − 6ĵ − 2k̂, B = −î + 4ĵ + 3k̂, C = −8î − ĵ + 3k̂, if A·(B×C) = 0, find x.
Scalar triple product (determinant) = 0: −x(4·3 − 3·(−1)) + 6((−1)·3 − 3·(−8)) − 2((−1)(−1) − 4(−8)) = 0.
−15x + 6(21) − 2(33) = −15x + 126 − 66 = −15x + 60 = 0.
x = 4
JEE PYQ · Main 2023
P = 3î + √3ĵ + 2k̂, Q = 4î + √3ĵ + 2.5k̂. The unit vector along P×Q is (1/x)(√3î + ĵ − 2√3k̂). Find x.
P×Q = 0.5√3 î + 0.5 ĵ − √3 k̂ = ½(√3î + ĵ − 2√3k̂); |√3î + ĵ − 2√3k̂| = √(3+1+12) = 4.
So |P×Q| = 2 and unit vector = ½(√3î + ĵ − 2√3k̂)/2 = ¼(√3î + ĵ − 2√3k̂).

JEE PYQ · Main 2023
A force −Pk̂ acts at the origin. Its torque about the point (2, −3) is P(aî + bĵ). If a/b = x/2, find x.
r = origin − pivot = −2î + 3ĵ; τ = r × F = (−2î + 3ĵ) × (−Pk̂) = −3Pî − 2Pĵ.
So a = −3, b = −2 ⇒ a/b = 3/2 = x/2.
