1A particle begins at the origin and moves successively: 1 unit to the right, 1/2 unit up, 1/4 unit to the right, 1/8 unit down, 1/16 unit to the right, etc. The length of each move is half the length of the previous move and movement continues in the 'zigzag' manner indefinitely. The co-ordinates of the point to which the 'zigzag' converges is: (a) (4/3, 2/3) (b) (4/3, 2/5) (c) (3/2, 2/3) (d) (2, 2/5)Sum of a geometric series of displacementsInfinite Geometric Series | Convergent vs Divergent & Finding the Sum🟡 Similarb(4/3, 2/5)
Concept The zigzag separates into two independent one-dimensional motions: every rightward hop changes only x, every up or down hop changes only y. Within each direction the hops shrink geometrically, so the x-displacements form one GP and the y-displacements form another. The point the path converges to is simply the sum of the horizontal GP paired with the sum of the vertical GP — two infinite-series evaluations, nothing more.
Formula S = a/(1 − r), valid for |r| < 1. Each hop is half the one before, so two consecutive hops in the same direction are apart by a factor (1/2)² = 1/4.
Solution
1. List the moves in order: 1 right, 1/2 up, 1/4 right, 1/8 down, 1/16 right, … each half the last.
2. Rightward hops are moves 1, 3, 5, … : 1, 1/4, 1/16, … — a GP with a = 1, r = 1/4.
3. x-coordinate: x = 1/(1 − 1/4) = 1/(3/4) = 4/3.
4. Vertical hops alternate up, down, up: +1/2, −1/8, +1/32, … so a = 1/2 and r = −1/4. The direction flips each time, so the common ratio is negative while its size stays 1/4.
5. y-coordinate: y = (1/2)/(1 − (−1/4)) = (1/2)/(5/4) = 2/5.
6. Both |r| = 1/4 < 1, so both series converge and the path settles at (4/3, 2/5).
  right hops: 1, 1/4, 1/16, ...   a=1,  r=1/4
  x = 1/(1 - 1/4) = 1/(3/4) = 4/3
  vert hops: +1/2, -1/8, +1/32    a=1/2, r=-1/4
  y = (1/2)/(1 + 1/4) = (1/2)/(5/4) = 2/5
  limit point = (4/3, 2/5)
⚡ JEE Trick Split any alternating zigzag into its x-series and y-series before touching a formula. Watch the signs: a down-then-up pattern gives a negative ratio, which makes the denominator (1 − r) larger and the limit smaller — exactly why y = 2/5, not 2/3.
Answer: (b) (4/3, 2/5).

Concept A point whose distances to two fixed points add to a constant traces an ellipse with those points as foci. The constant is the major axis length, and the focal half-distance plus the semi-axes obey b² = a² + c² along the two directions. Read off both denominators and add.
Formula PA + PB = 2·(semi-major); (semi-minor)² = (semi-major)² − c². c is half the distance between the foci A(0, 1) and B(0, −1), so c = 1 and the major axis lies on the y-axis.

2. 2·(semi-major) = 4, giving semi-major = 2; the foci sit on the y-axis, so the y-denominator is 2² = 4.
3. Focal half-distance c = 1 (half of |AB| = 2). The foci are symmetric about the origin, one unit each way.
4. (semi-minor)² = (semi-major)² − c² = 4 − 1 = 3 — this is the x-denominator.
5. Locus: x²/3 + y²/4 = 1, so in x²/a² + y²/b² = 1 we read a² = 3, b² = 4.

  foci (0, +-1): 2*(semi-major) = 4 -> semi-major = 2
  c = 1  ->  (semi-minor)^2 = 2^2 - 1^2 = 3
