💡 Allied-angle master ruleWrite the angle as 90°×n ± θ. If n is odd (90°, 270°) the function changes (sin↔cos, tan↔cot, sec↔cosec). If n is even (180°, 360°) the function stays. The sign = sign of the original ratio in the quadrant the whole angle lands in.
L-1

Trigonometric Ratios, Identities & Signs

  • Six ratios from a right triangle (P = perpendicular, B = base, H = hypotenuse) w.r.t. an acute angle θ.
definitionssinθ = P/H · cosθ = B/H · tanθ = P/B · cotθ = B/P · secθ = H/B · cosecθ = H/P

Reciprocal & quotient relations

reciprocalsinθ·cosecθ = 1 · cosθ·secθ = 1 · tanθ·cotθ = 1
quotienttanθ = sinθ/cosθ · cotθ = cosθ/sinθ

The three Pythagorean identities

fundamental identitiessin²θ + cos²θ = 1 · 1 + tan²θ = sec²θ · 1 + cot²θ = cosec²θ
Why sin²θ + cos²θ = 1
Drop PM ⟂ x-axis from a point P on the terminal ray; in right △OMP, OP² = OM² + PM². Then sin²θ + cos²θ = (PM/OP)² + (OM/OP)² = (PM²+OM²)/OP² = OP²/OP² = 1. Dividing this identity by cos²θ gives 1 + tan²θ = sec²θ; dividing by sin²θ gives 1 + cot²θ = cosec²θ.
★ Ranges−1 ≤ sinθ ≤ 1 · −1 ≤ cosθ ≤ 1 · |secθ| ≥ 1 · |cosecθ| ≥ 1 · tanθ, cotθ ∈ ℝ.
⚠ Trapsinθ is one symbol (sine of angle θ) — it is not "sin × θ". Likewise sin²θ means (sinθ)², not sin(θ²).

Sign & variation across quadrants

  • In QI all ratios positive; QII only sin/cosec; QIII only tan/cot; QIV only cos/sec (ASTC above).
  • As θ goes 0→90°: sinθ ↑ 0→1, cosθ ↓ 1→0, tanθ ↑ 0→∞. On the unit circle x = cosθ, y = sinθ.
Finding one ratio from another (worked in module)
Given cosθ = −12/13 with θ in QIII: sin²θ = 1 − cos²θ ⇒ sinθ = ±√(1 − 144/169) = ±5/13. QIII ⇒ sinθ negative ⇒ sinθ = −5/13, and tanθ = sinθ/cosθ = (−5/13)/(−12/13) = 5/12 (positive, as expected in QIII).

Book Example · L-1
If tanθ + sinθ = m and tanθ − sinθ = n, show that m² − n² = 4√(mn).
m² − n² = (tanθ+sinθ)² − (tanθ−sinθ)² = 4 tanθ sinθ.
4√(mn) = 4√((tanθ+sinθ)(tanθ−sinθ)) = 4√(tan²θ − sin²θ) = 4√(sin²θ/cos²θ − sin²θ) = 4√(sin²θ(1−cos²θ)/cos²θ) = 4√(sin⁴θ/cos²θ) = 4 sin²θ/cosθ = 4 tanθ sinθ.
Both sides = 4 sinθ tanθ ⇒ m² − n² = 4√(mn)

💡 Two-step recipe(1) Odd multiple of 90° (90°, 270°) ⇒ co-ratio (sin↔cos, tan↔cot); even multiple (180°, 360°) ⇒ same ratio. (2) Sign from ASTC of the full angle.
co-terminal (period)sin(360°·n + θ) = sinθ, etc. ⇒ sin(2nπ + θ) = sinθ for integer n

Periodic functions

  • sin x, cos x, sec x, cosec x have period 2π; tan x, cot x have period π.
  • |sin x|, |cos x|, |tan x|, |cot x|, |sec x|, |cosec x| all have period π.
  • sinⁿx, cosⁿx, secⁿx, cosecⁿx: period 2π if n odd, π if n even. tanⁿx, cotⁿx: period π (any n).

Even & odd functions

  • Even: f(−x) = f(x) — cos x, sec x (graph symmetric about y-axis).
  • Odd: f(−x) = −f(x) — sin x, tan x, cot x, cosec x (symmetric about origin).
Step method for any angle (module's Step I–V)
I. If the angle is negative, make it positive using sin(−θ)=−sinθ, cos(−θ)=cosθ, tan(−θ)=−tanθ. II. Write it as 90°×n ± θ with θ acute. III–IV. Find the quadrant of the full angle and the sign of the required ratio there. V. If n is odd, switch to the co-ratio; if even, keep the ratio — attach the sign from step IV.

Book Example · L-2
If A, B, C, D are the angles of a cyclic quadrilateral, prove that cos A + cos B + cos C + cos D = 0.
Opposite angles are supplementary: A + C = π and B + D = π ⇒ A = π − C, B = π − D.
So cos A = −cos C and cos B = −cos D. Hence the sum = −cos C − cos D + cos C + cos D.

Applications — Evaluating & Proving with Allied Angles

  • Combines the reduction table with the standard-angle values to evaluate ratios of large / negative angles and to prove identities.
  • Complementary angles (sum 90°): sin(90° − θ) = cosθ, sec(90° − θ) = cosecθ, tan(90° − θ) = cotθ — used constantly in "sin·cosec" style products.
complementary pairsin(90° − θ) = cosθ · tan(90° − θ) = cotθ · sec(90° − θ) = cosecθ
⚠ TrapWatch the sign carefully: tan(180° + θ) = +tanθ (QIII, tan positive) but tan(180° − θ) = −tanθ. The reduction table beats guessing.
Reading a big angle fast
For an angle like 17π/6, subtract whole turns / half-turns to reach 90°×n ± (acute): 17π/6 = 3π − π/6, an odd multiple of π that is really 90°×6 − π/6 landing in QII... but the safe route is n = 6 (even) here since 3π = 90°×6 ⇒ keep cos, and 3π − π/6 sits so that cos(3π − π/6) = −cos(π/6) = −√3/2. Always confirm the sign from the quadrant of the full angle.
