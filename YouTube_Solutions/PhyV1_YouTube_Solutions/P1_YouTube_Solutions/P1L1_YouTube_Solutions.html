Concept The radian is the natural unit of angle in physics: it is defined as arc-length divided by radius, so it is a pure number with no dimensions. Degrees are a human convention (360 to a turn); radians fall straight out of the geometry of a circle. The bridge between them comes from one fact — a full circle subtends 2π rad — and everything else is scaling. In all rotational-motion formulas (ω, α, s = rθ) the angle must be in radians.
Formula θ (rad) = arc/radius the definition. A whole circle: 2π rad = 360°, hence π rad = 180° and 1 rad = 180°/π ≈ 57.3°. The ratio arc/radius is dimensionless (metre ÷ metre), which is why radian carries no unit symbol in derived quantities.
Solution
1. Arc for one full turn = circumference = 2πr; angle = arc/radius = 2πr / r = 2π rad.the radius cancels, leaving a pure number.
2. That same full turn is 360° by definition, so 2π rad = 360°.
3. Divide both sides by 2: π rad = 180° — this is option (d).
4. Scale factor: 1 rad = 180°/π = 180/3.1416 ≈ 57.3°; conversely 1° = π/180 rad.
5. Spot-check: 90° = π/2 rad, 60° = π/3 rad, 45° = π/4 rad — all consistent with π ↔ 180°.

Concept A trigonometric equation has infinitely many solutions because sine and tangent are periodic — sine repeats every 2π rad, tangent every π rad. To "find all θ in [0, 2π]" you first write the general solution for the bracket, then solve for θ, then keep only the values that land inside the required window. The interval is in radians, so answers must be in radians too.
Formula sin x = 1 ⇒ x = π/2 + 2nπ (sine hits its maximum once per 2π-rad cycle). tan x = tan α ⇒ x = α + nπ (tangent has period π rad). Here n = 0, ±1, ±2… is any integer. Standard values used: tan(π/4) = 1, tan(π/3) = √3. All angles in rad; the ratios themselves are dimensionless.
Solution
