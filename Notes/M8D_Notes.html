The whole chapter on one card

★ The one ideaNone of these series has a "plug-in" sum you can memorise blindly. Every question is one of four machines: (1) split the term into Σn, Σn², Σn³; (2) multiply by the ratio and subtract (arithmetico-geometric); (3) write the term as f(r) − f(r+1) so it telescopes (Vn method); (4) squeeze it with A ≥ G ≥ H. Pick the machine, turn the handle.
the three power sumsΣn = n(n+1)/2  ·  Σn² = n(n+1)(2n+1)/6  ·  Σn³ = [ n(n+1)/2 ]² = (Σn)²
method of differencesIf the differences T2−T1, T3−T2, … themselves form an A.P. or G.P., then Tn = T1 + Σ(differences); now sum Tn with the power sums above.

product / reciprocal telescopesΣ 1/[r(r+1)(r+2)] = ¼ − 1/[2(n+1)(n+2)]  ·  Σ r(r+1)…(r+k) = r(r+1)…(r+k)(r+k+1)/(k+2)

L-1

Sum to n terms — Σn, Σn², Σn³ & the method of differences

  • The chapter's spine is three standard sums that every other series is reduced to.
  • Any term Tn that is a polynomial in n is summed by splitting it across these three and Σ1 = n.
  • Method of differences: when a series is not an A.P./G.P. but the successive differences Dk = Tk+1 − Tk form an A.P. (or G.P.), first build Tn = T1 + (D1 + D2 + … + Dn−1), then sum.
sum of first n natural numbers1 + 2 + 3 + … + n = Σn = n(n+1)/2
sum of squares1² + 2² + 3² + … + n² = Σn² = n(n+1)(2n+1)/6
sum of cubes1³ + 2³ + 3³ + … + n³ = Σn³ = [ n(n+1)/2 ]² = (Σn)²
⚠ Book misprint (p.71)The module states the squares theorem as "1² + 2² + … + n² = n(n−1)(2n−1)/6", but its own proof correctly reaches n(n+1)(2n+1)/6. Use the +1 form: a quick check at n = 1 gives 1, the wrong form gives 0.
How the method of differences works
Suppose Tn is unknown but Dk = Tk+1 − Tk is an A.P. Then Tn = T1 + Σk=1n−1 Dk, and Σ Dk is an ordinary A.P. sum. Once Tn is a polynomial in n, Sn = ΣTn is obtained termwise from Σn², Σn, Σ1. The same idea handles "sum of sums" like 1 + (1+2) + (1+2+3) + … where each term is itself a triangular number.
Worked examples from the module
Book Example-1 · L-1
Find the sum to n terms of the series 1 + 3 + 9 + 19 + 33 + …
Differences 2, 6, 10, 14, … are an A.P. (a = 2, d = 4), so the general term is Tn = 1 + 2(n−1)² = 2n² − 4n + 3.
Sn = Σ(2n² − 4n + 3) = 2·n(n+1)(2n+1)/6 − 4·n(n+1)/2 + 3n = n(n+1)(2n+1)/3 − 2n(n+1) + 3n.
Combine over 3: Sn = n[ (n+1)(2n+1) − 6(n+1) + 9 ]/3 = n[ 2n² − 3n + 4 ]/3.
Sn = n(2n² − 3n + 4)/3  (check n = 2: 2·6/3 = 4 = 1+3 ✓)
Book Example-2 · L-1
Show that (1·2² + 2·3² + … + n(n+1)²) / (1²·2 + 2²·3 + … + n²(n+1)) = (3n + 5)/(3n + 1).
Numerator term = n(n+1)² = n³ + 2n² + n; denominator term = n²(n+1) = n³ + n².
ΣNum = (Σn³) + 2(Σn²) + Σn = [n(n+1)/2]² + 2·n(n+1)(2n+1)/6 + n(n+1)/2 = n(n+1)(3n² + 11n + 10)/12.
ΣDen = (Σn³) + Σn² = [n(n+1)/2]² + n(n+1)(2n+1)/6 = n(n+1)(3n² + 7n + 2)/12.
Factor: 3n² + 11n + 10 = (n+2)(3n+5) and 3n² + 7n + 2 = (n+2)(3n+1). The common n(n+1)(n+2)/12 cancels.
Ratio = (3n + 5)/(3n + 1)
Book Example-3 · L-1
Find the sum to n terms of 1 + (1 + 2) + (1 + 2 + 3) + …
The k-th term is a triangular number: Tk = 1 + 2 + … + k = k(k+1)/2 = (k² + k)/2.
Sn = ½(Σk² + Σk) = ½[ n(n+1)(2n+1)/6 + n(n+1)/2 ] = ½·n(n+1)[ (2n+1) + 3 ]/6 = ½·n(n+1)(2n+4)/6.
Sn = n(n+1)(n+2)/6
Book Example-4 · L-1
Find the sum to n terms of 1² + 5² + 9² + …
The bases 1, 5, 9, … are an A.P. with Tn = 4n − 3, so the term is (4n − 3)² = 16n² − 24n + 9.
Sn = 16·n(n+1)(2n+1)/6 − 24·n(n+1)/2 + 9n = (n/3)[ 8(n+1)(2n+1) − 36(n+1) + 27 ].
Inside: 16n² + 24n + 8 − 36n − 36 + 27 = 16n² − 12n − 1.
Sn = n(16n² − 12n − 1)/3  (check n = 1: (16 − 12 − 1)/3 = 1 ✓)
⚠ Book misprint (Example-4 answer line)The module's boxed answer reads n(16n² + 12n − 1)/3, but its own previous line simplifies 24n − 36n = −12n. The +12n version fails the n = 1 check (gives 9, not 1). The correct sum is n(16n² − 12n − 1)/3.
L-2

Arithmetico-Geometric series (A.G.P.) & the difference method

  • An arithmetico-geometric progression multiplies, term by term, an A.P. by a G.P.: Tn = [a + (n−1)d]·rn−1. (Example: 1 + 4x + 7x² + 10x³ + …, where 1,4,7,10 is the A.P. and 1,x,x²,x³ the G.P.)
  • The one trick: to sum an A.G.P. write S, then write rS (or (1/2)S when the ratio is ½) shifted by one place, and subtract. The A.P.-part collapses to a constant and the remainder is a plain G.P.
  • The same subtract-a-shifted-copy idea is the method of difference for turning any tricky sum into a geometric one.
general termTn = [ a + (n − 1)d ] · rn − 1  — A.P. part (a, d), G.P. part (first term 1, ratio r)
sum to infinity, |r| < 1S∞ = a/(1 − r) + d·r/(1 − r)²
Deriving the infinite-sum formula
S = a + (a+d)r + (a+2d)r² + …; then rS = ar + (a+d)r² + …. Subtracting, (1 − r)S = a + d(r + r² + r³ + …) = a + d·r/(1 − r). Divide by (1 − r): S∞ = a/(1 − r) + d·r/(1 − r)². For a finite sum the same subtraction leaves an extra −[a + (n−1)d]rn/(1 − r) tail — do not drop it.
💡 Recognising the A.G.P.If the coefficients 1, 4, 7, 10, … are an A.P. and the powers x⁰, x¹, x², … are a G.P., you have an A.G.P. — never try Σn² on it. Multiply-and-subtract is the only move.
Worked examples from the module
Book Example-1 · L-2
Find 1·2 + 2·2² + 3·2³ + … + 100·2¹⁰⁰.
S = Σk=1100 k·2k. Then 2S = Σ k·2k+1; subtract: S − 2S = Σ2k − 100·2¹⁰¹.
−S = (2 + 2² + … + 2¹⁰⁰) − 100·2¹⁰¹ = (2¹⁰¹ − 2) − 100·2¹⁰¹ = −99·2¹⁰¹ − 2.
So S = 99·2¹⁰¹ + 2 = 99·2·2¹⁰⁰ + 2 = 198·2¹⁰⁰ + 2.
1·2 + 2·2² + … + 100·2¹⁰⁰ = 198·2¹⁰⁰ + 2
Book Example-2 · L-2
Find the sum to n terms of 1/2 + 2/4 + 3/8 + 4/16 + 5/32 + …
S = Σk=1n k/2k. Multiply by ½: S/2 = Σ k/2k+1, shifted one place.
Subtract: S − S/2 = ½ + (1/4 + 1/8 + … + 1/2n) − n/2n+1, i.e. S/2 = (½ + ½ + 1/4 + … + 1/2n) − n/2n+1.
The bracket is a G.P.: S/2 = (2n − 1)/2n − n/2n+1 = (2n+1 − 2 − n)/2n+1.
Sn = (2n+1 − 2 − n)/2n  (check n = 1: (4 − 2 − 1)/2 = ½ ✓)
Book Example-3 · L-2
Find the nth term of the A.G.P. 0 + 3x + 6x² + 9x³ + 12x⁴ + …
A.P. part 0, 3, 6, 9, … has a = 0, d = 3, so its nth term is 3(n − 1). G.P. part has first term 1 (the x⁰ that multiplies the "0"), ratio x, so its nth factor is xn−1.
Tn = 3(n − 1)xn − 1
Book Example-4 · L-2
Evaluate Σi=1∞ i²/2i.
S = 1/2 + 4/4 + 9/8 + 16/16 + …. This is not a bare A.G.P. (the numerator is i², quadratic), so difference twice.
Take T = S/2. Differencing S once gives T = S/2 = Σ(2i−1)/2i = 1/2 + 3/4 + 5/8 + 7/16 + … (an A.G.P.).
Difference T again: T/2 = ½ + (2/4 + 2/8 + 2/16 + …) = ½ + (2/4)/(1 − ½) = ½ + 1 = 3/2, so T = 3.
Hence S = 2T = 6.
Σi=1∞ i²/2i = 6
Book Example-5 · L-2
If the sum to infinity of 1 + 4x + 7x² + 10x³ + … is 35/16, find x.
A.G.P. with a = 1, d = 3, ratio x. S∞ = 1 + (3x + 3x² + …) all over (1 − x): (1 − x)S∞ = 1 + 3x/(1 − x) = (1 + 2x)/(1 − x).
So S∞ = (1 + 2x)/(1 − x)². Set = 35/16: 35(1 − x)² = 16(1 + 2x) ⇒ 32x² − 102x + 19 = 0.
(7x − 19)(5x − 1) = 0 ⇒ x = 19/7 or x = 1/5. Convergence needs |x| < 1, so reject 19/7.
x = 1/5
Book Example-6 · L-2
Evaluate Σi=1∞ (2i − 1)/2i+1.
Split: Σ(2i−1)/2i+1 = Σ i/2i − Σ 1/2i+1.
First is the A.G.P. a = ½, d = 1, r = ½: sum = (½)/(1 − ½) + (1)(½)/(1 − ½)² = 1 + (½)/(¼) = 1 + 2 = 3.
Second is a G.P.: Σi≥1 1/2i+1 = (1/4)/(1 − ½) = ½.
3 − ½ = 5/2 = 2.5
L-3

The Vn method — telescoping sums of products & reciprocals

  • When a term is 1 / (a product of factors in A.P.), or itself a product of consecutive A.P. factors, the sum telescopes: write Tr = Vr − Vr+1 and the middle cancels.
  • Reciprocal rule: for 1/[(first factor)(…)(last factor)], multiply and divide so the numerator becomes (last − first)/(gap × extra factor); each term splits into two pieces that cancel with neighbours.
  • Product rule: Σ (r)(r+1)…(r+k) = (r)(r+1)…(r+k)(r+k+1)/(k+2) — extend the product by one factor and divide by the number of factors + 1. This works only when the factors themselves form an A.P. with the first factors in one A.P.
telescoping engineTr = Vr − Vr+1 ⇒ Σr=1n Tr = V1 − Vn+1
product of consecutive factorsΣr=1n r(r+1)(r+2) = n(n+1)(n+2)(n+3)/4  (and similarly for k+1 factors ÷ (k+2))
Why the reciprocal telescope works
For Tr = 1/[r(r+1)(r+2)], note 1/[r(r+1)] − 1/[(r+1)(r+2)] = [(r+2) − r]/[r(r+1)(r+2)] = 2/[r(r+1)(r+2)]. So Tr = ½{ 1/[r(r+1)] − 1/[(r+1)(r+2)] } and the sum collapses to ½{ 1/(1·2) − 1/[(n+1)(n+2)] }. The general product-in-denominator case uses the same "difference of the outer factors = gap × spread" identity.
Worked examples from the module
Book Example-1 · L-3
Sum to n terms: 4/(1·2·3) + 5/(2·3·4) + 6/(3·4·5) + …
Tr = (r + 3)/[r(r+1)(r+2)]. Write r + 3 = ½[(r+2)(something)]… more simply split into partial-telescopes: Tr = A/[r(r+1)] − A/[(r+1)(r+2)] with the constant fixed by the numerator.
Matching gives Tr = 5/2·{1/[r(r+1)] − 1/[(r+1)(r+2)]} − adjustments; carrying the algebra, Sn = 5/4 − (2n + 5)/[2(n+1)(n+2)].
Check n = 1: 5/4 − 7/(2·2·3) = 5/4 − 7/12 = 15/12 − 7/12 = 8/12 = 2/3 = 4/(1·2·3) ✓.
Sn = 5/4 − (2n + 5)/[2(n + 1)(n + 2)]
Book Example-2 · L-3
If Σr=1n Tr = (n/8)(n+1)(n+2)(n+3), find Σr=1n 1/Tr.
Tn = Sn − Sn−1 = (1/8)[ n(n+1)(n+2)(n+3) − (n−1)n(n+1)(n+2) ] = (1/8)·n(n+1)(n+2)·[(n+3) − (n−1)] = ½·n(n+1)(n+2).
So 1/Tn = 2/[n(n+1)(n+2)] = 1/[n(n+1)] − 1/[(n+1)(n+2)] (telescopes).
Σ 1/Tr = 1/(1·2) − 1/[(n+1)(n+2)] = ½ − 1/[(n+1)(n+2)] = (n² + 3n)/[2(n+1)(n+2)].
Σ 1/Tr = (n² + 3n)/[2(n + 1)(n + 2)]
Book Example-3 · L-3
Sum to n terms: 1/[(1+x)(1+2x)] + 1/[(1+2x)(1+3x)] + …
Tr = 1/[(1+rx)(1+(r+1)x)]. The gap between the two factors is x, so Tr = (1/x)·{ 1/(1+rx) − 1/(1+(r+1)x) }.
Telescoping: Sn = (1/x)·{ 1/(1+x) − 1/(1+(n+1)x) } = n/[(1+x)(1+(n+1)x)].
Sn = n / [(1 + x)(1 + (n + 1)x)]
Book Example-4 · L-3
Find the sum to n terms of 1/(1·3·7) + 1/(3·5·9) + 1/(5·7·11) + …
Here Vn = 1/[(2n−1)(2n+1)(2n+5)]. Insert the missing consecutive factor: Vn = (2n+3)/[(2n−1)(2n+1)(2n+3)(2n+5)].
Write 2n+3 = ½[(2n+5) − (2n−1)]·(spread), splitting into two four-factor telescopes with the standard "constant − tail" shape.
Fixing the constant C at n = 1 (1/(1·3·7) = C − 17/(3·3·4·5·7)) gives C = 11/180.
Sn = 11/180 − (6n + 11)/[12(2n+1)(2n+3)(2n+5)].
Check n = 1: 11/180 − 17/(12·3·5·7) = 77/1260 − 17/1260 = 60/1260 = 1/21 = 1/(1·3·7) ✓.
Sn = 11/180 − (6n + 11)/[12(2n + 1)(2n + 3)(2n + 5)]
💡 The product-sum side note (module)The same rule sums products: for 1·3·5 + 2·4·6 + 3·5·7 + … the term Vn = (n+2)(n+4) is rewritten as n(n+1)(n+2) + 3n(n+1) + 3n, and each piece is summed by "extend the product, divide by the count." Result: Sn = ¼·n(n+1)(n+4)(n+5), the constant being zero.
L-4

Arithmetic, Geometric & Harmonic Means — insertion & properties

  • If three quantities are in A.P./G.P./H.P., the middle one is the A.M. / G.M. / H.M. of the outer two.
  • Insertion: to place n means between a and b, make a, (means), b a single A.P./G.P./H.P. of (n + 2) terms and read off the interior terms.
  • Two structural facts drive the harder questions: the n inserted means each sum/product to n × the single mean, and for two numbers A > G with x² − 2Ax + G² = 0 giving the numbers back as A ± √(A² − G²).
single means of a, bA = (a + b)/2  ·  G = √(ab)  ·  H = 2ab/(a + b)
insert n arithmetic meansd = (b − a)/(n + 1),  Ak = a + k(b − a)/(n + 1);  Σ Ak = n·(a + b)/2 = n × single A.M.
insert n geometric meansr = (b/a)1/(n+1),  Gk = a(b/a)k/(n+1);  product G1…Gn = (√(ab))n = (single G.M.)n
insert n harmonic means1/Hk = 1/a + k(a − b)/[(n+1)ab];  Σ 1/Hk = (n/2)(1/a + 1/b) = n × 1/(single H.M.)
recover the two numbers from A, Gquadratic x² − 2Ax + G² = 0 ⇒  numbers = A ± √(A² − G²)
The three quick "insertion" checks
Inserting 3 A.M.s between 3 and 19: d = (19 − 3)/4 = 4, giving 7, 11, 15. Inserting 3 G.M.s between 1 and 256: r = 2561/4 = 4, giving 4, 16, 64. Inserting 4 H.M.s between 2/3 and 2/13: work in the reciprocal A.P. 3/2, …, 13/2 with d = 1, giving H-means 2/5, 2/7, 2/9, 2/11. Same recipe every time — build the matching progression, read the interior terms.

Book Example-1 · L-4
Find four numbers in A.P. whose sum is 6 and the product of whose extremes is 10 times the product of the means.
Take the four as a − 3d, a − d, a + d, a + 3d. Sum = 4a = 6 ⇒ a = 3/2.
Extremes×: (a − 3d)(a + 3d) = a² − 9d²; means×: (a − d)(a + d) = a² − d². Condition a² − 9d² = 10(a² − d²).
⇒ −9a² + d² = 0 ⇒ d² = 9a² = 9·(9/4) = 81/4 ⇒ d = ±9/2.
With d = 9/2: the numbers are 3/2 − 27/2, 3/2 − 9/2, 3/2 + 9/2, 3/2 + 27/2 = −12, −3, 6, 15. (d = −9/2 just reverses them.)
−12, −3, 6, 15
Book Example-2 · L-4
Two consecutive numbers are removed from 1, 2, 3, …, n and the mean of the rest is 105/4. Find n and the removed numbers.
Remove P and P + 1. Remaining sum = n(n+1)/2 − (2P + 1), over (n − 2) terms: [n(n+1)/2 − (2P+1)]/(n − 2) = 105/4.
⇒ 2n² − 103n − 8P + 206 = 0. Since P must be an integer, n is even; setting n = 2 + 8t leads (with 1 ≤ P < n) to t = 6.
Then n = 50 and P = 7.
n = 50; the removed numbers are 7 and 8
Book Example-3 · L-4
Insert 5 geometric means between 576 and 9.
576, G1, …, G5, 9 is a G.P. of 7 terms: r = (9/576)1/6 = (1/64)1/6 = 1/2.
G1 = 576·½ = 288, G2 = 144, G3 = 72, G4 = 36, G5 = 18.
288, 144, 72, 36, 18
Book Example-4 · L-4
If a, b, c are in G.P. and ax² + 2bx + c = 0, dx² + 2ex + f = 0 share a common root, show that d/a, e/b, f/c are in A.P.
a, b, c in G.P. ⇒ b² = ac ⇒ b = √(ac). Then ax² + 2bx + c = ax² + 2√(ac)x + c = (√a·x + √c)² = 0, a repeated root x = −√(c/a).
This root also satisfies the second equation: d(c/a) − 2e√(c/a) + f = 0. Divide by c and use √(c/a) = 1/b·√(ac)·… i.e. 1/√(ac) = 1/b: d/a − 2e/b + f/c = 0.
So 2e/b = d/a + f/c.
d/a, e/b, f/c are in A.P.
Book Example-5 · L-4
The sum of four numbers in G.P. is 60 and the A.M. of the first and last is 18. Find the numbers.
Take a, ar, ar², ar³. Sum a(1 + r + r² + r³) = 60, i.e. a(1 + r)(1 + r²) = 60. A.M. of first & last: (a + ar³)/2 = 18 ⇒ a(1 + r)(1 − r + r²) = 36.
Divide: (1 + r²)/(1 − r + r²) = 60/36 = 5/3 ⇒ 3 + 3r² = 5 − 5r + 5r² ⇒ 2r² − 5r + 2 = 0 ⇒ (r − 2)(2r − 1) = 0.
r = 2 (or ½). With r = 2, a(1 + 2)(1 + 4) = 60 ⇒ 15a = 60 ⇒ a = 4.
4, 8, 16, 32 (r = ½ gives the same four reversed)
Book Example-6 · L-4
The A.M. of two positive numbers exceeds the G.M. by 5, and the G.M. exceeds the H.M. by 4. Find the numbers.
(a + b)/2 − √(ab) = 5 and √(ab) − 2ab/(a + b) = 4. Substitute (a + b)/2 = 5 + √(ab) into the second.
√(ab) − ab/(5 + √(ab)) = 4 ⇒ 5√(ab) + ab − ab = 20 + 4√(ab) ⇒ √(ab) = 20 ⇒ ab = 400.
Then (a + b)/2 = 5 + 20 = 25 ⇒ a + b = 50. With ab = 400: numbers solve x² − 50x + 400 = 0 ⇒ x = 40, 10.
40 and 10
Book Example-7 · L-4
If the A.M. and G.M. of two positive numbers a and b are 10 and 8, find the numbers.
a + b = 20 and ab = 64, so a, b are roots of x² − 20x + 64 = 0.
x² − 16x − 4x + 64 = 0 ⇒ (x − 16)(x − 4) = 0 ⇒ x = 4, 16.
4 and 16
Book Example-8 · L-4
Find r so that (pr+1 + qr+1)/(pr + qr) is the geometric mean of p and q.
Set (pr+1 + qr+1)/(pr + qr) = √(pq). Cross-multiply and collect: pr+1 − pr+½q½ = p½qr+½ − qr+1.
pr+½(p½ − q½) = qr+½(p½ − q½) ⇒ pr+½ = qr+½ ⇒ (p/q)r+½ = 1 = (p/q)0.
Since p ≠ q, the exponent must vanish: r + ½ = 0.
r = −1/2
L-5

Relation between the means — the A ≥ G ≥ H inequality & its uses

  • For two positive numbers, the three means are linked two ways: G² = A·H (so A, G, H are themselves a G.P.) and the ordering A ≥ G ≥ H, with equality only when the numbers are equal.
  • For n positive numbers, A ≥ G still holds (equality iff all equal) — this single inequality proves almost every "special/miscellaneous" inequality in the chapter.
  • Technique: apply A ≥ G (or A ≥ H, G ≥ H) to a cleverly chosen set of positive numbers or pairs, then multiply / add the resulting inequalities.
the master relationsA = (a+b)/2, G = √(ab), H = 2ab/(a+b) ⇒  G² = A·H  and  A ≥ G ≥ H  (equality ⇔ a = b)
n-number form(a1 + a2 + … + an)/n ≥ (a1a2…an)1/n  (equality ⇔ a1 = … = an)
💡 The reading of "in A.P. / G.P. / H.P."If a, b, c, d are in A.P. then A.M. of any three > G.M. of them; in G.P., A.M. > G.M. and G.M. > H.M. give the outer-vs-inner comparisons; in H.P. the reciprocals are an A.P. so the same tools apply to 1/a, 1/b, …. Choosing "first three" and "last three" and multiplying is the recurring move.
Worked examples from the module
Book Example-1 · L-5
If a, b, c, d are four distinct positive quantities in A.P., show (a) bc > ad, and (b) c⁻¹d⁻¹ + a⁻¹b⁻¹ > 2(b⁻¹d⁻¹ + a⁻¹c⁻¹ − a⁻¹d⁻¹).
(a) A.M. > G.M. on the first three: b > √(ac) ⇒ b² > ac; on the last three: c > √(bd) ⇒ c² > bd. Multiply: b²c² > (ac)(bd) ⇒ bc > ad.
(b) A.M. > H.M. on first three: b > 2ac/(a + c) ⇒ ab + bc > 2ac; on last three: c > 2bd/(b + d) ⇒ bc + cd > 2bd.
Add: ab + cd + 2bc > 2ac + 2bd ⇒ ab + cd > 2(ac + bd − bc). Divide every term by abcd.
c⁻¹d⁻¹ + a⁻¹b⁻¹ > 2(b⁻¹d⁻¹ + a⁻¹c⁻¹ − a⁻¹d⁻¹)
Book Example-2 · L-5
If a, b, c are positive, prove (b + c)(c + a)(a + b) ≥ 8abc.
A.M. ≥ G.M. on each pair: (b + c)/2 ≥ √(bc), (c + a)/2 ≥ √(ca), (a + b)/2 ≥ √(ab).
Multiply the three: (1/8)(b + c)(c + a)(a + b) ≥ √(bc·ca·ab) = abc.
(b + c)(c + a)(a + b) ≥ 8abc
Book Example-3 · L-5
If a, b, c, d are four distinct positive quantities in G.P., show (i) a + d > b + c and (ii) c⁻¹d⁻¹ + a⁻¹b⁻¹ > 2(b⁻¹d⁻¹ + a⁻¹c⁻¹ − a⁻¹d⁻¹).
(i) A.M. > G.M. on first three: (a + c)/2 > b ⇒ a + c > 2b; on last three: (b + d)/2 > c ⇒ b + d > 2c. Add: a + c + b + d > 2b + 2c ⇒ a + d > b + c.
(ii) G.M. > H.M. on first three: b > 2ac/(a + c) ⇒ ab + bc > 2ac; on last three: c > 2bd/(b + d) ⇒ bc + cd > 2bd. Add and divide by abcd, as in Example-1.
a + d > b + c, and the reciprocal inequality follows
Book Example-4 · L-5
If a, b, c, d are four distinct positive quantities in H.P., show (i) a + d > b + c and (ii) ad > bc.
(i) A.M. > H.M. on first three: (a + c)/2 > b ⇒ a + c > 2b; on last three: (b + d)/2 > c ⇒ b + d > 2c. Add: a + d > b + c.
(ii) G.M. > H.M. on first three: √(ac) > b ⇒ ac > b²; on last three: √(bd) > c ⇒ bd > c². Multiply: (ac)(bd) > b²c² ⇒ ad > bc.
a + d > b + c and ad > bc
Book Example-5 · L-5
If a, b, c are distinct positive numbers in H.P., prove aⁿ + cⁿ > 2bⁿ.
A.M. > G.M. on aⁿ, cⁿ: (aⁿ + cⁿ)/2 > (aⁿcⁿ)1/2 = (ac)n/2 ⇒ aⁿ + cⁿ > 2(ac)n/2 … (i).
Since a, b, c in H.P., G.M. > H.M. gives √(ac) > b ⇒ (ac)n/2 > bⁿ … (ii).
Combine (i) and (ii).
aⁿ + cⁿ > 2bⁿ
Book Example-6 · L-5
Show (i) (b + c)/a + (c + a)/b + (a + b)/c > 6, and (ii) 8xyz < (1 − x)(1 − y)(1 − z) < 8/27 when x + y + z = 1 (x, y, z > 0).
(i) Group as (b/a + a/b) + (c/b + b/c) + (a/c + c/a); each pair t + 1/t ≥ 2 by A.M. ≥ G.M., and equality is impossible for distinct terms, so the sum > 6.
(ii) Right bound: A.M. ≥ G.M. on 1 − x, 1 − y, 1 − z gives [(3 − (x+y+z))/3]³ ≥ (1−x)(1−y)(1−z), i.e. (2/3)³ = 8/27 ≥ product.
Left bound: with x + y + z = 1, 1 − x = y + z > 2√(yz), similarly 1 − y > 2√(zx), 1 − z > 2√(xy). Multiply: (1−x)(1−y)(1−z) > 8√(x²y²z²) = 8xyz.
8xyz < (1 − x)(1 − y)(1 − z) < 8/27
Book Example-7 · L-5
Show that nⁿ·((n + 1)/2)2n > (n!)³.
Apply A.M. > G.M. to the n distinct positives 1³, 2³, …, n³: (1³ + 2³ + … + n³)/n > (1³·2³·…·n³)1/n = (n!)3/n.
The left side is [n(n+1)/2]²/n = n(n+1)²/4, so n(n+1)²/4 > (n!)3/n, i.e. n²(n+1)²/(4n) > ((n!)³)1/n.
Raise both sides to the power n: nⁿ·((n + 1)/2)2n > (n!)³.
nⁿ·((n + 1)/2)2n > (n!)³
Book Example-8 · L-5
If a, b, c are positive with a + b + c = 1, find the minimum of 1/(ab) + 1/(bc) + 1/(ca).
1/(ab) + 1/(bc) + 1/(ca) = (a + b + c)/(abc) = 1/(abc).
A.M. ≥ G.M.: (a + b + c)/3 ≥ (abc)1/3 ⇒ 1/3 ≥ (abc)1/3 ⇒ abc ≤ 1/27 ⇒ 1/(abc) ≥ 27.
Equality at a = b = c = 1/3.
Minimum value = 27

Let S = 1/(1!·25!) + 1/(3!·23!) + 1/(5!·21!) + … up to 13 terms. If 13S = 2k/n!, k ∈ ℕ, then n + k = ?  (a) 50 (b) 49 (c) 52 (d) 51
Each term is 1/[(2r−1)!(27 − 2r)!], and the two factorial arguments always add to 26. Multiply S by 26!: 26!·S = Σ 26!/[(odd)!(26 − odd)!] = C(26,1) + C(26,3) + … + C(26,25).

Strong Box · PYQ 11 · JEE Advanced 2007 (Paper-2)

An = (An−1 + Hn−1)/2. Since An−1 > Hn−1 (the numbers stay distinct), An lies strictly between them, so An < An−1.

Strong Box · PYQ 12 · JEE Advanced 2007 (Paper-2)

Hn = 2An−1Hn−1/(An−1 + Hn−1), the H.M. of An−1 and Hn−1; it lies strictly between them, so Hn > Hn−1.
