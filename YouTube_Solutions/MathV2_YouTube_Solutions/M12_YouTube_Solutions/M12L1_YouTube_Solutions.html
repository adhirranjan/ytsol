(a) Both A and R are individually true and R is the correct explanation of A (b) Both A and R are individually true but R is not the correct explanation of A (c) A is true but R is false (d) A is false but R is truetangent product assertion reasonIf \( A, B, C \) are the angles of an acute-angled triangle, show that \( \tan A \cdot \tan B \c...🟡 SimilardA is false but R is true
Concept In every triangle (no right angle) tan A + tan B + tan C = tan A tan B tan C. For an acute triangle all three tangents are positive and AM-GM pushes the product up to at least 3√3, so it can never equal 1: the Assertion is false. In an obtuse triangle exactly one tangent is negative, so the product is negative: the Reason is true. Trap: confusing this with the identity tan(A/2)tan(B/2) + … = 1.
Formula Σtan A = Πtan A and Σtan A ≥ 3(Πtan A)1/3 First from tan(A + B) = tan(π − C) = −tan C; second is AM-GM, valid only when all tangents are positive.
Solution
1. tan(A + B) = −tan C ⇒ (tanA + tanB)/(1 − tanA tanB) = −tanC ⇒ tanA + tanB + tanC = tanA tanB tanC.
2. Acute triangle: let P = tanA tanB tanC > 0. AM-GM: P = Σtan A ≥ 3P1/3 ⇒ P2/3 ≥ 3 ⇒ P ≥ 3√3.
3. So in an acute triangle P ≥ 3√3 ≈ 5.196 > 1; P = 1 is impossible ⇒ Assertion false.
4. Equilateral check: tan 60°3 = (√3)3 = 3√3, the minimum, still not 1 ✓.
5. Obtuse triangle, say A > 90°: tan A < 0 while B, C are acute with tan B, tan C > 0 ⇒ product < 0 ⇒ Reason true. Only one angle can be obtuse.
6. Example: A = 120°, B = C = 30°: (−√3)(1/√3)(1/√3) = −1/√3 < 0 ✓; and sum = −√3 + 2/√3 = −1/√3, matching the identity.
