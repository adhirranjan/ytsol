Concept Average velocity is a vector: net displacement ÷ total time. Average speed is a scalar: total path length ÷ total time. Both share the same denominator (total time), so their magnitudes can only be equal when the numerators match — i.e. when the length of the path actually travelled equals the straight-line displacement. Geometrically that demands a path with no bends and no reversals.
Formula |v_avg| = |Δs| ÷ t and speed_avg = (path length) ÷ t; equal ⇒ path length = |Δs|. Path length ≥ |displacement| for every motion, with equality only for a straight, one-way trip.
Solution
1. Write both definitions over the same interval t; the ratio speed/|velocity| = (path length)/|Δs| ≥ 1 always.
2. Equality needs path length = |Δs|, which is possible only if the particle never turns back — motion stays in one fixed direction along a line.Any curve or reversal makes the odometer reading exceed the crow-flight distance.
3. Option (a) curved path: length > |Δs| ⇒ speed > |v_avg| — fails.
4. Options (c) constant acceleration and (d) constant retardation allow the body to slow, stop and reverse (e.g. a ball thrown up), so in general length > |Δs| — not guaranteed equal.
5. Option (b) "in the same direction": no reversal, straight track ⇒ length = |Δs| ⇒ |v_avg| = speed_avg ✓.

⚡ JEE Trick Remember the one-line law: distance ≥ |displacement|, with equality iff the motion is straight and never turns back. Trap: students pick "constant acceleration" thinking uniform motion, but constant acceleration can point opposite to velocity and cause a turnaround (projectile going up then down), breaking the equality.
Answer: (b) in the same direction.

Concept The two legs (out and back) cover the same distance d but at different speeds. When equal distances are travelled at different speeds, the correct average is the harmonic mean, not the arithmetic mean. The slower leg eats up more time, so it must count more heavily — exactly what the harmonic mean does.
Formula v_avg = total distance ÷ total time = 2d ÷ (t_u + t_d), with tₖ = d/vₖ. Distances are equal, so d cancels and only the speeds survive.
Solution
1. Let each leg length = d. Time out t_u = d/v_u; time back t_d = d/v_d.
2. Total distance = d + d = 2d; total time = d/v_u + d/v_d = d(v_d + v_u)/(v_u v_d).
3. v_avg = 2d ÷ [d(v_u + v_d)/(v_u v_d)] — the d cancels top and bottom.
4. v_avg = 2 v_u v_d ÷ (v_u + v_d), the harmonic mean of the two speeds — option (d).Check limits: if v_u = v_d = v it gives v ✓; and the result is always ≤ the arithmetic mean.
 leg      length   speed    time
 X → Y    d        v_u      d/v_u
 Y → X    d        v_d      d/v_d
 ---------------------------------------
 v_avg = 2d / (d/v_u + d/v_d)
       = 2 v_u v_d / (v_u + v_d)   <-- answer (d)
⚡ JEE Trick Equal distances ⇒ harmonic mean 2v₁v₂/(v₁+v₂); equal times ⇒ arithmetic mean (v₁+v₂)/2. Trap: option (c) is the tempting arithmetic mean and option (a) the geometric mean — both wrong here because the equal quantity is distance, not time. Memorise: the average speed of a there-and-back trip is always below the plain average of the two speeds.
Answer: (d) 2v_d v_u/(v_d + v_u).
