1 (i)Fill in the blank: If a > b > 0 then 1/a ______ 1/b.Reciprocal inequality propertyInequality proofs — reciprocals of positive numbers🟢 Exact<
Concept For positive numbers, taking reciprocals reverses the order: the larger a positive number is, the smaller its reciprocal. So if a is bigger than b and both are positive, 1/a comes out smaller than 1/b. The trap is dropping the "both positive" condition — the clean flip is guaranteed only when a and b share the same sign and neither is zero.
Formula a > b > 0 ⇒ 1/a < 1/b One-line proof: divide the inequality a > b by the positive product ab.
Solution
1. Given a > b > 0; both numbers positive, so their product ab > 0.
2. Divide both sides of a > b by ab (a positive quantity, direction kept): a/(ab) > b/(ab) ⇒ 1/b > 1/a.Dividing by a positive number never flips an inequality.
3. Read the last line the other way round: 1/a < 1/b. The blank is "<".
4. Numerical check with a = 4, b = 2: 1/a = 1/4, 1/b = 1/2, and 1/4 < 1/2. ✓
5. Why "positive" matters: take a = 2, b = −3 (still a > b). Now 1/a = 0.5 but 1/b = −0.33, so 1/a > 1/b — the flip fails the moment the two numbers straddle 0.

Concept The sign of a product or a quotient of two non-zero reals is decided purely by whether the two numbers agree in sign. Two like signs (both +, or both −) give a positive result because the two minus signs cancel; unlike signs give a negative result. Since both ab and a/b are given as positive, a and b must carry the same sign.
Formula ab > 0 ⇔ a/b > 0 ⇔ a and b have the same sign; ab < 0 ⇔ a/b < 0 ⇔ a and b have opposite signs (b ≠ 0 throughout). a/b = ab / b², and b² > 0 always, so a/b and ab always carry the same sign — the two conditions are equivalent, not independent.
Solution
1. Enumerate the only two possibilities for a pair of non-zero reals: same sign or opposite signs.
2. Case A — both positive (a > 0, b > 0): ab = (+)(+) = positive ✓ and a/b = (+)/(+) = positive ✓. Both conditions hold.
3. Case B — both negative (a < 0, b < 0): ab = (−)(−) = positive ✓ and a/b = (−)/(−) = positive ✓. Both conditions hold again.
4. Case C — opposite signs: ab = (+)(−) = negative ✗, contradicting ab > 0. Rejected.
5. Cases A and B are exactly "a and b have the same sign" — so that is the answer.Both surviving cases share this one description; the data cannot tell us which sign, only that they agree.

The bracket shapes in the template are themselves data — the open left bracket must come from the strict x > 0, and the closed right bracket from the slack ≤.
Formula ax + b ≤ c ⇒ x ≤ (c − b)/a when a > 0 (no flip); the final set is {x : x ≤ (c−b)/a} ∩ {x : x > 0}. Dividing by the positive coefficient 2 preserves the direction of the inequality.

3. Bring in the given restriction x > 0 and intersect the two conditions: 0 < x ≤ 3.x must satisfy both simultaneously, so we take the overlap of (0, ∞) and (−∞, 3].
4. Write it as an interval: x ∈ (0, 3] — 0 is excluded (strict >) and 3 is included (slack ≤).

3 (ii)Find p, q, r: the solution of 3 − 2x < 1 is of the form x ∈ {p, q, r}, where x is an integer < 5 and p < q < r.Integer solutions of a linear inequalitySolving an inequality and finding the integer solution set🟡 Similarp = 2, q = 3, r = 4
Concept A linear inequality whose x-coefficient is negative, so the direction must flip at the dividing step — the single most common source of error in this chapter. After solving over the reals, the answer must be restricted twice: to integers, and to those below 5. The result is a short finite list, which is why the template is a set {p, q, r} rather than an interval.
Formula divide by a negative number ⇒ reverse the inequality sign. Then the integer solution set is {x ∈ ℤ : solved condition AND x < 5}. Restricting a real interval to integers means listing the whole numbers strictly inside it.
Solution
1. Start from 3 − 2x < 1 and subtract 3 from both sides: −2x < −2.Subtraction is safe — it never changes the inequality's direction.
2. Divide both sides by −2. The divisor is negative, so the sign flips from < to >: x > (−2)/(−2) = 1.Multiplying by a negative reflects the number line about 0, reversing every order relation.
3. So over the reals x > 1, i.e. x ∈ (1, ∞) — and note 1 itself is excluded (strict).
4. Apply the two restrictions: x must be an integer and x < 5. Combining, 1 < x < 5 with x ∈ ℤ.
5. List the integers strictly between 1 and 5: 2, 3, 4. (1 fails x > 1; 5 fails x < 5.)Both bounds are strict, so neither endpoint qualifies.
6. Match the template {p, q, r} with p < q < r, in increasing order: p = 2, q = 3, r = 4.
7. Verify each: x = 2 ⇒ 3 − 4 = −1 < 1 ✓; x = 3 ⇒ 3 − 6 = −3 < 1 ✓; x = 4 ⇒ 3 − 8 = −5 < 1 ✓; and x = 1 ⇒ 3 − 2 = 1 < 1 is false ✓ (correctly excluded).

        x > 1             (÷ by −2  -->  FLIP < to >)

   integers with  1 < x < 5 :

Answer: x ∈ {2, 3, 4} ⇒ p = 2, q = 3, r = 4.

Formula strict: a < b or a > b (endpoint out); slack: a ≤ b or a ≥ b (endpoint in). The presence of the little bar under the symbol is what makes it slack.
Solution
1. (a) x ≤ 5 — carries the bar (≤), equality allowed ⇒ slack, not strict.
2. (b) x ≥ 7 — carries the bar (≥) ⇒ slack, not strict.
3. (c) 3 < 8 — pure "<", no equality ⇒ strict. (It is also a true statement.) ✓
4. (d) y ≤ −1 — bar again (≤) ⇒ slack.
5. Only option (c) uses a bare strict sign, so it is the answer.

Concept The additive property of inequalities: adding the same number to both sides shifts both quantities by an identical amount, so their relative order is untouched. Geometrically it slides both points the same distance along the number line — the one on the left stays on the left. Crucially, "both sides" means both: adding 3 to only one side is a different (and wrong) operation.
Formula a < b ⇒ a + c < b + c for every real c. Because (b + c) − (a + c) = b − a, the gap between the two sides is unchanged, so the sign of the difference — and hence the direction of the inequality — is preserved. The same holds for >, ≤ and ≥.
Solution
1. Start from the given true statement: 5 < 9.
2. Add 3 to the left side: 5 + 3 = 8.
3. Add 3 to the right side: 9 + 3 = 12.The same 3 must be added to both sides for the property to apply.
4. By the additive property the direction is unchanged (still <), giving 8 < 12 — option (b).
5. Sanity-check the gap: before, 9 − 5 = 4; after, 12 − 8 = 4. Identical, confirming the order could not have changed.A translation preserves distance, so the inequality must survive intact.
6. Eliminate the distractors: (a) 8 < 9 added 3 to the left only; (c) 5 < 12 added 3 to the right only; (d) 3 < 6 is unrelated to the given numbers.

9Solve the inequation 2x³ − 3x² + 7x − 3 > 0.Cubic inequality, sign chartInequalities — wavy curve method (Class 11 / JEE)🟡 Similar(1/2, ∞)
Concept A cubic inequality whose quadratic cofactor has a negative discriminant. That quadratic never touches the x-axis and, having a positive leading coefficient, is positive for every real x — so it can be divided out without affecting the inequality at all. The whole cubic then reduces to a single linear condition. Spotting the irreducible factor is what turns a hard-looking cubic into a one-liner.
Formula rational root p/q: p divides the constant, q divides the leading coefficient; D = b² − 4ac < 0 with a > 0 ⇒ the quadratic is > 0 for all real x. Dividing an inequality by an always-positive factor preserves its direction.
Solution
1. Let f(x) = 2x³ − 3x² + 7x − 3. Candidate rational roots are p/q with p | 3 (±1, ±3) and q | 2 (±1, ±2): so ±1, ±3, ±1/2, ±3/2.
2. Test x = 1: 2 − 3 + 7 − 3 = 3 ≠ 0 ✗. Test x = 1/2: 2(1/8) − 3(1/4) + 7(1/2) − 3 = 0.25 − 0.75 + 3.5 − 3 = 0 ✓.
3. So x = 1/2 is a root and (2x − 1) is a factor.A root at x = 1/2 corresponds to the factor (x − 1/2), i.e. (2x − 1) after clearing the fraction.
4. Divide synthetically by (x − 1/2) on the coefficients 2, −3, 7, −3: bring down 2; (1/2)(2) − 3 = −2; (1/2)(−2) + 7 = 6; (1/2)(6) − 3 = 0 ✓. Quotient: 2x² − 2x + 6.
5. So f(x) = (x − 1/2)(2x² − 2x + 6) = (2x − 1)(x² − x + 3), after moving the factor 2 from the quadratic into the linear term.
6. Examine the quadratic x² − x + 3. Its discriminant is D = (−1)² − 4(1)(3) = 1 − 12 = −11 < 0.
7. Since D < 0 and the leading coefficient 1 is positive, x² − x + 3 has no real roots and is positive for every real x.Completing the square confirms it: x² − x + 3 = (x − 1/2)² + 11/4 ≥ 11/4 > 0 always.
8. Therefore we may divide the inequality by x² − x + 3 without any flip: the condition reduces to 2x − 1 > 0.
9. Solve: 2x > 1 ⇒ x > 1/2 ⇒ x ∈ (1/2, ∞), with 1/2 excluded (there f = 0, and the inequality is strict).
10. Verify: f(1) = 2 − 3 + 7 − 3 = 3 > 0 ✓; f(1/2) = 0, and 0 > 0 is false ✗ (correctly excluded); f(0) = −3 > 0 is false ✗; f(−1) = −2 − 3 − 7 − 3 = −15 > 0 is false ✗.

      f(1)   = 2 − 3 + 7 − 3 = 3   ≠ 0

          2  −2   6   0        ->  2x² − 2x + 6 = 2(x² − x + 3)

⚡ JEE Trick Always check the discriminant of a quadratic cofactor: if D < 0 with a positive leading coefficient, the factor is positive everywhere and can be discarded — a cubic collapses to a linear inequality. For a cubic with only one real root, the answer is always a single ray. Trap: attempting to "factor" x² − x + 3 and inventing roots — it has none over ℝ; confirm with D or by completing the square.
Answer: x ∈ (1/2, ∞) — since 2x³ − 3x² + 7x − 3 = (2x − 1)(x² − x + 3) and x² − x + 3 > 0 for all real x.
10Solve the inequation x⁴ + 6x³ + 6x² + 6x + 5 < 0.Quartic inequality, factorisingSolve the inequality X^4+6x^3+6x^2+6x+5 less than equal to 0🟢 Exact(−5, −1)
Concept A quartic inequality that factorises into two linear factors and an irreducible quadratic (x² + 1), which is positive for every real x. Once that always-positive factor is divided out, the quartic reduces to a simple quadratic inequality of the form (x+1)(x+5) < 0 — whose solution is the interval strictly between the roots.
Formula x² + 1 > 0 for all real x (a square is ≥ 0, so adding 1 makes it ≥ 1); (x−p)(x−q) < 0 ⇔ x strictly between p and q. Dividing by an always-positive factor never changes the direction of the inequality.
Solution
1. Let f(x) = x⁴ + 6x³ + 6x² + 6x + 5. Test the candidates ±1, ±5 (divisors of the constant 5).
2. Test x = −1: 1 − 6 + 6 − 6 + 5 = 0 ✓, so (x + 1) is a factor.
3. Divide by (x + 1) synthetically on 1, 6, 6, 6, 5 using the root −1: bring down 1; −1 + 6 = 5; −5 + 6 = 1; −1 + 6 = 5; −5 + 5 = 0 ✓. Quotient: x³ + 5x² + x + 5.
4. Factor the cubic by grouping: x³ + 5x² + x + 5 = x²(x + 5) + 1(x + 5) = (x + 5)(x² + 1).Grouping is faster here than testing more roots — the pairing is visible from the repeated (x+5).
5. So the full factorisation is f(x) = (x + 1)(x + 5)(x² + 1) < 0.
6. Examine x² + 1: since x² ≥ 0 for every real x, we get x² + 1 ≥ 1 > 0 — it is always positive and never zero (its discriminant is 0 − 4 = −4 < 0, so it has no real roots).
7. Divide the inequality by the always-positive x² + 1 — no flip: the condition reduces to (x + 1)(x + 5) < 0.
8. The roots of this product are x = −5 and x = −1. A product of two linear factors is negative strictly between its roots.
9. So −5 < x < −1 ⇒ x ∈ (−5, −1). Both endpoints are excluded, since there f = 0 and the inequality is strict.
10. Confirm with a sign chart on (−∞,−5), (−5,−1), (−1,∞): the product is +, −, + respectively, so only the middle interval qualifies.
11. Verify at x = −2: f(−2) = 16 − 48 + 24 − 12 + 5 = −15 < 0 ✓ — satisfied.
12. Verify the endpoints and outside: f(−1) = 1 − 6 + 6 − 6 + 5 = 0, and 0 < 0 is false ✗ (excluded); f(−5) = 625 − 750 + 150 − 30 + 5 = 0, likewise excluded ✗; f(0) = 5 > 0 ✗; f(−6) = 1296 − 1296 + 216 − 36 + 5 = 185 > 0 ✗.
