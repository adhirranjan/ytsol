Concept The defining feature of an A.P. is the gap between neighbouring terms. Shifting every term by the same amount slides the whole progression along the number line without changing any gap — so the sequence is still an A.P. and its common difference is untouched.
Formula (an+1 ± k) − (an ± k) = an+1 − an = d the ±k cancels between consecutive terms
Solution
1. Let the new sequence be bn = an ± k.
2. Test the difference of consecutive new terms: bn+1 − bn = (an+1 ± k) − (an ± k).
3. The ±k appears once with each sign and cancels: bn+1 − bn = an+1 − an = d, a constant.
4. A constant difference is exactly the definition of an A.P., so the new sequence is an A.P. with the same common difference d.Only the first term moves: it becomes a₁ ± k.
5. Concrete check: 2, 5, 8, 11 (d = 3). Add 7: 9, 12, 15, 18 — still d = 3 ✓.
6. Consequence for sums: Snnew = Sn ± nk, because each of the n terms picked up the same ±k.
   b_n = a_n +- k
   b_(n+1) - b_n = a_(n+1) - a_n = d     (unchanged)

   2, 5, 8, 11   (d = 3)
   +7 -> 9, 12, 15, 18   (d = 3)

Answer: an AP — with the same common difference d.

Concept Two constant step-sizes added together give another constant step-size. Formally, the general term of each A.P. is linear in n, and the sum of two linear functions is linear — so the combined sequence is an A.P.
Formula (an+1 ± bn+1) − (an ± bn) = d₁ ± d₂ d₁, d₂ are the two common differences
Solution
1. Let cn = an ± bn.
2. cn+1 − cn = (an+1 − an) ± (bn+1 − bn) = d₁ ± d₂.
3. Both d₁ and d₂ are constants, so their sum (or difference) is a constant — hence cn is an A.P.
4. Linear-function view: an = a + (n−1)d₁ and bn = b + (n−1)d₂ are both linear in n; adding gives (a ± b) + (n−1)(d₁ ± d₂), again linear ⇒ A.P.
5. Concrete check: 2, 5, 8 (d = 3) plus 1, 3, 5 (d = 2) gives 3, 8, 13 with d = 5 = 3 + 2 ✓.
6. Note the edge case: if d₁ = d₂ then the difference sequence has d = 0 — a constant sequence, which is still (trivially) an A.P.

Answer: an AP — with common difference d₁ ± d₂.

Concept Picking out every second term of an A.P. gives another A.P. — same first term, but double the common difference. Both sums have the same mean (the central term), so the ratio is just the ratio of the two term-counts.
Formula odd-place terms: a₁, a₃, a₅, … with common difference 2d; S = (count) × (middle term)
Solution
1. Write n = 2m + 1 (odd). The full A.P. has 2m + 1 terms.
2. Odd places are positions 1, 3, 5, …, 2m+1 — that is m + 1 terms, forming an A.P. with first term a and common difference 2d.
3. Both progressions are symmetric about the same centre term a + md, so each sum equals its count times that centre: S₁ = (2m+1)(a + md) and S₂ = (m+1)(a + md).
4. Ratio: S₁/S₂ = (2m + 1)/(m + 1). Now substitute m = (n − 1)/2, so m + 1 = (n + 1)/2.
5. S₁/S₂ = n / [(n+1)/2] = 2n/(n + 1).
6. Compare with pn/(rn − q): p = 2 and rn − q = n + 1 ⇒ r = 1, q = −1. Check n = 5 (terms 1..5, d = 1, a = 1): S₁ = 15, odd places 1, 3, 5 sum to 9, and 15/9 = 5/3 = 2(5)/6 ✓.

⚡ JEE Trick The pay-off here is beautiful: the three arguments turn out to be 2, 4, 8 — a G.P. That is the general principle behind every log-A.P. question: logs are in A.P. exactly when the arguments are in G.P. Spotting that lets you skip straight to (2n − 1)² = 2(2n + 3), which is just the G.P. mean condition.
Answer: (b) log₂5.
9The sequence log a, log(a²/b), log(a³/b²), …… is   (a) A.G.P.   (b) A.P.   (c) A.H.P.   (d) Both a G.P. and a H.P.Log laws turn a pattern into a linear termShow that the sequence log a, log(a^2/b), log(a^3/b^2), log(a^4/b^3), ... forms an A.P.🟢 ExactbA.P.
Concept Expand each logarithm with log(x/y) = log x − log y and log xᵏ = k log x. What emerges is a general term that is linear in n — the signature of an A.P.
Formula log(an/bn−1) = n log a − (n − 1) log b
Solution
1. Expand the terms: t₁ = log a; t₂ = log(a²/b) = 2 log a − log b; t₃ = log(a³/b²) = 3 log a − 2 log b.
2. The pattern for the general term is tn = n log a − (n − 1) log b.
3. Compute the difference: t₂ − t₁ = (2log a − log b) − log a = log a − log b.
4. And t₃ − t₂ = (3log a − 2log b) − (2log a − log b) = log a − log b — the same.
5. Generally tn+1 − tn = log a − log b = log(a/b), a constant. So the sequence is an A.P. → option (b).
6. Numerical check with a = 100, b = 10 (base 10): terms are 2, 3, 4, … with d = 1 = log(100/10) ✓.
   t_n = log(a^n / b^(n-1)) = n log a - (n-1) log b

   t2 - t1 = log a - log b
   t3 - t2 = log a - log b        (constant)

   => AP with d = log(a/b)

   a=100, b=10 (base 10) : 2, 3, 4, ...   d = 1
⚡ JEE Trick Whenever a sequence is built from logarithms, expand first and look at the exponents. If the exponents themselves move in A.P. (here 1, 2, 3 on a and 0, 1, 2 on b), the logarithms form an A.P. The mirror rule is the one from Q8: arguments in G.P. ⇔ logarithms in A.P.
Answer: (b) A.P.  (with common difference log(a/b)).
10If p, q, r are in A.P. and are positive, the roots of the quadratic equation px² + qx + r = 0 are all real for   (a) |r/p − 7| ≥ 4√3   (b) |p/r − 7| < 4√3   (c) All p and r   (d) No p and rDiscriminant condition under an A.P. constraintIf p, q, r are positive and are in AP, the roots of quadratic equation px^2 + qx + r = 0 are real🟢 Exacta|r/p − 7| ≥ 4√3
Concept Real roots need D = q² − 4pr ≥ 0. The A.P. condition replaces q by (p + r)/2, turning the inequality into one in p and r only — and dividing by p² reduces it to a single-variable quadratic inequality in t = r/p.
Formula q = (p + r)/2; D = q² − 4pr ≥ 0
Solution
1. p, q, r in A.P. ⇒ 2q = p + r ⇒ q = (p + r)/2.
2. Real roots require q² ≥ 4pr, i.e. (p + r)²/4 ≥ 4pr ⇒ (p + r)² ≥ 16pr.
3. Expand: p² + 2pr + r² ≥ 16pr ⇒ p² − 14pr + r² ≥ 0.
4. Divide by p² (positive) and set t = r/p: t² − 14t + 1 ≥ 0.
5. The roots of t² − 14t + 1 = 0 are t = (14 ± √192)/2 = 7 ± 4√3. So the inequality holds for t ≤ 7 − 4√3 or t ≥ 7 + 4√3.
6. Both branches together say the distance of t from 7 is at least 4√3, i.e. |r/p − 7| ≥ 4√3 → option (a).
   2q = p + r    ->   q = (p+r)/2
   D >= 0 :  (p+r)^2/4 >= 4pr
             (p+r)^2 >= 16 pr
             p^2 - 14pr + r^2 >= 0

   t = r/p :  t^2 - 14t + 1 >= 0
   roots  :  t = 7 +- 4 sqrt3
   =>  |r/p - 7| >= 4 sqrt3
⚡ JEE Trick "Outside the roots" for an upward parabola is exactly what an absolute-value inequality with ≥ encodes: t² − 14t + 1 ≥ 0 with roots 7 ± 4√3 becomes |t − 7| ≥ 4√3, where 7 is the midpoint of the roots and 4√3 is half their separation. Learn to read a quadratic inequality straight into that form — it converts to the printed option in one step. Note also that option (b) writes p/r instead of r/p and uses a strict <, so it is wrong on both counts.
Answer: (a) |r/p − 7| ≥ 4√3.
