1 (i)Sum of first n terms of an A.P. is denoted by ______.Notation for the sum of a seriesJEE Mathematics — Sum of n terms of an AP: theory and problem solving🟡 SimilarSn
Concept A sequence and a series are different objects and get different symbols. The terms of an A.P. are a₁, a₂, a₃, …, and the nth term carries the lower-case symbol an (or tn). The moment you start adding those terms you have a series, and the running total of the first n of them gets the capital letter Sn.
Formula Sn = a₁ + a₂ + a₃ + … + an the subscript n counts how many terms have been added, not which term you have reached
Solution
1. Name the pieces: aₙ = the nth term (one number); Sₙ = the sum of the first n terms (one number, but built from n of them).
2. Read the subscript the same way in both: a₅ is the fifth term alone, S₅ is a₁ + a₂ + a₃ + a₄ + a₅.This is why S₅ is almost always much larger than a₅.
3. The two are linked: adding one more term moves you from Sₙ₋₁ to Sₙ, and the extra bit is exactly aₙ. So Sₙ = Sₙ₋₁ + aₙ.
4. Rearranged, that link is the recovery formula of part (iv): aₙ = Sₙ − Sₙ₋₁.
5. Hence the blank is the capital-S symbol Sₙ.
   terms   :  a1, a2, a3, ... , an        <- sequence
   sum     :  Sn = a1 + a2 + ... + an     <- series
   link    :  Sn = S(n-1) + an
   inverse :  an = Sn - S(n-1)
⚡ JEE Trick Whenever a question hands you an expression in n — like 2n² + 5n — the very first thing to decide is whether it is aₙ or Sₙ. A quadratic in n is almost always Sₙ (because Σ of a linear term is quadratic); a linear expression in n is almost always aₙ. Misreading which one you were given is the single most common way to lose this entire question type.
Answer: Sn.
1 (ii)The formula of the sum of n terms of an A.P. is ______.The master sum formulaArithmetic Progression — proof of the sum of n terms (ExamSolutions)🟢 ExactSn = (n/2)[2a + (n−1)d]
Concept The formula is not something to memorise blindly — it comes from Gauss's pairing trick. Write the sum forwards, write it again backwards underneath, and add column by column. Every column gives the same total, because as one term climbs by d the other falls by d.
Formula Sn = (n/2)[2a + (n−1)d] a = first term, d = common difference, n = number of terms
Solution
1. Write Sₙ = a + (a+d) + (a+2d) + … + [a+(n−1)d].
2. Write the same sum in reverse: Sₙ = [a+(n−1)d] + … + (a+d) + a.
3. Add the two lines term-by-term. Each of the n columns totals 2a + (n−1)d — the d's cancel in pairs.Column 1: a + [a+(n−1)d]. Column 2: (a+d) + [a+(n−2)d] = 2a + (n−1)d. Same every time.
4. So 2Sₙ = n[2a + (n−1)d], giving Sₙ = (n/2)[2a + (n−1)d].
5. Sanity check with n = 1: S₁ = (1/2)[2a + 0] = a. Correct.
6. Check with n = 2: S₂ = (2/2)[2a + d] = 2a + d = a + (a+d). Correct.
     Sn =  a      + (a+d)      + ... + [a+(n-1)d]
     Sn = [a+(n-1)d] + [a+(n-2)d] + ... +  a
   -------------------------------------------------  add
    2Sn = [2a+(n-1)d] repeated n times
    2Sn = n[2a + (n-1)d]
     Sn = (n/2)[2a + (n-1)d]
⚡ JEE Trick Expand the formula once and keep the expanded version in your head: Sₙ = (d/2)n² + (a − d/2)n. It is a quadratic in n with zero constant term. That single observation instantly solves a whole family of questions — "is this sequence an A.P.?", "find d from Sₙ = pn + qn²", "S₀ = 0 always".
Answer: Sn = (n/2)[2a + (n−1)d].
1 (iii)If first term of A.P. is a, last term is ℓ then sum of n terms of an A.P. is ______.Sum from the two end termsThe sum of an A.P. — Sₙ = n/2(2a+(n−1)d) and Sₙ = n/2(a+ℓ)🟢 ExactSn = (n/2)(a + ℓ)
Concept This is the same formula as (ii), just wearing different clothes. The bracket 2a + (n−1)d is nothing but "first term + last term", because the last term is ℓ = a + (n−1)d. Use this version whenever the problem hands you both ends of the progression and never mentions d.
Formula Sn = (n/2)(a + ℓ) = n × (average of the two ends) ℓ = a + (n−1)d is the nth (last) term
Solution
1. Start from Sₙ = (n/2)[2a + (n−1)d] and split the bracket as a + {a + (n−1)d}.
2. The second piece is exactly the last term ℓ.
3. Substitute: Sₙ = (n/2)(a + ℓ).
4. Read it as "number of terms × mean of first and last" — legitimate because in an A.P. the mean of the two ends equals the mean of all the terms.The terms are evenly spaced, so they balance about their midpoint.
5. Example: 2 + 5 + 8 + … + 182 has a = 2, ℓ = 182, n = 61, so S = (61/2)(184) = 61 × 92 = 5612 — one line, no d needed.
   l  = a + (n-1)d          (last term)
   Sn = (n/2)[2a + (n-1)d]
      = (n/2)[ a + {a+(n-1)d} ]
      = (n/2)(a + l)        <- both ends only
⚡ JEE Trick When a question gives you both endpoints of a range ("all three-digit multiples of 7", "all integers between 100 and 800 leaving remainder 7"), this is always the faster formula: find a, find ℓ, find n = (ℓ − a)/d + 1, then multiply. You never touch the (n−1)d bracket at all.
Answer: Sn = (n/2)(a + ℓ).
1 (iv)If Sn is given then an is ______.Recovering the term from the sumIf Sₙ, the sum of first n terms of an A.P., is 2n²+n, find its nth term🟢 Exactan = Sn − Sn−1
Concept Sₙ already contains every term up to the nth. Sₙ₋₁ contains every term up to the (n−1)th. Subtract, and everything common cancels — the only survivor is the single term aₙ. This is the discrete version of differentiation.
Formula an = Sn − Sn−1 valid for n ≥ 2; for n = 1 use a₁ = S₁ directly
Solution
1. Sₙ = a₁ + a₂ + … + aₙ₋₁ + aₙ.
2. Sₙ₋₁ = a₁ + a₂ + … + aₙ₋₁.
3. Subtracting line 2 from line 1 kills every term except the last: aₙ = Sₙ − Sₙ₋₁.
4. Worked instance: Sₙ = 2n² + 5n ⇒ Sₙ₋₁ = 2(n−1)² + 5(n−1) = 2n² − 4n + 2 + 5n − 5 = 2n² + n − 3.
5. aₙ = (2n² + 5n) − (2n² + n − 3) = 4n + 3. Check: a₁ = 7 = S₁ = 2 + 5 ✓.
6. Since aₙ came out linear in n, the sequence is automatically an A.P. with d = coefficient of n = 4.
   Sn     = a1 + a2 + ... + a(n-1) + an
   S(n-1) = a1 + a2 + ... + a(n-1)
   ------------------------------------ subtract
   an     = Sn - S(n-1)

   Sn = 2n^2+5n  ->  an = 4n+3,  d = 4
⚡ JEE Trick Skip the algebra entirely: if Sₙ = An² + Bn, then aₙ = 2An + (B − A) and d = 2A. Just double the coefficient of n² to get the common difference. This one-liner cracks Level-3 Q4, Q5, Level-4 Q4 and Level-5 Q7 of this very lecture in a few seconds each.
Answer: an = Sn − Sn−1  (with a₁ = S₁).

Concept You are given the term, not the sum. Read a and d straight off the linear expression — the coefficient of k is d, and putting k = 1 gives a — then feed them into the sum formula and force the result into the printed shape.
Formula Σ(5k+1) = 5·Σk + Σ1 = 5·n(n+1)/2 + n or use a = 6, d = 5 in Sₙ = (n/2)[2a+(n−1)d]
Solution
1. ak = 5k + 1 is linear in k, so this is an A.P.: a = a₁ = 6, d = 5.
2. Sum directly: Sₙ = Σk=1..n(5k + 1) = 5·n(n+1)/2 + n.
3. Put over a common denominator: Sₙ = (5n² + 5n + 2n)/2 = (5n² + 7n)/2.
4. Factor out n: Sₙ = (n/2)(5n + 7).Exactly the printed shape (n/p)(qn + r).
5. Compare: p = 2, q = 5, r = 7.
6. Verify with n = 2: (2/2)(10 + 7) = 17, and a₁ + a₂ = 6 + 11 = 17 ✓.
   ak = 5k+1  ->  a = 6, d = 5
   Sn = 5*n(n+1)/2 + n = (5n^2+7n)/2 = (n/2)(5n+7)
   compare (n/p)(qn + r)  ->  p=2, q=5, r=7
⚡ JEE Trick For any linear term aₖ = Ak + B the sum is Sₙ = (n/2)(An + A + 2B). Memorise that one line and every "kth term is …, find Sₙ" question becomes pure substitution: here A = 5, B = 1 gives (n/2)(5n + 5 + 2) = (n/2)(5n + 7) instantly.

3 (ii)Find the value of p, q, r: the sum of first n natural numbers is pn(n + q)/r.The Σn identitySum to n terms of special series — Sequence and Series Class 11🟡 Similarp = 1, q = 1, r = 2
Concept The natural numbers 1, 2, 3, … are the simplest possible A.P.: a = 1, d = 1. Their sum is the single most-used identity in the whole chapter, and it is worth being able to write it without thinking.
Formula 1 + 2 + 3 + … + n = n(n+1)/2 Gauss's schoolboy result — pair 1 with n, 2 with n−1, …
Solution
1. Treat it as an A.P.: a = 1, d = 1, n terms, last term ℓ = n.
2. Ends-form: Sₙ = (n/2)(a + ℓ) = (n/2)(1 + n) = n(n+1)/2.
3. Write it as the printed shape pn(n + q)/r: numerator n(n + 1), denominator 2, no extra multiplier in front.
4. So p = 1, q = 1, r = 2.
5. Check n = 4: 1(4)(5)/2 = 10 = 1 + 2 + 3 + 4 ✓.
6. Note this is not unique-looking but is unique in lowest terms — writing 2n(n+1)/4 would also be "true", so the intended reading is the reduced form.
   1+2+...+n  (a=1, d=1, l=n)
   Sn = (n/2)(1+n) = n(n+1)/2
   pn(n+q)/r  ->  p=1, q=1, r=2
⚡ JEE Trick Keep the trio ready: Σn = n(n+1)/2, Σn² = n(n+1)(2n+1)/6, Σn³ = [n(n+1)/2]². Notice Σn³ = (Σn)² — that curiosity shows up in JEE Main almost every other year, usually disguised as "1³ + 2³ + … + n³ equals which of the following".
Answer: p = 1, q = 1, r = 2  ⇒  Σn = n(n+1)/2.
3 (iii)Find the value of p, q, r: the sum of the series 3 + 5 + 7 + 6 + 9 + 12 + 9 + 13 + 17 + … to 3n terms is pn(qn − r).Grouping a non-A.P. into an A.P. of blocksFind the sum of the series: 3 + 5 + 7 + 6 + 9 + 12 + 9 + 13 + 17 + ... to 3n terms🟢 Exactp = 3, q = 2, r = −3
Concept The series as written is not an A.P. — the differences run +2, +2, −1, +3, +3, −3, … The clue is "to 3n terms": the terms come in blocks of three. Sum each block, and the block totals form a clean A.P. This "group first, then progress" move is a standard JEE dodge.
Formula S = Σ(block totals) = (n/2)[2A + (n−1)D] A = first block total, D = common difference of the block totals
Solution
1. Cut into triples: (3, 5, 7), (6, 9, 12), (9, 13, 17), …
2. Block totals: 3+5+7 = 15; 6+9+12 = 27; 9+13+17 = 39.
3. 15, 27, 39, … is an A.P. with A = 15 and D = 12.Confirm the pattern continues: the next triple is (12, 17, 22) totalling 51 = 39 + 12 ✓.
4. Adding 3n original terms means adding n whole blocks: S = (n/2)[30 + 12(n−1)] = (n/2)(12n + 18) = n(6n + 9).
5. Factor 3: S = 3n(2n + 3).
6. Match against pn(qn − r): p = 3, q = 2, and qn − r = 2n + 3 forces r = −3.
   (3,5,7) (6,9,12) (9,13,17) ...
   block totals : 15, 27, 39, ...   A=15, D=12
   3n terms  =  n blocks
   S = (n/2)[30 + 12(n-1)] = n(6n+9) = 3n(2n+3)
   pn(qn - r) = 3n(2n + 3)  ->  p=3, q=2, r=-3
⚡ JEE Trick The phrase "to 3n terms" (or 2n, or 4n) is never decoration — it is telling you the block size. Whenever the term count is a multiple of some k and the raw differences look chaotic, cut the series into runs of k and sum the runs. Also note the sign trap here: the printed template has a minus (qn − r), so a genuinely positive +3 must be reported as r = −3.
Answer: p = 3, q = 2, r = −3  ⇒  S = 3n(2n + 3).

Formula 1+3+5+…+(2n−1) = n²; Sn = (n/2)[2a+(n−1)d]; Sn = (n/2)(a+ℓ)
Solution
1. (A) Odd numbers 1, 3, …, 2001: 2n − 1 = 2001 ⇒ n = 1001. Sum = n² = 1001² = 1002001 → (s).
2. (B) a + 11d = −13 and S₄ = 2(2a + 3d) = 24 ⇒ 2a + 3d = 12. Substituting a = −13 − 11d gives −26 − 22d + 3d = 12 ⇒ −19d = 38 ⇒ d = −2, a = 9.

4. (C) a = −14, a + 4d = 2 ⇒ d = 4. Then Sₙ = (n/2)[−28 + 4(n−1)] = n(2n − 16) = 40 ⇒ n² − 8n − 20 = 0 ⇒ (n−10)(n+2) = 0 ⇒ n = 10 → (q).

1Which of these represents the sum of 3 A.P. terms? (Level-1)   (a) 3a   (b) 3d   (c) 3a + d   (d) 3a (since (a − d) + a + (a + d))Symmetric selection of three termsTrick for three numbers in A.P. when the sum and product are known🟢 Exactd3a  ⚠
Concept When a problem tells you three numbers are in A.P. and gives you their sum, do not write them as a, a+d, a+2d. Centre them instead: a − d, a, a + d. The d's then cancel on addition and the sum collapses to a single unknown.
Formula (a − d) + a + (a + d) = 3a the middle term is always sum ÷ 3
Solution
1. Take the three terms symmetrically about their middle: a − d, a, a + d.
2. Add: (a − d) + a + (a + d). The −d and +d annihilate.
3. Sum = 3a, i.e. three times the middle term.
4. Cross-check with the ordinary labelling a, a+d, a+2d: sum = 3a + 3d = 3(a + d), and a + d is the middle term — the same statement.So option (c) 3a + d is wrong under either labelling.
5. This is why Level-4 Q2 (sum 18) and Level-5 Q8 (sum 33) both start by dividing the sum by 3 to get the middle term instantly.
6. Key note: options (a) and (d) are the same value 3a — (d) simply carries the reason with it. The printed key chooses (d), but (a) is not wrong.
   symmetric : a-d,  a,  a+d      sum = 3a
   ordinary  : a,  a+d,  a+2d     sum = 3(a+d)
   both say  : sum = 3 x (middle term)
⚡ JEE Trick Extend the pattern: 3 terms → a−d, a, a+d; 4 terms → a−3d, a−d, a+d, a+3d (note the gap is 2d); 5 terms → a−2d, a−d, a, a+d, a+2d. Even counts use 2d as the step so that everything stays symmetric about a. Suggested Problems 7, 9 and 10 in this same lecture all fall out in two lines with the 4-term version.
Answer: (d) 3a  — identical in value to option (a). ⚠

Formula Sn ∝ n² ⇒ an = Sn − Sn−1 ∝ n² − (n−1)² = 2n − 1
Solution
1. Sₘ/Sₙ = m²/n² for all m, n forces Sₙ = kn² for some constant k.Fix n and let m vary: Sₘ = (Sₙ/n²)m², so the coefficient is the same k for every index.
2. Recover the term: aₙ = Sₙ − Sₙ₋₁ = k[n² − (n−1)²] = k(2n − 1).
3. Similarly aₘ = k(2m − 1).
4. Ratio: aₘ/aₙ = k(2m−1)/k(2n−1) = (2m − 1)/(2n − 1) → option (b).
5. Consistency with the general bridge: the mth-term ratio is the sum ratio at index 2m − 1 versus 2n − 1, i.e. (2m−1)²/(2n−1)² divided by the count ratio (2m−1)/(2n−1) — giving (2m−1)/(2n−1) ✓.
6. Concrete check: the A.P. 1, 3, 5, 7, … has Sₙ = n² ✓, and a₃/a₂ = 5/3 = (2·3−1)/(2·2−1) ✓.
   Sm/Sn = m^2/n^2   ->  Sn = k n^2
   an = k[n^2 - (n-1)^2] = k(2n-1)
   am/an = (2m-1)/(2n-1)

   model AP : 1, 3, 5, 7, ...   (Sn = n^2)
⚡ JEE Trick "Sₙ ∝ n²" is a complete description of an A.P.: it is k times the odd numbers, so a = k and d = 2k, i.e. d = 2a. That single fact also answers LEVEL-4 Q5 and Q9 of this lecture (S₁₀ = 4S₅ is just S₂ₙ = 2²Sₙ, which is the same proportionality, giving a : d = 1 : 2).
Answer: (b) (2m − 1)/(2n − 1).
7In the arithmetic progression whose common difference is non-zero, the sum of first 3n terms is equal to the sum of next n terms. Then the ratio of the sum of the first 2n terms to the next 2n terms is   (a) 1/5   (b) 2/3   (c) 3/4   (d) noneBlock sums with a constraint (repeat of L4 Q10)In the arithmetic progression whose common difference is non-zero, the sum of first 3n terms equals the sum of the next n terms🟢 Exacta1/5
Concept Word-for-word the same as LEVEL-4 Q10. Convert "sum of next n terms" into S₄ₙ − S₃ₙ, extract the relation between a and d, and substitute it into the two 2n-blocks.
Formula 2S₃ₙ = S₄ₙ ⇒ 2a = (1 − n)d
Solution
1. Condition: S₃ₙ = S₄ₙ − S₃ₙ, i.e. 2S₃ₙ = S₄ₙ.
2. Expand: 3n[2a + (3n−1)d] = 2n[2a + (4n−1)d] ⇒ 6a + (9n−3)d = 4a + (8n−2)d.
3. Solve for a: 2a = (8n − 2 − 9n + 3)d = (1 − n)d.
4. First 2n terms: S₂ₙ = n[2a + (2n−1)d] = n[(1−n)d + (2n−1)d] = n(nd) = n²d.
5. First 4n terms: S₄ₙ = 2n[2a + (4n−1)d] = 2n[(1−n)d + (4n−1)d] = 2n(3nd) = 6n²d. So the next 2n terms sum to 5n²d.
6. Ratio = n²d : 5n²d = 1/5 → option (a). (The condition d ≠ 0 is what makes the cancellation legitimate.)
   2 S(3n) = S(4n)   ->   2a = (1-n)d

   S(2n)      =  n^2 d
   S(4n)      = 6 n^2 d
   next 2n    = 5 n^2 d
   ratio      = 1/5
⚡ JEE Trick Once 2a = (1 − n)d is known, every block sum is a clean multiple of n²d: Sₙ = 0, S₂ₙ = n²d, S₃ₙ = 3n²d, S₄ₙ = 6n²d — the triangular numbers 0, 1, 3, 6 again. Noticing that Sₙ = 0 is a particularly striking consequence and a fast way to sanity-check the relation.
Answer: (a) 1/5.  (Identical to LEVEL-4 Q10.)
8The sum of all two digit natural numbers which leave a remainder 5 when they are divided by 7 is equal to   (a) 715   (b) 702   (c) 615   (d) 602Sum over a residue class (repeat of Q5)The sum of all two digit natural numbers which leave a remainder of 5 when divided by 7🟢 Exactb702
Concept This question is printed twice in the same level — it is a verbatim repeat of Q5. The answer and the reasoning are identical; here the counting is set out via the k-range method as an alternative route.
Formula members are 7k + 5; S = 7·Σk + 5n
Solution
1. General member: 7k + 5 for integer k ≥ 0.
2. Two-digit condition: 10 ≤ 7k + 5 ≤ 99 ⇒ 5 ≤ 7k ≤ 94 ⇒ 0.71 ≤ k ≤ 13.43, so k = 1, 2, …, 13.
3. Count: n = 13.
4. Split the sum: S = Σ(7k + 5) = 7Σk + 5 × 13 = 7 × (13 × 14)/2 + 65.
5. 7 × 91 = 637, plus 65 gives 702 → option (b).
6. Ends-form confirmation: first = 12, last = 96, so S = (13/2)(12 + 96) = 13 × 54 = 702 ✓.
   7k + 5,  k = 1 .. 13
   S = 7 * (13x14)/2 + 5*13
     = 7 x 91 + 65
     = 637 + 65 = 702
⚡ JEE Trick The k-range method (S = m·Σk + r·n) is worth preferring over the ends-form for residue-class sums: you never compute a first or last term, so there is nothing to mis-round, and the two pieces are both standard identities. Note also that the paper repeats questions — Q5/Q8 here and LEVEL-4 Q5/Q9 — so a solved question may reappear.
Answer: (b) 702.  (Identical to Q5 above.)
9The sum of the integers from 1 to 100 which are not divisible by 3 or 5 is   (a) 2489   (b) 4735   (c) 2317   (d) 2632Inclusion–exclusion over three A.P.sThe sum of the integers from 1 to 100 which are not divisible by 3 or 5🟢 Exactd2632
Concept Counting "not divisible" directly is painful. Instead sum everything, then subtract what is divisible by 3 or 5 — remembering that multiples of 15 got subtracted twice and must be added back. That is inclusion–exclusion.
Formula Snot = Sall − (S₃ + S₅ − S₁₅) multiples of 15 lie in both the 3-list and the 5-list
Solution
1. All integers 1…100: S = 100 × 101/2 = 5050.
2. Multiples of 3: 3, 6, …, 99 = 3(1 + … + 33) = 3 × 561 = 1683.
3. Multiples of 5: 5, 10, …, 100 = 5(1 + … + 20) = 5 × 210 = 1050.
4. Multiples of 15 (counted in both): 15, 30, …, 90 = 15(1 + … + 6) = 15 × 21 = 315.
5. Divisible by 3 or 5: 1683 + 1050 − 315 = 2418.
6. Not divisible: 5050 − 2418 = 2632 → option (d).
   all       : 100 x 101 / 2       = 5050
   mult of 3 : 3 x (33x34)/2       = 1683
   mult of 5 : 5 x (20x21)/2       = 1050
   mult of 15: 15 x (6x7)/2        =  315
   3 or 5    : 1683 + 1050 - 315   = 2418
   answer    : 5050 - 2418         = 2632
⚡ JEE Trick Never forget to add back the overlap. If you subtract 1683 and 1050 without restoring the 315, you get 2317 — which is printed as distractor (c) precisely to catch that omission. The overlap divisor is always the LCM of the two (here lcm(3,5) = 15), not their product in general.
Answer: (d) 2632.
10If [x] denotes the greatest integer ≤ x, then the value of S = [√1] + [√2] + [√3] + …… + [√25] is   (a) 125   (b) 70   (c) 75   (d) 120Greatest-integer sum with square blocksHow to find the sum [√1]+[√2]+[√3]+…+[√120] — greatest integer, JEE Main🟢 Exactc75
Concept [√n] stays constant on stretches between consecutive perfect squares. [√n] = k exactly when k² ≤ n < (k+1)², which is a run of 2k + 1 integers. Group the 25 terms into those runs and multiply.
Formula [√n] = k for n = k², k²+1, …, (k+1)² − 1 — that is 2k + 1 values
Solution
1. k = 1: n = 1, 2, 3 → three terms of value 1 (since 4 is the next square). Contribution 1 × 3 = 3.
2. k = 2: n = 4 … 8 → five terms of value 2. Contribution 2 × 5 = 10.
3. k = 3: n = 9 … 15 → seven terms of value 3. Contribution 3 × 7 = 21.
4. k = 4: n = 16 … 24 → nine terms of value 4. Contribution 4 × 9 = 36.
5. k = 5: n = 25 only → one term of value 5 (the run is cut short by the upper limit). Contribution 5.
6. Total: 3 + 10 + 21 + 36 + 5 = 75 → option (c). Term count check: 3 + 5 + 7 + 9 + 1 = 25 ✓.
   [sqrt n] = k  for  k^2 <= n < (k+1)^2   (2k+1 values)

   k=1 : n = 1..3    3 terms  ->  3
   k=2 : n = 4..8    5 terms  -> 10
   k=3 : n = 9..15   7 terms  -> 21
   k=4 : n = 16..24  9 terms  -> 36
   k=5 : n = 25      1 term   ->  5
   ------------------------------------
   terms 25            total  = 75
⚡ JEE Trick Always verify the term count when you group — here 3 + 5 + 7 + 9 + 1 must equal 25, and it does. The last block is nearly always truncated, and forgetting that is how you get distractor (d) 120 (which is what a full k = 5 block of 11 terms would produce). The general closed form for Σn=1m²[√n] is m(m−1)(4m+1)/6 + m; with m = 5 that is 5(4)(21)/6 + 5 = 70 + 5 = 75 ✓ — and note that 70 is printed as distractor (b), the answer you get if you stop before the final +m.
Answer: (c) 75.
