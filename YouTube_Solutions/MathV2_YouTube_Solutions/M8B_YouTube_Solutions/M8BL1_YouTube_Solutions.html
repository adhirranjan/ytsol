1 (i)The first term of G.P. is generally denoted by ______.Notation for the first termGeometric Progression — formula for the nth term, Class 11🟡 Similara
Concept A geometric progression is built from exactly two numbers: where it starts and what it gets multiplied by. The starting value is the first term, universally written a — the same letter used for an A.P., because it plays the same role.
Formula G.P. = a, ar, ar², ar³, … a = first term, r = common ratio
Solution
1. Write out a general G.P.: the first entry is a, and every later entry is the previous one times r.
2. So the list reads a, ar, ar², ar³, … and the blank is a.
3. Note the parallel with an A.P.: there a is the starting value and you add d; here a is the starting value and you multiply by r.Same letter a, different operation.
4. Constraint worth remembering: a ≠ 0. If the first term were 0 every term would be 0 and the ratio would be undefined.
5. Likewise r ≠ 0, for the same reason — a zero ratio kills the progression after the first term.
6. Example: in 3, 6, 12, 24, … we have a = 3 and r = 2.
   G.P. :  a,  ar,  ar^2,  ar^3,  ...
   first term  = a      (a != 0)
   common ratio= r      (r != 0)

   3, 6, 12, 24, ...   ->  a = 3,  r = 2
⚡ JEE Trick Keep the A.P./G.P. correspondence in front of you all chapter: a ↔ a, d ↔ r, a + (n−1)d ↔ arn−1, addition ↔ multiplication. Almost every A.P. property has a G.P. twin obtained by that swap, which is why "sum of terms equidistant from the ends is constant" becomes "product of terms equidistant from the ends is constant".
Answer: a.
1 (ii)The nth term is the ______ of finite G.P. which contains 'n' terms.Last term of a finite G.P.How to find the nth term of a geometric progression — Class 11🟡 Similarlast term
Concept If a progression is declared to have exactly n terms, then position n is the final position — so the nth term is by definition the last term. This is why the symbol ℓ (for "last") and an mean the same thing in a finite progression.
Formula ℓ = an = arn−1 for a finite G.P. of exactly n terms
Solution
1. A finite G.P. with n terms is a, ar, ar², …, arn−1.
2. Counting positions: position 1 holds a, position 2 holds ar, …, position n holds arn−1.
3. There is no position n+1, so arn−1 is the last term.
4. Hence the two notations coincide: ℓ = an = arn−1.Exactly as in an A.P., where ℓ = a + (n−1)d.
5. Practical use: knowing ℓ lets you count the terms, since ℓ/a = rn−1 gives n = 1 + log(ℓ/a)/log r — the result proved in LEVEL-6 Q3 of this lecture.
6. Example: 3, 6, 12, …, 3072 has a = 3, r = 2, and 3072 = 3·210, so n = 11 and 3072 is the 11th (last) term.
   finite G.P. of n terms :
      a,  ar,  ar^2,  ... ,  ar^(n-1)
      pos 1  2     3           n

   last term  l = a_n = a r^(n-1)

   3, 6, 12, ..., 3072 :  3072 = 3 * 2^10  ->  n = 11
⚡ JEE Trick The exponent on r is always one less than the position — the first term carries r⁰ = 1. Every "which term is …?" question reduces to solving rn−1 = (target)/a, so write both sides as powers of the same base and compare exponents rather than taking logs.
Answer: the last term.
1 (iii)The common ratio of G.P. is denoted by ______.Notation for the common ratioGeometric Progression explained with examples🟡 Similarr
Concept The number you multiply by to step forward one place is the common ratio, written r. It is "common" because the same value works at every step — that constancy is precisely what makes the sequence geometric.
Formula r = an+1/an the same value for every n; this is the test for a G.P.
Solution
1. Take any two neighbouring terms and divide the later by the earlier: an+1/an.
2. For a G.P. that quotient is the same number every time, and that number is r.
3. Test in practice: 3, 6, 12, 24 gives 6/3 = 2, 12/6 = 2, 24/12 = 2 — constant, so it is a G.P. with r = 2.
4. Counter-test: 7, 14, 21, 28 gives 2, 1.5, 1.33… — not constant, so not a G.P. (it is an A.P.). That is exactly LEVEL: BOARD Q1(ii) of this lecture.
5. r may be negative (then the terms alternate in sign, as in 1/4, −1/2, 1, −2) or a fraction (then the terms shrink).
6. Only r = 0 is forbidden, since it would make every term after the first equal to zero.
   r = a_(n+1) / a_n     (must be the SAME for every n)

   3, 6, 12, 24 :  2, 2, 2        -> G.P.,  r = 2
   7, 14, 21, 28:  2, 1.5, 1.33   -> NOT a G.P. (it is an A.P.)
   1/4, -1/2, 1, -2 :  -2 each    -> G.P.,  r = -2
⚡ JEE Trick To test a candidate sequence, divide adjacent terms, do not subtract. Two quotients agreeing is not enough — check at least three pairs, because a sequence can accidentally match on one step. And a negative r is the standard trap: the terms alternate sign, so "which term equals this positive number?" forces the position to make the exponent even.
Answer: r.
1 (iv)The nth term of the G.P. is ______.The general-term formulaGeometric Progression — formula for the nth term, Class 11🟢 Exactan = arn−1
Concept Reaching position n from position 1 takes n − 1 multiplications by r. So the nth term is the first term carrying r to the power (n − 1) — the multiplicative twin of a + (n−1)d.
Formula an = arn−1 a = first term, r = common ratio
Solution
1. a₁ = a (no multiplications yet, i.e. r⁰).
2. a₂ = ar (one multiplication), a₃ = ar² (two), a₄ = ar³ (three).
3. The exponent always trails the position by one, so an = arn−1.
4. Check at n = 1: ar⁰ = a ✓ — the safety test that kills the wrong version arⁿ.arⁿ at n = 1 gives ar, which is the second term.
5. Companion formula for counting backwards: the nth term from the end is ℓ(1/r)n−1, used four separate times in this lecture.
6. Example: 2, 6, 18, … has a = 2, r = 3, so a₅ = 2·3⁴ = 162.
   a1 = a       = a r^0
   a2 = ar      = a r^1
   a3 = ar^2
   ...
   an = a r^(n-1)          <- exponent = position - 1

   from the end :  a_n(end) = l (1/r)^(n-1)
⚡ JEE Trick Pair the two directions and you can answer almost every term question instantly: from the start an = arn−1, from the end an = ℓ/rn−1. Suggested Problem 4, Quick Recap 2(D), Quick Recap 4(D) and LEVEL-3 Q4 of this lecture are all the second formula with different numbers — one division each.
Answer: an = arn−1.
