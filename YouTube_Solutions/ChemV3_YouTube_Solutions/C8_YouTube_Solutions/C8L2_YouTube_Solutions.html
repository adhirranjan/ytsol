1 (i)Fill in the blank: Oxidant is a substance in which the oxidation number of one of the atoms ____oxidant reductant definitionsOxidizing and Reducing Agents | Easy Trick🟡 Similardecreases
Concept An oxidant (oxidising agent) is the species that brings about oxidation of the other reactant, and to do that it must accept the electrons the other species gives up. Accepting electrons is reduction, so the oxidant is itself reduced. The classic trap is to confuse what the oxidant does to its partner (oxidises it) with what happens to the oxidant itself (it gets reduced).
Key relation gain of e⁻ = reduction = oxidation number falls The blank is about the atom inside the oxidant, and that atom is reduced, so its oxidation number must go down.
Solution
1. Fix the role: an oxidant oxidises its partner, i.e. it pulls electrons away from it.
2. By charge conservation those electrons must land on the oxidant, so the oxidant gains electrons. Electrons are neither created nor destroyed.
3. Gaining electrons is the definition of reduction, so the oxidant is reduced in the reaction.
4. Oxidation number is a formal charge; adding negative electrons makes that number more negative, so the oxidation number of one of its atoms decreases.
5. Worked example: in MnO4− → Mn2+, manganese goes from +7 to +2 (Δ = −5); permanganate is the oxidant and its Mn number falls.
6. Hence the blank is “decreases”.
 oxidant  -> accepts e-  -> is REDUCED
 oxidation number of one atom goes DOWN
 e.g. Mn in MnO4- :   +7  ->  +2   (falls 5)
 -----------------------------------------
 blank = decreases
⚡ JEE Trick Chant “oxidant is reduced, reductant is oxidised” — each agent does the opposite to itself. If you blank out, the oxidant takes electrons, and taking negative charge pulls the number down.
Answer: the oxidation number decreases (the oxidant is reduced).
1 (ii)Fill in the blank: When the oxidation number of an element is maximum it can act only as ____oxidant reductant definitionsOxidizing and Reducing Agents | Easy Trick🟡 Similaroxidising agent
Concept An element sitting at its maximum oxidation number has no electrons left to lose from that bonding set, so it cannot be oxidised any further. The only redox change open to it is to accept electrons and come down, i.e. to be reduced. A species that gets reduced is by definition an oxidising agent, so such an element can act only as an oxidising agent.
Key relation O.N. already maximum ⇒ can only go DOWN ⇒ only reduced Only reduction is possible, and the species that is reduced is the oxidising agent.
Solution
1. Oxidation would require the oxidation number to rise still higher, but it is already at the ceiling for that element.
2. So oxidation is blocked; only a decrease in oxidation number is available. There is room to go down, none to go up.
3. A decrease in oxidation number is reduction, so the species can only be reduced.
4. The species that undergoes reduction is the one that oxidises its partner — it is the oxidising agent.
5. Example: S in H2SO4 and Mn in KMnO4 are at +6 and +7 (their maxima), so both act only as oxidising agents.
6. Hence the blank is “oxidising agent”.
 max O.N. -> no higher state -> cannot oxidise
 only path left:  O.N. decreases (reduction)
 reduced species = OXIDISING agent
 e.g. S(+6) in H2SO4 , Mn(+7) in KMnO4
 -----------------------------------------
 blank = oxidising agent
⚡ JEE Trick “Top of the ladder can only climb down.” Highest oxidation state = pure oxidiser (KMnO4, K2Cr2O7, conc. H2SO4); lowest state = pure reducer. Intermediate states can do either.
Answer: it can act only as an oxidising agent.

1 (v)Fill in the blank: In redox reaction the component which is oxidised act as a ____oxidant reductant definitionsOxidizing and Reducing Agents | Easy Trick🟡 Similarreducing agent
Concept In any redox reaction one partner is oxidised and the other is reduced. The component that is oxidised is the one that lost electrons; those electrons went to the partner and reduced it. By causing the partner’s reduction, the oxidised component acts as the reducing agent. The usual slip is to call the oxidised species “the oxidising agent” — it is the opposite.
Key relation component oxidised = electron donor = reducing agent Being oxidised means it supplied the electrons that reduced the other species.
Solution
1. “Oxidised” means this component lost electrons (its oxidation number rose).
2. Those lost electrons are picked up by the partner, which is thereby reduced. Electrons released must be accepted somewhere.
3. The species that causes reduction of the partner is, by name, the reducing agent.
4. Therefore the oxidised component and the reducing agent are the same species.
5. Example: in Zn + Cu2+ → Zn2+ + Cu, zinc is oxidised (0 → +2) and is the reducing agent that reduces Cu2+.
6. Hence the blank is “reducing agent”.
 component oxidised -> loses e- -> gives them away
 those e- reduce the partner
 so the oxidised one = REDUCING agent
 e.g. Zn(0->+2) reduces Cu2+ in Zn + Cu2+
 -----------------------------------------
 blank = reducing agent
⚡ JEE Trick Cross-pair rule: oxidised ↔ reducing agent, reduced ↔ oxidising agent. The agent is named for what it does to the other species, not to itself, so the labels always cross over.
Answer: it acts as a reducing agent.
2 (i)Which of the following half reactions is an oxidation and which one is a reduction? Identify this and write in the blank space: Zn → Zn2+ + 2e−half reaction oxidation reductionOxidation & Reduction by Electron Transfer method - IIT JEE & NEET | Vineet Khatri Sir | ATP STAR🟡 Similaroxidation
Concept A half-reaction is labelled by the electrons alone: if electrons appear on the product side the species has lost them (oxidation); if electrons appear on the reactant side the species has gained them (reduction). Here loss of electrons is oxidation. The sign check and the oxidation-number change must agree, which guards against a transcription slip in the electron count.
Key relation Zn → Zn2+ + 2e− Loss of electrons is oxidation, so Zn loses electrons and its oxidation number rises.
Solution
1. Write the half-reaction: Zn → Zn2+ + 2e−.
2. Locate the electrons: they are on the product side. That side placement fixes the type.
3. Assign oxidation numbers: Zn goes from 0 to +2.
4. The number rises, which means the species loses electrons — that is oxidation.
5. Electron bookkeeping checks: the change in oxidation number equals the number of electrons shown, so the half-reaction is balanced.
6. So neutral zinc, giving up two electrons, is oxidised to Zn2+; it would serve as a reducing agent.
 Zn -> Zn2+ + 2e-
 O.N. of Zn :  0  ->  +2   (rises)
 electrons on product side  =>  oxidation
 -----------------------------------------
 answer = oxidation
⚡ JEE Trick “LEO the lion says GER”: Loss of Electrons = Oxidation, Gain of Electrons = Reduction. Electrons on the right ⇒ oxidation; electrons on the left ⇒ reduction — read them off directly.
Answer: this half-reaction is a oxidation.

Concept Each equation is first slotted by its skeletal shape — two things joining, one thing splitting, or one element shoved out — and then confirmed as redox by an oxidation-number (ON) change. The trap is telling a decomposition-redox apart from a disproportionation: in the first two different elements move up and down, in the second the same element at one ON splits two ways.
Key relation a reaction is redox iff some atom's ON changes; type follows the skeleton (A+B→AB, AB→A+B, A+BC→AC+B) Every option here does change an ON, so each is redox; only the shape decides the label.
Solution
1. (A) Mg + N2 → Mg3N2: Mg goes 0→+2 and N goes 0→−3, two elements fusing into one product → combination redox = (s).
2. (B) 2KClO3 → 2KCl + 3O2: one solid splits; Cl falls +5→−1 while O rises −2→0 → decomposition redox = (r).
3. (C) Zn + H2SO4 → ZnSO4 + H2: Zn 0→+2 pushes H out of the acid, H+ +1→0 → displacement = (q). A free element replaces one bound in a compound.
4. (D) 2H2O2 → 2H2O + O2: the same peroxide O at −1 goes partly to −2 (water) and partly to 0 (O2) → disproportionation = (p).
5. So (B) and (D) are both “one reactant breaking up,” but only (D) has one element splitting two ways; (B) moves two different elements, which is why it is plain decomposition-redox, not (p).

 (C) Zn0 -> Zn+2 ; H+1 -> H0      displ.  (q)
 (D) O-1 -> O-2 and O-1 -> O0    dispro.  (p)

Concept The electronic (modern) definition fixes oxidation by electron bookkeeping, not by oxygen or hydrogen: a species is oxidised when it loses electrons, which simultaneously raises its oxidation number. The classical “addition of oxygen” picture is just a special case of this.
Key relation Oxidation = loss of e− ⇒ ON increases (OIL: Oxidation Is Loss) Mass and neutron count play no part; only the electron tally and the resulting ON matter.
Solution
1. By the electronic concept oxidation is defined as loss of electrons by the species, e.g. Zn → Zn2+ + 2e−. This is exactly (b).
2. (a) Gain of electrons is the definition of reduction, the opposite process, so it is wrong.
3. (c) Increase in mass is irrelevant: an electron's mass is negligible and a species can be oxidised while losing mass overall.
4. (d) Decrease in oxidation number also describes reduction; oxidation raises the ON (Na 0 → +1, Fe2+ → Fe3+).
5. Only (b) survives, and it is self-consistent: losing e− must push the ON up.
6. Sanity check on the direction: Fe2+ → Fe3+ + e− loses an electron and the ON rises +2 → +3, so this is oxidation — matching (b) and flatly contradicting the “decrease in ON” of (d).
 species -> species(n+) + x e-      = OXIDATION
   electrons LOST, ON goes UP
 species(n+) + x e- -> species      = REDUCTION
 ----------------------------------------
 oxidation = LOSS of electrons   (b)
⚡ JEE Trick Chant OIL RIG — Oxidation Is Loss, Reduction Is Gain (of electrons). The tempting (d) sneaks in “oxidation number” but with the wrong direction; oxidation always makes the number more positive, never less.
Answer: (b) Loss of electrons by a species.

Concept A reducing agent is the electron donor: it hands electrons to another species, reducing that partner while itself getting oxidised. So the reducing agent is the one that loses electrons. The classic oxygen/hydrogen phrasings are only sometimes-true symptoms of this.

3In a redox reaction, which of the following pairs is correctly matched? (Level-3)
(a) Substance oxidised → gains electrons   (b) Substance reduced → loses electrons   (c) Oxidising agent → gains electrons   (d) Reducing agent → gains electrons		redox matchingOxidizing Agents and Reducing Agents🟡 Similar(c) Oxidising agent → gains electrons
Concept Four role-to-behaviour pairings are offered and only one is internally correct. The anchor facts: a substance that is oxidised loses electrons; one that is reduced gains them; the oxidising agent gets reduced (gains e−) and the reducing agent gets oxidised (loses e−).
Key relation oxidised = lose e−; reduced = gain e−; ox. agent gains e−; red. agent loses e− An agent does the opposite of the fate named: the oxidising agent is itself reduced.
Solution
1. (a) Substance oxidised → gains electrons is false: being oxidised means losing electrons.
2. (b) Substance reduced → loses electrons is false: being reduced means gaining electrons.
3. (c) Oxidising agent → gains electrons is true: the oxidising agent accepts electrons and is thereby reduced (e.g. in Cu2+ + Zn, Cu2+ gains 2e−).
4. (d) Reducing agent → gains electrons is false: a reducing agent donates electrons, so it loses them.
5. Cross-check with ON: the oxidising agent's own atom is reduced, so its ON falls (e.g. Cl 0 → −1 in Cl2 + 2e−) — gaining electrons, exactly as (c) states.
6. Only (c) is self-consistent, so it is the correctly matched pair.
 substance oxidised   -> loses e-    (a) NO
 substance reduced    -> gains e-    (b) NO
 oxidising agent      -> gains e-    (c) OK
 reducing agent       -> loses e-    (d) NO
⚡ JEE Trick Two mirror rules kill three distractors fast: “oxidised = loses, reduced = gains,” and “the agent suffers the opposite fate of its name” (oxidising agent is reduced). Both point only to (c).
Answer: (c) Oxidising agent → gains electrons.
4Which of the following statements is always true for a redox reaction? (Level-4)
(a) Oxidation can occur without reduction   (b) Reduction can occur without oxidation   (c) Oxidation and reduction occur simultaneously   (d) Oxidising agent and reducing agent are the same species		redox simultaneityOxidation & Reduction by Electron Transfer method - IIT JEE & NEET | Vineet Khatri Sir | ATP STAR🟡 Similar(c) Oxidation and reduction occur simultaneously
Concept Electrons are neither created nor destroyed, so whatever electrons one species loses another must gain in the same reaction. Oxidation and reduction are therefore two halves of one event and must happen together — this is the defining feature of a redox reaction.
Key relation e− lost in oxidation = e− gained in reduction (electron balance) A free electron cannot linger in solution, so a donor needs a simultaneous acceptor.
Solution
1. In any redox change, electrons released by the species being oxidised are picked up by the species being reduced at the same time. So (c) is always true.
2. (a) Oxidation without reduction is impossible: the lost electrons must go somewhere, i.e. something is reduced.
3. (b) Reduction without oxidation fails for the same reason in reverse: gained electrons must have come from a species that was oxidised.
4. (d) Oxidising and reducing agent are the same species only happens in the special case of disproportionation; it is not always true, so it cannot be the general answer.
5. Example: Zn + Cu2+ → Zn2+ + Cu — Zn is oxidised exactly as Cu2+ is reduced, in one step.
6. The electron count also balances: the 2e− Zn loses are precisely the 2e− Cu2+ gains, so neither half can run alone, which is why (a) and (b) are impossible.
 Zn -> Zn2+ + 2e-        (oxidation half)
 Cu2+ + 2e- -> Cu        (reduction half)
 ----------------------------------------
 both halves occur together     (c)
⚡ JEE Trick “Always true” questions reward the conservation law: electrons must balance, so oxidation and reduction are inseparable. Option (d) is true only for disproportionation (a subset), which the word always rules out.
Answer: (c) Oxidation and reduction occur simultaneously.

1Define (i) oxidising agent and (ii) reducing agent in terms of oxidation number.define oxidising reducing agentOxidizing and Reducing Agents | Easy Trick🟡 SimilarOA: ON of an atom decreases; RA: ON of an atom increases
Concept In the oxidation-number language, an agent is named by what happens to its own atom, not its partner. An oxidising agent causes oxidation in something else and is itself reduced; a reducing agent causes reduction in something else and is itself oxidised. The definitions below pin this to the ON direction.
Key relation ON increase = oxidation; ON decrease = reduction An “agent” undergoes the change opposite to the one it brings about in its partner.
Solution
1. (i) Oxidising agent: a substance in which the oxidation number of one of its atoms decreases during the reaction; i.e. it is itself reduced (gains electrons) while it oxidises the other species.
2. Example: in Cr2O72− + SO2, Cr goes +6 → +3, a decrease, so dichromate is the oxidising agent.
3. (ii) Reducing agent: a substance in which the oxidation number of one of its atoms increases during the reaction; i.e. it is itself oxidised (loses electrons) while it reduces the other species.
4. Example: in that same reaction S of SO2 goes +4 → +6, an increase, so SO2 is the reducing agent.
5. The two are complementary: in every redox reaction one ON rises (reducing agent) exactly as another falls (oxidising agent).
 Oxidising agent : ON of its atom DECREASES
                   (itself reduced, gains e-)
 Reducing agent  : ON of its atom INCREASES
                   (itself oxidised, loses e-)
⚡ JEE Trick Remember by the opposite-fate rule: the oxidising agent's own number goes down, the reducing agent's own number goes up. An element already at its highest ON (e.g. S in SO42−) can act only as an oxidising agent; at its lowest ON, only as a reducing agent.
Answer: OA — ON of an atom decreases (itself reduced); RA — ON of an atom increases (itself oxidised).

Concept Rusting is a redox reaction: iron is oxidized and oxygen reduced. Judge each statement by who loses and who gains electrons, remembering that the reducing agent is the species oxidized while the oxidizing agent is the species reduced.
Key relation Fe: 0 → +3 (loses 3e⁻, oxidized); O: 0 → −2 (gains 2e⁻, reduced) Species oxidized = reducing agent; species reduced = oxidizing agent.
Solution
1. Oxidation numbers change: Fe from 0 to +3 and O from 0 to −2, so (a) it is a redox reaction — correct.
2. Fe(s) loses electrons (is oxidized) and hands them to O₂, so (b) Fe(s) is the reducing agent — correct.
3. Fe₃⁺ can accept electrons to drop to lower states, so it acts as an oxidizing agent; (c) is correct as a general property.
4. (d) says Fe(s) is “reduced to Fe₃⁺,” but 0 → +3 is a rise in oxidation number — that is oxidation, not reduction. Wrong.
5. The oxidizing agent that actually runs the reaction is O₂ (0 → −2); Fe₃⁺ being an oxidant is a separate, still-true statement.
6. Correct options: (a), (b) and (c).
 Fe : 0 -> +3   oxidized (reducing agent)
 O2 : 0 -> -2   reduced  (oxidizing agent)
 Fe3+ can accept e-  -> an oxidizing agent
 (d) Fe -> Fe3+ is oxidation, not reduction
 -----------------------------------------
 correct : (a),(b),(c)
⚡ JEE Trick Fix the direction first: a rising oxidation number means oxidation, hence reducing agent. Fe goes up, so it is oxidized and is the reducing agent; calling it “reduced” in (d) flips the sign and is the planted error.
Answer: (a), (b) and (c).
9[One or more than one option may be correct] In the reaction: Cl2 + OH− → Cl− + ClO4− + H2O, chlorine is:
(a) Oxidized   (b) Reduced   (c) Disproportionate   (d) Neither oxidized nor reduced		chlorine disproportionationIn the reaction, Cl2+OH- -> Cl-+ClO4-+H2O, chlorine is: (1) Oxidised (2) Reduced (3) Oxidised and reduced🟢 Exact(a), (b), (c) Oxidized; Reduced; Disproportionate
Concept Chlorine starts as Cl₂ with O.N. 0 and ends in two products, one with chlorine below 0 and one above it. When one element of a single reactant goes both up and down within the same reaction, that is disproportionation, which by definition means the element is at once oxidized and reduced.
Key relation Cl: 0 → −1 (reduced) and 0 → +7 (oxidized) = disproportionation One element, one reactant state splitting into a higher and a lower product state.
Solution
1. In Cl₂ chlorine is 0; in the product Cl⁻ it is −1, so part of the chlorine has gained electrons and is reduced.
2. In ClO₄⁻ the four O at −2 give −8 against an overall charge of −1, so Cl = +7, meaning another part of the chlorine has lost electrons and is oxidized.
3. Because the same element is simultaneously oxidized and reduced, (a) oxidized and (b) reduced are both correct statements about chlorine here.
4. That very behaviour — one element splitting into a higher and a lower state — is the definition of disproportionation, so (c) disproportionate is correct too.
5. (d) “neither oxidized nor reduced” directly contradicts the oxidation-number changes found above, so it is wrong.
6. Hence chlorine is oxidized, reduced and disproportionating all at once. Correct options: (a), (b) and (c).
 Cl2   : Cl = 0   (start)
 Cl-   : Cl = -1  reduced
 ClO4- : Cl = +7  oxidized
 one element up AND down = disproportion.
 -----------------------------------------
 correct : (a),(b),(c)
⚡ JEE Trick Whenever a free element on the left lands in two products, one above and one below its start, it is disproportionating — so “oxidized,” “reduced” and “disproportionate” are all true at once.
Answer: (a), (b) and (c).
10[One or more than one option may be correct] Indicate in which of the following processes the nitrogen is reduced?
(a) NH4+ → N2   (b) NO3− → NO   (c) NO2 → NO2−   (d) NO3− → NH4+		nitrogen reduction processesHow to find Oxidation number of Nitrogen in NH4NO3 (Ammonium nitrate)🟡 Similar(b), (c), (d) NO₃⁻→NO; NO₂→NO₂⁻; NO₃⁻→NH₄⁺
Concept Nitrogen is reduced only when its oxidation number falls, because reduction is a gain of electrons. So the method is to assign the O.N. of N on each side of the four processes and keep only those where the number decreases; a rise in the number means oxidation, not reduction, and is rejected.
Key relation reduction ⇔ O.N.(N)final < O.N.(N)initial Gaining electrons lowers the oxidation number, so only a downward change of the nitrogen state counts as reduction.
Solution
1. (a) NH₄⁺ (N = −3) → N₂ (N = 0): the number rises by 3, so nitrogen is oxidized, not reduced. Wrong.
2. (b) NO₃⁻ (N = +5) → NO (N = +2): the number falls by 3, so nitrogen is reduced. Correct.
3. (c) NO₂ (N = +4) → NO₂⁻ (N = +3): the number falls by 1, so nitrogen is reduced. Correct.
4. (d) NO₃⁻ (N = +5) → NH₄⁺ (N = −3): the number falls by a full 8 units, so nitrogen is strongly reduced. Correct.
5. Only process (a) is a rise in the oxidation number; (b), (c) and (d) are all decreases and so are reductions.
6. Hence nitrogen is reduced in (b), (c) and (d), while (a) is the lone oxidation. Correct options: (b), (c) and (d).
 (a) NH4+  -3 -> N2    0   up   : oxidized
 (b) NO3-  +5 -> NO   +2   down : reduced
 (c) NO2   +4 -> NO2- +3   down : reduced
 (d) NO3-  +5 -> NH4+ -3   down : reduced
 -----------------------------------------
 nitrogen reduced : (b),(c),(d)
⚡ JEE Trick Write the O.N. of N on both sides and read the arrow of the number: down = reduced. Only NH₄⁺ → N₂ goes up, so (a) is the lone oxidation and is excluded.
Answer: (b), (c) and (d).
