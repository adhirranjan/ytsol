6Prove that: (cosA − cosB + cosC + 1) / (cosA + cosB + cosC − 1) = cot(A/2)·cot(C/2)Conditional identity in a triangle (proof)——
Concept A conditional identity: A, B, C are the angles of a triangle, so A + B + C = π and half-angles satisfy (A+C)/2 = π/2 − B/2. Convert the numerator and denominator with sum-to-product, then use that relation to force cot(A/2)cot(C/2) out.
Formula A + B + C = π; cosA + cosC = 2 cos((A+C)/2) cos((A−C)/2); 1 + cosB = 2cos²(B/2); 1 − cosB = 2sin²(B/2).
Solution
1. Numerator N = (cosA + cosC) + (1 − cosB).Group the pair that shares a sum-to-product formula and leave the B-terms with the constant.
2. cosA + cosC = 2 cos((A+C)/2) cos((A−C)/2), and 1 − cosB = 2sin²(B/2).
3. Since A + C = π − B, we get (A+C)/2 = π/2 − B/2, so cos((A+C)/2) = sin(B/2).This is the only place the triangle condition enters — and it is decisive.
4. N = 2 sin(B/2) cos((A−C)/2) + 2sin²(B/2) = 2 sin(B/2)[cos((A−C)/2) + sin(B/2)].
5. Also sin(B/2) = cos((A+C)/2), so N = 2 sin(B/2)[cos((A−C)/2) + cos((A+C)/2)].
6. Apply sum-to-product again: cos((A−C)/2) + cos((A+C)/2) = 2 cos(A/2) cos(C/2).
7. So N = 4 sin(B/2) cos(A/2) cos(C/2).
8. Denominator D = (cosA + cosC) − (1 − cosB) = 2 sin(B/2) cos((A−C)/2) − 2sin²(B/2).
9. D = 2 sin(B/2)[cos((A−C)/2) − cos((A+C)/2)] = 2 sin(B/2)·2 sin(A/2) sin(C/2) = 4 sin(B/2) sin(A/2) sin(C/2).
10. Divide: N/D = [4 sin(B/2) cos(A/2) cos(C/2)] / [4 sin(B/2) sin(A/2) sin(C/2)] = cot(A/2) cot(C/2). Proved.Everything in B cancels — which is exactly what the target expression predicts.
  Let A + B + C = pi   ==>  (A+C)/2 = pi/2 - B/2  ==>  cos((A+C)/2) = sin(B/2)

  N = (cosA + cosC) + (1 - cosB)
    = 2 sin(B/2) cos((A-C)/2)  +  2 sin^2(B/2)
    = 2 sin(B/2) [ cos((A-C)/2) + cos((A+C)/2) ]
    = 2 sin(B/2) * 2 cos(A/2) cos(C/2)
    = 4 sin(B/2) cos(A/2) cos(C/2)

  D = (cosA + cosC) - (1 - cosB)
    = 2 sin(B/2) [ cos((A-C)/2) - cos((A+C)/2) ]
    = 2 sin(B/2) * 2 sin(A/2) sin(C/2)
    = 4 sin(B/2) sin(A/2) sin(C/2)

  N/D = cot(A/2) cot(C/2)        QED
⚡ JEE Trick In every conditional identity of this family the move is the same: isolate the ±1 and marry it to the odd cosine, because 1 − cosB = 2sin²(B/2) and 1 + cosB = 2cos²(B/2) are what let a half-angle factor out. Then convert cos((A+C)/2) → sin(B/2) using the triangle condition. Numerator and denominator differ only in the sign of the second cosine, so one gives 2cos(A/2)cos(C/2) and the other 2sin(A/2)sin(C/2) — the ratio is forced to be a product of cotangents.
