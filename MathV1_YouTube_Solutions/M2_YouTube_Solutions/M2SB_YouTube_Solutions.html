1Let S be the set of the first 11 natural numbers. The number of non-empty subsets A of S such that the product of elements …🟡 Similar1979
Concept "Product is even" is a condition that is far easier to count by its complement. A product of integers is odd exactly when every factor is odd. So instead of chasing the even case directly, count all admissible subsets and subtract the all-odd ones. The extra clause n(B) ≥ 2 just removes the empty set and the singletons from both counts.
Formula A set with n elements has 2^n subsets. Subsets of size ≥ 2: 2^n − 1 − n (drop the empty set and the n singletons). Product odd ⇔ all elements odd.
Solution
1. Identify S: the first 11 natural numbers, S = {1, 2, 3, …, 11}, so |S| = 11.In the JEE convention N starts at 1, so S = {1,…,11}, not {0,…,10}.
2. Split S by parity: odd elements {1, 3, 5, 7, 9, 11} → 6 of them; even elements {2, 4, 6, 8, 10} → 5 of them. Check: 6 + 5 = 11 ✓
3. Count all subsets B ⊆ S with n(B) ≥ 2: total 211 = 2048, minus the empty set (1), minus the 11 singletons ⇒ 2048 − 1 − 11 = 2036.
4. Count the bad ones (product odd, n(B) ≥ 2): every element must be odd, so B is a subset of the 6-element odd set. Subsets: 26 = 64, minus the empty set (1), minus the 6 singletons ⇒ 64 − 1 − 6 = 57.Same "−1−n" surgery, but with n = 6 now.
5. Subtract: n(A) = 2036 − 57 = 1979.Every subset of size ≥ 2 that is not all-odd contains at least one even number, hence has an even product.
  S = {1,...,11}         odd: 1,3,5,7,9,11   (6)
                         even: 2,4,6,8,10    (5)

  all B with n(B) >= 2 :   2^11 - 1 - 11 = 2048 - 12 = 2036
  product ODD  (all odd) :   2^6 - 1 -  6 =   64 -  7 =   57
  ---------------------------------------------------------
  product EVEN           :   2036 - 57            = 1979
⚡ JEE Trick Any time a question says "the product is even", "at least one is even", or "at least one of …", flip immediately to the complement — the complement is a single clean multiplicative condition (all odd) while the direct count needs inclusion–exclusion over 5 even elements. Second reflex: apply the size restriction (n(B) ≥ 2) to both counts before subtracting, never to just one — forgetting to strip the 6 odd singletons is the trap here and lands you on 1985.
Answer: 1979
2Let A = {x : |x² − 10| ≤ 6} and B = {x : |x − 2| > 1}. Concept Two modulus-defined sets. Resolve each into plain intervals first, then test the four options mechanically on the number line. The only subtlety is bracket type: ≤ gives closed ends, > gives open ends, and set difference flips the bracket at every shared endpoint (removing a closed point leaves an open end).
Formula |u| ≤ c ⇔ −c ≤ u ≤ c; |u| > c ⇔ u > c or u < −c; and a ≤ |x| ≤ b ⇔ x ∈ [−b, −a] ∪ [a, b]. Also B − A = B ∩ A'.
Solution
1. Unpack A: |x² − 10| ≤ 6 ⇒ −6 ≤ x² − 10 ≤ 6 ⇒ 4 ≤ x² ≤ 16.Add 10 across all three parts.
2. Take square roots: 4 ≤ x² ≤ 16 ⇒ 2 ≤ |x| ≤ 4 ⇒ A = [−4, −2] ∪ [2, 4].Never write "2 ≤ x ≤ 4" — x² forgets the sign, so the negative mirror branch is compulsory.
3. Unpack B: |x − 2| > 1 ⇒ x − 2 > 1 or x − 2 < −1 ⇒ x > 3 or x < 1, i.e. B = (−∞, 1) ∪ (3, ∞).A strict > means both ends are open: 1 and 3 are excluded.
4. Test (a) B − A. Work branch by branch. From (−∞, 1), remove the part of A that lies inside it, namely [−4, −2]: this leaves (−∞, −4) ∪ (−2, 1).−4 and −2 belong to A, so they are deleted — the ends turn open. [2, 4] misses (−∞, 1) entirely.
5. Still on (a): from (3, ∞), remove A ∩ (3, ∞) = (3, 4]. That leaves (4, ∞).4 ∈ A so 4 goes; everything above 4 survives.
6. Union the branches: B − A = (−∞, −4) ∪ (−2, 1) ∪ (4, ∞) — this is exactly option (a). ✓
7. Test (b): A ∩ B = ([−4,−2] ∪ [2,4]) ∩ ((−∞,1) ∪ (3,∞)) = [−4, −2] ∪ (3, 4]. Printed as [−4, −2] ∪ [3, 4] — false, since 3 ∉ B while 4 ∈ A ∩ B.The bracket on the second piece is wrong: it must be half-open (3, 4].
8. Test (c): A ∪ B = (−∞, 1) ∪ [−4,−2] ∪ [2,4] ∪ (3,∞) = (−∞, 1) ∪ [2, ∞). Printed as [−∞, 1] ∪ (2, ∞) — false (and "[−∞" is not even legal notation).
9. Test (d): A − B = A ∩ [1, 3] = [2, 3]. Printed [2, 3) — false, because 3 ∉ B so 3 survives the removal and the end stays closed.

⚡ JEE Trick For |x² − k| ≤ c always go to a ≤ |x| ≤ b and then mirror — the two-branch shape [−b,−a] ∪ [a,b] is where most marks are lost. Then don't solve all four options: options in this family differ almost entirely in bracket type, so scan endpoints first. Rule of thumb for a difference: removing a closed point opens the neighbouring end; removing an open point leaves the end closed. Here 3 is open in B, which is precisely why (b) and (d) are wrong — you can kill both in five seconds without computing anything.

Concept B is simply the even numbers from 2 to 200, so A ∩ B is "even numbers ≤ 200 that are coprime to 45". Since 45 = 3² × 5, HCF(n, 45) = 1 means n is divisible by neither 3 nor 5 — the factor 2 in n never matters because 45 is odd. So sum all of B, then use inclusion–exclusion to strip out the even multiples of 3 and of 5.
Formula 1 + 2 + … + k = k(k+1)/2; sum of an AP d, 2d, …, kd = d · k(k+1)/2; inclusion–exclusion on sums: S(not 3, not 5) = S(all) − S(mult 3) − S(mult 5) + S(mult 15). Inside B, "even multiple of 3" = multiple of 6, "even multiple of 5" = multiple of 10, "even multiple of 15" = multiple of 30.
Solution
1. Write out B: B = {2k : k = 1, …, 100} = {2, 4, …, 200}. Its total sum = 2(1 + 2 + … + 100) = 2 × 5050 = 10100.
2. Translate the condition: 45 = 3² × 5, so HCF(n, 45) = 1 ⇔ 3 ∤ n and 5 ∤ n.Coprimality only sees the primes of 45, namely 3 and 5; being even is irrelevant.
3. Sum of multiples of 6 in B: 6, 12, …, 198 → 33 terms; sum = 6 × 33×34/2 = 6 × 561 = 3366.
4. Sum of multiples of 10 in B: 10, 20, …, 200 → 20 terms; sum = 10 × 20×21/2 = 10 × 210 = 2100.
5. Sum of multiples of 30 in B (removed twice, add back once): 30, 60, …, 180 → 6 terms; sum = 30 × 6×7/2 = 30 × 21 = 630.
6. Inclusion–exclusion: sum(A ∩ B) = 10100 − 3366 − 2100 + 630 = 5264.Multiples of 30 sit in both step-3 and step-4 lists, so without the +630 they would be subtracted twice.

  minus mult of 6  (33 terms, 6..198)  sum      =  3366
  minus mult of 10 (20 terms, 10..200) sum      =  2100
  plus  mult of 30 ( 6 terms, 30..180) sum      =   630
  ------------------------------------------------------

⚡ JEE Trick The instant you see HCF(n, 45) = 1, factorise 45 and keep only its primes {3, 5}; then work with 6, 10, 30 (not 3, 5, 15), since every element of B is even. The classic trap: forgetting to add back the multiples of 30 gives 4634, and using 15 instead of 30 for the overlap corrupts the add-back — both are common wrong answers on this exact PYQ.

4Let A and B be two finite sets with m and n elements respectively. The total number of subsets of the set A is 56 more than the total number of subsets of B. Then the distance of the point P(m, n) from the point Q(−2, −3) is (a) 10 (b) 6 (c) 4 (d) 8 [JEE Main 2024 (27 Jan Shift 2)] (Level-6)2^m − 2^n = 56; distance formulaLet A and B be two finite sets with m and n elements respectively. The total number | JEE Main 2024🟢 Exacta10
Concept A set with m elements has exactly 2m subsets, so the condition is the exponential equation 2m − 2n = 56. The standard move is to pull out the smaller power of 2: the difference splits as a power of 2 times an odd factor of the form 2k − 1, and matching odd parts pins down m and n uniquely. Then the question becomes a one-line distance computation.
Formula Number of subsets of an m-set: 2m. Factoring: 2m − 2n = 2n(2m−n − 1) 2m−n − 1 is odd, so it must equal the full odd part of 56. Distance: PQ = √((x₁−x₂)² + (y₁−y₂)²).
Solution
1. Set up: 2m − 2n = 56, with m > n (A has more subsets).
2. Factor both sides: 2n(2m−n − 1) = 56 = 2³ × 7.Split 56 into its even part 8 and odd part 7.
3. Match parts: the bracket 2m−n − 1 is odd, so it must be 7, and 2n must be 8 ⇒ n = 3 and 2m−n = 8 ⇒ m − n = 3 ⇒ m = 6.
4. Verify: 2⁶ − 2³ = 64 − 8 = 56 ✓ So P(m, n) = P(6, 3).
5. Distance from P(6, 3) to Q(−2, −3): PQ = √((6−(−2))² + (3−(−3))²) = √(8² + 6²) = √(64 + 36) = √100 = 10.8–6–10 is just the 3–4–5 right triangle scaled by 2.
  2^m - 2^n = 56
  2^n (2^(m-n) - 1) = 2^3 x 7
     even part: 2^n = 8      -> n = 3
     odd  part: 2^(m-n)-1 = 7 -> m-n = 3 -> m = 6
  P(6,3), Q(-2,-3):  PQ = sqrt(8^2 + 6^2) = sqrt(100) = 10   <-- (a)
⚡ JEE Trick For any 2m − 2n = N, immediately write N = (even part) × (odd part): the odd part must be 2m−n − 1 (i.e. one less than a power of 2: 1, 3, 7, 15, 31, …), so a valid N announces its own m and n. Here 7 = 2³ − 1 does it instantly. The trap is swapping the roles — taking m = 3, n = 6 gives P(3, 6) and distance √(25+81) = √106, which matches no option and wastes a re-solve; remember the larger exponent belongs to A, the set with more subsets. Spotting 8–6–10 as a Pythagorean triple saves the arithmetic.
Answer: (a) 10

Concept HCF(α, 24) = 1 with 24 = 2³ × 3 means α shares no prime with 24, i.e. α is odd and not divisible by 3. Rather than listing such numbers, sum everything from 1 to 100 and remove the multiples of 2 and of 3 by inclusion–exclusion — adding back the multiples of 6, which get removed twice. This is the same machinery as Q3 but with primes {2, 3} instead of {3, 5}.
Formula 1 + 2 + … + n = n(n+1)/2; multiples of d up to 100 sum to d · k(k+1)/2 where k = ⌊100/d⌋; S(coprime) = S(all) − S(mult 2) − S(mult 3) + S(mult 6) only the primes of 24 matter — the cube on 2 is irrelevant to coprimality.
Solution
1. Total: 1 + 2 + … + 100 = 100×101/2 = 5050.
2. Multiples of 2: 2, 4, …, 100 → 50 terms; sum = 2 × 50×51/2 = 2 × 1275 = 2550.
3. Multiples of 3: 3, 6, …, 99 → 33 terms; sum = 3 × 33×34/2 = 3 × 561 = 1683.
4. Multiples of 6 (counted in both lists): 6, 12, …, 96 → 16 terms; sum = 6 × 16×17/2 = 6 × 136 = 816.⌊100/6⌋ = 16, not 17 — 102 overshoots.
5. Inclusion–exclusion: required sum = 5050 − 2550 − 1683 + 816 = 1633.

Concept We need subsets C of A that meet B in at least one element. "At least one" screams complement: count all subsets of A, subtract those that avoid B completely. Crucially, C ∩ B only depends on the part of B inside A — the element 9 ∈ B is not in A, so it can never be in C and is a pure decoy.
Formula An n-set has 2ⁿ subsets. Complement count: #{C : C ∩ B ≠ φ} = 2^|A| − 2^|A − B| C avoids B exactly when C is built only from elements of A outside B.

5. Cross-check by direct construction: pick a non-empty subset of {3,6,7} (2³ − 1 = 7 ways) and pair it with any subset of {1,2,4,5} (2⁴ = 16 ways): 7 × 16 = 112 ✓Every valid C splits uniquely into its (non-empty) part inside {3,6,7} and its free part outside.

⚡ JEE Trick "≠ φ" (or "at least one common element") = total minus avoiders: 2^|A| − 2^(|A| − |A∩B|) — a 10-second formula once you replace B by A ∩ B. 9. Option (d). cosθ + i sinθ with θ = π(a + b√2). This lies in Z only if it is real, i.e. sinθ = 0, i.e. θ = kπ for some k ∈ Z.
10. θ = kπ ⇔ π(a + b√2) = kπ ⇔ a + b√2 = k ∈ Z ⇔ b√2 = k − a ∈ Z. Since √2 is irrational, b√2 is an integer only when b = 0.If b ≠ 0 then √2 = (k−a)/b would be rational — contradiction.
11. Conversely if b = 0 then θ = aπ and cos(aπ) + i sin(aπ) = (−1)^a + 0i = ±1 ∈ Z. ✓ Both directions hold, so option (d) is TRUE.

⚡ JEE Trick In any Z[√d] question three reflexes settle nearly every option: (i) closure — sums and products of a+b√d stay in the ring, so any "is this power still in S?" option is automatically TRUE; (ii) reciprocal conjugates — (√2−1)(√2+1) = 1, so one surd's powers vanish exactly as fast as the other's explode, and a single threshold n answers both the "→ 0" and the "→ ∞" options at once; (iii) e^(iθ) ∈ Z ⇔ sinθ = 0, which converts a scary trig option into pure irrationality of √2. 9Let S₁ = {(i, j, k) ; i, j, k ∈ {1, 2, …, 10}}, S₂ = {(i, j) ; 1 ≤ i < j + 2 ≤ 10, i, j ∈ {1, 2, …, 10}}, S₃ = {(i, j, k, l) ; 1 ≤ i < j < k < l, i, j, k, l ∈ {1, 2, …, 10}} and S₄ = {(i, j, k, l) ; i, j, k and l are distinct elements in {1, 2, …, 10}}. If the total number of elements in the set Sᵣ is nᵣ, r = 1,2,3,4, then which of the following statements is (are) TRUE? MULTI CORRECT. (a) n₁ = 1000 (b) n₂ = 44 (c) n₃ = 220 (d) n₄/12 = 420 [JEE Advanced (2024 Paper1)] (Level-…)Counting ordered tuples vs. increasing tuplesJEE Advanced 2021 [ Question Paper Solutions With Answer Key ] | Vedantu JEE🟡 Similara, b, d(a) n₁ = 1000; (b) n₂ = 44; (d) n₄/12 = 420
Concept Four counting regimes, and the whole question is about telling them apart: free (repeats allowed, order matters → 10ⁿ), strictly increasing (a chain i < j < k < l is determined by which four values you pick → a combination), and distinct but ordered (a permutation). S₂ is the odd one out: the "+2" shifts the inequality, so it must be counted by hand.
Formula Ordered with repetition from n values, r slots: nⁿ. Strictly increasing r-tuples from n values: C(n, r) — one per subset. Ordered distinct: P(n, r) = n(n−1)…(n−r+1).
Solution
1. n₁: S₁ is all triples (i, j, k) with each coordinate free in {1,…,10} — no order condition, repeats allowed. So n₁ = 10 × 10 × 10 = 1000. Option (a) is TRUE. ✓
2. n₂: condition 1 ≤ i < j + 2 ≤ 10. Split the chain into its two halves: (i) j + 2 ≤ 10 ⇒ j ≤ 8; and (ii) i < j + 2 ⇒ i ≤ j + 1, together with i ≥ 1.A chained inequality asserts 1 ≤ i, i < j+2, and j+2 ≤ 10 all at once.
3. So for each j from 1 to 8, i ranges over 1, 2, …, j+1 — that is j + 1 admissible values of i.j ≥ 1 because j ∈ {1,…,10}. Note i may exceed j here — e.g. j = 3, i = 4 is legal since 4 < 5.
4. Sum over j: n₂ = Σ (j = 1 to 8) (j + 1) = 2 + 3 + 4 + 5 + 6 + 7 + 8 + 9.
5. That is an AP with 8 terms, first 2 and last 9: n₂ = 8 × (2 + 9)/2 = 8 × 5.5 = 44. Option (b) is TRUE. ✓
6. n₃: S₃ is all (i, j, k, l) with 1 ≤ i < j < k < l ≤ 10. A strictly increasing 4-tuple is uniquely determined by the 4-element subset it uses — choose the values, and there is exactly one legal ordering.
7. So n₃ = C(10, 4) = (10×9×8×7)/(4×3×2×1) = 5040/24 = 210, not 220. Option (c) is FALSE. ✗210 vs 220 is the deliberate near-miss: C(10,4) = 210, while 220 = C(12,3) is a decoy.
8. n₄: S₄ is all (i, j, k, l) that are 4 distinct elements of {1,…,10}, with order mattering (it is a tuple, and no inequality is imposed). So n₄ = P(10, 4) = 10 × 9 × 8 × 7 = 5040.
9. Then n₄/12 = 5040/12 = 420. Option (d) is TRUE. ✓Sanity cross-check: n₄ = 4! × n₃ = 24 × 210 = 5040 ✓ — each increasing 4-tuple has 4! = 24 orderings.
  n1 = 10^3                          = 1000    (a) TRUE
  n2 = sum_{j=1..8} (j+1)
     = 2+3+4+5+6+7+8+9               =   44    (b) TRUE
  n3 = C(10,4) = 5040/24             =  210    (c) FALSE (printed 220)
  n4 = P(10,4) = 10*9*8*7            = 5040
       n4/12   = 5040/12             =  420    (d) TRUE

  cross-check:  n4 = 4! * n3 = 24 * 210 = 5040   ok
⚡ JEE Trick Classify before you compute — read only two things off each set: are repeats allowed? and is order forced? That gives 10ⁿ / C(n,r) / P(n,r) instantly, and three of the four options fall out in one line each. The single hand-count is S₂, and there the trap is reading "1 ≤ i < j + 2 ≤ 10" as "i < j" — it is not; the +2 lets i run one past j, which is exactly why the answer is 44 and not the Σj = 36 you would get from a plain i < j. Finally, the relation n₄ = 4!·n₃ is a free consistency check on both counts at once.
Answer: (a), (b), (d) — n₁ = 1000; n₂ = 44; n₄/12 = 420
