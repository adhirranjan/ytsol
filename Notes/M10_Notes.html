L-1

Polynomials, Remainder/Factor Theorem, Discriminant & Nature of Roots

Polynomials and how they are classified

  • A polynomial in x is an algebraic expression in which the variable carries only non-negative integer powers: p(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀, with real coefficients. The highest power is the degree.
  • By degree: linear (1), quadratic (2), cubic (3), biquadratic (4), … , nth degree.
  • By number of terms: monomial (1 term), binomial (2), trinomial (3).
  • A quadratic expression is P(x)=ax²+bx+c (a≠0); setting P(x)=0 makes it a quadratic equation.

Remainder & Factor theorems

remainder theoremIf P(x) is divided by (x − k), the remainder is P(k). [since P(x) = (x − k)Q(x) + R ⇒ at x=k, R = P(k)]
factor theorem(x − k) is a factor of P(x) ⇔ P(k) = 0. Zeros (roots) of P are the x with P(x)=0.

Nature of roots (real coefficients)

the deciding quantityx = [−b ± √(b²−4ac)]/2a, so everything hinges on D = b² − 4ac.
  • D = 0 → roots real & equal, α = β = −b/2a.
  • D > 0 → roots real & distinct (rational if a,b,c∈Q and D a perfect square — integral if a=1,b,c∈Z; irrational conjugate pair p±√q otherwise).
  • D < 0 → roots are a conjugate pair α = p+iq, β = p−iq, i = √(−1).
⚠ Complex-coefficient quadraticsIf a, b, c themselves are complex, the formula x = [−b ± √(b²−4ac)]/2a still holds, but the nature of the roots must NOT be judged from the sign of b²−4ac. "D < 0 ⇒ imaginary" is a real-coefficient statement only.
💡 Irrational & complex roots come in pairsWith real (rational) coefficients, if p+√q is a root so is p−√q; if p+iq is a root so is p−iq. This pairing is what forces "one common complex/irrational root ⇒ both roots common" in L-3.

Book Example-1 · L-1
A degree-3 polynomial in x vanishes at x = 1 and x = −2, and takes the values 4 and 28 at x = −1 and x = 2. Find its value at x = 0.
Roots 1 and −2 give factors (x−1)(x+2), so P(x) = (x−1)(x+2)(ax+b) for some a, b.
P(−1) = (−2)(1)(−a+b) = −2(b−a) = 4 ⇒ a − b = 2. P(2) = (1)(4)(2a+b) = 4(2a+b) = 28 ⇒ 2a + b = 7.
Solve: a − b = 2, 2a + b = 7 ⇒ 3a = 9 ⇒ a = 3, b = 1, so P(x) = (x−1)(x+2)(3x+1).
P(0) = (−1)(2)(1) = −2.
P(0) = −2
Book Example-2 · L-1
Find k for which (x + 2) is a factor of x² + kx + 4.
Factor theorem: P(−2) = 0 ⇒ (−2)² + k(−2) + 4 = 0 ⇒ 4 − 2k + 4 = 0 ⇒ 2k = 8.
k = 4
Book Example-3 · L-1
If the roots of x² − 2cx + ab = 0 are real and unequal, prove the roots of x² − 2(a+b)x + a² + b² + 2c² = 0 are imaginary.
Real & unequal ⇒ D₁ = 4c² − 4ab > 0 ⇒ c² − ab > 0, i.e. c² > ab.
For the second equation: D₂ = 4(a+b)² − 4(a² + b² + 2c²) = 4[2ab − 2c²] = −8(c² − ab).
Since c² − ab > 0, D₂ < 0.
D₂ < 0 ⇒ the roots are imaginary.
Book Example-4 · L-1
Find the relation between a, b, c if the roots of (a−b)x² + (c−a)x + (b−c) = 0 are equal.
Equal roots ⇒ D = 0 ⇒ (c−a)² − 4(a−b)(b−c) = 0.
Expand: (c−a)² − 4(ab − ac − b² + bc) = c² − 2ac + a² − 4ab + 4ac + 4b² − 4bc = (a + c − 2b)² = 0.
(Shortcut: coefficients sum to 0, so x = 1 is a root; equal roots ⇒ product (b−c)/(a−b) = 1 ⇒ 2b = a + c.)
a + c = 2b
Book Example-5 · L-1
If the roots of x² − 15 − m(2x − 8) = 0 are equal, find m.
Rewrite: x² − 2mx + (8m − 15) = 0.
Equal roots ⇒ Δ = 0 ⇒ (−2m)² − 4(8m − 15) = 0 ⇒ 4m² − 32m + 60 = 0 ⇒ m² − 8m + 15 = 0.
(m − 3)(m − 5) = 0.
m = 3 or m = 5
Book Example-6 · L-1
Find the roots of ax² + 3bx + c = 0 given that 3b = a + c.
Substitute 3b = a + c: ax² + (a + c)x + c = 0 ⇒ ax² + ax + cx + c = 0 ⇒ ax(x+1) + c(x+1) = 0.
(x + 1)(ax + c) = 0.
x = −1 and x = −c/a

Sum & Product of Roots, Forming Equations, Symmetric Functions

Relation between roots and coefficients

from ax² + bx + c = a(x − α)(x − β)α + β = −b/a = −(coeff of x)/(coeff of x²) · αβ = c/a = (constant)/(coeff of x²)

Building a quadratic from its roots

the standard constructionx² − (α + β)x + αβ = 0 i.e. x² − (sum of roots)x + (product of roots) = 0
  • Example: roots −4 and 6 → sum = 2, product = −24 → x² − 2x − 24 = 0.

Symmetric functions of roots

  • A function of the roots is symmetric if it is unchanged when α and β are swapped: α+β, αβ, α²+β², α³+β³ are symmetric; α − β is not.
  • Reduce every symmetric expression to α+β and αβ:
the two workhorsesα² + β² = (α + β)² − 2αβ · α³ + β³ = (α + β)³ − 3αβ(α + β) · α − β = ±√[(α+β)² − 4αβ]

Identity in a quadratic

identity vs equationIf ax² + bx + c = 0 holds for more than two values of x, it is an identity ⇒ a = b = c = 0.
💡 Don't hunt for the roots themselvesQuestions like "value of (2α−35)³(2β−35)³" or "1/(aα+b)² + 1/(aβ+b)²" are built to collapse onto α+β and αβ. Use aα + b = −c/α (because aα² + bα + c = 0 ⇒ aα + b = −c/α) to turn awkward denominators into α, β.

Book Example-3 · L-2
If α, β are the roots of ax² + bx + c = 0 (c ≠ 0), find 1/(aα+b)² + 1/(aβ+b)² in terms of a, b, c.
α is a root ⇒ aα² + bα + c = 0 ⇒ aα + b = −c/α; likewise aβ + b = −c/β.
So 1/(aα+b)² = α²/c² and 1/(aβ+b)² = β²/c²; sum = (α² + β²)/c².
α² + β² = (α+β)² − 2αβ = b²/a² − 2c/a = (b² − 2ac)/a².

Book Example-4 · L-2
If α, β are roots of x² + 3x − 2 = 0, find (α+1)/β + (β+1)/α.
α + β = −3, αβ = −2.
(α+1)/β + (β+1)/α = (α² + α + β² + β)/(αβ) = [(α+β)² − 2αβ + (α+β)]/(αβ).
= [9 − 2(−2) + (−3)]/(−2) = (9 + 4 − 3)/(−2) = 10/(−2).
−5
Book Example-5 · L-2
If one root of 8x² − 6x + k = 0 is the square of the other, find k.
Let the roots be α and α². Sum: α + α² = 6/8 = 3/4 ⇒ 4α² + 4α − 3 = 0 ⇒ (2α + 3)(2α − 1) = 0 ⇒ α = 1/2 or α = −3/2.
Product: α·α² = α³ = k/8. If α = 1/2 ⇒ k = 8·(1/8) = 1. If α = −3/2 ⇒ k = 8·(−27/8) = −27.
(Equivalently the book's cube-expansion gives k² + 26k − 27 = 0 ⇒ (k − 1)(k + 27) = 0.)
k = 1 or k = −27

Common Roots of Two Quadratic Equations

Exactly one common root

  • Let a₁x² + b₁x + c₁ = 0 and a₂x² + b₂x + c₂ = 0 share the root α. Then a₁α² + b₁α + c₁ = 0 and a₂α² + b₂α + c₂ = 0.
  • Treat these as two linear equations in the unknowns α² and α and solve by cross-multiplication.
cross-multiplicationα²/(b₁c₂ − b₂c₁) = α/(c₁a₂ − c₂a₁) = 1/(a₁b₂ − a₂b₁)
the common rootα = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁) · α² = (b₁c₂ − b₂c₁)/(a₁b₂ − a₂b₁)
condition for exactly one common root (eliminate α)(c₁a₂ − c₂a₁)² = (a₁b₂ − a₂b₁)(b₁c₂ − b₂c₁)
💡 Faster than the formulaMake the x² coefficients equal and subtract the two equations — the x² term cancels, leaving a linear equation whose solution is the common root. Substitute it back to fix the unknown constant. This beats memorising the determinant for numeric problems.

Both roots common

the two quadratics are proportionala₁/a₂ = b₁/b₂ = c₁/c₂
⚠ A non-real (or irrational) common root forces both roots commonIf two quadratics with real coefficients share a complex root p + iq, its conjugate p − iq is automatically a root of both — so both roots coincide and the proportionality a₁/a₂ = b₁/b₂ = c₁/c₂ must hold. The same is true for an irrational common root p + √q with rational coefficients.

Book Example-1 · L-3
If x² + 4ax + 3 = 0 and 2x² + 3ax − 9 = 0 have a common root, find a.
a₁=1, b₁=4a, c₁=3; a₂=2, b₂=3a, c₂=−9. Condition: (c₁a₂ − c₂a₁)² = (a₁b₂ − a₂b₁)(b₁c₂ − b₂c₁).
c₁a₂ − c₂a₁ = 3·2 − (−9)·1 = 15; a₁b₂ − a₂b₁ = 3a − 8a = −5a; b₁c₂ − b₂c₁ = 4a(−9) − 3a·3 = −45a.
15² = (−5a)(−45a) ⇒ 225 = 225a² ⇒ a² = 1.
a = ±1
Book Example-2 · L-3
If x² + bx + c = 0 and x² + cx + b = 0 (b ≠ c) have a common root, find the condition.
Let α be common: α² + bα + c = 0 …(1) and α² + cα + b = 0 …(2).
(1) − (2): (b − c)α + (c − b) = 0 ⇒ (b − c)(α − 1) = 0. Since b ≠ c, α = 1.
Substitute α = 1 in (1): 1 + b + c = 0.
b + c + 1 = 0
Book Example-3 · L-3
If k(6x² + 3) + rx + (2x² − 1) = 0 and 6k(2x² + 1) + px + (4x² − 2) = 0 have both roots common, find p/r.
Collect: (6k + 2)x² + rx + (3k − 1) = 0 …(1) and (12k + 4)x² + px + (6k − 2) = 0 …(2).
Both roots common ⇒ coefficients proportional: (6k + 2)/(12k + 4) = r/p = (3k − 1)/(6k − 2).
Since 12k + 4 = 2(6k + 2) and 6k − 2 = 2(3k − 1), the outer ratios equal ½, so r/p = ½.
p/r = 2
Book Example-4 · L-3
If (x − 2) is a common factor of x² + ax + b and x² + cx + d, find (b − d)/(c − a).
x = 2 is a root of both: 4 + 2a + b = 0 and 4 + 2c + d = 0.
Subtract: 2(a − c) + (b − d) = 0 ⇒ b − d = 2(c − a).
(b − d)/(c − a) = 2
Book Example-5 · L-3
x² + 3x + 5 = 0 and ax² + bx + c = 0 have a common root, a, b, c ∈ N. Find the least possible value of a + b + c.
For x² + 3x + 5 = 0, D = 9 − 20 = −11 < 0, so its roots are a non-real conjugate pair.
A real-coefficient quadratic sharing one non-real root must share both ⇒ a/1 = b/3 = c/5 = λ, so a = λ, b = 3λ, c = 5λ.
Least natural λ = 1 ⇒ a = 1, b = 3, c = 5.
Least a + b + c = 1 + 3 + 5 = 9

Range of a rational (quadratic/quadratic) expression

  • Put the expression = y, cross-multiply to get a quadratic in x, then demand real x by setting its discriminant ≥ 0 — an inequality in y whose solution is the range.

No real roots ⇒ f(x) = 2ax² + 3bx + 5c keeps one sign for all x. f(0) = 5c > 0, so f(x) > 0 ∀x (and a > 0).

Book Example-6 · L-4
Find the range of (x² + 34x − 71)/(x² + 2x − 7).
Set y ⇒ (1 − y)x² + (34 − 2y)x + (−71 + 7y) = 0. Real x ⇒ D ≥ 0.

⇒ y ≤ 5 or y ≥ 9 (y = 1 gives the linear case x = 2, and 1 ∈ (−∞, 5]).

Book Example-7 · L-4
Find all possible values of 1/(x² − x − 1).
Let t = x² − x − 1 = (x − ½)² − 5/4. Then t ≥ −5/4, i.e. t ∈ [−5/4, ∞) but t ≠ 0.

Quadratic & Rational Inequalities and Modulus Equations

The sign-scheme (wavy-curve) method

  • Factorise the expression into linear factors and mark every critical point (zeros of numerator and denominator) on the number line.
  • With the leading coefficient positive, the rightmost interval is +; the sign alternates at each simple factor. At a factor of even multiplicity the sign does not change.
  • Read off the intervals of the required sign. Zeros of the denominator are always excluded (open); for a strict inequality the numerator's zeros are excluded too, for ≤/≥ they are included.
💡 Rational inequalitiesNever cross-multiply by a variable expression (its sign is unknown). Bring everything to one side, combine over a common denominator, factorise, and apply the sign scheme.

Modulus equations

  • Split the real line at the critical points (where each modulus argument = 0), remove the modulus with the correct sign on each piece, solve, and keep only the solutions that lie in that piece.
  • Useful reductions: √(x² + 2x + 1) = |x + 1|, √(x² − 2x + 1) = |x − 1|.

L-6

Location of Roots of a Quadratic

The three tools

  • For f(x) = ax² + bx + c with real roots, place the roots relative to a number k (or interval (k₁, k₂)) using three quantities: the sign of a·f(k), the position of the vertex −b/2a, and the discriminant D.
  • Key fact: a·f(k) > 0 means k lies outside the roots; a·f(k) < 0 means k lies between the roots (and then D > 0 automatically).
Requirement on real roots α, βConditions (all must hold)
both roots > 0α+β = −b/a > 0 · αβ = c/a > 0 · D ≥ 0
both roots < 0α+β < 0 · αβ > 0 · D ≥ 0
roots of opposite sign (α<0<β)αβ = c/a < 0 (⇒ a·f(0) < 0; D > 0 automatic)
both roots > ka·f(k) > 0 · −b/2a > k · D ≥ 0
both roots < ka·f(k) > 0 · −b/2a < k · D ≥ 0
k between the roots (α<k<β)a·f(k) < 0
both roots in (k₁, k₂)a·f(k₁) > 0 · a·f(k₂) > 0 · k₁ < −b/2a < k₂ · D ≥ 0
exactly one root in (k₁, k₂)f(k₁)·f(k₂) < 0

★ Always three, never oneFor "both roots > k" you need all three: a·f(k)>0 (right side of vertex), vertex on the correct side, and D ≥ 0 for real roots. Dropping D is the classic mistake — sign and vertex conditions alone don't force the roots to be real.

L-7

Theory of Equations: Transformation, Vieta Relations, Rational-Root & Descartes' Rule

Transformation of an equation

  • To get the equation whose roots are f(α), f(β), … put y = f(x), solve x = f⁻¹(y), and substitute x back into the original equation. Squaring/rearranging then clears radicals.

Roots ↔ coefficients (Vieta) for higher degree

cubic ax³ + bx² + cx + d = 0Σα = −b/a · Σαβ = c/a · αβγ = −d/a
biquadratic ax⁴ + bx³ + cx² + dx + e = 0Σα = −b/a · Σαβ = c/a · Σαβγ = −d/a · αβγδ = e/a
general aₙxⁿ + … + a₁x + a₀ = 0Σα₁ = −aₙ₋₁/aₙ · Σα₁α₂ = aₙ₋₂/aₙ · Σα₁α₂α₃ = −aₙ₋₃/aₙ · … · α₁α₂…αₙ = (−1)ⁿ a₀/aₙ

Rational Root Theorem

candidate rational rootspossible rational root = ±(factor of constant term) / (factor of leading coefficient)

Descartes' Rule of Signs

  • The number of positive real roots equals the number of sign changes in the coefficients of f(x), or fewer by an even number.
  • The number of negative real roots equals the number of sign changes in f(−x), or fewer by an even number.
💡 Symmetric-function shortcutsΣ(α/β + β/α) over the roots reduces to a symmetric function: use Σ_sym α²β = (Σα)(Σαβ) − 3αβγ, then divide by αβγ. Never chase the individual roots.
