L-1

Ratios of Multiple (2A) & Submultiple (A/2) Angles

Double angle — 2A in terms of A

sin / cos / tan 2Asin2A = 2 sinA cosA · cos2A = cos²A − sin²A = 1 − 2sin²A = 2cos²A − 1 · tan2A = 2 tanA / (1 − tan²A)
in terms of tanA onlysin2A = 2tanA / (1 + tan²A) · cos2A = (1 − tan²A) / (1 + tan²A)

Half angle — A in terms of A/2

sinA / cosA / tanA / cotAsinA = 2 sin(A/2) cos(A/2) · cosA = cos²(A/2) − sin²(A/2) · tanA = 2tan(A/2) / (1 − tan²(A/2)) · cotA = (cot²(A/2) − 1) / (2 cot(A/2))

A/2 in terms of cosA

the "half-angle" setcos²(A/2) = (1 + cosA)/2 · sin²(A/2) = (1 − cosA)/2 · tan(A/2) = ±√((1 − cosA)/(1 + cosA)) · cot²(A/2) = (1 + cosA)/(1 − cosA)
Where the ± sign comes from
Squaring loses sign information, so cos(A/2) = ±√((1 + cosA)/2) and sin(A/2) = ±√((1 − cosA)/2). The sign is fixed by the quadrant in which A/2 lies, not by A. Example: if A/2 is in the 2nd quadrant, cos(A/2) and tan(A/2) are negative while sin(A/2) is positive — you must decide the sign after taking the root.
💡 TipThe three forms of cos2A are the most-used identities in the whole chapter. Pick the one that matches what you are given: have sinA → use 1 − 2sin²A; have cosA → use 2cos²A − 1; have tanA → use (1 − tan²A)/(1 + tan²A).
⚠ Traptan(A/2) = ±√((1−cosA)/(1+cosA)) carries a sign, but cot²(A/2) is written as a clean ratio (1+cosA)/(1−cosA) — do not slip a stray ± into a squared quantity.

Book Example · L-1
Prove that: sin2θ / (1 + cos2θ) = tanθ.
Top: sin2θ = 2 sinθ cosθ. Bottom: 1 + cos2θ = 2cos²θ.
Ratio = 2 sinθ cosθ / 2cos²θ = sinθ / cosθ.
= tanθ = RHS ✓
Book Example · L-1
Show that √(2 + √(2 + √(2 + 2cos8θ))) = 2cosθ, for 0 < θ < π/8.
Innermost: 2 + 2cos8θ = 2(1 + cos8θ) = 2·2cos²4θ = 4cos²4θ ⇒ √ = 2cos4θ.
Next: √(2 + 2cos4θ) = √(4cos²2θ) = 2cos2θ. Then √(2 + 2cos2θ) = √(4cos²θ) = 2cosθ.
= 2cosθ = RHS ✓ (all cosines positive on the given interval)
Book Example · L-1
Prove that: (cosA + cosB)² + (sinA − sinB)² = 4cos²((A + B)/2).
Expand: (cos²A + cos²B + 2cosA cosB) + (sin²A + sin²B − 2 sinA sinB).
Group Pythagoras: = (cos²A + sin²A) + (cos²B + sin²B) + 2(cosA cosB − sinA sinB) = 1 + 1 + 2cos(A + B).
= 2[1 + cos(A + B)] = 2·2cos²((A + B)/2).
= 4cos²((A + B)/2) = RHS ✓
Book Example · L-1
Prove that: cos⁴(π/8) + cos⁴(3π/8) + cos⁴(5π/8) + cos⁴(7π/8) = 3/2.
cos(5π/8) = −cos(3π/8) and cos(7π/8) = −cos(π/8), so their 4th powers repeat ⇒ LHS = 2[cos⁴(π/8) + cos⁴(3π/8)].
= 2[((1 + cosπ/4)/2)² + ((1 + cos3π/4)/2)²] = ½[(1 + 1/√2)² + (1 − 1/√2)²].
= ½[(1 + √2 + ½) + (1 − √2 + ½)] = ½·3.
= 3/2 = RHS ✓
L-2

Exact Values of 7.5° & 22.5° · Product of Cosines

Values for 7.5° (from cos15°)

sin / cos 7.5°sin7.5° = √((4 − √6 − √2)/8) · cos7.5° = √((4 + √6 + √2)/8)
tan / cot 7.5°tan7.5° = √6 − √3 + √2 − 2 · cot7.5° = √6 + √3 + √2 + 2

Values for 22.5° (from cos45°)

sin / cos / tan 22.5°sin22.5° = ½√(2 − √2) · cos22.5° = ½√(2 + √2) · tan22.5° = √2 − 1
How the 7.5° value is built
Start from cos2A = 1 − 2sin²A with A = 7.5°, so cos15° = 1 − 2sin²7.5°. Write cos15° = cos(45° − 30°) = cos45°cos30° + sin45°sin30° = (√3 + 1)/(2√2). Solving for sin²7.5° gives (4 − √6 − √2)/8, then take the positive root (7.5° is in Q1). The 22.5° set is the same idea using cos45° = 1/√2.

Product of cosines (telescoping)

chain productcosA · cos2A · cos2²A · … · cos2ⁿ⁻¹A = sin(2ⁿA) / (2ⁿ sinA)
Why it telescopes
Multiply and divide by 2 sinA. The pair 2 sinA cosA collapses to sin2A; that new sin2A pairs with cos2A to give sin2²A after another ÷2, and so on. After n steps the numerator is sin(2ⁿA) and the accumulated denominator is 2ⁿ sinA. This is the engine behind products like cos(π/7)cos(2π/7)cos(4π/7).
💡 TipTo evaluate any product of cosines whose angles double each time, force the pattern cosA·cos2A·cos4A… and apply the telescoping formula — never expand term by term.

Prove that: cos4x = 1 − 8 sin²x cos²x.
cos4x = cos2(2x) = 1 − 2sin²2x (using cos2θ = 1 − 2sin²θ).
= 1 − 2(sin2x)² = 1 − 2(2 sinx cosx)² = 1 − 8 sin²x cos²x.

Book Example · L-2
Prove that: sin⁴(π/8) + sin⁴(3π/8) + sin⁴(5π/8) + sin⁴(7π/8) = 3/2.
sin(7π/8) = sin(π − π/8) = sin(π/8) and sin(5π/8) = sin(3π/8), so LHS = 2[sin⁴(π/8) + sin⁴(3π/8)].
= 2[((1 − cosπ/4)/2)² + ((1 − cos3π/4)/2)²] = ½[(1 − 1/√2)² + (1 + 1/√2)²].
= ½[(1 − √2 + ½) + (1 + √2 + ½)] = ½·3.
= 3/2 = RHS ✓
L-3

Triple Angle (3A) & Exact Values 18°–108°

triple anglesin3θ = 3 sinθ − 4 sin³θ · cos3θ = 4 cos³θ − 3 cosθ · tan3θ = (3 tanθ − tan³θ) / (1 − 3 tan²θ)
💡 Memory hook"sin = 3 − 4 (minus first), cos = 4 − 3 (plus first)". Both cubics; watch the sign of the leading term.

The special-angle table

Deriving sin18°
Let θ = 18°, so 5θ = 90° ⇒ 2θ = 90° − 3θ. Take sine: sin2θ = cos3θ ⇒ 2 sinθ cosθ = 4cos³θ − 3cosθ. Cancel cosθ (≠ 0), replace cos²θ = 1 − sin²θ, and you get the quadratic 4sin²θ + 2sinθ − 1 = 0 ⇒ sinθ = (−1 + √5)/4 (positive root, Q1). Everything else (cos18°, cos36° = sin54°, cos72° = sin18°…) follows by identities and complementary angles.
★ Two to lock insin18° = (√5 − 1)/4 and cos36° = (√5 + 1)/4. Note sin18°·cos36° = (5 − 1)/16 = 1/4 — this exact product finishes many "prove that = 1/8 or 1/16" problems.

Book Example · L-3
Show that: (sin²24° − sin²6°)(sin²42° − sin²12°) = 1/16.
Write each factor as ½(2sin²) and use 2sin²θ = 1 − cos2θ: = ¼[cos12° − cos48°][cos24° − cos84°].

Book Example · L-3
If tanx = 3/4 and x lies in the third quadrant, find sin(x/2), cos(x/2), tan(x/2).
sec²x = 1 + 9/16 = 25/16 ⇒ cos²x = 16/25; x in Q3 ⇒ cosx = −4/5.
π < x < 3π/2 ⇒ π/2 < x/2 < 3π/4 (Q2): cos(x/2) < 0, sin(x/2) > 0.
cos(x/2) = −√((1 + cosx)/2) = −√((1/5)/2) = −1/√10; sin(x/2) = √((1 − cosx)/2) = √((9/5)/2) = 3/√10.
sin(x/2) = 3/√10, cos(x/2) = −1/√10, tan(x/2) = −3
Book Example · L-3
Find the value of tan9° − tan27° − tan63° + tan81°.
Regroup: (tan9° + tan81°) − (tan27° + tan63°). Since tan81° = cot9°, tan63° = cot27°: = (tan9° + cot9°) − (tan27° + cot27°).
tanθ + cotθ = 1/(sinθ cosθ) = 2/sin2θ ⇒ = 2/sin18° − 2/sin54° = 8/(√5 − 1) − 8/(√5 + 1).
= (8(√5 + 1) − 8(√5 − 1))/((√5)² − 1) = 16/4.
= 4
L-4

Conditional Trigonometric Identities (A + B + C = π)

  • These hold whenever A, B, C are the angles of a triangle (A + B + C = π). Learn them as matched pairs.
tangent / cotangenttanA + tanB + tanC = tanA · tanB · tanC · cotA cotB + cotB cotC + cotC cotA = 1
half-angletan(A/2)tan(B/2) + tan(B/2)tan(C/2) + tan(C/2)tan(A/2) = 1 · cot(A/2) + cot(B/2) + cot(C/2) = cot(A/2) cot(B/2) cot(C/2)
sum-to-productsin2A + sin2B + sin2C = 4 sinA sinB sinC · cos2A + cos2B + cos2C = −1 − 4 cosA cosB cosC
sum of sines / cosinessinA + sinB + sinC = 4 cos(A/2) cos(B/2) cos(C/2) · cosA + cosB + cosC = 1 + 4 sin(A/2) sin(B/2) sin(C/2)
★ Pairing rule"Full angles → product of full-angle sines; half angles → product of half-angle cos/sin." The extra −1 in cos2A+cos2B+cos2C and the +1 in cosA+cosB+cosC are the marks students most often drop.
The one substitution that proves them all
Because A + B + C = π, you always have (A+B)/2 = π/2 − C/2, so cos((A+B)/2) = sin(C/2) and sin((A+B)/2) = cos(C/2). Convert a sum of two terms into a product with sum-to-product formulae, replace the (A+B)/2 factor using this, and the third angle falls in naturally — that is the whole trick behind every identity above.
Worked examples from the module
Book Example · L-4
In any triangle ABC, sinA − cosB = cosC. Find angle B.
sinA = cosB + cosC ⇒ 2 sin(A/2)cos(A/2) = 2 cos((B+C)/2) cos((B−C)/2).
Since (B+C)/2 = (π − A)/2, cos((B+C)/2) = sin(A/2): 2 sin(A/2)cos(A/2) = 2 sin(A/2) cos((B−C)/2) ⇒ cos(A/2) = cos((B−C)/2) ⇒ A = B − C.
With A + B + C = π: (B − C) + B + C = π ⇒ 2B = π.
B = π/2
Book Example · L-4
If A + B + C = 3π/2, find cos2A + cos2B + cos2C.
cos2A + cos2B = 2 cos(A+B) cos(A−B); cos(A+B) = cos(3π/2 − C) = −sinC.
= −2 sinC cos(A−B) + cos2C = 1 − 2 sinC[cos(A−B) + sinC]. Using sinC = −cos(A+B), the bracket = cos(A−B) − cos(A+B) = 2 sinA sinB.
= 1 − 4 sinA sinB sinC
Book Example · L-4
If A, B, C are the angles of a triangle, show that tan²(A/2) + tan²(B/2) + tan²(C/2) ≥ 1.
A/2 + B/2 + C/2 = π/2 ⇒ tan(A/2)tan(B/2) + tan(B/2)tan(C/2) + tan(C/2)tan(A/2) = 1 (call it Σ tanU tanV = 1).
Σ tan²(A/2) − 1 = Σ tan²(A/2) − Σ tan(A/2)tan(B/2) = ½[(tan A/2 − tan B/2)² + (tan B/2 − tan C/2)² + (tan C/2 − tan A/2)²].
A sum of squares is ≥ 0, so Σ tan²(A/2) − 1 ≥ 0.
tan²(A/2) + tan²(B/2) + tan²(C/2) ≥ 1 ✓ (equality only for the equilateral triangle)
Book Example · L-4
If A + B + C = π, prove that (sin2A + sin2B + sin2C)/(cosA + cosB + cosC − 1) = 8 cos(A/2) cos(B/2) cos(C/2).
Numerator = 4 sinA sinB sinC; denominator = (cosA + cosB + cosC) − 1 = 4 sin(A/2) sin(B/2) sin(C/2).
Ratio = 4 sinA sinB sinC / [4 sin(A/2) sin(B/2) sin(C/2)]. Write sinA = 2 sin(A/2)cos(A/2), etc.
The three sin(·/2) cancel top-and-bottom, leaving 2·2·2 cos(A/2)cos(B/2)cos(C/2).
= 8 cos(A/2) cos(B/2) cos(C/2) = RHS ✓
