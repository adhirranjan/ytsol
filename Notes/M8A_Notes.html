💡 The Sn-is-a-quadratic shortcutIf Sn = An² + Bn (no constant term) the sequence is always an A.P. with d = 2A and a = A + B. So Sn = 5n² + 3n ⇒ d = 10, a = 8 — read straight off, no subtraction needed. A non-zero constant term means it is not an A.P.
⚠ (n − 1), not nThe single most expensive slip in this chapter is writing Tn = a + nd. The 1st term has taken zero steps of d, so the nth has taken n − 1. Same for the sum: (n − 1)d inside the bracket.
L-1

Sequence, Series and Progression

  • A sequence is an ordered list of objects. Its members are its terms; how many there are is its length. It is finite or infinite accordingly.
  • The nth term is a formula containing n that hands you any term directly — no walking up from the previous one. Substitute n = 50 to get the 50th. Written <an> or {an}.
  • A series is what you get by adding the terms: a1 + a2 + … + an.
  • A progression is a sequence whose terms follow a definite pattern. Not every sequence is one.
  • An A.P. is a progression in which the difference between a term and the one just before it is constant — that constant is d, the common difference; a is the first term.
the defining testt2 − t1 = t3 − t2 = t4 − t3 = … = tk − tk−1 = d , independent of k
⚠ Check more than one gap5, 5, 7, 7, 9, 9, 11, 11 … looks orderly but the differences run 0, 2, 0, 2, … — not an A.P. One matching pair of gaps proves nothing; the difference must be the same everywhere.
💡 Recursive vs explicitA sequence can be given explicitly (an = 2n/n — substitute and go) or recursively (a1 = 2, an+1 = f(an) — you must climb one rung at a time). Recursive definitions are rarely A.P.s; generate three or four terms before assuming anything.

L-1

The nth Term — from the Start and from the End

building it upt1 = a · t2 = a + d · t3 = a + 2d · t4 = a + 3d ⇒ tn = a + (n − 1)d
from the end (last term ℓ)Walk backwards: the direction reverses, so d becomes −d ⇒ Tn = ℓ − (n − 1)d
  • The multiple of d always matches the suffix minus one — that is the whole content of the formula.
  • How many terms? Set tn = the last value and solve for n. If n comes out fractional, that value is not a term of the A.P.
Two identities the exam keeps reusing
(1) Tm = n and Tn = m ⇒ Tm+n = 0. Subtracting the two conditions gives (m − n)d = n − m, so d = −1, and then a = m + n − 1; hence Tm+n = a + (m+n−1)(−1) = 0. (2) Tm = 1/n and Tn = 1/m ⇒ d = a = 1/mn, so Tmn = 1. Both are in this lecture's Suggested Problems and its Solved Examples — learn the results, not just the method.
💡 Never count backwards by hand"The 8th term from the end" does not need the total number of terms. Just treat ℓ as the new first term and step backwards: T = ℓ − (n − 1)d. Finding n first is wasted work.
⚠ Sign of d when the A.P. fallsFor 7, 2, −3, −8, … the common difference is d = 2 − 7 = −5. Substituting into ℓ − (n−1)d then adds: −113 − (15)(−5) = −113 + 75. Dropping the minus here is the classic error.

Book Example-8 · L-1
If Tm = 1/n and Tn = 1/m for positive integers m, n, find Tmn.
a + (m − 1)d = 1/n … (i) and a + (n − 1)d = 1/m … (ii).
(i) − (ii): (m − n)d = 1/n − 1/m = (m − n)/(mn) ⇒ d = 1/(mn).
Back into (i): a + (m − 1)/(mn) = 1/n ⇒ a = 1/n − 1/n + 1/(mn) ⇒ a = 1/(mn).
Tmn = a + (mn − 1)d = [1 + mn − 1]/(mn) = mn/(mn).
Tmn = 1

L-2

Sum of the First n Terms

the sumSn = (n/2)[2a + (n − 1)d] = (n/2)(a1 + an) = (n/2)(a + ℓ)
term from sumsSn = Sn−1 + an ⇒ an = Sn − Sn−1
The reverse-and-add derivation (worth being able to reproduce)
Write the sum forwards and backwards and add them term by term:
Sn = a1 + a2 + … + an−1 + an
Sn = an + an−1 + … + a2 + a1
Each vertical pair sums to the same thing: (a2 + an−1) = (a + d) + (a + (n−2)d) = 2a + (n−1)d = (a1 + an), and likewise for every other pair. There are n such pairs, so 2Sn = n(a1 + an). Replacing an by a + (n−1)d gives the 2a + (n−1)d form. This "pair the ends" idea is the engine behind half the properties in L-3.
💡 Pick the right face of the formulaLast term known → use (n/2)(a + ℓ), it is one step. Only a and d known → use (n/2)[2a + (n−1)d]. Given Sn as a formula in n → use an = Sn − Sn−1.
⚠ Two values of n can give the same sumSolving Sn = k is a quadratic in n, so a decreasing A.P. often has two valid answers (the terms in between cancel out to zero). Don't discard the larger root — only reject roots that are negative or fractional.
Worked example from the module
Book Example · L-2 theory
Find the sum of the first 20 terms of the A.P. −4, −2, 0, 2, 4, 6, … (a) 320 (b) 310 (c) 300 (d) 280
a = −4, d = 2, n = 20.
S20 = (20/2)[2(−4) + 19 × 2] = 10[−8 + 38] = 10 × 30.
(c) 300

Book Example-2 · L-2
If the sum of n terms of a series is 5n² + 3n, find its nth term. Are the terms in A.P.?
Tn = Sn − Sn−1 = (5n² + 3n) − [5(n−1)² + 3(n−1)].
= 5n² + 3n − [5n² − 10n + 5 + 3n − 3] = 10n − 2.
Terms: T1 = 8, T2 = 18, T3 = 28, T4 = 38 — every gap is 10.
Tn = 10n − 2 ; yes, an A.P. with d = 10 (matching d = 2A = 2 × 5)
Book Example-3 · L-2
How many terms of the series 20, 19⅓, 18⅔, … add up to 300?
The gaps are 19⅓ − 20 = −2/3 and 18⅔ − 19⅓ = −2/3, so it is an A.P. with a = 20, d = −2/3.
(n/2)[40 + (n − 1)(−2/3)] = 300 ⇒ n[20 − (n − 1)/3] = 300 ⇒ n[(60 + 1 − n)/3] = 300.
n(61 − n) = 900 ⇒ n² − 61n + 900 = 0 ⇒ (n − 25)(n − 36) = 0.
Both roots are valid positive integers. Terms 26 through 36 sum to exactly 0 (T26 = 10/3 and T36 = −10/3 balance out), which is why the sum revisits 300.
n = 25 or n = 36
Book Example-4 · L-2
Find four numbers in A.P. whose sum is 50 and in which the greatest is 4 times the least.
Take them symmetrically: a − 3d, a − d, a + d, a + 3d. Sum = 4a = 50 ⇒ a = 25/2.
Greatest = 4 × least: a + 3d = 4(a − 3d) ⇒ a + 3d = 4a − 12d ⇒ 15d = 3a ⇒ a = 5d.
So d = a/5 = (25/2)/5 = 5/2.
Terms: 25/2 − 15/2, 25/2 − 5/2, 25/2 + 5/2, 25/2 + 15/2 = 10/2, 20/2, 30/2, 40/2.
5, 10, 15, 20 (sum 50 ✓, and 20 = 4 × 5 ✓)
L-2

Selecting Terms in an A.P.

When a question gives you the sum of some unknown terms in A.P., don't write them as a, a+d, a+2d — centre them instead, and the d's cancel on the spot.

3 termsa − d , a , a + d sum = 3a
4 termsa − 3d , a − d , a + d , a + 3d sum = 4a (common difference 2d)
5 termsa − 2d , a − d , a , a + d , a + 2d sum = 5a
★ The rule behind the tableOdd number of terms → there is a genuine middle term, call it a, and the common difference is d. Even number of terms → the two middle terms are a − d and a + d, and the common difference is 2d. Getting this backwards for four terms is the usual mistake.
Linked concept — the arithmetic mean (used by the Levels of this chapter)
The A.M. of a and c is b = (a + c)/2; equivalently a, b, c are in A.P. exactly when 2b = a + c. To insert n arithmetic means between a and b, build an A.P. of (n + 2) terms with first term a and last term b, so d = (b − a)/(n + 1); the kth mean is a + k(b − a)/(n + 1), and all n of them add up to n(a + b)/2 — that is, n times the single A.M. of the two ends.
💡 Sum plus sum-of-squaresThe pairing "sum given and sum of squares given" is designed for symmetric terms: the sum fixes a immediately, then the squares give (a−d)² + a² + (a+d)² = 3a² + 2d², where the cross terms 2ad cancel. One equation, one unknown.
Worked example from the module
Book Example · L-2 theory
The sum of three numbers in A.P. is 27 and the sum of their squares is 293. Find the numbers.
Take them as a − d, a, a + d. Sum: 3a = 27 ⇒ a = 9.
Squares: (a − d)² + a² + (a + d)² = 3a² + 2d² = 293 (the ±2ad terms cancel).
3(81) + 2d² = 293 ⇒ 2d² = 293 − 243 = 50 ⇒ d² = 25 ⇒ d = ±5.
d = 5 gives 4, 9, 14; d = −5 gives the same three numbers in reverse order.
4, 9, 14
L-3

Important Properties of an A.P.

property 1 — shifting & scalingai ± K → still an A.P., d unchanged · aiK → A.P. with d × K · ai/K → A.P. with d ÷ K (K ≠ 0)
property 2 — combining two a.p.sIf {ai} and {bi} are A.P.s then {ai ± bi} is an A.P.
property 3 — equidistant endsa1 + an = a2 + an−1 = a3 + an−2 = … constant
property 4 — every term is a mid-pointar = (ar−k + ar+k)/2 for every k with 0 ≤ k ≤ n − r
  • Property 1 is why you may freely add a constant to every term, or clear a common factor, without leaving A.P.-land — the standard trick for turning an ugly-looking triple into a recognisable one.
  • Property 3 is Property 4 in disguise, and both come from the same "pair the ends" idea that produced the sum formula.
  • Products and reciprocals are not covered: multiplying two A.P.s term by term, or flipping an A.P., generally destroys the pattern (flipping gives an H.P. — see M-8C).
💡 The add-then-divide manoeuvreTo show an awkward triple is an A.P., add the same quantity to all three terms and then divide all three by the same quantity — by Property 1 neither step can change the answer. Choosing "add 1" or "add 2", then "divide by (a + b + c)", collapses most such problems in two lines.
★ Sum shortcut from Property 3Any pair of equidistant terms sums to a1 + an. So if a question hands you something like a6 + a9 + a12 + a15 for a 20-term A.P., recognise it as two equidistant pairs = 2(a1 + a20) and go straight to S20 = (20/2)(a1 + a20). No a, no d, no solving.
Worked example from the module
Book Example · L-3 theory
If (b + c − a)/a, (c + a − b)/b, (a + b − c)/c are in A.P., prove that 1/a, 1/b, 1/c are also in A.P.
By Property 1 we may add the same number to each term. Add 2:
(b + c − a)/a + 2 = (b + c + a)/a, and similarly (c + a + b)/b and (a + b + c)/c — still an A.P.
Now divide every term by the same non-zero quantity (a + b + c) — again still an A.P.
1/a, 1/b, 1/c are in A.P.
Solved Examples from the module
Book Example-1 · L-3
If a, b, c ∈ R⁺ are in A.P., prove that a + 1/(bc), b + 1/(ca), c + 1/(ab) are also in A.P.
Start from the given A.P.: a, b, c. Divide every term by abc — legal by Property 1.
That gives a/(abc), b/(abc), c/(abc) = 1/(bc), 1/(ca), 1/(ab) — a second A.P.
Now add the two A.P.s term by term, which is legal by Property 2.
a + 1/(bc), b + 1/(ca), c + 1/(ab) are in A.P.
Book Example-2 · L-3
The successive terms of an A.P. are a1, a2, a3, … Find S20 given a6 + a9 + a12 + a15 = 20.
In a 20-term A.P., a6 and a15 are equidistant from the two ends (6th from the front, 6th from the back), and so are a9 and a12.
By Property 3: a6 + a15 = a9 + a12 = a1 + a20.
So the given sum is 2(a1 + a20) = 20 ⇒ a1 + a20 = 10.
S20 = (20/2)(a1 + a20) = 10 × 10.
S20 = 100

JEE Main 2026 (22 Jan Shift 1) · Level-3
If the sum of the first four terms of an A.P. is 6 and the sum of its first six terms is 4, then the sum of its first twelve terms is — (a) −20 (b) −22 (c) −26 (d) −24
S4 = 2(2a + 3d) = 6 ⇒ 2a + 3d = 3.
S6 = 3(2a + 5d) = 4 ⇒ 2a + 5d = 4/3.
Subtract: 2d = 4/3 − 3 = −5/3 ⇒ d = −5/6, and 2a = 3 + 5/2 = 11/2.
S12 = 6(2a + 11d) = 6(11/2 − 55/6) = (33 − 55) = −22.
(b) −22
JEE Main 2026 (23 Jan Shift 1) · Level-4
Let Σk=1..n ak = αn² + βn. If a10 = 59 and a6 = 7a1, then α + β equals — (a) 12 (b) 3 (c) 5 (d) 7

a10 = 19α + β = 59 … (i)

JEE Main 2026 (24 Jan Shift 2) · Level-4
Let a1, a2, a3, a4 be an A.P. of four terms whose terms and common difference ℓ are all integers. If a1+a2+a3+a4 = 48 and a1a2a3a4 + ℓ⁴ = 361, the largest term is — (a) 24 (b) 21 (c) 23 (d) 27

Product = (144 − 9t²)(144 − t²) = 9t⁴ − 1440t² + 20736, and ℓ⁴ = 16t⁴.
Total: 25t⁴ − 1440t² + 20736 = 361 ⇒ 5t⁴ − 288t² + 4075 = 0.
t² = [288 ± √(82944 − 81500)]/10 = [288 ± 38]/10 = 32.6 or 25. Only t² = 25 keeps ℓ = 2t an integer, so t = 5, ℓ = 10.
Terms: −3, 7, 17, 27. Check: sum 48 ✓, product −9639, plus 10⁴ = 361 ✓.
(d) 27

JEE Main 2022 (27 Jul Shift 1) · Level-5
An A.P. of natural numbers has S5 : S9 = 5 : 17 and 110 < a15 < 120. Find S10. (a) 290 (b) 380 (c) 460 (d) 510
S5 = 5(a + 2d) and S9 = 9(a + 4d) — note S2k+1 = (2k+1) × middle term.
5(a + 2d)/[9(a + 4d)] = 5/17 ⇒ 17(a + 2d) = 9(a + 4d) ⇒ 8a = 2d ⇒ d = 4a.
a15 = a + 14d = a + 56a = 57a, and 110 < 57a < 120 forces a = 2 (57 × 2 = 114).
So a = 2, d = 8 and S10 = 5(2a + 9d) = 5(4 + 72).
(b) 380
JEE Advanced 2022 (Paper 1) · Level-6
l1…l100 is an A.P. with common difference d1; w1…w100 is an A.P. with common difference d2; d1d2 = 10. Ri is a rectangle of length li, width wi, area Ai. If A51 − A50 = 1000, find A100 − A90.
Write k = i − 1. Then Ai = (l1 + kd1)(w1 + kd2) = l1w1 + k(l1d2 + w1d1) + k²·d1d2 — a quadratic in k. Put P = l1d2 + w1d1.
A51 − A50 uses k = 50 and 49: (50 − 49)P + (50² − 49²)(10) = P + 99 × 10 = 1000 ⇒ P = 10.
A100 − A90 uses k = 99 and 89: (99 − 89)P + (99² − 89²)(10) = 10 × 10 + (9801 − 7921)(10).
= 100 + 1880 × 10 = 100 + 18800.
18900

★ Pattern of the whole Strong BoxAlmost every question reduces to two linear equations in a and d — form them, subtract to kill a, and substitute back. The only ones that don't (the product question, the rectangle question) are asking you to recognise a quadratic in n and difference it.
