Core Compound-Angle Formulas

A compound angle is any algebraic sum of two or more angles — A ± B, A + B + C, A − B + C, etc.

L-1

Trigonometric Ratios of Sum & Difference

  • Every ratio of A ± B is built from the ratios of A and B alone — expand, then substitute known values.
  • Fix the sign of each ratio by its quadrant before plugging in (e.g. cos A > 0 in Q1, sin B < 0 in Q3).
sum & differencesin(A ± B) = sin A cos B ± cos A sin B
cos(A ± B) = cos A cos B ∓ sin A sin B
tan(A ± B) = (tan A ± tan B)/(1 ∓ tan A tan B)
Reading a value off the unit-circle diagram
In the book's figure, ∠POQ = A and ∠QOR = B, so ∠POR = A + B. Dropping perpendiculars and comparing projected lengths gives sin(A+B) = sin A cos B + cos A sin B. Replacing B by −B (with cos even, sin odd) instantly yields the difference forms — you never memorise them separately.
💡 TipConvert awkward angles to a sum/difference of standard ones: 105° = 90° + 15°, 7π/12 − π/4 = π/3, 15° = 45° − 30°.
⚠ TrapSign errors: in cos(A+B) the middle sign flips to minus, and in tan(A+B) the denominator is 1 − tan A tan B. Mixing these up is the most common slip.

Book Example · L-1
If a tan α + b tan β = (a + b) tan((α + β)/2), with α ≠ β, prove that a cos β = b cos α.
Group as a{tan α − tan((α+β)/2)} = b{tan((α+β)/2) − tan β}.
Use tan A − tan B = sin(A − B)/(cos A cos B): each side gives sin((α−β)/2). Cancelling the common sin((α−β)/2) ≠ 0 leaves a/b = cos α/cos β.
⇒ a cos β = b cos α
Book Example · L-1
If tan A − tan B = x and cot B − cot A = y, prove cot(A − B) = 1/x + 1/y.
cot B − cot A = (tan A − tan B)/(tan A tan B) = x/(tan A tan B) = y ⇒ tan A tan B = x/y.
cot(A − B) = (1 + tan A tan B)/(tan A − tan B) = (1 + x/y)/x = (y + x)/(xy).
cot(A − B) = 1/x + 1/y
L-2

Product Forms, Triple-Angle Sums & Series in A.P.

square ⇄ productsin(A+B)·sin(A−B) = sin²A − sin²B = cos²B − cos²A
cos(A+B)·cos(A−B) = cos²A − sin²B = cos²B − sin²A
three anglessin(A+B+C) = cos A cos B cos C (tan A + tan B + tan C − tan A tan B tan C)
cos(A+B+C) = cos A cos B cos C (1 − tan A tan B − tan B tan C − tan C tan A)
tan(A+B+C) = (Σtan A − tan A tan B tan C)/(1 − Σtan A tan B)
★ Triangle corollaryIf A + B + C = π then tan A + tan B + tan C = tan A tan B tan C, and cot A cot B + cot B cot C + cot C cot A = 1.

Two special series (angles in A.P.)

sum of sines / cosinesΣ = [sin(nβ/2) / sin(β/2)] · sin or cos( (first angle + last angle)/2 )
for sin α + sin(α+β) + … + sin(α+(n−1)β) use sin; for the cosine series use cos.
Why the difference-of-squares trick is so useful
Any sin²A − sin²B (or cos² difference) collapses to a single product sin(A+B)·sin(A−B). It turns messy squared expressions into one clean product, which is why it dominates the "prove that" problems below — spot two squares, factor them into a product of a known sum-angle and difference-angle.

Book Example · L-2
Prove that sin²6x − sin²4x = sin 2x · sin 10x.
sin²A − sin²B = sin(A+B)·sin(A−B) with A = 6x, B = 4x.
= sin(6x + 4x)·sin(6x − 4x) = sin 10x · sin 2x.
= sin 2x · sin 10x (proved)
Book Example · L-2
Prove that √3 cosec 20° − sec 20° = 4.
L.H.S. = (√3 cos 20° − sin 20°)/(sin 20° cos 20°) = 4(½√3 cos 20° − ½ sin 20°)/(2 sin 20° cos 20°).
Numerator bracket = sin 60° cos 20° − cos 60° sin 20° = sin 40°; denominator = sin 40°.
= 4 · (sin 40°/sin 40°) = 4 (proved)
Book Example · L-2
Prove that sin²(π/8 + A/2) − sin²(π/8 − A/2) = (1/√2) sin A.
Apply sin²X − sin²Y = sin(X+Y)·sin(X−Y): X+Y = π/4, X−Y = A.
= sin(π/4)·sin A = (1/√2) sin A.
= (1/√2) sin A (proved)
Book Example · L-2
Prove that (cos²33° − cos²57°) / (sin²(21°/2) − sin²(69°/2)) = −√2.
Numerator = sin(33°+57°)·sin(57°−33°) = sin 90° · sin 24° = sin 24° (using cos²−cos² = sin²57° − sin²33°).
Denominator = sin(21°/2 + 69°/2)·sin(21°/2 − 69°/2) = sin 45° · sin(−24°) = −(1/√2) sin 24°.
= sin 24° / (−(1/√2) sin 24°) = −√2 (proved)
Book Example · L-2
Prove that cos 2α cos 2β + sin²(α − β) − sin²(α + β) = cos 2(α + β).
sin²(α−β) − sin²(α+β) = sin((α−β)+(α+β))·sin((α−β)−(α+β)) = sin 2α · sin(−2β) = −sin 2α sin 2β.
L.H.S. = cos 2α cos 2β − sin 2α sin 2β = cos(2α + 2β).
= cos 2(α + β) (proved)
L-3

Maximum & Minimum Values of a cosθ + b sinθ

  • Write a cosθ + b sinθ = r sin(θ + α) by putting a = r sin α, b = r cos α, so r = √(a² + b²).
  • Since −1 ≤ sin(θ + α) ≤ 1, the expression is squeezed between ±r.
range−√(a² + b²) ≤ a cosθ + b sinθ ≤ √(a² + b²)
max = √(a²+b²), min = −√(a²+b²); with a constant c added, shift both bounds by c.
Turn any a cosθ + b sinθ into one sinusoid
Factor out r = √(a²+b²): a cosθ + b sinθ = r[(a/r) cosθ + (b/r) sinθ]. Since (a/r)² + (b/r)² = 1, set sin α = a/r, cos α = b/r to get r sin(θ + α) — a single sine wave of amplitude r. Everything about extrema then follows from the fixed range [−1, 1] of the sine.
⚠ TrapBefore finding r, collapse every compound term (e.g. 5 sin(θ − π/6), 3 cos(θ + π/3)) into plain cosθ and sinθ pieces first — then r = √(a²+b²) uses those combined coefficients.
Worked examples from the module
Book Example · L-3
Find the maximum and minimum values of 7 cosθ + 24 sinθ.
r = √(a² + b²) = √(7² + 24²) = √(49 + 576) = √625 = 25.
max = 25, min = −25
Book Example · L-3
Find the maximum and minimum of (i) 3 cosθ + 5 sin(θ − π/6) and (ii) 4 sinθ − 3 cosθ + 7.
(i) 5 sin(θ − π/6) = (5√3/2) sinθ − (5/2) cosθ ⇒ expression = ½ cosθ + (5√3/2) sinθ; r = √(¼ + 75/4) = √19.
(ii) For 4 sinθ − 3 cosθ, r = √(16 + 9) = 5, so it ranges −5…5; add 7 ⇒ 2…12.
(i) max √19, min −√19 (ii) max 12, min 2
Book Example · L-3
Express 3 cosθ − 4 sinθ as a single sine, and as a single cosine.
r = √(3² + (−4)²) = 5. = 5[(3/5) cosθ − (4/5) sinθ] = 5 sin(α − θ) with tan α = 3/4.
Alternatively = 5 cos(α + θ) with tan α = 4/3.
3 cosθ − 4 sinθ = 5 sin(α − θ), tan α = 3/4 = 5 cos(α + θ), tan α = 4/3
Book Example · L-3
Reduce √3 sinθ + cosθ to (i) a single sine and (ii) a single cosine.
r = √((√3)² + 1²) = 2. = 2[(√3/2) sinθ + (½) cosθ] = 2(sinθ cos(π/6) + cosθ sin(π/6)) = 2 sin(θ + π/6).
Also = 2(cosθ cos(π/3) + sinθ sin(π/3)) = 2 cos(θ − π/3).
√3 sinθ + cosθ = 2 sin(θ + π/6) = 2 cos(θ − π/3)
Book Example · L-3
Find the sign of sin 100° + cos 100°.
= √2(sin 100° cos 45° + cos 100° sin 45°) = √2 sin(100° + 45°) = √2 sin 145°.
145° lies in the 2nd quadrant where sine is positive, so √2 sin 145° > 0.

★ STRONG BOX

Previous Year Questions (JEE)

  • The exam repeatedly disguises simple identities inside long expressions — always look for a hidden sin(A±B) or a difference-of-squares that collapses everything.
  • Complementary/supplementary angle pairs (15°/75°, 105°/195°) fold cot ⇄ tan and cancel in symmetric sums.
Worked examples from the Strong Box
JEE Main 2026 · Strong Box
If cot x = 5/12 for some x ∈ (π, 3π/2), find sin 7x[cos(13x/2) + sin(13x/2)] + cos 7x[cos(13x/2) − sin(13x/2)].
Regroup: [sin 7x cos(13x/2) − cos 7x sin(13x/2)] + [sin 7x sin(13x/2) + cos 7x cos(13x/2)] = sin(x/2) + cos(x/2).
(sin(x/2) + cos(x/2))² = 1 + sin x. In Q3, cos x = −5/13, sin x = −12/13 ⇒ 1 + sin x = 1/13; x/2 ∈ (π/2, 3π/4) makes the sum positive.
= 1/√13 (option c)
JEE Main 2023 · Strong Box
If tan 15° + 1/tan 75° + 1/tan 105° + tan 195° = 2a, find the value of a + 1/a.
1/tan 75° = cot 75° = tan 15°; 1/tan 105° = cot 105° = −tan 15°; tan 195° = tan 15°. Sum = tan 15° + tan 15° − tan 15° + tan 15° = 2 tan 15° ⇒ a = tan 15° = 2 − √3.
a + 1/a = tan 15° + cot 15° = 1/(sin 15° cos 15°) = 2/sin 30° = 4.
a + 1/a = 4 (option a)
