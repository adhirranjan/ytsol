The second half of the problem, and the reason three of the four options exist, is a range argument: pin down which of C, π−C, 2π−C, π/2−C actually lies in the interval that A+B can occupy.
Formula tan(A+B) = (tan A + tan B)/(1 − tan A tan B); and tan θ₁ = tan θ₂ ⇔ θ₁ = θ₂ + nπ.
Solution
1. Note x > 0 is forced: tan A and tan B involve √x and √(x(…)), and A, B ∈ (0, π/2) needs them real and positive.Also x²+x+1 > 0 always (D = 1−4 = −3 < 0), so that radical is never a problem.
2. Split the first radical: √(x(x²+x+1)) = √x · √(x²+x+1). So tan A = 1/(√x · √(x²+x+1)).Separating the two factors is what makes the product below cancel.
3. Product: tan A · tan B = [1/(√x·√(x²+x+1))] · [√x/√(x²+x+1)] = √x/(√x · (x²+x+1)) = 1/(x²+x+1).The √x cancels top and bottom; the two √(x²+x+1) multiply into (x²+x+1).
4. Sum: put both over the common denominator √x·√(x²+x+1). The second term becomes √x/√(x²+x+1) = x/(√x·√(x²+x+1)).Multiply numerator and denominator by √x, since √x·√x = x.
5. So tan A + tan B = (1 + x)/(√x · √(x²+x+1)).
6. Denominator of the formula: 1 − tan A tan B = 1 − 1/(x²+x+1) = (x²+x+1 − 1)/(x²+x+1) = x(x+1)/(x²+x+1).x²+x factors as x(x+1) — and that (x+1) is about to cancel the (1+x) upstairs.
7. Divide: tan(A+B) = [(1+x)/(√x·√(x²+x+1))] × [(x²+x+1)/(x(x+1))].
8. The (1+x) cancels, and (x²+x+1)/√(x²+x+1) = √(x²+x+1). Left with tan(A+B) = √(x²+x+1)/(x·√x) = √(x²+x+1)/x3/2.

10. So tan(A+B) = tan C identically in x.

12. Both A+B and C now lie in (0, π/2), where tan is strictly increasing and hence one-one. Equal tangents therefore force A + B = C.
13. Options (b) π−C and (c) 2π−C are outside (0, π/2); (d) π/2 − C would give tan(A+B) = cot C, not tan C. So (a) is the answer.

If sin(α + β) = 1/3 and cos(α − β) = 2/3, then the greatest integer less than or equal to (sinα/cosβ + cosβ/sinα + cosα/sinβ + sinβ/cosα)² is ______ [JEE Advanced 2022, Paper 2] (Level-6)Compound angles, pairing terms, greatest integersin(α + β) = 1/3, cos(α - β) = 2/3, then (sinα / cosβ + cosβ /sinα + cosα / sinβ + sinβ / cosα)² is🟢 Exact1
Concept Never chase α and β individually — the four fractions pair with their reciprocals: sinα/cosβ with cosβ/sinα, and cosα/sinβ with sinβ/cosα. Each pair becomes (sum of squares)/(product), and every piece — numerators and denominators alike — is expressible in s = sin(α+β) and t = sin(α−β) via sin²α − sin²β = st and the product-to-sum formulas. The given ranges fix t's sign and guarantee sin β < 0, which is why the expression comes out negative before squaring.
Formula sin²α − sin²β = sin(α+β)sin(α−β); sin α cos β = (1/2)[sin(α+β) + sin(α−β)]; cos α sin β = (1/2)[sin(α+β) − sin(α−β)]. Data: s = 1/3, cos(α−β) = 2/3.
Solution
1. Ranges: −π/4 < β < 0 < α < π/4 ⇒ α−β ∈ (0, π/2), so t = sin(α−β) = +√(1 − 4/9) = √5/3.First quadrant forces the + root; s = 1/3 is given.
2. Pair reciprocals: sinα/cosβ + cosβ/sinα = (sin²α + cos²β)/(sinα cosβ) and cosα/sinβ + sinβ/cosα = (cos²α + sin²β)/(cosα sinβ).
3. Numerators: sin²α + cos²β = 1 + (sin²α − sin²β) = 1 + st; cos²α + sin²β = 1 − (sin²α − sin²β) = 1 − st.
4. Denominators: sinα cosβ = (s + t)/2, cosα sinβ = (s − t)/2. So E = 2(1+st)/(s+t) + 2(1−st)/(s−t) = 2[(1+st)(s−t) + (1−st)(s+t)]/(s²−t²) = 2(2s − 2st²)/(s²−t²) = 4s(1 − t²)/(s² − t²).The cross terms ±s²t cancel; everything odd in t drops out.
5. Numbers: s = 1/3, t² = 5/9 ⇒ E = 4·(1/3)·(4/9)/((1/9) − (5/9)) = (16/27)/(−4/9) = −4/3.Negative, as expected: sin β < 0 makes the second pair large and negative.
6. Square and floor: E² = 16/9 = 1.777…, so [E²] = 1. Check: α ≈ 0.5905, β ≈ −0.2506 (both in range); the four fractions give 0.575 + 1.740 − 3.350 − 0.299 = −1.333 ✓.
