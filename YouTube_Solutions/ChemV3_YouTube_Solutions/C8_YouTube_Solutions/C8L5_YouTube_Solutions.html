1 (i)Fill in the blank: The valence factor of an acid is the number of replaceable ________ ions.Valence factor of acidN Factor Calculation | Trick to calculate n factor | How to calculate valency factor?🟡 SimilarH⁺ ions
Concept The valence factor (n-factor) of an acid is the count of replaceable H+ it can furnish per molecule in water. The trap is to count every hydrogen atom in the formula; only the ionisable ones (those released as H+) are counted.
Key relation n-factor(acid) = number of replaceable H+, and Equivalent mass = Molar mass / n-factor This is why basicity, not the total H count, fixes the equivalent mass.
Solution
1. An acid in the Arrhenius sense donates H+ when dissolved in water.
2. The valence factor equals the number of such H+ ions one molecule can release. This is the acid’s basicity.
3. HCl releases 1, so n = 1; H2SO4 releases 2, so n = 2; H3PO4 releases 3, so n = 3.
4. Only replaceable H counts: CH3COOH has 4 H atoms but only the –COOH hydrogen ionises, so n = 1.
5. H3PO3 has 3 H atoms but only 2 are on –OH and replaceable, so n = 2, not 3.
6. Hence the blank is filled by H+ (hydrogen) ions.
 acid  :  replaceable H+   n-factor
 ---------------------------------------
 HCl               1          1
 H2SO4             2          2
 H3PO4             3          3
 CH3COOH           1          1  (4 H total)
 ---------------------------------------
 n-factor of acid = replaceable H+ ions
⚡ JEE Trick Count acidic (ionisable) H, never total H. The giveaway for oxoacids: only H attached to oxygen (–OH) is replaceable; H bonded straight to the central atom (as in H3PO3, H3PO2) is not.
Answer: the valence factor of an acid is the number of replaceable H+ ions.

Concept The valence factor (n-factor) of a base is the count of replaceable OH− it furnishes per formula unit in water, i.e. its acidity. The trap is counting every O or H in the formula instead of the hydroxide groups actually released.
Key relation n-factor(base) = number of replaceable OH−, and Equivalent mass = Molar mass / n-factor Acidity of the base, not its molar mass alone, sets the equivalent mass.
Solution
1. A base in the Arrhenius sense releases OH− when dissolved in water.
2. The valence factor equals the number of OH− one formula unit can furnish. This is the base’s acidity.
3. NaOH gives 1, so n = 1; Ca(OH)2 gives 2, so n = 2; Al(OH)3 gives 3, so n = 3.
4. The equivalent mass follows: for Ca(OH)2 (M = 74) it is 74/2 = 37.
5. This mirrors the acid rule exactly, with OH− playing the role H+ plays for acids.
6. Hence the blank is filled by OH− (hydroxide) ions.

⚡ JEE Trick Acidity of a base = number of OH− it supplies; basicity of an acid = number of H+ it supplies. Keep the pair straight and the equivalent mass follows instantly as M divided by that count.

1 (iii)Fill in the blank: The valence factor of a redox reaction is the number of electrons ________ or ________ by one molecule of oxidant or reductant.Valence factor of redoxRedox Reactions (Mole Concept-2) | Class 11 (L4) | n factor for redox Reaction | Equivalent Weight🟡 Similarlost, gained
Concept For a redox change the valence factor (n-factor) is the number of electrons lost (by the reductant) or gained (by the oxidant) per molecule. The trap is to use basicity/acidity here; in redox it is the total change in oxidation number that counts.
Key relation n-factor = total change in oxidation number per molecule = electrons lost or gained, Eq. mass = M / n-factor One electron transferred corresponds to one unit of oxidation-number change.
Solution
1. In a redox reaction electrons move from the reductant to the oxidant.
2. The reductant loses electrons (oxidised); the oxidant gains electrons (reduced). Both counts are equal overall, so charge balances.
3. The valence factor of each is the number of electrons it loses or gains per molecule.
4. KMnO4 in acid: Mn goes +7 → +2, gaining 5 e−, so n = 5.
5. FeSO4: Fe goes +2 → +3, losing 1 e−, so n = 1.
6. Hence the two blanks are lost and gained.
 species   oxid. no. change   e- per molecule
 ---------------------------------------------
 KMnO4     +7 -> +2           5 gained  (n=5)
 FeSO4     +2 -> +3           1 lost    (n=1)
 ---------------------------------------------
 n-factor (redox) = e- lost OR gained
⚡ JEE Trick Never mix the two n-factor rules: use replaceable H+/OH− for acid–base, but electrons lost/gained for redox. For a salt acting in a redox titration, always switch to the electron-transfer count.
Answer: the number of electrons lost or gained by one molecule of oxidant or reductant.
1 (iv)Fill in the blank: A metal Mn+ has equivalent mass M/3 then value of n will be ________Equivalent mass and valencyRedox Reactions (Mole Concept-2) | Class 11 (L4) | n factor for redox Reaction | Equivalent Weight🟡 Similar3
Concept Equivalent mass of an ion equals its molar mass divided by its n-factor, and for a simple metal ion Mn+ the n-factor is just the magnitude of the charge n. Given the equivalent mass as M/3, read n straight off the denominator. The common trap is to confuse the molar mass symbol M with the chemical symbol of the metal, and a second trap is to think the equivalent mass is some fixed number rather than a ratio.
Key relation Equivalent mass = Molar mass / n-factor = M / n, with n-factor = charge of Mn+ For a bare cation the only ‘reaction’ is carrying its charge, so the n-factor equals that charge.
Solution
1. Write the definition: equivalent mass = M / n, where M is the molar mass and n the n-factor.
2. For a metal ion Mn+ taking part only as a charged species, the n-factor equals its charge n.
3. The problem states the equivalent mass is M/3.
4. Equate the denominators: M / n = M / 3, so n = 3. The molar mass M cancels, leaving n directly.
5. For the cation Mn+ the n-factor is its charge, so the ion is tripositive: M3+.
6. Check with a real ion: Al3+ (M = 27) has equivalent mass 27/3 = 9, matching the M/3 form exactly.
7. Hence n = 3.
 Eq. mass = M / n       (n = charge of cation)
 given    : M / 3
 ---------------------------------------------
 M/n = M/3   ->   n = 3
 ---------------------------------------------
 e.g. Al3+ : 27/3 = 9   (n = 3)        <-- n=3
 Fe3+      : 56/3 = 18.7 also n = 3
⚡ JEE Trick The denominator of an equivalent-mass expression IS the n-factor. Whenever you see M/k, read n = k at once — no oxidation-state bookkeeping is needed for a bare metal ion whose charge equals its n-factor. Here M/3 means the ion is M3+, so n = 3.
Answer: n = 3.

Concept Equivalent weight of a redox species = M / (total change in oxidation number per formula unit). Find the oxidation state before and after, multiply the per-atom change by the number of atoms changing, and divide M by that total. The trap is forgetting there are two atoms of the element in some formulas.

Concept Dichromate Cr2O72− is reduced to Cr3+ when it oxidises Fe(II) to Fe(III). The electrons involved per chromium atom is simply the drop in chromium’s oxidation number from reactant to product. The trap is to quote 6, the per-ion total for both Cr atoms (the n-factor of dichromate), when the stem explicitly asks per atom.
Key relation electrons per Cr = (ox. no. of Cr in Cr2O72−) − (ox. no. of Cr in Cr3+) Each unit of oxidation-number fall corresponds to exactly one electron gained.
Solution
1. In Cr2O72−: 2Cr + 7(−2) = −2, so 2Cr = +12 and each Cr = +6.
2. In the product Cr3+ chromium is +3.
3. Change per Cr = 6 − 3 = 3, so each chromium atom gains 3 electrons. This is the per-atom answer the stem wants.
4. The balanced half-reaction confirms it: Cr2O72− + 14H+ + 6e− → 2Cr3+ + 7H2O.
5. The ion accepts 6 electrons for its 2 Cr atoms, so 6/2 = 3 electrons per chromium atom.
6. The partner half-reaction is Fe2+ → Fe3+ + e−, needing 6 Fe(II) per dichromate. Consistent with 6 electrons transferred.
7. Hence the answer is 3 electrons per chromium atom, option (a).

 ------------------------------------------

⚡ JEE Trick Read “per chromium atom” carefully: the full ion takes 6 e− (the n-factor of dichromate), but per atom it is 6/2 = 3. Option (d) 4 and the distractor 6 both tempt if you blur the two.

Concept We need a reaction where one carbon atom moves across the full range from its most reduced state (−4) to its most oxidised state (+4). The combustion of methane does exactly this: carbon in CH4 is −4, carbon in CO2 is +4. The trap is a reaction that only partly oxidises carbon (e.g. to CO).
Key relation C in CH4 = −4 (H = +1); C in CO2 = +4 (O = −2) A swing of 8 units per carbon marks the extreme redox range.
Solution
1. In CH4, H = +1, so C + 4(+1) = 0 ⇒ C = −4 (fully reduced).
2. In CO2, O = −2, so C + 2(−2) = 0 ⇒ C = +4 (fully oxidised).
3. Combustion of methane carries carbon from −4 to +4, the maximum possible swing.
4. Write and balance: CH4 + 2O2 → CO2 + 2H2O.
5. Check atoms: C 1=1, H 4=4, O 4=4 (2+2). The equation is balanced.
6. Oxygen is reduced 0 → −2 while carbon is oxidised −4 → +4, confirming the redox change.
 CH4 + 2O2 -> CO2 + 2H2O
 -----------------------------------------

 O :  0 (O2)   ->  -2         reduced

In general n-factor of acid/base is number of moles of H+/OH− furnished per mole of acid/base. n-factor of a reactant is number of moles of electrons lost or gained per mole of reactant.
Example 1: (1) In acidic medium: KMnO4 (n = 5) → Mn2+; (2) In neutral medium: KMnO4 (n = 3) → Mn2+; (3) In basic medium: KMnO4 (n = 1) → Mn6+.
Example 2: FeC2O4 → Fe3+ + 2CO2. Total number of moles of e− lost by 1 mole of FeC2O4 = 1 + 1×2 ⇒ 3.
For the reaction,
Fe0.95O (molar mass = M) → Fe2O3,
what is the eq. mass of Fe0.95O?.
(a) M/0.85   (b) M/0.95   (c) M/0.8075   (d) None of these		Equivalent mass of wustiteEquivalent Mass and n-Factor | JEE Main 2027 Chemistry (English) | RankDeterminant🟡 Similar(a) M/0.85
Concept In non-stoichiometric wustite Fe0.95O some iron sits as Fe3+ to make up for the missing cations, but the crystal as a whole must stay electrically neutral, so the 0.95 iron atoms together carry exactly +2 (balancing one O2−). On oxidation to Fe2O3 every iron becomes +3. The n-factor is the total charge gained per formula unit, which neatly sidesteps the awkward fractional average oxidation state.
Key relation n = (total Fe charge in product) − (total Fe charge in reactant) Counting net electrons lost per formula unit is cleaner than using the average O.S. of +2/0.95.
Solution
1. Neutrality of Fe0.95O: total Fe charge = +2 (one O is −2).
2. In the product Fe2O3 every Fe is +3.
3. The same 0.95 Fe atoms end at +3 each: final total Fe charge = 0.95 × 3 = 2.85.
4. Electrons lost per formula = 2.85 − 2.00 = 0.85 = n.
5. Eq. mass = M ÷ n = M ÷ 0.85 = M/0.85.
6. The messy alternative via average O.S. gives the same 0.85 but invites arithmetic slips.
 Fe0.95O neutral : Fe total = +2
 product Fe2O3   : every Fe = +3
 final Fe charge = 0.95 x 3 = 2.85
 e- lost = 2.85 - 2.00 = 0.85 = n
 Eq = M / 0.85                      <-- answer
⚡ JEE Trick Use the net change in total cation charge, not the fractional average O.S. (+2/0.95 ≈ 2.105). The trap M/0.95 comes from wrongly using the atom count 0.95 as the n-factor, and M/0.8075 from multiplying 0.95×0.85; the true n is just the 0.85 electrons actually released per formula unit.
Answer: (a) M/0.85.

Concept The passage's rule is that the reciprocal of the reactants' n-factor ratio is their mole ratio. VO is oxidised (V +2 → +5) and Fe2O3 is reduced (Fe +3 → +2), so simply matching electrons lost to electrons gained fixes the coefficients x and y without balancing the whole equation first.
Key relation x × n(VO) = y × n(Fe2O3) ⇒ x : y = n(Fe2O3) : n(VO) Total electrons lost by the reductant must equal total electrons gained by the oxidant.
Solution
1. VO → V2O5: V +2 → +5 loses 3e− per V; so n(VO) = 3.
2. Fe2O3 → FeO: each of 2 Fe +3 → +2 gains 1e−; so n(Fe2O3) = 2.
3. Electron balance: 3x = 2y.
4. Smallest integer solution: x = 2, y = 3.
5. Mole ratio x : y = n(Fe2O3) : n(VO) = 2 : 3, consistent with step 4.
6. Check: 2VO + 3Fe2O3 → 6FeO + V2O5; O = 2+9 = 11 on each side.

⚡ JEE Trick Just set electrons-lost = electrons-gained: 3x = 2y gives x : y = 2 : 3 instantly, with no full balancing required. Option (c) 3, 2 is the reversed pair, the classic trap from swapping which reactant is oxidised and which is reduced; remember vanadium goes up (+2 to +5) and iron comes down (+3 to +2).
Answer: (b) x = 2, y = 3.
7The equivalent weight of Br2 is 96 in the following disproportionation reaction
Br2 + OH− → Br− + H2O + ? (Oxidized product)
The oxidation state of Br in the oxidized product is (Br = 80)		Oxidation state of oxidized BrEquivalent weight of Br2 is 96 in the following disproportionation reaction: Br2+OH- Br-+H2O🟢 Exact+5
Concept Br2 (M = 160) disproportionates in alkali: part becomes Br− (each Br gains 1e−) and part rises to an oxidised product of unknown state +x. The equivalent weight 96 that is quoted pins the overall n-factor, and from that single number the oxidation state x drops out.
Key relation n = 160/Eq = 160/96 = 5/3; and for this disproportionation n = 2x/(x+1) n = (total e− moved)/(moles Br2); x reduced Br pair with 1 oxidised Br of charge +x.
Solution
1. From Eq = M/n: n = 160/96 = 5/3.
2. Reduced Br: 0 → −1 gains 1e−; oxidised Br: 0 → +x loses x e−.
3. For charge balance x reduced Br accompany 1 oxidised Br, giving (x+1) Br atoms = (x+1)/2 moles Br2.
4. Electrons moved = x, so n = x ÷ [(x+1)/2] = 2x/(x+1).
5. Set 2x/(x+1) = 5/3 ⇒ 6x = 5(x+1) = 5x + 5.
6. Hence x = 5, the oxidised product being BrO3−.
 Eq = M/n : n = 160/96 = 5/3

 oxidise Br: 0 -> +x   (-x e each)

⚡ JEE Trick Work backwards from the fractional n: a value like 5/3 (neither 1 nor a whole number) is the tell-tale fingerprint of a disproportionation. Solving 2x/(x+1) = 5/3 lands on +5, the bromate ion BrO3−, which is the usual oxidised product of Br2 in hot alkali (cold alkali would give the +1 hypobromite instead).
Answer: +5 (oxidised product BrO3−).
8In the following redox reactions, NH3 appears either in reactant or product. In which case, the equivalent weight of NH3 is maximum ?
(a) N2 + 3H2 → 2NH3   (b) 4NH3 + 5O2 → 4NO + 6H2O   (c) 2NH3 + 2Na → 2NaNH2 + H2   (d) Equal in all cases		Maximum equivalent weight of NH3Redox Reactions (Mole Concept-2) | Class 11 (L4) | n factor for redox Reaction | Equivalent Weight🟡 Similar(c) 2NH₃ + 2Na → 2NaNH₂ + H₂
Concept The equivalent weight of NH3 is 17/n, so it is largest where n is smallest. The n-factor is the electron change on nitrogen, or — when nitrogen's state does not move — the H+ that NH3 furnishes. The biggest equivalent weight therefore comes from the smallest redox role, which turns out to be the case where N does not change at all.
Key relation Eq = 17 / n, with n = |ΔO.S. of N| (or H+ released if N is unchanged) Compare n across the three reactions; the smallest n gives the largest Eq.
Solution
1. (a) N2 + 3H2 → 2NH3: N 0 → −3, n = 3, Eq = 17/3 ≈ 5.67.
2. (b) 4NH3 + 5O2 → 4NO + 6H2O: N −3 → +2, n = 5, Eq = 17/5 = 3.4.
3. (c) 2NH3 + 2Na → 2NaNH2 + H2: in NaNH2 the amide N is still −3.
4. So nitrogen does not change; the redox is Na 0 → +1 and H+ → (1/2)H2.
5. NH3 merely donates one H, acting as an acid with n = 1, so Eq = 17.
6. Comparing 5.67, 3.4 and 17, the largest equivalent weight is case (c).
 (a) N: 0 -> -3   n=3   Eq=17/3=5.67
 (b) N:-3 -> +2   n=5   Eq=17/5=3.4
 (c) N:-3 -> -3   n=1   Eq=17/1=17   <-- max
⚡ JEE Trick The biggest equivalent weight means the smallest n. In (c) nitrogen's oxidation state never moves (NH3 → NH2−, both −3), so NH3 behaves only as a very weak acid (n = 1) and keeps its full mass of 17.
Answer: (c) 2NH3 + 2Na → 2NaNH2 + H2.
9Equivalent masses of NH3 in the reactions are :
(i) 4NH3 + 5O2 → 4NO + 6H2O,
(ii) 2NH3 → N2 + 3H2
(a) 5 : 6   (b) 6 : 5   (c) 5 : 3   (d) 3 : 5		Ratio equivalent masses NH3Redox Reactions (Mole Concept-2) | Class 11 (L4) | n factor for redox Reaction | Equivalent Weight🟡 Similar(d) 3 : 5
Concept Both reactions oxidise the nitrogen of NH3, but carry it to different final oxidation states, so their n-factors differ. Since equivalent mass is 17/n (the molar mass of NH3 is 17), the ratio of the two equivalent masses is the inverse of the ratio of the nitrogen electron changes — the n-values flip over when you turn them into equivalents, and that single flip is the whole question.
Key relation Eq = 17/n; so Eq(i):Eq(ii) = (1/ni):(1/nii) = nii:ni Equivalent mass is inversely proportional to the n-factor, so the larger n gives the smaller equivalent mass.
Solution
1. (i) 4NH3 + 5O2 → 4NO + 6H2O: nitrogen goes −3 → +2, a change of 5, so n = 5 and Eq = 17/5.
2. (ii) 2NH3 → N2 + 3H2: nitrogen goes −3 → 0, a change of 3, so n = 3 and Eq = 17/3.
3. Form the required ratio Eq(i) : Eq(ii) = (17/5) : (17/3).
4. Cancel the common factor 17: = 1/5 : 1/3.
5. Multiply both terms by 15 to clear the fractions: = 3 : 5.
6. So the equivalent masses are in the ratio 3 : 5.
7. Check: reaction (i) has the bigger n (5), so it correctly gets the smaller share (3).
 (i)  N -3 -> +2  n=5   Eq = 17/5
 (ii) N -3 ->  0  n=3   Eq = 17/3
 ratio = (17/5):(17/3) = (1/5):(1/3)
       x15 -> 3 : 5                 <-- answer
⚡ JEE Trick Equivalent mass flips the n-factors: n = 5 and 3 give an Eq ratio of 3 : 5, not 5 : 3. Option (c) 5 : 3 is the n-factor ratio itself left un-inverted, the planted trap for students who skip the reciprocal; the oxygen and hydrogen coefficients (5 : 6 etc.) in (a) and (b) are pure red herrings.
Answer: (d) 3 : 5.

Concept In pyrite FeS2 iron is +2 and the disulphide unit holds sulphur at −1 (there is an S–S bond), not −2. On roasting, both Fe and S are oxidised, so the whole formula carries a large n-factor, while each product's equivalent weight tracks only its own element. Testing each statement against these facts settles the multiple-correct choice.
Key relation n(FeS2) = Δ(Fe) + 2×Δ(S); Eq = M/n All oxidisable centres add into one n-factor, and the balanced equation fixes the O2 demand.
Solution
1. Oxidation states in FeS2: Fe = +2, each S = −1, so statement (c) claiming −2 is wrong.
2. Fe +2 → +3 loses 1e−; each S −1 → +4 (SO2) loses 5e−, two S give 10.
3. n(FeS2) = 1 + 10 = 11, so Eq(FeS2) = M/11: (a) is correct.
4. For SO2, its sulphur rose −1 → +4 (5e−), so Eq(SO2) = M/5: (b) is correct.
5. Balanced roasting: 4FeS2 + 11O2 → 2Fe2O3 + 8SO2.
6. Thus 1 mol FeS2 needs 11/4 O2, not 7/4: (d) is wrong. Correct set: (a), (b).
