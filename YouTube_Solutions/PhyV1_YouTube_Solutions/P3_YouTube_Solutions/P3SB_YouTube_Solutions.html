1Position vector r⃗ = xî + yĵ + zk̂ changes sign as −r⃗ — which one of the following vectors will not flip under the sign change? (JEE Main 2026, 28th Jan Shift 2, Level-3)Parity / pseudovectorsJEE Main 2026 (28 January Shift 2): When the position vector r = xi + yj + zk changes sign as -r🟢 ExactdAngular momentum
Concept Space inversion (parity) sends every position to its mirror image, r⃗ → −r⃗. Physical vectors split into two families under this operation. Polar (true) vectors — position, velocity, momentum, force, acceleration, electric field — reverse sign, because they are built directly from displacements. Axial (pseudo) vectors — angular momentum, torque, angular velocity, magnetic field — do not reverse, because each is a cross product of two polar vectors, so its two sign flips cancel. The one vector that survives the sign change is therefore the axial one.
Formula A polar vector transforms as V⃗ → −V⃗; a pseudovector built as W⃗ = U⃗ × V⃗ transforms as (−U⃗) × (−V⃗) = +U⃗ × V⃗ two minus signs cancel. Key case: angular momentum L⃗ = r⃗ × p⃗.
Solution
1. Under r⃗ → −r⃗, differentiate: velocity v⃗ = dr⃗/dt → −v⃗, and momentum p⃗ = mv⃗ → −p⃗. Both flip.
2. Force F⃗ = dp⃗/dt → −F⃗ and acceleration a⃗ → −a⃗. All of these are polar — they reverse sign.
3. Angular momentum: L⃗ = r⃗ × p⃗ → (−r⃗) × (−p⃗) = (−1)(−1)(r⃗ × p⃗) = +L⃗.The product of the two reversals is +1, so L⃗ is left unchanged — it is an axial vector.
4. Compare the candidates: velocity, momentum and force each flip; only angular momentum is invariant. Hence angular momentum is the vector that does not flip.
 quantity          type     under r -> -r
 position r        polar    -> -r       flips
 velocity v        polar    -> -v       flips
 momentum p        polar    -> -p       flips
 force F           polar    -> -F       flips
 ang. mom L = rxp  axial    -> +L       NO flip   <-- answer
⚡ JEE Trick One-line test: any vector you can write as (polar) × (polar) is axial and immune to parity — L⃗ = r⃗×p⃗, τ⃗ = r⃗×F⃗, ω⃗, and B⃗. The trap is to look at L⃗ = r⃗ × p⃗, spot the r⃗ inside, and assume “it contains r⃗, so it flips.” It does not: both factors flip, and the two signs cancel. Count sign reversals, not appearances of r⃗.
Answer: (d) Angular momentum — the only axial (pseudo)vector listed; L⃗ = r⃗×p⃗ gains two sign reversals that cancel, so it is unchanged under r⃗ → −r⃗.
2Two particles at equal distance from the origin, A⃗ = 2î + 3nĵ + 2k̂ and B⃗ = 2î − 2ĵ + 4pk̂; both vectors at right angles — find n⁻¹ (JEE Main 2025, Level-4)Dot product + equal magnitudesJEE MAIN 2025: Two particles are located at equal distance from origin. The position vectors🟢 Exactn⁻¹ = 3
Concept Two independent conditions are given for the same pair of vectors, and both must hold at once. “Equal distance from the origin” means the two position vectors have equal magnitude, |A⃗| = |B⃗|; “at right angles” means their dot product is zero. Solving the magnitude condition gives a square relation between n and p that carries a ± sign — and only one of the two sign branches is compatible with perpendicularity. The final ask is n⁻¹, the reciprocal, not n itself.
Formula |V⃗|² = Vx² + Vy² + Vz² and A⃗·B⃗ = AxBx + AyBy + AzBz. Given A⃗ = 2î + 3n ĵ + 2k̂, B⃗ = 2î − 2ĵ + 4p k̂.
Solution
1. Equal magnitudes: |A⃗|² = 4 + 9n² + 4 = 8 + 9n²; |B⃗|² = 4 + 4 + 16p² = 8 + 16p². Equate ⇒ 9n² = 16p² ⇒ 4p = ±3n.Squaring loses the sign, so keep both branches until one is ruled out.
2. Perpendicular: A⃗·B⃗ = (2)(2) + (3n)(−2) + (2)(4p) = 4 − 6n + 8p = 0 ⇒ 4p = 3n − 2.
3. Branch 4p = +3n: then 3n = 3n − 2 ⇒ 0 = −2, impossible. Reject.
4. Branch 4p = −3n: then −3n = 3n − 2 ⇒ 6n = 2 ⇒ n = 1/3, giving p = −1/4.
5. Check: |A⃗|² = 8 + 9(1/9) = 9, |B⃗|² = 8 + 16(1/16) = 9 ✓; A⃗·B⃗ = 4 − 2 − 2 = 0 ✓.
6. Required quantity: n⁻¹ = 1/n = 3.
 |A|^2 = 8 + 9n^2 ;  |B|^2 = 8 + 16p^2  =>  9n^2 = 16p^2  =>  4p = +/- 3n
 A.B   = 4 - 6n + 8p = 0                =>  4p = 3n - 2
   branch 4p = +3n :  3n = 3n - 2   (no solution)
   branch 4p = -3n : -3n = 3n - 2   =>  n = 1/3 ,  p = -1/4
 check: |A|^2 = |B|^2 = 9 ,  A.B = 0
 n^-1 = 1/n = 3       <-- answer
⚡ JEE Trick The magnitude condition delivers 4p = ±3n; students keep only the + branch, hit 0 = −2, and think the problem is broken. Always carry both roots of a square and let the second condition pick the valid one — here perpendicularity forces the negative branch. Second trap: the answer wanted is n⁻¹ = 3, not n = 1/3 — read the target of the question before boxing your value.
Answer: n⁻¹ = 3 (from n = 1/3, p = −1/4, which satisfy both |A⃗| = |B⃗| and A⃗·B⃗ = 0).
3Resultant of A⃗ and B⃗ is perpendicular to A⃗ and its magnitude is half that of B⃗ — the angle between A⃗ and B⃗ is ___° (JEE Main 2024, Level-4)Resultant perpendicular to a componentThe resultant of two vectors A and B is perpendicular to A and its magnitude half that of B — the angle🟢 Exact150°
Concept The resultant R⃗ = A⃗ + B⃗ is stated to be perpendicular to A⃗ (one of the components, not the other), and its length is half of B⃗. Perpendicularity is cleanest as a dot product set to zero; the magnitude condition is cleanest after squaring. Together they fix cosθ — and because the along-A⃗ part of B⃗ must exactly cancel A⃗, that cosine comes out negative, so the angle is obtuse.
Formula R⃗ = A⃗ + B⃗; perpendicular ⇒ A⃗·R⃗ = 0; |A⃗+B⃗|² = A² + B² + 2A⃗·B⃗, with A⃗·B⃗ = AB cosθ. Given |R⃗| = ½|B⃗|.
Solution
1. Perpendicular condition: A⃗·(A⃗ + B⃗) = 0 ⇒ A² + A⃗·B⃗ = 0 ⇒ A⃗·B⃗ = −A².
2. Write A⃗·B⃗ = AB cosθ: so AB cosθ = −A² ⇒ B cosθ = −A. …(i)The negative sign already signals θ > 90°.
3. Magnitude: |R⃗|² = A² + B² + 2A⃗·B⃗ = A² + B² − 2A² = B² − A².
4. Impose |R⃗| = B/2 ⇒ B²/4 = B² − A² ⇒ A² = 3B²/4 ⇒ A = (√3/2) B.
5. Substitute in (i): cosθ = −A/B = −(√3/2) ⇒ θ = 150°.
 R = A + B ,   R _|_ A
 A.(A+B) = 0  =>  A^2 + AB cos t = 0  =>  B cos t = -A     ...(i)
 |R|^2 = A^2 + B^2 + 2 A.B = B^2 - A^2
 |R| = B/2    =>  B^2/4 = B^2 - A^2  =>  A = (√3/2) B
 (i):  cos t = -A/B = -√3/2   =>   t = 150 deg    <-- answer
⚡ JEE Trick Read carefully — R⃗ is perpendicular to A⃗, not to B⃗; swapping them changes the answer. Geometric shortcut: if the resultant is perpendicular to a component of magnitude A while the other component is B, then sin(φ) relations give |R| = √(B²−A²); setting that to B/2 lands A = (√3/2)B instantly. The obtuse angle is not a trap once you see B cosθ = −A must be negative for B⃗’s projection to cancel A⃗.
Answer: θ = 150° (with A = (√3/2)B; the resultant then sits perpendicular to A⃗ with length B/2).
4a⃗ and b⃗ make an angle cos⁻¹(5/9); given |a⃗+b⃗| = √2 |a⃗−b⃗| for |a⃗| = n|b⃗| — the integer value of n (JEE Main 2024, Level-4)Magnitude of sum / difference#jeemain2024 If a and b makes an angle cos-1(5/9) with each other, then |a+b| = √2 |a-b|🟢 Exactn = 3
Concept The condition |a⃗+b⃗| = √2 |a⃗−b⃗| is a relation between the lengths of the sum and difference of two vectors. Squaring both sides converts every magnitude into a dot product and pulls in the known angle through a⃗·b⃗ = ab cosθ with cosθ = 5/9. Writing a = n b turns the whole thing into a quadratic in n, whose two roots are reciprocals; the problem asks for the integer one.
Formula |a⃗±b⃗|² = a² + b² ± 2ab cosθ, with a = |a⃗|, b = |b⃗|, cosθ = 5/9, and |a⃗| = n|b⃗|.
Solution
1. Square the given: |a⃗+b⃗|² = 2|a⃗−b⃗|² (√2)² = 2 — don’t leave the √2 unsquared.
2. Expand: a² + b² + 2ab cosθ = 2(a² + b² − 2ab cosθ).
3. Collect: 0 = a² + b² − 6ab cosθ ⇒ a² + b² = 6ab cosθ.
4. Insert cosθ = 5/9: a² + b² = 6ab(5/9) = (10/3)ab.
5. Put a = n b and divide by b²: n² + 1 = (10/3)n ⇒ 3n² − 10n + 3 = 0.
6. Solve: n = (10 ± √(100−36))/6 = (10 ± 8)/6 = 3 or 1/3. Integer ⇒ n = 3.
 |a+b|^2 = 2|a-b|^2 ,   c = cos t = 5/9
 a^2 + b^2 + 2ab c = 2(a^2 + b^2 - 2ab c)
 => a^2 + b^2 - 6ab c = 0
 => a^2 + b^2 = (10/3) ab      ;  a = n b
 3n^2 - 10n + 3 = 0  =>  n = (10 +/- 8)/6 = 3 or 1/3
 integer n = 3        <-- answer
⚡ JEE Trick The quadratic 3n²−10n+3 = 0 factors as (n−3)(3n−1), so its roots 3 and 1/3 are reciprocals — they just swap which vector is the longer one; the geometry is identical. The examiner asks for the integer to force a unique answer, so n = 3. Two classic slips: forgetting (√2)² = 2 (leaving a stray √2), and dropping the cosθ factor so 6ab cosθ becomes 6ab.
Answer: n = 3 (the reciprocal root 1/3 also satisfies the condition but is not an integer).
5For A⃗ = (−xî − 6ĵ − 2k̂), B⃗ = (−î + 4ĵ + 3k̂), C⃗ = (−8î − ĵ + 3k̂), if A⃗·(B⃗×C⃗) = 0 then x = ___ (JEE Main 2024, Level-4)Scalar triple product / coplanarityFor three vector A(-xi-6j-2k), B=(-i+4j+3k) and C=(-8i-j+3k). if A.(B x C)=0. then the value of x is🟢 Exactx = 4
Concept The scalar triple product A⃗·(B⃗×C⃗) equals the determinant whose rows are the three vectors’ components. Setting it to zero is exactly the coplanarity condition — the three vectors lie in one plane, so their box (parallelepiped) has zero volume. There is no need to compute B⃗×C⃗ on its own; one 3×3 determinant, expanded along the row containing the unknown x, gives a linear equation for x.
Formula A⃗·(B⃗×C⃗) = det[A⃗; B⃗; C⃗]; cofactor signs along the top row are + − +. Given A⃗ = (−x, −6, −2), B⃗ = (−1, 4, 3), C⃗ = (−8, −1, 3).
Solution
1. Coplanarity: the determinant of the matrix with rows A⃗, B⃗, C⃗ must vanish.
2. Expand along the first row: det = (−x)[(4)(3) − (3)(−1)] − (−6)[(−1)(3) − (3)(−8)] + (−2)[(−1)(−1) − (4)(−8)].
3. First minor: 12 − (−3) = 15 ⇒ term = −x·15 = −15x.
4. Second minor: −3 − (−24) = 21 ⇒ term = −(−6)(21) = +126.The cofactor sign (−) flips the −6, giving +6×21 — a double negative students often drop.
5. Third minor: 1 − (−32) = 33 ⇒ term = (−2)(33) = −66.
6. Sum: −15x + 126 − 66 = −15x + 60 = 0 ⇒ x = 4.
 | -x  -6  -2 |
 | -1   4   3 |  = 0     (A, B, C coplanar)
 | -8  -1   3 |
 = -x(12 - (-3)) + 6(-3 - (-24)) - 2(1 - (-32))
 = -x(15)      + 6(21)         - 2(33)
 = -15x + 126 - 66  =  -15x + 60
 -15x + 60 = 0   =>   x = 4      <-- answer
⚡ JEE Trick A⃗·(B⃗×C⃗) = 0 means “coplanar” — expand the single determinant along the row holding x and you never build B⃗×C⃗ separately. The trap is the middle cofactor: the top-row sign pattern is + − +, so the −6 entry becomes −(−6)(…) = +6(…); forget that flip and you get −15x − 66 and a wrong x. Every bracket here is positive after cleanup — a quick sanity flag.
Answer: x = 4 (makes A⃗, B⃗, C⃗ coplanar, so the scalar triple product vanishes).
6If P⃗ = 3î + √3ĵ + 2k̂ and Q⃗ = 4î + √3ĵ + 2.5k̂, the unit vector along P⃗×Q⃗ is (1/x)(√3î + ĵ − 2√3k̂) — find x (JEE Main 2023, Level-4)Cross product + unit vector#jeemain2023 If P = 3i + √3j + 2k and Q = 4i + √3j + 2.5k then, the unit vector in the direction of P×Q🟢 Exactx = 4
Concept The vector P⃗×Q⃗ is perpendicular to both P⃗ and Q⃗; the unit vector along it is P⃗×Q⃗ divided by its own magnitude. The question hands you that unit vector as (1/x)(√3î + ĵ − 2√3k̂), so x is simply the length of the vector (√3, 1, −2√3). You compute P⃗×Q⃗ by the determinant rule, factor out the common scalar so the direction matches the printed form, then read off x as the magnitude — the scalar prefactor itself never matters.
Formula P⃗×Q⃗ = (PyQz − PzQy)î + (PzQx − PxQz)ĵ + (PxQy − PyQx)k̂; unit vector = (P⃗×Q⃗)/|P⃗×Q⃗|. Given P⃗ = (3, √3, 2), Q⃗ = (4, √3, 2.5).
Solution
1. î-component: PyQz − PzQy = (√3)(2.5) − (2)(√3) = 2.5√3 − 2√3 = 0.5√3.
2. ĵ-component: PzQx − PxQz = (2)(4) − (3)(2.5) = 8 − 7.5 = 0.5.Order matters: it is PzQx − PxQz; reversing it flips the sign.
3. k̂-component: PxQy − PyQx = (3)(√3) − (√3)(4) = 3√3 − 4√3 = −√3.
4. So P⃗×Q⃗ = 0.5√3 î + 0.5 ĵ − √3 k̂ = 0.5(√3î + ĵ − 2√3k̂).Factor 0.5 to expose the direction printed in the answer.
5. Magnitude of (√3, 1, −2√3): |⋅| = √(3 + 1 + 12) = √16 = 4.
6. Unit vector = (√3î + ĵ − 2√3k̂)/4, so comparing with (1/x)(⋅) gives x = 4.
 P x Q :
   i : √3(2.5) - 2(√3)  = 0.5√3
   j : 2(4)   - 3(2.5)  = 0.5
   k : 3(√3)  - √3(4)   = -√3
 P x Q = 0.5(√3 i + j - 2√3 k)
 |(√3, 1, -2√3)| = √(3 + 1 + 12) = √16 = 4
 unit = (1/4)(√3 i + j - 2√3 k)   =>   x = 4     <-- answer
⚡ JEE Trick Ignore the 0.5 prefactor entirely — the printed answer already fixes the direction (√3, 1, −2√3), so x is just its magnitude, √(3+1+12) = 4. Two traps: the middle (ĵ) cofactor carries a built-in minus, PzQx − PxQz — write it backwards and the whole direction inverts; and the decimal 2.5 invites slips (3×2.5 = 7.5, not 6.5).
Answer: x = 4 (P⃗×Q⃗ = 0.5(√3î + ĵ − 2√3k̂), whose direction vector has magnitude 4).
7A force −Pk̂ acts at the origin; the torque about the point (2, −3) is P(aî + bĵ). If a/b = x/2, find x (JEE Main 2023, Level-4)Torque about a pointA force of -Fk acts on O, the origin of the co-ordinate system. The torque about the point (1, ...)🟡 Similarx = 3
Concept Torque is always taken about a chosen reference point, and the moment arm is the vector drawn from that reference point to the point where the force acts — not the other way round, and not from the origin unless the origin is the reference. Here the force acts at the origin while the reference point is (2, −3), so the moment arm points from (2, −3) back to O. The force is purely along −k̂, so crossing an in-plane arm with a z-force lands the result entirely in the xy-plane — which is why the printed answer has the form P(aî + bĵ) with no k̂ term.
Formula τ⃗ = r⃗ × F⃗, with r⃗ = r⃗application − r⃗reference (units: N·m = m × N). Unit-vector rules needed: î × k̂ = −ĵ and ĵ × k̂ = +î. Given: F⃗ = −P k̂ applied at O = (0, 0, 0); reference point A = (2, −3, 0); the answer is quoted as τ⃗ = P(aî + bĵ) with a/b = x/2.
Solution
1. Write the two position vectors: point of application r⃗O = 0î + 0ĵ, reference r⃗A = 2î − 3ĵ.
2. Moment arm: r⃗ = r⃗O − r⃗A = (0 − 2)î + (0 − (−3))ĵ = −2î + 3ĵ.Subtract the reference from the application point. Getting this backwards flips τ⃗ — though here the ratio a/b happens to survive the sign flip; see the trick.
3. Set up the cross product: τ⃗ = (−2î + 3ĵ) × (−P k̂).
4. Expand term by term. First term: (−2î) × (−P k̂) = (−2)(−P)(î × k̂) = 2P(−ĵ) = −2P ĵ.î × k̂ = −ĵ — this is the anti-cyclic one, so it carries the minus sign.
5. Second term: (3ĵ) × (−P k̂) = (3)(−P)(ĵ × k̂) = −3P(î) = −3P î.ĵ × k̂ = +î is cyclic, so no extra sign.
6. Add them: τ⃗ = −3P î − 2P ĵ = P(−3î − 2ĵ). Comparing with P(aî + bĵ): a = −3, b = −2.
7. Form the ratio: a/b = (−3)/(−2) = 3/2.Both components are negative, so the two minus signs cancel and the ratio comes out positive.
8. Match to the quoted form: a/b = x/2 ⇒ x/2 = 3/2 ⇒ x = 3.

⚡ JEE Trick When the question asks only for a ratio of the torque components, the overall sign of the moment arm cancels — so even a student who wrongly takes r⃗ = A − O = 2î − 3ĵ gets τ⃗ = P(3î + 2ĵ) and still lands on a/b = 3/2. Do not let that luck teach the wrong rule: for any question asking for τ⃗ itself, the direction matters. Faster route: for an in-plane arm (rx, ry) crossed with a pure −P k̂, the result is always P(−ryî + rxĵ) — a 90° rotation of the arm scaled by P. Here (−2, 3) → P(−3, −2) in one line, no determinant needed.
Answer: x = 3 (with a = −3, b = −2, giving a/b = 3/2).
8A particle of mass m moves in the xy-plane with velocity at (x, y) given by v⃗ = α(yx̂ + 2xŷ), α a non-zero constant — find the force F⃗ on the particle (JEE Advanced 2023, Level-6)Velocity field → accelerationjee2023 / A particle of mass m is moving in the xy-plane such that its velocity at a point (x, y) is🟢 ExactaF⃗ = 2mα²(xx̂ + yŷ)
Concept The velocity is given as a field — it depends on where the particle is (x, y), not explicitly on time. So acceleration is not zero even though α is constant: as the particle moves, x and y change, and v⃗ changes with them. The chain rule converts the position-dependence into a time-derivative, using dx/dt = vx and dy/dt = vy. This cross-coupling (vx depends on y, vy on x) is what makes the force come out neatly proportional to r⃗.
Formula F⃗ = m a⃗, a⃗ = dv⃗/dt, with the chain rule dvx/dt = (∂vx/∂y)(dy/dt) = (∂vx/∂y)vy. Given v⃗ = α(y x̂ + 2x ŷ), so vx = αy, vy = 2αx.
Solution
1. Read off components: vx = αy and vy = 2αx.
2. ax = dvx/dt = α (dy/dt) = α vy = α(2αx) = 2α²x.dy/dt is just vy; substitute it, do not treat y as constant.
3. ay = dvy/dt = 2α (dx/dt) = 2α vx = 2α(αy) = 2α²y.
4. Assemble: a⃗ = 2α²(x x̂ + y ŷ) = 2α² r⃗.
5. Force: F⃗ = m a⃗ = 2mα²(x x̂ + y ŷ) — a central force pointing radially outward (along +r⃗), growing linearly with distance.
 v = a(y x^ + 2x y^)   =>  vx = a y ,  vy = 2a x
 ax = d(vx)/dt = a dy/dt = a vy = a(2ax) = 2a^2 x
 ay = d(vy)/dt = 2a dx/dt = 2a vx = 2a(ay) = 2a^2 y
 F = m a_vec = 2 m a^2 (x x^ + y y^)     <-- answer (a)
 (a written for alpha;  F points along +r : repulsive central field)
⚡ JEE Trick Velocity depends on position, not time, so a⃗ = dv⃗/dt must go through the chain rule: dvx/dt = (∂vx/∂y) vy. The trap is to declare a⃗ = 0 because “α is a constant,” or to differentiate x, y as if fixed. The cross-coupling — vx carries y and vy carries x — is exactly what folds back to give F⃗ ∝ r⃗. Note the coefficient is 2α² (not α²), because vy already carries a factor 2.
Answer: (a) F⃗ = 2mα²(x x̂ + y ŷ) — a repulsive central force, linear in r⃗.
