★ The one habitAlmost every question reduces to two moves: pick the right form for the data you are handed, or reduce a given line to Ax + By + C = 0 and read off slope = −A/B, x-intercept = −C/A, y-intercept = −C/B, and distance from origin = |C|/√(A²+B²). 💡 Which bisector is whichFirst make both constants positive. Bisector containing the origin = the one with the + sign. For the acute-angle bisector: if a₁a₂ + b₁b₂ < 0 take +; if a₁a₂ + b₁b₂ > 0 take − (the other sign then gives the obtuse bisector). To pick the bisector through a chosen point P, arrange both constants with the same sign and choose the sign so that both expressions a₁x₁+b₁y₁+c₁ and a₂x₁+b₂y₁+c₂ have the same sign as P.
💡 Fast reductions & checksA line parallel to the x-axis has slope 0; parallel to the y-axis has undefined slope (x = const). Right-angle vertex of an isosceles right triangle ⇒ the two equal sides make 45° with the hypotenuse — use tan45° = 1 in the angle formula. The image of ax + by + c = 0 in the x-axis is ax − by + c = 0; in the y-axis −ax + by + c = 0; in y = x it is ay + bx + c = 0.
⚠ Four slips that cost marks(1) In the normal form keep p ≥ 0 and choose cosα, sinα so the constant is positive. (2) The perpendicular to ax+by+c=0 is bx − ay + λ (swap coefficients AND flip one sign) — not −ax+by. (3) Perpendicular distance needs the modulus: |ax₁+by₁+c|/√(a²+b²). (4) For the image use the factor −2(ax₁+by₁+c)/(a²+b²); the foot uses −1× it. Mixing the two is the classic error.
L-1

Inclination, Slope, Intercepts & Equations of the Axes

Inclination of a line

  • The inclination θ of a line is the angle it makes with the positive direction of the x-axis, measured anticlockwise. Anticlockwise is taken positive, clockwise negative (so a line sloping down to the right has inclination like −30°, i.e. 150°).
  • For a line parallel to the x-axis, θ = 0°; for a line parallel to the y-axis, θ = 90°.

Slope (gradient)

  • Slope m measures steepness and direction: as you move along the line, m = (change in y)/(change in x). It is the trigonometric tangent of the inclination.
slope of a line through (x₁,y₁) and (x₂,y₂)m = (y₂ − y₁)/(x₂ − x₁) = tanθ · parallel to x-axis ⇒ m = 0 · parallel to y-axis ⇒ m undefined

Intercepts on the axes

  • If a line cuts the x-axis at A and the y-axis at B, then OA is the x-intercept and OB the y-intercept. The x-intercept is the x-coordinate of the point where the line meets the x-axis (there y = 0); the y-intercept is the y-coordinate where it meets the y-axis (there x = 0).

Equations of the axes & lines parallel to them

the two axes and lines parallel to themx-axis: y = 0 · y-axis: x = 0 · parallel to x-axis: y = a · parallel to y-axis: x = a
💡 Reading the sign of the slopem > 0 ⇒ line rises left-to-right (acute inclination); m < 0 ⇒ line falls (obtuse inclination); m = 0 ⇒ horizontal; m undefined ⇒ vertical. A line through the origin bisecting the first quadrant (θ = 45°) has m = tan45° = 1.

Book Example · L-1
Find the slope of the line passing through (2, 3) and (4, 5).
m = (y₂ − y₁)/(x₂ − x₁) = (5 − 3)/(4 − 2) = 2/2 = 1.

L-2

Equation of a Line — Two-Point, Point-Slope, Slope-Intercept & Intercept Forms

These are the four standard templates for writing a line's equation. Pick the one that matches the data you are given; all of them collapse to Ax + By + C = 0.

Two-point form

  • Given two points A(x₁,y₁) and B(x₂,y₂) on the line, any point P(x,y) is collinear with them, so mAB = mAP.
from m_AB = m_AP(y₂ − y₁)/(x₂ − x₁) = (y − y₁)/(x − x₁) ⇒ y − y₁ = [(y₂ − y₁)/(x₂ − x₁)](x − x₁)

Point-slope (slope-point) form

  • Given the slope m and one point (x₁,y₁) on the line — the two-point form with the slope already named.
slope m through (x₁,y₁)y − y₁ = m(x − x₁)

Slope-intercept form

  • Given the slope m and the y-intercept c. Starting from y − y₁ = m(x − x₁) with the point (0,c): y − c = m(x − 0).
slope m, y-intercept cy = mx + c

Double-intercept form

  • Given the x-intercept a and y-intercept b, the line passes through (a,0) and (0,b). The two-point form reduces neatly:
x-intercept a, y-intercept bx/a + y/b = 1 (derived from y − 0 = [(b − 0)/(0 − a)](x − a))
💡 Choosing a form at a glanceTwo points → two-point form. Slope + a point → point-slope. Slope + y-intercept → slope-intercept. Both intercepts (or anything about the triangle the line cuts off with the axes) → double-intercept. If a line cuts equal intercepts a = b ⇒ x + y = a (slope −1); equal in magnitude, opposite sign ⇒ x − y = a (slope +1).
Worked examples from the module
Worked example · L-2 (two-point form)
Find the equation of the line through (2, 3) and (4, 5).
Slope m = (5 − 3)/(4 − 2) = 1; then y − 3 = 1·(x − 2) ⇒ y − 3 = x − 2.
y = x + 1 (i.e. x − y + 1 = 0)
Worked example · L-2 (double-intercept form)
Find the equation of the line whose x-intercept is 4 and y-intercept is 3.
x/a + y/b = 1 with a = 4, b = 3 ⇒ x/4 + y/3 = 1; multiply by 12: 3x + 4y = 12.
3x + 4y = 12
L-3

Normal, Parametric & General Forms; Point of Intersection & Concurrency

Normal (perpendicular) form

  • Describe a line by the length p of the perpendicular from the origin and the angle α that this perpendicular makes with the +x-axis. Using the intercepts p secα and p cosecα in the double-intercept form gives:
perpendicular p from O, at angle αx cosα + y sinα = p (keep p ≥ 0)

Parametric / distance / symmetric form

  • A line through Q(x₁,y₁) with inclination θ: for a point P at signed distance r from Q, QN = x − x₁ = r cosθ and PN = y − y₁ = r sinθ.
through (x₁,y₁), inclination θ, signed distance r(x − x₁)/cosθ = (y − y₁)/sinθ = r ⇒ x = x₁ + r cosθ, y = y₁ + r sinθ
💡 Sign of rr > 0 gives the point on one side of Q (in the direction θ); r < 0 the point on the other side. To get both points a fixed distance d from Q, use r = ±d.

Reducing the general equation Ax + By + C = 0

reduce toresult
slope-intercepty = (−A/B)x + (−C/B): slope = −A/B = −(coeff of x)/(coeff of y), y-int = −C/B
interceptx/(−C/A) + y/(−C/B) = 1: x-int = −C/A, y-int = −C/B
normaldivide by ±√(A²+B²) so the constant is positive; then p = |C|/√(A²+B²)

Point of intersection & concurrency

  • Two non-parallel lines a₁x+b₁y+c₁=0 and a₂x+b₂y+c₂=0 meet where, by cross-multiplication, x = (b₁c₂ − b₂c₁)/(a₁b₂ − a₂b₁), y = (c₁a₂ − c₂a₁)/(a₁b₂ − a₂b₁) — well-defined because a₁b₂ − a₂b₁ ≠ 0 for non-parallel lines.
  • Three lines are concurrent when the intersection of two of them lies on the third:
concurrency conditiondet[[a₁,b₁,c₁],[a₂,b₂,c₂],[a₃,b₃,c₃]] = 0
Worked examples from the module
Book Example · L-3 (normal form)
Find the equation of a straight line on which the length of the perpendicular from the origin is 4 units and the line makes an angle of 120° with the positive direction of the x-axis.
The line's inclination is 120°, so its perpendicular makes α = 120° − 90° = 30° with the +x-axis; p = 4.
x cosα + y sinα = p ⇒ x cos30° + y sin30° = 4 ⇒ x·(√3/2) + y·(1/2) = 4.
√3 x + y = 8
Book Example · L-3 (parametric form)
The slope of a straight line through A(3, 2) is 3/4. Find the coordinates of the points on the line that are 5 units away from A.
tanθ = 3/4 ⇒ sinθ = 3/5, cosθ = 4/5. Parametric: (x − 3)/cosθ = (y − 2)/sinθ = r = ±5.
x = 3 ± 5·(4/5) = 3 ± 4 = 7 or −1; y = 2 ± 5·(3/5) = 2 ± 3 = 5 or −1.
(7, 5) and (−1, −1)

Angle Between Lines, Parallel/Perpendicular, Distance, Foot & Image

Angle between two lines

  • If lines L₁, L₂ have slopes m₁, m₂, the acute angle φ between them satisfies (from φ = θ₁ − θ₂ and the tan-difference formula):
angle between lines of slopes m₁, m₂tanφ = |(m₁ − m₂)/(1 + m₁m₂)| · if one line is vertical (m₁ undefined): tanφ = |1/m₂|

Parallel & perpendicular conditions

for a₁x+b₁y+c₁=0 and a₂x+b₂y+c₂=0parallel: a₁/a₂ = b₁/b₂ ≠ c₁/c₂ · coincident: a₁/a₂ = b₁/b₂ = c₁/c₂ · perpendicular: a₁a₂ + b₁b₂ = 0
building a parallel / perpendicular line to ax + by + c = 0parallel: ax + by + λ = 0 · perpendicular: bx − ay + λ = 0 (swap a,b and flip one sign); fix λ with a point

A line through a point at a given angle to a line

through (x₁,y₁), at angle α to the line of slope my − y₁ = [(m ± tanα)/(1 ∓ m tanα)](x − x₁) (two lines, one on each side)

Distances

perpendicular distance of (x₁,y₁) from ax + by + c = 0d = |a x₁ + b y₁ + c| / √(a² + b²)
distance between the parallel lines ax+by+c₁=0 and ax+by+c₂=0d = |c₁ − c₂| / √(a² + b²)

Position of a point, foot of perpendicular & image

  • Position: for two points P, Q, the expressions (ax+by+c) evaluated at each have the same sign ⇒ same side of the line; opposite signs ⇒ opposite sides.
foot of ⊥ M(x,y) from P(x₁,y₁) on ax + by + c = 0(x − x₁)/a = (y − y₁)/b = −(a x₁ + b y₁ + c)/(a² + b²)
image (reflection) Q(x,y) of P(x₁,y₁) in ax + by + c = 0(x − x₁)/a = (y − y₁)/b = −2(a x₁ + b y₁ + c)/(a² + b²)
reflection of a point in the special linesin x-axis: (α,β) → (α, −β) · in y-axis: (α,β) → (−α, β) · in y = x: (α,β) → (β, α)

Book Example · L-4 (line at a given angle)
Find the equation of a line passing through (1, 2) and making an angle of 45° with the line 2x + 3y = 10.
Slope of 2x + 3y = 10 is −2/3. Let the required slope be m: tan45° = 1 = |(m + 2/3)/(1 − 2m/3)| = |(3m + 2)/(3 − 2m)|.
3m + 2 = ±(3 − 2m): either 3m + 2 = 3 − 2m ⇒ m = 1/5, or 3m + 2 = −(3 − 2m) ⇒ m = −5.
Lines through (1,2): y − 2 = (1/5)(x − 1) ⇒ 5y − x = 9; y − 2 = −5(x − 1) ⇒ 5x + y = 7.
5x + y = 7 and 5y − x = 9
Book Example · L-4 (angle between lines)
Find the tangent of the angle between the straight lines x − y + 5 = 0 and x + 2y = 0.
Slopes: m₁ = 1, m₂ = −1/2. tanθ = |(m₁ − m₂)/(1 + m₁m₂)| = |(1 + 1/2)/(1 − 1/2)| = |(3/2)/(1/2)|.
tanθ = 3
Book Example · L-4 (parallel & perpendicular lines)
(a) Find the line parallel to 3x + 2y + 4 = 0 through (1, 1). (b) Find the line perpendicular to 2x − y = 7 through the intersection of 3x + 4y = 8 with the y-axis.
(a) Parallel: 3x + 2y + c = 0; through (1,1): 3 + 2 + c = 0 ⇒ c = −5 ⇒ 3x + 2y = 5.
(b) 3x + 4y = 8 meets x = 0 at (0, 2). Perpendicular to 2x − y = 7 is x + 2y = c; through (0,2): 0 + 4 = c ⇒ c = 4.
(a) 3x + 2y = 5 (b) x + 2y = 4
Book Example · L-4 (isosceles right triangle)
Find the equations of the equal sides of an isosceles right-angled triangle whose hypotenuse is 3x + 4y = 4 and whose opposite (right-angle) vertex is (2, 2).
The two equal sides make 45° with the hypotenuse. Slope of 3x + 4y − 4 = 0 is m₁ = −3/4; tan45° = 1 = |(m + 3/4)/(1 − 3m/4)| = |(4m + 3)/(4 − 3m)|.
4m + 3 = ±(4 − 3m): m = 1/7 or m = −7. Lines through (2,2): y − 2 = (1/7)(x − 2) ⇒ 7y − x − 12 = 0; y − 2 = −7(x − 2) ⇒ 7x + y = 16.
7y − x − 12 = 0 and 7x + y = 16
Book Example · L-4 (position & distance)
(a) Are (3, 4) and (2, −6) on the same or opposite sides of 3x − 4y = 8? (b) Find the point on the y-axis whose perpendicular distance from 4x − 3y − 12 = 0 is 3.
(a) L = 3x − 4y − 8: L(3,4) = 9 − 16 − 8 = −15; L(2,−6) = 6 + 24 − 8 = 22. Opposite signs ⇒ opposite sides.
(b) P(0, k): |4·0 − 3k − 12|/√(4² + (−3)²) = 3 ⇒ |3k + 12| = 15 ⇒ 3k + 12 = ±15 ⇒ k = 1 or k = −9.
(a) opposite sides (b) (0, 1) and (0, −9)
Book Example · L-4 (image in a line mirror)
Find the image of the point (4, −13) with respect to the line mirror 5x + y + 6 = 0.
(x − 4)/5 = (y + 13)/1 = −2(5·4 − 13 + 6)/(5² + 1²) = −2(13)/26 = −1.
x − 4 = 5(−1) ⇒ x = −1; y + 13 = 1(−1) ⇒ y = −14.
Image = (−1, −14)

Family of Straight Lines & Area of a Parallelogram

Family of straight lines

  • Let L₁ ≡ a₁x + b₁y + c₁ = 0 and L₂ ≡ a₂x + b₂y + c₂ = 0. Every line through their point of intersection can be written as L₁ + λL₂ = 0 (λ ∈ ℝ), because that equation is satisfied at the intersection for any λ.
  • Conversely, any one-parameter family written as L₁ + λL₂ = 0 always passes through the fixed point L₁ = 0 ∩ L₂ = 0 — a powerful shortcut for "show the line passes through a fixed point" questions.
the family(a₁x + b₁y + c₁) + λ(a₂x + b₂y + c₂) = 0 ⇒ (a₁+λa₂)x + (b₁+λb₂)y + (c₁+λc₂) = 0; fix λ from the extra condition

Area of a parallelogram made by four lines

  • If the sides are a₁x+b₁y+c₁=0, a₁x+b₁y+d₁=0 (one pair) and a₂x+b₂y+c₂=0, a₂x+b₂y+d₂=0 (the other pair), the area is (product of the two perpendicular gaps)/sinθ, which simplifies to:
area of the parallelogramArea = |(c₁ − d₁)(c₂ − d₂)| / |a₁b₂ − a₂b₁| (= |(c₁ − d₁)(c₂ − d₂)| / |det[[a₁,b₁],[a₂,b₂]]|)

Book Example · L-5 (family of lines)
For L₁: 3x − 4y + 6 = 0 and L₂: x + y + 2 = 0, find the line through their intersection that (i) passes through (1, 2); (ii) is parallel to y = 2x + 3; (iii) has intercepts equal in magnitude but opposite in sign; (iv) is parallel to the x-axis; (v) is at distance √2 from the origin.
Family: 3x − 4y + 6 + λ(x + y + 2) = 0 ⇒ (3 + λ)x + (λ − 4)y + (6 + 2λ) = 0.
(i) through (1,2): (3+λ) + 2(λ−4) + (6+2λ) = 0 ⇒ 5λ + 1 = 0 ⇒ λ = −1/5 ⇒ 14x − 21y + 28 = 0 ⇒ 2x − 3y + 4 = 0.
(ii) slope = −(3+λ)/(λ−4) = 2 ⇒ −(3+λ) = 2(λ−4) ⇒ 5 = 3λ ⇒ λ = 5/3 ⇒ 14x − 7y + 28 = 0 ⇒ 2x − y + 4 = 0.
(iii) equal-and-opposite intercepts ⇒ slope 1 ⇒ −(3+λ)/(λ−4) = 1 ⇒ λ = 1/2 ⇒ (7/2)x − (7/2)y + 7 = 0 ⇒ x − y + 2 = 0.
(iv) parallel to x-axis ⇒ coeff of x = 0 ⇒ 3 + λ = 0 ⇒ λ = −3 ⇒ −7y = 0 ⇒ y = 0.
(v) |6 + 2λ|/√((3+λ)² + (λ−4)²) = √2 ⇒ (2λ+6)² = 2(2λ² − 2λ + 25) ⇒ 28λ = 14 ⇒ λ = 1/2 ⇒ x − y + 2 = 0.
(i) 2x − 3y + 4 = 0 (ii) 2x − y + 4 = 0 (iii) x − y + 2 = 0 (iv) y = 0 (v) x − y + 2 = 0

Angle Bisectors (Acute/Obtuse, Origin) & Centres by Slopes

Equations of the two angle bisectors

  • A bisector is the locus of points equidistant from the two lines, so setting the two perpendicular distances equal (with ±) gives both bisectors, which are perpendicular to each other.
bisectors of a₁x+b₁y+c₁=0 and a₂x+b₂y+c₂=0(a₁x + b₁y + c₁)/√(a₁²+b₁²) = ± (a₂x + b₂y + c₂)/√(a₂²+b₂²)

Picking the right bisector

  • Acute vs obtuse: make both constant terms positive, then compute a₁a₂ + b₁b₂. If it is < 0, the + sign gives the acute-angle bisector; if > 0, the − sign gives the acute-angle bisector (the other sign gives the obtuse one).
  • Bisector of the angle containing the origin: make both constants positive, then take the + sign.
  • Bisector of the angle containing a point P(x₁,y₁): arrange both constants to the same sign, check the signs of a₁x₁+b₁y₁+c₁ and a₂x₁+b₂y₁+c₂ — if they match, take the + sign, else −.

Circumcentre & orthocentre by slopes

  • Circumcentre O(x,y): perpendicular from O to each side bisects it, so (slope of O–midpoint) × (slope of that side) = −1. Solve any two such equations. Orthocentre: (slope of altitude) × (slope of opposite side) = −1.

Book Example · L-6 (both bisectors)
Find the equations of the bisectors of the angles between 3x − 4y + 7 = 0 and 12x + 5y − 2 = 0.
(3x − 4y + 7)/√(3² + 4²) = ±(12x + 5y − 2)/√(12² + 5²) ⇒ (3x − 4y + 7)/5 = ±(12x + 5y − 2)/13.
13(3x − 4y + 7) = ±5(12x + 5y − 2) ⇒ 39x − 52y + 91 = ±(60x + 25y − 10).
+ sign: 39x − 52y + 91 = 60x + 25y − 10 ⇒ 21x + 77y − 101 = 0; − sign: 39x − 52y + 91 = −60x − 25y + 10 ⇒ 99x − 27y + 81 = 0.
21x + 77y − 101 = 0 and 99x − 27y + 81 = 0
Book Example · L-6 (acute-angle bisector)
Find the equation of the bisector of the acute angle between 2x − y + 4 = 0 and x − 2y = 1.
Write them as 2x − y + 4 = 0 and −x + 2y + 1 = 0 (constants positive). Here a₁a₂ + b₁b₂ = (2)(−1) + (−1)(2) = −4 < 0, so the + sign gives the acute bisector.
(2x − y + 4)/√(1+4) = +(−x + 2y + 1)/√((−1)²+2²) ⇒ 2x − y + 4 = −x + 2y + 1 ⇒ 3x − 3y + 3 = 0.
x − y + 1 = 0
Book Example · L-6 (bisector containing the origin)
For 4x + 3y − 6 = 0 and 5x + 12y + 9 = 0, find the bisector of the angle that contains the origin.
Make constants positive: −4x − 3y + 6 = 0 and 5x + 12y + 9 = 0. The origin-containing bisector takes the + sign.
(−4x − 3y + 6)/√((−4)²+(−3)²) = +(5x + 12y + 9)/√(5²+12²) ⇒ 13(−4x − 3y + 6) = 5(5x + 12y + 9).
−52x − 39y + 78 = 25x + 60y + 45 ⇒ 77x + 99y − 33 = 0 ⇒ divide by 11.

Book Example · L-6 (circumcentre by slopes)
Find the circumcentre and circumradius of the triangle with vertices A(5, −1), B(−1, 5), C(6, 6).
Midpoints: D of BC = (5/2, 11/2), E of CA = (11/2, 5/2). Let O(α,β). OD ⊥ BC: ((β − 11/2)/(α − 5/2))·((6 − 5)/(6 + 1)) = −1 ⇒ 7α + β = 23.
OE ⊥ CA: ((β − 5/2)/(α − 11/2))·((−1 − 6)/(5 − 6)) = −1 ⇒ α + 7β = 23. Solving the two ⇒ α = β = 23/8.
R = OC = √((23/8 − 6)² + (23/8 − 6)²) = √(2·(25/8)²) = (25√2)/8.
Circumcentre = (23/8, 23/8), circumradius = (25√2)/8
