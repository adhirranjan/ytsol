1The indefinite integral of a function f(x) is represented as: ∫f(x)dx = F(x) + C (Level-1)Indefinite integral definitionIndefinite integrals: antiderivatives and +C · The Indefinite Integral or Anti-derivative🟢 Exactb∫ f(x) dx = F(x) + C
Concept The indefinite integral is nothing but differentiation run in reverse. F(x) is called an antiderivative of f(x) when its derivative gives back f(x), i.e. F′(x) = f(x). Because the derivative of any constant is zero, infinitely many functions share the same derivative, so the true answer is a whole family F(x) + C, not a single curve. The arbitrary constant C is exactly what makes the integral "indefinite" — no limits are supplied to fix its value.
Formula ∫f(x) dx = F(x) + C, where F′(x) = f(x) and C is an arbitrary constant. Test it by differentiating the right-hand side: d/dx[F(x) + C] = f(x) + 0 = f(x), which returns the integrand — proof that F(x)+C is the general antiderivative. The definite integral by contrast, ∫ₐᵇ f dx = F(b) − F(a), is a number and C cancels.
Solution
1. Read the symbol: ∫f(x) dx means "list every function whose derivative equals f(x)."The ∫ sign and the dx bracket the integrand; the task is to undo the derivative.
2. Name one such function F(x); by definition of antiderivative F′(x) = f(x).
3. Add a constant: d/dx[F(x) + C] = f(x) + 0 = f(x) for any C, so F(x) + C is also an antiderivative.Since the constant differentiates away, C is genuinely free — that is why the result is a family.
4. Why not just F(x)? Dropping C discards infinitely many valid answers — e.g. x²+3 and x²−7 both differentiate to 2x.
5. Worked example: ∫2x dx = x² + C; check d/dx(x² + C) = 2x ✓ — matches the integrand.
6. Hence the correct representation is ∫f(x) dx = F(x) + C with F′(x) = f(x).

 f(x)                integrand (given)               the derivative
 F(x)                one antiderivative, F'=f         area/accumulation

⚡ JEE Trick Read "∫ … dx" as "anti-derivative + C" and lock the pair differentiate ⇄ integrate. Trap 1: forgetting the + C on an indefinite integral costs marks even when the antiderivative is perfect. Trap 2: confusing this with a definite integral, which produces a number (no C) — the word "indefinite" signals no limits and hence the constant.
Answer: (b) ∫f(x) dx = F(x) + C, where F′(x) = f(x) and C is the arbitrary constant of integration.
2If electric current is the rate of flow of charge, which statement is correct? (i = dq/dt) (Level-2)Current = dq/dtElectric Current, An Explanation · Electric current worked example (I = Q/t)🟡 SimilarcI = dq/dt
Concept Electric current is defined as the rate of flow of charge past a point in a circuit. "Rate of" always means "derivative with respect to time," so current is the time-derivative of charge, i = dq/dt. The integral form is the inverse statement: if you know how the current varies in time, the total charge that has passed is the accumulated area under the i–t graph, i.e. q = ∫i dt. This derivative/integral pair is exactly the antiderivative idea of this lesson, dressed in physical units.
Formula i = dq/dt — i in amperes (A), q in coulombs (C), t in seconds (s); 1 A = 1 C s⁻¹. Inverting by integration: q = ∫ i dt + q₀, units A·s = C. The constant of integration q₀ is the charge already transferred at t = 0, so it is fixed by an initial condition, not by the integral itself. For the special case of constant current this collapses to q = i·t.
Solution
1. Translate the words into calculus: "current = rate of flow of charge" ⇒ i = dq/dt."Rate of flow of X" is the standard physics phrase for dX/dt — charge per unit time.
2. Check the units of this definition: dq/dt has units C ÷ s = C s⁻¹ = A. ✓This matches the SI unit of current, confirming the relation is dimensionally consistent.
3. Invert it by integrating both sides with respect to t: ∫i dt = ∫(dq/dt) dt = ∫dq = q + constant.Integration undoes differentiation — this is the fundamental theorem of calculus, the core of this lesson.
4. So q = ∫ i dt, with units A × s = C. ✓ Dimensionally consistent.
5. Special case — if i is constant at value I, it comes out of the integral: q = I∫dt = I·t (C).Assumption: i does not vary with time. Only then is q = it valid; otherwise the full integral is required.

⚡ JEE Trick Lock in the pair "differentiate q → get i; integrate i → get q." On a q–t graph the slope is the current; on an i–t graph the area is the charge. Trap: q = i·t is only valid for constant current — if the problem gives i as a function of t (e.g. i = 3t² A), you must integrate, and using q = it will be wrong.
Answer: i = dq/dt — current is the time-derivative of charge (A = C s⁻¹); equivalently q = ∫i dt.
3Integrate f(x) = 3x⁷ − 15x⁴ + 2 w.r.t. x (Level-3)Term-by-term power rulePolynomial integration — power rule · General indefinite integral (7x² + 5x⁻²) dx🟡 Similar3x⁸/8 − 3x⁵ + 2x + k
Concept A polynomial is a sum of independent power terms, and integration is a linear operation. That means two rules do all the work: the sum/difference rule lets you integrate term by term, and the constant-multiple rule lets each numerical coefficient ride outside its integral untouched. Each term then falls to the power rule. Only one constant of integration is needed at the very end, because the sum of several arbitrary constants is just one arbitrary constant.
Formula Power rule: ∫xⁿ dx = xn+1/(n+1) + C, valid for n ≠ −1. Differentiating x^(n+1)/(n+1) brings down (n+1), which cancels the denominator and drops the power back to n — so it really is the antiderivative. Linearity: ∫[a·f(x) ± b·g(x)]dx = a∫f dx ± b∫g dx. Also ∫k dx = kx + C (the n = 0 case, since k = k·x⁰).
Solution
1. Split the integral term by term using the sum/difference rule:∫(3x⁷ − 15x⁴ + 2)dx = ∫3x⁷dx − ∫15x⁴dx + ∫2 dx.
2. Pull each constant coefficient out front (constant-multiple rule): = 3∫x⁷dx − 15∫x⁴dx + 2∫x⁰dx.
3. First term, n = 7: ∫x⁷dx = x⁸/8, so 3∫x⁷dx = 3x⁸/8 = 3x⁸/8.n + 1 = 7 + 1 = 8, so raise the power to 8 and divide by 8.
4. Second term, n = 4: ∫x⁴dx = x⁵/5, so 15∫x⁴dx = 15x⁵/5 = 3x⁵.n + 1 = 5; then 15 ÷ 5 = 3 — the coefficient simplifies cleanly.
5. Third term, n = 0: ∫2 dx = 2·x¹/1 = 2x.A constant integrates to itself times x — the n = 0 case of the power rule.
6. Reassemble with the signs and add one constant: 3x⁸/8 − 3x⁵ + 2x + C.
7. Verify by differentiating the result — it must return the original integrand:d/dx(3x⁸/8) = 3·8x⁷/8 = 3x⁷ ✓; d/dx(−3x⁵) = −15x⁴ ✓; d/dx(2x) = 2 ✓; d/dx(C) = 0. Sum = 3x⁷ − 15x⁴ + 2 ✓ matches.

 3x⁷       7    x⁸/8                      3 × x⁸/8           3x⁸/8
 −15x⁴     4    x⁵/5                      −15 × x⁵/5         −3x⁵

⚡ JEE Trick The power rule is "add one to the index, then divide by the new index" — mechanical, so do it in one pass and never split the +C per term. Always differentiate your answer back; it takes three seconds and catches every arithmetic slip. Trap: the rule fails at n = −1 (it would divide by zero) — ∫x⁻¹dx = ln|x| + C, a completely different form.
Answer: ∫(3x⁷ − 15x⁴ + 2)dx = 3x⁸/8 − 3x⁵ + 2x + C.
4∫(t² − 3t + 1)/t^(3/2) dt — choose the correct result (Level-4)Divide by t^(3/2)Evaluate ∫(x³+3x+4)/√x dx · Integrate (x³+3x+4)/√x dx🟡 Similara2t³ᐟ²/3 − 6t¹ᐟ² − 2t⁻¹ᐟ² + c
Concept There is no quotient rule for integration, so a fraction like this must first be turned into a sum that the power rule can eat. Because the denominator is a single term (a monomial), you can legally divide it into each numerator term separately. Dividing powers of the same base means subtracting indices, so every term collapses to a plain power of t and the problem becomes routine.
Formula Index law: ta ÷ tb = ta−b. Power rule: ∫tn dt = tn+1/(n+1) + C, n ≠ −1. Splitting a fraction over a monomial denominator is valid because (A + B + D)/E = A/E + B/E + D/E — but this only works when the SINGLE term is the denominator, never the numerator. Assumption: t > 0, so t^(3/2) and t^(−1/2) are real and non-zero.
Solution
1. Split the fraction over the monomial denominator t^(3/2):(t² − 3t + 1)/t^(3/2) = t²/t^(3/2) − 3t/t^(3/2) + 1/t^(3/2).
2. Simplify each term by subtracting indices (t^a ÷ t^b = t^(a−b)):
  • t²/t^(3/2) = t^(2 − 3/2) = t^(1/2)2 − 3/2 = 4/2 − 3/2 = 1/2.
  • 3t/t^(3/2) = 3t^(1 − 3/2) = 3t^(−1/2)1 − 3/2 = 2/2 − 3/2 = −1/2.
  • 1/t^(3/2) = t^(−3/2)1 = t⁰, so 0 − 3/2 = −3/2.
3. The integral is now a simple sum: ∫[t^(1/2) − 3t^(−1/2) + t^(−3/2)]dt.
4. Integrate t^(1/2), n = 1/2: t^(3/2)/(3/2) = (2/3)t^(3/2).n + 1 = 1/2 + 1 = 3/2; dividing by 3/2 means multiplying by 2/3.
5. Integrate −3t^(−1/2), n = −1/2: −3 × t^(1/2)/(1/2) = −3 × 2t^(1/2) = −6t^(1/2).n + 1 = −1/2 + 1 = 1/2; dividing by 1/2 doubles it, so −3 × 2 = −6.
6. Integrate t^(−3/2), n = −3/2: t^(−1/2)/(−1/2) = −2t^(−1/2).n + 1 = −3/2 + 1 = −1/2; dividing by −1/2 multiplies by −2. Note the sign flips to negative.
7. Combine: (2/3)t^(3/2) − 6t^(1/2) − 2t^(−1/2) + C.
8. Check by differentiating back:d/dt[(2/3)t^(3/2)] = (2/3)(3/2)t^(1/2) = t^(1/2) ✓; d/dt[−6t^(1/2)] = −6(1/2)t^(−1/2) = −3t^(−1/2) ✓; d/dt[−2t^(−1/2)] = −2(−1/2)t^(−3/2) = t^(−3/2) ✓. Sum rebuilds the integrand exactly.

5Find ∫ sin 4(x − π/16) dx (Level-5)∫sin(ax+b)dxIntegral of sin(ax + b) dx · Integral of sin(ax+b) — substitution🟡 Similar[−cos 4(x − π/16)]/4 + k
Concept The argument here is not a bare x but a linear function of x, 4(x − π/16) = 4x − π/4. For any linear inner function the chain rule produces a constant multiplier a on differentiation, so integration must divide by that same a to compensate. This is the one case where you can integrate "as if" the argument were x and simply divide by the coefficient of x — no full substitution machinery is needed, though u-substitution proves it rigorously.
Formula ∫sin(ax + b)dx = −cos(ax + b)/a + C, where a is the coefficient of x (here a = 4, dimensionless) and b is the phase (here b = −π/4 radians). The 1/a appears because d/dx[cos(ax+b)] = −a·sin(ax+b) — the chain rule injects a factor a, so the antiderivative must carry 1/a to cancel it. Angles are in radians throughout; sin and cos are dimensionless.
Solution
1. Expand the argument into standard ax + b form: 4(x − π/16) = 4x − 4π/16 = 4x − π/4.4 ÷ 16 = 1/4, so the phase b = −π/4 rad. Now a = 4 and b = −π/4.
2. Substitute u = 4x − π/4 (radians).
3. Differentiate: du/dx = 4 ⇒ du = 4 dx ⇒ dx = du/4.The phase −π/4 is a constant, so it contributes nothing to the derivative — only the coefficient of x survives.
4. Rewrite the integral entirely in u: ∫sin(u) · (du/4) = (1/4)∫sin u du.The constant 1/4 comes straight out of the integral by the constant-multiple rule.
5. Use the standard result ∫sin u du = −cos u + C: = (1/4)(−cos u) + C = −(1/4)cos u + C.The minus sign is essential — d/du(−cos u) = +sin u, so −cos u is the antiderivative of sin u, not +cos u.
6. Substitute u back: −cos(4x − π/4)/4 + C, equivalently −cos[4(x − π/16)]/4 + C.
7. Verify by differentiating:d/dx[−cos(4x − π/4)/4] = −(1/4)·(−sin(4x − π/4))·4 = sin(4x − π/4) ✓ — the 4 from the chain rule cancels the 1/4, returning the integrand exactly.

⚡ JEE Trick For a linear argument, skip substitution entirely: integrate as though the argument were x, then divide by the coefficient of x. So ∫sin(4x − π/4)dx = −cos(4x − π/4)/4 instantly. Trap 1: forgetting to divide by a = 4 — the most common error. Trap 2: the sign — ∫sin = −cos and ∫cos = +sin; sin "goes negative." Warning: this shortcut works only for linear arguments — ∫sin(x²)dx cannot be done this way (it has no elementary antiderivative).
Answer: ∫sin 4(x − π/16)dx = −cos(4x − π/4)/4 + C = −(1/4)cos[4(x − π/16)] + C.

1Which of the following is the Constant Multiple Rule? (∫k f(x)dx = k∫f(x)dx)Constant multiple ruleConstant Multiple Rule for integration explained · Power, constant multiple & sum rules for antiderivatives🟢 Exactb∫ k f(x) dx = k ∫ f(x) dx
Concept Integration is a linear operation, and one half of that linearity is the Constant-Multiple Rule: a purely numerical factor multiplying the integrand may be slid straight out in front of the integral sign. It works because scaling a function by k scales its antiderivative by the same k. The rule holds only for a genuine constant — a factor that depends on x cannot be pulled out.
Formula ∫k f(x) dx = k ∫f(x) dx, k = constant. If F is an antiderivative of f (F′ = f), then d/dx[kF] = kF′ = kf, so kF is an antiderivative of kf — which is precisely the statement above. The companion linearity rule is the sum/difference rule; together they let you integrate any linear combination term by term.
Solution
1. Let F(x) be an antiderivative of f(x), so F′(x) = f(x).
2. Differentiate kF(x): d/dx[kF(x)] = k·F′(x) = k f(x).The constant k rides through differentiation untouched — it is just a scale factor.
3. Therefore kF(x) is an antiderivative of k f(x) ⇒ ∫k f(x) dx = kF(x) + C = k ∫f(x) dx.
4. Note the restriction: k must be constant. A variable factor like x cannot be taken out — ∫x·f(x)dx ≠ x∫f dx.Pulling out a function of x would break the derivative check; that case needs substitution or parts.
5. Example: ∫5x² dx = 5∫x² dx = 5·x³/3 = 5x³/3 + C; check d/dx(5x³/3) = 5x² ✓.
6. Reject look-alike options: ∫k f = k + ∫f (adds instead of scales) and ∫k f = (∫f)/k are both false.

 ∫k f(x)dx = k + ∫f(x)dx       no       adds, not scales

⚡ JEE Trick Pull every numerical constant out in front first — it declutters the integrand and prevents arithmetic slips. Trap: the rule is for constants only; a factor containing x (or t, θ, …) must stay inside, and trying to yank it out is the classic wrong move that turns an integral into nonsense.
Answer: (b) ∫k f(x) dx = k ∫f(x) dx — the Constant-Multiple Rule.
2Which of the following is the Sum and Difference Rule? (∫[f(x) ± g(x)]dx = ∫f(x)dx ± ∫g(x)dx)Sum & difference ruleSum Rule: ∫(f+g) = ∫f + ∫g · Integral Sum Difference Rule🟢 Exactb∫ [f(x) ± g(x)] dx = ∫ f(x) dx ± ∫ g(x) dx
Concept The second half of integration's linearity is the Sum & Difference Rule: the integral of a sum (or difference) equals the sum (or difference) of the integrals. It lets you break a long integrand into pieces and attack each term by term. It follows directly from the fact that the derivative of a sum is the sum of the derivatives, read backwards.
Formula ∫[f(x) ± g(x)] dx = ∫f(x) dx ± ∫g(x) dx. If F′ = f and G′ = g, then d/dx[F ± G] = F′ ± G′ = f ± g, so F ± G is an antiderivative of f ± g. This extends to any finite number of terms, and combined with the constant-multiple rule handles every linear combination.
Solution
1. Take antiderivatives F, G of f, g: F′(x) = f(x), G′(x) = g(x).
2. Differentiate their sum/difference: d/dx[F(x) ± G(x)] = f(x) ± g(x).Differentiation distributes across ± term by term — the property being reversed.
3. Reverse it: ∫[f ± g] dx = F ± G + C = ∫f dx ± ∫g dx.
4. This generalises: ∫(f₁ + f₂ + … + fₙ) dx = ∫f₁ dx + … + ∫fₙ dx — integrate each term separately.
5. Warning — it does not apply to products or quotients: ∫f·g dx ≠ (∫f dx)(∫g dx).There is no product rule for integration; such integrands need substitution, parts, or algebraic simplification first.
6. Example: ∫(x + cos x) dx = ∫x dx + ∫cos x dx = x²/2 + sin x + C; check d/dx = x + cos x ✓.

Trap: students wrongly "distribute" the integral over a product or quotient; ∫f·g ≠ ∫f·∫g. Simplify products into sums first (expand, divide, use identities).
Answer: (b) ∫[f(x) ± g(x)] dx = ∫f(x) dx ± ∫g(x) dx — the Sum & Difference Rule.

This "integrate normally, then divide by the coefficient of x" shortcut is the standard trick for any linear inner function.
Formula ∫cos(kx) dx = sin(kx)/k + C (k a non-zero constant). Because d/dx[sin(kx)] = k·cos(kx), the antiderivative of cos(kx) must carry a compensating 1/k so the chain-rule factor cancels. Sister result: ∫sin(kx) dx = −cos(kx)/k + C.

5. Verify: d/dx[sin(kx)/k] = (1/k)·k cos(kx) = cos(kx) ✓ — the k and 1/k cancel.
6. Reject wrong forms: sin(kx) alone (missing 1/k), −sin(kx)/k (wrong sign), or k sin(kx) (multiplied instead of divided).

4Which rule allows substitution u = g(x), du = g′(x)dx? (Rule of Substitution)u-substitutionHow to integrate using u-substitution · Integration with u-substitution (introduction)🟢 ExactcRule of Substitution
Concept The technique that introduces a new variable u = g(x) with du = g′(x) dx is the Rule of Substitution (u-substitution). It is the chain rule read in reverse: whenever the integrand contains a composite function together with the derivative of its inner part, switching to u collapses the integral into a standard form.
Formula ∫f(g(x))·g′(x) dx = ∫f(u) du, with u = g(x), du = g′(x) dx. The chain rule says d/dx[F(g(x))] = F′(g(x))·g′(x); reversing that identity is exactly what substitution does, turning an x-integral into a u-integral.
Solution
1. Identify the technique described: introducing u = g(x) and du = g′(x) dx to simplify a composite integrand.
2. Origin — chain rule: d/dx F(g(x)) = F′(g(x))·g′(x); running it backwards defines substitution.So substitution is not a new fact but the inverse of a rule you already know.
3. Procedure: (a) pick the inner function u = g(x); (b) differentiate to get du = g′(x) dx; (c) replace both the composite and dx.
4. The integral becomes ∫f(u) du — solved in u, then u is substituted back to x.
5. Distinguish from the alternatives: the constant-multiple and sum rules handle linear combinations, not compositions; only the described u = g(x) move is the Rule of Substitution.
6. Example: ∫2x·cos(x²) dx with u = x², du = 2x dx gives ∫cos u du = sin u = sin(x²) + C.
