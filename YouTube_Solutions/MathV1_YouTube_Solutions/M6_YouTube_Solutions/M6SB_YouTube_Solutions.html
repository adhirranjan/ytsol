1Let f be a function such that 3f(x) + 2f(m/(19x)) = 5x, x ≠ 0, where m = Σ (from i=1 to 9) i². Then f(5) − f(2) is equal to [JEE Main 2026, 24 Jan Shift-1] (Level-4) (a) −9 (b) 9 (c) 18 (d) 36Functional equation f(x), f(k/x)Let f be a function such that 3f(x)+2f(m/19x)=5x, x≠0, where m=sum(i=1 to 9)(i)^2. Then f(5)-f(2)🟢 Exactc18
Concept A "reciprocal-swap" functional equation. The two arguments x and m/(19x) multiply to a constant, so substituting x → m/(19x) maps each argument onto the other and produces a second equation in the same two unknowns f(x) and f(m/(19x)). Two linear equations, two unknowns — eliminate the unwanted one.
Formula Σ (i=1..n) i² = n(n+1)(2n+1)/6; and for a·f(x) + b·f(k/x) = g(x) the swap x → k/x gives a·f(k/x) + b·f(x) = g(k/x).
Solution
1. Evaluate m: m = Σ (i=1 to 9) i² = 9·10·19/6 = 1710/6 = 285.Standard sum-of-squares formula with n = 9.
2. Simplify the inner argument: m/(19x) = 285/(19x) = 15/x.285 = 19 × 15, so the 19 cancels — this is the whole point of dressing m up as a sum.
3. The given equation becomes 3f(x) + 2f(15/x) = 5x … (I).Note x·(15/x) = 15 is constant, so the swap x → 15/x is self-inverse.
4. Replace x by 15/x throughout (I): 3f(15/x) + 2f(x) = 5·(15/x), i.e. 2f(x) + 3f(15/x) = 75/x … (II).Legal because 15/x ≠ 0 for every x ≠ 0, so (II) holds on the same domain.
5. Eliminate f(15/x): 3×(I) − 2×(II) gives 9f(x) + 6f(15/x) − 4f(x) − 6f(15/x) = 15x − 150/x, so 5f(x) = 15x − 150/x.Multipliers chosen to make the f(15/x) coefficients match (6 and 6).
6. Divide by 5: f(x) = 3x − 30/x.
7. f(5) = 3(5) − 30/5 = 15 − 6 = 9.
8. f(2) = 3(2) − 30/2 = 6 − 15 = −9.
9. f(5) − f(2) = 9 − (−9) = 18.
Eliminating the unwanted f:

  (I)  x  ->  3 f(x)    + 2 f(15/x)  = 5x
  (II) 15/x -> 2 f(x)   + 3 f(15/x)  = 75/x

  3*(I) :  9 f(x) + 6 f(15/x) = 15x
  2*(II):  4 f(x) + 6 f(15/x) = 150/x
  ------------------------------------  subtract
           5 f(x)             = 15x - 150/x
           f(x) = 3x - 30/x
⚡ JEE Trick Spot the invariant first: if the two arguments multiply to a constant k (here x · 15/x = 15), one substitution x → k/x closes the system — never try to "guess" f. Shortcut for a f(x) + b f(k/x) = g(x): f(x) = [a·g(x) − b·g(k/x)]/(a² − b²). Here (3·5x − 2·75/x)/5 = 3x − 30/x in one line. Also: the disguised constant (Σi² = 285 = 19·15) exists only so the 19 cancels — always simplify it before doing any algebra.
Answer: (c) 18
2Let f and g be functions satisfying f(x+y) = f(x)f(y), f(1) = 7 and g(x+y) = g(x+y), g(1) = 1, for all x, y ∈ N. If Σ (from x=1 to n) ( f(x)/g(x) ) = 19607, then n is equal to: [JEE Main 2026, 21 Jan Shift-1] (Level-3) (a) 6 (b) 7 (c) 5 (d) 4Exponential functional equation, GP sumLet f and g be functions satisfying f(x+y)=f(x)f(y), f(1)=7 — JEE Main 2026 solution🟢 Exact⚠ c5
Concept f(x+y) = f(x)f(y) with f(1) = 7 is the multiplicative Cauchy equation, forcing f(x) = 7x on ℕ. The printed g-relation g(x+y) = g(x+y) is a tautology (a book typo) that leaves g undefined; the intended relation is g(x+y) = g(x)g(y) with g(1) = 1, which forces g ≡ 1. Then f(x)/g(x) = 7x and the sum is a plain geometric progression.
Formula f(x+y)=f(x)f(y), f(1)=a ⇒ f(x)=ax; GP sum Σ (x=1..n) arx−1 = a(rn−1)/(r−1). Here first term 7, common ratio 7.
Solution
1. f(2) = f(1)f(1) = 7² , f(3) = f(2)f(1) = 7³ , and by induction f(x) = 7x.Each unit step multiplies by f(1) = 7.
2. Intended g: g(x+y) = g(x)g(y), g(1) = 1 ⇒ g(x) = 1x = 1 for all x ∈ ℕ.The value that reproduces itself under multiplication is 1; the printed g(x+y)=g(x+y) says nothing, so we use the standard form.
3. Therefore f(x)/g(x) = 7x/1 = 7x.
4. Σ (x=1..n) 7x = 7(7n − 1)/(7 − 1) = 7(7n−1)/6.
5. Set equal to 19607: 7(7n−1) = 6 × 19607 = 117642 ⇒ 7n − 1 = 16806 ⇒ 7n = 16807.
6. 16807 = 75, so n = 5.7² = 49, 7³ = 343, 7⁴ = 2401, 7⁵ = 16807.
  f(x) = 7^x ,  g(x) = 1  ==>  f/g = 7^x

  n :  partial sum  7 + 49 + 343 + 2401 + 16807
  1 :        7
  2 :       56
  3 :      399
  4 :     2800
  5 :    19607     <-- answer  (n = 5)
⚡ JEE Trick Skip the GP algebra: just add powers of 7 until you hit 19607 — 7+49+343+2401+16807 lands exactly at the 5th term, so n = 5 by inspection. Trap: the misprinted g-equation g(x+y)=g(x+y) is a defect; read it as g(x)g(y) (its only sensible form), which gives g ≡ 1, not g(x) = x. Reading g as anything but 1 breaks the clean 7x series.
Answer: (c) 5.
3Let [x] denote the greatest integer less than or equal to x. Then the domain of f(x) = sec⁻¹(2[x]+1) is: [JEE Main 2025, 28 Jan Shift-2] (Level-4) (a) (−∞, −1] ∪ [0, ∞) (b) (−∞, −1] ∪ [1, ∞) (c) (−∞, ∞) (d) (−∞, ∞) − {0}Domain with greatest-integer, sec inverseDomain of f(x)=sec⁻¹(2[x]+1), [x] greatest integer — JEE Main 2025🟢 Exactc(−∞, ∞)
Concept sec⁻¹(u) is defined only when |u| ≥ 1, i.e. u ∈ (−∞, −1] ∪ [1, ∞). Here u = 2[x] + 1 and [x] is always an integer, so u = 2(integer) + 1 is always an odd integer. Every odd integer has magnitude at least 1, so the condition holds for every real x.
Formula sec⁻¹(u) defined ⇔ |u| ≥ 1; for any x ∈ ℝ, [x] = n ∈ ℤ ⇒ 2[x]+1 = 2n+1 (odd). 2n+1 is never 0 and never lies strictly between −1 and 1.
Solution
1. Domain requirement: |2[x] + 1| ≥ 1.This is the only restriction — sec⁻¹ has no other constraint.
2. For every real x, [x] = n is an integer, so 2[x] + 1 = 2n + 1 runs through the odd integers … −3, −1, 1, 3, … only.
3. The odd integer of smallest magnitude is ±1 (at n = 0 → 1, n = −1 → −1); there is no integer n making 2n+1 land inside the forbidden open interval (−1, 1).2n+1 = 0 would need n = −½, not an integer.
4. Boundaries are fine: sec⁻¹(1) = 0 and sec⁻¹(−1) = π are both defined, so n = 0 and n = −1 are allowed too.
5. Hence |2[x]+1| ≥ 1 for all integers n, i.e. for all x ∈ ℝ. Domain = (−∞, ∞).
   [x] = n :   -2   -1    0    1    2
   2[x]+1  :   -3   -1    1    3    5
   |2[x]+1|:    3    1    1    3    5    all >= 1

   ==> sec^-1 defined for every real x
   Domain = (-oo, oo)
⚡ JEE Trick The greatest-integer wrapper tempts you to carve out a strip of x, but 2[x]+1 can only ever equal an odd integer, and every odd integer already satisfies |u| ≥ 1 — so nothing is excluded. Trap: option (b) (−∞,−1]∪[1,∞) is the range of valid u, not of x; students copy the sec⁻¹ domain condition straight onto x and mis-answer.
Answer: (c) (−∞, ∞).
4Consider the function f : R → R defined by f(x) = 2x / √(1+9x²). If the composition f∘(f∘f∘f∘…∘f)(x) [10 times] = 2¹⁰ / √(1+90x²), then the value of √(3α+1) is equal to ______ [JEE Main 2024, 4 Apr Shift-2] (Level-4)Repeated composition of a functionf:R→R, f(x)=2x/√(1+9x²), fofo…of(x)=2¹⁰x/√(1+9αx²), find √(3α+1) — JEE Main 2024🟢 Exact1024
Concept Composing f(x) = 2x/√(1+9x²) with itself keeps the same shape A·x/√(1+B·x²): the numerator constant doubles each time and B follows a simple recurrence. Find B after 10 compositions, match it to the given 1+9αx², then evaluate √(3α+1). Printed statement is garbled; the standard form is f(10)(x) = 2¹⁰x/√(1+9αx²).
Formula If g(x) = A x/√(1+B x²) then f(g(x)) = 2A·x/√(1 + (B+9A²)x²). Because 1+9g² = (1+(B+9A²)x²)/(1+Bx²).
Solution
1. Start f₁(x) = 2x/√(1+9x²): A₁ = 2, B₁ = 9.
2. Recurrences: An+1 = 2An ⇒ An = 2n; and Bn+1 = Bn + 9An² = Bn + 9·4n.
3. Sum the B-recurrence: Bn = 9 + 9Σ(k=1..n−1)4k = 9·Σ(k=0..n−1)4k = 9(4n−1)/3 = 3(4n−1).Check: B₁ = 3(3) = 9, B₂ = 3(15) = 45. ✓
4. Ten compositions: f(10)(x) = 210x/√(1 + 3(410−1)x²) = 1024x/√(1 + 3145725 x²).4¹⁰ = 1048576, so 3(4¹⁰−1) = 3·1048575 = 3145725.
5. Match to 1 + 9αx²: 9α = 3145725 ⇒ α = 349525.
6. √(3α+1) = √(1048575 + 1) = √1048576 = 1024.1024² = 1048576 = 4¹⁰.
  n : A_n=2^n    B_n=3(4^n - 1)
  1 :    2            9
  2 :    4           45
  ...
 10 : 1024      3145725   ->  9a = 3145725, a = 349525

  3a + 1 = 1048576 = 1024^2   ->  sqrt(3a+1) = 1024   <-- answer
⚡ JEE Trick Never expand ten nested radicals: only the coefficient under the root iterates, and it does so as a geometric series in 4n. Get Bn = 3(4n−1) in closed form and everything falls out. Trap: forgetting the factor 9 when equating B10 to 9α (giving α = 3145725 instead of 349525), or fumbling 4¹⁰.
Answer: √(3α+1) = 1024.
5The equation x² − 4x + [x] + 3 = x[x], where [x] denotes the greatest integer function, has: [JEE Main 2023, 24 Jan Shift-1] (Level-5) (a) exactly two solutions in (−∞, ∞) (b) no solution (c) a unique solution in (−∞, 1) (d) a unique solution in (−∞, ∞)Greatest-integer equation, number of solutionsThe equation x²−4x+[x]+3=x[x] — number of solutions (JEE Main 2023)🟢 Exactda unique solution in (−∞, ∞)
Concept Don't split into integer strips blindly — regroup the equation so the greatest-integer term factors out. Moving everything to one side, x²−4x+3 = (x−1)(x−3) and the [x]-terms give [x](1−x), which shares the factor (x−1). A clean factorisation kills almost all candidate solutions at once.
Formula x²−4x+3 = (x−1)(x−3); and [x] − x[x] = [x](1−x). Fractional part {x} = x − [x] ∈ [0, 1), so x − [x] can never equal 3. This last fact rules out the second factor.
Solution
1. Rewrite: x² − 4x + [x] + 3 = x[x] ⇒ (x²−4x+3) + [x] − x[x] = 0.
2. Factor both pieces: (x−1)(x−3) + [x](1−x) = 0 ⇒ (x−1)(x−3) − [x](x−1) = 0.1 − x = −(x − 1).
3. Pull out (x−1): (x−1)·(x − 3 − [x]) = 0.
4. First factor: x − 1 = 0 ⇒ x = 1. Check: 1 − 4 + [1] + 3 = 1 and 1·[1] = 1. ✓
5. Second factor: x − 3 − [x] = 0 ⇒ x − [x] = 3 ⇒ {x} = 3, which is impossible since 0 ≤ {x} < 1.The fractional part is always less than 1, so this branch has no solution.
6. Only x = 1 survives, so there is exactly one real solution, valid over all of (−∞, ∞).
  (x-1)(x-3) - [x](x-1) = 0
        (x-1)( x - 3 - [x] ) = 0

  factor 1:  x = 1                      <-- valid solution
  factor 2:  x - [x] = 3  => {x} = 3    impossible (0 <= {x} < 1)

  ==> unique solution x = 1 in (-oo, oo)
⚡ JEE Trick Whenever [x] appears linearly beside a factorable quadratic, collect terms and hunt for a common linear factor — here (x−1) — instead of testing interval by interval. Trap: option (c) says "unique solution in (−∞, 1)", but x = 1 is the endpoint and is not inside the open interval (−∞, 1); the solution is unique over the whole line, so (d) is correct, not (c).
Answer: (d) a unique solution in (−∞, ∞).
6The domain of the function f(x) = sin⁻¹[2x² − 3] + log₂(log_(1/4)(x² − 5x + 5)), where [t] is the greatest integer function, is: [JEE Main 2022, 27 Jul Shift-2] (Level-6) (a) (−√(5/2), (5 − √5)/2) (b) ((5 − √5)/2, (5 + √5)/2) (c) (1, (5 − √5)/2) (d) [1, (5 + √3)/2)Domain: inverse sine with logarithmDomain of sin⁻¹[2x²−3] + log₂(log(x²−5x+5)) — JEE Main 2022🟢 Exactc(1, (5 − √5)/2)
Concept A sum is defined only where both pieces are defined. sin⁻¹[2x²−3] needs its integer argument in [−1, 1]; the nested log needs the inner log positive, which (base ¼ < 1) forces its argument between 0 and 1. Solve each region, then intersect.
Formula sin⁻¹(t) needs t ∈ [−1,1], and for integer [u]: [u] ≥ −1 ⇔ u ≥ −1, [u] ≤ 1 ⇔ u < 2; log1/4(y) > 0 ⇔ 0 < y < 1. Base < 1 makes the log decreasing.
Solution
1. sin⁻¹ part: need −1 ≤ [2x²−3] ≤ 1 ⇒ −1 ≤ 2x²−3 < 2 ⇒ 1 ≤ x² < 5/2.[u]≥−1 gives u≥−1; [u]≤1 gives u<2.
2. So x ∈ (−√(5/2), −1] ∪ [1, √(5/2)), where √(5/2) ≈ 1.581. … (A)
3. Log part: need log1/4(x²−5x+5) > 0 ⇒ 0 < x²−5x+5 < 1.
4. Upper: x²−5x+5 < 1 ⇒ x²−5x+4 < 0 ⇒ (x−1)(x−4) < 0 ⇒ 1 < x < 4.
5. Lower: x²−5x+5 > 0 ⇒ x < (5−√5)/2 ≈ 1.382 or x > (5+√5)/2 ≈ 3.618. Combined with 1<x<4: x ∈ (1, (5−√5)/2) ∪ ((5+√5)/2, 4). … (B)
6. Intersect (A) ∩ (B): the only overlap is [1, √(5/2)) ∩ (1, (5−√5)/2) = (1, (5−√5)/2), since (5−√5)/2 ≈ 1.382 < 1.581.x = 1 is dropped: (A) includes it but (B) is open at 1.
  (A) sin^-1 :  1 <= x^2 < 5/2
                x in (-1.581, -1] U [1, 1.581)

  (B) log    :  0 < x^2-5x+5 < 1
                x in (1, 1.382) U (3.618, 4)

  overlap    :  (1, (5 - sqrt5)/2)   ~ (1, 1.382)   <-- domain
⚡ JEE Trick With a greatest-integer inside sin⁻¹, convert [u]∈[−1,1] directly to −1 ≤ u < 2 (note the strict upper bound) before touching x — that half-open translation is where marks are lost. Trap: the log's lower cut (5−√5)/2 ≈ 1.382 is tighter than the sin⁻¹ bound √(5/2) ≈ 1.581, so it governs the right end; picking √(5/2) gives the wrong interval (5−√5)/2 vs 1.581.
Answer: (c) (1, (5 − √5)/2).
7Considering only the principal values of the inverse trigonometric functions, the domain of the function f(x) = cos⁻¹((x² − 4x + 2)/(x² + 3)) is: [JEE Main 2022, 28 Jul Shift-1] (Level-4) (a) (−∞, 1/4] (b) [−1/4, ∞) (c) [−1/3, ∞) (d) (−∞, 1/3]Domain of cos inverse of rationalDomain of cos⁻¹ of a rational (x²…)/(x²…) function — JEE technique🟡 Similar⚠ b−1/4, ∞
Concept cos⁻¹(t) is defined only for t ∈ [−1, 1]. So the domain is the set of x satisfying the double inequality −1 ≤ (x²−4x+2)/(x²+3) ≤ 1. The denominator x²+3 is strictly positive for every real x, so we may cross-multiply without flipping either inequality — that is the key safety check.
Formula cos⁻¹t defined ⇔ −1 ≤ t ≤ 1; a quadratic ax²+bx+c with a > 0 and discriminant D = b²−4ac < 0 is positive for all real x.
Solution
1. Denominator check: x²+3 ≥ 3 > 0 for all x ∈ R, so the fraction is defined everywhere and cross-multiplication preserves the inequality signs.If the denominator could change sign we would have to split into cases.
2. Require −1 ≤ (x²−4x+2)/(x²+3) ≤ 1. Handle the two halves separately.
3. Right half: (x²−4x+2)/(x²+3) ≤ 1 ⇒ x²−4x+2 ≤ x²+3.Multiply through by the positive x²+3.
4. The x² cancels: −4x + 2 ≤ 3 ⇒ −4x ≤ 1 ⇒ x ≥ −1/4.Dividing by −4 flips the inequality sign.
5. Left half: −1 ≤ (x²−4x+2)/(x²+3) ⇒ −(x²+3) ≤ x²−4x+2 ⇒ 0 ≤ 2x² − 4x + 5.
6. For 2x²−4x+5: D = (−4)² − 4(2)(5) = 16 − 40 = −24 < 0 and the leading coefficient 2 > 0, so 2x²−4x+5 > 0 for every real x.The left inequality imposes no restriction at all — it is vacuously satisfied.
7. Intersect the two conditions: x ≥ −1/4 with x ∈ R gives the domain [−1/4, ∞).Closed at −1/4 because x = −1/4 makes the fraction exactly 1, and cos⁻¹(1) = 0 is defined.
   -1  <=  (x^2 - 4x + 2)/(x^2 + 3)  <=  1      [x^2+3 > 0 always]

   RIGHT:  x^2 - 4x + 2  <=  x^2 + 3
              -4x + 2    <=  3
                   -4x   <=  1
                      x  >= -1/4          <-- binding

   LEFT :  -(x^2 + 3)    <=  x^2 - 4x + 2
            0            <=  2x^2 - 4x + 5
            D = 16 - 40 = -24 < 0, a = 2 > 0
                             ==> true for all x   <-- no restriction

   Domain = [-1/4, oo)
⚡ JEE Trick When the same x² sits in both numerator and denominator, each half of the sandwich collapses to something one degree lower — the "≤ 1" side kills the x² and leaves a linear inequality (instant answer), while the "≥ −1" side doubles the x² into a definite quadratic that is almost always vacuous. Test the discriminant before grinding: a negative D means that half contributes nothing, and the whole problem is decided by one line of linear algebra.
Answer: (b) [−1/4, ∞)
