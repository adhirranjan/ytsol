L-1

Sine Rule, Triangle Basics & Nature of a Triangle

Elements of a triangle

  • In △ABC the side opposite angle A is a (= BC), opposite B is b (= CA), opposite C is c (= AB). "Solving a triangle" means finding the remaining three of its six elements from three given ones.
  • Always true: A + B + C = 180°, with A, B, C > 0 and a, b, c > 0.
  • Triangle inequalities: a + b > c, b + c > a, c + a > b; equivalently |a − b| < c, |b − c| < a, |c − a| < b.

The sine rule

sine rule (2R = circum-diameter)a/sinA = b/sinB = c/sinC = 2R — the sides are proportional to the sines of the opposite angles.
  • Proof idea: drop the altitude h from A to BC. In △ADB, h = c sinB; in △ADC, h = b sinC ⇒ sinB/b = sinC/c. Repeating with an altitude from B gives sinA/a = sinC/c, so all three ratios are equal.
  • Note: if a, b, c are in A.P., then sinA, sinB, sinC are in A.P. (scale by the common ratio 1/2R).
💡 When to reach for itThe sine rule is the tool when you know a side and its opposite angle (fixing 2R) plus one more angle or side. It also converts any "sides ↔ angles" relation into pure trigonometry via a = 2R sinA.
Worked examples from the module
Book Example · L-1 (theory)
The sides of a triangle are proportional to cos(A/2), cos(B/2), cos(C/2). Find the angles of this triangle.
Sides are also proportional to sinA, sinB, sinC. Writing cos(A/2) = sin(π/2 − A/2), the sides ∝ sin(π/2 − A/2), sin(π/2 − B/2), sin(π/2 − C/2).
So the triangle's angles are π/2 − A/2, π/2 − B/2, π/2 − C/2 (their sum is 3π/2 − (A+B+C)/2 = 3π/2 − π/2 = π ✓).
Angles = π/2 − A/2, π/2 − B/2, π/2 − C/2
Book Example · L-1 (theory)
In △ABC, a = 2, b = 3 and sinA = 2/3. Find ∠B.
Sine rule: a/sinA = b/sinB ⇒ 2/(2/3) = 3/sinB ⇒ 3 = 3/sinB ⇒ sinB = 1.
∠B = 90°
Book Example-1 · L-1
In any △ABC, simplify (cos2A)/a² − (cos2B)/b².
cos2A = 1 − 2sin²A, so (cos2A)/a² − (cos2B)/b² = 1/a² − 1/b² − 2(sin²A/a² − sin²B/b²).
By the sine rule sinA/a = sinB/b = 1/2R, so sin²A/a² = sin²B/b² and the bracket vanishes.
= 1/a² − 1/b²
Book Example-2 · L-1
In △ABC prove that a sin(B−C) + b sin(C−A) + c sin(A−B) = 0.
Put a = 2R sinA etc.; the sum = 2R Σ sinA sin(B−C). Since A = π − (B+C), sinA = sin(B+C), so sinA sin(B−C) = sin(B+C)sin(B−C) = sin²B − sin²C.
Summing cyclically: (sin²B − sin²C) + (sin²C − sin²A) + (sin²A − sin²B) = 0.
= 0 (any cyclic expression with a "−" inside collapses to 0)
L-2

Cosine Rule, Projection Rule & Solution of Triangles

The cosine rule

cosine rulecosA = (b²+c²−a²)/2bc · cosB = (c²+a²−b²)/2ca · cosC = (a²+b²−c²)/2ab
equivalent "side" forma² = b²+c² − 2bc cosA · b² = c²+a² − 2ca cosB · c² = a²+b² − 2ab cosC
  • Proof idea: drop AD ⊥ BC with foot D, BD = x = c cosB. Then h² = c² − x² (from △ADB) and h² = b² − (a−x)² (from △ADC). Equating gives a² + c² − b² = 2ac cosB.
  • Use: the cosine rule is the tool when you know three sides (find any angle) or two sides and the included angle (find the third side).

Projection rule

each side as a projection of the other twoa = b cosC + c cosB · b = c cosA + a cosC · c = a cosB + b cosA
  • Read straight off the foot of an altitude: BC = BD + DC = c cosB + b cosC.
Worked examples from the module
Book Example · L-2 (theory)
If a cos²(C/2) + c cos²(A/2) = 3b/2, show that a, b, c are in A.P.
cos²(θ/2) = (1 + cosθ)/2, so a(1+cosC)/2 + c(1+cosA)/2 = 3b/2 ⇒ a + a cosC + c + c cosA = 3b.
By the projection rule a cosC + c cosA = b, so a + c + b = 3b ⇒ a + c = 2b.
a + c = 2b ⇒ a, b, c in A.P.
Book Example · L-2 (theory)
b = √3, c = 1, ∠A = 30°. Solve the triangle.
cosA = (b²+c²−a²)/2bc ⇒ cos30° = (3+1−a²)/(2√3) ⇒ √3/2 = (4−a²)/(2√3) ⇒ 3 = 4 − a² ⇒ a = 1.
cosB = (a²+c²−b²)/2ac = (1+1−3)/2 = −1/2 ⇒ ∠B = 120°; then ∠C = 180° − 30° − 120° = 30°.
a = 1, ∠B = 120°, ∠C = 30°
Book Example · L-2 (theory)
Find ∠A given (2cosA)/a + (cosB)/b + (2cosC)/c = a/bc + b/ac.
Multiply through by 2abc using the cosine rule: 2(b²+c²−a²) + (a²+c²−b²) + 2(a²+b²−c²) = 2(a²+b²).
LHS = 3b² + c² + a²; setting = 2a² + 2b² gives b² + c² = a².
∠A = 90° (Pythagoras)
Book Example-1 · L-2
In △ABC, find sin(A−B)/sin(A+B).
sin(A−B)/sin(A+B) = (sinA cosB − sinB cosA)/sinC = (a/c)cosB − (b/c)cosA.
= (a/c)·(a²+c²−b²)/2ac − (b/c)·(b²+c²−a²)/2bc = [ (a²+c²−b²) − (b²+c²−a²) ]/2c² = (2a²−2b²)/2c².
= (a² − b²)/c²
Book Example-2 · L-2
In △ABC, if c² + a² − b² = ac, find ∠B.
cosB = (c²+a²−b²)/2ac = ac/2ac = 1/2.
∠B = π/3
Book Example-3 · L-2
In △ABC, a = 2 cm, b = 3 cm, c = 4 cm. Find ∠A.
cosA = (b²+c²−a²)/2bc = (9 + 16 − 4)/(2·3·4) = 21/24 = 7/8.
∠A = cos⁻¹(7/8)
L-3

Napier's Analogy (Law of Tangents) & Area of a Triangle

Napier's analogy (law of tangents)

three cyclic formstan[(B−C)/2] = [(b−c)/(b+c)] cot(A/2) · tan[(A−B)/2] = [(a−b)/(a+b)] cot(C/2) · tan[(C−A)/2] = [(c−a)/(c+a)] cot(B/2)
  • Proof idea: (b−c)/(b+c) = (sinB − sinC)/(sinB + sinC) = [2cos((B+C)/2)sin((B−C)/2)] / [2sin((B+C)/2)cos((B−C)/2)] = tan(A/2)·... which rearranges to the stated form (using (B+C)/2 = 90° − A/2).

Area of a triangle

area from two sides & the included angleΔ = (1/2)ab sinC = (1/2)bc sinA = (1/2)ca sinB
  • Proof idea: Δ = (1/2)·base·height = (1/2)·a·AD, and AD = b sinC from △ADC.
Worked examples from the module
Book Example · L-3 (theory)
In △ABC, b = √3 + 1, c = √3 − 1, ∠A = 60°. Find tan[(B−C)/2].
tan[(B−C)/2] = [(b−c)/(b+c)] cot(A/2) = [ (√3+1)−(√3−1) ]/[ (√3+1)+(√3−1) ] · cot30° = (2/2√3)·√3.
tan[(B−C)/2] = 1
Book Example · L-3 (theory)
Find the area of △ABC with ∠A = 60°, b = 4 cm, c = √3 cm.
Δ = (1/2)bc sinA = (1/2)·4·√3·sin60° = (1/2)·4·√3·(√3/2) = 3.
Area = 3 sq. cm
Book Example · L-3 (theory)
In △ABC, a = √3 cm, b = √3 cm, c = √5 cm. Find the area.
cosC = (a²+b²−c²)/2ab = (2 + 3 − 5)/(2·√2·√3) — here a = √2 in the figure — = 0, so C = π/2.
With the right angle at C, Δ = (1/2)ab = (1/2)·√2·√3 = √6/2.
Area = √6/2 sq. cm
Book Example-1 · L-3
In △ABC, a = 6, b = 3 and cos(A−B) = 4/5. Find the area.
Let t = tan[(A−B)/2]. cos(A−B) = (1−t²)/(1+t²) = 4/5 ⇒ 5 − 5t² = 4 + 4t² ⇒ t² = 1/9 ⇒ t = 1/3.
tan[(A−B)/2] = [(a−b)/(a+b)] cot(C/2) ⇒ 1/3 = (3/9) cot(C/2) ⇒ cot(C/2) = 1 ⇒ C = 90°.
Δ = (1/2)ab sinC = (1/2)·6·3·1.
Area = 9 sq. units
Book Example-2 · L-3
In △ABC, (cosA)/a = (cosB)/b = (cosC)/c and a = 2. Find the area.
Write a = k sinA etc.: cosA/sinA = cosB/sinB = cosC/sinC ⇒ cotA = cotB = cotC ⇒ A = B = C = 60°.
Equilateral with side a = 2: Δ = (√3/4)a² = (√3/4)·4.
Area = √3 sq. units
L-4

Heights & Distances (Angles of Elevation/Depression, m–n Theorem)

Basic terms

  • Line of sight: the line from the observer's eye to the point viewed.
  • Angle of elevation: angle the line of sight makes with the horizontal when the object is above the observer.
  • Angle of depression: angle the line of sight makes with the horizontal when the object is below the observer (equals the angle of elevation of the observer from the object).

m–n theorem

D on BC with BD:DC = m:n, ∠ADC = θ, ∠BAD = α, ∠DAC = β(m + n) cotθ = m cotα − n cotβ and (m + n) cotθ = n cotB − m cotC
  • Proof uses the sine rule in △ABD and △ADC and divides the two relations (the AD's cancel).
Worked examples from the module
Book Example · L-4 (theory)
From the top of a 60 m tower the angles of depression of the top and bottom of a pole are α and β. Find the height h of the pole.
Let d be the horizontal distance. From the top of the pole: d = (60 − h) cotα. From the foot: d = 60 cotβ.
So (60 − h)cotα = 60 cotβ ⇒ 60(cotα − cotβ) = h cotα.
h = 60(cotα − cotβ)/cotα
Book Example · L-4 (theory)
A 20 m tree is broken by the wind; its top strikes the ground at 30°. Find the height of the break point.
Let the break be at height h; the broken part (length 20 − h) makes 30° with the ground. sin30° = h/(20 − h).
1/2 = h/(20 − h) ⇒ 20 − h = 2h ⇒ 3h = 20.
h = 20/3 m
Book Example · L-4 (theory)
In △ABC, ∠ABC = 45°; D on BC with 2BD = CD and ∠DAB = 15°. Find ∠ACB.
∠ADB = 180° − (15° + 45°) = 120°, so ∠ADC = 60°. Here BD:DC = 1:2, so m = 1, n = 2, θ = 60°.
(m+n)cotθ = n cotB − m cotC ⇒ 3 cot60° = 2 cot45° − cotC ⇒ cotC = 2 − √3.
∠ACB = 75°
Book Example-1 · L-4
An observer at the top of a tree sees a car approaching; the angle of depression is 30°, and after 3 minutes it is 60°. After how long will the car reach the tree?
If h is the tree's height, the car moves from distance h cot30° to h cot60°, covering d = h(cot30° − cot60°) in 3 min; speed = d/3.
Remaining distance = h cot60°; time = h cot60° ÷ [h(cot30° − cot60°)/3] = 3cot60°/(cot30° − cot60°) = 3(1/√3)/(√3 − 1/√3) = (√3)/(2/√3)... = 3/2.
1.5 minutes more
Book Example-2 · L-4
In △ABC with altitude AD, ∠BAC = 45°, DB = 3, DC = 2. Find the area.
Let ∠BAD = α, ∠CAD = 45° − α. m–n with m = 3, n = 2, θ = 90° (AD ⊥ BC): 5 cot90° = 3 cotα − 2 cot(45°−α) ⇒ 3 cotα = 2 cot(45°−α).
So 3/tanα = 2(1+tanα)/(1−tanα) ⇒ 2tan²α + 5tanα − 3 = 0 ⇒ (2tanα − 1)(tanα + 3) = 0 ⇒ tanα = 1/2 (α < 45°).
tanα = DB/AD = 3/AD = 1/2 ⇒ AD = 6. Area = (1/2)·BC·AD = (1/2)·5·6.
Area = 15
Book Example-3 · L-4
If the median of △ABC through A is perpendicular to AB, find tanA/tanB.
Let AD be the median (D midpoint of BC) with AD ⊥ AB. Then ∠BAD = 90°, so ∠ADB = 90° − B and ∠ADC = 90° + B; here m = n = 1.
(m+n)cotθ = m cotα − n cotβ with θ = ∠ADC = 90°+B: 2cot(90°+B) = cot90° − cot(A−90°) ⇒ −2tanB = tanA.
tanA/tanB = −2

Half-Angle Formulas & Heron's Formula

Half-angle formulas (2s = a + b + c)

sin of half-anglessin(A/2) = √[(s−b)(s−c)/bc] · sin(B/2) = √[(s−c)(s−a)/ca] · sin(C/2) = √[(s−a)(s−b)/ab]
cos of half-anglescos(A/2) = √[s(s−a)/bc] · cos(B/2) = √[s(s−b)/ca] · cos(C/2) = √[s(s−c)/ab]
tan of half-anglestan(A/2) = √[(s−b)(s−c)/s(s−a)] = Δ/[s(s−a)] · tan(B/2) = Δ/[s(s−b)] · tan(C/2) = Δ/[s(s−c)]
  • Derivation: sin²(A/2) = (1 − cosA)/2 = [2bc − (b²+c²−a²)]/4bc = [a² − (b−c)²]/4bc = (s−b)(s−c)/bc. The cos version uses (1 + cosA)/2 = s(s−a)/bc.

Heron's formula

area from the three sidesΔ = √[s(s−a)(s−b)(s−c)], s = (a+b+c)/2
  • Proof: Δ = (1/2)ab sinC = (1/2)ab·2sin(C/2)cos(C/2) = ab·√[(s−a)(s−b)/ab]·√[s(s−c)/ab] = √[s(s−a)(s−b)(s−c)].
Worked examples from the module
Book Example · L-5 (theory)
In any △ABC, prove b cos²(C/2) + c cos²(B/2) = s.
b cos²(C/2) + c cos²(B/2) = b·s(s−c)/ab + c·s(s−b)/ac = s(s−c)/a + s(s−b)/a = s(2s − b − c)/a.
2s − b − c = a, so = s·a/a = s.
= s
Book Example-1 · L-5
If A is the area and 2S the perimeter of a triangle, show A ≤ S²/(3√3).
A² = S(S−a)(S−b)(S−c). By AM ≥ GM on the three positive numbers S−a, S−b, S−c: [(S−a)+(S−b)+(S−c)]/3 ≥ [(S−a)(S−b)(S−c)]^{1/3}.
The left side = (3S − 2S)/3 = S/3, so (S/3)³ ≥ A²/S ⇒ S⁴/27 ≥ A² ⇒ A ≤ S²/(3√3) (equality for the equilateral triangle).
A ≤ S²/(3√3)
Book Example-2 · L-5
If cos(A/2) = √[(b+c)/2c], prove a² + b² = c².
cos²(A/2) = (b+c)/2c and cos²(A/2) = s(s−a)/bc, so s(s−a)/bc = (b+c)/2c ⇒ 2s(s−a) = b(b+c).
2s(2s − 2a) = 2b(b+c) ⇒ (a+b+c)(b+c−a) = 2b² + 2bc ⇒ (b+c)² − a² = 2b² + 2bc ⇒ b² + c² + 2bc − a² = 2b² + 2bc.
c² = a² + b²
Book Example-3 · L-5
If the cotangents of the half-angles of a triangle are in A.P., prove the sides are in A.P.
2cot(B/2) = cot(A/2) + cot(C/2) ⇒ 2√[s(s−b)/(s−a)(s−c)] = √[s(s−a)/(s−b)(s−c)] + √[s(s−c)/(s−a)(s−b)].
Multiply through by √[(s−a)(s−b)(s−c)/s]: 2(s−b) = (s−a) + (s−c) ⇒ 2b = a + c.
a, b, c are in A.P.
L-6

Circum-radius, In-radius & Ex-radii

Circum-radius R

two faces of RR = a/2sinA = b/2sinB = c/2sinC and R = abc/4Δ
  • The circumcentre (intersection of the perpendicular bisectors) is equidistant (= R) from the three vertices; it lies inside for an acute triangle, on the hypotenuse's midpoint for a right triangle, outside for an obtuse one. From Δ = (1/2)bc sinA = (1/2)bc·(a/2R) one gets Δ = abc/4R.

In-radius r

four faces of rr = Δ/s = (s−a)tan(A/2) = [a sin(B/2)sin(C/2)]/cos(A/2) = 4R sin(A/2)sin(B/2)sin(C/2)
  • Splitting △ABC into △BIC, △CIA, △AIB (I = incentre, each of height r): Δ = (1/2)r(a+b+c) = rs ⇒ r = Δ/s. Using tan(A/2) = Δ/s(s−a) gives r = (s−a)tan(A/2).

Ex-radii r₁, r₂, r₃

ex-radius opposite A (cyclic for r₂, r₃)r₁ = Δ/(s−a) = s tan(A/2) = [a cos(B/2)cos(C/2)]/cos(A/2) = 4R sin(A/2)cos(B/2)cos(C/2)
  • The escribed circle opposite A touches side BC and the extensions of AB, AC; its centre is the meet of the internal bisector of A and the external bisectors of B and C. Tangent-length argument gives the tangent from A equal to s, whence r₁ = s tan(A/2).
💡 High-yield identitiesr₁ + r₂ + r₃ − r = 4R · r₁r₂ + r₂r₃ + r₃r₁ = s² · r·r₁·r₂·r₃ = Δ². In a right angle at C: r = s − c, r₃ = s, and R = c/2.

s = 9, Δ = √[9·5·3·1] = √135 = 3√15. r = Δ/s = 3√15/9.

Book Example · L-6 (theory)
In △ABC, a = 18, b = 24, c = 30. Find r₁, r₂, r₃.
s = 36, Δ = 216. r₁ = Δ/(s−a) = 216/18 = 12; r₂ = 216/12 = 18; r₃ = 216/6 = 36.
r₁ = 12, r₂ = 18, r₃ = 36 (check r₁ + r₂ + r₃ − r = 12 + 18 + 36 − 6 = 60 = 4R, R = 15 ✓)

Prove Σ r₁r₂ = r₁r₂ + r₂r₃ + r₃r₁ = s².

L-7

Regular Polygons, Cyclic Quadrilaterals & Exradii Identities

Regular polygon of n sides

inscribed in a circle of radius rside = 2r sin(π/n) · perimeter = 2nr sin(π/n) · area = (1/2) n r² sin(2π/n)
circumscribed about a circle of radius Rside = 2R tan(π/n) · perimeter = 2nR tan(π/n) · area = nR² tan(π/n)
  • Split the n-gon into n congruent isosceles triangles from the centre, each with apex angle 2π/n; the side and area come from that one triangle times n.

Cyclic quadrilateral (sides a, b, c, d; s = (a+b+c+d)/2)

key resultsopposite angles sum to 180° · Ptolemy: AC·BD = ac + bd · area = (1/2)(ab+cd)sinB = √[(s−a)(s−b)(s−c)(s−d)] (Brahmagupta)
circum-radius of the cyclic quadrilateralR = (1/4)√[ (ab+cd)(ac+bd)(ad+bc) / ((s−a)(s−b)(s−c)(s−d)) ]

Book Example · L-7 (theory)
Each side of a regular dodecagon (n = 12) is 20 cm. Find (i) the in-radius, (ii) the circum-radius, (iii) the area (of the dodecagon circumscribed about its incircle).
Central angle = 360°/12 = 30°. (i) Side = 2R·tan15° (R = in-radius): 20 = 2R tan15° ⇒ R = 10/(2−√3) = 10(2+√3).
(ii) Side = 2r sin15° (r = circum-radius): 20 = 2r sin15° ⇒ r = 10/sin15° = 10√2(√3+1).
(iii) Area = nR² tan(π/n) = 12·20²·tan15° = 4800(2 − √3).
In-radius = 10(2+√3) cm · Circum-radius = 10√2(√3+1) cm · Area = 4800(2 − √3) cm²
