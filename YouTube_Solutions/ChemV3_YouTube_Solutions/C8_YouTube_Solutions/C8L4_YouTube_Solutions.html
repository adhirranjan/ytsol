1 (i)True or false: For the balanced redox reaction FeCl3 + H2S → FeCl2 + HCl + S — H2S → 2H+ + S + 2e− is oxidation half reaction.Redox half reactionsHow to Balance FeCl3 + H2S = FeCl2 + HCl + S🟡 SimilarTrue
Concept An oxidation half-reaction shows loss of electrons (electrons on the product side) and a rise in oxidation number. Track sulphur through FeCl3 + H2S → FeCl2 + HCl + S to classify the half shown.
Key relation Oxidation: O.N. rises and e− are released. For S: −2 → 0, so 2e− lost. Electrons on the right-hand side define an oxidation.
Solution
1. In H2S, H is +1, so sulphur sits at −2.
2. In free sulphur (elemental S) the oxidation number is 0. Any element in its standard state is zero.
3. Sulphur goes −2 → 0, a rise of 2, so each H2S releases 2 electrons — that is an oxidation.
4. As a half-reaction: H2S → 2H+ + S + 2e−; the electrons stand on the product side, matching an oxidation.
5. Balance check: 2 H and 1 S on each side; net charge 0 = (+2) + 0 + (−2). Mass and charge both balance.
6. The partner change is Fe3+ + e− → Fe2+, so the electrons set free by sulphur are exactly what the iron accepts.
7. Electrons released ⇒ oxidation half, so the printed statement is True.
 H2S  ->  2H+  +  S  +  2e-
 S:  -2  ->  0        (loses 2 e-)
 charge:  0  =  +2 + 0 - 2      OK
 e- on PRODUCT side  ->  OXIDATION
 ----------------------------------
 statement is TRUE
⚡ JEE Trick Electrons on the right = oxidation; on the left = reduction. You never need the full balanced equation — the side the electrons land on decides it instantly, so the −2→0 jump alone proves this is oxidation.
Answer: True — H2S → 2H+ + S + 2e− is the oxidation half.

Concept A reduction half-reaction shows gain of electrons (electrons on the reactant side) and a fall in oxidation number. Here iron is tracked in FeCl3 + H2S → FeCl2 + HCl + S, where Fe3+ becomes Fe2+.
Key relation Reduction: O.N. falls and e− are consumed. For Fe: +3 → +2, so 1e− gained. Electrons on the left-hand side define a reduction.
Solution
1. In FeCl3 iron is +3; in FeCl2 iron is +2. Each Cl is −1, so Fe balances the chloride charge.
2. Iron goes +3 → +2, a fall of one unit, so each Fe3+ takes in 1 electron.
3. Gain of electrons with a drop in O.N. is, by definition, a reduction.
4. As a half-reaction: Fe3+ + e− → Fe2+; the electron sits on the reactant side, exactly as a reduction requires.
5. Charge check: left = (+3) + (−1) = +2; right = +2. Charge balances, atoms balance.
6. The matching oxidation is H2S → 2H+ + S + 2e−, which supplies the electrons this half consumes.
7. Reduction confirmed (electrons on the left, O.N. drops), so the printed statement is True.
 Fe3+  +  e-  ->  Fe2+
 Fe:  +3  ->  +2      (gains 1 e-)
 charge:  +3 - 1  =  +2        OK
 e- on REACTANT side  ->  REDUCTION
 ----------------------------------

⚡ JEE Trick “Reduction = Reduces O.N.” and the electron is a reactant. Fe3+/Fe2+ is the classic one-electron couple — it is the oxidising agent here, pairing with the H2S oxidation.
Answer: True — Fe3+ + e− → Fe2+ is the reduction half.

Concept The number of electrons exchanged in a balanced redox equation equals the total electrons lost by the oxidation half (which must equal those gained by the reduction half). Combine the two halves of FeCl3 + H2S → FeCl2 + HCl + S to count them.
Key relation electrons lost = electrons gained; H2S gives 2e−, each Fe3+ takes 1e− To balance, 2 Fe3+ are needed per S.
Solution
1. Oxidation half: H2S → 2H+ + S + 2e− (S: −2 → 0), releasing 2 electrons.
2. Reduction half: Fe3+ + e− → Fe2+, taking 1 electron each.
3. To match electrons, multiply the reduction half by 2: 2Fe3+ + 2e− → 2Fe2+.
4. Add the halves; the 2e− cancel, giving 2Fe3+ + H2S → 2Fe2+ + 2H+ + S.
5. Restoring spectator Cl−: 2FeCl3 + H2S → 2FeCl2 + 2HCl + S.
6. Sulphur loses 2 electrons; the two Fe3+ gain 1 each, so 2 are gained — the counts match.
7. Electrons traded = 2 (lost by S) = 2 (gained by the two Fe), so the statement is True.
 ox:  H2S -> 2H+ + S + 2e-        (2 e- out)
 red: 2Fe3+ + 2e- -> 2Fe2+        (2 e- in)
 ------------------------------------------
 2FeCl3 + H2S -> 2FeCl2 + 2HCl + S
 electrons exchanged  =  2        TRUE
⚡ JEE Trick The exchanged-electron count is just the LCM of the two half-reaction electron numbers (here lcm(2,1) = 2). The coefficient 2 on FeCl3 is a direct consequence — one S feeds two Fe3+.
Answer: True — exactly 2 electrons are exchanged.

Concept A reducing agent is the species that is itself oxidised (it donates electrons); the species that is reduced is the oxidising agent. Identify what happens to Fe3+ in FeCl3 + H2S → FeCl2 + HCl + S before labelling it.
Key relation reducing agent = gets oxidised (loses e−); oxidising agent = gets reduced (gains e−) The agent’s own change is opposite to its name.
Solution
1. Iron changes +3 → +2 (FeCl3 → FeCl2), a fall in oxidation number.
2. A fall in O.N. means Fe3+ gains an electron — it is being reduced.
3. The species that gets reduced is the oxidising agent (it oxidises the other partner).
4. So Fe3+ is the oxidising agent here, not the reducing agent.
5. The actual reducing agent is H2S, since sulphur is oxidised −2 → 0 and donates the electrons.
6. Put plainly: Fe3+ takes electrons from H2S, which is the job of an oxidiser, so it cannot be the reducer.
7. The claim “Fe3+ is reducing agent” is therefore False.
 Fe3+  ->  Fe2+     (+3 -> +2, gains e-)
   = REDUCED  =  OXIDISING agent
 H2S  ->  S         (-2 -> 0, loses e-)
   = OXIDISED  =  REDUCING agent
 ------------------------------------------
 "Fe3+ is reducing agent"  ->  FALSE
⚡ JEE Trick Memory hook: the agent does the opposite of its name — a reducing agent is oxidised, an oxidising agent is reduced. Fe3+ grabbing an electron makes it the oxidiser, the exact trap this statement sets.
Answer: False — Fe3+ is the oxidising agent; H2S is the reducing agent.

 H: +1 (no change)   Cl: -1 (no change)

Answer: True — H2S (its sulphur, −2 → 0) is the component oxidised.

Concept In P4 + 3NaOH + 3H2O → 3NaH2PO2 + PH3, phosphorus starts as the element (O.N. 0) and ends in two different products. If one product has P above 0 and the other below 0, the same element is both oxidised and reduced — a disproportionation.

This is the classic “volcano” demonstration and is grouped with KClO3 and NH4NO3 as intramolecular (not intermolecular) redox.
Key relation (NH4)2Cr2O7 → N2 + Cr2O3 + 4H2O N: −3→0 (up); Cr: +6→+3 (down).
Solution
1. N in NH4+ is −3, going to 0 in N2: nitrogen is oxidized ⇒ (a) true.
2. Cr in Cr2O72− is +6, going to +3 in Cr2O3: chromium is reduced ⇒ (b) true.
3. (c) Disproportionation needs one element splitting; here two different elements change, so false.
4. Both the oxidized and reduced atoms lie inside one formula unit, so this is an intramolecular redox reaction.
5. (d) labels it “intermolecular” (redox between separate molecules), which is the wrong category ⇒ strictly false.
6. By correct classification only (a) and (b) hold; the key’s (d) treats an intramolecular process as intermolecular.
