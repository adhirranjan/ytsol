Concept A square root of z is any complex number w with w² = z. Writing w = a + ib converts that single complex equation into two real equations, because two complex numbers agree only when their real and imaginary parts agree separately. A third relation comes free by taking modulus on both sides, and those facts pin a and b down completely. Every non-zero z therefore has exactly two square roots, negatives of each other.
Formula √(x + iy) = ±[√((|z|+x)/2) + i·sign(y)·√((|z|−x)/2)], with |z| = √(x²+y²). The sign(y) factor is not decoration: it records 2ab = y, so a and b share a sign when y > 0 and oppose when y < 0.
Solution
1. Put √z = a + ib, so (a + ib)² = x + iy gives a² − b² = x and 2ab = y.
2. Modulus of both sides: |a + ib|² = |z| ⟹ a² + b² = √(x²+y²) = |z|. This extra equation is what makes the system solvable without solving a quartic.
3. Adding it to a² − b² = x: 2a² = |z| + x ⟹ a = ±√((|z|+x)/2).
4. Subtracting instead: 2b² = |z| − x ⟹ b = ±√((|z|−x)/2). Both radicands are ≥ 0 because |z| ≥ |x| always.
5. The four sign combinations collapse to two, since 2ab = y forces ab to carry the sign of y.
6. Hence √(x + iy) = ±[√((|z|+x)/2) + i·sign(y)·√((|z|−x)/2)].
7. Test z = i (x = 0, y = 1, |z| = 1): ±[√(1/2) + i√(1/2)] = ±(1+i)/√2, and ((1+i)/√2)² = 2i/2 = i. ✓

Concept The argument of z is the angle the ray from the origin to the point z makes with the positive real axis, measured anticlockwise. It is fixed only up to multiples of 2π, so the principal argument is the single representative lying in (−π, π]. For z = i the point is (0, 1), sitting one unit up the imaginary axis, and the ray to it is a quarter turn from the positive real axis. That quarter turn is π/2, which already lies inside the principal range.
Formula z = x + iy = r(cos θ + i sin θ), r = |z|, cos θ = x/r, sin θ = y/r, θ ∈ (−π, π]. Using both cos θ and sin θ, not tan θ alone, is what fixes the quadrant.
Solution
1. Write i in Cartesian form: i = 0 + 1·i, so x = 0 and y = 1.
2. Modulus: r = |i| = √(0² + 1²) = √1 = 1.
3. Direction cosines: cos θ = x/r = 0/1 = 0 and sin θ = y/r = 1/1 = 1.
4. cos θ = 0 gives θ = ±π/2 in (−π, π]; sin θ = 1 keeps only θ = π/2. The sine test is what rejects −π/2, which belongs to −i.
5. Check the polar form: 1·(cos π/2 + i sin π/2) = 0 + i·1 = i. ✓
6. So arg(i) = π/2, and the general argument is π/2 + 2nπ, n ∈ ℤ. Only the n = 0 member lies in (−π, π], so it is the principal one.
7. Companion values worth storing: arg(1) = 0, arg(−1) = π, arg(−i) = −π/2.

⚡ JEE Trick The trap is computing θ = tan⁻¹(y/x), which blows up here since x = 0, and then guessing a sign. Read the axis instead: on the positive imaginary axis the argument is π/2, on the negative imaginary axis it is −π/2 (never +3π/2, which is outside the principal range). Memorising the four axis values makes powers of i instant.

Concept Multiplication of complex numbers multiplies moduli and adds arguments, because that is exactly what the polar form does to the trigonometric parts. Raising z to the n-th power is repeated multiplication by the same number, so the argument gets added to itself n times. That is De Moivre's theorem read as a statement about angles rather than about cosines. The equality holds as an equality of general arguments; a principal value may need a 2kπ shift to fall back into (−π, π].
Formula z = r(cos θ + i sin θ) ⟹ zⁿ = rⁿ(cos nθ + i sin nθ), so arg(zⁿ) = n·arg(z). Modulus and argument separate cleanly: |zⁿ| = |z|ⁿ and the angle simply scales.
Solution
1. Write z = r(cos θ + i sin θ) where r = |z| and θ = arg z.
2. Multiply z by itself: z² = r²[(cos²θ − sin²θ) + i(2 sin θ cos θ)] = r²(cos 2θ + i sin 2θ).
3. The angle doubled, so arg(z²) = 2θ = 2 arg z; repeating the step n times gives zⁿ = rⁿ(cos nθ + i sin nθ). Formally this is induction on n, the compound-angle identities supplying the step.
4. Reading off the angle: arg(zⁿ) = nθ = n·arg(z), so the required multiplier is n.
5. Check with z = 1 + i, arg z = π/4: z⁴ = ((1+i)²)² = (2i)² = −4, and arg(−4) = π = 4·(π/4). ✓
6. Now z⁶ = (2i)³ = 8i³ = −8i, whose principal argument is −π/2, while 6·(π/4) = 3π/2. 3π/2 − 2π = −π/2, so the two agree modulo 2π exactly as claimed.
7. Hence the blank is n, with the standard caveat "up to an additive multiple of 2π".

Concept Conjugation reflects a point in the real axis: (x, y) becomes (x, −y). A reflection in the real axis keeps the distance from the origin unchanged but reverses the sense of the angle, so the modulus survives while the argument changes sign. Adding the two arguments therefore cancels them. The single exception is a negative real number, which sits on the reflection axis' opposite ray and is its own conjugate.
Formula |z̄| = |z| and arg(z̄) = −arg(z), hence arg z + arg z̄ = 0. Equivalently z·z̄ = |z|² is a positive real, and a positive real has argument 0.
Solution
1. Let z = x + iy = r(cos θ + i sin θ), so r = |z| and θ = arg z.
2. Then z̄ = x − iy = r(cos θ − i sin θ) = r(cos(−θ) + i sin(−θ)), using cos(−θ) = cos θ and sin(−θ) = −sin θ.
3. Comparing with the standard polar form: |z̄| = r and arg(z̄) = −θ. The point has simply been flipped across the real axis, so the turn is the same size the other way.
4. Adding: arg z + arg z̄ = θ + (−θ) = 0, which is the required blank.
5. Check with z = 1 + i√3: arg z = π/3 and z̄ = 1 − i√3 has arg = −π/3, sum = 0. ✓
6. Cross-check by product: z·z̄ = |z|² = 4 > 0, and arg of a positive real is 0, so arg z + arg z̄ = 0. Same conclusion from the "arguments add on multiplication" rule.
7. Lone exception: z = −3 is real, z̄ = −3, and arg z + arg z̄ = π + π = 2π ≡ 0 (mod 2π). Still zero as a general argument, which is how the identity is stated.

The same mirror gives arg(z/z̄) = 2 arg z, a one-line shortcut for many objective questions.

Concept In polar form every complex number carries a size and a turn. Multiplying multiplies the sizes and adds the turns; dividing divides the sizes and subtracts the turns. So the argument behaves like a logarithm of the number: products become sums, quotients become differences, powers become multipliers. Applying that dictionary to (z₁²z₂³)/z₃ reads the coefficients straight off the exponents.
Formula arg(z₁z₂) = arg z₁ + arg z₂, arg(z₁/z₂) = arg z₁ − arg z₂, arg(zⁿ) = n arg z (all modulo 2π). These are one rule seen three ways, since a power is a repeated product and a quotient is a product with an inverse.
Solution
1. Split the quotient first: arg((z₁²z₂³)/z₃) = arg(z₁²z₂³) − arg(z₃).
2. Split the product: arg(z₁²z₂³) = arg(z₁²) + arg(z₂³).
3. Pull the exponents out: arg(z₁²) = 2 arg z₁ and arg(z₂³) = 3 arg z₂.
4. Assembling: arg((z₁²z₂³)/z₃) = 2 arg z₁ + 3 arg z₂ − 1·arg z₃, so p = 2, q = 3, r = 1. The minus sign is already built into the given form, so r is +1, not −1.

2. A positive real lies on the positive real axis, so arg|z| = 0, giving p = 0. Note |z| is real even though z is not — the modulus has already thrown the direction away.
3. Next z + z̄ = (x + iy) + (x − iy) = 2x = 2 Re(z), again a real number.

Concept A ray from the origin can be described by infinitely many angles differing by full turns, so arg(z) is not a function until we choose one representative. Solution

3. Base 1/3 < 1 makes log1/3 decreasing, so log1/3X > 1 becomes X < 1/3. Forgetting to reverse the sign is the single biggest trap in this question.
4. So (t² + 2)/(11t − 2) < 1/3; since 11t − 2 > 0 we may cross-multiply safely: 3t² + 6 < 11t − 2.
5. Rearranging, 3t² − 11t + 8 < 0, and factoring, (t − 1)(3t − 8) < 0, so 1 < t < 8/3. Roots from 3t² − 11t + 8 = 0 are t = (11 ± 5)/6 = 1 and 8/3.
6. This interval already lies inside t > 2/11, so the domain adds nothing new and the full solution is 1 < |z − 3| < 8/3.
7. Distance greater than 1 means z is outside C₁, and distance less than 8/3 means z is inside C₂. Both circles are centred at 3 + 0i, so one distance decides both.

⚡ JEE Trick The radii 1 and 8/3 in the options are the giveaway: they are precisely the roots of the quadratic you are about to form, so if your factorisation gives anything else, recheck the sign flip. Students who treat log1/3 as increasing get 3t² − 11t + 8 > 0, i.e. t < 1 or t > 8/3, and land on option (c). Also never drop the domain step — the inequality is meaningless unless 11|z − 3| − 2 is positive.
Answer: (a) z lies outside C₁ but inside C₂.
