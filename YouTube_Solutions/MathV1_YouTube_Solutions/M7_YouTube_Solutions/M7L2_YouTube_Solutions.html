1 (i)Fill in the blank: The equations N = log_a b and ______ are equivalent.Log form and exponential form equivalenceExponential and Logarithmic Form — Don't Memorise🟡 SimilaraN = b
Concept A logarithm is nothing more than a re-arranged exponent. The statement "N = log_a b" answers the question "to what power must the base a be raised to produce b?" The answer is N. So every logarithmic statement has an exactly equivalent exponential twin, and being able to flip between the two forms on sight is the single most useful skill in this whole chapter.
Formula log_a b = N ⇔ aN = b, valid for a > 0, a ≠ 1, b > 0. The base stays the base, the logarithm becomes the exponent, and the argument becomes the result.
Solution
1. Read the given statement aloud: N = log_a b says "N is the power of a that gives b."This verbal reading is the definition of the logarithm.
2. Turn that sentence directly into symbols: a raised to the power N equals b, i.e. aN = b.
3. Check the roles: a is the base in both forms; N moves from being the value of the log to being the exponent; b moves from being the argument to being the result.
4. Verify with a number: log28 = 3 ⇔ 2³ = 8 ✓.Both statements carry identical information, so they are equivalent.

 N = log_a b       <==>  a^N = b
       |  |   |            |  |  |
      val base arg       base exp result
 e.g. 3 = log_2 8   <==>  2^3 = 8
⚡ JEE Trick Memorise the circular sweep: base to the answer gives the argument — start at a, swing up to N, land on b. Every log identity in this chapter is proved by flipping to exponential form first. Trap: writing bN = a (swapping base and argument) is the single most common error — always keep the base anchored.
Answer: aN = b  (equivalently, N = log_a b ⇔ aN = b).
1 (ii)Fill in the blank: The logarithmic function can be considered as the inverse of an ______ function.Logarithm as inverse of exponentialA Logarithmic Function is the Inverse of an Exponential Function🟡 SimilarExponential
Concept Exponentiation and taking a logarithm are opposite operations: one builds a number from an exponent, the other recovers the exponent from the number. Because the exponential function y = ax is one-to-one (strictly increasing for a > 1, strictly decreasing for 0 < a < 1), it possesses an inverse — and that inverse is precisely the logarithmic function.
Formula f(x) = ax  ⇔  f−1(x) = log_a x, so that log_a(ax) = x and alog_a x = x. Composing a function with its inverse in either order returns the input untouched — that is the definition of an inverse.
Solution
1. Start from y = ax, the exponential function with base a (a > 0, a ≠ 1).
2. To invert, solve for x in terms of y: by the definition of the logarithm, x = log_a y.Reading "y = a to the power x" backwards gives "x is the log of y to base a."
3. Swap the names x and y (the standard last step in finding an inverse): y = log_a x.Interchanging the letters reflects the graph in the line y = x, which is what inversion does geometrically.
4. Hence the logarithmic function is the inverse of the exponential function.
5. Confirm the domain/range swap: ax has domain ℝ and range (0, ∞); log_a x has domain (0, ∞) and range ℝ — exactly interchanged, as inverses must be.
 function        domain      range      graph
 y = a^x         all reals   (0, inf)   passes (0,1)
 y = log_a x     (0, inf)    all reals  passes (1,0)
 --> mirror images across the line y = x
⚡ JEE Trick The inverse relationship instantly explains why log_a x needs x > 0: ax can never output a negative number or zero, so the inverse can never accept one. Use the two cancellation rules alog_a x = x and log_a(ax) = x to kill nested expressions in one stroke.
Answer: exponential  (the logarithmic function is the inverse of the exponential function).
1 (iii)Fill in the blank: The base of the logarithm 'a' must not equal ______.Restriction on the logarithm baseRestrictions on Logarithms — base cannot be negative, zero or one🟡 SimilarUnity
Concept A logarithm is only well defined when the base can produce every positive number, each in exactly one way. The base 1 fails catastrophically: 1 raised to any power is still 1. So log1b would either have no answer at all (for b ≠ 1) or infinitely many answers (for b = 1). Neither is a function, so the base 1 is banned outright.
Formula The full legality conditions are a > 0, a ≠ 1, and argument > 0. a > 0 keeps ax real for fractional x; a ≠ 1 keeps ax non-constant so the function stays one-to-one and invertible.
Solution
1. Suppose the base were a = 1 and write the definition: log1b = x means 1x = b.
2. But 1x = 1 for every real x.Multiplying 1 by itself any number of times never leaves 1.
3. Case b ≠ 1: the equation 1 = b is false, so no value of x works — the log does not exist.
4. Case b = 1: the equation 1 = 1 is true for every x — infinitely many answers, so the log is not unique.
5. Either way log1b is not a valid function, so the base must satisfy a ≠ 1.A function must return exactly one output for each input.
 base a    a^x behaviour        log_a valid?
 a > 1     strictly increasing  YES (one-to-one)
 0 < a < 1 strictly decreasing  YES (one-to-one)
 a = 1     constant, always 1   NO  (not one-to-one)
 a <= 0    not real for all x   NO
⚡ JEE Trick In any question where the base itself contains the unknown (e.g. log3x, logx−1), write the three conditions base > 0, base ≠ 1, argument > 0 before you solve. Roots that break them are extraneous and must be rejected — examiners plant them deliberately.
Answer: 1  (the base a must not equal 1; also a must be > 0).
1 (iv)Fill in the blank: The approximate value of exponential (e) is ______.Approximate value of eWhat is Number e? Euler's Number Explained🟡 Similar2.718 ⚠
Concept The number e is the natural base of exponentials and logarithms. It is an irrational (in fact transcendental) constant, so it has a non-terminating, non-repeating decimal expansion. It arises as the limit of continuously compounded growth, which is why every "natural" log (ln) uses it as its base.
Formula e = limn→∞ (1 + 1/n)n = 2.718281828…, equivalently e = 1/0! + 1/1! + 1/2! + 1/3! + …. The factorial series converges very quickly, which is how the decimal digits are actually computed.
Solution
1. Recall that e is defined by the compound-growth limit (1 + 1/n)n as n → ∞.
2. Evaluate the equivalent series 1 + 1 + 1/2 + 1/6 + 1/24 + 1/120 + …Each term is 1/k!, and the terms shrink fast, so a few terms already pin down the value.
3. Add: 1 + 1 = 2; + 0.5 = 2.5; + 0.1667 = 2.6667; + 0.0417 = 2.7083; + 0.0083 = 2.7167; + 0.0014 = 2.7181…
4. The value settles at e ≈ 2.718 (commonly quoted as 2.72 to two decimal places).

3 (ii)If log(1+x)−log(1−x)=log(x+3)−log(4−x), x<1, then the value of x is p×q/r. Find p, q, r.Log equation from difference of logsSolving Logarithmic Equations — Equations with Log(x)🟡 Similarp = −1, q = 1, r = 5
Concept Both sides are a difference of two logs, which the quotient rule turns into a single log of a fraction. Once each side is one logarithm with the same base, the logs can be stripped off (because log is one-to-one) leaving an ordinary algebraic equation. The pleasant surprise here: the x² terms cancel, so a seemingly quadratic problem collapses to a linear one.
Formula log M − log N = log(M/N); and log A = log B ⇒ A = B (log is injective). Every argument must stay positive, so the domain must be checked at the end.
Solution
1. Apply the quotient rule to the left side: log(1+x) − log(1−x) = log[(1+x)/(1−x)].
2. Apply it to the right side too: log(x+3) − log(4−x) = log[(x+3)/(4−x)].
3. Equate and drop the logs: (1+x)/(1−x) = (x+3)/(4−x).log is one-to-one, so equal logs force equal arguments.
4. Cross-multiply: (1+x)(4−x) = (x+3)(1−x).
5. Expand the left: 4 − x + 4x − x² = 4 + 3x − x².
6. Expand the right: x − x² + 3 − 3x = 3 − 2x − x².
7. Set equal: 4 + 3x − x² = 3 − 2x − x². The −x² cancels from both sides.This is the key simplification — the equation is only linear.
8. Solve: 4 + 3x = 3 − 2x ⇒ 5x = −1 ⇒ x = −1/5.
9. Check the domain: 1+x = 4/5 > 0, 1−x = 6/5 > 0, x+3 = 14/5 > 0, 4−x = 21/5 > 0, and x < 1 ✓ — all four arguments positive, so the root is genuine.
10. Compare with the stated form x = p × q/r: with p = −1, q = 1, r = 5 we get −1 × 1/5 = −1/5 ✓.
 (1+x)/(1-x) = (x+3)/(4-x)
 (1+x)(4-x)  = (x+3)(1-x)
 4 + 3x - x^2 = 3 - 2x - x^2      <-- x^2 cancels
 4 + 3x = 3 - 2x
 5x = -1   ->  x = -1/5
 check: all of 1+x, 1-x, x+3, 4-x are > 0  OK
⚡ JEE Trick When both sides are log-differences, go straight to "fraction = fraction" and cross-multiply — never expand logs into decimals. Watch for the x² terms cancelling: two products of the form (linear)(linear) with opposite x² signs almost always collapse to a linear equation, which is the examiner's whole point.
Answer: x = −1/5  (p = −1, q = 1, r = 5).

10Passage: Let a in (0,1); f(x)=log_a(x−1) (domain x>1) and g(x)=a^(x−2). The number of real intersections of f and g is: (a) 0 (b) 1 (c) 2 (d) Infinitely manyIntersections of log and exponential curvesPoint of Intersection of Logarithmic Functions🟡 Similarb1
Concept A passage-based question about how many times the shifted curves f(x) = log_a(x−1) and g(x) = ax−2 cross, for a base in (0,1). Both functions are decreasing, so monotonicity alone will not settle the count — instead we examine the difference h = f − g at the two ends of the domain. It runs from +∞ down to −∞, so by the Intermediate Value Theorem it must cross zero, and the crossing turns out to be unique.
Formula For 0 < a < 1: log_a(t) → +∞ as t → 0⁺ and log_a(t) → −∞ as t → ∞; as > 0 always, decreasing in s. IVT: a continuous h with h > 0 somewhere and h < 0 elsewhere must vanish in between. The domain is x > 1, since log_a(x−1) needs a positive argument.
Solution
1. Fix the domain: f(x) = log_a(x−1) requires x − 1 > 0, so x > 1. g is defined everywhere.
2. Behaviour of f near the left end. As x → 1⁺, the argument x − 1 → 0⁺; since 0 < a < 1, log_a of a tiny positive number is large and positive, so f → +∞.Base below 1 means the log is decreasing, blowing up to +∞ as the argument shrinks to 0.
3. Behaviour of f at the right end. As x → ∞, x − 1 → ∞, so f → −∞ (decreasing log).
4. Behaviour of g. As x → 1⁺, g → a−1 = 1/a, a finite number greater than 1. As x → ∞, g = ax−2 → 0⁺ (decreasing exponential with base < 1).
5. Form the difference h(x) = f(x) − g(x), continuous on (1, ∞).
6. Near x = 1⁺: h → +∞ − (1/a) = +∞, so h is positive there.An infinite term dominates the finite 1/a.
7. As x → ∞: h → −∞ − 0 = −∞, so h is negative far out.
8. By the Intermediate Value Theorem, h vanishes at least once ⇒ at least one intersection exists.A continuous function passing from positive to negative must hit zero.
9. Verify the count concretely with a = 1/2. Compute h at several points:
  • x = 1.2: f = log0.5(0.2) = 2.322, g = 0.5−0.8 = 1.741 ⇒ h = +0.581
  • x = 1.3: f = 1.737, g = 0.5−0.7 = 1.625 ⇒ h = +0.112
  • x = 1.35: f = 1.515, g = 0.5−0.65 = 1.569 ⇒ h = −0.054 ← sign change, root near x ≈ 1.32
  • x = 1.5: f = 1.000, g = 1.414 ⇒ h = −0.414
  • x = 3.0: f = −1.000, g = 0.500 ⇒ h = −1.500
10. After the single sign change near x ≈ 1.32, h stays negative and keeps falling — f plunges to −∞ while g decays to 0, so the gap only widens.No second sign change can occur, so no second crossing.
11. Therefore the curves meet exactly once — option (b) 1.

⚡ JEE Trick For "how many intersections" questions, never try to solve f(x) = g(x) — it is usually transcendental and has no closed form. Instead build h = f − g, evaluate its limits at the ends of the domain, and apply the IVT.
