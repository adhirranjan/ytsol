1Maximum number of rectangular components into which a vector can be split in space? (a) 2 (b) 3 (c) 4 (d) Infinite — [Level-1]Resolution of vectorsResolution of Vectors — rectangular components (Class 11) · Rectangular components of a vector in a plane🟡 Similarb3
Concept "Rectangular components" means components taken along mutually perpendicular axes. The question asks for the maximum number of such components a vector can be split into in space (3-D), not in a plane. The answer is fixed by geometry, not by the vector: space has exactly three mutually perpendicular directions (x, y, z). You cannot draw a fourth line through a point that is simultaneously perpendicular to all three — so three is the ceiling.
Formula In 3-D, A = Axî + Ayĵ + Azk̂ with Ax = A cosα, Ay = A cosβ, Az = A cosγ and the constraint cos²α + cos²β + cos²γ = 1. Each component carries the same unit as the vector itself (e.g. if A is a force in N, every component is in N) — resolving never changes the physical dimension. The number of terms equals the dimension of the space = 3.
Solution
1. Ask what "rectangular" demands: every pair of axes must be at 90° to each other.This is what makes the components independent — one component's value never leaks into another.
2. Count how many mutually perpendicular directions exist through a point in space: x ⊥ y, y ⊥ z, z ⊥ x — that is 3 directions.
3. Attempt a 4th: any new direction û in space can be written as û = aî + bĵ + ck̂. For û ⊥ î, ĵ and k̂ we need a = 0, b = 0, c = 0, i.e. û = 0 — not a direction at all.So a 4th mutually perpendicular axis is mathematically impossible in 3-D space.
4. Therefore the maximum number of rectangular components in space = 3 → option (b).
5. Sanity check with the identity: A² = Ax² + Ay² + Az² needs exactly 3 squared terms to reproduce the magnitude in 3-D.

 a line (1-D) x                                1
 a plane (2-D) x, y                            2
 space  (3-D) x, y, z                          3   <-- ANSWER (b)
 4th axis?    must satisfy u.i = u.j = u.k = 0  => u = 0  (impossible)

The number of rectangular components is capped at the dimension; only non-rectangular (oblique) components can be infinite in number — that is why "Infinite" is a distractor here, not the answer.
Answer: (b) 3.
2(Matrix Match) (u+v)+w = u+(v+w); u+0 = u; u+v = v+u; closed polygon sum = 0 ↔ commutative / associative / additive identity / polygon law — [Level-2]Properties of vector additionThe associative law of vector addition explained · Polygon law of vector addition (Class 11)🟡 SimilaraP-2, Q-3, R-1, S-4
Concept Vector addition obeys the same structural laws as ordinary number addition, and each law has a standard name. This matrix-match tests whether you can attach the right name to the right equation by inspecting what the equation actually changes: brackets moved (associative), zero added (identity), order swapped (commutative), or a closed figure summing to nothing (polygon law).
Formula The four statements: (u+v)+w = u+(v+w) — associative; u + 0 = u — additive identity (0 is the null vector, magnitude 0, no direction); u + v = v + u — commutative; closed polygon ⇒ Σ = 0 — polygon law of vector addition. All four are dimensionally trivial — every term is the same kind of vector (all displacements, or all forces), so units match automatically on both sides.
Solution
1. P: (u+v)+w = u+(v+w) — the order of the vectors is unchanged; only the grouping (brackets) moved. Regrouping ⇒ associative property = Column-II item 2.Head-to-tail construction reaches the same terminal point regardless of which pair you join first.
2. Q: u + 0 = u — adding the null vector leaves u untouched, so 0 is the element that "does nothing" ⇒ additive identity = item 3.
3. R: u + v = v + u — the order is swapped and the result is unchanged ⇒ commutative property = item 1.This is the parallelogram law: both routes around the parallelogram end at the same corner.
4. S: closed polygon sum = 0 — if vectors placed head-to-tail close the figure, the tail of the first meets the head of the last, so the net displacement is zero ⇒ polygon law (closure) = item 4.
5. Assemble the pairing: P-2, Q-3, R-1, S-4 — this is option (a).

 Q. u + 0 = u                      added null vector    additive identity  3

3Child pulls a rope attached to a stone with 60 N at 37° to the ground: (a) effective pull along ground (b) force tending to lift the stone — [Level-3]Resolution of a forceChild pulls a rope attached to a stone with a force of 80 N…🟡 Similar (80 N version, same method)(a) 48 N (b) 36 N
Concept A single slanted pull does two jobs at once: part of it drags the stone forward along the ground, and part of it tries to lift the stone off the ground. Resolving the 60 N force into rectangular components along the ground (horizontal) and perpendicular to it (vertical) separates these two effects so each can be answered independently. This is the whole point of resolution: one awkward slanted vector becomes two convenient perpendicular ones that do not interfere with each other.
Formula For a force F at angle θ to the horizontal ground: Fhorizontal = F cos θ and Fvertical = F sin θ, both in newton (N). cos θ goes with the component adjacent to the angle (along the ground, since θ is measured from the ground) and sin θ with the opposite one (perpendicular to the ground). Data: F = 60 N, θ = 37°, with the standard 37°–53° values sin 37° = 0.6, cos 37° = 0.8.
Solution
1. Draw the rope force F = 60 N acting at θ = 37° above the ground and drop a perpendicular to the ground to form the right triangle.The angle is given to the ground, so the ground-hugging component is the adjacent side ⇒ cos.
2. (a) Effective pull along the ground = F cos θ = 60 N × cos 37° = 60 N × 0.8 = 48 N.Only this part tends to slide the stone forward; N × (pure number) = N, so the unit is correct.
3. (b) Force tending to lift the stone = F sin θ = 60 N × sin 37° = 60 N × 0.6 = 36 N.This part acts upward, reducing the normal reaction from the ground rather than moving the stone forward.
4. Check the components reconstruct the original force: √(48² + 36²) N = √(2304 + 1296) N = √3600 N = 60 N ✓ — equal to the applied 60 N, as it must be.
5. Check the direction too: tan θ = 36 N ÷ 48 N = 0.75 ⇒ θ = 37° ✓ — matches the given angle.

4Four co-planar concurrent forces (√3 N, 1 N, 2 N and P at θ) keep a body in equilibrium; find P and θ — [Level-4]Equilibrium of concurrent forcesFour co-planar concurrent forces in equilibrium — find P and θ🟢 ExactbP = 2 N, θ = 90°
Concept A body under several concurrent forces is in equilibrium only when their vector sum is zero, i.e. ΣFx = 0 and ΣFy = 0 hold separately. The unknown fourth force P is therefore the equilibrant: equal in magnitude and exactly opposite in direction to the resultant of the other three. So the plan is simply — resolve √3 N, 1 N and 2 N into components, add them, and P reverses that sum.
Formula Px = −Σ(known Fx), Py = −Σ(known Fy), then P = √(Px² + Py²) and θ = tan⁻¹(Py/Px). Every term is in newton, so components add newton-to-newton. Geometry from the figure: √3 N along +x (0°), 1 N along +y (90°), 2 N at 150°.
Solution
1. Resolve √3 N at 0°: Fx = √3 N, Fy = 0.
2. Resolve 1 N at 90°: Fx = 0, Fy = 1 N.
3. Resolve 2 N at 150°: Fx = 2 cos150° = 2(−√3/2) = −√3 N; Fy = 2 sin150° = 2(½) = 1 N.150° sits in the second quadrant, so its x-part is negative and cancels the √3 N.
4. Add the three: ΣFx = √3 − √3 = 0; ΣFy = 0 + 1 + 1 = 2 N — a resultant of 2 N straight up the y-axis.
5. Equilibrant: Px = −0 = 0, Py = −2 N ⇒ P = √(0² + 2²) = 2 N, pointing straight down.
6. Direction: P lies along the y-axis, i.e. perpendicular to the x-axis ⇒ θ = 90°.

Here ΣFx collapses to 0, which is precisely why the odd magnitudes (√3, 1, 2) and 150° were chosen. 5Forces X, Y, Z of magnitudes 10 N, 5(√3−1) N, 5(√3+1) N; Y and Z act in the same direction; resultant of X & Y equals resultant of X & Z in magnitude — find θ between X and Y — [Level-5]Resultant of two vectors at an angleForces X, Y and Z have magnitudes 10N, 5(sqrt(3)-1) N and 5(sqrt(3)+1) N, respectively🟢 Exact150°
Concept Y and Z point along the same direction, so each of them makes the same angle θ with X. We are told the two resultants |X+Y| and |X+Z| are equal in magnitude even though Y and Z have different magnitudes. Squaring the parallelogram-law expression turns this statement into an algebraic equation in cos θ; the difference of two squares then collapses, and θ falls out. The physical message: a longer vector can produce the same resultant as a shorter one only if the angle is obtuse, so that the extra length partly cancels X.
Formula Parallelogram law: |X+Y|² = X² + Y² + 2XY cos θ, all terms in N². Since Y and Z are parallel, the angle between X and Z is the same θ as between X and Y — this is the key that makes the two equations comparable. Data: X = 10 N, Y = 5(√3−1) N, Z = 5(√3+1) N.
Solution
1. Write both resultants with the same angle θ (legitimate because Y ∥ Z):|X+Y|² = X² + Y² + 2XY cos θ and |X+Z|² = X² + Z² + 2XZ cos θ.
2. Set them equal, as the problem states: X² + Y² + 2XY cos θ = X² + Z² + 2XZ cos θ.
3. Cancel X² from both sides and collect: Y² − Z² = 2X cos θ (Z − Y).All terms are in N², so the equation is dimensionally consistent.
4. Factorise the left side as a difference of squares: (Y − Z)(Y + Z) = 2X cos θ (Z − Y) = −2X cos θ (Y − Z).
5. Divide both sides by (Y − Z), which is non-zero since Y ≠ Z: Y + Z = −2X cos θ, i.e. cos θ = −(Y + Z) / (2X).
6. Substitute the magnitudes with units: Y + Z = 5(√3−1) N + 5(√3+1) N = 5√3 N − 5 N + 5√3 N + 5 N = 10√3 N.The ∓5 N terms cancel exactly — this is why the odd-looking magnitudes were chosen.
7. Hence cos θ = −(10√3 N) ÷ (2 × 10 N) = −10√3/20 = −√3/2 (a pure number ✓, N ÷ N cancels).
8. Therefore θ = cos⁻¹(−√3/2) = 150° (the obtuse solution in 0°–180°, matching the figure where Y leans back over the −x side).

1Explain what is resolution of vectorsResolution of vectorsResolution of Vectors — rectangular components (Class 11) · Resolution of Vectors — Class 11 Physics🟢 Exact (concept)—
Concept Resolution of a vector is the exact reverse of vector addition: replacing a single vector by two (or more) other vectors — its components — whose combined effect equals the original. Almost always the components are taken along mutually perpendicular axes (rectangular resolution), because perpendicular components are independent: what happens along x never affects what happens along y. This is what turns one awkward slanted vector into two convenient ones you can handle one axis at a time.
Formula For a vector A making angle θ with the x-axis: Ax = A cos θ, Ay = A sin θ, so A = Ax î + Ay ĵ. It is recovered by A = √(Ax² + Ay²) and θ = tan⁻¹(Ay/Ax). Each component carries the same unit as A itself — resolving a 10 N force gives components still measured in N.
Solution
1. Definition: resolution = expressing one vector as the sum of components along chosen directions that together reproduce it.
2. Drop a perpendicular from the tip of A to the x-axis; the base is Ax (adjacent to θ ⇒ cos) and the height is Ay (opposite θ ⇒ sin).The right triangle is what makes the cos/sin split exact.
3. Write the components: Ax = A cos θ along x, Ay = A sin θ along y.
4. Check reconstruction: Ax î + Ay ĵ has magnitude √(A²cos²θ + A²sin²θ) = A√(cos²θ + sin²θ) = A ✓ — the components genuinely rebuild the original.
5. Why it matters: each axis can now be analysed on its own — equilibrium, projectile motion and inclined-plane problems all reduce to two simple one-dimensional problems.
              /|
     A       / | A sinθ  (y-component)
            /  |
           / θ |
   O -----+----+------  x-axis
          A cosθ  (x-component)

   rebuild:  A = √((Acosθ)² + (Asinθ)²) = A ✓
⚡ JEE Trick The single most common error is pairing cos and sin with the wrong axis. The rule: the component adjacent to the marked angle carries cos, the one opposite carries sin — so if the angle is measured from the vertical instead of the horizontal, cos and sin swap. Always mark which axis the angle springs from before writing a single equation.
Answer: Resolution of a vector is splitting it into components (usually along perpendicular axes) that together reproduce it: Ax = A cos θ, Ay = A sin θ, with A = Ax î + Ay ĵ. (Board concept — no key value.)
2What are rectangular components of vectors? Explain their useRectangular componentsRectangular components of a vector in a plane (Class 11)🟢 Exact (concept)—
Concept Rectangular components are the components of a vector taken along mutually perpendicular axes — î, ĵ (and k̂ in space). "Rectangular" simply means the axes meet at 90°. Their special value is independence: because the axes are perpendicular, the x-component projects to zero on the y-axis and vice-versa, so the two components never interfere. That is what lets us analyse a 2-D or 3-D problem as several separate 1-D problems.
Formula In a plane A = Ax î + Ay ĵ with Ax = A cos θ, Ay = A sin θ; in space A = Ax î + Ay ĵ + Az k̂ and A = √(Ax² + Ay² + Az²). Only because the axes are perpendicular does the magnitude come from a simple sum of squares (Pythagoras) — oblique components would carry cross terms.
Solution
1. Definition: rectangular components = the projections of A onto a set of perpendicular axes; each is A times the cosine of the angle to that axis.
2. In 2-D there are two of them (A cos θ, A sin θ); in 3-D there are three, the maximum, since space has only three mutually perpendicular directions.
3. Use 1 — adding vectors: add several vectors by summing their x-components and y-components separately, then recombine — far easier than repeated parallelogram law.
4. Use 2 — independent physics: projectile motion splits into uniform horizontal + accelerated vertical; on an incline, weight splits into mg sinθ (down the slope) and mg cosθ (into the slope).
5. Use 3 — recovering the vector: magnitude from √(Ax²+Ay²) and direction from tan⁻¹(Ay/Ax) — components store the vector completely.
 axes ⊥ each other  ->  components independent
 add vectors:   Rx = ΣAx,  Ry = ΣAy,  R = √(Rx²+Ry²)
 incline:       mg -> mg sinθ (along slope) + mg cosθ (normal)
 space (max):   A = Ax î + Ay ĵ + Az k̂     (3 rectangular comps)
⚡ JEE Trick Whenever a problem mixes vectors at odd angles, resolve everything into rectangular components first — never chase parallelograms. The perpendicular axes let you add scalars along each direction and only combine at the very end. Trap: "components" in general can be along any two directions (oblique), but only rectangular ones give the clean Pythagorean magnitude and independent equations.
Answer: Rectangular components are the projections of a vector onto mutually perpendicular axes (Ax = A cos θ, Ay = A sin θ); their use is to make the two directions independent so vectors can be added component-wise and physics solved one axis at a time. (Board concept — no key value.)
3Prove that the rectangular components of two equal vectors must be equal to each otherRectangular componentsResolution of Vectors — rectangular components (Class 11)🟡 Similar—
Concept Two vectors are equal only when they have the same magnitude AND the same direction (position is irrelevant for free vectors). The claim to prove is that equality forces every rectangular component to match, one axis at a time. This matters because it is the licence for the whole component method: it guarantees that a single vector equation A = B may be replaced by the independent scalar equations Ax = Bx, Ay = By, Az = Bz — the step used in nearly every problem in this chapter.
Key relation Resolution along common axes: A = A cos θ î + A sin θ ĵ and B = B cos φ î + B sin φ ĵ. Equality of vectors means |A| = |B| and θ = φ. î and ĵ are non-collinear (linearly independent), so the only way a î + b ĵ can equal the null vector is a = 0 AND b = 0 separately — this is the engine of the proof. Components carry the same unit as the vectors (N, m, m s⁻¹ …).
Solution
1. Set up: resolve both vectors along the same pair of rectangular axes, measuring both angles from the same +x axis.Comparing components only makes sense on a shared frame — the components themselves are frame-dependent.
2. Write A = Axî + Ayĵ with Ax = A cos θ, Ay = A sin θ; and B = Bxî + Byĵ with Bx = B cos φ, By = B sin φ.
3. Method 1 (direct substitution). "A and B are equal vectors" gives two facts: magnitudes equal, A = B; and directions equal, θ = φ.
4. Then Ax = A cos θ = B cos φ = Bx (using A = B and θ = φ), and likewise Ay = A sin θ = B sin φ = By. Hence Ax = Bx and Ay = By. ∎
5. Method 2 (independence of axes). From A = B, subtract: A − B = 0 ⇒ (Ax − Bx)î + (Ay − By)ĵ = 0.
6. î and ĵ are perpendicular, hence non-collinear: no non-zero multiple of î can ever cancel a multiple of ĵ.Formally, dot the equation with î to kill the ĵ term: (Ax − Bx)(î·î) + (Ay − By)(ĵ·î) = 0 ⇒ (Ax − Bx)(1) + (Ay − By)(0) = 0.
7. Therefore Ax − Bx = 0 ⇒ Ax = Bx; dotting instead with ĵ gives Ay − By = 0 ⇒ Ay = By. In 3-D, dotting with k̂ adds Az = Bz. ∎
8. Converse (also true): if Ax = Bx and Ay = By, then |A| = √(Ax²+Ay²) = √(Bx²+By²) = |B| and tan θ = Ay/Ax = By/Bx = tan φ ⇒ A = B. So equality of vectors ⇔ equality of all components.

4Points A(2, −1, 3) and B(4, 2, 5): find vector AB (2î+3ĵ+2k̂)Vector between two pointsFinding a vector from two points (KristaKingMath) · How to find the vector between 2 points🟡 Similar—
Concept The vector AB is the displacement that carries you from point A to point B. Its components are obtained by the "head minus tail" rule: subtract the coordinates of the starting point (tail, A) from those of the finishing point (head, B). The rule follows from the triangle law applied to position vectors drawn from the origin.
Formula AB = rB − rA = (x₂−x₁)î + (y₂−y₁)ĵ + (z₂−z₁)k̂, in metre (m) if the coordinates are in metres. Derivation: OA + AB = OB (triangle law) ⇒ AB = OB − OA = rB − rA. Data: A(x₁, y₁, z₁) = (2, −1, 3) and B(x₂, y₂, z₂) = (4, 2, 5).

2. Apply the triangle law at the origin: OA + AB = OB, so AB = OB − OA = rB − rA — head minus tail.
3. Subtract component-by-component (never mix axes):
  • x: x₂ − x₁ = 4 − 2 = 2
  • y: y₂ − y₁ = 2 − (−1) = 2 + 1 = 3Subtracting a negative adds — the commonest slip in this problem.
  • z: z₂ − z₁ = 5 − 3 = 2

2. Check (a). The angle α between R and A satisfies tan α = |Ry| / Rx = B sin θ / (A − B cos θ) — exactly statement (a) ✓ correct.Rx is the component along A and |Ry| the one perpendicular to it, so their ratio is tan α by definition.
3. Check (b). Rewrite R = A + (−B) and measure from −B. Using the formula with X = (−B) (magnitude B), Y = A and φ = angle(−B, A) = 180° − θ:tan β = A sin(180° − θ) / (B + A cos(180° − θ)) = A sin θ / (B − A cos θ) — exactly statement (b) ✓ correct.
4. Check (c): "if θ = 0, then α = 0 when A > B". Substitute θ = 0 into (a): tan α = B sin 0 / (A − B cos 0) = 0 / (A − B) = 0.
5. Interpret the sign: if A > B the denominator (A − B) is positive, so R = (A − B, 0) points along +A ⇒ α = 0 ✓ correct. (Had A < B, the denominator would be negative, R would point along −A, and α = 180° — which is why the condition A > B is genuinely needed in (c).)
6. Check (d): "if θ = π, then α = 0 when A > B". Substitute θ = π into (a): tan α = B sin π / (A − B cos π) = 0 / (A + B) = 0.
7. Here the denominator (A + B) is always positive, so R = (A + B, 0) points along +A and α = 0 regardless of whether A > B. The statement "α = 0 when A > B" is therefore a true claim ✓ correct — though the condition A > B is unnecessary, since α = 0 holds for all A and B.Physically: at θ = π, B is antiparallel to A, so −B is parallel to A and R = A + (−B) has magnitude A + B pointing along A.
8. So all four statements (a), (b), (c) and (d) are correct as printed, with the caveat that (d)'s condition "A > B" is redundant rather than wrong.

The two results are mirror images: tan α = B sinθ/(A − B cosθ) from A, and tan β = A sinθ/(B − A cosθ) from −B — just swap A ↔ B. For special-case statements, always check the sign of the denominator, not just the numerator: at θ = 0 the numerator vanishes either way, but only A > B keeps A − B cos0 positive and hence α = 0 (otherwise α = 180°). That sign is precisely what (c) is testing. Note the contrast in (d): at θ = π the denominator A + B is positive unconditionally, so α = 0 always — making the "A > B" clause true but superfluous.
