8If a, b, c, d and p are distinct real numbers such that (a^2 + b^2 + c^2)x^2 - 2x(ab + bc + cd) + (b^2 + c^2 + d^2) ≤ 0 then a, b, c, d satisfy: (a) AP (b) GP (c) HP (d) ab = cdSign of a quadraticIf a, b, c, d and p are distinct real numbers such🟢 ExactbG.P.
Concept A quadratic in x with a positive leading coefficient can only be ≤ 0 on a bounded interval, and if it is asserted to be ≤ 0 for a particular real p the discriminant must be ≥ 0. But the far cleaner route is to recognise the whole left side as a sum of three perfect squares. A sum of real squares is never negative, so ≤ 0 forces every square to vanish simultaneously, and that gives three equations linking a, b, c, d. Recognising the square-sum pattern is the entire problem.
Formula (ax − b)² + (bx − c)² + (cx − d)² = (a²+b²+c²)x² − 2(ab+bc+cd)x + (b²+c²+d²). Expanding the right-hand grouping reproduces the printed trinomial term for term, so the identity is exact, not an estimate.
Solution
1. Expand the candidate identity: (ax−b)² = a²x² − 2abx + b², (bx−c)² = b²x² − 2bcx + c², (cx−d)² = c²x² − 2cdx + d².
2. Adding gives exactly (a²+b²+c²)x² − 2(ab+bc+cd)x + (b²+c²+d²), the printed expression.
3. At x = p the hypothesis says this sum of three real squares is ≤ 0. Each square is ≥ 0, so their sum is ≥ 0; combined with ≤ 0 the sum must be exactly 0.
4. A sum of squares vanishes only if each term vanishes: ap = b, bp = c, cp = d. This is where “real numbers” in the stem is essential — over the complexes a sum of squares can be zero without each term being zero.
5. Therefore b/a = c/b = d/c = p, a single common ratio for consecutive terms. a, b, c are non-zero here since a = 0 would force b = c = d = 0 and destroy the “distinct” hypothesis.
6. Constant ratio between consecutive terms is precisely the definition of a geometric progression, so a, b, c, d are in G.P. with common ratio p.
  f(x) = (a^2+b^2+c^2)x^2 - 2(ab+bc+cd)x + (b^2+c^2+d^2)
  f(x) = (ax - b)^2 + (bx - c)^2 + (cx - d)^2
  f(p) <= 0  and  f(p) >= 0   =>   f(p) = 0
  ap - b = 0 , bp - c = 0 , cp - d = 0
  b/a = c/b = d/c = p
  a, b, c, d  =  a, ap, ap^2, ap^3   ->  G.P.

The discriminant route also works (D ≤ 0 forces D = 0 and the same ratios) but takes far longer. Concept Whenever the coefficients of a quadratic add to zero, x = 1 is a root: here λ − (λ + 3) + 3 = 0, so the equation factors on sight as (x − 1)(λx − 3) = 0. That converts a symmetric-function problem into an explicit pair of roots, 1 and 3/λ. The condition 1/α − 1/β = 1/3 is not symmetric — it is antisymmetric in α and β — so the ordering α < β genuinely matters and both assignments must be examined. Each surviving assignment contributes one value of λ, and the question asks for their sum.
Formula 1/α − 1/β = (β − α)/(αβ). Sum of coefficients zero ⇒ x = 1 is a root, which beats the quadratic formula here; also λ ≠ 0 or the equation is not quadratic.
Solution
1. λ − (λ + 3) + 3 = 0, so x = 1 is a root and λx² − (λ + 3)x + 3 = (x − 1)(λx − 3); the roots are 1 and 3/λ, λ ≠ 0.
2. Case A: α = 1, β = 3/λ with 3/λ > 1. Then 1/α − 1/β = 1 − λ/3 = 1/3 ⇒ λ/3 = 2/3 ⇒ λ = 2. Check 3/λ = 3/2 > 1, so the ordering α < β is respected.
3. Case B: α = 3/λ, β = 1 with 3/λ < 1. Then 1/α − 1/β = λ/3 − 1 = 1/3 ⇒ λ/3 = 4/3 ⇒ λ = 4.
4. Check Case B ordering: 3/λ = 3/4 < 1 ✔, so λ = 4 is admissible too. Both cases must be tested precisely because 1/α − 1/β changes sign when α and β swap.
5. Verify λ = 2: 2x² − 5x + 3 = 0 gives roots 1 and 3/2, and 1/1 − 2/3 = 1/3 ✔.
6. Verify λ = 4: 4x² − 7x + 3 = 0 gives roots 3/4 and 1, and 4/3 − 1 = 1/3 ✔.
7. Both roots are real and distinct in each case (3/λ ≠ 1), so the sum of all possible λ is 2 + 4 = 6.

Concept The condition is a closure statement: the map α ↦ α² − 2 must send the root set of x² + ax + b = 0 back into itself.
