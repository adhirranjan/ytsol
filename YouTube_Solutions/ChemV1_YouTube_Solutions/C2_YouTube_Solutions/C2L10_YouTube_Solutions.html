1Maximum number of electrons that can occupy a 2p subshellSubshell capacity (4ℓ+2)A-SHELLCAP🟡 Similarc6
Concept The number of electrons a subshell can hold is fixed by two things only: how many orbitals it contains and Pauli's limit of 2 electrons per orbital. A p subshell always has three orbitals (px, py, pz), so its capacity is the same in every shell — the "2" in 2p (the principal number n) tells you which shell, not how many electrons fit.
Formula capacity = 2 × (2ℓ + 1) = 4ℓ + 2. Here ℓ is the azimuthal quantum number (s=0, p=1, d=2, f=3), (2ℓ+1) is the orbital count, and ×2 is Pauli's two-per-orbital limit. For p, ℓ = 1, so 2ℓ+1 = 3 orbitals and 4ℓ+2 = 6 electrons.
Solution
1. Identify the subshell: "p" means azimuthal quantum number ℓ = 1.The letter, not the digit 2, sets ℓ.
2. Count its orbitals: number = 2ℓ + 1 = 2(1) + 1 = 3 (px, py, pz).
3. Apply Pauli: each orbital holds 2 electrons, so 3 × 2 = 6.
4. The n = 2 label does not enter — every p subshell (2p, 3p, 4p …) holds 6.
 subshell  ℓ   orbitals (2ℓ+1)   electrons (4ℓ+2)
 s         0   1                 2
 p         1   3                 6   <-- this question
 d         2   5                 10
 f         3   7                 14
⚡ JEE Trick Memorise the subshell capacities s 2, p 6, d 10, f 14 — they never change with n. Trap: the "2" in 2p is the shell number, not a hint that only 2 electrons fit.
Answer: (c) 6.

3Unpaired electrons in ground-state N (Z=7)Hund's rule / unpaired e⁻Nitrogen atom has 3 unpaired electrons in its ground state - explained🟢 Exactc3
Concept To count unpaired electrons you write the ground-state configuration and then fill the outermost partly-filled subshell by Hund's rule: electrons occupy each degenerate orbital singly, all with parallel spin, before any pairing begins. Nitrogen's three 2p electrons therefore spread one-to-an-orbital and stay unpaired.
Formula ground config of N (Z=7) = 1s² 2s² 2p³. Fill in energy order 1s→2s→2p; 2 + 2 + 3 = 7 electrons. Unpaired count = number of singly-occupied orbitals after Hund filling.
Solution
1. Distribute 7 electrons: 1s² (2), 2s² (2), leaving 3 for 2p → 2p³.
2. The 2p subshell has 3 orbitals; by Hund's rule the 3 electrons go one into each, all spins parallel.
3. Every 2p orbital is singly occupied, so all 3 are unpaired (the 1s and 2s pairs are fully paired).
 2p:   ↑ | ↑ | ↑        3 orbitals, each singly filled  ⇒  3 unpaired
⚡ JEE Trick A half-filled subshell (p³, d⁵, f⁷) has the maximum unpaired electrons = number of orbitals (3, 5, 7). Trap: don't pair the 2p³ electrons — Hund forbids pairing until every orbital has one.
Answer: (c) 3.

Concept There are two different "orders" for the 4s and 3d orbitals: the order they are filled (4s before 3d, lower n+ℓ) and the order they are emptied when an ion forms. Once both are occupied, 4s actually lies slightly higher in energy, and the outermost shell (largest n) is stripped first — so 4s electrons leave before 3d when a cation forms.
Formula neutral Ti (Z=22) = [Ar] 3d² 4s²; ionisation removes electrons from the highest-n shell first (4s before 3d). The 4s electrons are in shell n=4, outermost and most shielded, so they are the easiest to remove.
Solution
1. Write neutral Ti: 22 electrons = [Ar] 3d² 4s².
2. To make Ti²⁺, remove 2 electrons; take them from the outermost shell, n = 4, i.e. the 4s.
3. Result: Ti²⁺ = [Ar] 3d² (both 4s electrons gone, 3d untouched).
4. Hence the subshell that loses electrons first is 4s — option (c).
 species   configuration        electrons removed
 Ti        [Ar] 3d² 4s²          —
 Ti²⁺      [Ar] 3d²              2 × 4s  (4s emptied first)
⚡ JEE Trick "Fill 4s first, but remove 4s first too" — for any transition-metal cation, strip ns before (n−1)d. Trap: don't remove 3d electrons for Ti²⁺; the 3d² stays and it is the 4s² that goes.
Answer: (c) 4s.

Concept Three configurations are compared: I = 3p³, II = 3p⁴, III = 3p⁵. Filling the three 3p orbitals by Hund's rule (singly first, then pair) fixes the unpaired-electron count, the number of parallel-spin (exchange) interactions, and how symmetric the electron cloud is. The half-filled case (p³) is the most symmetric and most exchange-stabilised; each electron added beyond it must pair up, lowering both the unpaired count and the symmetry.

1. Draw the orbital diagrams:
 I   3p³:  ↑  | ↑  | ↑        3 unpaired,  spins ↑↑↑

1Explain de Broglie's equation (relationship)de Broglie equationA-DEBROGLIE🟡 Similar—
Concept Louis de Broglie proposed that matter, like light, has a dual nature: every moving particle has an associated wave. The faster and heavier the particle, the shorter its wavelength — which is why wave character is obvious for electrons but utterly negligible for a cricket ball. The relation ties a particle property (momentum) to a wave property (wavelength) through Planck's constant.
Key relation λ = h ÷ p = h ÷ (m v), where λ = wavelength (m), h = Planck's constant = 6.626×10⁻³⁴ J s, p = momentum, m = mass (kg), v = speed (m s⁻¹). λ is inversely proportional to momentum: large mass or speed ⇒ tiny, unobservable wavelength.
Solution
1. Photon analogy: for light E = hν and E = mc², so combining gives momentum p = h/λ.This suggested wavelength and momentum are linked by h for any particle.
2. de Broglie generalised p = h/λ to all matter, giving λ = h/p = h/mv.
3. Estimate for an electron (m = 9.1×10⁻³¹ kg, v = 10⁶ m s⁻¹): λ = 6.626×10⁻³⁴ ÷ (9.1×10⁻³¹ × 10⁶) ≈ 7×10⁻¹⁰ m — atom-sized, hence detectable.
4. For a 0.1 kg ball at 10 m s⁻¹: λ ≈ 6.6×10⁻³⁴ m — immeasurably small, so no wave behaviour is seen.
 object        m (kg)        v (m/s)   λ = h/mv
 electron      9.1×10⁻³¹     10⁶       ~7×10⁻¹⁰ m   (significant)
 cricket ball  0.1           10        ~7×10⁻³⁴ m   (negligible)
⚡ JEE Trick λ = h/mv — wavelength is inversely proportional to mass and speed, so only light, fast particles (electrons) show wave nature. Trap: if kinetic energy is given use λ = h/√(2m·KE); for a charge accelerated through V, λ = h/√(2mqV).
Key point: de Broglie's equation λ = h/mv assigns a wavelength to every moving particle, expressing the wave–particle duality of matter; the wave nature is significant only for very small masses.

4Explain the Aufbau principleAufbau principleA-AUFBAU🟡 Similar—
Concept The Aufbau ("building-up") principle tells us the order in which electrons occupy orbitals in a ground-state atom: they enter the lowest-energy orbital available first, filling upward one orbital at a time. Because 4s lies below 3d in energy, the sequence is not simply by shell number — it follows increasing orbital energy, which the (n+ℓ) rule captures.
Key relation fill in order of increasing (n + ℓ); if equal, lower n first. Orbital energy rises with n+ℓ; a tie is broken by the smaller principal quantum number. This gives 1s 2s 2p 3s 3p 4s 3d 4p 5s …
Solution
1. List candidate orbitals and their n+ℓ: 4s → 4+0 = 4; 3d → 3+2 = 5.Lower n+ℓ means lower energy, so 4s (4) fills before 3d (5).
2. When two orbitals tie on n+ℓ (e.g. 3d = 5 and 4p = 5), the one with smaller n fills first (3d before 4p).
3. Applying the rule end to end gives the filling sequence 1s 2s 2p 3s 3p 4s 3d 4p 5s 4d 5p 6s …
4. Example — Sc (Z=21): fill to 1s²2s²2p⁶3s²3p⁶4s²3d¹, exactly following this order.
 orbital  n   ℓ   n+ℓ   fills…
 4s       4   0   4     before 3d
 3d       3   2   5     after 4s
 4p       4   1   5     after 3d (tie broken by lower n)
⚡ JEE Trick Use the (n+ℓ) rule: smaller n+ℓ fills first; equal n+ℓ → smaller n first. Trap: Cr and Cu break Aufbau (3d⁵4s¹, 3d¹⁰4s¹) for extra half/fully-filled stability — the principle has famous exceptions.
Key point: the Aufbau principle fills orbitals in order of increasing energy, given by increasing (n+ℓ) with ties resolved by lower n, producing the sequence 1s 2s 2p 3s 3p 4s 3d …

Concept The rule that dictates the sequence in which orbitals receive electrons in a ground-state atom is the Aufbau principle. Its job is different from Pauli's (which caps an orbital at 2 electrons) and Hund's (which spreads electrons within a subshell) — Aufbau alone answers "which orbital next?"

Solution
1. The question asks specifically about order of filling — that is the domain of the Aufbau principle.
2. Eliminate the others: Pauli limits electrons per orbital to 2; Hund governs spin distribution within equal-energy orbitals; neither sets the overall order.
3. Therefore the answer is the Aufbau Principle — option (c).

2Which rule states no two electrons have identical sets of quantum numbers?Pauli's exclusion principleA-PAULI🟡 SimilarcPauli’s Exclusion Principle
Concept The statement "no two electrons in an atom can have the same set of all four quantum numbers" is the definition of the Pauli exclusion principle. Its immediate consequence is that a single orbital (fixed n, ℓ, m) can hold at most two electrons, and only if they have opposite spins (ms = +½ and −½).
Formula no two electrons share (n, ℓ, m, ms). If three quantum numbers match (same orbital), the fourth (spin) must differ, allowing only two electrons per orbital.
Solution
1. The defining phrase "identical sets of quantum numbers" points directly to Pauli's principle.
2. Consequence: two electrons in one orbital already share n, ℓ, m, so their spins must be opposite — hence 2 electrons per orbital maximum.
3. Rule out others: Aufbau sets filling order, Hund sets spin alignment; neither forbids identical quantum-number sets.
4. Answer: Pauli's Exclusion Principle — option (c).
⚡ JEE Trick "Identical quantum numbers" or "max 2 e⁻ per orbital, opposite spins" ⇒ always Pauli. Trap: don't confuse with Hund (which is about parallel spins in different degenerate orbitals).
Answer: (c) Pauli’s Exclusion Principle.

Concept The maximum number of electrons a shell can hold follows directly from counting its orbitals. Shell n contains n subshells (ℓ = 0 … n−1), each subshell holds 2(2ℓ+1) electrons, and the sum over all subshells collapses to the famous 2n² rule. The trap is arithmetic haste — squaring 4 to get 8 or 16-then-doubling-wrongly — or picking a distractor like 50 that corresponds to no shell at all.
Formula Max electrons in shell n = 2n² each of the n² orbitals in shell n holds at most 2 electrons (Pauli), so capacity = 2 × n². Subshell capacities needed: s = 2, p = 6, d = 10, f = 14.
Solution
1. Identify the shell: n = 4, so the subshells present are 4s, 4p, 4d, 4f ℓ runs 0,1,2,3 — exactly n values.
2. Apply the rule directly: capacity = 2n² = 2 × 4² = 2 × 16 = 32 electrons.
3. Cross-check by adding subshells: 4s(2) + 4p(6) + 4d(10) + 4f(14) = 2 + 6 + 10 + 14 = 32 ✓ — both routes agree.
4. Sanity-check the distractor 50: 2n² = 50 would need n² = 25, i.e. n = 5. Fifty is the n = 5 capacity, not n = 4 a classic shifted-shell distractor.
5. Conclude: the n = 4 shell accommodates 32 electrons, which matches option (c) on the printed paper.

Concept Hydrogen is a one-electron atom, so there is no electron–electron repulsion to split subshells: its orbital energies depend on n alone, making all orbitals of a given shell (2s and 2p, or 3s, 3p, 3d) exactly degenerate. Solution
1. (a) In hydrogen, orbital energy depends only on n — true (one-electron atom).
2. (b) Hence all orbitals with the same n (e.g. 3s, 3p, 3d) are degenerate in H — true.
3. (c) The Aufbau (n+ℓ) order, which puts 2s below 2p, does not apply to H, so it mis-predicts H's energies — true.
