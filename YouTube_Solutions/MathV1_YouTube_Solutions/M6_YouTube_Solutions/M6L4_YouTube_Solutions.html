Formula Substitute u = x² + x; note 2x² + 2x + 9 = 2u + 9. Squaring is safe when both sides are non-negative.
Solution

2. The equation becomes √(u + 4) + √(u + 1) = √(2u + 9).

10Solve the inequation √(x² − 9x + 24) − √(6x² − 59x + 149) = |5 − x|.Radical equation involving a modulusSquare root equation — solving technique🟡 Similarx = 5
Concept Two radicals and a modulus. Both radicands have negative discriminants, so the domain is all of R; isolating and squaring once produces a "sum of non-negatives = 0" identity that pins x uniquely.
Formula Squaring A = B + C with A, B, C ≥ 0 gives A² = B² + 2BC + C²; a sum of non-negative terms is 0 only if each term is 0.
Solution
1. Domain of √(x² − 9x + 24): D = 81 − 96 = −15 < 0 with a positive leading coefficient ⇒ x² − 9x + 24 > 0 for every real x. No restriction.A negative discriminant means the parabola never touches the axis.
2. Domain of √(6x² − 59x + 149): D = 59² − 4(6)(149) = 3481 − 3576 = −95 < 0 ⇒ also always positive. Domain = R.Both radicals are defined everywhere.
3. Write A = √(x² − 9x + 24) ≥ 0, B = √(6x² − 59x + 149) ≥ 0. The equation is A − B = |5 − x|, i.e. A = B + |x − 5|.
4. All three of A, B, |x − 5| are non-negative, so square both sides: A² = B² + 2B|x − 5| + (x − 5)².Safe — both sides are already ≥ 0.
5. Substitute: x² − 9x + 24 = (6x² − 59x + 149) + 2B|x − 5| + (x² − 10x + 25).
6. Collect the polynomial parts on the left: (x² − 9x + 24) − (6x² − 59x + 149) − (x² − 10x + 25) = −6x² + 60x − 150.
7. Factor: −6x² + 60x − 150 = −6(x² − 10x + 25) = −6(x − 5)². So the equation becomes −6(x − 5)² = 2B|x − 5|.A perfect square emerges — the crux of the problem.
8. Rearrange: 2B|x − 5| + 6(x − 5)² = 0. Both terms are ≥ 0 (B ≥ 0, |x − 5| ≥ 0, (x − 5)² ≥ 0).A sum of two non-negatives equal to zero.
9. A sum of non-negatives vanishes only if every term vanishes ⇒ 6(x − 5)² = 0 ⇒ x = 5.Forced — no other real x can work.
10. Verify x = 5: x² − 9x + 24 = 25 − 45 + 24 = 4 ⇒ A = 2. 6x² − 59x + 149 = 150 − 295 + 149 = 4 ⇒ B = 2. LHS = 2 − 2 = 0; RHS = |5 − 5| = 0 ✓.Genuine, and unique.
11. Solution: x = 5 (the unique real solution).

Answer: x = 5
