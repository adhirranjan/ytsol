1Range of the basic sine function f(x)=sin xsin range = [−1,1]A-TRIG🟡 Similarc[−1, 1]
Concept The range of a function is the complete set of output values (y-values) it can actually produce as x runs over its domain. For sin x the input x is an angle, and sin x is defined as the y-coordinate of the point where that angle meets the unit circle (radius 1). Since that point can never leave the circle, its height is trapped between the top and bottom of the circle — this geometric fact is what pins the range down.
Definition On the unit circle a point is (cos x, sin x) with cos²x + sin²x = 1. Because the radius is exactly 1, the vertical coordinate sin x is the signed height of that point above the x-axis. The highest the point rises is +1 (top of circle) and the lowest is −1 (bottom), and it passes through every height in between continuously.
Solution
1. Take x on the unit circle; the point is (cos x, sin x) at distance 1 from the origin.Distance 1 forces −1 ≤ sin x ≤ 1, since no coordinate of a unit-radius point can exceed the radius.
2. Maximum: at x = π/2 the point is at the top (0, 1), so sin(π/2) = +1 is reached.
3. Minimum: at x = 3π/2 (or −π/2) the point is at the bottom (0, −1), so sin = −1 is reached.
4. The curve is continuous, so every value between −1 and 1 is also attained ⇒ range = [−1, 1] (a closed interval — both ends included).
   y
  +1 |___•___           max at x=π/2
     |  /   \
   0 |•/     \•______   crosses zero at 0, π, 2π
     | \     /
  -1 |__\_•_/           min at x=3π/2
     +----------- x
   domain = R (all reals)   range = [-1, 1]
⚡ JEE Trick For any bare sinusoid y = A sin(…) + B the range is [B−|A|, B+|A|]; here A = 1, B = 0 gives [−1, 1] instantly. Trap: the domain of sin is all of R (no gaps), but the range is only the tight band [−1, 1] — never confuse the unrestricted input with the bounded output.
Answer: [−1, 1] (i.e. −1 ≤ sin x ≤ 1).
2Value of tan(π/4)+cot(π/4)Standard-angle valuesA-STDVAL🟡 Similarc2
Concept This is a standard-angle evaluation: π/4 rad = 45°, one of the handful of angles whose trig ratios you should know by heart. The key structural fact is that cot θ = 1/tan θ, so tan and cot are reciprocals — at any angle where tan θ = 1, cot θ must also equal 1, making the sum easy.
Formula tan θ = sin θ / cos θ and cot θ = cos θ / sin θ = 1/tan θ. At 45° the reference triangle is right-isosceles, so its two legs are equal and sin 45° = cos 45° = 1/√2. Standard values: tan(π/4) = 1, cot(π/4) = 1.
Solution
1. Evaluate tan(π/4): tan 45° = sin45°/cos45° = (1/√2)÷(1/√2) = 1.Equal legs make opposite/adjacent = 1.
2. Evaluate cot(π/4): cot 45° = 1/tan45° = 1/1 = 1.
3. Add: tan(π/4) + cot(π/4) = 1 + 1 = 2.
 θ = π/4 (45°):  opposite = adjacent  ⇒  tan = 1
 tan(π/4) = 1
 cot(π/4) = 1/tan(π/4) = 1
 sum      = 1 + 1 = 2
⚡ JEE Trick Whenever an expression pairs a ratio with its reciprocal at 45° (tan+cot, sin+cosec-style at special angles), spot that tan 45° = cot 45° = 1 and skip the fractions. General identity: tan θ + cot θ = 1/(sin θ cos θ) = 2/sin 2θ; at θ=π/4, sin 2θ = sin(π/2) = 1, so the sum = 2 — a fast cross-check.
Answer: 2.
3Domain of f(x)=sec xsec domainA-TRIG🟡 SimilaraAll real x except x = (2n+1)π/2, n ∈ Z
Concept The domain of a function is the set of inputs for which the output is defined. Since sec x = 1/cos x is a reciprocal, it blows up (is undefined) exactly where the denominator cos x = 0. So finding the domain of sec means listing every angle where cosine hits zero and throwing those out; everywhere else sec is perfectly fine.
Formula sec x = 1/cos x, defined ⇔ cos x ≠ 0. Division by zero is undefined, so any x making cos x = 0 must be excluded. Cosine is zero at the odd multiples of π/2: x = (2n+1)π/2, n ∈ Z (i.e. ±π/2, ±3π/2, …).
Solution
1. Write sec as a reciprocal: sec x = 1/cos x.The only trouble spots are where the bottom is zero.
2. Solve cos x = 0 ⇒ x = π/2, 3π/2, 5π/2, … = (2n+1)π/2, n ∈ Z.Cosine crosses zero once each half-turn, at every odd multiple of π/2.
3. Remove those points from the real line: domain = R \ {(2n+1)π/2 : n ∈ Z}.
4. At those excluded x the graph has vertical asymptotes (sec → ±∞); everywhere else |sec x| ≥ 1.
 cos x :  1    0    -1    0    1    0   -1 ...
 x     :  0   π/2   π   3π/2  2π  5π/2 3π
 sec x :  1   und  -1   und   1   und  -1
                ↑          ↑         ↑    asymptotes
 domain = all real x EXCEPT x = (2n+1)π/2
⚡ JEE Trick Reciprocal trig functions are undefined where their parent is zero: sec & tan die where cos = 0 (odd multiples of π/2); cosec & cot die where sin = 0 (multiples of π). Memorise the pairing and you never need to re-derive a domain. Trap: don't write "all reals" — sec has infinitely many gaps.
Answer: All real x except x = (2n+1)π/2, n ∈ Z (i.e. R \ {odd multiples of π/2}).
4Graph of y=sin x+k is obtained by shifting y=sin x by …Vertical shiftA-TRANSF🟡 SimilarbVertically by k units (up if k > 0, down if k < 0)
Concept Adding a constant outside a function — y = f(x) + k — is a vertical translation. Every output is raised (or lowered) by the same amount k, so the whole curve slides straight up or down without changing its shape, width, or period. This is the "outside affects y, vertically" rule, and it is distinct from a change inside the function argument (which would move the graph horizontally).
Rule y = f(x) + k shifts the graph of y = f(x) up by k if k > 0 and down by |k| if k < 0. For a fixed x the new height is the old height plus k, so each point (x, f(x)) moves to (x, f(x)+k) — a purely vertical move of k units. Here f(x) = sin x, so y = sin x + k is sin x lifted by k.
Solution
1. Compare y = sin x with y = sin x + k: same input x, output increased by k.Nothing inside the sin(...) changed, so no horizontal movement occurs.
2. Each point (x, sin x) maps to (x, sin x + k) — the x stays put, y goes up by k.
3. Therefore the graph is translated vertically by k units (upward when k > 0, downward when k < 0).
4. The range shifts with it: [−1, 1] → [k−1, k+1]; period (2π) and amplitude (1) are unchanged.
 y = sin x        range [-1, 1],  centre line y = 0
 y = sin x + k    range [k-1, k+1], centre line y = k
 effect: whole wave slides UP by k (k>0) — shape identical
⚡ JEE Trick "Outside the function → vertical; inside the function → horizontal." So +k outside moves up/down by k, while sin(x+k) (k inside) moves left/right. Also note outside-addition shifts the range but never the period or amplitude. Trap: sin(x+k) and sin x + k look alike but move the graph in perpendicular directions.
Answer: Vertically by k units (upward if k > 0, downward if k < 0).
5Period of f(x)=sin(3x)Period 2π/nA-TRANSF🟡 Similarb2π/3
Concept The period is the smallest horizontal distance after which a wave exactly repeats. Multiplying the input by a constant n — sin(nx) — compresses the graph horizontally by a factor n, so it completes its cycle n times faster and its period shrinks accordingly. The bigger the coefficient of x, the shorter the period.
Formula For y = sin(nx) (or cos), period T = 2π / |n|. Base sin x repeats every 2π; replacing x by nx makes the argument run through 2π while x runs through only 2π/n, so one full cycle now fits in 2π/n. Here n = 3.
Solution
1. Identify the coefficient of x inside sin: n = 3.Only the multiplier of x sets the period; the amplitude out front would not matter.
2. Apply T = 2π/|n| = 2π/3.
3. Verify by the defining property: sin(3(x + 2π/3)) = sin(3x + 2π) = sin(3x). ✓Adding 2π/3 to x adds a full 2π to the argument, returning the same value — and no smaller shift does.
 base:  sin x     → period 2π
 given: sin 3x    → period 2π/3 ≈ 2.094
 check: sin(3(x+2π/3)) = sin(3x+2π) = sin 3x  ✓
 (three full waves now fit in the old width 2π)
⚡ JEE Trick Period of sin/cos of (nx) is 2π/|n|; for tan/cot it is π/|n|. Amplitude and vertical/phase shifts never change the period — only the coefficient of x does. Trap: the answer is 2π/3, not 3·2π — a larger n means a shorter period, so you divide, never multiply.
Answer: 2π/3.

1Draw & find domain/range: (i) y=sin(2x) (ii) y=cos(2x)Period changeA-TRANSF🟡 SimilarDomain = R, Range = [−1, 1], period π (both)
Concept Both graphs are the standard sine / cosine waves with the input doubled. Doubling the argument (coefficient n = 2) halves the period — the wave is squeezed horizontally to complete two full cycles in the space the parent used for one. Crucially, multiplying the angle does not touch the output values, so amplitude, domain and range are identical to the parents; only the horizontal spacing changes.
Formulas period = 2π/|n| = 2π/2 = π; domain = R; range = [−1, 1] for both. n only compresses the x-axis; the highest/lowest heights (±1) and the fact that every real x is allowed are inherited unchanged from sin/cos.
Solution
1. (i) y = sin 2x: coefficient n = 2 ⇒ period = 2π/2 = π. Starts at 0, up to 1 at x=π/4, back to 0 at π/2, −1 at 3π/4, 0 at π.
2. (ii) y = cos 2x: period also π. Starts at 1 (x=0), 0 at π/4, −1 at π/2, 0 at 3π/4, back to 1 at π.
3. Output range unchanged: both oscillate between −1 and 1 ⇒ range = [−1, 1].The "2" is inside the function, so it cannot alter how high or low the curve reaches.
4. Every real x is valid for sin and cos ⇒ domain = R for both.

  0 |•   •   •              0 |  •   •

 -1 |      •                -1 |    •

⚡ JEE Trick A coefficient inside sin/cos changes only the period (÷n); it never changes domain (stays R) or range (stays [−1,1]). To alter the range you need a factor outside (amplitude) or an added constant. Trap: students shrink the range when they see "2x" — resist; the range stays [−1, 1].
Answer: Both — domain = R, range = [−1, 1], period = π (two cycles over [0, 2π]).
2Draw: (i) y=sin x−1 (ii) y=cos x−1Vertical shiftA-TRANSF🟡 Similar(i) centre y = −1, min −2 (ii) centre y = −1, passes (0,0)
Concept Subtracting 1 outside the trig function is a vertical translation downward by 1 unit. The wave keeps its identical shape, amplitude and period; only its centre line (the horizontal axis it oscillates about) drops from y = 0 to y = −1. Because the whole curve moves down, the range moves down by the same amount.
Rule y = f(x) − 1 ⇒ shift graph of f down by 1. Every output loses 1, so each point (x, f(x)) → (x, f(x)−1). New range = [−1−1, 1−1] = [−2, 0]; period 2π and amplitude 1 unchanged; domain = R.
Solution
1. (i) y = sin x − 1: take sin x (range [−1,1]) and drop it 1 unit ⇒ oscillates about y = −1.Max = 1−1 = 0 at x=π/2; min = −1−1 = −2 at x=3π/2.
2. (ii) y = cos x − 1: drop cos x by 1 ⇒ starts at 1−1 = 0 (x=0), reaches −2 at x=π, back to 0 at 2π.
3. Range for both: [−2, 0]; the curve never rises above 0 or falls below −2.
4. Domain = R, period = 2π, amplitude = 1 — all inherited from the parent.
 y = cos x - 1
  0 |•             •            top just touches 0
    | \           /
 -1 |  \         /              centre line y = -1
    |   \       /
 -2 |    •_____•                bottom at y = -2 (x=π)
    +--------------- x
    0   π/2  π  3π/2 2π
 shift: whole wave DOWN 1 · range [-2, 0]
⚡ JEE Trick Outside "−1" ⇒ slide down 1, so just subtract 1 from both ends of the range: [−1,1] → [−2,0]. The centre line becomes y = (constant added) = −1. Trap: vertical shift changes the range but never the period or amplitude, and it is unrelated to any horizontal move.
Answer: Both — sin x−1 and cos x−1 are the parent waves shifted down 1; domain R, range [−2, 0], period 2π.
3Draw: (i) y=sin(x+π/2) (ii) y=cos(x−π/2) (iii) y=sin(x−π/2)Phase shiftA-TRANSF🟡 Similar—
Concept Adding a constant inside the argument — sin(x + c) — is a horizontal (phase) shift. The sign is counter-intuitive: +c inside moves the graph LEFT by c, and −c inside moves it RIGHT by c. A π/2 shift is exactly a quarter-period of a sine wave, and it happens to convert sine into ±cosine, so each of these three collapses to a familiar standard curve.
Identities sin(x + π/2) = cos x; cos(x − π/2) = sin x; sin(x − π/2) = −cos x. These are the co-function / shift identities: sliding a sine left by 90° lands on cosine; sliding a cosine right by 90° lands on sine; sliding a sine right by 90° lands on the flipped cosine.
Solution
1. (i) sin(x + π/2): shift sine left by π/2 ⇒ equals cos x (starts at max 1 when x=0).Left by a quarter period turns the rising-through-zero sine into the peak-at-zero cosine.
2. (ii) cos(x − π/2): shift cosine right by π/2 ⇒ equals sin x (starts at 0, rising).
3. (iii) sin(x − π/2): shift sine right by π/2 ⇒ equals −cos x (starts at min −1 when x=0).Right by a quarter period gives cosine flipped through the x-axis.
4. All three keep domain = R, range = [−1, 1], period = 2π; only the starting phase differs.
 x            0     π/2    π    3π/2   2π
 sin(x+π/2)=  1      0    -1     0     1   (= cos x)
 cos(x-π/2)=  0      1     0    -1     0   (= sin x)
 sin(x-π/2)= -1      0     1     0    -1   (= -cos x)
 same shape, quarter-period shifts left/right
⚡ JEE Trick Inside sign is opposite to the visual move: (x+c) → left, (x−c) → right. And memorise the quarter-turn chain sin(x+π/2)=cos x, cos(x−π/2)=sin x, sin(x−π/2)=−cos x. Trap: never touch the range — phase shifts move the wave sideways only, so it stays [−1, 1].
Answer: (i) sin(x+π/2) = cos x; (ii) cos(x−π/2) = sin x; (iii) sin(x−π/2) = −cos x — all with domain R, range [−1, 1], period 2π.

1Domain of the sine functionsin domain = RA-TRIG🟡 SimilarbR (all real numbers)
Concept The domain lists every input the function accepts. sin x takes an angle as input, and any real number can serve as an angle (in radians) — you can rotate around the unit circle by any amount, positive, negative, or zero. There is no division and no even root that could break, so sin never becomes undefined; hence its domain is the whole real line.
Definition sin: R → [−1, 1], so domain = R = (−∞, ∞). Every real angle corresponds to exactly one point on the unit circle, whose y-coordinate is sin x — always defined, no exceptions.
Solution
1. Ask where sin x could fail: it is not a fraction (no zero denominator) and not a root (no negative-inside issue).Only such operations can restrict a domain; sine has neither.
2. Any real x maps to an angle and a unique unit-circle point ⇒ sin x exists for all x.
3. Therefore domain = R (all real numbers). (Contrast: the range is the bounded set [−1, 1].)
 function   domain      range
 sin x      R           [-1, 1]
 (defined for every real angle — no gaps, no asymptotes)
⚡ JEE Trick sin and cos are the only two basic trig functions with domain all of R — the other four (tan, cot, sec, cosec) have gaps where a denominator vanishes. Trap: don't answer [−1, 1] — that is the range; the domain (allowed inputs) is R.
Answer: R (all real numbers, −∞ < x < ∞).
2Range of the cosine functioncos range = [−1,1]A-TRIG🟡 Similarb[−1, 1]
Concept On the unit circle, cos x is defined as the x-coordinate of the point at angle x. Just as with sine, that point stays on a circle of radius 1, so its horizontal coordinate is boxed between −1 (leftmost) and +1 (rightmost). The output therefore sweeps the closed band [−1, 1] and nothing outside it.
Definition Point on unit circle = (cos x, sin x) with cos²x + sin²x = 1. A unit-radius point's x-coordinate cannot exceed the radius, so −1 ≤ cos x ≤ 1. Both extremes are actually reached, so the range is the closed interval.
Solution
1. cos x is the horizontal coordinate of a point 1 unit from the origin ⇒ −1 ≤ cos x ≤ 1.
2. Maximum: at x = 0 the point is (1, 0), so cos 0 = +1 is attained.
3. Minimum: at x = π the point is (−1, 0), so cos π = −1 is attained.
4. Cosine is continuous, so it also hits every value between ⇒ range = [−1, 1].
 x      0    π/2    π    3π/2   2π
 cos x  1     0    -1     0     1
 highest +1 (x=0), lowest -1 (x=π) → range [-1, 1]
⚡ JEE Trick cos has the same range as sin — [−1, 1] — because it is just sine shifted by π/2; a phase shift never changes the range. For a scaled/shifted cosine A cos x + B the range becomes [B−|A|, B+|A|]. Trap: the domain is R, the range is [−1, 1] — keep inputs and outputs distinct.
Answer: [−1, 1] (i.e. −1 ≤ cos x ≤ 1).
3Range of the tangent functiontan range = (−∞,∞)A-TRIG🟡 Similara(−∞, ∞) = R
Concept Unlike sin and cos, tan x = sin x / cos x is a ratio, and dividing a bounded quantity by one that shrinks to zero lets the result grow without limit. As x approaches an odd multiple of π/2, cos x → 0 while sin x → ±1, so tan x shoots off to ±∞. Between consecutive asymptotes tan climbs continuously from −∞ to +∞, so it attains every real value.
Formula tan x = sin x / cos x, undefined at x = (2n+1)π/2. Near those points the denominator cos x → 0 while the numerator stays near ±1, forcing the quotient toward ±∞; the graph has vertical asymptotes there. Hence range = (−∞, ∞) = R.
Solution
1. On one branch, say x ∈ (−π/2, π/2): as x → −π/2⁺, tan → −∞; as x → π/2⁻, tan → +∞.cos x → 0⁺ makes the ratio blow up, with sign set by sin x.
2. tan is continuous and strictly increasing across that branch, so by the intermediate-value property it passes through every real number once.
3. Therefore the set of outputs is all reals ⇒ range = (−∞, ∞) = R.
4. (Note: the domain is restricted, R minus the asymptotes, but the range is unrestricted.)
      |   /        /        each branch runs
  +∞  |  /        /         from -∞ up to +∞
   0 -|-•--------•--------  crossing 0 at 0, π, ...
  -∞  |/        /
      +----------------- x
     -π/2      π/2   3π/2   (asymptotes)
 range = (-∞, ∞) = R
⚡ JEE Trick tan and cot both have range all of R (unbounded), while sec and cosec have range (−∞,−1]∪[1,∞) (a forbidden middle band). Memorise this split by remembering tan/cot pass through 0, but sec/cosec never enter (−1, 1). Trap: here the domain has gaps but the range is the full real line — opposite of sin/cos.
Answer: (−∞, ∞), i.e. all real numbers R.
4Which function has undefined values at multiples of π?cot / cosecA-TRIG🟡 Similarbcot x and cosec x
Concept A trig function becomes undefined where it is a fraction with a zero denominator. Multiples of π (…, −π, 0, π, 2π, …) are exactly the angles where sin x = 0. So any function that carries sin x in its denominator will blow up there. Those are cot x and cosec x.
Formulas cot x = cos x / sin x and cosec x = 1 / sin x. Both divide by sin x, so both are undefined wherever sin x = 0, i.e. at x = nπ. By contrast tan x = sin/cos and sec x = 1/cos vanish (undefined) where cos = 0, at (2n+1)π/2 — different points.
Solution
1. Find where sin x = 0: x = 0, ±π, ±2π, … = nπ, n ∈ Z.Sine crosses zero once every half-turn, at integer multiples of π.
2. Identify functions with sin x on the bottom: cot x (cos/sin) and cosec x (1/sin).
3. At x = nπ these have denominator 0 ⇒ both are undefined and show vertical asymptotes.
4. Cross-check the others: tan and sec depend on cos x, which is nonzero at nπ, so they are perfectly defined there.
 function   denominator   zero at            undefined at
 cot x      sin x         x = nπ             x = nπ      ✓
 cosec x    sin x         x = nπ             x = nπ      ✓
 tan x      cos x         x = (2n+1)π/2      NOT at nπ
 sec x      cos x         x = (2n+1)π/2      NOT at nπ
⚡ JEE Trick Pair each reciprocal with its zero-maker: "co" partners cot & cosec die at multiples of π (sin=0); tan & sec die at odd multiples of π/2 (cos=0)." Trap: cot and cosec, not tan/sec, are the pair keyed to π; reversing them is the classic mistake.
Answer: cot x and cosec x (both undefined at x = nπ, since sin x = 0 there).
5The secant function is undefined at …sec asymptotes (2n+1)π/2A-TRIG🟡 Similarcx = (2n+1)π/2, n ∈ Z
Concept sec x = 1/cos x, so secant fails wherever its denominator cos x = 0. Cosine equals zero at the odd multiples of π/2 — 90°, 270°, and so on — so those are precisely the angles where sec is undefined and its graph has vertical asymptotes.
Formula sec x = 1/cos x, undefined ⇔ cos x = 0 ⇔ x = (2n+1)π/2, n ∈ Z. (2n+1) generates the odd integers, so (2n+1)π/2 = π/2, 3π/2, 5π/2, … — every odd multiple of a right angle.
Solution
1. Write sec as 1/cos x; the danger points are cos x = 0.
2. Solve cos x = 0 ⇒ x = π/2, 3π/2, 5π/2, … i.e. x = (2n+1)π/2, n ∈ Z.Cosine is zero exactly a quarter-turn away from each of its peaks/troughs.
3. At these x, sec x = 1/0 is undefined ⇒ vertical asymptotes; between them |sec x| ≥ 1.
4. So the secant function is undefined at all odd multiples of π/2.
 x        0    π/2    π    3π/2   2π
 cos x    1     0    -1     0     1
 sec x    1    und   -1    und    1
              ↑           ↑        undefined (asymptotes)
 undefined at x = (2n+1)π/2  =  ±π/2, ±3π/2, ...
⚡ JEE Trick "sec follows cos" — sec is undefined wherever cos = 0, at (2n+1)π/2; likewise cosec follows sin, undefined at nπ. Trap: the answer is odd multiples of π/2, NOT all multiples of π/2 (sec is perfectly defined at the even ones like 0, π, 2π where cos = ±1).
Answer: x = (2n+1)π/2, n ∈ Z (all odd multiples of π/2, where cos x = 0).

1Period of cos(2x)Period 2π/nA-TRANSF🟡 Similaraπ
Concept The period is the shortest x-interval after which the graph repeats. Doubling the input, cos(2x), makes the angle advance twice as fast, so the wave completes a full cycle in half the usual distance. The coefficient of x controls the period inversely — larger coefficient, shorter period.
Formula For y = cos(nx), period T = 2π/|n|. Base cos x repeats every 2π; with argument 2x, the input reaches 2π when x = π, so one cycle now fits in π. Here n = 2.
Solution
1. Read off the coefficient of x inside cosine: n = 2.
2. Apply T = 2π/|n| = 2π/2 = π.
3. Confirm with the repeat test: cos(2(x + π)) = cos(2x + 2π) = cos(2x). ✓Adding π to x adds a full 2π inside cosine, reproducing the same value — and nothing smaller does.
 cos x   → period 2π
 cos 2x  → period 2π/2 = π
 two complete cosine waves fit in [0, 2π]
⚡ JEE Trick Period of sin/cos(nx) = 2π/|n|; here 2π/2 = π. Amplitude, phase, and vertical shifts leave the period untouched. Trap: a bigger n divides the period down — the answer is π, never 4π.

Concept Here cosine is restricted to the open interval (−π, π), and the openness matters. Concept cot x = cos x / sin x, so within (−π, π) we must drop any x where sin x = 0. Inside that interval sin vanishes only at x = 0 (the ends ±π are already excluded). On each of the two resulting pieces cot runs continuously over all real values, so the range is unbounded.
