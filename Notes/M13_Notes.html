💡 What rotation leaves unchanged (invariants)For a conic ax² + 2hxy + by² + …, a pure rotation preserves a + b (sum of the x² and y² coefficients) and h² − ab. Choose θ with tan 2θ = 2h/(a − b) to kill the xy-term. Shifting the origin never changes the second-degree terms — only the linear and constant parts.

Area independent of a parameter t ⇒ the three points move along fixed parallel-ish lines keeping Δ constant. Ratio in which an axis cuts a segment: set that coordinate = 0 in the section formula.
⚠ Three slips that cost marks(1) Keep the modulus on area — the signed determinant can be negative; a bare negative "area" is wrong. (2) External division uses m − n in the denominator (undefined when m = n); don't reuse the internal formula. (3) On the Euler line it is G that lies between O and H with OG:GH = 1:2 — do not put O in the middle.
L-1

Distance Formula, Section Formula, Area of a Triangle & Collinearity

Setting up the plane

  • Two perpendicular lines X′OX (x-axis) and Y′OY (y-axis) meet at the origin O. A point P is fixed by its abscissa (x, along OM) and ordinate (y, the height MP), written as the ordered pair (x, y) — the rectangular (orthogonal) coordinate system.
  • When the axes are not at right angles they are called oblique axes. Signs by quadrant: I (+,+), II (−,+), III (−,−), IV (+,−).
  • The same point may be given in polar form (r, θ); Cartesian ↔ polar via x = r cosθ, y = r sinθ.

Distance formula

derived from Pythagoras on the right triangle PRQPQ = √[(x₂ − x₁)² + (y₂ − y₁)²] · distance of P(x,y) from O(0,0) = √(x² + y²)
Worked examples from the module
Book Example · L-1 (theory)
Prove that the distance of the point (a cosα, a sinα) from the origin is independent of α.
OP = √[(a cosα − 0)² + (a sinα − 0)²] = √(a²cos²α + a²sin²α) = √[a²(cos²α + sin²α)] = √(a²) = |a|.
OP = |a| — free of α
Book Example · L-1 (theory)
Find the distance between P(a cosα, a sinα) and Q(a cosβ, a sinβ), a > 0.
PQ = √[(a cosα − a cosβ)² + (a sinα − a sinβ)²] = |a|√[(cos²α + sin²α) + (cos²β + sin²β) − 2(cosα cosβ + sinα sinβ)].
= |a|√[1 + 1 − 2cos(α − β)] = |a|√[2(1 − cos(α − β))] = |a|√[4 sin²((α − β)/2)].
PQ = 2a |sin((α − β)/2)|

Section formula

  • If P lies on segment AB between A and B it divides AB internally in the ratio AP:PB; if P is on line AB but outside the segment it divides externally.
internal division of P(x₁,y₁)–Q(x₂,y₂) in m:n( (m x₂ + n x₁)/(m + n) , (m y₂ + n y₁)/(m + n) )
external division in m:n( (m x₂ − n x₁)/(m − n) , (m y₂ − n y₁)/(m − n) )
mid-point (internal, m = n)( (x₁ + x₂)/2 , (y₁ + y₂)/2 )
💡 Use the λ:1 formWhen the ratio is the unknown, take it as λ:1 and use ( (λx₂ + x₁)/(λ + 1) , (λy₂ + y₁)/(λ + 1) ). Solving gives λ; λ > 0 ⇒ internal, λ < 0 ⇒ external. To find where an axis cuts a segment, set the matching coordinate (y for the x-axis) to 0.
💡 Proving a quadrilateral's typeFor vertices A, B, C, D use diagonals AC, BD and sides. Parallelogram: diagonals bisect each other. Rhombus: that + adjacent sides equal. Rectangle: diagonals equal and bisect each other. Square: diagonals equal, bisect each other, and adjacent sides equal.
Worked examples from the module
Book Example-1 · L-1
Find the coordinates of the point which divides the segment joining (5, −2) and (9, 6) internally in the ratio 3 : 1.
x = (3·9 + 1·5)/(3 + 1) = (27 + 5)/4 = 8; y = (3·6 + 1·(−2))/(3 + 1) = (18 − 2)/4 = 4.
(8, 4)
Book Example-2 · L-1
Determine the ratio in which the line y − x + 2 = 0 divides the segment joining (3, −1) and (8, 9).
Take the ratio λ:1, so P = ( (8λ + 3)/(λ + 1) , (9λ − 1)/(λ + 1) ). P lies on the line ⇒ (9λ − 1)/(λ + 1) − (8λ + 3)/(λ + 1) + 2 = 0.
⇒ [9λ − 1 − 8λ − 3 + 2(λ + 1)]/(λ + 1) = 0 ⇒ (3λ − 2)/(λ + 1) = 0 ⇒ λ = 2/3.
λ = 2/3 > 0 ⇒ internal; ratio = 2/3 : 1 = 2 : 3.
Internally in the ratio 2 : 3
L-2

Medians, Centroid, Incentre, Circumcentre & Orthocentre

The four cevians

  • Median: joins a vertex to the mid-point of the opposite side. The three medians are concurrent at the centroid.
  • Perpendicular bisector: perpendicular to a side through its mid-point; the three meet at the circumcentre.
  • Angle bisector: splits a vertex angle in two; the three internal bisectors meet at the incentre.
  • Altitude (perpendicular from a vertex to the opposite side); the three meet at the orthocentre.

Centroid

G divides each median 2:1 from the vertexG = ( (x₁ + x₂ + x₃)/3 , (y₁ + y₂ + y₃)/3 )

Incentre & ex-centres

a = BC, b = CA, c = AB (side lengths)I = ( (a x₁ + b x₂ + c x₃)/(a + b + c) , (a y₁ + b y₂ + c y₃)/(a + b + c) )
  • The internal bisector from A meets BC at D with BD:DC = AB:AC = c:b, which drives the derivation.
  • Ex-centres (bisector of one angle + the two external bisectors) come from flipping one sign: I₁ (opp. A) uses −a, +b, +c; I₂ (opp. B) uses +a, −b, +c; I₃ (opp. C) uses +a, +b, −c.
  • In an equilateral triangle a = b = c ⇒ I collapses to G: incentre and centroid coincide.

Circumcentre & orthocentre

  • Circumcentre O: equidistant from all vertices, OA² = OB² = OC² — solve two of those equations. It is the centre of the circle through the vertices.
  • Orthocentre H: intersection of any two altitudes.
★ Euler lineCircumcentre O, centroid G and orthocentre H are always collinear, and G divides OH with OG : GH = 1 : 2. Hence G = (O + 2H)/3, i.e. H = 3G − 2O and O = (3G − H)/2.
💡 Right-angle & equilateral shortcutsRight-angled triangle → circumcentre is the mid-point of the hypotenuse and orthocentre is the right-angle vertex. Equilateral triangle → centroid, incentre, circumcentre and orthocentre all coincide.

Book Example · L-2 (theory)
Find the centroid of the triangle whose vertices are (0, 0), (2, 5) and (7, 4).
G = ( (0 + 2 + 7)/3 , (0 + 5 + 4)/3 ) = (9/3, 9/3).
G = (3, 3)
Book Example · L-2 (theory)
Find the incentre of the triangle with vertices A(−36, 7), B(20, 7), C(0, −8).
a = BC = √(20² + (7 + 8)²) = √(400 + 225) = 25; b = CA = √(36² + 15²) = √1521 = 39; c = AB = √(56² + 0²) = 56.
I_x = (25·(−36) + 39·20 + 56·0)/(25 + 39 + 56) = (−900 + 780)/120 = −120/120 = −1.
I_y = (25·7 + 39·7 + 56·(−8))/120 = (175 + 273 − 448)/120 = 0/120 = 0.
I = (−1, 0)
Book Example · L-2 (theory)
The mid-points of the sides of a triangle are D(1, 1), E(2, −3), F(3, 4). Find the ex-centre opposite vertex A.
Recover the vertices from the medial triangle: A = −D + E + F = (4, 0), B = D − E + F = (2, 8), C = D + E − F = (0, −6).
a = BC = √(2² + 14²) = √200 = 10√2; b = CA = √(4² + 6²) = √52 = 2√13; c = AB = √(2² + 8²) = √68 = 2√17.
Ex-centre opposite A uses (−a, b, c): I₁ = ( (−a·4 + b·0 + c·0)/(−a + b + c) , (−a·0 + b·8 + c·(−6))/(−a + b + c) ).
= ( (−40√2 + 2√13)/(−10√2 + 2√13 + 2√17) , (16√13 − 12√17)/(−10√2 + 2√13 + 2√17) ) = ( (−20√2 + √13)/(−5√2 + √13 + √17) , (8√13 − 6√17)/(−5√2 + √13 + √17) ).
I₁ = ( (−20√2 + √13)/(−5√2 + √13 + √17) , (8√13 − 6√17)/(−5√2 + √13 + √17) )
Book Example-1 · L-2
The orthocentre and circumcentre of △ABC are (a, b) and (c, d). If vertex A = (x₁, y₁), find the mid-point M(p, q) of BC.
Centroid G lies on the median AM with AG:GM = 2:1, so G = ( (x₁ + 2p)/3 , (y₁ + 2q)/3 ).
On the Euler line G divides H(a,b)–O(c,d) with HG:GO = 2:1, so G = ( (a + 2c)/3 , (b + 2d)/3 ).
Equate: x₁ + 2p = a + 2c and y₁ + 2q = b + 2d.
M = ( (a + 2c − x₁)/2 , (b + 2d − y₁)/2 )
Book Example-2 · L-2
Vertices A(−1, −7), B(5, 1), C(1, 4). The internal bisector of ∠B meets AC at D. Find the length AD.
AB = √(6² + 8²) = 10, BC = √(4² + 3²) = 5, so D divides AC with AD:DC = AB:BC = 2:1.
D = ( (1·(−1) + 2·1)/3 , (1·(−7) + 2·4)/3 ) = (1/3, 1/3).
AD = √[(1/3 + 1)² + (1/3 + 7)²] = √[(4/3)² + (22/3)²] = √[(16 + 484)/9] = √(500)/3.
AD = 10√5 / 3
Book Example-3 · L-2
Find the orthocentre of the triangle with vertices A(2, (√3 − 1)/2), B(1/2, −1/2), C(2, −1/2).
AB = √[(2 − 1/2)² + ((√3 − 1)/2 + 1/2)²] = √[(3/2)² + (√3/2)²] = √3; BC = √[(1/2 − 2)² + 0] = 3/2; CA = √[0 + ((√3 − 1)/2 + 1/2)²] = √3/2.
BC² + CA² = 9/4 + 3/4 = 3 = AB², so the right angle is at C.
In a right triangle the orthocentre is the right-angle vertex.
Orthocentre = C(2, −1/2)
L-3

Area, Collinearity & Locus of a Point

Area of a triangle

from the trapezium decomposition — keep the modulusΔ = (1/2)|x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)| = (1/2)|det[[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]]|

Area of a polygon — the stair (shoelace) method

  • List the vertices in order and repeat the first at the end. Cross-multiply down-arrows (+) and up-arrows (−):
quadrilateral / n-gonArea = (1/2)|(x₁y₂ + x₂y₃ + … + xₙy₁) − (y₁x₂ + y₂x₃ + … + yₙx₁)|

Collinearity

zero area ⇔ one straight lineA, B, C collinear ⇔ det[[x₁,y₁,1],[x₂,y₂,1],[x₃,y₃,1]] = 0 ⇔ Δ = 0

Locus of a point

  • A locus is the path traced by a point that moves under a stated condition; its equation is the relation satisfied by every point on it.
  • Method: (1) let the moving point be (h, k); (2) translate the condition into an equation in h, k; (3) eliminate any parameter; (4) replace h → x, k → y.
💡 Reading the shoelace signIf the stair sum comes out negative you simply traversed the vertices clockwise — take the absolute value. If it comes out exactly 0 the points are collinear (no enclosed area).
Worked examples from the module
Book Example · L-3 (theory)
Find the area of the triangle with vertices (1, 2), (4, −6) and (3, 5).
Δ = (1/2)|1(−6 − 5) + 4(5 − 2) + 3(2 − (−6))| = (1/2)|−11 + 12 + 24| = (1/2)|25|.
Δ = 25/2 sq units
Book Example · L-3 (theory)
Prove that the area of the triangle with vertices (t, t − 2), (t + 2, t + 2) and (t + 3, t) is independent of t.
Δ = (1/2)|t((t + 2) − t) + (t + 2)(t − (t − 2)) + (t + 3)((t − 2) − (t + 2))|.
= (1/2)|t(2) + (t + 2)(2) + (t + 3)(−4)| = (1/2)|2t + 2t + 4 − 4t − 12| = (1/2)|−8|.
Δ = 4 sq units — independent of t
Book Example · L-3 (theory)
Find the area of the quadrilateral ABCD with vertices A(1, 1), B(7, −3), C(12, 2), D(7, 21).
Shoelace in order A→B→C→D: downs = 1·(−3) + 7·2 + 12·21 + 7·1 = −3 + 14 + 252 + 7 = 270.
ups = 1·7 + (−3)·12 + 2·7 + 21·1 = 7 − 36 + 14 + 21 = 6. Area = (1/2)|270 − 6| = (1/2)(264).
Area = 132 sq units
Book Example-1 · L-3
A rod of length ℓ slides with its ends on two perpendicular lines. Find the locus of its mid-point.
Take the lines as the axes; ends A(a, 0), B(0, b) and mid-point P(h, k), so h = a/2, k = b/2 ⇒ a = 2h, b = 2k.
Rod length: a² + b² = ℓ² ⇒ (2h)² + (2k)² = ℓ² ⇒ 4h² + 4k² = ℓ².
x² + y² = ℓ²/4 (a circle of radius ℓ/2 about the corner)
Book Example-2 · L-3
If the coordinates of a variable point P are (a cosθ, b sinθ), find the locus of P.
x = a cosθ, y = b sinθ ⇒ x/a = cosθ, y/b = sinθ.
Square and add: x²/a² + y²/b² = cos²θ + sin²θ = 1.
x²/a² + y²/b² = 1 (an ellipse)
Book Example-3 · L-3
Find the equation of the locus of a point equidistant from A(1, 3) and B(−2, 1).
Let P(h, k) with AP = PB ⇒ AP² = PB²: (h − 1)² + (k − 3)² = (h + 2)² + (k − 1)².
h² − 2h + 1 + k² − 6k + 9 = h² + 4h + 4 + k² − 2k + 1 ⇒ −6h − 4k + 10 = 0 ⇒ 6h + 4k = 5.
6x + 4y = 5 (the perpendicular bisector of AB)
L-4

Transformation of Axes: Shifting of Origin & Rotation of Axes

Shifting (translating) the origin

  • Move the origin to O′(h, k) with the axes kept parallel. A point keeps its place; only its labels change.
old (x,y) ↔ new (X,Y)x = X + h, y = Y + k · new coordinates of an old point (x₁,y₁) = (x₁ − h, y₁ − k)
💡 What a shift does to an equationSubstituting x = X + h, y = Y + k leaves the second-degree terms untouched and only reshuffles the linear and constant parts — that is why a well-chosen (h,k) can kill the linear terms (complete the square): set each linear coefficient to 0.

Rotating the axes

  • Rotate the axes through angle θ (anticlockwise) about a fixed origin. Project the point onto the new axes:
old (x,y) in terms of new (X,Y)x = X cosθ − Y sinθ, y = X sinθ + Y cosθ
new (X,Y) in terms of old (x,y)X = x cosθ + y sinθ, Y = −x sinθ + y cosθ
coefficientxy
Xcosθsinθ
Y−sinθcosθ

Both together

origin to (α, β) and axes rotated by θx = α + X cosθ − Y sinθ, y = β + X sinθ + Y cosθ
💡 Killing the xy-termFor ax² + 2hxy + by² rotate by θ with tan 2θ = 2h/(a − b) (take θ = 45° if a = b). The sum of the squared-term coefficients a + b is invariant, so you can check the new coefficients add up correctly.
Worked examples from the module
Book Example-1 · L-4
If the axes are shifted to (1, −2) without rotation, what do these become? (i) 2x² + y² − 4x + 4y = 0 (ii) y² − 4x + 4y + 8 = 0.
Shift: x = X + 1, y = Y − 2.
(i) 2(X + 1)² + (Y − 2)² − 4(X + 1) + 4(Y − 2) = 2X² + 4X + 2 + Y² − 4Y + 4 − 4X − 4 + 4Y − 8 = 2X² + Y² − 6 = 0.
(ii) (Y − 2)² − 4(X + 1) + 4(Y − 2) + 8 = Y² − 4Y + 4 − 4X − 4 + 4Y − 8 + 8 = Y² − 4X = 0.
(i) 2X² + Y² = 6 (ii) Y² = 4X
Book Example-2 · L-4
Through what angle should the axes be rotated so that 9x² − 2√3 xy + 7y² = 10 changes to 3x² + 5y² = 5?
Replace (x, y) by (X cosθ − Y sinθ, X sinθ + Y cosθ); the new XY-coefficient must vanish.
XY-coefficient = −9·2 sinθ cosθ − 2√3(cos²θ − sin²θ) + 7·2 sinθ cosθ = −2 sin2θ − 2√3 cos2θ = 0 ⇒ tan 2θ = −√3.
2θ = 120° ⇒ θ = 60°. (Check: new coefficients a + b = 9 + 7 = 16 split as 6 and 10, giving 6X² + 10Y² = 10, i.e. 3X² + 5Y² = 5.)
θ = 60°
Book Example-3 · L-4
Without turning the axes, the origin is moved to (h, k) so that the linear terms of x² + y² − 4x + 6y − 7 = 0 vanish. Find (h, k).
Put x = X + h, y = Y + k. The linear part becomes X(2h − 4) + Y(2k + 6).
No linear terms ⇒ 2h − 4 = 0 and 2k + 6 = 0 ⇒ h = 2, k = −3 (the centre of the circle).
(h, k) = (2, −3)
Book Example-4 · L-4
Find the new coordinates of the point (4, 5) when the origin is shifted to (1, −2).
New coordinates = (x − h, y − k) = (4 − 1, 5 − (−2)) = (3, 7).
(3, 7)

c + 2d = 3 → (c)
Strong Box · PYQ · JEE Main 2025 (7 Apr Shift-1)
△ABC has AB: 3y − x = 2 and AC: x + y = 2, with B, C on the x-axis. P is the orthocentre. Find area of △PBC.
On y = 0: B (from 3y − x = 2) = (−2, 0); C (from x + y = 2) = (2, 0); A = intersection = (1, 1).
BC is horizontal, so altitude from A is x = 1. Altitude from B ⊥ AC (slope −1) has slope 1: y = x + 2; at x = 1, y = 3 ⇒ P(1, 3).
Area △PBC = (1/2)·(base BC = 4)·(height = 3) = 6.
Area = 6 → (d)
Strong Box · PYQ · JEE Main 2017
k is an integer; the triangle with vertices (k, −3k), (5, k), (−k, 2) has area 28. Find its orthocentre.
Area = (1/2)|k(k − 2) + 5(2 + 3k) + (−k)(−3k − k)| = (1/2)|5k² + 13k + 10| = 28 ⇒ 5k² + 13k − 46 = 0 ⇒ k = 2 (integer root).
Vertices become (2, −6), (5, 2), (−2, 2); the side through (5,2),(−2,2) is horizontal ⇒ altitude from (2,−6) is x = 2.
Altitude from (5,2) ⊥ line (2,−6)–(−2,2) (slope −2) has slope 1/2: y − 2 = (1/2)(x − 5); at x = 2, y = 1/2.
Orthocentre = (2, 1/2) → (a)

Strong Box · PYQ · AIEEE 2009
Three distinct points A, B, C with [distance from (1,0)] : [distance from (−1,0)] = 1/3. Find the circumcentre of △ABC.
Each point satisfies 9[(x − 1)² + y²] = (x + 1)² + y² ⇒ 8x² + 8y² − 20x + 8 = 0 ⇒ x² + y² − (5/2)x + 1 = 0.
This Apollonius circle carries all three points, so its centre is the circumcentre: x = 5/4, y = 0.
(5/4, 0) → (a)
Strong Box · PYQ · AIEEE 2007
A(h, k), B(1, 1), C(2, 1) form a right triangle with AC as hypotenuse and area 1. Find the set of values of k.
Right angle at B ⇒ AB ⊥ BC. BC = (1, 0), so AB = (h − 1, k − 1) must satisfy h − 1 = 0 ⇒ h = 1; thus A = (1, k).
Area = (1/2)·|AB|·|BC| = (1/2)·|k − 1|·1 = 1 ⇒ |k − 1| = 2 ⇒ k = 3 or k = −1.
{−1, 3} → (c)
