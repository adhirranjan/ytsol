The right side sin x cos x is also (1/2)sin 2x, so the whole equation collapses to one quadratic in t = sin 2x. The trap is forgetting that t must lie in [−1, 1], so one root of the quadratic is thrown away.

1When using graphs to solve equations, what do intersections represent? (Level-1)
(a) Slope (b) Angle (c) Roots (d) Range		Graphical solution meaningTrigonometric Functions | Number of Solutions by Graph | Class 11 & 12 | IIT JEE & CET🟡 SimilarcRoots
Concept To solve f(x) = g(x) graphically you draw y = f(x) and y = g(x) on the same axes. A point where the curves cross has the same x giving the same y on both, so that x satisfies the equation: it is a root. The number of intersection points is the number of real roots. The trap is to read the y-coordinate (a value of the functions) as the answer.
Formula f(x₀) = g(x₀) ⇔ (x₀, f(x₀)) lies on both graphs. An intersection point is exactly a common point of the two curves.
Solution
1. Rewrite the equation as f(x) = g(x), e.g. sin x = x/10 ⇒ f(x) = sin x, g(x) = x/10.
2. Plot y = f(x) and y = g(x) on the same axes.
3. At an intersection (x₀, y₀): y₀ = f(x₀) and y₀ = g(x₀) ⇒ f(x₀) = g(x₀).So x₀ solves the original equation.
4. Conversely every root x₀ gives a common point (x₀, f(x₀)) ⇒ intersections and roots correspond one-to-one.
5. So intersections represent roots; counting them counts the solutions (e.g. sin x = x/10 has 7 real roots: 7 crossings).
6. Check the distractors: slope is a tangent property, angle is between curves at a crossing, range is the set of y-values; none is what the crossing represents ⇒ (c).
