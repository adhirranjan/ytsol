1 (i)
The sum of integers from 1 to 100 that are divisible by 2 or 5 is ______.
📝 PYQ: IIT-JEE 1984Solution ↗
M8DL3VRecapQ1iInclusion–exclusion on two A.P.s
🟢 ExactThe sum of integers…
3050
Concept "Divisible by 2 or 5" is a set-union question wearing a series disguise. The multiples of 2 form an A.P., the multiples of 5 form an A.P., and the numbers counted twice are exactly the multiples of 10 = lcm(2, 5). So sum the two A.P.s and subtract the overlap once — that is inclusion–exclusion, the single most useful counting identity in this chapter.
Formula |A ∪ B| sum = ΣA + ΣB − Σ(A ∩ B) with each piece an A.P.: Sₙ = (n/2)(first + last). A ∩ B here is "divisible by both 2 and 5" = "divisible by 10", never "divisible by 2×5 terms".
Solution
1. Multiples of 2 in [1,100]: 2, 4, 6, …, 100. Count n = 100/2 = 50.
2. Their sum = (50/2)(2 + 100) = 25 × 102 = 2550.Equivalently 2(1+2+…+50) = 2·(50·51/2) = 2550.
3. Multiples of 5: 5, 10, …, 100. Count n = 20, sum = (20/2)(5 + 100) = 10 × 105 = 1050.
4. Multiples of 10 (counted in both lists): 10, 20, …, 100. Count n = 10, sum = (10/2)(10 + 100) = 5 × 110 = 550.
5. Inclusion–exclusion: total = 2550 + 1050 − 550 = 3050.
6. Sanity check by complement: 1+2+…+100 = 5050. Numbers divisible by neither 2 nor 5 are those coprime-ish to 10, i.e. ending in 1, 3, 7, 9 — ten decades × (1+3+7+9 + 4×offset). Decade k (offset 10k, k = 0..9) contributes 20 + 40k, so the total is 10·20 + 40(0+1+…+9) = 200 + 1800 = 2000. And 5050 − 2000 = 3050 ✓
⚡ JEE Trick For "divisible by a or b" always subtract the multiples of lcm(a,b), not of ab. Trap: 2×5 = 10 = lcm(2,5) here so nothing goes wrong, but with "divisible by 4 or 6" the overlap is lcm = 12, not 24 — candidates who subtract multiples of 24 lose the mark.
Answer: 3050.
1 (ii)
If a, b, c are in G.P., then the equations ax² + 2bx + c = 0 and dx² + 2ex + f = 0 have a common root if d/a, e/b, f/c are in ______.
📝 PYQ: JEE Main 2019 · 8 Apr · EveningSolution ↗
M8DL3VRecapQ1iiCommon root + G.P. condition → A.P.
🟢 ExactIf a,b,c are in GP,…
A.P.
Concept The hypothesis "a, b, c in G.P." means b² = ac, and that is exactly the condition that makes the discriminant of ax² + 2bx + c vanish: (2b)² − 4ac = 4(b² − ac) = 0. So the first quadratic has a repeated root, which pins the common root down completely — no case work needed.
Formula Repeated root of ax² + 2bx + c = 0 is x = −b/a. Substituting into the second equation and dividing by a gives d/a − 2e/b + f/c = 0. Any relation of the shape 2·middle = first + last is an A.P. statement.
Solution
1. G.P. condition: b² = ac.
2. Discriminant of the first equation: (2b)² − 4ac = 4b² − 4ac = 4(b² − ac) = 0, so it has the double root x₀ = −2b/(2a) = −b/a.
3. The two quadratics share a root, and the first has only one root, so that shared root must be x₀ = −b/a.
4. Put x₀ into the second: d·(b²/a²) − 2e·(b/a) + f = 0.
5. Replace b² by ac in the first term: d·(ac/a²) − 2eb/a + f = 0 ⟹ dc/a − 2eb/a + f = 0.
6. Multiply by a/c: d − 2eb/c + fa/c = 0. Now use b² = ac once more in the form a/c = a²/(ac) = a²/b², giving d − 2e·a/b + f·a²/(ac) = d − 2ea/b + fa/c = 0.Every step is just "replace ac by b²" or "replace b² by ac" — nothing else happens.
7. Divide the last line by a: d/a − 2e/b + f/c = 0, i.e. 2(e/b) = d/a + f/c.
8. That is precisely the middle-term condition for an A.P., so d/a, e/b, f/c are in A.P.
9. Numerical check: take a, b, c = 1, 2, 4 (G.P.). Then x² + 4x + 4 = 0 has the double root −2. Choose d = 1, f = 4 and force −2 to be a root of x² + 2ex + 4 = 0: 4 − 4e + 4 = 0 ⟹ e = 2. Now d/a, e/b, f/c = 1, 1, 1 — an A.P. ✓
⚡ JEE Trick Whenever a quadratic is written with a 2b middle coefficient and the data says "a, b, c in G.P.", stop and check the discriminant — it is always zero, and the double root −b/a turns a two-equation problem into a one-line substitution. Trap: hunting for the common root with the cross-multiplication formula; it works but takes five times longer.
Answer: A.P. — d/a, e/b, f/c form an arithmetic progression.
1 (iii)
Sum of the first n terms of the series 1/2 + 3/4 + 7/8 + 15/16 + …… is equal to ______.
📝 PYQ: IIT-JEE 1988Solution ↗
M8DL3VRecapQ1iiiSplitting Tₙ into "1 − (1/2)ⁿ"
🟢 ExactThe sum to n terms o…
n + 2−n − 1
Concept Neither an A.P. nor a G.P. — but the numerator of every term is exactly one less than its denominator. That single observation splits each term into a constant 1 minus a G.P. term, and the whole sum collapses into "n minus a geometric sum". This split-the-term move is the workhorse of the entire "special series" lesson.
Formula Tₖ = (2ᵏ − 1)/2ᵏ = 1 − (1/2)ᵏ, and Σ(1/2)ᵏ, k = 1…n = 1 − (1/2)ⁿ. The bracketed geometric sum has a = 1/2, r = 1/2, so it equals (1/2)(1 − (1/2)ⁿ)/(1 − 1/2) = 1 − 2⁻ⁿ.
Solution
1. Read the pattern of denominators: 2, 4, 8, 16, … = 2ᵏ. Numerators: 1, 3, 7, 15, … = 2ᵏ − 1.
2. So the general term is Tₖ = (2ᵏ − 1)/2ᵏ.
3. Split it: Tₖ = 2ᵏ/2ᵏ − 1/2ᵏ = 1 − 2⁻ᵏ.Do not try to sum (2ᵏ−1)/2ᵏ directly; the split is what makes it summable.
4. Add k = 1 to n: Sₙ = Σ1 − Σ2⁻ᵏ = n − (2⁻¹ + 2⁻² + … + 2⁻ⁿ).
5. The bracket is a G.P. with a = 1/2, r = 1/2: its sum = (1/2)·[1 − (1/2)ⁿ]/(1/2) = 1 − 2⁻ⁿ.
6. Therefore Sₙ = n − (1 − 2⁻ⁿ) = n + 2⁻ⁿ − 1.
7. Check n = 1: 1 + 1/2 − 1 = 1/2 ✓ (the first term). Check n = 2: 2 + 1/4 − 1 = 5/4, and 1/2 + 3/4 = 5/4 ✓. Check n = 3: 3 + 1/8 − 1 = 17/8, and 1/2 + 3/4 + 7/8 = 4/8 + 6/8 + 7/8 = 17/8 ✓
⚡ JEE Trick Whenever numerator = denominator − 1, write the term as 1 − (1/denominator). The same trick answers "sum of 1/2 + 3/4 + 7/8 + … to infinity" instantly: it diverges, because Sₙ → n. Trap: reading 1/2, 3/4, 7/8 as an A.P. of fractions — the differences 1/4, 1/8 are not equal.
Answer: Sₙ = n + 2−n − 1.
1 (iv)
An infinite G.P. has first term 'x' and sum '5', then x belongs to ______.
📝 PYQ: IIT-JEE 2004 ScreeningSolution ↗
M8DL3VRecapQ1ivConvergence condition |r| < 1 turned into a range for the first term
🟢 ExactAn infinite G.P has…
0 < x < 10 ⚠
Concept An infinite G.P. only has a sum when |r| < 1. So a question that fixes the sum is really a question about r: solve for r in terms of the first term, then feed r into the convergence inequality. The answer is always an interval, never a single number.
Formula S∞ = a/(1 − r), valid only for |r| < 1. Here a = x and S∞ = 5, so r = 1 − x/5. Rearranged from 5(1 − r) = x.
Solution
1. Write the sum formula: 5 = x/(1 − r).
2. Cross-multiply: 5 − 5r = x ⟹ 5r = 5 − x ⟹ r = 1 − x/5.
3. Impose convergence: −1 < r < 1, i.e. −1 < 1 − x/5 < 1.
4. Subtract 1 throughout: −2 < −x/5 < 0.
5. Multiply by −5 and flip both inequality signs: 10 > x > 0, i.e. 0 < x < 10.Multiplying an inequality by a negative number reverses it — this is the step where marks are lost.
6. Reality check on the endpoints: x = 10 forces r = −1 (oscillating, no sum); x = 0 forces r = 1 and a zero first term (no G.P. at all). Both are correctly excluded.
7. Spot check inside the range: x = 5 gives r = 0 — degenerate but the sum 5 works; x = 2 gives r = 3/5 and S∞ = 2/(1 − 0.6) = 5 ✓; x = 9 gives r = −4/5 and S∞ = 9/(1 + 0.8) = 5 ✓
⚡ JEE Trick Sum fixed and positive ⇒ the first term must be positive too, because a/(1−r) with |r| < 1 has 1 − r > 0. That one line kills every negative option instantly, without solving anything. Trap: forgetting to reverse the inequality when dividing by −5 (which is exactly how the answer −10 < x < 0 gets manufactured).
Answer: 0 < x < 10. ⚠ Flag: the printed key −10 < x < 0 is the sign-flip error; a negative first term cannot give a sum of +5 in a convergent G.P.

M8DL3VRecapQ2Four independent series/algebra results
🟡 SimilarProperties of Arithm…
(A)→(r), (B)→(p), (C)→(s), (D)→(q) ⚠
Concept Four unrelated results are bundled into one matching grid, so the fastest route is to compute the two you are certain of and let elimination finish the job. (A) and (D) are clean algebra; (B) is an "intersection of two A.P.s" count; (C) is a one-line AM–GM.
Formula Sᵣ = (r/2)[2A + (r−1)D]; common terms of two A.P.s step by lcm(d₁, d₂); AM ≥ GM; coefficient of xⁿ in P(x)² is Σ aᵢ aₙ₋ᵢ. Four tools, one for each row.
Solution
1. (A) Sₐ/a² = C gives (1/2)[2A + (a−1)D] = aC, i.e. 2A + (a−1)D = 2aC. Same with b: 2A + (b−1)D = 2bC.
2. Subtract: (a − b)D = 2C(a − b) ⟹ D = 2C. Back-substitute: 2A + (a−1)(2C) = 2aC ⟹ 2A = 2C ⟹ A = C.
3. So Sᵣ = (r/2)[2C + (r−1)2C] = (r/2)(2Cr) = Cr². Hence S_c = C·c². But C = A and, from step 2, the A.P. is C, 3C, 5C, … whose sum of c terms is Cc²; the required answer is expressed with the parameter: since S_c/c² = C means S_c = Cc², and the question wants it in Column-II form, S_c = c³ when C = c. ⟹ (r).Column-II offers c³, which is Cc² with the natural reading C = c — the intended pairing.
4. (B) First sequence: 1, 11, 21, … (d = 10), 100th term = 1 + 99·10 = 991. Second: 31, 36, 41, … (d = 5), 100th term = 31 + 99·5 = 526.
5. Common terms start at 31 and step by lcm(10, 5) = 10: 31, 41, 51, …. They must stay ≤ 526, so the largest is 521. The only remaining Column-II entry is (p), printed as 531 ⟹ (p).See the flag: 531 exceeds 526, so it cannot belong to the second sequence's first 100 terms.
6. (C) By AM ≥ GM on the three positive quantities sin x, cos x, cosec 2x: (sin x + cos x + cosec 2x)/3 ≥ (sin x · cos x · cosec 2x)1/3.
7. But sin x · cos x · cosec 2x = sin x cos x / sin 2x = sin x cos x /(2 sin x cos x) = 1/2, a constant.
8. So the bracket ≥ 3(1/2)1/3 and cubing gives (…)³ ≥ 27 × 1/2 = 13.5 ⟹ (s).
9. (D) Let P(x) = 1 + x + 2x² + 3x³ + … + n xⁿ, so a₀ = 1 and a_k = k for k ≥ 1. Coefficient of xⁿ in P² = 2a₀aₙ + Σ_{i=1}^{n−1} i(n − i) = 2n + [n·Σi − Σi²].
10. Σ_{i=1}^{n−1} i = n(n−1)/2 and Σ_{i=1}^{n−1} i² = (n−1)n(2n−1)/6, so the bracket = n²(n−1)/2 − n(n−1)(2n−1)/6 = n(n−1)[3n − (2n−1)]/6 = n(n−1)(n+1)/6.
11. Total = 2n + n(n² − 1)/6 = (12n + n³ − n)/6 = n(n² + 11)/6 ⟹ (q). Check n = 1: 1(12)/6 = 2, and (1 + x)² has x-coefficient 2 ✓
⚡ JEE Trick In "common terms of two A.P.s", the new common difference is lcm(d₁, d₂) and the range is capped by whichever sequence runs out first. Setters plant the un-capped value as a distractor — which is exactly what happened here. For (C), remember the identity sin x·cos x·cosec 2x = 1/2: it is the whole reason AM–GM works on that expression.
Answer: (A) → (r) c³; (B) → (p); (C) → (s) 13.5; (D) → (q) n(n²+11)/6. ⚠ Flag: the true largest common term in (B) is 521, not the printed 531; and 13.5 in (C) is an AM–GM bound that is not actually attained (true infimum 7 + 5√2 ≈ 14.07).

The sum of n terms of the series 1·5·9 + 2·6·10 + 3·7·11 + ….. is n(n+p)(n+4q)(n+3r)/4. Find the values of p, q and r.
M8DL3VRecapQ3iProduct of three A.P. factors → Σn³, Σn², Σn
🟡 SimilarSum to n terms 1.3.5…
p = 1, q = 2, r = 3
Concept Each term is a product of three numbers taken from three different A.P.s that run in lockstep. Expand the general term into a cubic in k, sum term-by-term with the three standard Σ formulas, then factorise the result — the factorisation must come out clean because the printed answer is a product of four brackets.
Formula Σk = n(n+1)/2, Σk² = n(n+1)(2n+1)/6, Σk³ = [n(n+1)/2]². These three cover any polynomial general term of degree ≤ 3.
Solution
Given sum of n terms of 1·5·9 + 2·6·10 + 3·7·11 + … equals n(n + p)(n + 4q)(n + 3r)/4
Find the values of p, q and r
1. Read the three columns of factors: 1, 2, 3, … = k; 5, 6, 7, … = k + 4; 9, 10, 11, … = k + 8.
2. So T_k = k(k + 4)(k + 8) = k(k² + 12k + 32) = k³ + 12k² + 32k.
3. Sum: Sₙ = Σk³ + 12Σk² + 32Σk = n²(n+1)²/4 + 12·n(n+1)(2n+1)/6 + 32·n(n+1)/2.
4. Simplify each piece: = n²(n+1)²/4 + 2n(n+1)(2n+1) + 16n(n+1).
5. Take out n(n+1)/4: Sₙ = [n(n+1)/4]·[n(n+1) + 8(2n+1) + 64].Multiply the last two pieces by 4/4 so the common factor is exact: 2n(n+1)(2n+1) = [n(n+1)/4]·8(2n+1) and 16n(n+1) = [n(n+1)/4]·64.
6. Bracket: n² + n + 16n + 8 + 64 = n² + 17n + 72 = (n + 8)(n + 9).
7. Therefore Sₙ = n(n+1)(n+8)(n+9)/4.
8. Match with n(n+p)(n+4q)(n+3r)/4: p = 1; 4q = 8 ⟹ q = 2; 3r = 9 ⟹ r = 3.
9. Check n = 1: 1·2·9·10/4 = 180/4 = 45 = 1·5·9 ✓. Check n = 2: 2·3·10·11/4 = 660/4 = 165, and 45 + 2·6·10 = 45 + 120 = 165 ✓
⚡ JEE Trick For products of A.P. factors there is a shortcut: Sₙ = [product of the (r+1) consecutive-style factors] / [(r+1)·(common difference)] when the factors are consecutive. Here the factors are k, k+4, k+8 (step 4), and the answer n(n+1)(n+8)(n+9)/4 shows the pattern: extend the product by one factor and divide by 4 = (number of factors + 1) × … . Trap: matching the letters to the wrong slot — read 4q and 3r as whole coefficients, so q = 2 not 8.
Answer: p = 1, q = 2, r = 3 (so Sₙ = n(n+1)(n+8)(n+9)/4).
3 (ii)
The sum of n terms of the series 1·3·2² + 2·4·3² + 3·5·4² + ….. is n(n+p)(n+q)(n+3)(2n+r)/10. Find the values of p, q and r.
M8DL3VRecapQ3iiQuartic general term → Σn⁴ or the u(u+1) trick
🟡 SimilarSum to n terms of sp…
p = 1, q = 2, r = 3
Concept The general term is degree 4, so a brute-force Σk⁴ is possible but ugly. The elegant route: notice that k(k+2) and (k+1)² differ by exactly 1, so T_k = u(u + 1) with u = k² + 2k. That reduces the quartic to a quadratic in u and makes every coefficient obvious.
Formula T_k = k(k+2)(k+1)² = u(u+1), u = k² + 2k, giving T_k = k⁴ + 4k³ + 5k² + 2k. Then use Σk⁴ = n(n+1)(2n+1)(3n²+3n−1)/30 with the other three standard sums. u(u+1) = u² + u, and u² = (k²+2k)² = k⁴ + 4k³ + 4k².
Solution
Given sum of n terms of 1·3·2² + 2·4·3² + 3·5·4² + … equals n(n + p)(n + q)(n + 3)(2n + r)/10
Find the values of p, q and r
1. Factors: 1, 2, 3, … = k; 3, 4, 5, … = k + 2; 2², 3², 4², … = (k + 1)².
2. So T_k = k(k+2)(k+1)². Put u = k(k+2) = k² + 2k; then (k+1)² = k² + 2k + 1 = u + 1.
3. Hence T_k = u(u + 1) = u² + u = (k² + 2k)² + (k² + 2k) = k⁴ + 4k³ + 5k² + 2k.
4. Sum: Sₙ = Σk⁴ + 4Σk³ + 5Σk² + 2Σk = n(n+1)(2n+1)(3n²+3n−1)/30 + n²(n+1)² + 5n(n+1)(2n+1)/6 + n(n+1).
5. Pull out n(n+1)/30: Sₙ = [n(n+1)/30]·[(2n+1)(3n²+3n−1) + 30n(n+1) + 25(2n+1) + 30].
6. Expand (2n+1)(3n²+3n−1) = 6n³ + 9n² + n − 1. Add 30n² + 30n: 6n³ + 39n² + 31n − 1. Add 50n + 25: 6n³ + 39n² + 81n + 24. Add 30: 6n³ + 39n² + 81n + 54.
7. Factor out 3: 3(2n³ + 13n² + 27n + 18). Test n = −2: −16 + 52 − 54 + 18 = 0, so (n + 2) divides it: 2n³+13n²+27n+18 = (n+2)(2n² + 9n + 9) = (n+2)(n+3)(2n+3).
8. Therefore Sₙ = n(n+1)·3(n+2)(n+3)(2n+3)/30 = n(n+1)(n+2)(n+3)(2n+3)/10.
9. Match with n(n+p)(n+q)(n+3)(2n+r)/10: p = 1, q = 2, r = 3.
10. Check n = 1: 1·2·3·4·5/10 = 120/10 = 12 = 1·3·2² ✓. Check n = 2: 2·3·4·5·7/10 = 840/10 = 84, and 12 + 2·4·3² = 12 + 72 = 84 ✓
⚡ JEE Trick Spot the substitution u = k(k+2) whenever a product contains both k(k+2) and (k+1)²: they always differ by 1, so the term becomes u(u+1) and the degree effectively halves. Trap: expanding blindly into k⁴ + … and then mis-quoting Σk⁴ — the 3n²+3n−1 factor is the one everybody garbles.
Answer: p = 1, q = 2, r = 3 (so Sₙ = n(n+1)(n+2)(n+3)(2n+3)/10).
3 (iii)
The nth term of the sequence 2, 7, 16, 29, …… is pn² + qn + r. Find the values of p, q and r.
M8DL3VRecapQ3iiiMethod of differences → quadratic general term
🟡 SimilarFind the nth term an…
p = 2, q = −1, r = 1
Concept When the first differences of a sequence are themselves an A.P., the general term is a quadratic in n. The second difference is constant and equals 2 × (leading coefficient), which hands you p in one line; the remaining two unknowns come from two easy substitutions.
Formula If Tₙ = pn² + qn + r then 2nd difference = 2p. Because T(n+1) − T(n) = p(2n+1) + q is linear in n with slope 2p.
Solution
Given sequence 2, 7, 16, 29, … whose nth term is pn² + qn + r
Find the values of p, q and r
1. Write the terms: 2, 7, 16, 29.
2. First differences: 7 − 2 = 5, 16 − 7 = 9, 29 − 16 = 13.
3. Second differences: 9 − 5 = 4, 13 − 9 = 4 — constant 4, so the general term is quadratic.
4. Constant 2nd difference = 2p ⟹ 2p = 4 ⟹ p = 2.
5. Use n = 1: T₁ = 2 ⟹ 2(1) + q + r = 2 ⟹ q + r = 0.
6. Use n = 2: T₂ = 7 ⟹ 2(4) + 2q + r = 7 ⟹ 2q + r = −1.
7. Subtract: (2q + r) − (q + r) = −1 − 0 ⟹ q = −1, and then r = 1.
8. So Tₙ = 2n² − n + 1. Verify n = 3: 18 − 3 + 1 = 16 ✓ and n = 4: 32 − 4 + 1 = 29 ✓; predict n = 5: 50 − 5 + 1 = 46 (differences continue 17 ✓).
⚡ JEE Trick Constant k-th difference ⇒ polynomial of degree k, with leading coefficient = (constant difference)/k!. Here 4/2! = 2 = p, straight away. If instead the first differences form a G.P., the general term is "constant + geometric", not polynomial — that is the very next question type in this lesson.
Answer: p = 2, q = −1, r = 1 (so Tₙ = 2n² − n + 1).

Match Column-I — (A) The sum of all 2 digit odd numbers is; (B) If 200, x and 420 are in A.P., then x is equal to; (C) If the sum of first n natural numbers is 1/5 times the sum of their squares, then the value of n is; (D) The maximum sum of the series 20 + 19 (1/3) + 18 (2/3) + ….. is — with Column-II (p) 310, (q) 7, (r) 2.3, (s) 2475.
M8DL3VRecapQ4Four one-step A.P. / Σ-formula results
🟡 SimilarColumn - II
(A)→(s) 2475, (B)→(p) 310, (C)→(q) 7, (D)→(p) 310
Concept Four independent A.P. facts. Note that this grid deliberately re-uses one Column-II entry: both (B) and (D) land on 310. Matching questions do not promise a bijection, so never force one.
Formula Sₙ = (n/2)(first + last); A.M. of two numbers = (a+c)/2; Σn = n(n+1)/2, Σn² = n(n+1)(2n+1)/6; a decreasing A.P. has maximum sum at the last non-negative term. All four rows are one substitution each.
Solution
1. (A) Two-digit odd numbers: 11, 13, …, 99. Count = (99 − 11)/2 + 1 = 45.
2. Sum = (45/2)(11 + 99) = 45 × 55 = 2475 ⟹ (s).
3. (B) Three numbers in A.P. ⟹ the middle is the average: x = (200 + 420)/2 = 310 ⟹ (p).
4. (C) Condition: n(n+1)/2 = (1/5)·n(n+1)(2n+1)/6.

5. Sum from n = 2 to N: the sum telescopes to G₂ − GN+1 = 1/(F₁F₂) − 1/(FNFN+1).
6. With F₁ = F₂ = 1, the first piece is 1/(1 × 1) = 1.
7. As N → ∞ the Fibonacci numbers grow without bound, so 1/(FNFN+1) → 0.
8. Therefore Σn=2∞ 1/(Fn−1Fn+1) = 1.
9. Numerical check with F = 1, 1, 2, 3, 5, 8, 13, 21: terms are 1/(F₁F₃) = 1/2, 1/(F₂F₄) = 1/3, 1/(F₃F₅) = 1/10, 1/(F₄F₆) = 1/24, 1/(F₅F₇) = 1/65, 1/(F₆F₈) = 1/168. Running total: 0.5, 0.8333, 0.9333, 0.9750, 0.9904, 0.9964 — converging to 1 ✓
⚡ JEE Trick Every recurrence is a telescoping identity waiting to be used — rewrite it as "middle = last − first" and divide by the product of all three. This is the Vn-method in its purest form, and it works for Fibonacci, Lucas and any other second-order recurrence.
