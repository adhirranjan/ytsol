1Street car A→B, acceleration f = a − bx (x measured from A) — distance between the stations & the maximum velocityVariable acceleration a(x)A street car moves rectilinearly from station A to the next station B (from rest to rest) with an acceleration varying as f = a - bx🟢 Exactax = 2a/b; vmax = a/√b
Concept The acceleration is given as a function of position, not time, so use f = v·dv/dx and integrate in x. "Rest to rest" fixes the distance: the station B is the point where v returns to zero. The speed is largest where the acceleration changes sign, i.e. where f = 0. The trap is to set f = 0 for the stopping point; f = 0 gives the maximum speed, not the stop.
Formula v·dv/dx = a − bx ⇒ v² = 2ax − bx² Chain rule f = dv/dt = (dv/dx)(dx/dt) = v·dv/dx turns an a(x) law into a separable equation.
Solution
1. Write f = v·dv/dx = a − bx and separate: v dv = (a − bx) dx.
2. Integrate from rest at A (x = 0, v = 0): v²/2 = ax − bx²/2 ⇒ v² = 2ax − bx² = x(2a − bx).
3. The car stops again at B where v = 0 with x ≠ 0: 2a − bx = 0 ⇒ x = 2a/b.The root x = 0 is just station A itself.
4. v is maximum where dv/dx = 0, i.e. where f = a − bx = 0 ⇒ x = a/b (exactly midway).
5. Substitute: vmax² = 2a(a/b) − b(a/b)² = 2a²/b − a²/b = a²/b.
6. Sanity check: for 0 < x < a/b, f > 0 (speeding up); for a/b < x < 2a/b, f < 0 (braking) — exactly the rest-to-rest pattern of a tram between stops.At x = 2a/b the deceleration is f = a − 2a = −a, the mirror of the starting push +a.
7. Hence vmax = a/√b; this matches option (a).

⚡ JEE Trick f = a − bx is SHM-like about x = a/b, so the motion is symmetric: the stop is at twice the equilibrium distance (2a/b) and the peak speed sits at the centre. Quick dimension check: a/b is a length and a/√b has units of (m/s²)/(1/s) = m/s. Trap: option (d) uses x = a/b as the total distance, mixing up "f = 0" with "v = 0".
Answer: (a) x = 2a/b; vmax = a/√b.

Concept A steady horizontal wind adds a constant horizontal acceleration but touches nothing vertical. So the time of flight and the maximum height are exactly the ordinary projectile values; only the horizontal displacement grows by an extra ½a·T² term. The trap is to think the launch angle or H must be recomputed — they are not.
Formula x = (u cosθ)T + ½·(g/2)·T² with T = 2u sinθ/g. Standard results: R = u²sin2θ/g and H = u²sin²θ/(2g), both unchanged because g is unchanged.
Solution
1. Vertical motion is untouched by the horizontal wind ⇒ T = 2u sinθ/g and H = u²sin²θ/(2g) stay as given.
2. Ordinary horizontal part: (u cosθ)·T = u cosθ·(2u sinθ/g) = u²sin2θ/g = R.
3. Extra wind part: ½·(g/2)·T² = (g/4)·T².
4. Substitute T: (g/4)·(2u sinθ/g)² = (g/4)·(4u²sin²θ/g²) = u²sin²θ/g.The g² cancels, leaving a clean u²sin²θ/g.
5. Rewrite with H: u²sin²θ/g = 2·[u²sin²θ/(2g)] = 2H.
6. New range = ordinary part + wind part = R + 2H.

⚡ JEE Trick Spot that (g/4)T² is just twice H — no numbers needed. Trap: students add the wind but wrongly keep only R (forgetting the second half of the flight also drifts), or they re-solve for a new angle. Since only horizontal a changed, R gets a bonus of exactly 2H.
Answer: (d) R + 2H.

Concept In projectile motion the only force is gravity, which is vertical. So the horizontal component of velocity never changes: it is u cosθ at launch and still u cosθ at every later instant. Whenever the velocity makes an angle φ with the horizontal, its horizontal component is v cosφ. Equating the two gives v immediately; no time or height is needed. The trap is to use energy and get lost in the vertical part.
Formula v cosφ = u cosθ ⇒ v = u cosθ/cosφ = u cosθ·secφ ax = 0, so vx is a constant of the motion.
Solution
1. Resolve the launch velocity: ux = u cosθ, uy = u sinθ.
2. Gravity acts only along −y, so ax = 0 and vx = u cosθ for the whole flight.
3. At the instant the velocity makes angle φ with the horizontal, its horizontal component is v cosφ.This holds whether the particle is rising (φ above horizontal) or falling (φ below).
4. Equate: v cosφ = u cosθ.
5. Solve: v = u cosθ/cosφ = u cosθ·secφ.
6. Checks: φ = θ gives v = u (launch point, or the symmetric landing point); φ = 0 gives v = u cosθ, the speed at the top. Both correct.
