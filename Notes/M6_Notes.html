L-1

Introduction to Inequality & Linear Inequality in One Variable

  • Strict inequality: uses < or > (e.g. 5 < 9, 10 > 7).
  • Slack inequality: uses ≤ or ≥ (e.g. x ≥ 15, x ≤ 9) — endpoints included.
  • A linear inequality relates a linear expression to another by <, >, ≤, ≥ (e.g. 3x + 7 < 16).

Algebraic operation properties

core movesp < q ⇒ p + r < q + r · p < q ⇒ p − r < q − r r > 0: p < q ⇒ pr < qr · r < 0: p < q ⇒ pr > qr (FLIP)
  • If a > b > 0 then 1/a < 1/b, and aⁿ > bⁿ (n > 0).
  • x > y > 0, a > 1 ⇒ aˣ > aʸ ;   0 < a < 1 ⇒ aˣ < aʸ.
  • If a ≤ b ≤ c with a,b,c ∈ [0,∞) then a² ≤ b² ≤ c²; if a,b,c ∈ (−∞,0) then a² ≥ b² ≥ c².
Why the sign flips for a negative multiplier
Multiplying by a negative number reflects the number line about 0, so the order of any two numbers is reversed. That is why −2x ≥ 20 ⇒ x ≤ −10 (divide by −2 and flip), and −14x < 8 ⇒ x > 4/(−7). Treat every ×/÷ by a negative as a "flip" step and you never lose marks here.

Number-line representation

standard formsax + b ≤ 0 ⇒ x ≤ −b/a (a > 0) · −3 < 2x + 5 < 17 ⇒ −4 < x < 6 (double inequality)
💡 TipFor a double inequality (−1 ≤ ½x − 3 < 1), operate on all three parts simultaneously.
⚠ Trap"Solve … where x is an integer" changes the answer: solve over ℝ first, then keep only the integers in that range.

L-2

Systems of Linear Inequations & Two-Variable Inequalities

System in one variable

  • Solve each inequation separately, then take the intersection of the solution sets (the common region).
  • Example: 3x − 6 ≥ 0 gives [2, ∞); 4x − 10 ≤ 6 gives (−∞, 4]; intersection = [2, 4].
system ruleSolution of a system = ∩ (intersection) of the individual solution sets

Linear inequality in two variables

  • An ordered pair (x, y) is a solution if it makes the statement true (uses <, >, ≤, ≥ — never =).
  • Graphically, the line Ax + By = C splits the plane into two half-planes; test a point (usually origin) to pick the correct side.
  • The feasible region can be a bounded polygon, an unbounded region, or empty.
Origin test for a half-plane
For 2x + y ≤ 4, substitute (0,0): 0 ≤ 4 is true, so the origin's side is shaded. If the test gives a false statement (as (0,0) in 3x + 4y ≥ 12 gives 0 ≥ 12), the region is on the opposite side. Boundary lines are included for ≤/≥ (solid) and excluded for </> (dashed).
💡 TipFor a system in two variables, shade every half-plane; the overlap is the answer. If half-planes are disjoint (parallel lines pointing apart), the solution is empty.

L-3

Modulus (Absolute Value) Function, Equations & Inequalities

definitionf(x) = |x| = { −x, x < 0 ;   x, x ≥ 0 } · domain = ℝ, range = [0, ∞)

Key properties

  • √(x²) = |x| ;   x² = |x|² ;   |−x| = |x| ;   |xⁿ| = |x|ⁿ.
  • |x₁x₂…xₙ| = |x₁||x₂|…|xₙ| ;   |x/y| = |x|/|y| (y ≠ 0).
  • a² < b² ⇒ |a| < |b| ;   |x − a| < b ⇒ x ∈ (a − b, a + b).
  • |x + y| = |x| + |y| when x, y have the same sign (or one is 0); |x + y| < |x| + |y| when they have opposite signs (triangle inequality).

Solving modulus equations

types|X| = p (p > 0) ⇒ X = p or X = −p · |X| = |Y| ⇒ X = Y or X = −Y · |X| = (−ve) ⇒ no solution
Isolate first, then split
For 2|5x − 1| − 3 = 9: first isolate the modulus — add 3, divide by 2 to get |5x − 1| = 6 — then split into 5x − 1 = 6 or 5x − 1 = −6, giving x = 7/5 or x = −1. Always isolate |·| before splitting; and if the isolated value equals a negative number, stop — there is no solution.
⚠ Trap|x + 2| = −3 (or any modulus = negative) has no solution: absolute value is never negative. But |x| ≥ (any negative) is true for all real x.

Quadratic Inequalities

formsax² + bx + c ⋛ 0 (a ≠ 0) — factor as a(x − α)(x − β), α < β

Sign rule (a > 0, real roots α < β)

InequalitySolution
(x − α)(x − β) > 0x ∈ (−∞, α) ∪ (β, ∞)  ("outside the roots")
(x − α)(x − β) < 0x ∈ (α, β)  ("between the roots")
≥ 0 / ≤ 0same, with endpoints included
⚠ TrapIf the coefficient of x² is negative, first multiply the whole inequality by −1 (and flip the sign) so a > 0 before applying the sign rule.
"Always positive / always negative" via the discriminant
A quadratic ax² + bx + c keeps one sign for all real x only when it has no real roots, i.e. D = b² − 4ac < 0. Then: a > 0, D < 0 ⇒ expression > 0 ∀x; a < 0, D < 0 ⇒ expression < 0 ∀x. Parameter ("find k") problems combine the sign of a with D < 0.
Worked examples from the module
Book Example · L-4
Solve the quadratic inequality x² − 2x − 3 < 0.
D = (−2)² − 4(1)(−3) = 16 > 0. Factor: x² − 3x + x − 3 = (x + 1)(x − 3) < 0.
Product negative ⇒ between the roots −1 and 3.
x ∈ (−1, 3)
Book Example · L-4
Solve 2x² + x < 15.
Standard form: 2x² + x − 15 < 0 ⇒ (2x − 5)(x + 3) < 0.
Critical points −3 and 5/2; sign analysis gives negative between them.
x ∈ (−3, 5/2)
Book Example · L-4
For what values of k is x² − (k − 3)x − k + 6 > 0 valid for all real x?
Coefficient of x² is 1 > 0, so need discriminant D < 0.
(k − 3)² − 4(−k + 6) < 0 ⇒ k² − 2k − 15 < 0 ⇒ (k + 3)(k − 5) < 0.
k ∈ (−3, 5)
Book Example · L-4
Solve |x² − 3x − 3| > |x² + 7x − 13|.
Both sides non-negative ⇒ square: (x² − 3x − 3)² > (x² + 7x − 13)².
Difference of squares factorises to (x + 4)(x − 2)(x − 1) < 0; solve by intervals.
x < −4 or 1 < x < 2, i.e. x ∈ (−∞, −4) ∪ (1, 2)
L-5

Rational Inequalities — Wavy Curve (Method of Intervals)

target formf(x)/g(x) ⋛ 0 — reduce to a product/quotient of linear factors, then read signs off the number line

The five steps

  • 1. Make the RHS zero and factor into linear factors.
  • 2. Make every factor's x-coefficient positive (multiply by −1 and flip if needed).
  • 3. Set each factor = 0 to get the critical points; mark them on the number line.
  • 4. Put + on the extreme right; alternate signs across each simple root.
  • 5. Pick the +regions (for > 0) or −regions (for < 0) per the inequality.
⚠ TrapAn even-power factor (e.g. (x + 4)²) touches the axis but the sign does not change there. An odd-power factor flips the sign. Denominator roots are always excluded (open circles), even for ≤/≥.
Why signs alternate at simple roots
Between consecutive critical points every factor keeps a constant sign, so the whole product does too. Crossing a simple (odd-multiplicity) root flips exactly one factor's sign, flipping the product. A repeated even root flips a factor an even number of times — net no change — so the curve "bounces" without crossing. That is the whole logic of the wavy curve.
Worked examples from the module
Book Example · L-5
Solve (3x − x²)/(x + 4)² ≥ 0.
Factor: x(3 − x)/(x + 4)² ≥ 0. Make coefficients positive: −x(x − 3)/(x + 4)² ≥ 0 ⇒ x(x − 3)/(x + 4)² ≤ 0.
Critical points x = 0, 3 (simple) and x = −4 (double, sign does not change; excluded).
x ∈ [0, 3]
Book Example · L-5
Solve (x − 1)²(x − 2) / [(4 − x)(x − 3)⁵] ≥ 0.
Make coefficients positive: rewrite (4 − x) = −(x − 4), giving (x − 1)²(x − 2)/[(x − 4)(x − 3)⁵] ≤ 0.
Critical points x = 1 (double), 2, 3, 4; (x − 1)² does not change sign; x = 3, 4 excluded (denominator).
x ∈ (−∞, 2] ∪ (3, 4) − {1}
Book Example · L-5
Find the solution of (x + 2)²(x − 3) ≤ 0.
Critical points x = −2 (double) and x = 3. The (x + 2)² factor never changes sign.
Expression is ≤ 0 to the left of 3; x = −2 also satisfies (value 0).
x ∈ (−∞, 3]
Book Example · L-5
Find all x for which 2x³ + 5x² + 3x < x² + x.
Bring to one side: 2x³ + 4x² + 2x < 0 ⇒ 2x(x² + 2x + 1) < 0 ⇒ 2x(x + 1)² < 0.
Critical points x = 0 and x = −1 (double, no sign change; excluded). Negative for x < 0, x ≠ −1.
x ∈ (−∞, −1) ∪ (−1, 0)
