1 (i)Fill in the blanks: A cubic equation x^3 + 5x^2 + 7x + 5 = 0 then sum of roots ______Theory of equationsCubic and Bi-quadratic Equations || Relation Between Roots & Coefficients🟡 Similar−5
Concept A polynomial equation locks its coefficients to the symmetric functions of its roots, so a question about the sum of the roots never requires finding the roots. If a cubic ax³ + bx² + cx + d = 0 has roots α, β, γ, then it factors as a(x − α)(x − β)(x − γ); expanding and matching the x² term gives −a(α + β + γ) = b. That one comparison is the entire content of Vieta's first relation. Here the cubic is monic, so the work collapses to reading off one coefficient and flipping its sign.
Formula For ax³ + bx² + cx + d = 0 : Σα = −b/a, Σαβ = c/a, αβγ = −d/a.. The signs alternate because each elementary symmetric function collects one factor of (−1) for every root it multiplies together.
Solution
1. Compare x³ + 5x² + 7x + 5 = 0 with ax³ + bx² + cx + d = 0 : a = 1, b = 5, c = 7, d = 5.
2. a = 1 ≠ 0, so the equation really is cubic and carries exactly three roots counted with multiplicity. If the leading coefficient could vanish the degree would drop and Vieta's cubic relations would not apply.
3. Sum of roots = α + β + γ = −b/a = −5/1 = −5.
4. Companion values from the same table: Σαβ = c/a = 7 and αβγ = −d/a = −5.
5. Rational-root candidates are ±1, ±5, and f(−1) = 2, f(−5) = −30, f(1) = 18, f(5) = 290, so no root is rational. This is exactly why the coefficient route is the only practical one here.
6. All coefficients are positive, so f(x) > 0 for every x ≥ 0 ⇒ no positive root; every real root is negative, which agrees with a negative sum. A sanity check that costs one glance at the signs.
  x^3 + 5x^2 + 7x + 5 = 0    (a=1, b=5, c=7, d=5)
  ----------------------------------------------
  sum       alpha+beta+gamma = -b/a = -5/1 = -5
  pair sum  S(alpha*beta)    =  c/a =  7/1 =  7
  product   alpha*beta*gamma = -d/a = -5/1 = -5
  ----------------------------------------------
  sign pattern: -b/a , +c/a , -d/a  (alternating)
  ANSWER: sum of roots = -5
⚡ JEE Trick The trap is dropping the minus sign and answering +5, which is what happens when a student memorises "sum = b/a". Anchor the sign by remembering the alternation −, +, − running down the coefficient list. A second trap is dividing by a leading coefficient that is not 1 — harmless here since a = 1, but fatal the moment the cubic reads 2x³ + 5x² + …
Answer: sum of roots = −5.
1 (ii)Fill in the blanks: A cubic equation x^3 + 5x^2 + 7x + 5 = 0 then sum of product of two at time ______Theory of equationsCubic and Bi-quadratic Equations || Relation Between Roots & Coefficients🟡 Similar7
Concept The second symmetric function of the roots of a cubic is Σαβ = αβ + βγ + γα, the sum of the products taken two at a time. It appears when a(x − α)(x − β)(x − γ) is expanded: the x term collects every product of exactly two roots, each carrying two factors of (−1), so the sign comes out positive. A cubic has C(3,2) = 3 such pairs, which is why the answer is a three-term sum and not something longer. As with the sum of roots, the coefficients alone settle it.
Formula For ax³ + bx² + cx + d = 0 : Σα = −b/a, Σαβ = c/a, αβγ = −d/a.. The middle relation is the only one of the three with a plus sign, because (−1)² = +1 for a two-root product.
Solution
1. Read the coefficients of x³ + 5x² + 7x + 5 = 0 : a = 1, b = 5, c = 7, d = 5, and a ≠ 0 so the cubic relations apply.
2. The quantity asked for is Σαβ = αβ + βγ + γα, i.e. the coefficient-of-x relation, not the coefficient-of-x² one. Position in the polynomial is what tells you which symmetric function you are being asked about.
3. Σαβ = c/a = 7/1 = 7.
4. Identity check on the same equation: Σα = −b/a = −5 and αβγ = −d/a = −5.
5. These feed the standard consequence α² + β² + γ² = (Σα)² − 2Σαβ = 25 − 14 = 11. Positive, as a sum of squares of real numbers must be — but note it would also come out positive for complex conjugate roots, so it is a weak test.
6. Also 1/α + 1/β + 1/γ = Σαβ/αβγ = 7/(−5) = −7/5, the usual reason Σαβ is worth extracting. Reciprocal sums always reduce to e₂/e₃.
  x^3 + 5x^2 + 7x + 5 = 0    (a=1, b=5, c=7, d=5)
  ----------------------------------------------
  e1 = alpha+beta+gamma      = -b/a = -5
  e2 = ab + bc + ca          =  c/a =  7   <== asked
  e3 = alpha*beta*gamma      = -d/a = -5
  ----------------------------------------------
  check  Sa^2 = e1^2 - 2e2 = 25 - 14 = 11
  ANSWER: sum of products two at a time = 7
⚡ JEE Trick The distractor here is −7: students who have just done part (i) carry the minus sign forward mechanically. Only the odd-numbered symmetric functions (Σα and αβγ) pick up the sign flip; the even one does not. The other trap is confusing "sum of products two at a time" with "product of the roots", which is −5, not 7.
Answer: Σαβ = 7.

Concept For a quadratic ax² + bx + c = 0 with a ≠ 0, dividing through by a gives x² + (b/a)x + (c/a) = 0, and any monic quadratic with roots α, β is exactly (x − α)(x − β) = x² − (α+β)x + αβ. Comparing the two forms term by term is the whole derivation of the sum and product relations. The division by a is the step people skip, and it is precisely the step that matters whenever the leading coefficient is not 1. Here a = 5, so the constant term must be scaled before it can be read as a product of roots.
Formula For ax² + bx + c = 0 : α + β = −b/a and αβ = c/a.. Both come from matching x² + (b/a)x + (c/a) against x² − (α+β)x + αβ, so a divides into both relations.
Solution
1. Identify the coefficients of 5x² + 7x − 25 = 0 : a = 5, b = 7, c = −25, and a = 5 ≠ 0 so it is a genuine quadratic.
2. Product of roots = αβ = c/a = (−25)/5 = −5.
3. Sum of roots = α + β = −b/a = −7/5, kept only as a cross-check.
4. D = b² − 4ac = 7² − 4(5)(−25) = 49 + 500 = 549 > 0, so the roots are real, distinct and irrational. 549 = 9·61 is not a perfect square, so √549 = 3√61 stays surd.
5. αβ = −5 < 0 forces the two roots to have opposite signs, one positive and one negative. A negative product can only arise from roots straddling zero, which also re-confirms D > 0.
6. Explicit check: roots are (−7 ± 3√61)/10, and their product is (49 − 9·61)/100 = (49 − 549)/100 = −500/100 = −5. The (p−q)(p+q) = p² − q² collapse is why this check is fast.
  5x^2 + 7x - 25 = 0     (a=5, b=7, c=-25)
  ----------------------------------------------
  sum      alpha + beta = -b/a = -7/5
  product  alpha * beta =  c/a = -25/5 = -5
  ----------------------------------------------
  D = 49 + 500 = 549 > 0  -> real, distinct

⚡ JEE Trick The engineered distractor is −25: the constant term read straight off the page without dividing by a = 5. The relation is c/a, not c, and the same slip turns the sum into −7 instead of −7/5. Whenever the leading coefficient is not 1, write the division explicitly rather than trusting your eye.

1 (iv)Fill in the blanks: A biquadratic px^4 + 5x^2 + 7x + 3 = 0 here a root x + 1 then value of p ______Theory of equationsQUADRATIC EQUATION 01 | Remainder Theorem, Factor Theorem | Maths | Pure English | Class 11th /JEE🟡 Similarp = −1
Concept The factor theorem says (x − k) divides a polynomial f(x) exactly when f(k) = 0, so naming (x + 1) as a factor is the same as declaring x = −1 a root. Once a root is known, substituting it turns the polynomial identity into a plain linear equation in the unknown coefficient. This is far cheaper than long division, because division would force you to carry p through every line. The only extra care needed is checking that the value of p found does not destroy the stated degree of the equation.
Formula (x − k) is a factor of f(x) ⇔ f(k) = 0; here (x + 1) a factor ⇒ f(−1) = 0.. Write x + 1 as x − (−1) so the root is read off with the correct sign.
Solution
1. Let f(x) = px⁴ + 5x² + 7x + 3; note the x³ term is absent, so its coefficient is 0.
2. (x + 1) a factor ⇒ f(−1) = 0, i.e. x = −1 is a root. Root and factor are the same statement; substituting is the shortcut.
3. f(−1) = p(−1)⁴ + 5(−1)² + 7(−1) + 3 = p + 5 − 7 + 3 = p + 1.
4. Set p + 1 = 0 ⇒ p = −1.
5. Check the degree survives: p = −1 ≠ 0, so f stays biquadratic (degree 4) with leading coefficient −1. Had the algebra produced p = 0 the equation would have collapsed to a cubic and the question would have been self-contradictory.
6. Verify by synthetic division of −x⁴ + 0x³ + 5x² + 7x + 3 by (x + 1): the remainder is 0 and the quotient is −x³ + x² + 4x + 3. A zero remainder is independent proof that the factor really divides.
  f(x) = p x^4 + 0 x^3 + 5 x^2 + 7 x + 3
  root x = -1  (since x + 1 is a factor)
  ----------------------------------------------
  f(-1) = p(1) + 5(1) + 7(-1) + 3 = p + 1 = 0
              =>  p = -1
  ----------------------------------------------
  synthetic div by -1:  -1  1  4  3 | rem 0  OK
  ANSWER: p = -1
⚡ JEE Trick The classic slip is substituting x = +1 because the factor reads "x + 1"; that gives p + 15 = 0 and the wrong value p = −15. Always rewrite the factor as x − (−1) before reading the root. The second habit worth keeping is the degree check: any p that makes the leading coefficient vanish must be rejected in a "biquadratic" question.
Answer: p = −1.

Concept For a degree-n equation a₀xⁿ + a₁xⁿ⁻¹ + … + aₙ = 0, the elementary symmetric function eₖ (sum of products of the roots taken k at a time) equals (−1)ᵏ aₖ/a₀. Every row of this table is one instance of that single rule, so the only real work is counting which k is being asked for and then locating the coefficient k places to the right of the leading one. The sign is decided purely by the parity of k, and the denominator is always the leading coefficient. Getting the mapping right is therefore an exercise in careful indexing, not in algebra.
Formula eₖ = Σ(products of k roots) = (−1)ᵏ aₖ/a₀, so e₁ = −a₁/a₀, e₂ = +a₂/a₀, e₃ = −a₃/a₀.. Each root contributes one factor of (−1) when (x − α) is expanded, so k roots contribute (−1)ᵏ.
Solution

2. (B) 5x⁴ + 7x³ + 3x² + 5x + 10 = 0 asks for Σαβ = e₂ = +a₂/a₀ = 3/5 ⇒ matches (s). Here a₀ = 5, so the division that was invisible in (A) becomes the whole point.
3. (C) 3x⁵ + 5x⁴ + 3x³ + 9x² + 5x + 3 = 0 asks for Σα₁α₂α₃ = e₃ = −a₃/a₀ = −9/3 = −3 ⇒ matches (r).
4. In (C) the coefficient three places right of the leading 3 is the coefficient of x², namely 9 — not the 3 sitting on x³. Index by position from the left, never by the power of x, or every odd-degree case goes wrong.
5. (D) x³ + 3x² + 5x + 9 = 0 asks for αβγ = e₃ = −a₃/a₀ = −9/1 = −9 ⇒ matches (p).
6. Every entry of Column-II is used exactly once, and (q) 3, (s) 3/5, (r) −3, (p) −9 are all consumed, so the mapping is consistent. A one-to-one check catches an indexing error instantly, since a slip usually leaves one option unused and another doubled.

Concept Building an equation from its roots is Vieta's relations run backwards: instead of reading coefficients to get symmetric functions, you compute the symmetric functions of the known roots and write the coefficients from them. For a monic cubic with roots α, β, γ the equation is simply (x − α)(x − β)(x − γ) = 0, and expanding it gives x³ − e₁x² + e₂x − e₃ = 0. The alternating signs in that expansion are the entire mechanism. Because the leading coefficient is 1, no division is needed anywhere.
Formula x³ − (Σα)x² + (Σαβ)x − αβγ = 0, i.e. p = −Σα, q = Σαβ, r = −αβγ.. Matching this against x³ + px² + qx + r = 0 term by term is the entire solution.
Solution
1. The printed equation x³ + px + qx + r = 0 has no x² term, so it would demand Σα = 0; but 1 + 2 + 3 = 6, so the misprint must be read as x³ + px² + qx + r = 0. A cubic with a missing x² term always means its roots sum to zero — a one-line test that exposes the typo.
2. Roots α = 1, β = 2, γ = 3 give e₁ = Σα = 1 + 2 + 3 = 6.
3. e₂ = Σαβ = (1)(2) + (2)(3) + (3)(1) = 2 + 6 + 3 = 11.
4. e₃ = αβγ = (1)(2)(3) = 6.
5. Hence p = −e₁ = −6, q = e₂ = 11, r = −e₃ = −6. Only p and r flip sign; the middle coefficient does not, matching the ± alternation.
6. Expand directly as a check: (x − 1)(x − 2)(x − 3) = (x − 1)(x² − 5x + 6) = x³ − 6x² + 11x − 6. The expansion reproduces exactly the same three numbers, so no sign has slipped.
  roots 1, 2, 3   (monic cubic)
  ----------------------------------------------
  e1 = 1+2+3        = 6   ->  p = -e1 = -6
  e2 = 2 + 6 + 3    = 11  ->  q = +e2 =  11
  e3 = 1*2*3        = 6   ->  r = -e3 = -6
  ----------------------------------------------
  (x-1)(x-2)(x-3) = x^3 - 6x^2 + 11x - 6   OK
  ANSWER: p = -6, q = 11, r = -6
⚡ JEE Trick The trap is copying the symmetric functions straight in as p = 6, q = 11, r = 6 without the alternating signs; only the even-position coefficient q escapes the flip. A second trap is the printed misprint itself — "px + qx" collapses to a single linear term and cannot host three roots summing to 6, so read it as px². Expanding the factored form takes ten seconds and settles both issues.
Answer: p = −6, q = 11, r = −6.
3 (ii)Find the values of p, q, r: If px^3 + qx^2 + rx + 1 = 0 have roots 2, -1, 1 then values of p, q, r. Value of p = ______, Value of q = ______, Value of r = ______Theory of equationsCubic and Bi-quadratic Equations || Relation Between Roots & Coefficients🟡 Similarp = 1/2, q = −1, r = −1/2
Concept This is the reverse of the usual exercise: the roots are known and three coefficients are unknown, but the constant term is pinned at 1. Because Vieta's relations all divide by the leading coefficient p, the fixed constant term is what determines p, and only then do q and r follow. The cleanest route is to write the cubic in factored form p(x − α)(x − β)(x − γ) = 0, expand once, and match all four coefficients at a stroke. That avoids solving three separate Vieta equations that all contain p.
Formula px³ + qx² + rx + 1 ≡ p(x − α)(x − β)(x − γ), equivalently Σα = −q/p, Σαβ = r/p, αβγ = −1/p.. The last relation contains only p, so it is the one to solve first.
Solution
1. Roots are α = 2, β = −1, γ = 1, so αβγ = (2)(−1)(1) = −2.
2. αβγ = −(constant)/p = −1/p ⇒ −1/p = −2 ⇒ p = 1/2. Start here because this is the only relation free of q and r.
3. Σα = 2 − 1 + 1 = 2, and Σα = −q/p ⇒ q = −p·Σα = −(1/2)(2) = −1.
4. Σαβ = (2)(−1) + (−1)(1) + (1)(2) = −2 − 1 + 2 = −1, and Σαβ = r/p ⇒ r = p·(−1) = −1/2.
5. p = 1/2 ≠ 0, so the equation is genuinely cubic and all three Vieta relations were legitimate. If the constant-term equation had forced p = 0 the problem would have been inconsistent.
6. Check by expansion: (1/2)(x − 2)(x + 1)(x − 1) = (1/2)(x − 2)(x² − 1) = (1/2)(x³ − 2x² − x + 2) = (1/2)x³ − x² − (1/2)x + 1. The constant lands on exactly 1, confirming p was fixed correctly.
  p x^3 + q x^2 + r x + 1 = 0 ; roots 2, -1, 1
  ----------------------------------------------
  product = -1/p = (2)(-1)(1) = -2  ->  p = 1/2
  sum     = -q/p = 2   -> q = -(1/2)(2) = -1
  pairsum =  r/p = -1  -> r =  (1/2)(-1) = -1/2
  ----------------------------------------------
  check (1/2)(x-2)(x+1)(x-1)
      = 0.5x^3 - x^2 - 0.5x + 1        OK
  ANSWER: p = 1/2, q = -1, r = -1/2
⚡ JEE Trick Most students try to start from the sum of roots and get stuck with one equation in two unknowns; the product relation is the only one with a single unknown, so it must go first. The other trap is the sign of the product relation: αβγ = −d/p with d = 1, so it is −1/p, not 1/p, and the sign error would give p = −1/2 and flip q and r as well.
Answer: p = 1/2, q = −1, r = −1/2.

Concept A quartic has four Vieta relations, one per elementary symmetric function, and each is (−1)ᵏ aₖ/a₀. When the roots are all given, every relation becomes a direct evaluation, so any coefficient that is also printed acts as a consistency check rather than an unknown. That is the situation here: p, q, r are unknown but the x² coefficient is printed, so it must agree with e₂ computed from the roots. Overdetermined data of this kind is exactly where printing errors surface, and it should always be tested rather than assumed.
Formula For a₀x⁴ + a₁x³ + a₂x² + a₃x + a₄ = 0 : e₁ = −a₁/a₀, e₂ = a₂/a₀, e₃ = −a₃/a₀, e₄ = a₄/a₀.. Signs alternate with k, and every relation is divided by the leading coefficient a₀ = 2.
Solution
1. Roots 1, −1, 2, 3 give e₁ = 1 − 1 + 2 + 3 = 5, so −p/2 = 5 ⇒ p = −10.
2. e₂ = (1)(−1) + (1)(2) + (1)(3) + (−1)(2) + (−1)(3) + (2)(3) = −1 + 2 + 3 − 2 − 3 + 6 = 5, so the x² coefficient must be 2e₂ = 10. The paper prints 3 here, which no choice of p, q, r can repair — the data is contradictory.
3. e₃ = (1)(−1)(2) + (1)(−1)(3) + (1)(2)(3) + (−1)(2)(3) = −2 − 3 + 6 − 6 = −5, so −q/2 = −5 ⇒ q = +10.
4. e₄ = (1)(−1)(2)(3) = −6, so r/2 = −6 ⇒ r = −12.
5. Direct expansion confirms it: 2(x − 1)(x + 1)(x − 2)(x − 3) = 2(x² − 1)(x² − 5x + 6) = 2x⁴ − 10x³ + 10x² + 10x − 12. Pairing (x−1)(x+1) first turns the quartic into a product of two quadratics.
6. Reading off that expansion: p = −10, x² coefficient 10, q = +10, r = −12 — so the key's q = −10 carries a sign error. e₃ is negative and the relation itself carries a minus, and the two minuses cancel to give a positive q.

1In a biquadratic equation, the sum of all roots is: (Level-1) (a) -a (b) -b/a (c) -c/a (d) -d/aRelation between coefficients and rootsCubic and Bi-quadratic Equations || Relation Between Roots & Coefficients🟡 Similarb−b/a
Concept "Biquadratic" is the standard name for a degree-four equation, written ax⁴ + bx³ + cx² + dx + e = 0 with a ≠ 0. Over the complex numbers it has exactly four roots counted with multiplicity, and factoring it as a(x − α)(x − β)(x − γ)(x − δ) and expanding lets every coefficient be read as a symmetric function of those roots. The x³ term of that expansion is −a(α + β + γ + δ), so equating it to bx³ gives the sum of the roots at once. The pattern is identical to the quadratic and cubic cases — only the coefficient's position changes.
Formula For ax⁴ + bx³ + cx² + dx + e = 0 : Σα = −b/a, Σαβ = c/a, Σαβγ = −d/a, αβγδ = e/a.. The sum of the roots always uses the coefficient one place right of the leading one, whatever the degree.
Solution
1. Write the biquadratic as a(x − α)(x − β)(x − γ)(x − δ) = 0 with a ≠ 0, which is legitimate because a degree-4 polynomial splits completely over ℂ.
2. Expanding, the x³ coefficient collects one root at a time with one factor of (−1): it equals −a(α + β + γ + δ).
3. Matching that with the given x³ coefficient b: −a·Σα = b ⇒ Σα = −b/a, which is option (b).
4. Option (a) −a is dimensionally impossible — the sum of roots must be a ratio of coefficients, never a bare coefficient. Scaling the whole equation by any k leaves the roots unchanged, so only ratios can appear.
5. Option (c) −c/a is wrong on two counts: c/a is Σαβ and it carries a plus sign, not a minus.
6. Option (d) −d/a is the sum of products taken three at a time, Σαβγ, not the sum of the roots. It is the correct-looking decoy because its sign is right; only its position is wrong.

Formula tan(A + B) = (tanA + tanB)/(1 − tanA·tanB), sin²θ = tan²θ/(1 + tan²θ). The first needs only Vieta's two numbers; the second avoids finding the angle.
Solution
1. From x² − 2x + 2 = 0: tanA + tanB = 2 and tanA·tanB = 2.
2. tan(A + B) = 2/(1 − 2) = 2/(−1) = −2. The denominator 1 − product is where the whole question is decided.
3. sin²(A + B) = tan²/(1 + tan²) = (−2)²/(1 + (−2)²) = 4/5.
4. Consistency: with tan = −2, sin(A + B) = ∓2/√5 and cos(A + B) = ±1/√5, so sin² + cos² = 4/5 + 1/5 = 1 ✓. The ambiguous sign disappears on squaring, so no quadrant analysis is needed.
5. Note D = 4 − 8 = −4, so tanA and tanB are the conjugates 1 ± i and the angles are not real. The working is a formal identity in the two Vieta numbers, so the value 4/5 stands regardless.
6. Hence sin²(A + B) = 4/5, option (a).
  x^2 - 2x + 2 = 0 : tanA + tanB = 2 , product = 2
  tan(A+B) = (tanA + tanB)/(1 - tanA tanB)
           = 2/(1 - 2) = -2
  sin^2 t = tan^2 t / (1 + tan^2 t)
          = 4/(1 + 4) = 4/5
  cos^2 t = 1/(1 + tan^2 t) = 1/5   (sums to 1)
  D = 4 - 8 = -4 : roots 1 +- i, identity is formal
⚡ JEE Trick The single fatal slip is writing 1 + tanA·tanB in the denominator, which gives tan(A + B) = 2/3 and sin² = 4/13 — not among the options, which is itself the warning that you dropped the minus. Distractor (c) 3/5 and (d) 1/4 have no derivation from the correct tangent value; the only companion value that is genuinely meaningful is cos²(A + B) = 1/5. Whenever roots are tangents, go straight through tan(A + B) rather than trying to identify A and B.
Answer: (a) 4/5.
