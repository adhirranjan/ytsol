1For a 2s orbital, the number of radial nodes is?Radial nodeswatch?v=DukLTL1mV9g🟢 Exactb1
Concept A radial node is a spherical surface (a certain distance r from the nucleus) on which the wave function ψ = 0, so the probability ψ² of finding the electron there is exactly zero. As you walk outward from the nucleus in a 2s orbital, ψ starts positive, passes through zero once, and becomes negative — that single crossing is its radial node. The count comes straight from the quantum numbers n and ℓ, no plotting needed.
Formula radial nodes = n − ℓ − 1 of the total n−1 nodes, ℓ are angular (planar/conical), so the spherical ones left over are n−ℓ−1. Data: for 2s, n = 2 and ℓ = 0 (the letter s means ℓ = 0).
Solution
1. Read the quantum numbers from the label "2s": the digit gives n = 2, the letter s gives ℓ = 0.s, p, d, f correspond to ℓ = 0, 1, 2, 3.
2. Apply the formula: radial nodes = n − ℓ − 1 = 2 − 0 − 1 = 1.
3. Cross-check with the total: total nodes = n − 1 = 1, angular nodes = ℓ = 0, so all 1 node must be radial — consistent.radial + angular must always add up to n − 1.
4. Physical picture: the 2s orbital is a small inner sphere of one sign of ψ wrapped in an outer shell of opposite sign, separated by exactly one spherical nodal surface. So the answer is 1 — option (b).
 orbital   n   ℓ   radial = n−ℓ−1   angular = ℓ   total = n−1
 1s        1   0   0                0             0
 2s        2   0   1  <-- answer    0             1
 3s        3   0   2                0             2
⚡ JEE Trick For any ns orbital the radial-node count is instant: ℓ = 0, so radial = n − 1 (1s → 0, 2s → 1, 3s → 2). Trap: students blurt "0" because 1s has none, or quote the total node formula n − 1 for a p/d orbital where it no longer equals the radial count — always subtract ℓ first.
Answer: (b) 1 radial node.
2For which orbital is the radius of maximum probability farthest from the nucleus?Radial probabilityA-RADPROB🟡 Similarc3s
Concept The radial probability distribution 4πr²ψ² tells us how likely the electron is to be found at a distance r from the nucleus. Its outermost peak — the most probable distance of the last, valence-like maximum — moves outward as the principal quantum number n grows, because higher shells are physically larger. So "farthest from the nucleus" is really asking "which option has the largest n?" (with ℓ breaking ties only slightly).
Formula most-probable outermost radius scales as rmax ∝ n²/Z (Bohr-like), so for the same atom a bigger n ⇒ a larger r. Each extra shell (higher n) adds a new, farther-out probability maximum; the electron's charge cloud simply reaches further as n increases. For equal n, a smaller ℓ pushes the outer peak marginally farther out, but the n-difference dominates.
Solution
1. Read n for each candidate orbital: 1s (n=1), 2s (n=2), 2p (n=2), 3s (n=3).The digit in front of the orbital label IS the principal quantum number n.
2. Rank by n, since rmax grows with n²: 3s (n=3) > 2s ≈ 2p (n=2) > 1s (n=1).
3. The largest n present is 3 (the 3s orbital), so its outermost probability maximum lies farthest from the nucleus.
4. Therefore the answer is 3s — option (c).n=3 beats every n=2 and n=1 option regardless of ℓ.
 orbital   n    r_max ∝ n²/Z (relative)   distance rank
 1s        1    1                         nearest
 2s        2    4                         middle
 2p        2    4                         middle
 3s        3    9                         FARTHEST  <-- answer
⚡ JEE Trick "Farthest / most probable distance" MCQs are decided almost entirely by n (r ∝ n²) — pick the orbital with the highest principal quantum number. Use ℓ only to break a tie between two orbitals of the same n. Trap: don't confuse "most probable radius" (an outer peak, grows with n) with "number of nodes"; a 2p has zero radial nodes yet still sits nearer than 3s.
Answer: (c) 3s.
3Which orbital has the highest number of total nodes (2p/3s/3p/4s)?Total nodesA-NODES🟡 Similard4s
Concept Every orbital has a fixed number of surfaces on which the wave function ψ is zero — its nodes. These split into radial (spherical) and angular (planar/conical) nodes, but the total node count depends only on the principal quantum number n. So ranking orbitals by total nodes is the same as ranking them by n: the higher the shell number, the more nodes.
Formula total nodes = n − 1, made up of radial = n − ℓ − 1 and angular = ℓ (note ℓ cancels in the sum: (n−ℓ−1) + ℓ = n−1). Because ℓ drops out, only n sets the total — the sub-shell letter is irrelevant to the total count.
Solution
1. Identify n for each option: 2p → n=2, 3s → n=3, 3p → n=3, 4s → n=4.
2. Apply total = n − 1 to each:
  • 2p: 2 − 1 = 1 node
  • 3s: 3 − 1 = 2 nodes
  • 3p: 3 − 1 = 2 nodes
  • 4s: 4 − 1 = 3 nodes
3. The maximum is 3, belonging to 4s (largest n) — option (d).4s has the highest principal quantum number, so it carries the most total nodes.
 orbital   n   ℓ   radial=n−ℓ−1   angular=ℓ   total=n−1
 2p        2   1   0              1           1
 3s        3   0   2              0           2
 3p        3   1   1              1           2
 4s        4   0   3              0           3   <-- MAX
⚡ JEE Trick Total nodes = n − 1 only — ignore the sub-shell letter entirely. For a "most total nodes" MCQ just pick the orbital with the biggest number in front. Trap: don't split into radial/angular and re-add under time pressure; ℓ always cancels, so the letter (s, p, d…) never changes the total.
Answer: (d) 4s.
4Which statement regarding 2s and 2p radial probability distributions is correct?Radial probabilityA-RADPROB🟡 Similarc2s has one radial node whereas 2p has no radial node
Concept A radial node is a spherical shell where the radial part of the wave function passes through zero, so the electron is never found there. The number of radial nodes is set by both n and ℓ, so two orbitals in the same shell (here both n=2) can still differ: the 2s and 2p have the same n but different ℓ, and therefore different radial-node counts. Comparing them is a clean test of the node formula.
Formula radial nodes = n − ℓ − 1, with ℓ = 0 for s and ℓ = 1 for p. A larger ℓ eats into the radial-node count, so within one shell the s-orbital (ℓ=0) has the most radial nodes and the highest-ℓ orbital has the fewest.
Solution
1. For 2s: n = 2, ℓ = 0 ⇒ radial nodes = 2 − 0 − 1 = 1.The 2s curve dips to zero once between its two maxima — one spherical node.
2. For 2p: n = 2, ℓ = 1 ⇒ radial nodes = 2 − 1 − 1 = 0.The 2p radial curve rises to a single maximum and falls off, never touching zero in between.
3. So 2s has one radial node while 2p has none — exactly the statement in option (c).
4. Reject the distractors that claim equal nodes, or that 2p has more — they contradict n − ℓ − 1.
 orbital   n   ℓ   radial nodes = n−ℓ−1
 2s        2   0   2−0−1 = 1     (one spherical node)
 2p        2   1   2−1−1 = 0     (no radial node)
⚡ JEE Trick Within a shell, radial nodes decrease as ℓ increases: ns has (n−1) radial nodes, np has (n−2), nd has (n−3)… For n=2 that gives 2s→1, 2p→0 instantly. Trap: the 2p has an angular node (the nodal plane, from ℓ=1), which is easy to miscount as radial — angular ≠ radial.
Answer: (c) 2s has one radial node whereas 2p has no radial node.
5For which orbitals does the wavefunction change sign and exhibit a radial node?Wavefunction sign / nodeA-RADPROB🟡 Similarb2s only
Concept A wave function ψ can flip sign for two different reasons: at a radial node (a spherical shell where the radial part R(r) crosses zero) or at an angular node (a plane/cone where the angular part crosses zero). The question demands both conditions at once — a sign change that happens specifically at a radial node. Only an orbital that actually possesses a radial node qualifies, so we count radial nodes for each candidate.
Formula radial nodes = n − ℓ − 1. An orbital's radial part changes sign only if this count is ≥ 1. Each radial node is a zero-crossing of R(r), and on either side R(r) has opposite signs — that is precisely a radial sign change.
Solution
1. 1s: n=1, ℓ=0 ⇒ radial nodes = 1 − 0 − 1 = 0. R(r) is one-signed everywhere — no radial sign change.
2. 2s: n=2, ℓ=0 ⇒ radial nodes = 2 − 0 − 1 = 1. R(r) is positive near the nucleus, crosses zero, then goes negative — a genuine radial sign change. ✓
3. 2p: n=2, ℓ=1 ⇒ radial nodes = 2 − 1 − 1 = 0. The 2p does change sign, but across its angular (planar) node, not a radial one — so it fails the "radial node" requirement.
4. Only 2s both changes sign and does so at a radial node — option (b).1s has no node at all; 2p's sign flip is angular, not radial.
 orbital   radial nodes   sign change at a radial node?
 1s        0              no (no node at all)
 2s        1              YES  <-- answer
 2p        0              no (its flip is angular, not radial)
⚡ JEE Trick Separate the two node types: a radial sign change needs n − ℓ − 1 ≥ 1 (favours low-ℓ, high-n like ns); an angular sign change needs ℓ ≥ 1 (p, d, f). Trap: the 2p's two oppositely-signed lobes tempt you to call it a radial sign change — it is angular. For radial nodes, s-orbitals from 2s upward are the reliable "yes."
Answer: (b) 2s only.

1Explain Pauli's exclusion principlePauli principleA-HUND🟡 Similar—
Concept An electron in an atom is completely specified by four quantum numbers — n (shell), ℓ (subshell/shape), mℓ (orbital orientation) and ms (spin). Pauli's exclusion principle is the rule that keeps any two electrons from occupying the exact same quantum state. It is the reason electrons stack into successive shells instead of all collapsing into the 1s, and it fixes the maximum capacity of every orbital, subshell and shell.
Statement No two electrons in the same atom can have all four quantum numbers identical. If two electrons share n, ℓ and mℓ (i.e. the same orbital), their spins ms must differ (+½ and −½) — so an orbital holds at most two electrons, and they must be paired with opposite spins.
Solution
1. State the principle: two electrons cannot have the same set of all four quantum numbers (n, ℓ, mℓ, ms).
2. Consequence for one orbital: an orbital is fixed by (n, ℓ, mℓ); the only free label left is spin, which has just two values (±½), so an orbital holds at most 2 electrons of opposite spin.
3. This caps each subshell at 2(2ℓ+1) electrons and each shell at 2n².Number of orbitals in a subshell = 2ℓ+1, each ×2 electrons; summing over subshells of a shell gives 2n².
4. Example — the 1s orbital: the two electrons are (1,0,0,+½) and (1,0,0,−½); a hypothetical third electron would have to repeat one of these sets, which Pauli forbids.
 subshell   orbitals (2ℓ+1)   max electrons 2(2ℓ+1)
 s (ℓ=0)    1                 2
 p (ℓ=1)    3                 6
 d (ℓ=2)    5                 10
 f (ℓ=3)    7                 14
⚡ JEE Trick Pauli in one line: "one orbital, two electrons, opposite spins." It is the origin of the 2, 6, 10, 14 capacities and of the 2n² shell rule — memorise those and you can fill any configuration. Trap: Pauli fixes the maximum per orbital; how electrons spread across degenerate orbitals is Hund's rule, a separate principle.
Key point: Pauli's exclusion principle — no two electrons in an atom may have all four quantum numbers the same; hence each orbital holds a maximum of two electrons with opposite spins, giving subshell capacity 2(2ℓ+1) and shell capacity 2n².
2Explain Hund's rule of maximum multiplicity with a suitable exampleHund's ruleA-HUND🟡 Similar—
Concept When several orbitals of a subshell have the same energy (they are degenerate — e.g. the three p or five d orbitals), Pauli tells us each can hold two electrons but does not say in what order to fill them. Hund's rule of maximum multiplicity supplies that order: electrons spread out to keep as many spins parallel as possible before any pairing begins. This minimises electron–electron repulsion and maximises exchange stabilisation, lowering the atom's energy.
Statement Electrons occupy degenerate orbitals singly, all with parallel spin, before pairing up. Two electrons in the same orbital repel strongly; putting one electron in each orbital first keeps them apart, and equal spins add an extra quantum "exchange" stabilisation.
Solution (example: nitrogen, Z = 7)
1. Full configuration: 1s² 2s² 2p³ — three electrons to place in the three 2p orbitals (2px, 2py, 2pz).
2. By Hund's rule the three 2p electrons go one into each orbital, all spins parallel — not two paired in one orbital.Singly-filled with parallel spins gives the lowest repulsion and maximum multiplicity (three unpaired ⇒ 3 unpaired electrons).
3. Correct filling: ↑ | ↑ | ↑ (three unpaired). Wrong: ↑↓ | ↑ | ___ (only one unpaired, higher energy).
4. Multiplicity = 2S + 1, with total spin S = 3 × ½ = 3⁄2, so multiplicity = 2(3⁄2)+1 = 4 (maximum) — hence "maximum multiplicity."
 2p filling for N (2p³)     unpaired e⁻   note
 ↑ | ↑ | ↑                  3             correct (Hund) — lowest energy
 ↑↓ | ↑ | __                1             wrong — pairs before half-filling
⚡ JEE Trick "Fill singly first, pair later, keep spins parallel." Number of unpaired electrons (needed for magnetic moment μ = √[n(n+2)] BM) comes straight from Hund filling. Trap: don't start pairing in a p or d subshell until every orbital of that subshell already holds one electron — that mistake undercounts unpaired electrons.
Key point: Hund's rule of maximum multiplicity — electrons fill degenerate orbitals singly with parallel spins before pairing, minimising repulsion and giving the maximum number of unpaired electrons (e.g. nitrogen 2p³ = three unpaired electrons).
3Write the electronic configuration of copperCu config (exception)A-ECONFIG🟡 Similar—
Concept Copper (Z = 29) is one of the two famous Aufbau exceptions (the other is chromium). A naïve fill would give [Ar] 3d⁹ 4s², but copper instead adopts [Ar] 3d¹⁰ 4s¹. The driving force is the extra stability of a completely filled 3d¹⁰ subshell: one 4s electron drops into 3d to complete it, because a full d-shell (and the exchange energy it provides) more than pays for leaving 4s half-filled.
Key idea fully-filled (d¹⁰) and half-filled (d⁵) subshells are extra stable. Symmetric, completely/half-filled d subshells have maximum exchange energy and a lower total energy, so copper "borrows" one 4s electron to reach d¹⁰.
Solution
1. Copper has Z = 29, so 29 electrons to place following the Aufbau order 1s→2s→2p→3s→3p→4s→3d.
2. Fill up to argon core (18 e⁻): 1s² 2s² 2p⁶ 3s² 3p⁶ = [Ar], leaving 29 − 18 = 11 electrons for 4s and 3d.
3. Expected (naïve) filling: 4s² 3d⁹ ⇒ [Ar] 3d⁹ 4s².
4. Apply the stability exception: shift one 4s electron into 3d to complete the d subshell → 4s¹ 3d¹⁰.3d¹⁰ (fully filled) plus 4s¹ is lower in energy than 3d⁹ 4s².
5. Final: Cu (Z=29) = 1s² 2s² 2p⁶ 3s² 3p⁶ 3d¹⁰ 4s¹ = [Ar] 3d¹⁰ 4s¹ (one unpaired 4s electron).
 species   naïve fill        actual (stable)     reason
 Cu        [Ar] 3d⁹ 4s²      [Ar] 3d¹⁰ 4s¹       full d¹⁰ subshell
 (Cr       [Ar] 3d⁴ 4s²      [Ar] 3d⁵ 4s¹        half-filled d⁵)
⚡ JEE Trick Remember the two exceptions by their end-states: Cr = [Ar]3d⁵4s¹ (half-filled), Cu = [Ar]3d¹⁰4s¹ (fully filled) — in both, a 4s electron moves to 3d. Trap: writing Cu as 3d⁹4s² loses a mark; and Cu⁺ (lose the lone 4s) = [Ar]3d¹⁰, which is diamagnetic.
Key point: copper (Z=29) = [Ar] 3d¹⁰ 4s¹, an Aufbau exception in which one 4s electron shifts to 3d to gain the stability of a completely filled 3d¹⁰ subshell.
4Write the electronic configuration of Fe, Fe²⁺, Fe³⁺Ion configurationsA-ECONFIG🟡 Similar—
Concept The one subtlety in writing transition-metal ion configurations is the order of electron removal. Although 4s fills before 3d during Aufbau (lower energy when empty), once 3d is occupied the 4s orbital becomes the higher-energy, outer orbital. Therefore, when a transition metal is ionised, electrons leave 4s first, then 3d — not in the reverse of the filling order. Getting this right is what separates Fe²⁺ (3d⁶) from a common wrong answer.
Key rule Fill: 4s before 3d. Remove (ionise): 4s before 3d. After 3d is populated it drops below 4s in energy, so 4s holds the outermost, most loosely bound electrons and is emptied first on ionisation. Iron has Z = 26.
Solution
1. Neutral Fe (26 e⁻): [Ar] core (18) + remaining 8 electrons → 4s² 3d⁶. So Fe = [Ar] 3d⁶ 4s².18 + 2 (4s) + 6 (3d) = 26 ✓.
2. Fe²⁺ = remove 2 electrons, taking them from 4s first: drop 4s² → Fe²⁺ = [Ar] 3d⁶ (4 unpaired electrons).Both removed electrons come from 4s, leaving 3d untouched.
3. Fe³⁺ = remove a 3rd electron; 4s is now empty, so it comes from 3d: 3d⁶ → 3d⁵ ⇒ Fe³⁺ = [Ar] 3d⁵ (5 unpaired electrons).3d⁵ is a half-filled subshell — extra stable, which is why Fe³⁺ is a very common oxidation state.
 species   electrons   configuration      unpaired e⁻
 Fe        26          [Ar] 3d⁶ 4s²       4
 Fe²⁺      24          [Ar] 3d⁶           4   (removed 4s²)
 Fe³⁺      23          [Ar] 3d⁵           5   (half-filled, stable)
⚡ JEE Trick For any transition-metal cation: write the neutral atom, then strip 4s electrons before 3d. Fe³⁺ = [Ar]3d⁵ is favoured because a half-filled d⁵ is stable — this is why Fe³⁺ is more stable than Fe²⁺ in many reactions. Trap: never write Fe²⁺ as [Ar]3d⁴4s² by removing 3d first — 4s always leaves first.
Key point: Fe = [Ar] 3d⁶ 4s²; on ionisation 4s empties before 3d, giving Fe²⁺ = [Ar] 3d⁶ (4 unpaired) and Fe³⁺ = [Ar] 3d⁵ (5 unpaired, a stable half-filled subshell).

1Physical significance of the wave function (ψ)?Wave function meaningA-WAVEFN🟡 SimilardNo direct physical meaning
Concept The wave function ψ is the mathematical solution of the Schrödinger equation for an electron. By itself it is an amplitude that can be positive, negative or even complex, so it cannot represent anything we can directly measure (a probability or a density can never be negative). Physical meaning appears only when we take its square, ψ². Hence ψ on its own has no direct physical significance; it is ψ² that carries the observable content.
Key relation ψ = amplitude (may be ±), whereas ψ² = probability density (always ≥ 0). Squaring removes the sign, turning a signed amplitude into a non-negative density — the quantity that can be interpreted physically (Born's interpretation).
Solution
1. Note ψ can be negative (e.g. the outer lobe of a 2s, or one lobe of a 2p) — a probability can never be negative, so ψ itself is not a probability.A negative "probability" is meaningless, so ψ cannot be measured directly.
2. ψ is only an amplitude of the matter wave; the sign matters for bonding/interference but not as an observable on its own.
3. Physical meaning is recovered by squaring: ψ² (Born) gives the probability density — always non-negative.
4. Therefore ψ by itself has no direct physical meaning — option (d).
 quantity   sign        directly observable?
 ψ          + or −      no (just an amplitude)  <-- this question
 ψ²         ≥ 0 only    yes → probability density
⚡ JEE Trick Remember the pairing: "ψ = amplitude (no direct meaning); ψ² = probability density (the physical one)." Any option that gives ψ a measurable meaning is a distractor. Trap: don't select "probability density" for ψ — that belongs to ψ² (the very next question).
Answer: (d) No direct physical meaning.
2The square of the wave function (ψ²) represents?Probability densityA-WAVEFN🟡 SimilardProbability density
Concept This is Max Born's interpretation of the wave function, the bridge between the abstract ψ and something we can measure. Since ψ itself has no direct meaning, we square it: ψ² at a point gives the probability density — the probability of finding the electron per unit volume at that location. It is always non-negative, which is exactly what a density must be, and integrating it over all space gives 1 (the electron is somewhere).
Key relation ψ² = probability per unit volume (probability density); probability in a small volume dV is ψ² dV. ψ² ≥ 0 everywhere, so it can legitimately act as a density; the sign information of ψ is discarded on squaring.
Solution
1. Start from ψ (an amplitude, possibly negative) — not directly observable.
2. Square it: ψ² is always ≥ 0, the requirement for any probability quantity.Negative or complex values vanish on squaring, leaving a valid density.
3. Born's rule: ψ² = probability density = probability of finding the electron per unit volume at that point.
4. Hence ψ² represents probability density — option (d). (The actual probability in a shell is ψ² × volume, e.g. 4πr²ψ² for a radial shell.)
 quantity        meaning
 ψ               amplitude (sign ±, no direct meaning)
 ψ²              probability density (per unit volume)  <-- answer
 4πr²ψ²          radial probability (in a thin shell at r)
⚡ JEE Trick ψ² = "probability density" (per unit volume); multiply by the shell volume 4πr² to get the "radial probability" that peaks at the Bohr-like radius. Trap: don't equate ψ² with the total probability — it is a density; you must multiply by a volume element to get an actual probability.
Answer: (d) Probability density.
3What does a node in the radial probability distribution curve indicate?Node = zero probabilityA-WAVEFN🟡 SimilarbZero probability of finding electron
Concept A node is any point where the wave function ψ — and therefore the probability ψ² — falls to zero. On a radial probability distribution curve (a plot of 4πr²ψ² versus r), a node shows up as a place where the curve touches the r-axis. Physically it is a distance at which the electron is never found: the probability density there is exactly zero.
Key relation at a node ψ = 0 ⇒ ψ² = 0 ⇒ 4πr²ψ² = 0. If the amplitude is zero, its square is zero, so the probability of finding the electron at that radius is zero. Number of radial nodes = n − ℓ − 1.
Solution
1. Read what the curve plots: radial probability 4πr²ψ² against distance r.
2. A node is where this curve = 0, i.e. where ψ (and hence ψ²) vanishes.
3. Zero probability density ⇒ the electron has zero probability of being found at that radius.The curve dipping to the axis is the visual signature of a forbidden distance.
4. Therefore a node indicates zero probability of finding the electron — option (b), not "maximum probability" or "an orbital boundary."
 point on curve         4πr²ψ²    interpretation
 peak (maximum)         large     most probable radius
 node (touches axis)    0         electron never found here  <-- answer
⚡ JEE Trick Node = "zero probability" — the curve kisses the axis. Count them with n − ℓ − 1 (radial). Trap: don't confuse a node (probability = 0) with a peak/maximum (most probable radius); they are opposite features of the same curve, and the origin r=0 for s-orbitals is a zero of 4πr²ψ² but is not counted as a radial node.
Answer: (b) Zero probability of finding electron.
4The angular part of the wave function depends on?Angular part (θ, φ)A-ORBSHAPE🟡 SimilarbZenith and azimuthal angles (θ, φ)
Concept In spherical polar coordinates the hydrogen-atom wave function separates into a radial part and an angular part: ψ(r,θ,φ) = R(r) · Y(θ,φ). The radial part R(r) depends only on the distance r (and controls size and radial nodes), while the angular part Y depends only on the two angles that fix a direction in space — the zenith (polar) angle θ and the azimuthal angle φ. It is this angular part that gives an orbital its shape and orientation (spherical s, dumb-bell p, etc.).
Key relation ψ = R(r) × Y(θ, φ), where Y = angular part = f(θ, φ). θ and φ specify direction only; distance r is handled entirely by R(r), so the angular part cannot depend on r.
Solution
1. Write the separated form: ψ(r,θ,φ) = R(r)·Y(θ,φ).Spherical symmetry of the atom lets the three-variable function split into a radial × angular product.
2. Identify the coordinates: r = distance from nucleus; θ = zenith/polar angle; φ = azimuthal angle.
3. The angular part Y = Y(θ, φ) — it depends on the two angles, describing direction, not distance.
4. Therefore the angular part depends on the zenith and azimuthal angles (θ, φ) — option (b); r belongs to the radial part.
 part of ψ       symbol      depends on      governs
 radial          R(r)        r               size, radial nodes
 angular         Y(θ,φ)      θ and φ         shape, orientation  <-- answer
