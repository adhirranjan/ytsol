Concept Squaring is not reversible: a = b and a = −b both become a² = b², so the squared equation has extra roots that the original does not. In trig this happens constantly (sin x + cos x = 1, √3 sin x − cos x = 1, sec x + tan x = k). The book's advice is to avoid squaring where an identity works, and if you must square, check every root. The trap is thinking the other options (graphing, reciprocals) are the dangerous ones.
Formula a = b ⇒ a² = b², but a² = b² ⇒ a = b OR a = −b Only the forward direction holds, so the root set can grow (extraneous roots).
Solution
1. Example: cos x − sin x = 1. Better route (no squaring): √2 cos(x + π/4) = 1 ⇒ cos(x + π/4) = 1/√2 ⇒ x + π/4 = 2nπ ± π/4 ⇒ x = 2nπ or x = 2nπ − π/2.

5. (a) Graphing never adds roots (it only estimates); (b) differentiation is not a solving step; (d) taking reciprocals (sin x = 1/2 ⇔ cosec x = 2) is reversible where both are defined.
6. Hence the operation to avoid (or to follow with a mandatory check) is squaring both sides.

Concept An extraneous solution is a value produced by the solving process (squaring, multiplying by a variable expression, clearing denominators, substituting t = tan(x/2)) that does not satisfy the original equation or lies outside its domain. It is an artefact of the method, not a real root. The trap is (a): a value that satisfies both sides is, by definition, a genuine root.
Formula x₀ extraneous ⇔ x₀ solves the transformed equation but LHS(x₀) ≠ RHS(x₀) (or undefined) in the original Transformations that are only one-way (⇒, not ⇔) can add such values.
Solution
1. Example A (squaring): √3 sin x − cos x = 1 is solved as 2 sin(x − π/6) = 1; squaring instead would also produce roots of √3 sin x − cos x = −1.
2. Example B (domain): tan x + sec x = 1. Write it as (sin x + 1)/cos x = 1, which needs cos x ≠ 0, then clear the denominator: sin x + 1 = cos x ⇒ sin x − cos x = −1.
3. √2 sin(x − π/4) = −1 ⇒ x = 2nπ or x = 2nπ + 3π/2. But at x = 3π/2, cos x = 0 ⇒ tan and sec are undefined ⇒ extraneous; only x = 2nπ survives.It solves the cleared-denominator form, not the original.
4. So an extraneous value is one "not valid in the original equation": option (c).
5. (a) describes a true root; (b) "one from the domain" is a requirement for any root, not a definition; (d) rationality has nothing to do with validity.
6. Practical rule: list candidates, then strike out every one that fails the original equation or its domain (cos x ≠ 0 for tan/sec, sin x ≠ 0 for cot/cosec).
