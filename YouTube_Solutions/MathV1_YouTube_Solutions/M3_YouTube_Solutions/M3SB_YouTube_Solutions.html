1The sum of all the elements in the range of f(x) = Sgn(sin x) + Sgn(cos x) + Sgn(tan x) + Sgn(cot x), x ≠ nπ/2, n ∈ Z, where Sgn(t) = 1 if t > 0 and −1 if t < 0, is : [JEE Main 2026, 28 Jan Shift 1] (Level-4) (a) 2 (b) 0 (c) −2 (d) 4Signum of trig ratios, quadrant signs, rangeThe sum of all the elements in the range of f(x)=Sgn(sinx)+Sgn(cosx)+Sgn(tanx)+Sgn(cotx), x!=npi/2🟢 Exacta2
Concept Sgn only records a sign, never a magnitude. Excluding x = nπ/2 removes every axis, so x always lies strictly inside one of the four quadrants. Inside a fixed quadrant all four signs are constant, so f takes only four possible values — one per quadrant. The range is the set of those values (duplicates counted once), and the question wants the sum of that set.
Formula Sgn(t) = +1 (t > 0), −1 (t < 0); and the quadrant sign rule tan = sin/cos, cot = cos/sin — so tan and cot always carry the same sign, namely sign(sin)·sign(cos).
Solution
1. Because tan = sin/cos and cot = cos/sin, both tan and cot have sign = sign(sin)×sign(cos). So f(x) = s + c + 2sc, where s = Sgn(sin x), c = Sgn(cos x), each ±1.This collapses four independent-looking terms into a function of just two signs.
2. Quadrant I (s = +1, c = +1): f = 1 + 1 + 2(1)(1) = 1 + 1 + 1 + 1 = 4.All four ratios positive.
3. Quadrant II (s = +1, c = −1): f = 1 − 1 + 2(1)(−1) = 1 − 1 − 1 − 1 = −2.sin positive; cos, tan, cot negative.
4. Quadrant III (s = −1, c = −1): f = −1 − 1 + 2(−1)(−1) = −1 − 1 + 1 + 1 = 0.sin and cos both negative, so tan and cot are positive — the two pairs cancel exactly.
5. Quadrant IV (s = −1, c = +1): f = −1 + 1 + 2(−1)(1) = −1 + 1 − 1 − 1 = −2.Same value as Quadrant II — a duplicate.
6. Collect the distinct values: Range = {4, −2, 0}. Note −2 arises twice but appears in the set once.This is the single step the whole problem is testing — a "range" is a set, not a list of four outputs.
7. Sum the elements: 4 + (−2) + 0 = 2.
  Quadrant | sin cos tan cot |  f = sum
  ---------+-----------------+---------
     I     |  +   +   +   +  |   +4
     II    |  +   -   -   -  |   -2
     III   |  -   -   +   +  |    0
     IV    |  -   +   -   -  |   -2   <-- repeat of II

  Range (a SET) = { 4, -2, 0 }
  Sum of elements = 4 + (-2) + 0 = 2
⚡ JEE Trick Two traps are hidden here. First, the identity f = s + c + 2sc means you only ever build a 2×2 table, never a 4-row grind. Second — and this is where most candidates lose the mark — adding the four quadrant outputs gives 4 − 2 + 0 − 2 = 0, which is option (b), planted deliberately. The range is a set, so the repeated −2 is counted once and the answer is 2. Whenever a question says "sum of all elements in the range", de-duplicate before adding.
Answer: (a) 2
2The value of (√3 cosec 20° − sec 20°) / (cos 20° cos 40° cos 60° cos 80°) is equal to [JEE Main 2026, 24 Jan Shift 1] (Level-4) (a) 16 (b) 32 (c) 12 (d) 64Multiple-angle product, cosec–sec combinationJEE Main 2026 (24 Jan Shift 1): The value of root3 cosec20 - sec20/cos20 cos40 cos60 cos80 is equal🟢 Exactd64
Concept Two independent classics bolted together. The numerator is the standard "√3 cosec − sec" identity: take a common denominator and the numerator becomes a sine of a difference in disguise (because √3/2 and 1/2 are cos 30° and sin 30°). The denominator is the cos·cos2·cos4 chain, killed by the sin-doubling telescope. Evaluate each separately, then divide.
Formula sin(A − B) = sin A cos B − cos A sin B; sin 2θ = 2 sinθ cosθ; and the chain product cosθ · cos2θ · cos4θ · … · cos(2ⁿ⁻¹θ) = sin(2ⁿθ) / (2ⁿ sinθ).
Solution
1. Numerator N = √3/sin 20° − 1/cos 20°. Take the common denominator sin20°cos20°: N = (√3 cos 20° − sin 20°) / (sin 20° cos 20°).
2. Force the coefficients into sine/cosine form: pull out a 2 so that √3 → √3/2 = cos 30° and 1 → 1/2 = sin 30°.This is the standard a·cos + b·sin normalisation with √(a²+b²) = √(3+1) = 2.

8. sin 160° = sin(180° − 20°) = sin 20°, so the product = sin20°/(8 sin20°) = 1/8.The whole reason 20° is chosen: 8×20° = 160° folds back onto 20°.
9. Multiply in the leftover cos 60° = 1/2: D = (1/8)·(1/2) = 1/16.

Concept The expression is a homogeneous degree-2 combination of sinθ and cosθ plus a constant. Every such expression (a sin²θ + b sinθcosθ + c cos²θ) flattens into the single-frequency form P + Q cos2θ + R sin2θ once the power-reduction identities are applied — and a Q cos2θ + R sin2θ wave has range ±√(Q²+R²). The trap is the sign bookkeeping: the least value needs the wave at its maximum when the wave is being subtracted.
Formula cos²θ = (1+cos2θ)/2; sin²θ = (1−cos2θ)/2; 2 sinθcosθ = sin2θ; −√(Q²+R²) ≤ Q cos x + R sin x ≤ √(Q²+R²) the a·cos+b·sin bound, attained because x = 2θ sweeps the full circle.

5If (cos²48° − sin²12°) / (sin²24° − sin²6°) = (α + β√5)/2, where α, β ∈ N, then α + β is equal to ______ [JEE Main 2026, 21 Jan Shift 1] (Level-3)cos²A − sin²B and sin²A − sin²B factorisations; 18°/36° valuesIf (cos^2 48 - sin^2 12)/(sin^2 24 - sin^2 6) = (alpha + root5 beta)/2 then value of alpha + beta is🟢 Exact4
Concept Both numerator and denominator are difference-of-squares forms that factor into a single product of two trig functions. Crucially, in each one the sum of the two angles is a friendly angle (48+12 = 60, 24+6 = 30) and the difference is a "golden-ratio" angle (48−12 = 36, 24−6 = 18). That is not a coincidence — the whole question is engineered so that cos 36° and sin 18° appear, and their ratio produces the √5.
Formula cos²A − sin²B = cos(A+B) cos(A−B); sin²A − sin²B = sin(A+B) sin(A−B); cos 36° = (√5 + 1)/4; sin 18° = (√5 − 1)/4.
Solution
1. Numerator: cos²48° − sin²12° = cos(48° + 12°) · cos(48° − 12°) = cos 60° · cos 36°.Direct use of cos²A − sin²B = cos(A+B)cos(A−B).
2. cos 60° = 1/2, so Numerator = (1/2) cos 36°.
3. Denominator: sin²24° − sin²6° = sin(24° + 6°) · sin(24° − 6°) = sin 30° · sin 18°.Note this is a different identity from step 1 — sin²−sin² gives sin·sin, not cos·cos.
4. sin 30° = 1/2, so Denominator = (1/2) sin 18°.
5. The two halves cancel: Ratio = [(1/2)cos36°] / [(1/2)sin18°] = cos 36° / sin 18°.
6. Substitute the golden values: cos 36° = (√5+1)/4 and sin 18° = (√5−1)/4. The /4 cancels: Ratio = (√5 + 1)/(√5 − 1).
7. Rationalise by multiplying top and bottom by (√5 + 1): Ratio = (√5+1)² / [(√5)² − 1²] = (5 + 2√5 + 1)/(5 − 1) = (6 + 2√5)/4.
8. Reduce by 2: Ratio = (3 + √5)/2.Now it is exactly in the demanded shape (α + β√5)/2.
9. Compare with (α + β√5)/2: α = 3, β = 1. Both are natural numbers, as required.The problem states α, β ∈ N — this pins the representation uniquely, so no other split is admissible.
10. α + β = 3 + 1 = 4.

6Let α and β respectively be the maximum and the minimum values of the function f(θ) = 4(sin⁴(7π/2 − θ) + sin⁴(11π + θ)) − 2(sin⁶(3π/2 − θ) + sin⁶(9π − θ)), θ ∈ R. Concept The frightening arguments (7π/2 − θ, 11π + θ, 3π/2 − θ, 9π − θ) are pure decoration: every one of them reduces by allied-angle rules to ±sinθ or ±cosθ, and the even powers (4 and 6) wipe out every sign. What survives is the classic pair sin⁴+cos⁴ and sin⁶+cos⁶, both of which are functions of the single quantity t = sin²θ cos²θ. The problem then becomes linear in t.
Formula Allied angles — add/subtract multiples of π: odd multiples of π/2 swap sin↔cos, whole multiples of π do not. Power reduction: sin⁴θ + cos⁴θ = 1 − 2t and sin⁶θ + cos⁶θ = 1 − 3t, where t = sin²θ cos²θ = (1/4)sin²2θ, so 0 ≤ t ≤ 1/4.
Solution
1. Reduce sin(7π/2 − θ). Write 7π/2 = 3π + π/2, so sin(3π + π/2 − θ) = sin(π + (π/2 − θ)) = −sin(π/2 − θ) = −cosθ. Hence sin⁴(7π/2 − θ) = cos⁴θ.Dropping 2π is free; the leftover π flips the sign; the 4th power discards it.
2. Reduce sin(11π + θ) = sin(π + θ) = −sinθ. Hence sin⁴(11π + θ) = sin⁴θ.11π = 5·2π + π, so only the odd π matters.
3. Reduce sin(3π/2 − θ) = sin(π + (π/2 − θ)) = −cosθ. Hence sin⁶(3π/2 − θ) = cos⁶θ.
4. Reduce sin(9π − θ) = sin(π − θ) = +sinθ. Hence sin⁶(9π − θ) = sin⁶θ.
5. So f(θ) = 4(cos⁴θ + sin⁴θ) − 2(cos⁶θ + sin⁶θ) — the disguise is fully removed.
6. Derive the reductions. sin⁴+cos⁴ = (sin²+cos²)² − 2sin²cos² = 1 − 2t.Complete the square on a²+b² = (a+b)² − 2ab with a = sin²θ, b = cos²θ.
7. sin⁶+cos⁶ = (sin²+cos²)³ − 3sin²cos²(sin²+cos²) = 1 − 3t.Using a³+b³ = (a+b)³ − 3ab(a+b), again with a+b = 1.
8. Substitute: f = 4(1 − 2t) − 2(1 − 3t) = 4 − 8t − 2 + 6t = 2 − 2t.f is linear and decreasing in t — so max f ↔ min t, and min f ↔ max t.
9. Bound t: t = sin²θcos²θ = (1/4)sin²2θ, and sin²2θ ranges over [0, 1]. So t ∈ [0, 1/4], both endpoints attained (t = 0 at θ = 0; t = 1/4 at θ = π/4).
10. Maximum: t = 0 gives α = 2 − 0 = 2.
11. Minimum: t = 1/4 gives β = 2 − 2(1/4) = 2 − 1/2 = 3/2.

Concept One observer A, one vertical line PQ, two targets on it: R (part-way up) and P (the top). Both right triangles AQR and AQP share the same base AQ. That shared base is the hinge of the whole problem: compute it once from the known 15 m and 60°, then reuse it for the top. The 15° is not an elevation — it is the angle subtended by the segment PR, i.e. the gap between the two elevations, so the elevation of P is 60° + 15° = 75°.
Formula tan(elevation) = opposite / adjacent; tan 60° = √3; and the compound angle tan(A+B) = (tan A + tan B)/(1 − tan A tan B) giving tan 75° = 2 + √3.
Solution
1. Set up: Q is the base on the ground, P the top, R on segment QP with QR = 15 m. A is on the ground; AQ is horizontal; ∡AQP = 90°.
2. Angle of elevation of R from A is 60°, so in right triangle AQR: tan 60° = QR/AQ = 15/AQ.
3. Solve for the shared base: AQ = 15/tan 60° = 15/√3 = 15√3/3 = 5√3 m.Rationalising 15/√3 → 5√3 ≈ 8.66 m. This one number carries the rest of the solution.

⚡ JEE Trick In every "two targets on one vertical line, one observer" problem the base AQ is the invariant — find it from the known length first and never re-derive it. Read the wording with care: "the angle of elevation of R is 60°" is measured from the ground, but "PR subtends 15° at A" is measured between two sight lines, so elevations add (60° → 75°); subtracting instead gives 45° and PQ = 5√3 ≈ 8.7 m — below R, an instant contradiction you should catch. Keep tan 15° = 2 − √3 and tan 75° = 2 + √3 memorised; they are reciprocals, and their appearance is the signal that a 45°±30° split is intended.
