1 (i)Fill in the blank: Given that x ≥ y, then x − y ______ 0.Subtraction property of inequalityAddition and Subtraction Properties of Inequality🟡 Similar≥
Concept Adding or subtracting the same quantity from both sides of an inequality never changes its direction — it just slides both numbers along the number line by an equal amount, so their relative order survives. This is the very first property of inequalities and it is what lets us "move terms across" exactly as in an equation.
Formula a ≥ b  ⇔  a − c ≥ b − c for every real c. The sign only ever flips when you multiply or divide by a negative number — not when you add or subtract.
Solution
1. Start with the given statement: x ≥ y.This is the only hypothesis available.
2. Subtract y from both sides (take c = y): x − y ≥ y − y.Subtraction is order-preserving, so ≥ stays ≥.
3. Simplify the right side: y − y = 0, giving x − y ≥ 0.
4. Sanity-check both cases the ≥ allows:
 case        example      x - y      x - y ≥ 0 ?
 x > y       x=7, y=3     4          yes (strictly > 0)
 x = y       x=3, y=3     0          yes (equals 0)
5. Since equality is reachable, the blank must be ≥, not >.
⚡ JEE Trick "x ≥ y" and "x − y ≥ 0" are the same statement — always rewrite an inequality with 0 on one side before doing anything else; every sign-chart / wavy-curve method requires that form. Trap: writing > here. The hypothesis permits x = y, and dropping the equality would lose that case.
Answer: x − y ≥ 0.

The job is to first strip away the constants and the coefficient sitting outside the modulus — using only order-preserving steps — until the modulus stands alone, and only then unfold.
Formula |E| ≤ k  ⇔  −k ≤ E ≤ k (valid for k ≥ 0; if k < 0 the solution is empty). |E| is the distance from E to 0, so bounding it by k confines E to the closed interval [−k, k].

1. Given: 4|x + 3| − 7 ≤ 5. Isolate the modulus term by adding 7 to both sides: 4|x + 3| ≤ 12.Adding a constant preserves the direction of ≤.

4. Unfold the modulus into a double inequality: −3 ≤ x + 3 ≤ 3.x + 3 must lie within 3 units of 0.

 -7       4      4(4) - 7 =  9   no  (outside, as expected)
  1       4      4(4) - 7 =  9   no  (outside, as expected)

3 (iii)Find p, q, r: the solution of [1 + 3/n] > 2 is of the form n ∈ (p, q) ∪ (q, r).Reciprocal inequality in nRational Inequalities — sign / interval method🟡 Similarp = −1, q = 0, r = 3
Concept The required answer shape, (p, q) ∪ (q, r) — two intervals meeting at a single excluded point q — is the signature of a modulus inequality on a rational expression: the excluded middle point is where the denominator vanishes. So the bracket is read as a modulus, |1 + 3/n| > 2, and the excluded q will turn out to be n = 0.
Formula |E| > k  ⇔  E > k  or  E < −k (for k ≥ 0) — an OR, giving two pieces. "Distance from 0 exceeds k" means E is beyond k on the right or beyond −k on the left. Also 3/n > c > 0 ⇔ 0 < n < 3/c, since 3/n can only exceed a positive number when n itself is positive.
Solution
1. Read the statement as |1 + 3/n| > 2, with n ≠ 0 required for 3/n to exist.n = 0 is outside the domain — this is the point that will split the answer into two intervals.
2. Unfold the modulus into an OR: 1 + 3/n > 2  or  1 + 3/n < −2.
3. Branch 1: 1 + 3/n > 2 ⇒ 3/n > 1. The left side is positive only when n > 0, so multiply by the positive n without flipping: 3 > n. Hence 0 < n < 3.If n < 0 then 3/n < 0, which can never exceed 1 — that case dies immediately.
4. Branch 2: 1 + 3/n < −2 ⇒ 3/n < −3. The left side is negative only when n < 0; multiply by the negative n and flip the sign: 3 > −3n, i.e. n > −1. Combined with n < 0: −1 < n < 0.The flip is forced because we multiplied by a quantity known to be negative.
5. Union the two branches: n ∈ (−1, 0) ∪ (0, 3).
6. Verify representative points, including the excluded ones:
 n        3/n       1 + 3/n     |1 + 3/n|    > 2 ?
 -0.5     -6        -5           5           YES  (in (-1, 0))
 -0.9     -3.33     -2.33        2.33        YES  (in (-1, 0))
 -1       -3        -2           2           no   (boundary, EXCLUDED)
 -2       -1.5      -0.5         0.5         no   (outside)
  0       undefined  --          --          EXCLUDED (domain)
  1        3          4          4           YES  (in (0, 3))
  2.9      1.034      2.034      2.034       YES  (in (0, 3))
  3        1          2          2           no   (boundary, EXCLUDED)
  5        0.6        1.6        1.6         no   (outside)
7. Match against the required shape (p, q) ∪ (q, r): the shared excluded point is q = 0, the left end is p = −1 and the right end is r = 3. So p = −1, q = 0, r = 3.The fact that a single value q is excluded from the middle confirms the modulus reading — a plain "1 + 3/n > 2" would give the single interval (0, 3) and could not produce this shape.
⚡ JEE Trick The shape of the answer tells you the question: a union of two intervals sharing an excluded endpoint means a modulus (OR) plus a domain exclusion. Also, for 3/n > positive, skip the case work — a positive value of 3/n forces n > 0 instantly. Trap: multiplying an inequality by n when n's sign is unknown; either split into n > 0 / n < 0 as done here, or multiply by n² (always positive) instead.
Answer: n ∈ (−1, 0) ∪ (0, 3), i.e. p = −1, q = 0, r = 3.  ⚠ Note: this requires reading the bracket as a modulus, |1 + 3/n| > 2; without the modulus the answer is the single interval (0, 3), which cannot match the printed (p, q) ∪ (q, r) shape.

1The solution set of a system of linear inequations in one variable is: (Level 1) (a) Union of the solution sets of each inequation (b) Intersection of the solution sets of each inequation (c) Difference of the solution sets of each inequation (d) None of theseSolution set of a system: intersectionSystems of Inequalities — How to Solve Them🟡 SimilarbIntersection of the solution sets of each inequation
Concept The word system means the inequations are joined by AND: a value of x solves the system only if it solves every inequation at once. In set language "satisfies all of them simultaneously" is precisely the intersection of the individual solution sets. Union would correspond to "OR" — satisfying at least one — which is a different (and weaker) requirement.
Formula If S₁, S₂, …, Sₙ are the solution sets of the individual inequations, then S = S₁ ∩ S₂ ∩ … ∩ Sₙ. AND ↔ ∩ (intersection); OR ↔ ∪ (union). The connective in the question dictates the set operation.
Solution
1. Read what a "system" demands: x must satisfy inequation 1 and inequation 2 and … — all of them together.A single failure disqualifies x entirely.
2. Translate to sets: x ∈ S ⇔ (x ∈ S₁) and (x ∈ S₂) and … — which is the definition of S₁ ∩ S₂ ∩ …
3. Test the wrong options on a concrete system, say x ≥ 3 and x < 7, where S₁ = [3, ∞) and S₂ = (−∞, 7):
 option                     result for  x ≥ 3  AND  x < 7
 (a) union      S₁ ∪ S₂      = all reals   ← wrong: x = 100 fails x < 7
 (b) intersection S₁ ∩ S₂    = [3, 7)      ← correct: every point obeys both
 (c) difference S₁ - S₂      = [7, ∞)     ← wrong: x = 8 fails x < 7
 (d) none of these                        ← wrong: (b) works
4. Only the intersection keeps exactly the values obeying every constraint, so option (b) is correct.
5. Geometric reading: graph each solution set on the number line and take the overlap — the stretch shaded by every inequation.
⚡ JEE Trick One word decides the operation: "and"/"system"/"simultaneously" → intersection (overlap); "or" → union. The same logic scales to two variables, where the intersection is the feasible region common to all shaded half-planes. Trap: an intersection can easily be ∅ (e.g. x > 5 and x < 2) — that is a legitimate answer, not an error.
Answer: (b) Intersection of the solution sets of each inequation.

9. Since the system has no solutions at all, the number of integral values of x satisfying it is 0.Even taken alone, the first interval (0.1429, 0.1818) contains no integer — it is a sliver strictly between 0 and 1 — so the count would be 0 regardless.
