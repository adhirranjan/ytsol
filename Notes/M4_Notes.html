L-1

Sets, Relations & Functions

  • A set is a well-defined collection of distinct objects; order is irrelevant and no element repeats. So {1,2,3} = {3,2,1}.
  • An ordered pair (a, b) has a fixed order: (a, b) ≠ (b, a) unless a = b.
cartesian productA × B = {(a, b) : a ∈ A, b ∈ B} · n(A × B) = n(A) · n(B)
triple productA × B × C = {(a, b, c) : a ∈ A, b ∈ B, c ∈ C} · n(A×B×C) = n(A)·n(B)·n(C)

Relation & its inverse

  • A relation R from A to B is any subset of A × B (⇔ R ⊆ A × B).
  • Domain(R) = set of first components; Range(R) = set of second components.
  • Inverse R⁻¹ = {(b, a) : (a, b) ∈ R}. So Dom(R) = Range(R⁻¹) and Range(R) = Dom(R⁻¹).
number of relationsIf n(A) = p and n(B) = q, number of possible relations A → B = 2^(pq)

Function (a special relation)

  • A relation f: A → B is a function if (i) every a ∈ A has an image, and (ii) that image is unique — no first element repeats with two different images.
  • Domain = A, Co-domain = B, Range = f(A) = {f(x) : x ∈ A} ⊆ B.
⚠ TrapA relation is not always a function. If one input maps to two outputs (e.g. {(1,4),(1,5)}), or if some domain element has no image, it fails.
💡 Vertical line testA curve is the graph of a function iff no vertical line meets it more than once. A sideways parabola or a circle fails (two y-values per x).
Equality of two functions
f = g requires all three: (i) same domain, (ii) same co-domain, (iii) f(x) = g(x) for every common x. Two rules that simplify to the same formula are not equal if their domains differ — the classic trap tested below.

Let f: R − {3} → R be f(x) = (x² − 9)/(x − 3) and g: R → R be g(x) = x + 3. Is f = g?
f(x) = (x − 3)(x + 3)/(x − 3) = x + 3 for all x ≠ 3, so f(x) = g(x) on the common domain.

Let A = {−2, −1, 0, 1, 2} and f: A → Z, f(x) = x² + 5x + 6. Find (i) the range of f, (ii) the pre-image of 2.
f(−2)=0, f(−1)=2, f(0)=6, f(1)=12, f(2)=20 ⇒ range = {0, 2, 6, 12, 20}.
(ii) x² + 5x + 6 = 2 ⇒ x² + 5x + 4 = 0 ⇒ x = −1 or −4; but −4 ∉ A.

Let f: R → R be f(x) = x² + 1. Find (i) f⁻¹(−5), (ii) f⁻¹(26), (iii) f⁻¹({5, 10}).

(i) φ (ii) {−5, 5} (iii) {−2, 2, −3, 3}

L-2

Range of Functions & Standard Functions

Finding the range — 4-step method

range process1) put y = f(x) 2) solve x = φ(y) 3) find all y giving real x in Dom(f) 4) that y-set is the range
Why the method works
The range is exactly the set of outputs y that are actually hit. Inverting to x = φ(y) and then demanding x be real and inside the domain filters out impossible y-values (e.g. a y that would force a square root of a negative, or division by zero). What survives is the range.

Standard functions & their graphs

  • Identity I(x) = x: straight line through origin at 45°; Domain = Range = R.
  • Constant f(x) = k: horizontal line; Range = {k}.
  • Signum: +1 (x>0), 0 (x=0), −1 (x<0); Range = {−1, 0, 1}.
  • Greatest integer (step / floor) [x]: greatest integer ≤ x. E.g. [3.4]=3, [−4.99]=−5, [−0.2]=−1. Range = Z.
  • Modulus |x|: V-shape; Range = [0, ∞).
  • Fractional part {x} = x − [x]: sawtooth, Range = [0, 1). E.g. {3.25}=0.25, {−2.75}=0.25.
  • Least integer ⌈x⌉: smallest integer ≥ x; ⌈3.7⌉=4, ⌈−7.2⌉=−7. Range = Z.
modulus key results|x| ≤ a ⇒ x ∈ [−a, a] · |x| ≥ a ⇒ x ∈ (−∞,−a] ∪ [a,∞) · √(x²) = |x| · |x − a| < b ⇒ x ∈ (a−b, a+b)
⚠ TrapFor x < 0 the greatest integer rounds down: [−4.001] = −5, not −4. And {−2.75} = −2.75 − (−3) = 0.25, always in [0,1).
★ Bounded-trig trickSince −1 ≤ cos 3x ≤ 1 ⇒ 1 ≤ 2 − cos 3x ≤ 3, any 1/(2 − cos 3x) is squeezed into [1/3, 1]. Squeeze the denominator to get the range fast.
Worked examples from the module
Book Example · L-2
Find the range of f(x) = (x − 3)/(2 − x).
Put y = (x − 3)/(2 − x) ⇒ 2y − xy = x − 3 ⇒ x(1 + y) = 2y + 3 ⇒ x = (2y + 3)/(y + 1).
x is real for every y except y + 1 = 0, i.e. y = −1.
Range = R − {−1}
Book Example · L-2
Find the domain and range of f(x) = (x² − 16)/(x − 4).
Not defined at x = 4 ⇒ Domain = R − {4}.
y = (x−4)(x+4)/(x−4) = x + 4 for x ≠ 4 ⇒ x = y − 4; y = 8 would need x = 4 (excluded).
Domain = R − {4}, Range = R − {8}
Book Example · L-2
Find the range of f(x) = √(9 − x²).
Domain: 9 − x² ≥ 0 ⇒ −3 ≤ x ≤ 3. Then y = √(9 − x²) ⇒ x² = 9 − y².
Real x needs 9 − y² ≥ 0 ⇒ −3 ≤ y ≤ 3; and y = √(…) ≥ 0.
Range = [0, 3]
Book Example · L-2
Find the domain and range of f(x) = 1/(2 − cos 3x).
−1 ≤ cos 3x ≤ 1 ⇒ 1 ≤ 2 − cos 3x ≤ 3, never 0 ⇒ Domain = R.
Reciprocating: 1/3 ≤ 1/(2 − cos 3x) ≤ 1.
Domain = R, Range = [1/3, 1]

Algebra of Functions & Range Practice

Combining functions

algebra of functions(f ± g)(x) = f(x) ± g(x) · (fg)(x) = f(x)·g(x) · (f/g)(x) = f(x)/g(x), g(x) ≠ 0
  • Domain of f ± g and fg = Dom(f) ∩ Dom(g).
  • Domain of f/g = Dom(f) ∩ Dom(g) minus the points where g(x) = 0.
  • Scalar multiple: (cf)(x) = c·f(x); e.g. for f(x) = x/c, (cf)(x) = x and (c²f)(x) = cx.
More standard functions (graphs)
Quadratic f(x) = ax² + bx + c: parabola; with vertex form a(x − h)² + k the range is [k, ∞) if a > 0, else (−∞, k]. Cubic x³, cube root x^(1/3): Domain = Range = R (odd symmetry). Square root √x: Domain = Range = [0, ∞). Reciprocal 1/x: rectangular hyperbola, Domain = Range = R − {0}.
💡 Perfect-square trickTo find the range of a quadratic, complete the square. For x² + 4x + 5 = (x + 2)² + 1, the minimum is 1, so the range is [1, ∞).
⚠ TrapCancelling a factor changes the domain. x(x−1)(x−2)/[(x−1)(x−2)] = x but only for x ≠ 1, 2 — so those images are removed from the range.
Worked examples from the module
Book Example · L-3
Let f(x) = 1/(x + 4) and g(x) = (x + 4)³. Find (f + g)(x) and (fg)(x), with domains.
Dom(f) = R − {−4}, Dom(g) = R ⇒ common domain = R − {−4}.
(f + g)(x) = 1/(x+4) + (x+4)³ = [(x+4)⁴ + 1]/(x+4).
(fg)(x) = (1/(x+4))·(x+4)³ = (x + 4)².
(f+g)(x) = [(x+4)⁴+1]/(x+4); (fg)(x) = (x+4)²; both on R − {−4}
Book Example · L-3
If f(x) = (x − 1)/(x + 1), x ≠ −1, show that f(f(x)) = −1/x, provided x ≠ 0.
f(f(x)) = [ (x−1)/(x+1) − 1 ] / [ (x−1)/(x+1) + 1 ].
Numerator = (x − 1 − x − 1)/(x+1) = −2/(x+1); denominator = (x − 1 + x + 1)/(x+1) = 2x/(x+1).
Ratio = −2 / 2x = −1/x, meaningful for x ≠ 0.
f(f(x)) = −1/x (x ≠ 0)
Book Example · L-3
Find the domain and range of f(x) = 1/√(x − [x]).
x − [x] = {x} satisfies 0 ≤ {x} < 1, and equals 0 exactly when x ∈ Z ⇒ Domain = R − Z.
On R − Z: 0 < {x} < 1 ⇒ 0 < √{x} < 1 ⇒ 1/√{x} > 1.
Domain = R − Z, Range = (1, ∞)
Suggested Problem · L-3 (answer key)
Find the range of f(x) = x(x − 1)(x − 2)/[(x − 1)(x − 2)].
Cancel (x−1)(x−2): f(x) = x, but x ≠ 1 and x ≠ 2 (else denominator = 0).
So the outputs are all reals except the images at x = 1 and x = 2, namely 1 and 2.
Range = R − {1, 2}

Transformations of y = sin x / cos x

  • y = sin x + k: shifts the graph up along the y-axis to the line y = k.
  • y = k sin x: amplitude scales to k; range becomes [−k, k].
  • y = sin(kx) or sin(nx): period changes to 2π/k (horizontal compression); sin x has period 2π.
  • y = sin(x + k): shifts the graph along the x-axis (to x = −k).
amplitude & periody = k sin(nx): amplitude = |k|, period = 2π/n, range = [−|k|, |k|]
★ Undefined pointstan x & sec x blow up at x = (2n+1)π/2 (odd multiples of π/2). cot x & cosec x blow up at x = nπ (multiples of π).
Sketching y = k sin(nx) quickly
Draw y = sin x over [0, 2π], then (i) multiply every y-value by k to set the amplitude, and (ii) divide the x-coordinates of the zero-crossings by n to set the period. For y = 3 sin 2x the peaks are ±3 and the period is 2π/2 = π, so one full wave fits in [0, π].

Book Example · L-4
Sketch y = 3 sin 2x — state its amplitude, maximum, minimum and period.
Start from y = sin x, divide the x-coordinates of the x-axis crossings by 2, and scale the height by 3.
Amplitude = 3, so max = 3 and min = −3; period = 2π/2 = π.
Amplitude 3, max 3, min −3, period π

Sketch y = 3 cos 2x — give its amplitude and period.
Replace c by 3 and the angular factor by 2 in y = c cos(ax): the cosine wave starts at its peak (0, 3).
Amplitude = 3 (range [−3, 3]); period = 2π/2 = π.
Amplitude 3, range [−3, 3], period π
