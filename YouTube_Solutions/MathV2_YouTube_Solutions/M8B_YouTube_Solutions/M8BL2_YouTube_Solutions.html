1 (i)Sum of first n terms of an G.P. is denoted by ______.Notation for the sum of a G.P.Sum of n terms of a Geometric Progression — GP series🟡 SimilarSn
Concept The same capital-S convention as for an A.P.: lower-case an is a single term, capital Sn is the running total of the first n of them. Only the formula for Sn changes when you move from A.P. to G.P.
Formula Sn = a + ar + ar² + … + arn−1 n terms, exponents 0 to n−1
Solution
1. Write out what is being added: a, ar, ar², …, arn−1 — that is n terms.
2. Their total is written Sn, exactly as in the arithmetic case.
3. The link to the terms is the same too: Sn = Sn−1 + an, hence an = Sn − Sn−1.
4. What differs is the closed form: for an A.P. Sn is quadratic in n, but for a G.P. it is exponential in n.Sn = a(rⁿ − 1)/(r − 1) contains rⁿ.
5. Example: for 3, 6, 12, … the totals run S₁ = 3, S₂ = 9, S₃ = 21, S₄ = 45 — each one is 3(2ⁿ − 1).
6. So the blank is the capital-S symbol Sn.
   terms : a, ar, ar^2, ... , a r^(n-1)
   sum   : S_n = a + ar + ... + a r^(n-1)

   link  : a_n = S_n - S_(n-1)
   3, 6, 12, 24 :  S_n = 3(2^n - 1)  ->  3, 9, 21, 45
⚡ JEE Trick Decide the family from the shape of Sn: a quadratic in n with no constant term means an A.P.; something containing rⁿ means a G.P. That single reflex tells you which formula set to reach for before you read another word of the question.
Answer: Sn.
1 (ii)If r < 1 then sum of first n terms of a G.P. is ______.The (1 − rⁿ) formGeometric Progression — formula for the nth term, Class 11🟡 SimilarSn = a(1 − rⁿ)/(1 − r)
Concept The derivation is the "multiply and subtract" trick: write Sn, multiply it by r, and subtract. Almost everything cancels, leaving only the first term and the term just past the end.
Formula Sn = a(1 − rⁿ)/(1 − r) preferred when r < 1, so both brackets stay positive
Solution
1. Write Sn = a + ar + ar² + … + arn−1.
2. Multiply by r: rSn = ar + ar² + … + arn−1 + arn.
3. Subtract the second line from the first: every middle term cancels, leaving Sn − rSn = a − arn.
4. Factor both sides: Sn(1 − r) = a(1 − rⁿ).
5. Divide: Sn = a(1 − rⁿ)/(1 − r), valid whenever r ≠ 1.
6. Check with a = 1, r = 1/2, n = 4: (1 − 1/16)/(1/2) = (15/16)(2) = 15/8, matching 1 + 1/2 + 1/4 + 1/8 ✓.
    S_n = a + ar + ... + a r^(n-1)
   r S_n =     ar + ... + a r^(n-1) + a r^n
   ------------------------------------------ subtract
   S_n (1 - r) = a (1 - r^n)
   S_n = a(1 - r^n)/(1 - r)

   a=1, r=1/2, n=4 :  (15/16)/(1/2) = 15/8
⚡ JEE Trick Both forms of the sum are the same formula — multiply numerator and denominator by −1 to swap between them. Choose the one that keeps your arithmetic positive: (1 − rⁿ)/(1 − r) when r < 1, (rⁿ − 1)/(r − 1) when r > 1. Neither is "more correct"; picking the wrong one just means dividing two negatives.
Answer: Sn = a(1 − rn)/(1 − r).
1 (iii)If r > 1 then sum of first n-terms of a G.P. is ______.The (rⁿ − 1) formSum of n terms of a Geometric Progression — GP series🟢 ExactSn = a(rn − 1)/(r − 1)
Concept Identical to (ii) with both signs flipped. When r exceeds 1 the quantity rⁿ − 1 is positive and r − 1 is positive, so the arithmetic stays clean.
Formula Sn = a(rn − 1)/(r − 1) multiply the (ii) form top and bottom by −1
Solution
1. Start from Sn = a(1 − rⁿ)/(1 − r).
2. Multiply numerator and denominator by −1: numerator becomes rⁿ − 1, denominator becomes r − 1.
3. So Sn = a(rⁿ − 1)/(r − 1) — the same number, written for positive quantities.
4. Check with 3, 6, 12, 24, 48: a = 3, r = 2, n = 5 gives 3(32 − 1)/1 = 93 ✓, which is Quick Recap 2(A) of this lecture.
5. Both forms fail at r = 1 (division by zero); that case is handled separately as Sn = an.
6. Powers of 2 make a useful anchor: a = 1, r = 2 gives Sn = 2ⁿ − 1, the familiar 1, 3, 7, 15, 31, 63, 127, 255, 511, …
   S_n = a(1 - r^n)/(1 - r)      [x -1 top and bottom]
       = a(r^n - 1)/(r - 1)

   3, 6, 12, 24, 48 :  3(2^5 - 1)/1 = 93

1 (iv)If |r| < 1 then sum of infinite G.P. is ______.Sum to infinitySum to infinity of a geometric progression — Class 11🟢 ExactS∞ = a/(1 − r)
Concept When |r| < 1 the powers rⁿ shrink to zero, so the rⁿ in the finite-sum formula simply disappears. What survives is a/(1 − r) — a finite number even though infinitely many terms are being added.
Formula S∞ = a/(1 − r), valid only for |r| < 1
Solution
1. Start from Sn = a(1 − rⁿ)/(1 − r).
2. If |r| < 1 then rⁿ → 0 as n grows without bound.e.g. (1/2)ⁿ runs 0.5, 0.25, 0.125, … → 0.
3. So Sn → a(1 − 0)/(1 − r) = a/(1 − r).
4. The condition matters: if |r| ≥ 1 the powers do not shrink and the series diverges — no finite sum exists.
5. Check with 1, 1/2, 1/4, 1/8, …: S∞ = 1/(1 − 1/2) = 2, which is Quick Recap 4(D) of this lecture ✓.
6. Negative r is allowed: 10 − 9 + 8.1 − … has r = −0.9 and sums to 10/1.9 ≈ 5.263 ✓.
   |r| < 1  =>  r^n -> 0
   S_n = a(1 - r^n)/(1 - r)  ->  a/(1 - r)

   1, 1/2, 1/4, ...  :  1/(1 - 1/2) = 2
   10 - 9 + 8.1 ...  :  10/(1 + 0.9) = 5.263
⚡ JEE Trick The condition is |r| < 1, not 0 < r < 1 — negative ratios are perfectly allowed, and papers exploit that constantly. LEVEL-1 Q1 and Q4 of this lecture both test exactly this point, and the option "only for 0 < r < 1" is the planted trap.
Answer: S∞ = a/(1 − r), for |r| < 1.

Formula 5 + 55 + … = (5/9)[(10 + 10² + … + 10ⁿ) − n] ⇒ (5/81)[10n+1 − 9n − 10]
Solution
1. Multiply and divide by 9: 5 + 55 + 555 + … = (5/9)(9 + 99 + 999 + …).
2. Write each repunit as a power of ten minus one: 9 + 99 + 999 + … = (10 − 1) + (10² − 1) + … + (10ⁿ − 1).
3. Split: = (10 + 10² + … + 10ⁿ) − n. The bracket is a G.P. with a = 10, r = 10, so it equals 10(10ⁿ − 1)/9 = (10n+1 − 10)/9.
4. Therefore the sum is (5/9)[(10n+1 − 10)/9 − n] = (5/81)[10n+1 − 9n − 10].
5. Match against (5/p²)[(2q)n+1 + 3rn − 10]: p² = 81 ⇒ p = 9; 2q = 10 ⇒ q = 5; 3r = −9 ⇒ r = −3.

Concept For three terms in G.P. the product is the middle term cubed, so the middle term drops out immediately. The sum then gives the total of the outer pair, and their product is the middle squared — a standard quadratic.
Formula pqr = q³; pr = q²; p + r = 38 − q
Solution
1. Product: p·q·r = q³ = 1728 ⇒ q = ∛1728 = 12.
2. Sum: p + 12 + r = 38 ⇒ p + r = 26.
3. G.P. condition: pr = q² = 144.
4. So p and r are roots of t² − 26t + 144 = 0. Discriminant = 676 − 576 = 100.
5. t = (26 ± 10)/2 = 18 or 8. Since p < q < r we take p = 8 and r = 18.
6. Verify: 8 + 12 + 18 = 38 ✓, 8 × 12 × 18 = 1728 ✓, and 8, 12, 18 has ratio 3/2 ✓.
   pqr = q^3 = 1728   ->  q = 12
   p + r = 26 ,  pr = q^2 = 144
   t^2 - 26t + 144 = 0  ->  t = 8, 18

   p < q < r  ->  8, 12, 18      (ratio 3/2)
⚡ JEE Trick Contrast the two families: for three terms in A.P. the sum gives the middle term (Σ/3); for three in G.P. the product gives it (∛Π). Whichever datum is offered tells you which family the setter intends. This exact triple returns as Suggested Problem 8 of the same lecture.
Answer: p = 8, q = 12, r = 18.
