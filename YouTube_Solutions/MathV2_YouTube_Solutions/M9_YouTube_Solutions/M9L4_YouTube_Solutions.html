1 (i)|z₁| + |z₂| ____ |z₁ + z₂|Triangle inequalityComplex Number 12 | Triangular Inequality of Modulus of Complex Number | JEE/BITSAT/CET/ Class 11🟡 Similar≥
Concept In the Argand plane z₁ and z₂ are position vectors from the origin, and z₁ + z₂ is the diagonal of the parallelogram they span. Walking from O to z₁ and then on to z₁ + z₂ covers a distance |z₁| + |z₂|, whereas the straight hop from O to z₁ + z₂ costs only |z₁ + z₂|. A straight path can never be longer than a bent one, so the bent route dominates. That geometric fact is the triangle inequality, and it is an inequality with equality allowed, not a strict one.
Formula |z₁ + z₂| ≤ |z₁| + |z₂|, equivalently |z₁| + |z₂| ≥ |z₁ + z₂|. Equality holds exactly when z₁ and z₂ point the same way, i.e. arg z₁ = arg z₂ or one of them is 0.
Solution
1. Square the left side using |w|² = w·w̄ : |z₁ + z₂|² = (z₁ + z₂)(z̄₁ + z̄₂) = |z₁|² + |z₂|² + (z₁z̄₂ + z̄₁z₂).
2. The bracket is a real number: z₁z̄₂ + z̄₁z₂ = 2Re(z₁z̄₂) ≤ 2|z₁z̄₂| = 2|z₁||z₂|. Re(w) ≤ |w| always, since |w| = √(Re²+Im²) ≥ |Re w|.
3. Substitute: |z₁ + z₂|² ≤ |z₁|² + 2|z₁||z₂| + |z₂|² = (|z₁| + |z₂|)².
4. Both sides are non-negative, so square-rooting preserves the order: |z₁ + z₂| ≤ |z₁| + |z₂|. Read backwards, the blank must be ≥.
5. Numerical check with z₁ = 3, z₂ = 4i : |z₁| + |z₂| = 3 + 4 = 7, while |z₁ + z₂| = |3 + 4i| = √25 = 5, and 7 ≥ 5. Perpendicular vectors give the biggest gap between the two sides.
6. Equality test with z₁ = 3, z₂ = 4 : 3 + 4 = 7 = |7|, so the two sides can be equal and the blank cannot be a strict >. Same argument means the triangle collapses onto a line.
  z1      z2       |z1|+|z2|    |z1+z2|   relation
  ---------------------------------------------------
   3      4i          7            5        7 > 5
   3      4           7            7        equal
   3     -4           7            1        7 > 1
  1+i    1-i        2sqrt2         2       2.83 > 2
  so always  |z1|+|z2| >= |z1+z2|
⚡ JEE Trick The trap is writing a strict > because a triangle "must" have three genuine sides; the degenerate collinear case is legal for complex numbers, so ≥ is the only safe symbol. Remember the pair as one sandwich: ||z₁| − |z₂|| ≤ |z₁ ± z₂| ≤ |z₁| + |z₂|. Whenever a problem asks for a maximum of a sum of moduli, this upper half is what you invoke; the lower half handles minima.
Answer: ≥ (that is, |z₁| + |z₂| ≥ |z₁ + z₂|).
1 (ii)|z₁| + |z₂| ____ |z₁ - z₂|Triangle inequalityComplex Number 12 | Triangular Inequality of Modulus of Complex Number | JEE/BITSAT/CET/ Class 11🟡 Similar≥
Concept |z₁ − z₂| is the distance between the points z₁ and z₂ in the Argand plane, while |z₁| and |z₂| are their distances from the origin. Those three lengths are the three sides of the triangle O z₁ z₂, so the side z₁z₂ can never exceed the other two added together. Algebraically the same statement follows by replacing z₂ with −z₂ in the ordinary triangle inequality, because negating a complex number does not change its modulus. So the difference obeys exactly the same upper bound as the sum.
Formula |z₁ − z₂| ≤ |z₁| + |−z₂| = |z₁| + |z₂|. |−z₂| = |−1|·|z₂| = |z₂|, since multiplying by −1 is a rotation through π and rotations preserve length.
Solution
1. Write the difference as a sum: z₁ − z₂ = z₁ + (−z₂), which is legitimate because subtraction is addition of the additive inverse.
2. Apply the sum form of the inequality to this pair: |z₁ + (−z₂)| ≤ |z₁| + |−z₂| = |z₁| + |z₂|. Hence the blank is ≥.
3. Verify by expansion: |z₁ − z₂|² = |z₁|² + |z₂|² − 2Re(z₁z̄₂) ≤ |z₁|² + |z₂|² + 2|z₁||z₂| = (|z₁| + |z₂|)². −2Re(w) ≤ 2|w| holds for every complex w, so the middle term is bounded.
4. Numerical check with z₁ = 3, z₂ = 4i : |z₁| + |z₂| = 7 and |z₁ − z₂| = |3 − 4i| = 5, so 7 ≥ 5.
5. Equality case: take z₁ = 3, z₂ = −3. Then |z₁| + |z₂| = 6 and |z₁ − z₂| = |6| = 6, so equality is attainable and ≥ cannot be tightened to >. Equality needs arg z₁ and arg z₂ to differ by π, i.e. opposite directions.
6. Geometrically the chord z₁z₂ is longest when O lies between the two points on one straight line; then the chord is exactly |z₁| + |z₂|. This is the standard way to read off the maximum distance between two points on a circle centred at O.
  z1     z2      |z1|+|z2|   |z1-z2|    relation
  -------------------------------------------------
   3     4i          7          5        7 > 5
   3     -3          6          6        equal
   3      3          6          0        6 > 0
  same rule as (i) because |-z2| = |z2|
  so   |z1|+|z2| >= |z1-z2|   always
⚡ JEE Trick Students often assume the difference must obey a smaller bound than the sum; it does not — the upper bound |z₁| + |z₂| is identical for both, only the equality case flips from "same argument" to "opposite arguments". The one-line reason is |−z₂| = |z₂|, so every result proved for sums transfers to differences free of charge. Keep the four-part sandwich ||z₁| − |z₂|| ≤ |z₁ ± z₂| ≤ |z₁| + |z₂| as a single memorised object.
Answer: ≥ (that is, |z₁| + |z₂| ≥ |z₁ − z₂|).
1 (iii)||z₁| - |z₂|| ____ |z₁ - z₂|Triangle inequalityComplex Number 12 | Triangular Inequality of Modulus of Complex Number | JEE/BITSAT/CET/ Class 11🟡 Similar≤
Concept This is the reverse triangle inequality, the lower half of the standard sandwich. Geometrically |z₁| and |z₂| are two sides of triangle O z₁ z₂ and |z₁ − z₂| is the third; the difference of two sides of a triangle can never exceed the third side. The outer modulus bars on ||z₁| − |z₂|| are there because we do not know which of |z₁|, |z₂| is larger, and the bound must hold either way. So the distance between two points is at least the gap between their distances from the origin.
Formula ||z₁| − |z₂|| ≤ |z₁ − z₂|. It is derived from the ordinary triangle inequality applied twice, once in each order, so no new principle is needed.
Solution
1. Write z₁ = (z₁ − z₂) + z₂ and take moduli: |z₁| ≤ |z₁ − z₂| + |z₂|, hence |z₁| − |z₂| ≤ |z₁ − z₂|.
2. Swap the roles: z₂ = (z₂ − z₁) + z₁ gives |z₂| − |z₁| ≤ |z₂ − z₁| = |z₁ − z₂|. |z₂ − z₁| = |−(z₁ − z₂)| = |z₁ − z₂|, so the right side is unchanged.
3. Both a number and its negative are ≤ |z₁ − z₂|, so the larger of them, which is ||z₁| − |z₂||, satisfies ||z₁| − |z₂|| ≤ |z₁ − z₂|. The blank is ≤.
4. Numerical check with z₁ = 3 + 4i, z₂ = 1 : ||z₁| − |z₂|| = |5 − 1| = 4 and |z₁ − z₂| = |2 + 4i| = √20 ≈ 4.47, so 4 ≤ 4.47.
5. Equality case: z₁ = 5, z₂ = 1 gives ||5| − |1|| = 4 = |5 − 1|, so ≤ is the correct symbol, not a strict <. Equality needs z₁ and z₂ on the same ray from O, arg z₁ = arg z₂.
6. Practical use: if |z − 3| = 2 then ||z| − 3| ≤ 2, so 1 ≤ |z| ≤ 5 — the min and max of |z| on a circle drop straight out of this one line. That is why every "least value of |z|" question in this lecture is really this inequality in disguise.
  z1        z2     ||z1|-|z2||   |z1-z2|    relation
  ------------------------------------------------------
  3+4i       1          4          4.47      4 <= 4.47
   5         1          4           4        equal
   3        -3          0           6        0 <= 6
   2i        2          0          2.83      0 <= 2.83
  lower bound of the sandwich, upper bound is |z1|+|z2|
⚡ JEE Trick The trap is dropping the outer bars and writing |z₁| − |z₂| ≤ |z₁ − z₂|; that statement is true but weaker, and it fails to give a bound when |z₂| > |z₁|. Keep the bars so the inequality is symmetric in the two numbers. Anytime you see "least value of |z| given |z − a| = r", answer instantly with ||z| − |a|| ≤ r, giving |z| ≥ |a| − r.
Answer: ≤ (that is, ||z₁| − |z₂|| ≤ |z₁ − z₂|).
1 (iv)||z₁| - |z₂|| ____ |z₁| + |z₂|Triangle inequalityComplex Number 12 | Triangular Inequality of Modulus of Complex Number | JEE/BITSAT/CET/ Class 11🟡 Similar≤
Concept Here both sides are built only from the two non-negative real numbers a = |z₁| and b = |z₂|, so the complex structure has already been squeezed out. The question reduces to comparing |a − b| with a + b for a, b ≥ 0. Since subtracting a non-negative quantity can only shrink a number while adding it can only grow it, the difference is always the smaller of the two. This is also the outermost pair of the standard chain ||z₁| − |z₂|| ≤ |z₁ ± z₂| ≤ |z₁| + |z₂|, obtained by skipping the middle term.
Formula ||z₁| − |z₂|| ≤ |z₁| + |z₂|, i.e. |a − b| ≤ a + b for a, b ≥ 0. It is the two ends of the sandwich compared directly, so it follows from transitivity through |z₁ − z₂|.
Solution
1. Put a = |z₁| ≥ 0 and b = |z₂| ≥ 0; the claim to test is |a − b| ≤ a + b.
2. Case b ≤ a : |a − b| = a − b, and a − b ≤ a + b because b ≥ 0 forces −b ≤ b. Subtracting b instead of adding it can only lower the value when b ≥ 0.
3. Case a < b : |a − b| = b − a ≤ b + a, by the same reasoning with a ≥ 0.
4. Both cases give ||z₁| − |z₂|| ≤ |z₁| + |z₂|, so the blank is ≤.
5. Chain proof in one line: ||z₁| − |z₂|| ≤ |z₁ − z₂| ≤ |z₁| + |z₂| by parts (iii) and (ii), and transitivity closes it. This shows (iv) carries no new information — it is the weakest link of the chain.
6. Equality test: z₁ = 3, z₂ = 0 gives |3 − 0| = 3 = 3 + 0, so equality is possible and the symbol must be ≤. Numerical check with z₁ = 3, z₂ = 4i : ||z₁| − |z₂|| = |3 − 4| = 1 and |z₁| + |z₂| = 7, so 1 ≤ 7. Equality happens only when at least one of z₁, z₂ is 0.
  |z1|   |z2|    ||z1|-|z2||    |z1|+|z2|   relation
  ------------------------------------------------------
    5      3           2             8       2 <= 8
    3      4           1             7       1 <= 7
    3      0           3             3       equal
    0      0           0             0       equal
  gap = 2*min(|z1|,|z2|), zero only if one is 0
⚡ JEE Trick Do not hunt for a clever complex-number argument here; once you name a = |z₁| and b = |z₂| the problem is pure real-number arithmetic on non-negatives. The exact gap is (a + b) − |a − b| = 2·min(a, b), which instantly tells you equality needs min(a, b) = 0. Memorise the full chain ||z₁| − |z₂|| ≤ |z₁ ± z₂| ≤ |z₁| + |z₂| and all four parts of this question are one object.
Answer: ≤ (that is, ||z₁| − |z₂|| ≤ |z₁| + |z₂|).

Concept |z − c| = ρ is a circle of centre c and radius ρ, so every question about |z| becomes a question about distances from the origin to points of that circle. The nearest and farthest points both lie on the straight line through O and c, which is why the extreme values are just |c| ± ρ. For two points on one circle the largest possible separation is the diameter, achieved when they are diametrically opposite. All three unknowns therefore come from one picture.
Formula On |z − c| = ρ : |z|max = |c| + ρ, |z|min = ||c| − ρ|, |z₁ − z₂|max = 2ρ. The first two are the triangle inequality sandwich ||c| − ρ| ≤ |z| ≤ |c| + ρ applied to z = c + (z − c).
Solution
1. Put the equation in standard form: |z − 3 + 4i| = |z − (3 − 4i)| = 6, so the centre is c = 3 − 4i and the radius is ρ = 6.
2. Distance from the origin to the centre: |c| = √(3² + (−4)²) = √(9 + 16) = √25 = 5. Since 5 < 6 the origin lies inside the circle, which decides the shape of the minimum.
3. Maximum: |z| ≤ |c| + |z − c| = 5 + 6 = 11, attained at the point of the circle diametrically beyond the centre. Hence p = 11.
4. Minimum: ||z| − |c|| ≤ |z − c| = 6 gives |z| ≥ |c| − 6 = −1, which is vacuous, so use |z| ≥ ρ − |c| = 6 − 5 = 1 from the same inequality read the other way. Hence q = 1. With O inside the circle the closest point is at distance ρ − |c|, never 0 unless |c| = ρ.
5. Largest separation of two points z₁, z₂ on the circle: |z₁ − z₂| ≤ |z₁ − c| + |c − z₂| = 6 + 6 = 12, i.e. the diameter, so r = 12.
6. Consistency check: the extreme moduli occur at z = c(1 ± 6/5), i.e. at z = (3 − 4i)(11/5) with |z| = 11 and z = −(3 − 4i)/5 with |z| = 1, and 11 + 1 = 12 = the diameter. Those two points are ends of the same diameter through O, so their separation must equal 2ρ.

Concept An equation mixing z with z̄ is not a polynomial in z, so the fundamental theorem of algebra does not apply and the root count must be found by hand. The standard opening move is to take moduli of both sides, because |z̄| = |z| turns the mixed equation into a real equation in |z| alone. Once |z| is pinned down, the relation z z̄ = |z|² lets you eliminate z̄ and get a genuine polynomial. Zero must be checked separately, since dividing by z is illegal there.
Formula |z̄| = |z|, z z̄ = |z|², so |z| = 1 ⇒ z̄ = 1/z. Taking moduli converts an equation between complex numbers into one between non-negative reals, which is far easier to solve.
Solution
1. Take moduli in z² = −z̄ : |z|² = |−z̄| = |z|, so |z|(|z| − 1) = 0 and |z| = 0 or |z| = 1. The non-trivial modulus is p = 1.
2. z = 0 satisfies the equation, giving one solution with |z| = 0. It is a genuine root but it is the degenerate one; the stated p = 1 refers to the non-zero roots.
3. For |z| = 1 use z z̄ = 1, so z̄ = 1/z, and the equation z² + z̄ = 0 becomes z² + 1/z = 0, i.e. z³ = −1.
4. z³ = −1 = e^(iπ) has exactly three roots, z = e^(iπ/3), e^(iπ) = −1, e^(i5π/3), that is −1 and (1 ± i√3)/2, all of modulus 1. A degree-3 polynomial equation has exactly 3 roots in ℂ, no more and no fewer.
5. Cartesian cross-check with z = x + iy : x² − y² + x = 0 and y(2x − 1) = 0. The branch y = 0 gives x = 0, −1; the branch x = 1/2 gives y = ±√3/2 — the same four points. Two independent methods agreeing is the safest way to trust a root count.
6. Total: q = 3 + 1 = 4 solutions, and r = 2p + q = 2(1) + 4 = 6.
  z^2 = -zbar    ->  |z|^2 = |z|  ->  |z| = 0 or 1
  ---------------------------------------------------
  |z| = 0 :  z = 0                        1 solution
  |z| = 1 :  zbar = 1/z  ->  z^3 = -1     3 solutions
     roots : -1,  (1 + i*sqrt3)/2,  (1 - i*sqrt3)/2
  ---------------------------------------------------
  p = 1,  q = 4,  r = 2(1) + 4 = 6
⚡ JEE Trick The classic loss of marks is dividing by z to reach z³ = −1 and reporting only 3 solutions — the division silently discards the root z = 0, and the intended count is 4. The mirror-image error is squaring or conjugating carelessly and picking up spurious roots, so always substitute your candidates back. Note also that |z| = 0 and |z| = 1 both survive step 1; the value p = 1 is the modulus of the three non-zero roots, all of which lie on the unit circle.
Answer: p = 1, q = 4, r = 6.

Concept Squaring a complex number is ordinary binomial expansion with the single extra rule i² = −1, which converts the last term from +b² into −b². Comparing the result with p + qi then identifies p as the real part and q as the coefficient of i, because a complex number determines its real and imaginary parts uniquely. The modulus squared is a separate quantity: |z|² = z z̄ = a² + b², always real and non-negative. Keeping z² and |z|² apart is the whole point of this drill.
Formula (a + ib)² = a² − b² + 2abi and |a + ib|² = a² + b². The first keeps the sign flip from i² = −1; the second comes from z z̄ = (a + ib)(a − ib), where the cross terms cancel instead.
Solution
1. Here a = 3 and b = 1, so z = 3 + i and z̄ = 3 − i.
2. Square directly: z² = (3 + i)² = 9 + 6i + i² = 9 + 6i − 1 = 8 + 6i. The i² term is the only place a sign changes; forgetting it gives the wrong 10 + 6i.
3. Compare with p + qi : p = 8 and q = 6, since two complex numbers are equal only when both real and imaginary parts match.
4. Modulus squared: |z|² = 3² + 1² = 9 + 1 = 10, so r = 10. Equivalently |z|² = z z̄ = (3 + i)(3 − i) = 9 − i² = 10.
5. Cross-check through |z²| = |z|² : |8 + 6i| = √(64 + 36) = √100 = 10 = (√10)², which confirms both p, q and r at once. |z²| = |z|² because the modulus is multiplicative, so an error in z² would show up here immediately.
6. Note p + q = 14 ≠ r and p² + q² = 100 = r², so the three answers are p = 8, q = 6, r = 10 with no accidental coincidence to mislead you. (8, 6, 10) is just the 3-4-5 triangle scaled by 2, arising from the doubling of the argument.

So the expression is a weighted sum of distances from three points that all lie on the real axis, with weights 1, 1 and 2. Because the three points are collinear, moving off the real axis only lengthens every term, so the minimum is found by studying a piecewise-linear function of one real variable.
Formula |2z − 3| = 2|z − 3/2| and |z − a| = √((x−a)² + y²) ≥ |x − a| for real a. Equality holds only when y = 0, which is what confines the minimiser to the real axis.
Solution
1. Factor the coefficient out: f(z) = |z| + |z−1| + 2|z − 3/2|, i.e. weights 1, 1, 2 at the points 0, 1, 3/2.
2. Write z = x + iy; each term obeys |z − a| ≥ |x − a|, so f(z) ≥ g(x) = |x| + |x−1| + 2|x − 3/2| with equality iff y = 0.
3. On 1 ≤ x ≤ 3/2: g(x) = x + (x−1) + 2(3/2 − x) = 2x − 1 + 3 − 2x = 2, a constant. The +2 slope from the left pair exactly cancels the −2 slope from the weighted point.
4. On 0 ≤ x ≤ 1: g(x) = x + (1−x) + 2(3/2 − x) = 4 − 2x, decreasing, so its least value on that piece is g(1) = 2.
5. On x ≥ 3/2: g(x) = x + (x−1) + 2(x − 3/2) = 4x − 4, increasing from g(3/2) = 2; and on x ≤ 0, g(x) = 4 − 4x ≥ 4.
