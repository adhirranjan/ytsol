1Which is true for all θ? (sin(90°−θ)=cosθ …)Allied-angle identitywatch?v=xiMDTiFTeE8🟡 Similarasin(90°−θ) = cos θ
Concept 90°−θ is the complement of θ. The co-function identities say a trig ratio of an angle equals the co-ratio of its complement — sin↔cos, tan↔cot, sec↔cosec — because in a right triangle the two acute angles sum to 90° and the "opposite" side of one is the "adjacent" side of the other. So the only universally true statement is the genuine co-function pairing.
Formula sin(90°−θ)=cos θ, cos(90°−θ)=sin θ, tan(90°−θ)=cot θ. 90°−θ lands in the first quadrant for acute θ, where every ratio is positive, so no sign change appears — only the name flips to its co-ratio.
Solution
1. Locate 90°−θ: subtracting from 90° gives the complementary angle, and 90° sits on the y-axis, so the function name changes to its co-function.Reflection about the 45° line swaps the roles of the opposite and adjacent sides.
2. Fix the sign: for the standard acute θ, 90°−θ is still in Quadrant I where sine is positive, so no minus sign is introduced.
3. Combine name-change + sign: sin(90°−θ) = +cos θ.This matches the printed identity, so that option is the one true for every θ.
⚡ JEE Trick Angles measured from the vertical axis (90°, 270°) flip the function to its co-function; angles from the horizontal axis (180°, 360°) keep the function. Then attach the sign of the original ratio in the quadrant the angle lands in. Trap: options like "sin(90°−θ)=sin θ" keep the name — wrong, because 90° forces a co-function switch.
Answer: (a) sin(90°−θ) = cos θ.
2Evaluate tan(180°+45°)Allied-angle evaluationwatch?v=BO5ABJ86sMc🟡 Similarb1
Concept 180°+45° is an angle in the third quadrant. Adding 180° to an angle rotates it half a turn; since 180° lies on the horizontal axis, the function name stays tan, and we only decide the sign from the quadrant. In Q3 both sine and cosine are negative, so their ratio tangent is positive.
Formula tan(180°+θ)=+tan θ. tan(180°+θ)=sin(180°+θ)/cos(180°+θ)=(−sinθ)/(−cosθ)=tanθ — the two minus signs cancel. Standard value tan 45° = 1.
Solution
1. Split the angle: 180°+45° puts the terminal side in Quadrant III (180°–270°).
2. Apply the allied rule: 180° is a horizontal-axis angle, so tan stays tan, and tan is positive in Q3 → tan(180°+45°)=+tan45°.Q3 is where "Add Sugar To Coffee": only Tan (and cot) are positive.
3. Substitute the standard value: tan45° = 1.
⚡ JEE Trick tan and cot have period 180°, so tan(180°+θ)=tanθ instantly — no sign hunting needed for these two. Trap: the same shortcut fails for sin/cos, which have period 360°, so sin(180°+θ)=−sinθ.
Answer: 1.
3cos θ=5/13 (acute) → sin(180°−θ)Allied-angle identitywatch?v=xiMDTiFTeE8🟡 Similara12/13
Concept Two ideas combine: first, sin(180°−θ) is a Q2 supplement whose sine equals +sin θ; second, the given cos θ fixes sin θ through the Pythagorean identity. So the whole task is "find sin θ from cos θ, then carry it through the allied-angle rule."
Formula sin(180°−θ)=sin θ (180° is horizontal → name stays sin; Q2 → sine positive). Pythagorean identity sin²θ+cos²θ=1 ⇒ sin θ=√(1−cos²θ) (positive root, θ acute).
Solution
1. Reduce the allied angle: sin(180°−θ)=sin θ, so I just need sin θ.
2. Insert cos θ=5/13 into the identity: sin²θ = 1 − (5/13)² = 1 − 25/169.
3. Common denominator: 1 = 169/169, so sin²θ = 169/169 − 25/169 = 144/169.
4. Take the positive square root (θ acute ⇒ sin θ>0): sin θ = √(144/169) = 12/13.√144=12, √169=13; acute angle guarantees the + sign.
5. Therefore sin(180°−θ) = sin θ = 12/13.
⚡ JEE Trick Recognise 5-12-13 as a Pythagorean triple: cos=5/13 instantly gives sin=12/13, no algebra needed. Trap: sin(180°−θ) keeps the plus sign (Q2 sine positive); it is only cos and tan of a supplement that turn negative.
Answer: sin(180°−θ) = 12/13.

6Find acute A,B: cot(A+B)=1, cosec(A−B)=2Ratios from equationswatch?v=G4Dm8WYc73s🟡 SimilarA = 37½°, B = 7½°
Concept Convert each trig equation into a plain angle equation using the standard-angle table, giving a linear system in the compound angles A+B and A−B. Then solve the two simultaneous linear equations for A and B.
Formula cot θ = 1 ⇒ θ = 45° (since cot45°=1); cosec θ = 2 ⇒ sin θ = 1/2 ⇒ θ = 30°. Then solve A = ½[(A+B)+(A−B)], B = ½[(A+B)−(A−B)].

1. From cot(A+B)=1: the acute angle with cotangent 1 is 45°, so A+B = 45°.

8Prove sin(8π/3)cos(23π/6)+cos(13π/3)sin(35π/6)=1/2Allied-angle evaluationwatch?v=hw1EiP9lgJk🟢 Exact—
Concept Every angle here is larger than 2π, so the first move is to strip complete revolutions — sine and cosine repeat every full turn, so only the leftover matters. Reduce each of the four big angles to a small allied angle, read its exact value from the standard table with the sign fixed by parity (sin is odd, cos is even) or quadrant, then the "proof" collapses to arithmetic with √3/2 and 1/2.
Formula sin(2nπ+θ)=sin θ, cos(2nπ+θ)=cos θ; parity sin(−θ)=−sin θ, cos(−θ)=cos θ. Full turns change nothing; reducing against the nearest even multiple of π may leave a negative angle, and parity converts it instantly. Standard values: sin(π/3)=√3/2, cos(π/6)=√3/2, cos(π/3)=1/2, sin(π/6)=1/2.
Solution
1. sin(8π/3): 8π/3 = 2π + 2π/3 ⇒ sin(8π/3) = sin(2π/3) = sin(π − π/3) = sin(π/3) = √3/2.2π/3 lies in Q2, where sine stays positive.
2. cos(23π/6): 23π/6 = 4π − π/6 ⇒ cos(23π/6) = cos(−π/6) = cos(π/6) = √3/2.cos is even, so the minus sign vanishes.
3. cos(13π/3): 13π/3 = 4π + π/3 ⇒ cos(13π/3) = cos(π/3) = 1/2.
4. sin(35π/6): 35π/6 = 6π − π/6 ⇒ sin(35π/6) = sin(−π/6) = −sin(π/6) = −1/2.sin is odd — this is the only negative value in the whole problem, and the proof hinges on it.
5. Form the two products: (√3/2)(√3/2) = 3/4 and (1/2)(−1/2) = −1/4.
6. Add: LHS = 3/4 − 1/4 = 1/2 = RHS — proved.

⚡ JEE Trick Reduce against the nearest even multiple of π (4π, 6π, …) instead of peeling off 2π repeatedly — 23π/6 = 4π − π/6 in one glance, then sin-odd/cos-even fixes the sign instantly. Trap: writing sin(35π/6) = +1/2; the angle terminates in Q4 where sine is negative, and that single minus sign is exactly what turns the wrong 3/4 + 1/4 = 1 into the correct 3/4 − 1/4 = 1/2.
Answer: LHS = 1/2 — identity proved.
9a=secθ−tanθ, b=cosecθ+cotθ → show ab+a−b+1=0Identity proofIf a = sec x - tan x and b = cosec x + cot x, then show that ab + a - b + 1 = 0🟢 Exact—
Concept The cleanest way to prove a relation between secθ−tanθ and cosecθ+cotθ is the half-angle (Weierstrass) substitution t=tan(θ/2): it turns both a and b into simple rational functions of t, after which the target reduces to elementary algebra. The goal ab+a−b+1=0 rearranges to a=(b−1)/(b+1), so we prove that.
Formula With t=tan(θ/2): sinθ=2t/(1+t²), cosθ=(1−t²)/(1+t²). Also secθ−tanθ=(1−sinθ)/cosθ and cosecθ+cotθ=(1+cosθ)/sinθ.
Solution
1. Simplify a: a = secθ−tanθ = (1−sinθ)/cosθ = [1 − 2t/(1+t²)] ÷ [(1−t²)/(1+t²)] = (1+t²−2t)/(1−t²) = (1−t)²/[(1−t)(1+t)] = (1−t)/(1+t).1+t²−2t=(1−t)² and 1−t²=(1−t)(1+t); one (1−t) cancels.
2. Simplify b: b = cosecθ+cotθ = (1+cosθ)/sinθ = [1 + (1−t²)/(1+t²)] ÷ [2t/(1+t²)] = (1+t²+1−t²)/(2t) = 2/(2t) = 1/t.
3. From step 2, t = 1/b. Substitute into a: a = (1−t)/(1+t) = (1 − 1/b)/(1 + 1/b) = (b−1)/(b+1).Multiply top and bottom by b to clear the 1/b.
4. Cross-multiply: a(b+1) = b−1 ⇒ ab + a = b − 1 ⇒ ab + a − b + 1 = 0.Move every term to the left; the identity is established.
5. Numeric check at θ=45°: a=√2−1≈0.414, b=√2+1≈2.414, ab≈1, so ab+a−b+1 ≈ 1+0.414−2.414+1 = 0. ✓
⚡ JEE Trick secθ−tanθ = tan(45°−θ/2) and cosecθ+cotθ = cot(θ/2) are worth memorising — they instantly linearise "prove a relation between them" problems. Trap: don't expand ab directly in sec/tan/cosec/cot form; the t=tan(θ/2) substitution avoids a messy cross-multiplication.
Answer: ab + a − b + 1 = 0 (proved).

12cos²θ + 3cosθ = 2 → find cos θQuadratic in cos θwatch?v=G4Dm8WYc73s🟡 Similarcos θ = 1/2
Concept Treat cos θ as a single unknown c; the equation is an ordinary quadratic in c. Solve it, then reject any root that violates the range −1 ≤ cos θ ≤ 1, because a cosine can never exceed 1 in magnitude.
Formula A quadratic 2c²+3c−2=0 factorises via the AC-method (product 2×(−2)=−4, splitting 3 into 4 and −1). Constraint: −1 ≤ cos θ ≤ 1.
Solution
1. Bring all terms to one side: 2cos²θ + 3cosθ − 2 = 0. Let c = cos θ ⇒ 2c² + 3c − 2 = 0.
2. Factor: split 3c into 4c − c ⇒ 2c² + 4c − c − 2 = 2c(c+2) − 1(c+2) = (2c−1)(c+2) = 0.
3. Set each factor to zero: 2c − 1 = 0 ⇒ c = 1/2; or c + 2 = 0 ⇒ c = −2.
4. Apply the range: c = −2 is impossible since |cos θ| ≤ 1, so reject it. Only c = 1/2 survives.cos θ = 1/2 corresponds to θ = 60° (or 300°).
⚡ JEE Trick In any quadratic-in-a-trig-ratio, solve normally then discard roots outside [−1,1] for sin/cos (or any real value for tan). Trap: c=−2 looks like a valid algebraic root but is not a valid cosine — always range-check before quoting the answer.
Answer: cos θ = 1/2.

3Prove sin⁴θ+cos⁴θ=1−2sin²θcos²θ; 2(sin⁶θ+cos⁶θ)−3(sin⁴θ+cos⁴θ)=−1Identity proofwatch?v=NaT8174VjPQ🟡 Similar—
Concept Both identities are built on one master fact: sin²θ+cos²θ=1. By treating sin²θ and cos²θ as two numbers whose sum is 1, the algebraic identities for a²+b² (from (a+b)²) and a³+b³ (from (a+b)³) do all the work. Let p = sin²θ·cos²θ to keep the bookkeeping tidy.
Formula (a+b)² = a²+b²+2ab, (a+b)³ = a³+b³+3ab(a+b), with a=sin²θ, b=cos²θ, a+b=1.
Solution
1. Part (i): from (sin²θ+cos²θ)² = sin⁴θ + cos⁴θ + 2sin²θcos²θ, and the left side is 1² = 1.
2. Rearrange: sin⁴θ + cos⁴θ = 1 − 2sin²θcos²θ. ✓ (first identity proved).
3. Part (ii): from (sin²θ+cos²θ)³ = sin⁶θ + cos⁶θ + 3sin²θcos²θ(sin²θ+cos²θ), left side = 1³ = 1.
4. Since sin²θ+cos²θ=1, this gives 1 = sin⁶θ + cos⁶θ + 3sin²θcos²θ ⇒ sin⁶θ + cos⁶θ = 1 − 3sin²θcos²θ.
5. Substitute both results into the target. Let p = sin²θcos²θ:
2(sin⁶θ+cos⁶θ) = 2(1 − 3p) = 2 − 6p;   3(sin⁴θ+cos⁴θ) = 3(1 − 2p) = 3 − 6p.
6. Subtract: (2 − 6p) − (3 − 6p) = 2 − 3 = −1. ✓ The −6p terms cancel exactly.
⚡ JEE Trick Memorise sin⁴+cos⁴ = 1−2s²c² and sin⁶+cos⁶ = 1−3s²c² (s²c²=sin²θcos²θ); most power-identity problems fall out in one line. Trap: the second is 1−3s²c², not 1−3s⁴c⁴ — the coefficient comes from the (a+b)³ expansion, not a higher power.
Answer: both identities proved; the combination equals −1.
