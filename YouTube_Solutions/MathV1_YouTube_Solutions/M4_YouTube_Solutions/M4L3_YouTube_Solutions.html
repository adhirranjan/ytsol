1Range of `f(x)=√x`Root rangeA-SQRT🟡 SimilarbRange = [0, ∞)
Concept The range is the set of every output the function can actually produce as x runs over the whole domain. For the principal square root, two facts fix it: the input is restricted (you cannot take a real root of a negative number) and the output is restricted (the √ symbol denotes the non-negative root only). So the range is decided entirely by those two sign restrictions, not by any algebra.
Formula f(x) = √x, real only when x ≥ 0; by convention √x ≥ 0. "√" always means the principal (non-negative) root, so outputs never go below 0.
Solution
1. Domain: √x is real only for x ≥ 0, so the domain is [0, ∞).Negative inputs give non-real values and are excluded.
2. Smallest output: at x = 0, √0 = 0 — attained.0 is included because x = 0 is allowed.
3. Largest output: as x → ∞, √x → ∞ with no upper bound, and √x is continuous and increasing, so it hits every value in between.Continuity means no output between 0 and ∞ is skipped.
4. Therefore the outputs sweep [0, ∞).
 x        0     1     4     9    →∞
 √x       0     1     2     3    →∞     (never negative)
⚡ JEE Trick For any principal even root, domain and range are both [0, ∞) — memorise the "√ can't be negative on either side" rule. Trap: don't write range = R; √x is a single-valued non-negative function, not the two-branch ±√x.
Answer: Range = [0, ∞).
2Value of {3.75}+{2} (fractional part)FPFA-FPF🟡 Similarb0.75
Concept The fractional-part function {x} strips off the integer part of a number and keeps only the "leftover" after the largest integer that does not exceed it. It always returns a value in [0, 1). Recognising that an integer has zero fractional part is the whole trick here.
Formula {x} = x − ⌊x⌋, where ⌊x⌋ is the greatest integer ≤ x. Subtracting the floor removes the whole-number part, leaving only the decimal remainder, which lies in [0, 1). For any integer n, {n} = 0.
Solution
1. Compute {3.75}: ⌊3.75⌋ = 3, so {3.75} = 3.75 − 3 = 0.75.The floor of 3.75 is 3; the decimal tail is 0.75.
2. Compute {2}: 2 is an integer, ⌊2⌋ = 2, so {2} = 2 − 2 = 0.Integers have no fractional part.
3. Add: {3.75} + {2} = 0.75 + 0 = 0.75.
 x       ⌊x⌋    {x}=x−⌊x⌋
 3.75     3      0.75
 2        2      0
 sum             0.75
⚡ JEE Trick {integer} = 0 always — spot integers instantly and drop them. And {x} for a positive decimal is just "the digits after the point." Trap: for negative non-integers {x} ≠ the visible decimal, e.g. {−0.3} = 0.7, because the floor drops down to −1.
Answer: 0.75.
3Range of f(x)=x²+4x+5Quadratic rangeA-QUAD🟡 SimilaraRange = [1, ∞)
Concept A quadratic with a positive leading coefficient graphs as an upward parabola, so it has a single lowest point (the vertex) and rises to +∞ on both sides. The range is therefore "[vertex y-value, ∞)". The cleanest way to expose that minimum without calculus is completing the square, which rewrites the quadratic as a perfect square (always ≥ 0) plus a constant.
Formula ax²+bx+c = a(x + b/2a)² + (c − b²/4a); for a > 0 the minimum value is the constant term c − b²/4a. A squared bracket is never negative, so the smallest it can be is 0, leaving just the constant.
Solution
1. Group the x-terms: x² + 4x + 5 = (x² + 4x) + 5.
2. Complete the square: half of 4 is 2, so x² + 4x = (x + 2)² − 4.(x+2)² expands to x²+4x+4, which is 4 too big, so subtract 4.
3. Substitute back: (x + 2)² − 4 + 5 = (x + 2)² + 1.
4. Since (x + 2)² ≥ 0, the smallest value of f is 0 + 1 = 1, reached at x = −2.The square is zero exactly when x = −2, giving the vertex.
5. As x → ±∞, f → ∞, so outputs fill [1, ∞).
 f(x) = (x+2)² + 1
 x      −2    −1/−3    0/−4    →±∞
 f       1      2        5      →∞     (min = 1 at x = −2)
⚡ JEE Trick For a > 0 the minimum is c − b²/4a — here 5 − 16/4 = 5 − 4 = 1 — read the range straight off as [1, ∞) without graphing. Trap: this shortcut gives a maximum (range (−∞, max]) when a < 0; always check the sign of the leading coefficient first.
Answer: Range = [1, ∞).
4Which statement about the cubic f(x)=x³ is correct?Cubic functionA-CUBIC🟡 Similarbx³ is an odd, strictly increasing bijection of R
Concept The basic cubic f(x)=x³ is the model of a function that is defined for every real number, strictly increasing everywhere, and symmetric through the origin. Because it never levels off or turns back, each output is produced by exactly one input — it is a bijection (one-one and onto) from R to R. These four properties are what MCQ options test.
Formula Odd-function test: f(−x) = (−x)³ = −x³ = −f(x). Monotonicity: f′(x) = 3x² ≥ 0, zero only at x = 0. A derivative that is ≥ 0 and vanishes only at an isolated point still means strictly increasing, so no output repeats.
Solution
1. Domain: x³ is a polynomial, defined for all x, so domain = R.
2. Odd symmetry: f(−x) = −f(x), so the graph has half-turn symmetry about the origin.Replacing x by −x flips the sign of the output.
3. Strictly increasing: f′(x) = 3x² ≥ 0 and is 0 only at the single point x = 0, so f keeps rising — it never repeats a value.A momentary flat tangent at one point does not stop the overall increase.
4. One-one + onto: distinct inputs give distinct outputs, and x³ reaches every real as x → ±∞, so range = R and f is a bijection.
 x      −2    −1     0     1     2
 x³     −8    −1     0     1     8      (increasing, odd, range = R)
⚡ JEE Trick Odd-power monomials (x, x³, x⁵…) are all odd, strictly increasing bijections of R; even-power ones (x², x⁴…) are even and many-one. Trap: f′(0)=0 tempts you to call x=0 a max/min — it is only a point of inflection; x³ has no turning point.
Answer: f(x)=x³ is an odd, strictly increasing bijection of R (one-one, onto, range = R).
5Range of f(x)=x(x−1)(x−2)/((x−1)(x−2))Rational (holes)A-RRAT🟡 SimilarR − {1, 2}
Concept When a rational function has factors that cancel top and bottom, the simplified rule is a much simpler function — but only on the restricted domain. Every x that made the original denominator zero must stay excluded, creating "holes" in the graph. The cancelled expression tells you the shape; the excluded x-values tell you which outputs are missing from the range.
Formula f(x) = x(x−1)(x−2) / [(x−1)(x−2)] = x, valid only for x ≠ 1, x ≠ 2. You may cancel (x−1)(x−2) because it appears in both, but the cancellation is illegal at x = 1 and x = 2 where the original is 0/0 (undefined).
Solution
1. Note the denominator is zero at x = 1 and x = 2, so those points are excluded from the domain.Division by zero is undefined, so 1 and 2 can never be inputs.
2. Cancel the common factor: for all other x, f(x) = x.The identical factors divide out, leaving the identity function.
3. So f behaves as the line y = x but with two points punched out — at x = 1 the output 1 is missing, at x = 2 the output 2 is missing.Since y = x, the missing inputs 1 and 2 remove exactly the outputs 1 and 2.
4. Every other real value is still produced, so range = R \ {1, 2}.
 f(x) = x   except x = 1, 2 are holes
 output 1 (needs x=1) → missing
 output 2 (needs x=2) → missing
 range = all reals except 1 and 2
⚡ JEE Trick Cancel first to get the shape, then plug each excluded x back into the simplified rule to find the missing output — that is the hole in the range. Trap: never forget the removed points; the range is R minus {f(1), f(2)} = R \ {1, 2}, not all of R.
Answer: Range = R \ {1, 2} (all reals except 1 and 2).
6Range of y=x²+x+1 by perfect squareQuadratic rangeA-QUAD🟡 Similar[3/4, ∞)
Concept The problem itself names the method: rewrite the quadratic as a perfect square plus a constant. Because the leading coefficient is positive, the parabola opens upward, so the constant left over after the square is the minimum output. Fractions in the vertex are normal — here the vertex sits at a half-integer x.
Formula x² + x + 1 = (x + ½)² + ¾. Half of the x-coefficient 1 is ½; (x+½)² = x²+x+¼, which overshoots the constant by ¼, so add the remaining ¾ to keep the value 1. Minimum = the constant ¾, since (x+½)² ≥ 0.
Solution
1. Take half of the coefficient of x: ½ of 1 = ½; the square term is (x + ½)².This is the standard complete-the-square step.
2. Expand to check the leftover: (x + ½)² = x² + x + ¼.
3. Match to the original: x² + x + 1 = (x² + x + ¼) + ¾ = (x + ½)² + ¾.1 − ¼ = ¾ is the constant that must be added back.
4. Since (x + ½)² ≥ 0, minimum y = 0 + ¾ = ¾, at x = −½.
5. y → ∞ as x → ±∞, so outputs fill [¾, ∞).
 y = (x + ½)² + ¾
 x     −½     0/−1      1/−2      →±∞
 y     0.75    1         3        →∞     (min = ¾ at x = −½)
⚡ JEE Trick Vertex y-value = c − b²/4a = 1 − 1/4 = ¾ — a one-line check that the completed square is right. Trap: the minimum is ¾ (at x = −½), not the constant 1 you read off the original; f(0) = 1 is just one ordinary point, not the vertex.
Answer: Range = [¾, ∞).
7Domain of f(x)=√(|x|−1)Root + modulusA-SQRT🟡 SimilaraDomain = (−∞, −1] ∪ [1, ∞)
Concept A square root is real only when what sits under it is non-negative, so finding a domain means solving an inequality on the radicand. Here the radicand contains a modulus, so the inequality |x| − 1 ≥ 0 becomes |x| ≥ 1 — and a "|x| ≥ constant" statement always splits into two outward rays.
Formula √u real ⟺ u ≥ 0; and |x| ≥ a (a > 0) ⟺ x ≤ −a or x ≥ a. |x| is the distance of x from 0, so |x| ≥ 1 means x is at least 1 unit away from the origin on either side.
Solution
1. Require the radicand ≥ 0: |x| − 1 ≥ 0.Negative inputs to √ give non-real outputs.
2. Rearrange: |x| ≥ 1.
3. Split the modulus inequality: x ≥ 1 or x ≤ −1.|x| ≥ 1 is satisfied by points 1 or more to the right, or 1 or more to the left.
4. Combine into the domain: (−∞, −1] ∪ [1, ∞).The band (−1, 1) is excluded because there |x| < 1 makes the radicand negative.
 |x| − 1 ≥ 0  ⇒  |x| ≥ 1
 ───●========|========●───   (● at −1 and 1 included)
   ≤ −1    (−1,1) out    ≥ 1
⚡ JEE Trick "|x| ≥ a" opens outward (two rays), while "|x| ≤ a" closes inward (one interval) — mixing these up is the classic error. Trap: the endpoints ±1 are included (≥, not >) because √0 = 0 is a valid real output.
Answer: Domain = (−∞, −1] ∪ [1, ∞).
8Range of (i) (x−1)/(x−2) (ii) (2x−1)/(5−3x)Rational rangeA-RRAT🟡 Similar(i) R − {1}  (ii) R − {−2/3}
Concept To find the range of a rational function, treat the output as a parameter y, solve the equation for x in terms of y, and ask which y-values give a valid real x. For a (linear)/(linear) fraction, solving for x always leaves one value of y that makes the x-formula blow up — that single missing y is the horizontal asymptote, and the range is "all reals except that value."
Formula Set y = f(x), cross-multiply, collect x: x = g(y). The excluded y is where the coefficient of x vanishes. If x's coefficient is 0 for some y, no finite x produces that y, so it is absent from the range.
Solution
1. (i) Put y = (x−1)/(x−2) and clear the fraction: y(x−2) = x−1.
2. Expand and collect x: yx − 2y = x − 1 ⇒ x(y − 1) = 2y − 1 ⇒ x = (2y − 1)/(y − 1).x is defined for every y except where y − 1 = 0.
3. So y = 1 is impossible ⇒ range (i) = R \ {1}.y = 1 is the horizontal asymptote of (x−1)/(x−2).
4. (ii) Put y = (2x−1)/(5−3x): y(5 − 3x) = 2x − 1 ⇒ 5y − 3xy = 2x − 1.
5. Collect x: 5y + 1 = 2x + 3xy = x(2 + 3y) ⇒ x = (5y + 1)/(2 + 3y).x fails only when 2 + 3y = 0, i.e. y = −⅔.
6. So range (ii) = R \ {−⅔}.
 (i)  x = (2y−1)/(y−1)   blows up at y = 1     → range R \ {1}
 (ii) x = (5y+1)/(3y+2)  blows up at y = −2/3  → range R \ {−2/3}
⚡ JEE Trick For (ax+b)/(cx+d) the excluded output is just the ratio of leading coefficients a/c — (i) 1/1 = 1, (ii) 2/(−3) = −⅔ — read the missing value off instantly. Trap: the excluded value belongs to the range (from y), not the domain; the domain exclusion comes from the denominator in x (x ≠ 2 and x ≠ 5/3).
Answer: (i) Range = R \ {1}; (ii) Range = R \ {−2/3}.
9Range of y=(x²+x+2)/(x²+x+1)Rational rangewatch?v=TTwl3kyVPMM🟢 Exact(1, 7/3]
Concept The numerator and denominator here contain the same quadratic x²+x+1, differing only by a constant. Whenever that happens, split off the whole part: the fraction collapses to 1 + (constant)/(quadratic), and the whole problem reduces to knowing the range of one quadratic. The quadratic x²+x+1 has negative discriminant, so it never vanishes — the function is defined for all real x.
Formula y = 1 + 1/(x²+x+1) with x²+x+1 = (x+½)² + ¾ ≥ ¾. Completing the square shows the denominator's minimum is ¾ at x = −½, and it grows without bound both ways.
Solution
1. Split the fraction: y = (x²+x+1+1)/(x²+x+1) = 1 + 1/(x²+x+1).Numerator = denominator + 1, so pull out 1 and keep the leftover.
2. Range of the denominator: t = x²+x+1 = (x+½)² + ¾, so t ∈ [¾, ∞); since t ≥ ¾ > 0 the domain is all of R.
3. Invert: as t runs over [¾, ∞), 1/t runs over (0, 4/3].1/t is decreasing: largest value 1/(¾) = 4/3 at t = ¾; as t → ∞, 1/t → 0⁺ but never reaches 0.
4. Shift by 1: y = 1 + 1/t ∈ (1 + 0, 1 + 4/3] = (1, 7/3].
5. Endpoints: y = 7/3 is attained at x = −½; y = 1 would need 1/t = 0, impossible — it is a horizontal asymptote, approached as x → ±∞.
6. Continuity of y on R sweeps out every value in between, so nothing inside (1, 7/3] is missed.
 x        t = x²+x+1    y = 1 + 1/t
 −1/2      3/4           7/3        <-- answer (max, attained)
 0         1             2
 1         3             4/3
 →±∞       →∞            →1⁺        (1 never attained)
 Range = (1, 7/3]
⚡ JEE Trick Same quadratic top and bottom ⇒ write y = 1 + k/Q(x) and just range the reciprocal — no cross-multiplication and discriminant grind needed. Trap: bracket direction — 7/3 is included (the quadratic's minimum is attained) but 1 is excluded (asymptote); writing [1, 7/3] or (1, 7/3) loses the mark.
Answer: Range = (1, 7/3].

1Draw y=2sin x on [0,2π], y=3cos x on [−π/2,π/2]Trig graphsA-GRAPH🟡 Similar—
Concept Multiplying a sine or cosine by a constant only stretches it vertically — it scales the amplitude but leaves the zeros, the period and the horizontal shape untouched. So to sketch y = A sin x or y = A cos x you take the standard wave and multiply every y-value by A; the x-positions of peaks, troughs and crossings stay exactly where they are for the basic wave.
Formula For y = A sin x (or A cos x): amplitude = |A|, so range = [−A, A]; period 2π; zeros unchanged. A is a vertical scale factor; it cannot move points left/right, only up/down.
Solution
1. y = 2 sin x on [0, 2π]: amplitude 2, so peaks at +2, troughs at −2.
2. Key points: (0,0), (π/2, 2), (π, 0), (3π/2, −2), (2π, 0) — one full wave.sin x hits 0, 1, 0, −1, 0 at these x; times 2 gives 0, 2, 0, −2, 0.
3. y = 3 cos x on [−π/2, π/2]: amplitude 3; cos is a hump centred on x = 0.
4. Key points: (−π/2, 0), (0, 3), (π/2, 0) — rises to a single peak of 3 at x = 0 then falls back.cos(±π/2)=0 and cos 0 = 1; times 3 gives the 0–3–0 arch.
 y = 2 sin x, x∈[0,2π]           y = 3 cos x, x∈[−π/2,π/2]
  2 |   *                         3 |      *
  0 |*-----*-----*  x            0 |*-----------*  x
 −2 |         *                    −π/2   0   π/2
    0  π/2  π  3π/2 2π            (arch, peak 3 at x=0)
⚡ JEE Trick A coefficient in front of sin/cos changes only the amplitude (range = [−A, A]); a coefficient inside (sin bx) would change the period. Trap: 2 sin x and 3 cos x still cross the x-axis at the same places as sin x and cos x — don't shift the zeros.
Answer: y = 2 sin x — one sine wave on [0, 2π], range [−2, 2]; y = 3 cos x — a single arch on [−π/2, π/2] peaking at (0, 3), range [0, 3].
2Draw f(x)=2[x] and f(x)={x}GIF & FPF graphsA-GIF🟡 Similar—
Concept Both graphs are built from the greatest-integer function [x]. y = 2[x] is a staircase: on each unit interval [x] is a constant integer, so 2[x] is a flat step, and the factor 2 doubles the step height. y = {x} = x − [x] is a sawtooth: on each unit interval it rises linearly from 0 up to (but not reaching) 1, then drops back. Knowing where the closed/open dots go is the key skill.
Formula [x] = n for x ∈ [n, n+1), so 2[x] = 2n on that interval; {x} = x − [x] ∈ [0, 1), period 1. On every unit block the floor is constant, making 2[x] flat and {x} a straight line of slope 1 restarting at each integer.
Solution
1. y = 2[x]: on [0,1) value 0; [1,2) value 2; [2,3) value 4; on [−1,0) value −2.[x] = 0,1,2,−1 on those blocks; doubled gives 0,2,4,−2.
2. Each step is closed (●) at its left integer end and open (○) at the right.[n, n+1) includes n but not n+1.
3. y = {x}: on each [n, n+1) draw the line segment from (n, 0) up to (n+1, 1), closed at the bottom-left, open at the top-right.
4. This repeats every 1 unit — a sawtooth of height just under 1; range [0, 1).
 y = 2[x] (steps of 2)          y = {x} (sawtooth)
  4        ●──○                 1 ○   ○   ○
  2    ●──○                       /   /   /
  0 ●──○                       0 ●───●───●─ x
 −2 ●──○                         0   1   2
    x=−1..3                     each ramp rises 0→1
⚡ JEE Trick Remember the pairing x = [x] + {x}: the staircase [x] plus the sawtooth {x} rebuilds the line y = x. Always mark closed dot on the left, open dot on the right of every step/ramp. Trap: {x} never actually reaches 1 (open top), and for the "2" coefficient it is the step height that doubles, not the step width.
Answer: y = 2[x] is a staircase with steps of height 2 (value 2n on [n, n+1)); y = {x} is a period-1 sawtooth rising 0→1 on each unit interval, range [0, 1).
3Draw |x|−1, |x|+1, |x+1|Modulus graphsA-MOD🟡 SimilarVertices (0, −1), (0, 1), (−1, 0)
Concept All three are rigid shifts of the basic V-shaped graph y = |x| (vertex at the origin, arms of slope ±1). A change outside the modulus moves the whole V up or down; a change inside the modulus moves it left or right. Keeping "outside = vertical, inside = horizontal (opposite sign)" straight is the entire task.
Formula y = |x| + c shifts up by c; y = |x + a| shifts left by a. Adding c to the output raises every point; replacing x by x+a makes the vertex occur where x + a = 0, i.e. x = −a.
Solution
1. y = |x| − 1: shift the V down 1 — vertex at (0, −1); crosses x-axis at x = ±1; range [−1, ∞)."−1" is outside the modulus, so it lowers the graph.
2. y = |x| + 1: shift the V up 1 — vertex at (0, 1); never touches the x-axis; range [1, ∞).
3. y = |x + 1|: shift the V left 1 — vertex at (−1, 0); range [0, ∞).Vertex where x + 1 = 0 ⇒ x = −1; the arms still have slope ±1.
 |x|−1        |x|+1         |x+1|
  \   /        \   /         \   /
   \ /          \ /           \ /
 ───V───     ────V────     ──V──────
  (0,−1)       (0,1)        (−1,0)
 down 1        up 1         left 1
⚡ JEE Trick Outside the bars ⇒ vertical shift; inside the bars ⇒ horizontal shift in the opposite direction. So |x+1| moves left (not right). Trap: |x| + 1 vs |x + 1| look alike but the first lifts the vertex to (0,1), the second slides it to (−1,0) — completely different graphs.
Answer: |x|−1 → V with vertex (0,−1); |x|+1 → V with vertex (0,1); |x+1| → V with vertex (−1,0); all arms of slope ±1.
4Draw f(x)=[x] (GIF)GIF graphA-GIF🟡 SimilarDomain = (−∞, ∞), Range = integers
Concept The greatest-integer (floor) function rounds every input down to the nearest integer, so its graph is a staircase of flat unit-length steps, each step being a whole integer high. The subtle part is the endpoints: each step includes its left integer (closed dot) but stops just before the next integer (open dot), because the floor jumps up exactly at each integer.
Formula [x] = n for all x ∈ [n, n+1), n ∈ Z. Every value from n up to just below n+1 floors down to n, giving a flat step; at x = n+1 the floor jumps to n+1. Domain R, range Z.
Solution
1. On [0, 1) the floor is 0 → flat step at height 0, closed at (0,0), open at (1,0).
2. On [1, 2) the floor is 1 → step at height 1; on [2, 3) height 2; and so on upward.
3. On [−1, 0) the floor is −1 → step at height −1; on [−2, −1) height −2 (steps continue downward).Negatives floor further down, e.g. −0.4 → −1.
4. Result: an infinite staircase, each tread 1 unit wide and 1 unit high, jumping up by 1 at every integer.
        ●──○
     ●──○
  ●──○            ● = included (left integer)
──○   x           ○ = excluded (right end)
 ●──○
   −1  0  1  2  3
⚡ JEE Trick Floor always rounds toward −∞, so [−2.3] = −3, not −2 — the left (closed) dot sits at the lower integer. Trap: the graph is not continuous; there is a unit jump at every integer, and each tread's right endpoint is open (○).
Answer: f(x)=[x] is a staircase — height n on [n, n+1), closed dot at the left integer, open at the right; domain R, range Z.
5Draw f(x)={x} (FPF)FPF graphA-FPF🟡 SimilarDomain = (−∞, ∞), Range = [0, 1)
Concept The fractional-part function keeps only the "decimal remainder" after removing the integer part, so its graph is a periodic sawtooth. First, harvest the constraints: every expression inside a log must be strictly positive, and those inequalities are part of the answer — they survive even after the logs disappear. Second, strip the logs using the laws to get a clean algebraic relation. Because it is easier to express x in terms of y than the reverse, we find the domain by computing the range of x(y) — a standard inversion of viewpoint.
Formula a log m = log mᵃ, log m − log n = log(m/n), and log A = log B ⟺ A = B (with A, B > 0). The log is one-one on (0,∞), so equal logs force equal arguments — but only where both arguments were legal to begin with.
Solution
1. Constraints first. log y needs y > 0; log x needs x > 0; log(y−1) needs y − 1 > 0 ⇒ y > 1.y > 1 already implies y > 0, so the binding conditions are x > 0 and y > 1.
2. Strip the logs. 2 log y − log x − log(y−1) = 0 ⇒ log y² = log x + log(y−1) = log[x(y−1)].
3. Since log is one-one: y² = x(y − 1).Both sides are positive under the constraints, so equating arguments is valid.
4. Solve for x (easy direction): x = y²/(y − 1), defined for y > 1.
5. Find which x occur — i.e. the range of h(y) = y²/(y−1) on (1, ∞), which will be the domain of the relation.
6. Differentiate: h′(y) = [2y(y−1) − y²]/(y−1)² = (y² − 2y)/(y−1)² = y(y−2)/(y−1)².Quotient rule; the denominator (y−1)² > 0, so only the numerator's sign matters.
7. Sign of h′ on (1,∞): y > 0 always there, so the sign follows (y − 2) — negative on (1,2), zero at y = 2, positive on (2,∞) ⇒ h decreases then increases, with a minimum at y = 2.
8. Minimum value: h(2) = 4/(2−1) = 4. Behaviour at the ends: as y → 1⁺, y²/(y−1) → +∞; as y → ∞, h(y) ≈ y → ∞.Near y = 1 the denominator → 0⁺ with numerator → 1, so x blows up; for large y it grows like y.
9. So h is continuous on (1,∞) and sweeps [4, ∞) — twice over: once decreasing on (1,2] and once increasing on [2,∞) ⇒ domain = [4, ∞).Every x ≥ 4 is achieved; no x < 4 is, since the minimum is 4.
10. Range. Every y > 1 is legal and produces its own x = y²/(y−1) ≥ 4, and y > 1 was the only restriction ⇒ range = (1, ∞).y = 1 is excluded by log(y−1); nothing else is.
11. Note the shape: at x = 4 there is exactly one y (namely 2); for each x > 4 the quadratic y² − xy + x = 0 gives two values y = [x ± √(x²−4x)]/2, both > 1.The discriminant x² − 4x = x(x−4) ≥ 0 exactly when x ≥ 4 — an independent confirmation of the domain.

10Range of tan⁻¹(√([x]+[−x]))+√(2−|x|)+1/x²GIF + composite rangeA-GIF🟡 SimilarcRange = {1/4, 2}
Concept This looks fearsome but it is a domain problem in disguise. The identity [x] + [−x] = 0 or −1 is the key: it is 0 only when x is an integer, and −1 otherwise. Since that quantity sits under a square root, non-integers are instantly illegal — the domain collapses to a handful of integers. Once the domain is a finite set, the "range" is found by simply evaluating at each surviving point, no analysis required.
Formula [x] + [−x] = 0 if x ∈ Z, and = −1 if x ∉ Z. For non-integer x, write x = n + f with 0 < f < 1; then [−x] = [−n−f] = −n−1, so the sum is n + (−n−1) = −1. For integer x, [−x] = −x = −[x] and the sum is 0. Also √u needs u ≥ 0, and 1/x² needs x ≠ 0.
Solution
1. Condition A (the first root). √([x]+[−x]) is real only if [x] + [−x] ≥ 0.
2. By the identity the bracket is 0 (x integer) or −1 (x not integer); −1 is not allowed ⇒ x must be an integer.A non-integer would put −1 under the root, giving a non-real value.
3. Consequence: for every legal x the bracket is 0, so the first term is tan⁻¹(√0) = tan⁻¹ 0 = 0 — it contributes nothing.
4. Condition B (the second root). √(2 − |x|) needs 2 − |x| ≥ 0 ⇒ |x| ≤ 2 ⇒ −2 ≤ x ≤ 2.
5. Condition C (the reciprocal). 1/x² needs x ≠ 0.Division by zero is undefined.
6. Intersect A, B, C: integers in [−2, 2] excluding 0 ⇒ domain = {−2, −1, 1, 2} — only four points.
7. Evaluate at x = ±1: first term 0; √(2 − 1) = √1 = 1; 1/(±1)² = 1 ⇒ total = 0 + 1 + 1 = 2.|±1| = 1 and (±1)² = 1, so both signs give the same value.
8. Evaluate at x = ±2: first term 0; √(2 − 2) = √0 = 0; 1/(±2)² = 1/4 ⇒ total = 0 + 0 + 0.25 = 1/4.
9. Those are all four points, so the range is the two-element set {1/4, 2}.The function is even, so ±1 duplicate each other and ±2 duplicate each other — only two distinct outputs.
