The whole chapter on one card

★ The one ideaA single homogeneous second-degree equation ax² + 2hxy + by² = 0 is really two straight lines through the origin multiplied together. Treat it as a quadratic in the slope m = y/x: that quadratic's two roots are the two slopes. Everything else — the angle between the lines, when they are perpendicular, their bisectors — is read straight off a, h, b. When linear terms (2gx + 2fy + c) are present the pair no longer passes through O, but the same a, h, b still fix the directions — only the meeting point moves.

sum & product of the two slopesm₁ + m₂ = −2h/b · m₁·m₂ = a/b

💡 Instant recognisersAngle came out 0 ⇒ the pair is a perfect square (coincident lines), e.g. x² + 4xy + 4y² = (x + 2y)². The angle of a general-equation pair equals the angle of its homogeneous part ax² + 2hxy + by² — the linear terms shift the pair but never tilt it. To test if an equation is a pair, compute Δ; if Δ = 0 you can then factorise it into two linears.
⚠ Three slips that cost marks(1) In ax² + 2hxy + 2gx + 2fy, the middle coefficients are 2h, 2g, 2f — so h = (1/2)(coeff of xy), g = (1/2)(coeff of x), f = (1/2)(coeff of y). Forgetting the (1/2) wrecks Δ. (2) Perpendicular needs a + b = 0, not h = 0. (3) For the parallel-pair distance the numerator uses g² − ac (or f² − bc) — this only applies when h² = ab (the lines are actually parallel).
L-1

Homogeneous Pair through the Origin — Slopes, Angle & Bisectors

What "pair of straight lines" means

  • Multiply two line equations a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 and set the product to zero: (a₁x + b₁y + c₁)(a₂x + b₂y + c₂) = 0 is the joint (combined) equation of the two lines. Conversely any such product can be split back into its two factors.
  • To build a joint equation, first make each line's RHS zero, then multiply. E.g. y = x and y = −x give (y − x)(y + x) = 0, i.e. x² − y² = 0; and (x + y − 1)(x − y + 2) = 0 gives x² − y² + x + 3y − 2 = 0.

Homogeneous second-degree equation = two lines through O

  • A homogeneous equation has the same total degree in every term. For degree 2, ax² + 2hxy + by² = 0. Dividing by x² turns it into bm² + 2hm + a = 0 with m = y/x — a quadratic whose two roots m₁, m₂ are the slopes, so the equation is y = m₁x and y = m₂x: two lines through the origin.
slope quadratic and its rootsbm² + 2hm + a = 0 → m₁ + m₂ = −2h/b , m₁·m₂ = a/b
nature of the linesreal & distinct: h² − ab > 0 · coincident: h² − ab = 0 · imaginary: h² − ab < 0

Separating the two lines from the joint equation

  • Make RHS = 0 and factorise the LHS into two linear factors (or treat it as a quadratic in x — the Shri Dharacharya / quadratic formula — and solve). Each factor set to zero is one line. Example: x² − 6xy + 8y² = (x − 4y)(x − 2y) = 0 ⇒ x − 4y = 0 and x − 2y = 0.

Angle between the pair

from tan θ = |(m₁ − m₂)/(1 + m₁m₂)| with the slope relationstan θ = |2√(h² − ab) / (a + b)| (equivalently θ = sin⁻¹{ 2√(h²−ab) / √((a−b)² + 4h²) })
💡 The two shortcut conditionsPerpendicular (θ = 90°): tan θ is undefined ⇒ denominator a + b = 0, i.e. coeff of x² + coeff of y² = 0. Parallel / coincident (θ = 0): the numerator vanishes ⇒ h² = ab.

Pair perpendicular to a given pair, through O

lines ⟂ to ax² + 2hxy + by² = 0 and through the originbx² − 2hxy + ay² = 0 · aid to memory: swap the x² and y² coefficients, change the sign of xy

Bisectors of the angle between the pair

  • The bisectors are the locus of points equidistant from the two lines. Carrying that condition through gives a single homogeneous second-degree equation — itself a pair, and the two bisectors are always mutually perpendicular.
joint equation of the two bisectors(x² − y²)/(a − b) = xy/h · i.e. h(x² − y²) = (a − b)xy

L-2

General Second-Degree Equation as a Pair of Lines

When does ax² + 2hxy + by² + 2gx + 2fy + c = 0 split into two lines?

  • This is the general equation of second degree. It represents a pair of straight lines precisely when its determinant vanishes.
necessary & sufficient condition (Δ = 0)abc + 2fgh − af² − bg² − ch² = 0 · det[[a,h,g],[h,b,f],[g,f,c]] = 0
💡 Reading the coefficientsWrite the equation as ax² + 2hxy + by² + 2gx + 2fy + c. Then a = coeff of x², b = coeff of y², c = constant, h = (1/2)(coeff of xy), g = (1/2)(coeff of x), f = (1/2)(coeff of y). Keep those halves — they are where sign/arithmetic errors creep in.

Angle between the lines

same as the homogeneous partθ = tan⁻¹{ 2√(h² − ab) / (a + b) } · ⟂ ⇔ a + b = 0, parallel ⇔ h² = ab
  • The angle depends only on the second-degree terms, so the general-equation pair makes the same angle as ax² + 2hxy + by² = 0.
  • Coincident lines need all three: h² − ab = 0, g² − ac = 0 and f² − bc = 0.

Factorising into the two linear equations

  • Factorise the second-degree part first, then add unknown constants: (second-degree factors with c₁, c₂). Compare coefficients of x and of y to solve for c₁, c₂; the two factors set to zero are the lines.

Point of intersection of the pair

closed form( (bg − hf)/(h² − ab) , (af − gh)/(h² − ab) ) = ( √[(f²−bc)/(h²−ab)] , √[(g²−ac)/(h²−ab)] )
  • Partial-differentiation route (fastest): with φ = ax² + 2hxy + by² + 2gx + 2fy + c, set ∂φ/∂x = 0 and ∂φ/∂y = 0. These give the two linear equations ax + hy + g = 0 and hx + by + f = 0; solve them for the meeting point.
💡 Two handy spin-offsOnce the pair meets at (α, β): the lines through O parallel to them are ax² + 2hxy + by² = 0, and the lines through (α, β) parallel to them are a(x − α)² + 2h(x − α)(y − β) + b(y − β)² = 0.
Worked examples from the module
Book Example-1 · L-2
For what value of λ does 12x² − 10xy + 2y² + 11x − 5y + λ = 0 represent a pair of straight lines? Find the angle between them.
a = 12, h = −5, b = 2, g = 11/2, f = −5/2, c = λ.
Δ = abc + 2fgh − af² − bg² − ch² = 24λ + 2(−5/2)(11/2)(−5) − 12(25/4) − 2(121/4) − 25λ.
= 24λ + 275/2 − 75 − 121/2 − 25λ = −λ + 2 = 0 ⇒ λ = 2. Also h² − ab = 25 − 24 = 1 > 0 (real, distinct).
tan θ = |2√(h² − ab)/(a + b)| = 2√1/|14| = 1/7.
λ = 2 ; θ = tan⁻¹(1/7)
Book Example-2 · L-2
Show that 2x² − xy − y² − x + 4y − 3 = 0 can be factorised into two linear factors; find them and the angle between the lines.
a = 2, h = −1/2, b = −1, g = −1/2, f = 2, c = −3. Δ = 2(−1)(−3) + 2(2)(−1/2)(−1/2) − 2(4) − (−1)(1/4) − (−3)(1/4) = 6 + 1 − 8 + 1/4 + 3/4 = 0 ⇒ it is a pair.
Factor the quadratic part (2x + y)(x − y), add constants: (2x + y + c₂)(x − y + c₁). Matching x: 2c₁ + c₂ = −1; matching y: c₁ − c₂ = 4 ⇒ c₂ = −3, c₁ = 1.
Lines: 2x + y − 3 = 0 and x − y + 1 = 0. Angle: tan θ = |2√(1/4 + 2)/(2 − 1)| = 2·(3/2) = 3.
(2x + y − 3)(x − y + 1) = 0 ; θ = tan⁻¹3
Book Example-3 · L-2
Factorise 12x² + 7xy − 10y² + 13x + 45y − 35 = 0 into two linear factors.
Split the second-degree part: 12x² + 7xy − 10y² = (3x − 2y)(4x + 5y). Write (3x − 2y + c₁)(4x + 5y + c₂).
Compare coeff of x: 4c₁ + 3c₂ = 13; coeff of y: 5c₁ − 2c₂ = 45. Solving: c₁ = 7, c₂ = −5.
Check constant: c₁c₂ = (7)(−5) = −35 ✓.
(3x − 2y + 7)(4x + 5y − 5) = 0
Book Example-4 · L-2
Find the point of intersection of the lines represented by 2x² − 7xy − 4y² − x + 22y − 10 = 0.
φ = 2x² − 7xy − 4y² − x + 22y − 10. ∂φ/∂x = 4x − 7y − 1 = 0; ∂φ/∂y = −7x − 8y + 22 = 0.
Solve: from 4x − 7y = 1 and 7x + 8y = 22 ⇒ 81x = 162 ⇒ x = 2, then 7y = 4(2) − 1 = 7 ⇒ y = 1.
Point of intersection = (2, 1)
L-3

Parallel-Pair Distance, Bisectors & Homogenisation

Distance between a parallel pair of lines

  • If ax² + 2hxy + by² + 2gx + 2fy + c = 0 is a pair of parallel lines then h² = ab, and it factorises as (√a·x + √b·y + c₁)(√a·x + √b·y + c₂) = 0 — two lines with the same direction but different intercepts.
perpendicular distance between the two parallel linesD = 2√[ (g² − ac)/(a² + ab) ] = 2√[ (f² − bc)/(b² + ab) ]

Bisectors when the pair does not pass through O

  • Let (α, β) be the point of intersection of the general-equation pair. Shift the origin there (x = X + α, y = Y + β); the pair becomes homogeneous, aX² + 2hXY + bY² = 0, whose bisectors are (X² − Y²)/(a − b) = XY/h. Undo the shift (X = x − α, Y = y − β):
bisectors of the angles of the general pair[(x − α)² − (y − β)²]/(a − b) = (x − α)(y − β)/h · (α, β) = point of intersection

Homogenisation — lines joining O to where a line cuts a curve

  • The combined equation of the lines joining the origin to the two points where the line ℓx + my + n = 0 meets the second-degree curve ax² + 2hxy + by² + 2gx + 2fy + c = 0 is obtained by making the curve's equation homogeneous of degree 2 using the line.
  • Method: from the line write 1 = (ℓx + my)/(−n), then substitute so every term becomes degree 2 — multiply the linear terms 2gx + 2fy by (ℓx + my)/(−n) and the constant c by [(ℓx + my)/(−n)]².
joint equation of the two lines through O (homogenised)ax² + 2hxy + by² + (2gx + 2fy)·(ℓx + my)/(−n) + c·[(ℓx + my)/(−n)]² = 0
💡 Why homogenisation is a JEE favouriteOnce you have this homogeneous pair through O, you can instantly read the angle the chord-ends subtend at the origin (tan θ formula), decide when OA ⟂ OB (coeff of x² + coeff of y² = 0), or find the locus condition on the line — all without ever solving for A and B.

Product of perpendiculars from a point onto the pair

from (x₁, y₁) onto ax² + 2hxy + by² = 0product of the two ⟂ distances = |a x₁² + 2h x₁y₁ + b y₁²| / √[ (a − b)² + 4h² ]
Worked examples from the module
Book Example-1 · L-3
Find the equation of the line pair joining the origin to the points of intersection of the line 2x − y = 3 and the curve x² − y² − xy + 3x − 6y + 18 = 0, and the angle between these two lines.
Make "1" from the line: 2x − y = 3 ⇒ 1 = (2x − y)/3. Homogenise the curve by replacing each 1 with (2x − y)/3 so every term reaches degree 2.
x² − y² − xy + 3x·(2x − y)/3 − 6y·(2x − y)/3 + 18·[(2x − y)/3]² = 0.
= x² − y² − xy + x(2x − y) − 2y(2x − y) + 2(2x − y)² = x² − y² − xy + 2x² − xy − 4xy + 2y² + 2(4x² − 4xy + y²) = 0.
Collect: (1 + 2 + 8)x² + (−1 + 2 + 2)y² + (−1 − 1 − 4 − 8)xy ⇒ 11x² + 3y² − 14xy = 0 — the required line pair through O.
Angle: a = 11, b = 3, 2h = −14 ⇒ h = −7. tan θ = |2√(h² − ab)/(a + b)| = |2√(49 − 33)/(11 + 3)| = 2·4/14 = 4/7.
Line pair 11x² + 3y² − 14xy = 0 ; θ = tan⁻¹(4/7)
Book Example-2 · L-3
Find the value of m for which the lines joining the origin to the common points of x² + y² + x − 2y − m = 0 and x + y = 1 are at right angles.
Homogenise using 1 = (x + y): x² + y² + x(x + y) − 2y(x + y) − m(x + y)² = 0.
= x² + y² + x² + xy − 2xy − 2y² − m(x² + 2xy + y²) = 0 ⇒ (2 − m)x² + (−1 − m)y² + (−1 − 2m)xy = 0.
OA ⟂ OB ⇒ coeff of x² + coeff of y² = 0: (2 − m) + (−1 − m) = 1 − 2m = 0.
m = (1/2)
Book Example-3 · L-3
The second-degree equation x² + 2√2 xy + 2y² + 4x + 4√2 y + 1 = 0 represents a pair of straight lines; find the distance between them.
Compare with ax² + 2hxy + by² + 2gx + 2fy + c = 0: a = 1, h = √2, b = 2, g = 2, f = 2√2, c = 1.
Check h² = ab: (√2)² = 2 = (1)(2) ✓, so the lines are parallel.
Distance D = 2√[(g² − ac)/(a² + ab)] = 2√[(4 − 1)/(1 + 2)] = 2√(3/3) = 2√1.
D = 2

Strong Box · Level-8
The greatest slope along the graph represented by 4x² − y² + 2y − 1 = 0 is: (a) −3 (b) −2 (c) 2 (d) 3.
Group the perfect squares: 4x² − (y² − 2y + 1) = 0 ⇒ 4x² − (y − 1)² = 0 ⇒ [2x − (y − 1)][2x + (y − 1)] = 0.
The two lines are 2x − y + 1 = 0 (y = 2x + 1, slope 2) and 2x + y − 1 = 0 (y = −2x + 1, slope −2).
Greatest of the slopes {2, −2} is 2.
(c) 2
Strong Box · Level-7
L₁: y = mx and L₂: y = nx. L₁ makes twice as large an angle with the horizontal as L₂ and has 4 times the slope of L₂. If L₁ is not horizontal, the product mn equals: (a) √2/2 (b) −√2/2 (c) 2 (d) −2.
Let the angle of L₂ be θ, so n = tan θ and the angle of L₁ is 2θ, so m = tan 2θ. Also m = 4n.
tan 2θ = 4 tan θ ⇒ 2 tan θ/(1 − tan²θ) = 4 tan θ. Since L₁ is not horizontal, tan θ ≠ 0; divide: 2/(1 − tan²θ) = 4 ⇒ 1 − tan²θ = (1/2) ⇒ tan²θ = (1/2).
n² = tan²θ = (1/2), and mn = (4n)(n) = 4n² = 4·(1/2) = 2.
(c) 2
Strong Box · Level-10
If the pair of lines 6x² − αxy − 3y² − 24x + 3y + β = 0 intersect on the x-axis, find 20α − β.
Match ax² + 2hxy + by² + 2gx + 2fy + c = 0: a = 6, h = −α/2, b = −3, g = −12, f = 3/2, c = β.
The intersection point solves ∂φ/∂x = 0 ⇒ 6x − (α/2)y − 12 = 0 and ∂φ/∂y = 0 ⇒ −(α/2)x − 3y + 3/2 = 0. On the x-axis y = 0, so 6x = 12 ⇒ x = 2; then −(α/2)·2 + 3/2 = 0 ⇒ α = 3/2.
The point (2, 0) lies on the pair: 6·4 − 0 − 0 − 48 + 0 + β = 0 ⇒ β = 24.
20α − β = 20·(3/2) − 24 = 30 − 24 = 6.
20α − β = 6 (α = 3/2, β = 24)
Strong Box · Level-11
There are two ordered triplets (a, b, c) for which 4x² − 4xy + ay² + bx + cy + 1 = 0 represents a pair of identical straight lines. Find the sum of all six numbers a₁ + b₁ + c₁ + a₂ + b₂ + c₂.
Identical (coincident) lines ⇒ the LHS is a perfect square (2x + ky + m)² = 4x² + k²y² + m² + 4kxy + 4mx + 2kmy.
Match xy: 4k = −4 ⇒ k = −1, so a = k² = 1. Constant: m² = 1 ⇒ m = ±1. Then b = 4m and c = 2km = −2m.
m = 1 ⇒ (a, b, c) = (1, 4, −2); m = −1 ⇒ (a, b, c) = (1, −4, 2).
Sum = (1 + 4 − 2) + (1 − 4 + 2) = 3 + (−1) = 2.
a₁ + b₁ + c₁ + a₂ + b₂ + c₂ = 2
Strong Box · PYQ · JEE Advanced 2008
Let a, b be non-zero real numbers. Then (ax² + by² + c)(x² − 5xy + 6y²) = 0 represents: (a) two straight lines and a circle, when a = b and c is of sign opposite to that of a; (b) four straight lines, when c = 0 and a, b of the same sign; (c) a circle and an ellipse …; (d) two straight lines and a hyperbola, when a, b same sign and c opposite to a.
The second factor is always two lines: x² − 5xy + 6y² = (x − 2y)(x − 3y) = 0 ⇒ x − 2y = 0 and x − 3y = 0.
(a) a = b with c opposite sign ⇒ ax² + ay² + c = 0 ⇒ x² + y² = −c/a > 0, a circle. Two lines + a circle ✓.
(b) c = 0, a, b same sign ⇒ ax² + by² = 0 has only (0,0) — no new lines, so NOT four lines ✗.
(c) second factor is two lines, not a circle ✗. (d) a, b same sign, c opposite ⇒ ax² + by² = −c is an ellipse, not a hyperbola ✗.
(a) two straight lines and a circle
Strong Box · PYQ · JEE Advanced 2024
S = {(a, b, c) : ax² + 2bxy + cy² > 0 for all (x, y) ≠ (0, 0)}. Show that if (3, b, 1/12) ∈ S then |2b| < 1.
ax² + 2bxy + cy² is a positive-definite quadratic form (its pair ax² + 2bxy + cy² = 0 has no real lines) ⇔ a > 0 and the discriminant b² − ac < 0, i.e. b² < ac.
With a = 3, c = 1/12: b² < 3·(1/12) = (1/4) ⇒ |b| < (1/2).
Hence |2b| < 1.
|2b| < 1 (the imaginary-pair / positive-definite condition b² < ac)
