1In a conservative system, the work done around a closed path is: (a) Maximum (b) Minimum (c) Zero (d) Infinite — (Level-1)Closed-loop work, conservative forceConservative & Non-conservative Forces (Class 11, JEE/NEET)🟡 SimilarcZero
Concept This is the definition of a conservative force restated as a loop statement. "Conservative" means the work from A to B is the same along every path; the closed-loop statement is an immediate consequence, not a separate fact. Do not reach for any formula here — reach for the path-independence property and reverse one leg of the trip.
Formula Path independence: WA→B(path 1) = WA→B(path 2) — W in joules (J). Loop form: Wloop = ∮ F⃗ · dr⃗ = 0 — F in newtons (N), dr in metres (m), so the product is J. Energy form: W = −ΔU — U in J. Both sides are joules; and since U is a single-valued function of position, returning to the start gives ΔU = 0 J exactly, so W must be 0 J.
Solution
1. Take any closed path. Mark two points A and B on it, so the loop splits into an outward leg (path 1, A→B) and a return leg (path 2, B→A).Any closed curve can be cut this way; nothing is assumed about its shape.
2. The loop work is the sum of the two legs: Wloop = WA→B(1) + WB→A(2) (J).
3. Reversing the direction of travel reverses every dr⃗, so it flips the sign of the work: WB→A(2) = − WA→B(2).F⃗·dr⃗ changes sign when dr⃗ → −dr⃗; the force field itself is unchanged because it depends only on position.
4. Because the force is conservative, WA→B(2) = WA→B(1).
5. Substitute into step 2: Wloop = WA→B(1) − WA→B(1) = 0 J.
6. Cross-check by energy: for a round trip the start and end positions are identical, so Uf = Ui, giving ΔU = 0 J and W = −ΔU = 0 J ✓.

     ┌───────────▸ B
   A │             │
     └◂───────────┘
        path 2  (= path 1 reversed in sign)

   W_loop = W_A→B(1) + W_B→A(2)
          = W_A→B(1) − W_A→B(2)
   conservative ⇒ W_A→B(1) = W_A→B(2)
          ⇒  W_loop = 0  J
⚡ JEE Trick Use the loop test as a one-line detector: compute the work around any closed path — if it is non-zero the force is non-conservative, no partial derivatives needed. Friction is the standard counter-example: dragging a block out a distance ℓ and back gives W = −μmgℓ − μmgℓ = −2μmgℓ ≠ 0. Trap: options (a) "Maximum" and (b) "Minimum" tempt students who half-remember that potential energy is a maximum or a minimum at equilibrium — that is a statement about U at a point, not about work around a loop.
Answer: (c) Zero — the work done by a conservative force around any closed path is exactly 0 J.
2Are the following forces conservative? (i) F⃗ = (ax + bx³ + cx⁴) î  (ii) F⃗ = Ax² î + Bxy ĵ — (Level-2)Cross-derivative test for conservativenessPath integrals and non-conservative forces🟡 Similar(i) Yes  (ii) No
Concept Two different tests are needed here, and spotting which one applies is the whole exercise. Part (i) is a one-dimensional force that depends only on x — such a force is automatically conservative, because the antiderivative U(x) = −∫F dx always exists and the work between two x-values can only be U(x₁) − U(x₂). Part (ii) is genuinely two-dimensional, so you must run the cross-derivative (zero-curl) test taught in the lecture.
Formula Cross-derivative test in a plane: the force is conservative iff ∂Fx/∂y = ∂Fy/∂x — each side has units of N/m. Potential: F = −dU/dx ⇒ U(x) = −∫F dx — U in J, F in N, x in m. N × m = J ✓; and N/m = N/m on both sides of the test ✓.
Solution
1. Part (i). F⃗ = (ax + bx³ + cx⁴) î has Fy = 0 and Fz = 0, and Fx contains no y or z at all.
2. Apply the test: ∂Fx/∂y = 0 and ∂Fy/∂x = ∂(0)/∂x = 0 ⇒ equal ⇒ conservative.Equivalently, integrate directly: U(x) = −∫(ax + bx³ + cx⁴)dx = −(ax²/2 + bx⁴/4 + cx⁵/5) + C, a perfectly good single-valued potential — so the work can only depend on the endpoints.
3. Part (ii). Read off the components: Fx = Ax², Fy = Bxy.
4. Differentiate Fx with respect to y: ∂Fx/∂y = ∂(Ax²)/∂y = 0 (N/m), because Ax² contains no y.
5. Differentiate Fy with respect to x: ∂Fy/∂x = ∂(Bxy)/∂x = By (N/m).
6. Compare: 0 ≠ By for any y ≠ 0, so the test fails ⇒ the force is non-conservative.A force can be non-conservative on the whole plane while accidentally passing the test on the single line y = 0 — the definition requires it to hold everywhere.
  TEST:   ∂F_x/∂y  ?=  ∂F_y/∂x

  (i)  F = (ax + bx³ + cx⁴) î        [1-D, x only]
       ∂F_x/∂y = 0 ,  ∂F_y/∂x = 0   ⇒ EQUAL  ⇒ CONSERVATIVE
       U(x) = −(a x²/2 + b x⁴/4 + c x⁵/5)

  (ii) F = A x² î + B x y ĵ
       ∂F_x/∂y = ∂(Ax²)/∂y = 0
       ∂F_y/∂x = ∂(Bxy)/∂x = B y
       0 ≠ B y                      ⇒ NOT EQUAL ⇒ NON-CONSERVATIVE
⚡ JEE Trick Memorise the shortcut: any force of the form F(x) î is conservative — full stop. So in a mixed list, cross off every purely-1D entry instantly and spend your time only on the multi-variable ones. Trap: students see the higher powers x³, x⁴ in (i) and assume "complicated ⇒ non-conservative". Degree is irrelevant; only the variables matter. Second trap: in (ii) some differentiate Fx with respect to x (getting 2Ax) — the test pairs each component with the other variable.
Answer: (i) Yes — conservative.  (ii) No — non-conservative (∂Fx/∂y = 0 ≠ By = ∂Fy/∂x).
3Conservative force versus position graph (figure: F starts at a peak A, falls through zero at B, dips to a minimum C, rises through zero at D, peaks at E, then flattens onto the axis at F). Find points of equilibrium and specify the type of equilibrium. — (Level-3)F–r graph → equilibrium typeStable, Unstable & Neutral Equilibrium (Class 11 / JEE / NEET)🟡 SimilarStable → B; Unstable → D; Neutral → F
Concept The graph plotted is F versus r, not U versus r — so the usual "minimum of U ⇒ stable" rule must be translated. Equilibrium needs F = 0, i.e. the points where the curve crosses or touches the r-axis. The type is then decided by the slope of F there: a force that turns negative as you move right is restoring (stable); one that turns positive pushes you further away (unstable); one that stays identically zero is neutral.
Formula Equilibrium: F(r) = 0 (N). Stability from the F-graph: dF/dr < 0 ⇒ stable, dF/dr > 0 ⇒ unstable, dF/dr = 0 (F ≡ 0 over a stretch) ⇒ neutral — dF/dr in N/m. Because F = −dU/dr, we have dF/dr = −d²U/dr²; so dF/dr < 0 is exactly d²U/dr² > 0, the familiar "U is a minimum ⇒ stable" condition. The two languages agree with a sign flip.
Solution
1. Find every point where the curve meets F = 0. From the printed figure these are B, D and F. Points A, C and E are turning points of the force (peaks and a trough) where F ≠ 0, so they are not equilibria at all.A very common slip is to call A, C, E "equilibrium points" because they are extrema — but extrema of F mean dF/dr = 0, not F = 0.
2. Point B. Just left of B the curve is above the axis (F > 0, pushing towards larger r); just right of B it is below (F < 0, pushing back towards smaller r). So F is decreasing through B: dF/dr < 0.
3. A displacement +δ from B therefore produces a force pointing back to B (and −δ produces a force pointing forward to B). That is a restoring force ⇒ B is stable equilibrium (and U has a minimum there).
4. Point D. Just left of D the curve is below the axis (F < 0, pushing to smaller r); just right of D it is above (F > 0, pushing to larger r). So F is increasing through D: dF/dr > 0.
5. Any displacement from D is therefore amplified — the force drives the body further away ⇒ D is unstable equilibrium (U has a maximum there).
6. Point F. Beyond E the curve comes down and lies along the r-axis at F, so F = 0 over a stretch: dF/dr = 0. Displace the body a little and it still feels no force ⇒ F is neutral equilibrium (U is constant there).

   │      ╱‾╲                  E
   │    ╱     ╲              ╱‾╲
 ──┼──╱─────────╲──────────╱─────╲────────────▸ r
   │  |         B╲       ╱D       ╲___________  F  (F ≡ 0)
   │  |           ╲_____╱
   │  |              C

   F = 0 at :  B , D , F
   B :  dF/dr < 0  →  restoring   →  STABLE     (U minimum)
   D :  dF/dr > 0  →  repelling   →  UNSTABLE   (U maximum)
   F :  F ≡ 0      →  no force    →  NEUTRAL    (U constant)
   A, C, E : F ≠ 0  →  NOT equilibrium points
⚡ JEE Trick On an F–r graph read the sign of the crossing: a downward (positive-to-negative) zero crossing is stable; an upward (negative-to-positive) crossing is unstable; a flat run along the axis is neutral. On a U–r graph it is the opposite-looking rule (valley = stable, hill = unstable) — always check the axis label first, because examiners deliberately alternate between the two graph types. Trap: marking A, C, E as equilibria (they are force extrema, not zeros).
Answer: Equilibrium at B, D and F — B is stable, D is unstable, F is neutral.
4The potential energy of a particle moving along the x-axis is given by U = x³/3 − 6x² + 9x, where U is in joules and x in metres. Find the positions of stable and unstable equilibrium. — (Level-4)dU/dx = 0, second-derivative testPotential Energy vs Stability (IIT-JEE / NEET / Class 11)🟡 SimilarStable at x = 6 + 3√3 m; unstable at x = 6 − 3√3 m
Concept A completely standard two-step calculus question: first derivative zero locates the equilibria, second derivative sign classifies them. The only real difficulty is that the roots are irrational, so you must keep them in surd form rather than rounding. The cubic U gives a quadratic U′, so exactly two equilibrium points are expected — one hill and one valley.
Formula F = −dU/dx — F in N, U in J, x in m (J/m = N ✓). Equilibrium: dU/dx = 0. Classification: d²U/dx² > 0 ⇒ stable (U minimum), d²U/dx² < 0 ⇒ unstable (U maximum) — d²U/dx² in J/m² = N/m. d²U/dx² is literally the "spring constant" of the well: positive means a restoring force −kx acts on displacement, which is the definition of stability.
Solution
1. Differentiate: dU/dx = d/dx (x³/3 − 6x² + 9x) = x² − 12x + 9 (units J/m = N).
2. Set it to zero for equilibrium: x² − 12x + 9 = 0.
3. Quadratic formula: x = [12 ± √(144 − 36)]/2 = [12 ± √108]/2.Discriminant 144 − 36 = 108 > 0, so there really are two distinct equilibrium positions.
4. Simplify the surd: √108 = √(36 × 3) = 6√3, so x = (12 ± 6√3)/2 = 6 ± 3√3 m.
  Numerically 3√3 = 5.196, so x = 11.196 m and x = 0.804 m.
5. Second derivative: d²U/dx² = d/dx (x² − 12x + 9) = 2x − 12 (N/m).
6. At x = 6 + 3√3: d²U/dx² = 2(6 + 3√3) − 12 = 6√3 = +10.39 N/m > 0 ⇒ U is a minimum ⇒ stable equilibrium.
7. At x = 6 − 3√3: d²U/dx² = 2(6 − 3√3) − 12 = −6√3 = −10.39 N/m < 0 ⇒ U is a maximum ⇒ unstable equilibrium.Notice the two second derivatives are exact negatives of each other — a useful arithmetic check whenever U′ is a quadratic, because d²U/dx² = 2x − 12 is antisymmetric about the vertex x = 6.

        │    /     \                          /
        │   /       \                       /
     ───┼──/─────────\____________________/──────▸ x
        │ 0        \    \_____ ____/

             x = 6−3√3        x = 6+3√3

⚡ JEE Trick For a cubic U the two roots of U′ = 0 always pair as one maximum and one minimum, and the smaller root is the maximum whenever the x³ coefficient is positive. So once you have 6 ± 3√3 you can name them without computing U″ at all: smaller (6 − 3√3) = unstable, larger (6 + 3√3) = stable. Trap: writing √108 as 10.39 and then quoting x = 12 ± 10.39 — you must divide the whole numerator by 2.
Answer: Stable equilibrium at x = 6 + 3√3 m ≈ 11.20 m; unstable equilibrium at x = 6 − 3√3 m ≈ 0.80 m.
5The P.E. function for a diatomic molecule is U(x) = a/x¹² − b/x⁶. It is in stable equilibrium. Find the distance between the particles. — (Level-5)Lennard-Jones equilibrium separationThe potential energy function for a diatomic molecule is U(x) =(a)/(x^(12)) - (b)/(x^(6)). In st...🟢 Exactx = (2a/b)1/6
Concept This is the Lennard-Jones 12–6 potential, the single most-examined potential-energy function in JEE. The a/x¹² term is the short-range repulsion (electron-cloud overlap) and the −b/x⁶ term is the long-range van-der-Waals attraction; their competition produces one and only one minimum, which is the bond length. Do not try to sketch it — just set dU/dx = 0 and be careful with negative powers.
Formula U(x) = a x⁻¹² − b x⁻⁶ — U in J, x in m, so a is in J·m¹² and b in J·m⁶. Equilibrium: dU/dx = 0. Stability check: d²U/dx² > 0. Dimensional check on the answer: (a/b) has units J·m¹²/(J·m⁶) = m⁶, so (2a/b)1/6 comes out in metres ✓ — exactly what a "distance between the particles" must be.
Solution
1. Write U with negative exponents so differentiation is mechanical: U = a x⁻¹² − b x⁻⁶.
2. Differentiate: dU/dx = −12 a x⁻¹³ + 6 b x⁻⁷ = −12a/x¹³ + 6b/x⁷ (N).Bring the exponent down and reduce it by one: d(x⁻ⁿ)/dx = −n x⁻ⁿ⁻¹. The minus signs are where nearly all the marks are lost.
3. Set dU/dx = 0 for equilibrium: 12a/x¹³ = 6b/x⁷.
4. Cross-multiply and cancel: 12 a x⁷ = 6 b x¹³ ⇒ 12a = 6b x⁶ ⇒ x⁶ = 12a/6b = 2a/b.Dividing both sides by x⁷ is legal because a physical separation x is strictly positive — x = 0 is not an admissible root.
5. Take the sixth root: x = (2a/b)1/6 (m).
6. Confirm it is the stable one: d²U/dx² = 156a/x¹⁴ − 42b/x⁸. Substituting x⁶ = 2a/b gives d²U/dx² = (1/x⁸)(156a/x⁶ − 42b) = (1/x⁸)(156a·b/2a − 42b) = (1/x⁸)(78b − 42b) = 36b/x⁸ > 0 ⇒ minimum of U ⇒ stable ✓, as the question states.
7. Bonus (needed in Level-6 Q2): the depth of the well is Umin = a/x¹² − b/x⁶ = a(b/2a)² − b(b/2a) = b²/4a − b²/2a = −b²/4a J.
   U(x) = a/x¹² − b/x⁶     (Lennard-Jones 12–6)

   U │ \
     │  \   repulsion  a/x¹²  dominates (small x)
     │   \
   0 ─┼────\──────────────────────────────▸ x
     │      \        ______________
     │       \______/   attraction −b/x⁶ dominates
     │            ↑
     │        x₀=(2a/b)^(1/6)      U(x₀) = −b²/4a
     │        U′=0 , U″=36b/x₀⁸ > 0  → STABLE
⚡ JEE Trick For any potential of the form U = A/xᵐ − B/xⁿ (m > n) the equilibrium separation is x₀ = (mA / nB)1/(m−n) — one line, no differentiation. Here m = 12, n = 6: x₀ = (12a/6b)1/6 = (2a/b)1/6 ✓. Memorise the companion result Umin = −b²/4a; the pair covers almost every diatomic-molecule question ever set. Trap: quoting (a/b)1/6 or (2a/b)1/12 — the factor 2 comes from 12/6, and the root index is 12 − 6 = 6.
Answer: The separation at stable equilibrium is x = (2a/b)1/6 metres.

1Questions for short answers: (i) What are the differences between conservative and non-conservative forces? (ii) Potential is defined for conservative and not for non-conservative forces — why? (iii) In the given figure the work done by a force is the same along the three given paths (1), (2), (3) from A to B. Then is the force conservative or non-conservative and why? (iv) If work done by a force between two points for different paths is given, then how will you justify that the force is conservative or non-conservative? (v) If the function of force is given as F = f(x, y, z), then how will you find whether the given force is conservative or non-conservative? (vi) Is work done against a conservative force completely recoverable? (vii) Is work done against a non-conservative force completely recoverable? (viii) Show how work done in a closed loop for a conservative force is zero. (ix) State the condition for a particle to be in equilibrium; which type of equilibrium is this — translational or rotational or both, and why? (x) Define the different conditions of equilibrium with proper diagram; also state the physical resemblance of each mathematical expression. (xi) In a potential energy (U) vs position (x) curve, how will you find out in which region the force is attractive, repulsive or zero? — (Level : Board)Conservative-force theory, equilibriumConservative and Non-Conservative Forces — Khan Academy (Grade 11)🟡 Similarnot in key
Concept Eleven short board-style parts, all built on one idea: a conservative force does path-independent work, which is exactly what makes a single-valued potential energy function U(r⃗) exist. Everything else in the lecture — the closed-loop theorem, F = −dU/dx, the three equilibrium conditions, reading attraction/repulsion off a U–x curve — is a consequence of that one property. The ICAD answer key does not print an entry for this Board question; the answers below are worked from the lecture text on book pages 151–155.
Formula Path independence ⟺ ∮ F⃗·dr⃗ = 0 (J) ⟺ ∇⃗ × F⃗ = 0. Potential: ΔU = −∫ F⃗·dr⃗ (J), and componentwise Fx = −∂U/∂x, Fy = −∂U/∂y, Fz = −∂U/∂z — U in J, x/y/z in m, F in N (J/m = N ✓). Equilibrium: ΣF⃗ = 0 (N) for translational, Στ⃗ = 0 (N·m) for rotational.
Solution
1. (i) Differences. Conservative: work depends only on the initial and final positions, not on the path; work around any closed loop is zero; a potential energy function exists; mechanical energy (K + U) is conserved. Examples — gravity, elastic spring force, electrostatic force, buoyancy. Non-conservative (dissipative): work depends on the path actually followed; work around a closed loop is non-zero (and negative for friction); no potential energy can be defined; mechanical energy is converted into heat/sound. Examples — friction, air resistance, water drag, viscosity, electrical resistance.
2. (ii) Why potential exists only for conservative forces. U is meant to be a function of position alone: U(r⃗) with ΔU = −W. If the work W between two points depended on the route, then U at the second point would take different values depending on how the body got there — U would not be a function at all. Only path-independence makes U single-valued. Physically, the energy given to a non-conservative force is dissipated as heat and cannot be "stored at a position" for later recovery.
3. (iii) The figure. Paths (1), (2) and (3) all run from A to B and the work is the same along each. That is precisely the definition of path independence, so the force is conservative.
4. (iv) The justification rule. Compare the works along two (or more) different paths between the same pair of points: if they are equal for every choice of path, the force is conservative; if any two differ, it is non-conservative. Equivalent single test: take one path out and another back to form a closed loop — Wloop = 0 ⇒ conservative, Wloop ≠ 0 ⇒ non-conservative.
5. (v) Test for F = f(x, y, z). Check the three cross-derivative pairs: ∂Fx/∂y = ∂Fy/∂x, ∂Fy/∂z = ∂Fz/∂y, ∂Fz/∂x = ∂Fx/∂z. All three satisfied (i.e. curl F⃗ = 0) ⇒ conservative; any one violated ⇒ non-conservative. This is the test used in Example-1 of the lecture.
6. (vi) Recoverability, conservative. Yes. Work done against a conservative force is stored as potential energy, ΔU = +Wagainst, and is returned in full when the body goes back — e.g. lift a mass through h and it returns mgh on falling.
7. (vii) Recoverability, non-conservative. No. Work done against friction or drag becomes internal (thermal) energy and sound, which the system cannot spontaneously reconvert into ordered mechanical work. It is lost from the mechanical energy budget.
8. (viii) Closed-loop proof. Split the loop at two points A, B: Wloop = WA→B(path 1) + WB→A(path 2). Reversing a path reverses every dr⃗ and hence the sign of the work: WB→A(2) = −WA→B(2). Conservativeness gives WA→B(1) = WA→B(2). Therefore Wloop = WA→B(1) − WA→B(1) = 0.
9. (ix) Condition for equilibrium. Net force zero, ΣF⃗ = 0, gives translational equilibrium (the centre of mass has zero acceleration). Net torque zero about every axis, Στ⃗ = 0, gives rotational equilibrium (zero angular acceleration). A body is in complete (mechanical) equilibrium only when both hold — as with the balanced pencil in the lecture figure, where the weight and normal force cancel and their torques about the pivot cancel. One condition alone is not enough: a couple has zero net force but still spins the body.
10. (x) The three conditions, in U-language. All three require F = −dU/dr = 0, i.e. the U–r graph has zero slope. They differ in the curvature:
  • Stable: dU/dr = 0, d²U/dr² > 0 — U is a minimum. Displace the body and a restoring force pushes it back. Resemblance: a marble at the bottom of a bowl / the upright pencil resting on its flat end.
  • Unstable: dU/dr = 0, d²U/dr² < 0 — U is a maximum. Displace it and the force pushes it further away. Resemblance: a marble balanced on top of a dome / the pencil balanced on its sharpened tip.
  • Neutral: dU/dr = 0, d²U/dr² = 0 — U is constant. Displace it and it simply stays in the new position. Resemblance: a marble on a level table / the round pencil lying on its side and rolled.
11. (xi) Reading a U–x curve. The force is minus the slope, F = −dU/dx. Where U rises with x (positive slope) F is negative — it points back towards smaller x, i.e. the interaction is attractive. Where U falls with x (negative slope) F is positive — it pushes towards larger x, i.e. repulsive. Where the curve is flat (zero slope) the force is zero — an equilibrium region.

Concept "Translational" equilibrium is about the motion of the centre of mass only — it says nothing about spinning. Newton's second law makes the condition immediate: zero acceleration of the centre of mass requires zero net force. The distractors each describe a different kind of equilibrium or a consequence that is neither necessary nor sufficient.
Formula ΣF⃗ = M a⃗cm — F in N, M in kg, a in m/s². Translational equilibrium ⇔ a⃗cm = 0 ⇔ ΣF⃗ = 0 (N). Rotational equilibrium ⇔ Στ⃗ = 0 (N·m). N = kg·m/s² ✓; the torque condition has an extra factor of metres, which is the tell-tale that it is a separate, independent condition.
Solution
1. Equilibrium of translation means the body's centre of mass is not accelerating: a⃗cm = 0 m/s² (it may still move at constant velocity).Equilibrium does not mean "at rest" — uniform velocity is equally an equilibrium state.
2. Put that into Newton's second law: ΣF⃗ = M a⃗cm = M × 0 = 0 N.
3. So the necessary and sufficient condition is net force zero ⇒ option (c).
4. Reject (a): Στ⃗ = 0 is rotational equilibrium. A body acted on by a single force through its centre has zero torque about that centre yet accelerates linearly — so zero torque does not give translational equilibrium.
5. Reject (b): "acceleration is maximum" is the opposite of equilibrium; equilibrium needs a = 0.
6. Reject (d): constant kinetic energy only means the speed is constant. A body in uniform circular motion has constant K but a non-zero net (centripetal) force and is certainly not in translational equilibrium.This is the sharpest distractor — it is a genuine consequence of equilibrium but not equivalent to it.

2What is a key characteristic of non-conservative forces? (a) Path independence (b) No energy dissipation (c) Energy conservation (d) Path dependence — (Level-1)Defining property of non-conservative forceDifference between Conservative and Non-conservative Forces (JEE/NEET)🟡 SimilardPath dependence
Concept Straight recall of the lecture's own wording: "The work done by a non-conservative force depends on the path of the object." Every other listed property — no dissipation, energy conservation, path independence — is a property of conservative forces, so three of the four options describe the opposite family.
Formula Conservative: WA→B = UA − UB — independent of route; W and U in J. Non-conservative: WA→B = ∫path F⃗·dr⃗ — the integral genuinely depends on which curve you integrate along, and ∮F⃗·dr⃗ ≠ 0. Both expressions are in joules; only the first can be reduced to a difference of a position function, which is exactly what "conservative" buys you.
Solution
1. Recall the definitions. Conservative ⇒ work depends only on the endpoints. Non-conservative ⇒ work depends on the actual path travelled.
2. Test the claim with friction, the standard non-conservative force. Slide a block from A to B in a straight line of length d: Wfr = −μmg d (J).
3. Now go from A to B by a longer, curved route of path-length s > d: Wfr = −μmg s — a different number for the same endpoints.Friction always opposes the instantaneous motion, so its work accumulates with total distance travelled, never with displacement.
4. Therefore friction's work is path dependent ⇒ option (d).
5. Reject (a) Path independence — that is the defining feature of a conservative force.
6. Reject (b) and (c): non-conservative forces are exactly the dissipative ones; they convert mechanical energy into heat and sound, so mechanical energy is not conserved. (Total energy is still conserved, but that is a different statement from "mechanical energy conservation".)

     ╲                 ╱
      ╲___ s > d _____╱         W_friction = −μmg·s   (different!)

   same endpoints, different work  ⇒  PATH DEPENDENT

⚡ JEE Trick Learn the four-word contrast: conservative = path-independent, non-conservative = path-dependent. Everything else (loop work, existence of U, mechanical-energy conservation) follows from it, so in a "which is a characteristic of…" question always pick the path statement. Trap: (c) "Energy conservation" attracts students who reason "energy is always conserved" — true for total energy, but the option is about mechanical energy in the work-energy context, which non-conservative forces destroy.
Answer: (d) Path dependence.
3What happens to the kinetic energy of a block-spring system in frictional conditions over time? (a) Increases (b) Decreases (c) Remains constant (d) Becomes negative — (Level-1)Dissipation in a damped block-springMaximum Velocity of a Block Pushed by a Spring (with Friction)🟡 SimilarbDecreases
Concept This is Case-2 of the lecture, redrawn as an MCQ: a spring-block oscillator on a rough table. The spring force is conservative and returns all the energy it borrows, but friction takes a negative bite on every half-swing — outward and inward alike — so the mechanical energy strictly decreases. Comparing the speed each time the block crosses the same mean position A is the clean way to see it: v₀ > v₁ > v₂ … until the block stops.
Formula Work-energy theorem with dissipation: ΔK + ΔUspring = Wfriction — all terms in J. Spring energy U = ½kx² — k in N/m, x in m. Friction work over a path of length s: Wfr = −μmg s (J), always negative. N/m × m² = N·m = J ✓ for the spring term; μ is dimensionless so μmg·s is N·m = J ✓.
Solution
1. Pull the block aside to amplitude A₀ and release from rest. Initial mechanical energy: E₀ = ½kA₀² J, all of it spring potential energy, K = 0.
2. On the way in to the mean position (path length A₀), the spring returns ½kA₀² but friction removes μmg A₀, so the kinetic energy at the mean position is K₀ = ½kA₀² − μmg A₀ < ½kA₀².
3. The block overshoots to the other side, stopping at a smaller amplitude A₁ where ½kA₁² = K₀ − μmg A₁ < ½kA₀² ⇒ A₁ < A₀.Friction's work is negative on this leg too, because it reverses direction with the motion — it never gives energy back.
4. When the block returns and again passes the mean position, its speed v₁ satisfies ½mv₁² = ½kA₁² − μmg A₁ < ½mv₀², so v₁ < v₀ — exactly the lecture's Case-2 statement.
5. Repeating, the peak kinetic energy at each pass forms a strictly decreasing sequence, and the block finally comes to rest. Hence the kinetic energy decreases ⇒ option (b).
6. Reject (d): K = ½mv² with m > 0 and v² ≥ 0, so K can never be negative — it decreases to zero and stops there.A quantity that is a positive constant times a square is bounded below by zero; no amount of dissipation can push it past that floor.

Trap: option (c) "remains constant" is right only for the idealised frictionless spring — the question deliberately inserts "in frictional conditions".
Answer: (b) Decreases — friction dissipates mechanical energy every half-swing until the block stops (K → 0, never negative).

Concept Pure definition recall — but with a deliberately placed trap. The stem mentions "a gravitational field", tempting you to answer (a) gravitational. The question, however, asks what a force with the stated property is called, and the property described (work depends only on the endpoints) is the definition of the whole class of conservative forces. Gravity is just one member of that class.
Formula Conservative force: WA→C = U(A) − U(C) — W and U in J, and the right-hand side involves only the two positions. Equivalently ∮F⃗·dr⃗ = 0. Both sides are joules; the crucial point is that the right side contains no reference to the path, only to the endpoints A and C.
Solution
1. Extract the defining property from the stem: "work done depends only on the initial and final position."
2. Match it to the lecture's definition: "The work done by a conservative force depends only on the starting and ending positions of the object; it does not depend on the path the object takes." — an exact match ⇒ (c) conservative.
3. Reject (a) gravitational: gravity is a conservative force, but the question asks for the general name of any force with this property. Elastic spring force, electrostatic force and buoyancy share it too without being gravitational.Naming the category, not one example, is what "such a force is called" demands.
4. Reject (b) dissipative: that is the lecture's synonym for non-conservative — forces that convert mechanical energy into heat and whose work does depend on path.
5. Reject (d) retarding: a retarding force merely opposes motion (e.g. drag). Opposing motion is not the same as being path-independent — indeed drag is path-dependent.

5Given a potential energy function U(x), the corresponding force F⃗ is in the positive x direction if: (a) U is positive (b) U is negative (c) U is an increasing function of x (d) U is a decreasing function of x — (Level-1)Sign of F from slope of UFinding Force from Potential Energy Graphs🟡 SimilardU is a decreasing function of x
Concept The whole question turns on the minus sign in F = −dU/dx. The value of U is irrelevant — you can add any constant to U without changing a single force — so options (a) and (b) are ruled out on principle before any algebra. Only the slope matters, and the minus sign means F points "downhill" on the U curve.
Formula F = −dU/dx — F in N, U in J, x in m, and J/m = N ✓. Therefore F > 0 ⇔ dU/dx < 0. Only the derivative appears, never U itself — this is the mathematical statement of "the zero level of potential energy can be set wherever is convenient", quoted in the lecture.
Solution
1. Start from the definition of potential energy: dU = −F dx, i.e. F = −dU/dx (N).
2. Require the force to point along +x: F > 0.
3. Substitute: −dU/dx > 0 ⇒ dU/dx < 0.
4. A negative derivative means U decreases as x increases ⇒ option (d).
5. Eliminate (a) and (b) on principle: adding a constant U₀ to U changes its sign but leaves dU/dx — and hence every force — untouched. A physical force cannot depend on an arbitrary choice of zero level.This is a powerful general filter: any option that depends on the value of U rather than its change is automatically wrong.
6. Eliminate (c): if U increases with x then dU/dx > 0 and F = −dU/dx < 0, so the force points along −x — the exact opposite of what is asked.
7. Sanity check with gravity: take U = mgh with h measured upward. dU/dh = +mg > 0, so F = −mg, i.e. downward — the force points from high U to low U ✓, consistent with (d).

Concept This is Case-1 of the lecture, put into numbers. It is the standard demonstration that friction is non-conservative: the displacement over the round trip is zero, yet the work is not zero, because friction reverses with the motion and so does negative work on both legs. The key move is to use the path length (10 m) rather than the displacement (0 m).
Formula Normal force on a horizontal surface: N = mg — N in N, m in kg, g in m/s². Kinetic friction: f = μN = μmg (N), μ dimensionless. Work on a straight leg of length ℓ, friction opposing motion: W = −f ℓ = −μmg ℓ (J). Round trip: Wtotal = −2μmg ℓ. N × m = J ✓. Using g = 9.8 m/s², since the option −78.4 J is exactly 2(0.4)(2)(9.8)(5).
Solution
1. Normal reaction on the horizontal surface: N = mg = 2 kg × 9.8 m/s² = 19.6 N.There is no vertical acceleration and the pull is horizontal, so N simply balances the weight.
2. Kinetic friction force: f = μN = 0.4 × 19.6 N = 7.84 N, always opposite to the instantaneous velocity.
3. Outward leg (block moves right through ℓ = 5 m, friction acts left): W₁ = −f ℓ = −7.84 N × 5 m = −39.2 J.
4. 3If a particle is displaced from an equilibrium position, a restoring force acts on it to bring it back to the equilibrium position. Specify the type of equilibrium. If it is stable mark (1); if it is unstable mark (2); if it is neutral mark (3). — (Level-2)Identifying stable equilibriumWork, Energy and Power 05 — Equilibrium: Stable, Unstable, Neutral🟡 Similar1  (stable equilibrium)
Concept The word "restoring" is the entire question. A restoring force is by definition one directed opposite to the displacement — it undoes the disturbance. The lecture's own definition of stable equilibrium reads: "a system is in stable equilibrium if it experiences a net force or torque in a direction opposite to the direction of the displacement, when displaced from equilibrium." That is a verbatim match, so the answer is stable ⇒ mark 1.
Formula Stable: dU/dx = 0, d²U/dx² > 0 — U in J, x in m, d²U/dx² in N/m. For a small displacement δx the force is F ≈ −(d²U/dx²) δx (N), i.e. opposite in sign to δx. This is exactly Hooke's law F = −kδx with k = d²U/dx² > 0 — hence "restoring", and hence the units of d²U/dx² being N/m is no coincidence.
Solution
1. Let the particle sit at an equilibrium x₀ and be displaced by a small δx. Expand the force about x₀: F(x₀ + δx) = F(x₀) − (d²U/dx²)|x₀ δx. Since x₀ is an equilibrium, F(x₀) = 0.
2. So F ≈ −(d²U/dx²) δx (N).
3. "Restoring" means F must point back towards x₀, i.e. F and δx must have opposite signs.
4. That requires the coefficient (d²U/dx²) to be positive: d²U/dx² > 0.If it were negative, F would share the sign of δx and push the particle further out — that is the unstable case.
5. d²U/dx² > 0 at a stationary point means U is a minimum there — the textbook signature of stable equilibrium.
6. Contrast the other two so the choice is airtight: unstable — force is in the same direction as the displacement, U is a maximum, d²U/dx² < 0 (mark 2). Neutral — no force at all after displacement, U is constant, d²U/dx² = 0 (mark 3). Neither mentions a restoring force ⇒ the answer is mark 1.

Here 50 J is spent out of a 30 J account, so the final value must go negative, which is perfectly legal because only differences in U are physical.
Formula W = −ΔU = Ui − Uf — W, Ui, Uf all in joules. Rearranged: Uf = Ui − W. Every term is an energy in J, so the equation is trivially consistent; the content is entirely in the sign convention dU = −F⃗·dr⃗ = −dW from book page 152.
Solution
1. Write the defining relation for a conservative force: ΔU = −W, where W is the work done by the conservative force.
2. Expand ΔU: Uf − Ui = −W.
3. Solve for the unknown: Uf = Ui − W (J).
4. Substitute the given numbers, Ui = 30 J and W = +50 J: Uf = 30 J − 50 J = −20 J.
5. Sanity-check the sign: the force did positive work, so it drained 50 J from the store. Starting from 30 J the account goes 20 J into deficit ⇒ Uf = −20 J ✓.A negative U is not an error. The lecture notes that "the zero level can be set wherever is convenient" — a negative U simply means the system is 20 J below whatever reference was chosen.
6. Energy audit: ΔU = −20 − 30 = −50 J, and if this conservative force were the only one acting, the kinetic energy would have risen by exactly 50 J, keeping K + U constant ✓.

7Potential energy of a particle moving along the x-axis is given by U = (x³/3 − 4x + 6). Here U is in joule and x in metre. Concept This is Example-5 of the lecture reproduced verbatim as a Level-6 problem, so the numbers and the method are identical to the worked example on book page 157. A cubic U gives a quadratic U′ with two roots, which must be one hill and one valley; here they come out at the symmetric pair x = ±2 m, and the sign of U″ = 2x decides which is which purely by the sign of x.
Formula F = −dU/dx, equilibrium at dU/dx = 0 — U in J, x in m, F in N. Classification: d²U/dx² > 0 ⇒ stable (U minimum), d²U/dx² < 0 ⇒ unstable (U maximum) — units J/m² = N/m. Here d²U/dx² = 2x carries units N/m only if the coefficient of x³/3 is 1 J/m³, which it is; the numerical sign then follows the sign of x directly.
Solution
1. Differentiate: dU/dx = d(x³/3 − 4x + 6)/dx = x² − 4 (N).The constant +6 J differentiates away — it merely sets the zero level of U and cannot affect any force or equilibrium.
2. Force: F = −dU/dx = −(x² − 4) = 4 − x² (N).
3. Equilibrium requires F = 0, i.e. x² − 4 = 0 ⇒ x = ±2 m. So there are exactly two equilibrium positions, at x = +2 m and x = −2 m.
4. Second derivative: d²U/dx² = d(x² − 4)/dx = 2x (N/m).
5. At x = +2 m: d²U/dx² = 2(2) = +4 N/m > 0 ⇒ U is a minimum ⇒ stable equilibrium.Displace the particle to x = 2 + δ and F = 4 − (2 + δ)² ≈ −4δ < 0 pulls it back; displace to 2 − δ and F ≈ +4δ > 0 pushes it forward. Restoring both ways ✓.
6. At x = −2 m: d²U/dx² = 2(−2) = −4 N/m < 0 ⇒ U is a maximum ⇒ unstable equilibrium.At x = −2 + δ, F = 4 − (−2 + δ)² ≈ +4δ > 0 — the force points the same way as the displacement and drives the particle away.
7. Values for the sketch: U(2) = 8/3 − 8 + 6 = 0.67 J (the local minimum) and U(−2) = −8/3 + 8 + 6 = 11.33 J (the local maximum).
8. So the answer is: x = 2 m — stable; x = −2 m — unstable, matching the ICAD key exactly.

8A block A is placed over a block B having masses m and 2m respectively. Block B is resting on a frictionless surface and there is friction between blocks A and B. The system of blocks is pushed towards a spring with a velocity v₀ such that A doesn't slip on B by the time the system comes to momentary rest. The correct statement is: (a) work done by friction on A is zero (b) work done by friction on B is −½mv₀² (c) work done by spring on B is −(3/2)mv₀² (d) work done by friction on A & B is zero — (Level-6)Work-energy theorem on each blockBlock on Block Friction Problems — IIT JEE Mains and Advanced🟡 SimilarcWork done by spring on B is −(3/2)mv₀²
Concept The trick is to apply the work-energy theorem three times: once to A alone, once to B alone, and once to the system. Only B touches the spring, and only friction couples A to B. Because they move together (no slipping) they share one displacement, so friction's work on A and on B are equal and opposite — yet neither is zero, which is what kills options (a) and (d) while making (c) follow in one line.
Formula Work-energy theorem on a body: Won body = ΔK = Kf − Ki (J). Kinetic energies: K = ½Mv² — M in kg, v in m/s. Newton's third law across the A-B interface with a common displacement d: Wfr,A = −Wfr,B. Equal and opposite friction forces (f on A, −f on B) acting through the same displacement give works of equal magnitude and opposite sign — this is exactly why internal friction between bodies that do not slip dissipates nothing.
Solution
1. Set up. Total mass = m + 2m = 3m (kg). Both blocks start at v₀ and both end at rest (momentary rest at maximum spring compression). The ground under B is frictionless, so the only horizontal forces are the spring on B and friction at the A-B interface.
2. Block A alone. Its only horizontal force is friction from B. Work-energy theorem:
  Wfr,A = ΔKA = 0 − ½m v₀² = −½ m v₀².A is decelerated purely by friction — the spring never touches it — so friction must remove all of A's kinetic energy. This immediately makes option (a) false.
3. Statement (a) "work done by friction on A is zero" ⇒ FALSE (it is −½mv₀²).
4. Friction on B. By Newton's third law the friction on B from A is equal and opposite to that on A, and since A and B undergo the same displacement d (no slipping),
  Wfr,B = −Wfr,A = +½ m v₀² — positive.
5. Statement (b) claims Wfr,B = −½mv₀² ⇒ FALSE — right magnitude, wrong sign.
6. Block B alone. Two horizontal forces act: the spring and friction from A.
  Wspring + Wfr,B = ΔKB = 0 − ½(2m)v₀² = −m v₀²
7. Solve for the spring's work: Wspring = −m v₀² − Wfr,B = −m v₀² − ½ m v₀² = −(3/2) m v₀² ⇒ statement (c) is TRUE.
8. Cross-check on the whole system: the spring is the only external horizontal force, so Wspring = ΔKsystem = 0 − ½(3m)v₀² = −(3/2)m v₀² ✓ — the same result by a one-line route, confirming step 7.
9. Statement (d) "work done by friction on A & B is zero": the sum is indeed −½mv₀² + ½mv₀² = 0, but read as the intended claim that friction does zero work on A and on B individually, it is FALSE — each is ±½mv₀². Since the question asks for "the correct statement" (singular) and (c) is unambiguously true, the answer is (c).The physical content of the zero sum is that static friction between non-slipping surfaces dissipates no energy — it only transfers energy from B to A, here shuttling ½mv₀² across the interface.

⚡ JEE Trick In stacked-block problems, always write the work-energy theorem for the block that only friction touches — it hands you the friction work in one line (here Wfr,A = ΔKA), and everything else follows. Trap: option (a) — students reason "A doesn't slip, so friction is static, so it does no work". Static friction does no work only when the contact point is stationary; here the whole block A moves, and static friction is precisely what decelerates it.
Answer: (c) Work done by the spring on B is −(3/2)mv₀². (Friction does −½mv₀² on A and +½mv₀² on B — equal and opposite, so no energy is dissipated, but neither is zero.)

Concept The force is given as an explicit function of position, so its nature is completely determined — there is nothing probabilistic or unknowable about it, which disposes of options (a) and (b) before any calculation. 4. Compare: 2y ≠ 1 except on the single line y = 0.5 m; the equality must hold everywhere for the force to be conservative, so the test fails ⇒ the force is non-conservative ⇒ option (c).
