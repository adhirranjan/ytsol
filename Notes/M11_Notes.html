The whole chapter on one card

★ The one ideaEvery trig equation is reduced to one of three standard forms — sinθ=sinα, cosθ=cosα, or tanθ=tanα — and then you quote the matching general solution. All the "work" is the algebra (factor a quadratic, use a sum-to-product identity, or the a cos x + b sin x trick) that gets you to that standard form.

Principal solution — the numerically smallest angle

principal value lives in [0, 2π)Draw the unit circle, mark both candidate angles (one per relevant quadrant), pick the one numerically smallest. If a +ve and −ve angle tie, convention takes the positive one.

The a cos x + b sin x = c family

method — the "auxiliary angle"Put r = √(a²+b²). Divide through by r and read one term as cosα, the other as sinα, so the LHS becomes r cos(x − α) (or r sin(x + α)). Then solve cos(x − α) = c/r.
solvability testSolutions exist ⇔ |c| ≤ √(a²+b²). If |c| > √(a²+b²) there is no solution.
💡 Half-angle substitution (t = tan(x/2))sin x = 2t/(1+t²), cos x = (1−t²)/(1+t²), tan x = 2t/(1−t²). Turns a·cos x + b·sin x = c into a plain quadratic in t — but it silently drops x = (2n+1)π (where tan(x/2) is undefined), so check whether that angle is a root separately.
⚠ Three standing traps(1) After substituting sin²x = sin²α, the answer is x = nπ ± α, not "2x = …". (2) A candidate angle that makes any tan/sec/cosec/cot in the original equation undefined must be rejected (Ex. tan3x−tan2x = … loses x = nπ+π/4). (3) When you square an equation you may create extraneous roots — verify against the original.
L-1

Trigonometric Equations — Solutions & the General-Solution Formulas

  • A trigonometric equation involves trig ratios of an unknown angle, e.g. 2cosθ + 3cos2θ = 0. It differs from an identity (which holds for all θ, like cos²x = 1 − sin²x); an equation holds only for particular values.
  • A value of the unknown that satisfies the equation is a solution (or root). Because trig functions are periodic, if there is one solution there are infinitely many.
  • Particular solution: one specific satisfying value. Principal solution: the numerically smallest one, taken in [0, 2π). General solution: the complete family covering every particular and principal solution.

Finding the principal value

  • Draw the trigonometrical (unit) circle and mark the quadrant(s) where the angle can lie. Go anticlockwise for quadrants I & II, clockwise for III & IV.
  • Find the angle(s) in the first rotation and select the numerically least. If a positive and a negative angle are equally small, convention picks the positive one.
example — sinθ = −1/2candidates −π/6 and −5π/6 ; the numerically least is −π/6, so the principal value is −π/6 (equivalently 11π/6 or 7π/6 as particular values).

The five general-solution formulas

basic zerossinθ = 0 ⇒ θ = nπ · cosθ = 0 ⇒ θ = (2n+1)π/2 · tanθ = 0 ⇒ θ = nπ
standard formssinθ = sinα ⇒ θ = nπ + (−1)nα · cosθ = cosα ⇒ θ = 2nπ ± α · tanθ = tanα ⇒ θ = nπ + α
Where θ = nπ + (−1)ⁿα comes from (sketch)
For sinθ = sinα, sinθ − sinα = 0 ⇒ 2 cos((θ+α)/2) sin((θ−α)/2) = 0, giving the two interleaved families θ = 2nπ + α (from the second factor) and θ = (2n+1)π − α (from the first). The single compact way to write "both" is θ = nπ + (−1)ⁿα — even n gives 2kπ+α, odd n gives (2k+1)π−α. For cosθ = cosα the difference-to-product step gives −2 sin((θ+α)/2) sin((θ−α)/2) = 0, i.e. θ = 2nπ ± α; for tanθ = tanα it collapses to sin(θ−α) = 0, i.e. θ = nπ + α.
💡 Reciprocal pairs share a GScosec θ = cosec α behaves exactly like sinθ = sinα ; sec θ = sec α like cosθ = cosα ; cot θ = cot α like tanθ = tanα. So you never memorise separate formulas for the reciprocal ratios.

Equations reducible to a quadratic in one ratio

  • Use an identity (sin²+cos² = 1, or 1+tan² = sec², 1+cot² = cosec²) to make the equation contain a single ratio, then factor the quadratic and solve each factor with a standard form.
  • Always discard roots outside the range of the ratio: |sinθ| ≤ 1, |cosθ| ≤ 1, |cosec θ| ≥ 1, |sec θ| ≥ 1.

Book Example-3 · L-1
Solve (tan3x − tan2x)/(1 + tan3x·tan2x) = 1.

⚠ Domain check is the whole pointThis is the classic trap: the algebra hands you a clean family, but every member is barred because a ratio in the original expression blows up there. Always test candidate angles in the original equation, not the simplified one.
Book Example-4 · L-1
Solve (sin³(x/2) − cos³(x/2)) / (2 + sin x) = (cos x)/3.
Factor the numerator as (sin(x/2) − cos(x/2))(sin²(x/2) + cos²(x/2) + sin(x/2)cos(x/2)) and note 2 + sin x = 2(1 + sin(x/2)cos(x/2)). Cancelling reduces to sin(x/2) − cos(x/2) = (2/3)cos x.
Square both sides: (sin(x/2) − cos(x/2))² = 1 − sin x, so 1 − sin x = (4/9)cos²x = (4/9)(1 − sin²x).
9 − 9 sin x = 4 − 4 sin²x ⇒ 4 sin²x − 9 sin x + 5 = 0 ⇒ (sin x − 1)(4 sin x − 5) = 0.
sin x = 5/4 is rejected; sin x = 1.
x = (4n+1)π/2, n ∈ Z
Book Example-5 · L-1
Find the number of roots of tan(x + π/6) = 2 tan x for x ∈ (0, 3π).
Expand: (tan x + 1/√3)/(1 − tan x/√3) = 2 tan x ⇒ √3 tan x + 1 = 2 tan x(√3 − tan x).
Rearrange to 2 tan²x − √3 tan x + 1 = 0. With t = tan x, discriminant D = 3 − 8 = −5 < 0.
No real t, so no real x satisfies the equation.
0 roots
Book Example-6 · L-1
Solve cot²θ + 3/sinθ + 3 = 0.
cot²θ = cosec²θ − 1, so cosec²θ − 1 + 3 cosec θ + 3 = 0 ⇒ cosec²θ + 3 cosec θ + 2 = 0.
Factor: (cosec θ + 2)(cosec θ + 1) = 0 ⇒ cosec θ = −2 or cosec θ = −1.
cosec θ = −2 ⇒ sinθ = −1/2 ⇒ θ = nπ + (−1)n+1(π/6).
cosec θ = −1 ⇒ sinθ = −1 ⇒ θ = nπ + (−1)n+1(π/2) (i.e. (4n−1)π/2).
θ = nπ + (−1)n+1(π/6) or θ = (4n−1)π/2, n ∈ Z
Book Example-7 · L-1
Solve cosθ + cos7θ + cos3θ + cos5θ = 0.
Pair symmetrically: cosθ + cos7θ = 2 cos4θ cos3θ and cos3θ + cos5θ = 2 cos4θ cosθ.
Sum = 2 cos4θ (cos3θ + cosθ) = 2 cos4θ · 2 cos2θ cosθ = 4 cosθ cos2θ cos4θ = 0.
cosθ = 0 ⇒ θ = (2n+1)π/2 ; cos2θ = 0 ⇒ θ = (2n+1)π/4 ; cos4θ = 0 ⇒ θ = (2n+1)π/8.
θ = (2n+1)π/2 or (2n+1)π/4 or (2n+1)π/8, n ∈ Z

Squared Standard Forms & the a cos x + b sin x = c Family

The three squared forms all give θ = nπ ± α

unified resultsin²θ = sin²α  ·  cos²θ = cos²α  ·  tan²θ = tan²α   ⇒   θ = nπ ± α , n ∈ Z
Why all three land on the same answer
Each squared form is converted to a cos 2θ = cos 2α statement. sin²θ = sin²α ⇒ 1 − cos2θ = 1 − cos2α ⇒ cos2θ = cos2α. cos²θ = cos²α ⇒ 1 + cos2θ = 1 + cos2α ⇒ cos2θ = cos2α. tan²θ = tan²α ⇒ (1 − tan²θ)/(1 + tan²θ) = (1 − tan²α)/(1 + tan²α) ⇒ cos2θ = cos2α. In every case 2θ = 2nπ ± 2α, hence θ = nπ ± α.
⚠ Keep the factor straightThe answer to sin²θ = sin²α is θ = nπ ± α — not 2θ = nπ ± α. The doubling happens inside the derivation (cos2θ) and is cancelled when you divide the 2θ equation by 2.

Book Example · L-2 theory
Solve 2sin²x + sin²2x = 2.
sin2x = 2 sin x cos x, so sin²2x = 4 sin²x cos²x. Then 2sin²x + 4sin²x cos²x − 2 = 0.

cos²x = 0 ⇒ x = nπ ± π/2.   2sin²x − 1 = 0 ⇒ sin²x = 1/2 = sin²(π/4) ⇒ x = mπ ± π/4.
x = nπ ± π/2 or x = mπ ± π/4,   m, n ∈ Z

Equations of the form a cos x + b sin x = c

reductionDivide by r = √(a²+b²). Choosing cosα = a/r, sinα = b/r (so tanα = b/a) turns the LHS into r cos(x − α); the equation becomes cos(x − α) = c/r, giving x = 2nπ ± β + α with cosβ = c/r.
exists only when−1 ≤ c/√(a²+b²) ≤ 1 ⇔ |c| ≤ √(a²+b²).
Book Example · L-2 theory
Solve cosθ + sinθ = 1.
Here a = b = c = 1, r = √2. Divide by √2: (1/√2)cosθ + (1/√2)sinθ = 1/√2 ⇒ cos(θ − π/4) = 1/√2 = cos(π/4).
θ − π/4 = 2nπ ± π/4. Plus: θ = 2nπ + π/2. Minus: θ = 2nπ.
θ = 2nπ + π/2 or θ = 2nπ, n ∈ Z
Book Example · L-2 theory
Solve tanθ = cot5θ.
Write cot5θ = tan(π/2 − 5θ): tanθ = tan(π/2 − 5θ) ⇒ θ = nπ + π/2 − 5θ.
6θ = nπ + π/2.
θ = nπ/6 + π/12, n ∈ Z
Book Example-1 · L-2
Solve 4 sin x · sin2x · sin4x = sin3x.
Write sin2x = sin(3x − x), sin4x = sin(3x + x); their product = sin²3x − sin²x. So 4 sin x(sin²3x − sin²x) = sin3x.
4 sin x sin²3x − 4sin³x = sin3x, and sin3x = 3 sin x − 4sin³x, so 4 sin x sin²3x = 3 sin x ⇒ sin x(4sin²3x − 3) = 0.
sin x = 0 ⇒ x = nπ.   4sin²3x = 3 ⇒ sin²3x = 3/4 = sin²(π/3) ⇒ 3x = mπ ± π/3 ⇒ x = mπ/3 ± π/9.
x = nπ or x = mπ/3 ± π/9,   m, n ∈ Z
Book Example-2 · L-2
Solve 81sin²x + 81cos²x = 30.
cos²x = 1 − sin²x, so 81cos²x = 81/81sin²x. Let t = 81sin²x: t + 81/t = 30 ⇒ t² − 30t + 81 = 0 ⇒ (t − 27)(t − 3) = 0.
t = 27 ⇒ 34sin²x = 3³ ⇒ 4sin²x = 3 ⇒ sin²x = 3/4 = sin²(π/3) ⇒ x = nπ ± π/3.
t = 3 ⇒ 34sin²x = 3¹ ⇒ 4sin²x = 1 ⇒ sin²x = 1/4 = sin²(π/6) ⇒ x = nπ ± π/6.
x = nπ ± π/3 or x = nπ ± π/6, n ∈ Z
⚠ Book misprintThe module writes the answers here as "2x = nπ ± π/3" and "2x = nπ ± π/6". That extra factor of 2 is wrong: sin²x = sin²α gives x = nπ ± α directly, so the solutions are x = nπ ± π/3 and x = nπ ± π/6 (check: x = π/3 gives sin²x = 3/4 ✓).
Book Example-3 · L-2
Find the number of distinct solutions of sec x + tan x = √3 for 0 ≤ x ≤ 3π.
(1 + sin x)/cos x = √3 ⇒ 1 + sin x = √3 cos x ⇒ √3 cos x − sin x = 1.
Divide by 2: (√3/2)cos x − (1/2)sin x = 1/2 ⇒ cos(x + π/6) = 1/2 ⇒ x + π/6 = 2nπ ± π/3, so x = 2nπ ± π/3 − π/6.
"+" branch: x = 2nπ + π/6 ⇒ x = π/6 and 13π/6, both in [0, 3π]. "−" branch: x = 2nπ − π/2 ⇒ x = 3π/2, but there sec x and tan x are undefined — rejected.
2 solutions (x = π/6, 13π/6)
Book Example-4 · L-2
Prove that k cos x − 3 sin x = k + 1 has a solution iff k ∈ (−∞, 4].
This is a cos x + b sin x = c with a = k, b = −3, c = k+1, so it is solvable iff |c| ≤ √(a²+b²): |k+1| ≤ √(k²+9).
Square: (k+1)² ≤ k² + 9 ⇒ k² + 2k + 1 ≤ k² + 9 ⇒ 2k ≤ 8 ⇒ k ≤ 4.
Solvable ⇔ k ∈ (−∞, 4]
Book Example-5 · L-2
For what k does sin x + cos(k + x) + cos(k − x) = 2 have real solutions?
cos(k + x) + cos(k − x) = 2 cos k cos x. Equation: sin x + 2cos k · cos x = 2 — a cos x + b sin x = c with a = 2cos k, b = 1, c = 2.
Real solution needs c² ≤ a² + b²: 4 ≤ 4cos²k + 1 ⇒ 4cos²k ≥ 3 ⇒ 1 − sin²k ≥ 3/4 ⇒ sin²k ≤ 1/4 ⇒ |sin k| ≤ 1/2.
|sin k| ≤ 1/2 ⇒ k ∈ [nπ − π/6, nπ + π/6].
nπ − π/6 ≤ k ≤ nπ + π/6, n ∈ Z
⚠ Boundary is includedThe module writes the interval with strict inequalities (nπ − π/6 < k < nπ + π/6). At |sin k| = 1/2 we have c² = a² + b² exactly, which still yields a (single) real x, so the endpoints are genuine solutions — the interval should be closed.
Book Example-6 · L-2
If cos px + cos qx = 0, the values of x are in A.P. with common difference kπ/(p+q). Find k.
cos px = −cos qx = cos(π − qx) ⇒ px = 2nπ ± (π − qx).
Take "+": px + qx = 2nπ + π ⇒ x = (2n+1)π/(p+q). Successive values (n and n+1) differ by 2π/(p+q).
So the common difference is 2π/(p+q) = kπ/(p+q), giving k = 2.
k = 2

Simultaneous Equations, f(sin x, cos x, tan x) = 0 & the Half-Angle Substitution

Solving two equations at once (common general value)

  • Given two conditions on θ, solve each separately, list their particular values in [0, 2π), and take the value(s) satisfying both.
  • Because the shared value α is unique in one revolution, the common general solution repeats every 2π: θ = 2nπ + α.
shortcutcosθ = cosα and sinθ = sinα together ⇒ θ = 2nπ + α ; likewise sinθ = sinα and tanθ = tanα ⇒ θ = 2nπ + α.

The half-angle substitution t = tan(x/2)

identitiessin x = 2t/(1+t²) , cos x = (1−t²)/(1+t²) , tan x = 2t/(1−t²) , where t = tan(x/2).
Book Example · L-3 theory
Solve 3 sin x + 4 cos x = 5.
Substitute: 3·2t/(1+t²) + 4(1−t²)/(1+t²) = 5 ⇒ 6t + 4 − 4t² = 5 + 5t² ⇒ 9t² − 6t + 1 = 0.
(3t − 1)² = 0 ⇒ t = 1/3 ⇒ tan(x/2) = 1/3 ⇒ x/2 = nπ + tan−1(1/3).
x = 2nπ + 2 tan−1(1/3), n ∈ Z
⚠ Book misprintThe module boxes the answer as x = nπ + 2 tan−1(1/3). Since tan(x/2) = 1/3 gives x/2 = nπ + tan−1(1/3), we get x = 2nπ + 2 tan−1(1/3) (the maximum of 3 sin x + 4 cos x is 5, attained once per 2π, so the period must be 2π — check x = π + 2tan−1(1/3) fails).
Book Example · L-3 theory
Solve 4 cot2θ = 4cot²θ − tan²θ.
Use cot2θ = (1 − tan²θ)/(2tanθ) and cot²θ = 1/tan²θ. Clearing denominators leads to (1 − tan²θ)(tanθ − 1)²/tan²θ = 0.
With tanθ ≠ 0: 1 − tan²θ = 0 or tanθ = 1 ⇒ tanθ = ±1.
θ = nπ ± π/4, n ∈ Z

All have |t| < 1, but |sec θ| ≥ 1 always — so none is attainable.
No real roots
💡 Note on the printed statementThe module prints the equation's leading term as "6 sec³θ" in the question but works with "16 sec³θ" in the solution (which is what factorises cleanly as above). The intended coefficient is 16; either way the conclusion — no real roots — stands, because every candidate value of sec θ has modulus below 1.
Book Example-5 · L-3
Solve sin10x + cos10x = (29/16) cos42x.
Put sin²x = (1 − cos2x)/2, cos²x = (1 + cos2x)/2 and t = cos2x: ((1−t)/2)5 + ((1+t)/2)5 = (29/16)t⁴.
Multiply by 32: (1−t)5 + (1+t)5 = 58t⁴. The odd powers cancel: 2(1 + 10t² + 5t⁴) = 58t⁴ ⇒ 24t⁴ − 10t² − 1 = 0.
(2t² − 1)(12t² + 1) = 0 ⇒ t² = 1/2 (12t²+1 = 0 impossible) ⇒ cos²2x = 1/2 = cos²(π/4) ⇒ 2x = nπ ± π/4.
x = nπ/2 ± π/8, n ∈ Z
Book Example-6 · L-3
Solve 3 tan(θ − 15°) = tan(θ + 15°).
Expand both sides as products: 3 sin(θ−15°)cos(θ+15°) = sin(θ+15°)cos(θ−15°). Using product-to-sum, sin(θ−15°)cos(θ+15°) = ½(sin2θ − sin30°) and sin(θ+15°)cos(θ−15°) = ½(sin2θ + sin30°).
3·½(sin2θ − ½) = ½(sin2θ + ½) ⇒ 3sin2θ − 3/2 = sin2θ + ½ ⇒ 2 sin2θ = 2 ⇒ sin2θ = 1.
2θ = 2nπ + π/2 ⇒ θ = nπ + π/4 (check θ = 45°: 3 tan30° = √3 = tan60° ✓).
θ = nπ + π/4, n ∈ Z
⚠ Book misprintThe module mishandles the componendo–dividendo step and arrives at sin2θ = 1/4 with θ = nπ/2 + (−1)n½sin−1(1/4). Reworking gives sin2θ = 1, so θ = nπ + π/4. The direct check θ = 45° (3 tan15°... rather 3 tan30° = tan60°) confirms the corrected answer, and the book's value fails it.
Book Example-7 · L-3
Solve 1 + sin2x = 2cos²3x.
2cos²3x − 1 = cos6x, so sin2x = cos6x ⇒ cos(π/2 − 2x) = cos6x ⇒ π/2 − 2x = 2nπ ± 6x.
"+": π/2 − 2x = 2nπ + 6x ⇒ −8x = 2nπ − π/2 ⇒ x = −nπ/4 + π/16.   "−": π/2 − 2x = 2nπ − 6x ⇒ 4x = 2nπ − π/2 ⇒ x = nπ/2 − π/8.
x = −nπ/4 + π/16 or x = nπ/2 − π/8, n ∈ Z
Book Example-8 · L-3
Solve cos x cos y = 3/4 and sin x sin y = 1/4.
Add: cos x cos y + sin x sin y = cos(x − y) = 1 ⇒ x − y = 2nπ.
Subtract: cos x cos y − sin x sin y = cos(x + y) = 1/2 ⇒ x + y = 2mπ ± π/3.
Add/subtract these: 2x = 2(n+m)π ± π/3 ⇒ x = pπ ± π/6 ; 2y = 2(m−n)π ± π/3 ⇒ y = qπ ± π/6.
x = pπ ± π/6 , y = qπ ± π/6 ,   p, q ∈ Z
Book Example-9 · L-3
If (xyz)sin3θ = (y + x)cos3θ = 2z cos3θ + 2y sin3θ = y(cos3θ + sin3θ) + 2z cos3θ, with x, y, z ≠ 0, solve for θ.
Equating the last two expressions: 2z cos3θ + 2y sin3θ = y cos3θ + y sin3θ + 2z cos3θ ⇒ 2y sin3θ − y sin3θ = y cos3θ ⇒ y sin3θ = y cos3θ.
Since y ≠ 0, tan3θ = 1 ⇒ 3θ = nπ + π/4.
θ = nπ/3 + π/12, n ∈ Z
Book Example-10 · L-3
If tan2x · tan x = 1, find x.
tan2x = 2tan x/(1 − tan²x), so (2tan x/(1 − tan²x))·tan x = 1 ⇒ 2tan²x = 1 − tan²x ⇒ 3tan²x = 1.
tan²x = 1/3 = tan²(π/6) ⇒ x = nπ ± π/6.
x = nπ ± π/6 = (6n ± 1)π/6, n ∈ Z
