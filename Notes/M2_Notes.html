L-1

Sets: Definition, Types & Subsets

  • A set is a well-defined collection of distinct objects; the objects are its elements.
  • Well-defined = given any object we can say beyond doubt whether it is in the collection. "Good players", "tall boys", "rich persons", "difficult problems" are not sets (vague).
  • Distinct = no element repeats. Order is irrelevant.

Two ways to represent a set

roster / tabularlist elements in { }: even positives < 7 → {2, 4, 6}
set-builder{x : x has property P} · ":" or "|" reads "such that"
⚠ TrapIn roster form an element is never repeated: letters of "SCHOOL" → {S, C, H, O, L}, not {S,C,H,O,O,L}.

Cardinal number & types of set

cardinalityn(A) = number of distinct elements · n(φ) = 0
  • Null / empty / void φ: no elements (e.g. primes between 24 and 28 = φ).
  • Singleton: exactly one element. Non-empty: at least one element.
  • Finite: empty or a finite count of elements. Infinite: not finite (e.g. set of natural numbers N).
  • Equivalent sets: n(A) = n(B). Equal sets: exactly the same elements (equal ⇒ equivalent, but not conversely).

Subset, superset & power set

subsetA ⊆ B ⇔ (x ∈ A ⇒ x ∈ B) · A ⊂ B (proper): A ⊆ B and A ≠ B
counts (n elements)subsets = 2ⁿ · proper subsets = 2ⁿ − 1 · |P(A)| = 2ⁿ
  • Superset: if A ⊆ B then B ⊇ A. Improper subset: A = B (a set is an improper subset of itself).
  • φ is a subset of every set; every set is a subset of the universal set U.
Why the number of subsets is 2ⁿ
To build a subset, each of the n elements is independently in or out — 2 choices per element, so 2 × 2 × … (n times) = 2ⁿ subsets. Removing the improper subset (the set itself) leaves 2ⁿ − 1 proper subsets, and the power set P(A) simply collects all 2ⁿ of them as its elements.
★ MATHEMATICSn = 8: repeated letters count once → {M, A, T, H, E, I, C, S}.

Write down the total number of subsets of: (i) {1} (ii) {5, 6} (iii) {a, b, c} (iv) φ.

Book Example · L-1
For finite sets A and B, n[P(A)] = n[P(B)] + 15. Find n(A) and n(B).
Let n(A) = a, n(B) = b ⇒ 2ᵃ = 2ᵇ + 15. The only solution is a = 4, b = 0 since 2⁴ = 16 = 1 + 15.
n(A) = 4, n(B) = 0
Book Example · L-1
Two finite sets have m and n elements. The total number of subsets of the first set is 56 more than that of the second. Find m and n.
2ᵐ − 2ⁿ = 56. Try powers of 2: 2⁶ = 64, 2³ = 8 ⇒ 64 − 8 = 56.
m = 6, n = 3
Book Example · L-1
If A ⊂ B and B ⊂ C, prove that A ⊂ C.
Take any x ∈ A. Since A ⊂ B, x ∈ B; since B ⊂ C, x ∈ C.
So x ∈ A ⇒ x ∈ C for every x.
Therefore A ⊂ C.
Book Example · L-1
If A ⊆ B and B ⊆ A, prove that A = B.
Suppose A ≠ B: some element a lies in one set but not the other. If a ∈ A then a ∈ B (A ⊆ B); if a ∈ B then a ∈ A (B ⊆ A).
So a belongs to both — no element can be in one and not the other; the sets have exactly the same elements.
Therefore A = B.

💡 TipA square bracket includes the endpoint; a round bracket excludes it. ∞ always takes a round bracket.

Venn diagrams

  • A rectangle represents the universal set U; circles inside it represent sets, with elements written inside.

Union & intersection

unionA ∪ B = {x : x ∈ A or x ∈ B} (common elements taken once)
intersectionA ∩ B = {x : x ∈ A and x ∈ B}
Union lawsIntersection laws
A ∪ B = B ∪ AA ∩ B = B ∩ A
A ∪ φ = AA ∩ U = A
A ∪ A = AA ∩ A = A
U ∪ A = Uφ ∩ A = φ
distributiveA ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) · A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

Difference, symmetric difference, complement

differenceA − B = {x : x ∈ A and x ∉ B} (A − B ≠ B − A)
symmetric differenceA Δ B = (A − B) ∪ (B − A)
complementA′ = U − A · (A′)′ = A · φ′ = U · U′ = φ
De Morgan's laws(A ∪ B)′ = A′ ∩ B′ · (A ∩ B)′ = A′ ∪ B′
★ Disjoint setsA ∩ B = φ ⇒ A and B are disjoint (their circles don't overlap).
A ∪ B = A ∩ B forces A = B
Every element of A lies in A ∪ B = A ∩ B, hence in B, so A ⊆ B; symmetrically B ⊆ A. Two-way containment gives A = B. The same "chase an arbitrary element both ways" trick proves A ∪ B = B ⇒ A ⊆ B and A ∩ B = A ⇒ A ⊆ B.

Book Example · L-2
If A = {1, 2, 3, 4, 5} and B = {2, 4, 6, 8}, find A ∪ B and A ∩ B.
Union: list all elements, commons once → {1, 2, 3, 4, 5, 6, 8}.
Intersection: elements in both → {2, 4}.

Book Example · L-2
With A = {2, 3, 4, 5, 6}, B = {1, 3, 5}, C = {2, 4, 5}, show A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C).
LHS = {2,3,4,5,6} ∩ ({1,3,5} ∪ {2,4,5}) = {2,3,4,5,6} ∩ {1,2,3,4,5} = {2,3,4,5}.
RHS = ({2,3,4,5,6} ∩ {1,3,5}) ∪ ({2,3,4,5,6} ∩ {2,4,5}) = {3,5} ∪ {2,4,5} = {2,3,4,5}.
LHS = RHS = {2, 3, 4, 5} ✓ (distributive law verified)
Book Example · L-2
Let A = {1, 2, 3, 4, 5, 6} and B = {2, 4, 6, 8}. Find A − B and B − A.
A − B = elements in A but not B = {1, 3, 5}.
B − A = elements in B but not A = {8}.
A − B = {1, 3, 5}, B − A = {8} (so A − B ≠ B − A)
Book Example · L-2
If P = {1, 2, 3} and Q = {2, 3, 4}, find P Δ Q.
P − Q = {1}, Q − P = {4}; P Δ Q = (P − Q) ∪ (Q − P) = {1} ∪ {4}.
P Δ Q = {1, 4}
Book Example · L-2
U = {1,2,3,4,5,6}, A = {2,3}, B = {3,4,5}. Verify (A ∪ B)′ = A′ ∩ B′.
A′ = {1,4,5,6}, B′ = {1,2,6} ⇒ A′ ∩ B′ = {1, 6}.
A ∪ B = {2,3,4,5} ⇒ (A ∪ B)′ = {1, 6}.
Both equal {1, 6} ✓ (De Morgan verified)

Algebra of Sets & Counting Formulas

Algebra of sets (identities)

LawStatement
IdempotentA ∪ A = A ; A ∩ A = A
IdentityA ∪ φ = A ; A ∩ U = A
Associative(A ∪ B) ∪ C = A ∪ (B ∪ C) ; (A ∩ B) ∩ C = A ∩ (B ∩ C)
DistributiveA ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) ; A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
De Morgan(A ∪ B)′ = A′ ∩ B′ ; (A ∩ B)′ = A′ ∪ B′
ComplementA ∪ A′ = U ; A ∩ A′ = φ ; (A′)′ = A

Counting: number of elements

two setsn(A ∪ B) = n(A) + n(B) − n(A ∩ B) · disjoint: n(A) + n(B)
difference & symmetricn(A − B) = n(A) − n(A ∩ B) · n(A Δ B) = n(A) + n(B) − 2n(A ∩ B)
complement pairn(A′ ∪ B′) = n((A ∩ B)′) = n(U) − n(A ∩ B)
three setsn(A∪B∪C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)
Exactly-two and exactly-one (three sets)
Exactly two of A, B, C = n(A∩B) + n(B∩C) + n(C∩A) − 3·n(A∩B∩C).
Exactly one = n(A) + n(B) + n(C) − 2n(A∩B) − 2n(B∩C) − 2n(C∩A) + 3·n(A∩B∩C).
Neither / none = n(U) − n(A ∪ B ∪ C). These come from subtracting the over-counted overlaps in the Venn diagram region by region.
⚠ TrapFor "neither" you need n(U). n(A′ ∩ B′) = n((A ∪ B)′) = n(U) − n(A ∪ B), not n(A ∪ B) itself.

Book Example · L-3
X and Y are sets with n(X ∪ Y) = 50, n(X) = 28, n(Y) = 32. Find n(X ∩ Y).
n(X ∩ Y) = n(X) + n(Y) − n(X ∪ Y) = 28 + 32 − 50.
n(X ∩ Y) = 10
Book Example · L-3
In a survey of 400 students, 100 take apple juice, 150 take orange juice and 75 take both. How many take neither?
n(U) = 400, n(A) = 100, n(B) = 150, n(A ∩ B) = 75.
Neither = n(A′ ∩ B′) = n(U) − n(A ∪ B) = 400 − (100 + 150 − 75) = 400 − 175.
225 students take neither juice
Book Example · L-3
A survey of 1000 consumers finds 720 like product A and 450 like product B. Find the least number who must like both.
n(S ∪ T) = 720 + 450 − n(S ∩ T) = 1170 − n(S ∩ T). Since S ∪ T ⊆ U, n(S ∪ T) ≤ 1000.
n(S ∩ T) is least when n(S ∪ T) is maximum (= 1000) ⇒ least n(S ∩ T) = 1170 − 1000.
At least 170 consumers like both
Book Example · L-3
Show that A ∪ B = A ∩ B implies A = B.
Take a ∈ A ⇒ a ∈ A ∪ B = A ∩ B ⇒ a ∈ B, so A ⊆ B.
Take b ∈ B ⇒ b ∈ A ∪ B = A ∩ B ⇒ b ∈ A, so B ⊆ A.
A ⊆ B and B ⊆ A ⇒ A = B
