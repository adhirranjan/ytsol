Concept A number is a common root of two equations only when it satisfies both of them at the same time. So the cheapest route is always to look for the equation whose roots you can read off, get that root explicitly, and then force it into the other equation. Here the first equation is a perfect square, so its entire root set is known outright and no case-splitting is needed. Substituting that root into the second equation is exactly the relation the blank is asking for.
Formula x² + 2x + 1 = (x + 1)², and α is a root of f(x) = 0 ⇔ f(α) = 0. A perfect-square trinomial has D = 0, so it contributes just one distinct root.
Solution
1. For x² + 2x + 1 = 0: D = b² − 4ac = 2² − 4(1)(1) = 4 − 4 = 0, so the roots are equal.
2. x² + 2x + 1 = (x + 1)² = 0 ⇒ x = −1, repeated. Only one distinct value is on offer, so the common root is forced to be −1 — there is nothing to choose between.
3. −1 must therefore satisfy the second equation: a(−1)² − b(−1) + c = 0.
4. a(1) + b + c = 0, i.e. a + b + c = 0. The middle coefficient is written −b, and (−1)(−b) = +b, which is why a sum appears instead of the usual a − b + c.
5. Sanity check with a = 1, b = 1, c = −2 (so a + b + c = 0): x² − x − 2 = 0 has roots 2 and −1, and −1 is indeed shared.
6. Note a ≠ 0 is needed for the second equation to stay quadratic; b and c are otherwise free, only their sum with a is pinned. One common root gives exactly one linear condition on (a, b, c), never all three values.

Concept When two monic quadratics share a root, the fastest move is subtraction: both x² terms cancel and what survives is a linear equation that the common root must satisfy. A linear equation pins the root down immediately, with no discriminant and no factorisation. The pair here is symmetric — the second equation is the first with p and q swapped — so the subtraction produces a very clean factorisation. Only afterwards do we impose the condition on the coefficients.
Formula If α is common to a₁x²+b₁x+c₁=0 and a₂x²+b₂x+c₂=0, then (a₁−a₂)α² + (b₁−b₂)α + (c₁−c₂) = 0. Equal leading coefficients make the α² term vanish, leaving one linear condition.
Solution
1. Let α be the common root: α² + pα + q = 0 …(i) and α² + qα + p = 0 …(ii).
2. (i) − (ii): (p − q)α + (q − p) = 0 ⇒ (p − q)(α − 1) = 0. q − p = −(p − q), so (p − q) is a common factor — the symmetry does the work.
3. p ≠ q, otherwise the two equations are the same equation and “one root common” carries no information; hence α − 1 = 0, i.e. α = 1.
4. Putting α = 1 back in (i): 1 + p + q = 0 ⇒ p + q = −1, the condition the coefficients must obey. The root is fixed at 1 regardless of p, q; p + q = −1 is what makes such a shared root exist at all.
5. Test p = 2, q = −3 (p + q = −1): x² + 2x − 3 = 0 gives roots 1, −3 and x² − 3x + 2 = 0 gives roots 1, 2 — exactly one shared root, namely 1.
6. The other roots are q and p by the product rule (1·β = q and 1·γ = p), so they differ precisely because p ≠ q. This confirms the sharing is of one root only, not both.

The trap is forgetting to state p ≠ q: if p = q the subtraction gives 0 = 0 and every root is common, so the blank would have no unique answer. Symmetric pairs like this one almost always hide the root x = 1, because swapping p and q leaves 1 + p + q unchanged.

Concept Two quadratics with both roots common are the same equation up to an overall non-zero multiplier, because a quadratic is determined by its two roots and its leading coefficient. That single sentence converts the whole problem into a proportionality of coefficients, with no root-finding at all. Here the constant terms of the two equations are both 1, which immediately fixes the multiplier. Everything else then falls out.
Formula Both roots common ⇔ a₁/a₂ = b₁/b₂ = c₁/c₂. Equal root pairs mean equal sum −b/a and equal product c/a, and those two equalities are exactly this chain of ratios.
Solution
1. Compare x² + x + 1 = 0 with ax² + bx + 1 = 0 term by term: a/1 = b/1 = 1/1 = k, the common ratio.
2. The constant terms give k = 1/1 = 1 outright, so a = 1·k = 1 and b = 1·k = 1. Because both constants happen to equal 1, the multiplier cannot be anything but 1 — the second equation is forced to be identical, not merely proportional.
3. Given a = λb: λ = a/b = 1/1 = 1.
4. Verify: ax² + bx + 1 becomes x² + x + 1, literally the first equation, so of course both roots are shared.
5. Those roots are the non-real cube roots of unity ω, ω², since D = 1² − 4(1)(1) = 1 − 4 = −3 < 0. With real a, b the roots of Eq2 also come in a conjugate pair, so sharing one non-real root already forces sharing both — the hypothesis is self-consistent.
6. Note a ≠ 0 is automatic here (a = 1); had the ratio allowed a = 0 the second equation would collapse to linear and could not carry two roots. The a = 0 degenerate case is the usual trap in parameterised “quadratics”.

2. x² + 5x + 4 = (x + 1)(x + 4) = 0 ⇒ roots −1 and −4 (1 + 4 = 5, 1×4 = 4).
3. Intersecting the root sets: {−1, −2} ∩ {−1, −4} = {−1}, so the common root is −1.
4. Cross-check by subtraction: (x²+3x+2) − (x²+5x+4) = −2x − 2 = 0 ⇒ x = −1, the same value. Any common root must satisfy the difference of the two equations, so this linear equation traps it in one line.

Note also that x = −1 works here because 1 − 3 + 2 and 1 − 5 + 4 both vanish, i.e. a − b + c = 0 in each.

Concept Two quadratics have the same pair of roots exactly when one is a non-zero constant multiple of the other, since the roots fix the sum −b/a and the product c/a and nothing else. So “both roots common” is a statement about coefficients, and the roots themselves never need to be computed — which is lucky here, because they are not real. The answer is therefore a ratio, and the blanks are filled by taking the natural multiplier 1.
Formula Both roots common ⇔ p/1 = q/5 = r/7 = k, k ≠ 0. k = 0 would wipe out the second equation entirely, leaving 0 = 0 rather than a quadratic.
Solution
1. Write the proportionality: p/1 = q/5 = r/7 = k, so (p, q, r) = (k, 5k, 7k).
2. Then px² + qx + r = k(x² + 5x + 7), which vanishes wherever the first equation does, for every k ≠ 0. Scaling an equation cannot move its roots, so the data fix p, q, r only up to a common factor.
3. The standard (monic) choice k = 1 gives p = 1, q = 5, r = 7 — the values the blanks want.
4. Spot-check k = 2: 2x² + 10x + 14 = 2(x² + 5x + 7), same root pair, ratios still 2/1 = 10/5 = 14/7 = 2.

Concept “α is a root of f(x) = 0” means one thing only: the number f(α) is zero. So a root shared by two equations must make both polynomials vanish simultaneously, and that is the entire content of the phrase “common root”. Every technique in this lecture — subtracting the equations, cross-multiplication, the ratio test — is derived from this one substitution statement. Nothing about the kind of number α is implied by it.
Formula α common to f and g ⇔ f(α) = 0 and g(α) = 0, equivalently (x − α) divides both. The factor-theorem form is what lets you say the two polynomials share a linear factor.
Solution
1. By the definition of a root, α satisfying both equations means f(α) = 0 and g(α) = 0 at the same time — option (c).
2. (a) “solves only one” directly contradicts the premise that α satisfies both, so it is rejected at once.
3. (b) fails: x² − 2 = 0 and 2x² − 4 = 0 share α = √2, which is irrational. Rationality of a shared root needs rational coefficients plus a rational discriminant — neither is assumed here.
4. (d) fails too: x² − 1 = 0 and x² − 3x + 2 = 0 share α = 1, a perfectly real number. Nothing forces D < 0; a common root may be real, irrational or non-real.
5. Consequence worth carrying: since (x − α) divides both, it divides f(x) − g(x), which is how the standard subtraction trick is justified.
6. That difference is linear whenever the leading coefficients match, giving α in one step — a direct pay-off of choosing (c) as the definition. Definition first, machinery second: the formulas are consequences, not extra rules.

  common root a  =>  f(a) = 0  and  g(a) = 0
  (a) solves only one : contradicts premise      X
  (b) rational : x^2-2, 2x^2-4 share sqrt(2)     X

⚡ JEE Trick Definition questions are decided by counterexample, not by feel: one explicit pair of equations kills (b) and one kills (d) in seconds. Note also that “complex” in (d) is meant as non-real; in the strict sense every real number is complex, so the option is loose wording as well as wrong. Keep the factor-theorem restatement in mind, because “(x − α) divides both” is what generalises the idea to cubics and higher.

8If the equations ax^2 + bx + c = 0 and x^3 + 3x^2 + 3x + 2 = 0 and have two common roots, then: (a, b, c ∈ R) (a) a = b ≠ c (b) a = -b = c (c) a = b = c (d) a + b + c = 3Theory of equationsQUADRATIC EQUATIONS in One Shot: All Concepts & PYQs Covered | JEE Main & Advanced🟡 Similarca = b = c
Concept Factorise the cubic first: it has an obvious rational root, and dividing it out leaves a quadratic factor whose discriminant is negative. So the cubic's three roots are one real number and a conjugate pair of non-real numbers. Now the quadratic ax² + bx + c = 0 has real coefficients and must share two of those three roots. It cannot pair the real root with just one member of a conjugate pair, because real coefficients force non-real roots to occur in conjugate pairs — so the only possibility is that it shares the conjugate pair itself, making it a multiple of the quadratic factor.
Formula real coefficients ⇒ roots p + iq and p − iq occur together; sharing both roots ⇒ proportional coefficients. Two monic quadratics with the same root pair are identical, so a : b : c is forced.
Solution
1. Test x = −2 in the cubic: −8 + 3(4) + 3(−2) + 2 = −8 + 12 − 6 + 2 = 0, so (x + 2) is a factor.
2. Divide: x³ + 3x² + 3x + 2 = (x + 2)(x² + x + 1). Check the expansion: x³ + x² + x + 2x² + 2x + 2 ✓.
3. The quadratic factor has D = 1² − 4(1)(1) = −3 < 0, so its roots ω, ω̄ are non-real conjugates and the cubic's roots are −2, ω, ω̄.
4. If ax² + bx + c = 0 shared −2 and one of ω, ω̄, it would have one real and one non-real root — impossible for real a, b, c. Non-real roots of a real polynomial always arrive in conjugate pairs.
5. So the two common roots are ω and ω̄, giving ax² + bx + c = a(x² + x + 1), i.e. b = a and c = a, hence a = b = c.
6. Screen the rivals: (a) a = b ≠ c fails since c must equal a; (b) a = −b = c would need x² − x + 1, whose roots are not ω, ω̄; (d) a + b + c = 3 is only a special case (a = 1) and not forced. The relation must hold for every admissible triple, not just one scaling.

9If 3^(1+x) + 3^(1-x) = 10, then the values of x are: (a) 1, -1 (b) 1, 0 (c) 1, 2 (d) -1, -2Quadratic in disguiseSolving Exponential Equations Reducible to Quadratics🟡 Similara1, -1
Concept An exponential equation whose terms are 3⁺ˣ and 3⁻ˣ is a quadratic wearing a disguise: with t = 3ˣ the two terms are 3t and 3/t, reciprocals of each other up to constants. Multiplying through by t clears the denominator and produces an honest quadratic in t. Because 3ˣ > 0 for every real x, only positive roots t are admissible — a negative or zero root would have to be thrown away. Here both roots turn out positive and reciprocal, which is exactly why the answers for x come out as ±1.
Formula 3¹⁺ˣ = 3·3ˣ, 3¹⁻ˣ = 3/3ˣ; with t = 3ˣ > 0: 3t + 3/t = 10 ⇒ 3t² − 10t + 3 = 0. Multiplying by t is safe because t = 3ˣ is never zero.
Solution
1. Split the exponents: 3¹⁺ˣ + 3¹⁻ˣ = 3·3ˣ + 3·3⁻ˣ = 3t + 3/t with t = 3ˣ.
2. Set 3t + 3/t = 10 and multiply by t: 3t² − 10t + 3 = 0.
3. D = b² − 4ac = (−10)² − 4(3)(3) = 100 − 36 = 64 > 0, so t = (10 ± 8)/6 gives t = 3 or t = 1/3. The product of roots is 3/3 = 1, so the two values are reciprocals — a useful shortcut.
4. Both roots are positive, so both survive the constraint 3ˣ > 0; neither is discarded. In this family a non-positive root of the t-quadratic must be rejected, so the sign test is never optional.
5. Solve back: 3ˣ = 3 = 3¹ gives x = 1, and 3ˣ = 1/3 = 3⁻¹ gives x = −1.
6. Verify x = 1: 3² + 3⁰ = 9 + 1 = 10 ✓; and x = −1: 3⁰ + 3² = 1 + 9 = 10 ✓. The equation is even in x, so the root set had to be symmetric about 0.
