1 (i)Fill in the blanks with appropriate terms.
Entropy is an ______ property.		Entropy is extensiveTHERMODYNAMICS । Class 11 (L5) I Entropy | JEE | NEET🟡 Similarextensive
Concept A property is extensive if it scales with the amount of matter present and intensive if it does not. Entropy counts the number of ways the particles of a system can be arranged, so doubling the sample doubles the entropy: two moles of a gas have exactly twice the entropy of one mole under the same conditions.
Key relation S(2n) = 2 × S(n) at the same T and P Absolute entropies are tabulated as S° in J K−1 mol−1 — a "per mole" unit, which is the giveaway that the raw quantity is extensive.
Solution
1. Test the definition: split a container of gas into two equal halves. Each half has half the particles and half the number of accessible microstates weighting, so each carries half the entropy.
2. Adding the halves back gives the original total, so S is additive over amount — the signature of an extensive property.
3. Compare with temperature or pressure: splitting the container leaves both unchanged. Those are intensive.
4. The unit test settles it too. Entropy is quoted in J K−1; only after dividing by the amount does it become the intensive molar entropy J K−1 mol−1.
5. All the other energy-like thermodynamic functions behave the same way: U, H, G, S and V are extensive; T, P, density and molar quantities are intensive.
6. Hence the blank is extensive.
 extensive (scale with amount) : U, H, G, S, V, m, n
 intensive (do not scale)      : T, P, density, S_m
 -------------------------------------------------
 1 mol gas  ->  S
 2 mol gas  ->  2S      (same T and P)
 -------------------------------------------------
 unit J/K is extensive ; J/K/mol is intensive
⚡ JEE Trick To classify any property in one second, imagine cutting the system in half. If the number changes, it is extensive; if it stays put, it is intensive. Any "per mole" or "per gram" version of an extensive property is intensive.
Answer: extensive — entropy scales with the amount of substance.
1 (ii)Entropy of a system is a ______ function.Entropy is a state functionClass 11 chapter 6 | Thermodynamics 10 | What is ENTROPY ? | Spontaneity and Entropy JEE MAINS /NEET🟡 Similarstate
Concept A state function depends only on the present condition of the system — its temperature, pressure, composition and phase — and not on the route taken to reach it. Entropy qualifies: once you fix the state, S is fixed, so ΔS between two states is the same whether the change was carried out reversibly or violently.
Key relation ΔS = Sfinal − Sinitial, independent of path The chapter states this directly: "The change in entropy... does not depend on the path adopted."
Solution
1. Entropy is defined through qrev/T. Heat itself is a path function, but dividing the reversible heat by T produces a quantity that turns out to be path-independent.
2. Consequence 1: ΔS for a cyclic process is zero, because start and finish are the same state.
3. Consequence 2: to compute ΔS for an irreversible change you may replace it by any convenient reversible path between the same two states — the workhorse trick of this whole chapter.
4. Example: expanding a gas irreversibly into a vacuum from V1 to V2 has the same ΔS = nR ln(V2/V1) as the reversible isothermal expansion, even though q and w differ completely.
5. Other state functions: U, H, G, T, P, V. Path functions: q and w.
6. Hence the blank is state.
 state functions : S, U, H, G, T, P, V
 path functions  : q, w
 -------------------------------------------------
 dS = S(final) - S(initial)   route irrelevant
 -------------------------------------------------
 cyclic process  =>  dS = 0
 irreversible dS : compute via any reversible path
⚡ JEE Trick Whenever a question gives an irreversible or "free expansion" process and asks for ΔS, immediately invent a reversible path with the same endpoints. The answer is identical and the algebra becomes easy.
Answer: state — entropy is a state function, so ΔS depends only on the initial and final states.
1 (iii)The entropy change for a cyclic process is ______.ΔS over a closed cycleTHERMODYNAMICS -18 || ENTROPY & 2nd Law Of Thermodynamics || Total Entropy🟡 Similarzero
Concept A cyclic process returns the system to precisely the state it started from. Since entropy is a state function, its value at the end equals its value at the start, so the net change around the loop must vanish — no matter how many steps the cycle contains or how irreversible they are.
Key relation ∮ dS = 0 for any complete cycle True of every state function: ∮ dU = 0 and ∮ dH = 0 as well.
Solution
1. Let the cycle run A → B → C → A. Then ΔScycle = (SB − SA) + (SC − SB) + (SA − SC).
2. Every intermediate term cancels in pairs, leaving exactly zero.
3. Take the Carnot cycle as the standard illustration: +q2/T2 is gained on the isothermal expansion and −q1/T1 lost on the isothermal compression, the two adiabatics contribute nothing, and the sum is zero.
4. Important caution: it is ΔS of the system that vanishes. If the cycle contains irreversible steps, the surroundings are left with a net entropy gain, so ΔSuniverse > 0 even though ΔSsystem = 0.
5. The same logic gives ΔU = 0 and ΔH = 0 over a cycle, while q and w are generally non-zero — which is exactly how an engine does net work.
6. Hence the blank is zero.
 A -> B -> C -> A
 dS = (Sb-Sa) + (Sc-Sb) + (Sa-Sc) = 0
 -------------------------------------------------
 over one cycle : dS = dU = dH = 0
                  q and w are NOT zero
 -------------------------------------------------
 irreversible cycle : dS(system) = 0
                      dS(universe) > 0
⚡ JEE Trick "Cyclic process" is code for "every state function is zero". Read the word and write ΔU = ΔH = ΔS = ΔG = 0 before you look at anything else in the question.
Answer: zero — a cycle returns to the same state, so ΔSsystem = 0.
1 (iv)For natural processes, entropy of universe is ______.ΔSuniverse for spontaneous changeClass 11 chapter 6 | Thermodynamics 09 | Second Law Of Thermodynamics Introduction | IIT JEE /NEET🟡 Similarincreasing
Concept This is the second law in its most familiar form. Every real (natural, spontaneous, irreversible) change leaves the universe with more entropy than it had before. Only an idealised reversible change — which never actually happens — leaves the total unchanged.
Key relation ΔSuniverse = ΔSsystem + ΔSsurroundings > 0 for a natural process The chapter writes it as ΔSuniverse > 0.
Solution
1. Take heat flowing from a hot body at T2 to a cold one at T1, with T2 > T1. The hot body loses q/T2, the cold body gains q/T1.
2. Because T1 < T2, the gain q/T1 exceeds the loss q/T2, so the total is positive — and this is exactly the direction heat is observed to flow.
3. The reverse flow would make the total negative, which is why heat never travels spontaneously from cold to hot: the Clausius statement of the second law.
4. The same test applies to every spontaneous change — gases mixing, salt dissolving, iron rusting: each raises ΔSuniverse.
5. Note that ΔSsystem alone may be negative (water freezing, ammonia forming); it is the total that must rise.
6. Hence the blank is increasing.
 hot T2 --- q ---> cold T1        (T2 > T1)
 -------------------------------------------------
 hot loses  : -q/T2
 cold gains : +q/T1     and 1/T1 > 1/T2
 net        : q(1/T1 - 1/T2) > 0     INCREASE
 -------------------------------------------------
 natural    : dS(universe) > 0
 reversible : dS(universe) = 0  (idealised limit)
⚡ JEE Trick Always ask "entropy of what?" ΔSsystem can be any sign; ΔSuniverse is positive for spontaneous, zero for reversible and never negative. Most wrong answers come from testing the system instead of the universe.
Answer: increasing — for natural processes ΔSuniverse > 0.
1 (v)The entropy change in the equilibrium state is ______.ΔS at equilibriumEntropy and Second Law of Thermodynamics - Thermodynamics Class 11 Chemistry | NEET 2023 | Anoop sir🟡 Similarzero
Concept Equilibrium is the state a spontaneous process runs down to and then stops. Just before equilibrium the entropy of the universe is still rising; at equilibrium it has reached its maximum, and at a maximum the rate of change is zero. Any further movement in either direction would lower it, which the second law forbids.
Key relation ΔS = 0 at equilibrium (the chapter: "the entropy change in the equilibrium state is zero") Equivalently ΔStotal = 0, which is also the reversible condition — equilibrium and reversibility are the same limit.
Solution
1. Sketch Suniverse against the extent of reaction. A spontaneous change climbs the curve; equilibrium is the peak.
2. At the peak the slope is zero, so an infinitesimal change in either direction produces no first-order change in entropy: ΔS = 0.
3. This is precisely the definition of a reversible process, which is why a system at equilibrium can be nudged either way with no net entropy cost.
4. Concrete case: ice and water coexisting at 273 K. Melting a little ice raises Ssystem by ΔHfus/T and lowers Ssurroundings by exactly the same amount, so ΔStotal = 0.
5. Take care with the wording: ΔSsystem for that melting step is not zero; it is the total that vanishes. The book's sentence means the overall entropy change.
6. Hence the blank is zero.

   |        .'         '.
   +----------------------------> extent

 equilibrium : at the top dS = 0

   dS(sys) = +dHfus/T ; dS(surr) = -dHfus/T

1 (vi)At absolute zero, the entropy of a pure crystal is zero. This is ______.Third law of thermodynamicsAt absolute zero, the entropy of a perfect crystal is zero. This is.....of thermodynamics. (A) f...🟢 Exactthird law of thermodynamics
Concept The third law supplies the missing zero point for entropy. It asserts that a perfectly ordered crystalline solid, cooled to 0 K, has exactly one accessible arrangement of its particles and therefore zero entropy. That fixed reference is what allows chemists to tabulate absolute entropies S°, something impossible for U or H.
Key relation S = 0 for a perfect crystal at T = 0 K Boltzmann: S = k ln W, and a perfect crystal at 0 K has W = 1, so ln W = 0.
Solution
1. At absolute zero all thermal motion ceases and every particle occupies its lowest energy level in a fixed lattice position.
2. There is then exactly one microstate, W = 1, and S = k ln 1 = 0.
3. This statement is the third law of thermodynamics, distinct from the first (energy conservation) and the second (entropy of the universe increases).
4. Its practical payoff: heating the crystal from 0 K and integrating Cp/T gives the absolute molar entropy S° at 298 K, which is why entropy tables list positive absolute values while enthalpy tables list only changes.
5. Note the two qualifiers "perfect" and "crystalline". Glasses, solid solutions and molecules such as CO with two nearly identical orientations retain a residual entropy at 0 K.
6. Hence the blank is third law of thermodynamics.
 first law  : energy is conserved, dU = q + w
 second law : dS(universe) > 0 for spontaneity
 third law  : S = 0 for a perfect crystal at 0 K
 -------------------------------------------------
 Boltzmann  S = k ln W ; W = 1 at 0 K  =>  S = 0
 -------------------------------------------------
 use : gives ABSOLUTE entropies S(298 K) > 0
 exception : residual entropy in CO, glasses
⚡ JEE Trick Remember why entropy tables look different from enthalpy tables. S°(element) is a positive number because the third law fixes an absolute zero; ΔfH°(element) is zero only by convention.
Answer: third law of thermodynamics — a perfect crystal at absolute zero has S = 0.
1 (vii)The entropy of the universe is in increasing order but total energy is ______.First law vs second law of the universeThe Laws of Thermodynamics, Entropy, and Gibbs Free Energy🟡 Similarconstant
Concept The two great laws pull in different directions and this sentence contrasts them. The first law says the universe's total energy can never change; the second says its total entropy can only grow. Energy is conserved, but it is continuously degraded into less useful, more dispersed forms.
Key relation ΔUuniverse = 0 (first law) while ΔSuniverse > 0 (second law) Clausius's own summary: "The energy of the universe is constant; the entropy of the universe tends to a maximum."
Solution
1. The first law states that energy is neither created nor destroyed, only converted. Applied to the universe as an isolated system, its total energy is fixed.
2. The second law places no such restriction on entropy; every irreversible change adds to it.
3. So the blank must be constant.
4. What actually changes is the quality of the energy. A litre of petrol holds the same energy after burning as before, but it is now spread as warm exhaust and can no longer drive a car.
5. This degradation is why a 100% efficient engine is impossible — one of the limitations of the first law that the chapter opens with.
6. The eventual limit of the trend is the "heat death", a universe at uniform temperature with maximum entropy and no capacity for further change.
 first  law : energy of the universe = CONSTANT
 second law : entropy of the universe INCREASES
 -------------------------------------------------
 energy is conserved but DEGRADED :
   concentrated, useful  ->  dispersed, useless
 -------------------------------------------------
 consequence : no engine can be 100% efficient
⚡ JEE Trick Learn Clausius's one-line summary verbatim. Options that say "energy of the universe is increasing" or "entropy of the universe is constant" are then rejected instantly — both halves swapped is the standard distractor.
Answer: constant — the entropy of the universe rises but its total energy stays fixed.

2 (iv)The first law of thermodynamics does not explain why natural spontaneous processes are irreversibleLimitations of the first lawClass 11 chapter 6 | Thermodynamics 09 | Second Law Of Thermodynamics Introduction | IIT JEE /NEET🟡 SimilarTrue
Concept The first law is a bookkeeping rule: energy in equals energy out. It is completely blind to direction. Both a spontaneous change and its impossible reverse conserve energy perfectly, so the first law cannot say which one nature will choose — that is precisely what the second law was invented to supply.
Key relation ΔU = q + w holds equally for a process and for its reverse A law that is symmetric under time reversal cannot explain irreversibility.
Solution
1. Consider heat flowing from a hot body to a cold one. Energy lost by the hot body equals energy gained by the cold one, so the first law is satisfied.
2. Now imagine the reverse: heat flowing from cold to hot. The same energy balance holds, so the first law is equally satisfied — yet this never happens.
3. The first law therefore cannot forbid the reverse process, and cannot explain why the forward one is irreversible.
4. The chapter opens with a list of these limitations: the first law gives no information about direction, does not explain why reactions stop short of completion, and does not rule out a 100% efficient engine or a self-acting refrigerator.
5. The second law supplies the missing ingredient, ΔSuniverse > 0, which is not symmetric under reversal and so picks out a direction.
6. The statement is therefore True.

 -------------------------------------------------

⚡ JEE Trick Memorise the division of labour: the first law says how much, the second says which way, the third says where zero is. Almost every conceptual question in this lecture is testing that one sentence.

2 (vii)Entropy is a measured of disorder lines or randomness in the systemPhysical meaning of entropyWhat is entropy? - Jeff Phillips🟡 SimilarTrue
Concept Entropy is the thermodynamic measure of molecular disorder or randomness. Boltzmann made the idea quantitative: the more distinct microscopic arrangements a system can adopt while looking the same macroscopically, the larger its entropy. (The printed phrase "disorder lines" is a typographical slip for "disorder or randomness".)
Key relation S = k ln W W is the number of microstates; k = 1.38 × 10−23 J K−1 is Boltzmann's constant.
Solution
1. A perfectly ordered crystal at 0 K has one arrangement, W = 1, so S = 0. Every added freedom multiplies W and raises S.
2. Hence the standard ordering Sgas > Sliquid > Ssolid: gas particles roam the whole vessel, liquid particles slide past neighbours, solid particles only vibrate about fixed sites.
3. The same reasoning predicts entropy increases with temperature, with volume, on mixing and on dissolving a solid — all raise the number of accessible arrangements.
4. It also predicts a decrease when gas moles fall in a reaction, when a gas is compressed, or when a solute crystallises out.
5. Note the units, J K−1 mol−1 — entropy is not energy, though the two are linked through ΔS = qrev/T.
6. The statement is True.

 -------------------------------------------------
 S rises with : T, V, mixing, dissolving, n(gas)

                moles of gas
⚡ JEE Trick For any reaction, get the sign of ΔS in two seconds from Δngas = (moles of gaseous product) − (moles of gaseous reactant). Positive → ΔS positive; negative → ΔS negative; zero → ΔS small.

Solution

4. (d) Vaporisation of camphor: solid straight to vapour, the largest entropy gain available. Increases ✓
5. So the entropy of the system rises only in (b) and (d).
