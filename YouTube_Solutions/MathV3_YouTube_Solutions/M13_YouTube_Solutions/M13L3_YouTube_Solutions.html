1 (i)Fill in the blanks: If three points A, B and C are collinear, then the value of Area of △ABC is ______.Collinearity ⇒ zero areaCoordinate Geometry | Collinear points | Area of triangle = 0🟡 Similar0
Concept Three points are collinear exactly when the “triangle” they form is degenerate — it has no spread, so the region it encloses shrinks to a line segment of zero width. The signed-area formula therefore returns 0 for any three collinear points, and this is the cleanest algebraic test for collinearity.
Formula Area = (1/2)|x1(y2−y3) + x2(y3−y1) + x3(y1−y2)|. The bracket is the 3×3 determinant with a column of 1’s; a zero determinant means the rows are linearly dependent, i.e. the points lie on one line.
Solution
1. Collinear points share a single straight line, so no genuine triangle is enclosed.
2. In the determinant form, the third column of 1’s plus two collinear rows makes the rows dependent.
3. A dependent determinant equals 0, hence the bracket is 0. Linear dependence of the position rows is precisely collinearity.
4. Area = (1/2)|0| = 0.
5. The converse also holds: if the area is 0 the three points must be collinear, so this is an “if and only if”.
6. Therefore the required value of the area of △ABC is 0.
  Area = (1/2)|x1(y2-y3)+x2(y3-y1)+x3(y1-y2)|
  collinear  =>  determinant = 0
  Area = (1/2)|0| = 0
⚡ JEE Trick “Collinear” is a free gift: immediately write area = 0 or set the 3×3 determinant to 0 to solve for an unknown coordinate — never grind the distance formula. The same zero-area test instantly decides whether three given points are collinear.
Answer: 0.

Concept A(0,0), B(1,1) and C(−1,−1) all satisfy y = x, so they sit on one straight line through the origin. Any three points on a common line enclose no area, and the area formula confirms this by returning 0.
Formula Area = (1/2)|x1(y2−y3) + x2(y3−y1) + x3(y1−y2)|. Plugging the three coordinates in should give 0 because B and C are just O scaled along the line y = x.
Solution
1. Take (x1,y1) = (0,0), (x2,y2) = (1,1), (x3,y3) = (−1,−1).
2. Area = (1/2)|0·(1−(−1)) + 1·((−1)−0) + (−1)·(0−1)|.
3. = (1/2)|0 + 1·(−1) + (−1)·(−1)|.
4. = (1/2)|0 − 1 + 1| = (1/2)|0| = 0.
5. Check geometrically: B(1,1) and C(−1,−1) both obey y = x, as does O, so all three are collinear. The line y = x passes through every one of them.
6. Slope test confirms it: slope OB = (1−0)/(1−0) = 1 and slope OC = (−1−0)/(−1−0) = 1; equal slopes from a common point O means the points are collinear.
7. Zero area confirms collinearity, so the area of △ABC is 0.
  Area = (1/2)|0(1+1) + 1(-1-0) + (-1)(0-1)|
       = (1/2)|0 - 1 + 1|
       = (1/2)(0) = 0
  line y = x through all three points
⚡ JEE Trick Before computing, glance for an obvious line: if the points fit y = mx (here y = x), they are collinear and the area is 0 on sight. Spotting the pattern beats expanding the determinant under exam pressure.

Concept The set of points equidistant from two fixed points is the perpendicular bisector of the segment joining them. For (1,0) and (−1,0) that segment lies along the x-axis with mid-point the origin, so its perpendicular bisector is the vertical line through O — the y-axis.
Formula PA = PB ⇔ PA2 = PB2. Squaring removes the roots; the x2 and y2 terms cancel, leaving a single linear equation — the bisector.
Solution
1. Let P(x,y) be equidistant from A(1,0) and B(−1,0).
2. PA2 = PB2 ⇒ (x−1)2 + y2 = (x+1)2 + y2.
3. x2 − 2x + 1 + y2 = x2 + 2x + 1 + y2.
4. Cancel x2, y2 and the 1’s: −2x = 2x ⇒ 4x = 0 ⇒ x = 0.
5. So the locus is the line x = 0, the y-axis. Every point of the y-axis is the same distance left to (1,0) as right to (−1,0).
6. This matches the geometric picture: the segment AB lies along the x-axis, its mid-point is the origin O(0,0), and the perpendicular bisector through O is vertical.
7. Spot-check (0,5): distance to (1,0) = √26, distance to (−1,0) = √26 — equal, as required for a point on x = 0.
  (x-1)^2 + y^2 = (x+1)^2 + y^2
  -2x + 1 = 2x + 1
  4x = 0  ->  x = 0   (the y-axis)
⚡ JEE Trick When the two fixed points are symmetric about an axis, the equidistant locus is that axis itself — here (±1,0) are mirror images in the y-axis, so the answer x = 0 is immediate without algebra.
Answer: x = 0 (the y-axis).

Concept The 3×3 coordinate determinant equals twice the signed area of the triangle. For an equilateral triangle of side a the area is a fixed multiple of a2, so squaring the determinant gives a clean power of a whose coefficient reveals p, q, r.

Solution
1. The determinant D = |x1 y1 1; x2 y2 1; x3 y3 1| satisfies Area = (1/2)|D|.
2. So |D| = 2·Area = 2·(√3/4)a2 = (√3/2)a2.
3. Square both sides: D2 = ((√3/2)a2)2 = (3/4)a4.
4. Compare with D2 = (p/q)ar: coefficient 3/4 gives p = 3, q = 4, and the power a4 gives r = 4. Matching coefficient and exponent separately pins all three constants.
5. Check: an equilateral triangle of side a truly has area (√3/4)a2, so D2 = (3/4)a4 is dimensionally an (area)2 — consistent.
6. Hence p = 3, q = 4, r = 4.

  D^2 = (3/4) a^4 = (p/q) a^r
  p = 3, q = 4, r = 4

Concept The point moves with a parameter t. To get its locus we eliminate t between x = t + t2 and y = 2t + 1, leaving one relation purely in x and y — which turns out to be a parabola.
Formula solve one equation for t, substitute into the other. y = 2t + 1 is linear in t, so t = (y−1)/2 is the easiest substitution, feeding neatly into x = t + t2.
Solution
1. From y = 2t + 1, solve for t: t = (y − 1)/2.
2. Note x = t + t2 = t(1 + t), and 1 + t = (y + 1)/2.
3. So x = t(1+t) = [(y−1)/2]·[(y+1)/2] = (y−1)(y+1)/4 = (y2−1)/4.

Formula tan(∠RPQ − ∠RQP) = tan 2α. The two base angles have tangents built from y and (a−x), (a+x); subtracting via tan(A−B) and setting equal to tan 2α yields the curve.
Solution
1. R(x,y); the angle at P(a,0) and the angle at Q(−a,0) differ by 2α, a positive constant.
2. Setting tan of that difference equal to tan 2α and clearing denominators produces a relation among x, y and cot 2α.
3. The standard reduction gives x2 − y2 + 2xy cot 2α = a2. The “difference of base angles constant” condition is the classical generator of this rectangular hyperbola.
4. Rearranged: x2 − y2 + 2xy cot 2α − a2 = 0.
5. The sign on x2 − y2 (not x2 + y2) and the −a2 constant distinguish it from options (b), (c).
6. Hence option (a) is correct.
  tan(angle P - angle Q) = tan 2a
  reduces to:
  x^2 - y^2 + 2xy cot2a = a^2
  x^2 - y^2 + 2xy cot2a - a^2 = 0
⚡ JEE Trick “Difference of base angles = constant” → rectangular hyperbola x2−y2+2xy cot(const) = a2; “sum of base angles = constant” would give a different conic. The minus between x2 and y2 is the fingerprint of the difference case.
Answer: (a) x2 − y2 + 2xy cot 2α − a2 = 0.
9Vertices of a variable triangle are (3, 4), (5cosθ, 5sinθ) and (5sinθ, −5cosθ), where θ ∈ R. The locus of its orthocentre is: (a) x2 + y2 + 6x + 8y − 25 = 0 (b) x2 + y2 − 6x + 8y − 25 = 0 (c) x2 + y2 + 6x − 8y − 25 = 0 (d) x2 + y2 − 6x − 8y − 25 = 0Orthocentre locus (vertices on a fixed circle)Vertices of a variable triangle are (3,4),(5cos t,5sin t),(5sin t,-5cos t); locus of its orthocentre🟢 Exactdx2 + y2 − 6x − 8y − 25 = 0
Concept The three vertices (3,4), (5cosθ,5sinθ), (5sinθ,−5cosθ) all lie on the circle x2+y2 = 25, so the circumcentre is the origin. The orthocentre is then the vector sum of the vertices; eliminating θ gives its locus.
Formula H = A + B + C (circumcentre at O). H = (3 + 5cosθ + 5sinθ, 4 + 5sinθ − 5cosθ); then (x−3)2 + (y−4)2 = 50.
Solution
1. Each vertex lies on x2+y2 = 25: 32+42 = 25 and (5cosθ)2+(5sinθ)2 = 25, etc. So circumcentre O = (0,0).
2. Orthocentre H = A + B + C = (3 + 5cosθ + 5sinθ, 4 + 5sinθ − 5cosθ).
3. So x − 3 = 5(cosθ+sinθ) and y − 4 = 5(sinθ−cosθ).
4. Add squares: (x−3)2 + (y−4)2 = 25[(cosθ+sinθ)2 + (sinθ−cosθ)2] = 25·2 = 50. The amplitude 5 squared times 2 gives 50.
5. Expand: x2 − 6x + 9 + y2 − 8y + 16 = 50 ⇒ x2 + y2 − 6x − 8y + 25 = 50.
6. So x2 + y2 − 6x − 8y − 25 = 0 — option (d).
  vertices on x^2+y^2=25 -> circumcentre O
  H = A+B+C
  (x-3)^2 + (y-4)^2 = 25*2 = 50
  x^2 + y^2 - 6x - 8y - 25 = 0
⚡ JEE Trick Vertices on a circle centred at O → orthocentre = sum of the vertices. The two rotating vertices (cosθ+sinθ, sinθ−cosθ) contribute the reusable factor 2, so the locus is a circle of radius 5√2 centred at the fixed vertex (3,4).
Answer: (d) x2 + y2 − 6x − 8y − 25 = 0.
10If a rod AB of length 2 units slides on the coordinate axes in the first quadrant, and an equilateral triangle ABC is completed with C on the side away from O, then the locus of C is: (a) x2 + y2 − xy + 1 = 0 (b) x2 + y2 − xy√3 + 1 = 0 (c) x2 + y2 + xy√3 − 1 = 0 (d) x2 + y2 − xy√3 − 1 = 0Locus of the apex of an equilateral triangle on a sliding rodA rod AB of length 2 slides on coordinate axes; equilateral triangle ABC completed; locus of C🟢 Exactdx2 + y2 − xy√3 − 1 = 0
Concept A rod AB of length 2 slides with its ends on the axes in the first quadrant; an equilateral triangle ABC is built with C on the far side from O. As the rod slides, C traces a curve. Using the rod’s intercept angle and the 60° apex geometry, we eliminate the parameter to get C’s locus.
Formula A = (2cosφ, 0), B = (0, 2sinφ); C = midpoint + height × outward normal. The equilateral height is √3 (side 2), placed perpendicular to AB away from O; eliminating φ yields the xy√3 cross-term.
Solution
1. Put A = (2cosφ, 0), B = (0, 2sinφ), so AB = 2 and the midpoint M = (cosφ, sinφ).
2. The equilateral triangle on AB has height √3; C = M + √3·(unit outward normal to AB, away from O).
3. The outward unit normal is (cosφ, sinφ), so C = (cosφ + √3 cosφ, sinφ + √3 sinφ)—type combination; carrying the algebra through gives x2 + y2 and an xy√3 cross-term.
4. Eliminating φ yields x2 + y2 − √3 xy = 1. The −√3 xy term comes from the 60° rotation that builds C off the chord AB.
5. Rearranged: x2 + y2 − xy√3 − 1 = 0.
6. Verify the symmetric position φ = 45°: A = (√2,0), B = (0,√2), M = (√2/2, √2/2), C ≈ (1.93, 1.93); then 1.932+1.932 − √3(1.93)(1.93) − 1 ≈ 7.47 − 6.46 − 1 ≈ 0. ✓ So option (d).
  A=(2cosф,0), B=(0,2sinф), AB=2, height=sqrt3
  C = M + sqrt3 * outward normal
  eliminate ф:
  x^2 + y^2 - sqrt3 xy - 1 = 0
  check ф=45: C~(1.93,1.93) -> ~0
⚡ JEE Trick An equilateral triangle built on a chord introduces a √3 xy cross-term (from the 60° rotation). When stuck on the full derivation, plug the symmetric slide position (φ = 45°) into each option — only the true locus zeroes out.
Answer: (d) x2 + y2 − xy√3 − 1 = 0.
