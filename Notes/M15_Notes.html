L-1

Equation of a Circle — Standard, General, Diametric & Parametric Forms

Definition & standard equation

  • A circle is the locus of a point moving in a plane so that its distance from a fixed point (the centre) is a constant (the radius r).
  • For centre C(h,k): CP = r ⇒ (x − h)² + (y − k)² = r². Centre at origin ⇒ x² + y² = r². Radius 0 ⇒ point circle. Same centre, different radii ⇒ concentric circles.

Diameter form & general form

diameter endpoints (x₁,y₁),(x₂,y₂) — uses ∠APB = 90°(x − x₁)(x − x₂) + (y − y₁)(y − y₂) = 0 (circle of least radius through the two points)
general equationx² + y² + 2gx + 2fy + c = 0 ⇒ centre (−g, −f) = (−(1/2)·coeff x, −(1/2)·coeff y), radius √(g² + f² − c)
  • g² + f² − c > 0 real circle · = 0 point circle · < 0 imaginary (no real points). A 2nd-degree equation is a circle only when coeff x² = coeff y² ≠ 0 and coeff xy = 0.

Parametric form

any point on the circlex² + y² = a² : (a cosθ, a sinθ) · (x−h)²+(y−k)²=a² : (h + a cosθ, k + a sinθ), θ ∈ [0, 2π)

Book Example · L-1 (theory)
Find the locus of the point of intersection of the lines x cosθ + y sinθ = a and x sinθ − y cosθ = b.

Book Example-1 · L-1 (Solved)
Find the equations of the circles of radius 5 that touch the line 3x + 4y − 11 = 0 at the point P(1, 2).

C = (1 ± 5·(3/5), 2 ± 5·(4/5)) = (1 ± 3, 2 ± 4) = (4, 6) or (−2, −2).
(x − 4)² + (y − 6)² = 25 or (x + 2)² + (y + 2)² = 25
Book Example-2 · L-1 (Solved)

⇒ √(h²+k²) = 2a/√3 ⇒ h² + k² = 4a²/3.

P is a variable point on the circle x² + y² + 2gx + 2fy + c = 0; CA, CB are the perpendiculars from the centre C onto the axes. Show the locus of the centroid of △PAB is a circle of radius one-third that of the given circle.

A circle, centre (−2g/3, −2f/3) = centroid of △CAB, radius r/3

Equation of a Circle Under Various Conditions & Intercepts

Circles touching the axes

Intercept made on the axes

for x² + y² + 2gx + 2fy + c = 0x-intercept |AB| = 2√(g² − c) · y-intercept |CD| = 2√(f² − c) · (touches x-axis ⇔ g²=c; both ⇔ c = g² = f²)

Circle through three points & circumcircle of a triangle

  • x² + y² + 2gx + 2fy + c = 0 has three constants — substitute the three points to get three linear equations in g, f, c.
  • Circumcircle of the triangle formed by lines L₁ = L₂ = L₃ = 0: use L₁L₂ + λL₂L₃ + μL₃L₁ = 0 with coeff x² = coeff y² and coeff xy = 0, or find the three vertices and fit a circle.
💡 λ-form for a tangent/axis conditionWhen a circle "touches a line and both axes", take the centre (a, a) and radius a and set the distance from (a,a) to the line equal to a — this gives a quadratic in a (usually two circles).

Position of a Point, Line–Circle Intersection & Tangents

Position of a point & nearest / farthest distance

S₁ = x₁² + y₁² + 2gx₁ + 2fy₁ + cS₁ > 0 outside · S₁ = 0 on · S₁ < 0 inside · min distance = |CP − r|, max distance = CP + r

Line and circle · condition of tangency

  • Perpendicular distance p from the centre to the line versus radius r: p < r secant · p = r tangent · p > r misses. Equivalently substitute y = mx + c into x² + y² = a² and use the discriminant.
chord cut off from y = mx + c by x² + y² = a²length = 2√{(a²(1 + m²) − c²)/(1 + m²)} · tangency (zero chord): c² = a²(1 + m²)

Different forms of the tangent

point / parametric / slope format (x₁,y₁): T = 0 ⇒ xx₁ + yy₁ + g(x+x₁) + f(y+y₁) + c = 0 · at (a cosθ, a sinθ): x cosθ + y sinθ = a · slope m: y = mx ± a√(1 + m²)
tangent of slope m to general circle & from an external pointy + f = m(x + g) ± √(g²+f²−c)·√(1+m²) · from (x₁,y₁): m²(x₁²−a²) − 2mx₁y₁ + (y₁²−a²) = 0 (two tangents)
angle between the two tangents from (x₁,y₁)tan θ = |(m₁ − m₂)/(1 + m₁m₂)| · point of contact of y = mx ± a√(1+m²): (∓am/√(1+m²), ±a/√(1+m²))
💡 Reading the pictureTwo circles touch at (x₁,y₁) ⇔ the tangent (T = 0) to each at that point is the same line. A right angle between the two tangents from P means P lies on the director circle (L-4). From an external point exactly two tangents can be drawn.

L-4

Director Circle

The locus of perpendicular tangents

  • The director circle is the locus of the point from which the two tangents to a circle are perpendicular. If P(h,k) sees the circle under a right angle, then OP² = 2·(radius)².
director circlefor x² + y² = a² : x² + y² = 2a² · for (x−h)²+(y−k)²=a² : (x−h)² + (y−k)² = 2a² · for x²+y²+2gx+2fy+c=0 : (x+g)²+(y+f)² = 2(g²+f²−c)
💡 Why √2Tangents from P touch at Q, R; OQPR is a square of side a (radius), so OP = a√2. The director circle is concentric with radius √2 × r.

Arc AC subtends a right angle at centre O. B on arc AC divides it so that arc AB : arc BC = 1 : 5, and OC = α·OA + β·OB. Find α + √2(√3 − 1)β.
arc AC = 90° split 1:5 ⇒ arc AB = 15°. Take OA = (1,0), OC = (0,1), B = (cos15°, sin15°). (0,1) = α(1,0) + β(cos15°, sin15°) ⇒ β = 1/sin15° = √6 + √2, α = −cot15° = −(2 + √3).
√2(√3−1)(√6+√2) = (√3−1)(2√3+2) = 2(3−1) = 4, so α + 4 = −(2+√3) + 4 = 2 − √3.
2 − √3 → (c)
