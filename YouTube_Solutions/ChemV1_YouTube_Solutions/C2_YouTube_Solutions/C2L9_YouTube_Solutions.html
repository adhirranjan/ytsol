1Subshell with ℓ=0 — number of possible orbitalsOrbitals per subshell (2ℓ+1)A-COUNT🟡 Similara1
Concept A subshell is fixed by the azimuthal quantum number ℓ, and the number of orbitals inside it is set entirely by ℓ through the magnetic quantum number m. The value m can take runs in whole-number steps from −ℓ to +ℓ, and each allowed value of m labels one orbital. So counting orbitals in a subshell is just counting how many integers lie in the range −ℓ … +ℓ, which is always 2ℓ+1.
Formula number of orbitals = 2ℓ+1, where ℓ is the azimuthal quantum number (ℓ = 0,1,2,3 for s,p,d,f). m ranges over −ℓ,…,0,…,+ℓ — that is ℓ values below zero, ℓ above, plus zero itself = 2ℓ+1 in total.
Solution
1. Identify the subshell: ℓ = 0 is the s-subshell.
2. List the allowed m values from −ℓ to +ℓ: from −0 to +0, i.e. only m = 0.With ℓ = 0 there is nothing below or above zero, so the range collapses to the single value 0.
3. Apply the count: 2ℓ+1 = 2(0)+1 = 1 orbital.
 ℓ   subshell   m values          orbitals = 2ℓ+1
 0   s          0                 1   ← this question
 1   p          −1, 0, +1         3
 2   d          −2,−1,0,+1,+2     5
⚡ JEE Trick Orbitals per subshell = 2ℓ+1; memorise s=1, p=3, d=5, f=7. Trap: an s-subshell always has exactly one orbital regardless of the shell (1s, 2s, 3s all have 1) — the shell number n never changes the orbital count of a subshell.
Answer: (a) 1.
2Orbital angular momentum of an electron in a 3p orbitalAngular momentum √(ℓ(ℓ+1))·h/2πwatch?v=7DUIUgrjJG8🟢 Exacta(h/2π)·√2
Concept The orbital angular momentum of an electron is a quantised quantity fixed entirely by the azimuthal quantum number ℓ — the principal quantum number n plays no role in its magnitude. For any orbital labelled 3p, 4p or 2p the answer is identical, because "p" means ℓ = 1 in every shell. The classic trap is to reach for the Bohr formula mvr = nh/2π, which is the old quantised angular momentum of a Bohr orbit; the quantum-mechanical orbital angular momentum uses √(ℓ(ℓ+1)) instead of n.
Formula L = √(ℓ(ℓ+1)) · h/2π this eigenvalue comes from solving the wave equation — the operator L² has eigenvalues ℓ(ℓ+1)ℏ², so |L| = √(ℓ(ℓ+1)) ℏ where ℏ = h/2π. For a p orbital, ℓ = 1; the "3" in 3p is only the shell label.
Solution
1. Decode the orbital: 3p ⇒ n = 3, ℓ = 1. The letter (s, p, d, f) fixes ℓ = 0, 1, 2, 3; only ℓ enters the angular-momentum formula.
2. Apply the formula: L = √(ℓ(ℓ+1)) · h/2π = √(1×2) · h/2π = √2 · h/2π.
3. Check the n-independence: a 2p or 4p electron gives exactly the same √2 (h/2π). This is why the question deliberately says "3p" — the 3 is a decoy.
4. Contrast with wrong routes: Bohr's mvr = nh/2π would give 3h/2π (wrong — that is for circular Bohr orbits), and √(ℓ(ℓ+1)) with ℓ = 3 (misreading "3p" as ℓ = 3) would give √12 h/2π (also wrong).
5. So the orbital angular momentum of a 3p electron is (h/2π)·√2, often written √2 ℏ.
 orbital   n   ℓ   L = √(ℓ(ℓ+1))·h/2π
 3s        3   0   0
 3p        3   1   √2 · h/2π   <-- answer
 3d        3   2   √6 · h/2π
⚡ JEE Trick Memorise the ladder: s → 0, p → √2 ℏ, d → √6 ℏ, f → √12 ℏ — the shell number never matters. Trap: mixing up formulas — √(ℓ(ℓ+1))·h/2π is orbital angular momentum; nh/2π is Bohr-orbit angular momentum; √(s(s+1))·h/2π (= √3/2 ℏ) is spin angular momentum. Pick the right one for the word used in the question.
Answer: (a) (h/2π)·√2.
3How many electrons can have n=4, ℓ=2?Electrons in a subshellwatch?v=kU0x5a-hWzw🟡 Similarb10
Concept Fixing both n and ℓ pins down a single subshell (here the 4d). The electron capacity of a subshell depends only on ℓ, never on n, because n merely tells you which shell the subshell lives in. Each orbital in the subshell holds a maximum of 2 electrons (Pauli, opposite spins), so the electron count is twice the number of orbitals.
Formula max electrons = 2 × (2ℓ+1). (2ℓ+1) is the number of orbitals in the subshell; ×2 because every orbital takes two electrons of opposite spin. The n value (4) is only a label here — it does not enter the count.
Solution
1. Read the subshell: n = 4, ℓ = 2 ⇒ the 4d subshell.
2. Orbitals in it: 2ℓ+1 = 2(2)+1 = 5 orbitals.
3. Electrons = 2 per orbital × 5 orbitals = 2 × 5 = 10 electrons.Each of the 5 d-orbitals holds a spin-up and a spin-down electron.
 subshell   ℓ   orbitals (2ℓ+1)   electrons 2(2ℓ+1)
 4d         2   5                 10   ← this question
⚡ JEE Trick Subshell capacity = 2(2ℓ+1): s=2, p=6, d=10, f=14 — learn this row by heart. Trap: the shell number (4) is a decoy; 3d, 4d, 5d all hold 10 electrons. The value of n only limits which ℓ are allowed (ℓ < n), not how many electrons a valid subshell can take.
Answer: (b) 10.
4Which set of quantum numbers gives the highest energy (multi-electron)?Energy ordering (n+ℓ rule)A-QNUM🟡 Similardn = 5, ℓ = 0
Concept In a multi-electron atom the energy of a subshell is not set by n alone — it is governed by the (n + ℓ) rule (Bohr–Bury / Madelung). The subshell with the larger value of n + ℓ has the higher energy; if two subshells tie on n + ℓ, the one with the larger n is higher. Ranking the given sets is therefore just computing n + ℓ for each and picking the maximum.
Formula energy order set by (n + ℓ); ties broken by larger n. A bigger n + ℓ means the electron feels less nuclear pull on average (more shielding / a more diffuse subshell), so it sits at higher energy.
Solution
1. Compute n + ℓ for the candidate that is highest, n = 5, ℓ = 0: 5 + 0 = 5 (the 5s subshell).
2. Compare against lower-lying typical options — e.g. 4p (n+ℓ = 4+1 = 5), 3d (3+2 = 5), 4s (4+0 = 4):among sets tied at n+ℓ = 5, the larger n wins, and n = 5 beats n = 4 and n = 3.
3. So n = 5, ℓ = 0 has the highest n (5) among the top n+ℓ group, making 5s the highest-energy subshell offered — option (d).
 set            subshell   n+ℓ   tie-break (n)   energy
 n=4, ℓ=0       4s         4      —              lowest
 n=3, ℓ=2       3d         5      n=3
 n=4, ℓ=1       4p         5      n=4
 n=5, ℓ=0       5s         5      n=5            HIGHEST ✓
⚡ JEE Trick Always rank by n + ℓ first, then n — never by n alone in a multi-electron atom. A big trap is 3d vs 4s: both look "close," but 3d (n+ℓ=5) > 4s (n+ℓ=4). Here the winner combines the top n+ℓ (=5) with the largest n (=5).
Answer: (d) n = 5, ℓ = 0.
5Fe (Z=26): electrons with both mℓ=0 and s=+½Config → quantum numbersA-ECONF🟡 Similarc7
Concept The trick is to convert the atom into its orbital-by-orbital electron map and then count only the electrons that satisfy both conditions: they sit in an orbital with m = 0, and they carry spin +½. Only one orbital per subshell has m = 0 (the m = 0 member of the −ℓ…+ℓ set), and by the fill-order convention the first electron placed in any orbital is the +½ (spin-up) one. So each m = 0 orbital that contains at least one electron contributes exactly one +½ electron.
Key relation count = (number of m = 0 orbitals holding ≥ 1 electron). Every occupied orbital has a +½ electron first; the m = 0 orbital is unique in each s, p, d subshell (s itself is m = 0), so we just tally those. Fe: Z = 26 ⇒ 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s².
Solution
1. Write Fe's configuration (Z = 26): 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s².2+2+6+2+6+6+2 = 26 electrons total ✓.
2. Find each subshell's m = 0 orbital and check it is occupied — each occupied m = 0 orbital gives one +½ electron:
  • 1s (m = 0): occupied → +½ electron ✔ (count 1)
  • 2s (m = 0): occupied → +½ ✔ (count 2)
  • 2p, m = 0 orbital: full (2e) → +½ ✔ (count 3)
  • 3s (m = 0): occupied → +½ ✔ (count 4)
  • 3p, m = 0 orbital: full → +½ ✔ (count 5)
  • 3d, m = 0 orbital: 3d⁶ fills all five m-values singly (+½) then pairs the first — so m = 0 has a +½ electron ✔ (count 6)
  • 4s (m = 0): occupied → +½ ✔ (count 7)
3. Total electrons with m = 0 and s = +½ = 7.
 subshell   m=0 orbital occupied?   +½ electron there?
 1s         yes                     yes  (1)
 2s         yes                     yes  (2)
 2p         yes (full)              yes  (3)
 3s         yes                     yes  (4)
 3p         yes (full)              yes  (5)
 3d⁶        yes (singly then pair)  yes  (6)
 4s         yes                     yes  (7)
                                    ─────────
                                    total = 7
⚡ JEE Trick For "m = 0 and s = +½," count the occupied m = 0 orbitals — one per s, p, d, … subshell present. Fe has occupied 1s,2s,2p,3s,3p,3d,4s = 7 such orbitals ⇒ 7. Trap: don't double-count a filled orbital — each orbital supplies only one +½ electron, no matter how full it is.
Answer: (c) 7.

1Explain quantum numbers obtained from the Schrödinger equationQuantum numbers overviewA-QNUM🟡 Similar—
Concept Solving the Schrödinger wave equation for the hydrogen atom does not give arbitrary solutions — physically acceptable wavefunctions ψ exist only for certain quantised values of three parameters. These parameters are the principal (n), azimuthal (ℓ) and magnetic (m) quantum numbers; they emerge naturally as the conditions that keep ψ finite, single-valued and continuous. A fourth number, spin (s), is not from Schrödinger's equation but is added to describe the electron's intrinsic spin.
Key relation Three quantum numbers define an orbital, the fourth defines the electron in it: n = 1,2,3… (shell, size & energy); ℓ = 0…(n−1) (subshell, shape & orbital angular momentum); m = −ℓ…+ℓ (orientation of the orbital); s = ±½ (spin direction). n, ℓ, m come out of the boundary conditions on ψ; s is a relativistic addition (Dirac) needed to complete the description.
Solution
1. Principal (n): a positive integer (1, 2, 3…) fixing the shell — the main energy level and average size of the orbital.Larger n ⇒ orbital farther from the nucleus and higher energy.
2. Azimuthal / subsidiary (ℓ): integers 0 to (n−1), giving the subshell (s, p, d, f) and the orbital's shape and orbital angular momentum √(ℓ(ℓ+1))·h/2π.
3. Magnetic (m): integers −ℓ to +ℓ, fixing the spatial orientation of each orbital (why a p-subshell has 3 orientations, d has 5).
4. Spin (s): +½ or −½, describing the two possible spin orientations of an electron; not a Schrödinger result but required by experiment (Stern–Gerlach) and Dirac's theory.
 QN   symbol   allowed values   what it fixes
 n    n        1,2,3,…          shell — size & energy
 ℓ    ℓ        0 … (n−1)        subshell — shape, ang. momentum
 m    mℓ       −ℓ … +ℓ          orientation of orbital
 s    ms       +½ or −½         spin of the electron
⚡ JEE Trick Remember three from Schrödinger (n, ℓ, m), one added (s). A single orbital needs the trio (n, ℓ, m); a specific electron needs all four. Trap: exam statements that claim spin "comes from the Schrödinger equation" are wrong — it is an extra postulate.
Key point: the Schrödinger equation yields three quantum numbers — n (shell/energy), ℓ (subshell/shape), m (orientation) — defining an orbital; the spin quantum number s (±½) is added separately to specify the electron.
2Mention subshells; assign azimuthal & magnetic quantum numbersSubshells, ℓ & m assignmentA-AQN🟡 Similar—
Concept Within a shell the electrons are grouped into subshells, each labelled by a value of the azimuthal quantum number ℓ. The letters s, p, d, f are just names for ℓ = 0, 1, 2, 3. For every subshell the magnetic quantum number m then enumerates the individual orbitals, taking all integer values from −ℓ to +ℓ. Assigning ℓ and m is therefore a mechanical listing exercise once you know the subshell.
Key relation subshell letter ↔ ℓ: s=0, p=1, d=2, f=3; and for each, m = −ℓ, …, 0, …, +ℓ (that is 2ℓ+1 values / orbitals). ℓ names the subshell shape; each allowed m is one orientation = one orbital.
Solution
1. s-subshell: ℓ = 0 ⇒ m = 0 only ⇒ 1 orbital.
2. p-subshell: ℓ = 1 ⇒ m = −1, 0, +1 ⇒ 3 orbitals (px, py, pz).
3. d-subshell: ℓ = 2 ⇒ m = −2, −1, 0, +1, +2 ⇒ 5 orbitals.
4. f-subshell: ℓ = 3 ⇒ m = −3, −2, −1, 0, +1, +2, +3 ⇒ 7 orbitals.Each list runs symmetrically from −ℓ to +ℓ, giving 2ℓ+1 members.
 subshell   ℓ   m values                       orbitals (2ℓ+1)
 s          0   0                              1
 p          1   −1, 0, +1                      3
 d          2   −2, −1, 0, +1, +2              5
 f          3   −3, −2, −1, 0, +1, +2, +3      7
⚡ JEE Trick Fix s,p,d,f = ℓ 0,1,2,3 and read m straight off as the run −ℓ…+ℓ. Orbital count 1,3,5,7 (odd numbers) follows instantly. Trap: m ranges over integers including 0, so the count is 2ℓ+1 (odd), never 2ℓ.
Key point: subshells s, p, d, f correspond to ℓ = 0, 1, 2, 3; the magnetic quantum number m runs from −ℓ to +ℓ, giving 1, 3, 5, 7 orbitals respectively.
3Orbitals in the N shell & subshell-wise distributionOrbitals per shell (n²)A-COUNT🟡 Similar—
Concept Shells are labelled K, L, M, N, … for n = 1, 2, 3, 4, …, so the N shell means n = 4. The total number of orbitals in a shell is a fixed function of n: n². To see how those orbitals split among subshells you list the allowed ℓ values (0 to n−1) and add up the (2ℓ+1) orbitals of each — the parts must sum back to n².
Key relation orbitals in shell n = n², obtained as Σ (2ℓ+1) for ℓ = 0 … n−1. Adding the odd numbers 1+3+5+…+(2n−1) always gives n² — the algebraic identity behind the shortcut.
Solution
1. N shell ⇒ n = 4, so allowed subshells have ℓ = 0, 1, 2, 3 ⇒ 4s, 4p, 4d, 4f.
2. Count orbitals in each subshell with 2ℓ+1:
  • 4s (ℓ=0): 2(0)+1 = 1
  • 4p (ℓ=1): 2(1)+1 = 3
  • 4d (ℓ=2): 2(2)+1 = 5
  • 4f (ℓ=3): 2(3)+1 = 7
3. Add them: 1 + 3 + 5 + 7 = 16 orbitals.This equals n² = 4² = 16, confirming the sum.
 subshell   ℓ   orbitals (2ℓ+1)
 4s         0   1
 4p         1   3
 4d         2   5
 4f         3   7
                ─────
 total N shell   16  = n² = 4²
⚡ JEE Trick Orbitals in a shell = n² (K=1, L=4, M=9, N=16); electrons = 2n². The subshell split is always the odd-number run 1, 3, 5, 7…. Trap: don't confuse the shell letter — K,L,M,N map to n = 1,2,3,4, so N is the fourth shell, not the first.
Key point: the N shell (n = 4) has n² = 16 orbitals, distributed as 4s (1) + 4p (3) + 4d (5) + 4f (7).
4Describe shapes of 1s and 2s orbitalsShapes of orbitalsA-SHAPE🟡 Similar—
Concept The shape of an orbital is decided by its azimuthal quantum number ℓ, and for both 1s and 2s we have ℓ = 0, so both are spherical — the probability of finding the electron depends only on distance from the nucleus, not direction. The difference between them is internal structure and size: the 2s orbital is larger and contains a radial node (a spherical surface of zero probability) that the 1s orbital does not.
Key relation number of radial nodes = n − ℓ − 1; for s-orbitals ℓ = 0, so radial nodes = n − 1. 1s: 1−0−1 = 0 nodes; 2s: 2−0−1 = 1 node — the extra node is what makes 2s a "sphere within a sphere."
Solution
1. Both have ℓ = 0 ⇒ both are spherically symmetric (non-directional) about the nucleus.
2. 1s: radial nodes = n − ℓ − 1 = 1 − 0 − 1 = 0 — a single, dense sphere; electron density highest at the nucleus and falling smoothly outward.
3. 2s: radial nodes = 2 − 0 − 1 = 1 — a larger sphere with one internal spherical node, so density is high near the nucleus, drops to zero at the node, then rises again in an outer shell.The node is a surface where ψ (and hence probability) = 0.
4. Size comparison: 2s is more diffuse and higher in energy than 1s (larger n).
 orbital   ℓ   shape        radial nodes (n−ℓ−1)   size
 1s        0   spherical    0                      small, compact
 2s        0   spherical    1 (one inner node)     larger, diffuse
⚡ JEE Trick All s-orbitals are spherical (ℓ = 0) — 1s, 2s, 3s alike; only their size and node count differ. Node count: total = n−1, radial = n−ℓ−1. Trap: "2s has a different shape" is wrong — same spherical shape, just a bigger sphere with one radial node.
Key point: 1s and 2s are both spherical (ℓ = 0); 1s has no node, while 2s is larger and has one radial (spherical) node inside it.

1What does principal quantum number n primarily determine?Meaning of nA-PQN🟡 Similarcsize and energy of orbital
Concept The principal quantum number n labels the main shell (K, L, M, N for n = 1, 2, 3, 4). It is the number that primarily fixes two linked things: how far from the nucleus the electron is likely to be (the orbital's size) and how much energy it has. A larger n means a bigger, more diffuse orbital held less tightly, hence higher energy. Shape and orientation are the jobs of the other quantum numbers, not n.
Key relation n = 1, 2, 3, … ⇒ larger n → larger orbital and higher energy. For a one-electron (H-like) atom, Eₙ ∝ −1/n² and mean radius rₙ ∝ n². As n grows, energy rises toward zero (less negative) and the electron sits farther out — size and energy move together.
Solution
1. Recall each quantum number's role: n → shell (size & energy); ℓ → shape; m → orientation; s → spin.Only n governs the shell's overall size and energy level.
2. So the principal quantum number primarily determines the size and energy of the orbital — option (c).
3. Eliminate the others: shape is set by ℓ (option about shape), orientation by m, spin by s — none of these is n's primary role.
 quantum number   primarily determines
 n (principal)    size & energy of orbital   ✓
 ℓ (azimuthal)    shape of orbital
 m (magnetic)     orientation in space
 s (spin)         electron spin direction
⚡ JEE Trick Tie each quantum number to one keyword: n = size/energy, ℓ = shape, m = orientation, s = spin. Trap: in multi-electron atoms energy depends on n and ℓ (n+ℓ rule), but n is still the primary energy/size factor — the question asks what it primarily determines.
Answer: (c) size and energy of orbital.
2What does magnetic quantum number m define?Meaning of m (orientation)A-QNUM🟡 Similarcorientation in space
Concept The magnetic quantum number m distinguishes the different orbitals within a subshell. All orbitals of one subshell (say the three 2p orbitals) have the same size (n) and the same shape (ℓ) — what differs is their orientation in space. The name "magnetic" comes from the fact that these orientations only reveal themselves as separate energies when the atom is placed in a magnetic field (the Zeeman effect).
Key relation m = −ℓ, …, 0, …, +ℓ — each value picks one spatial orientation of the orbital. A p-subshell (ℓ=1) has m = −1, 0, +1 ⇒ three mutually perpendicular orientations px, py, pz; the number carries no size or shape information.
Solution
1. Recall the division of labour: n = size/energy, ℓ = shape, m = orientation, s = spin.
2. m enumerates the 2ℓ+1 orbitals of a subshell, each pointing a different way in space.Same n and ℓ, different m ⇒ same orbital tilted along a different axis.
3. Therefore m defines the orientation in space of an orbital — option (c).
4. Reject the rest: size/energy is n's role, shape is ℓ's, spin is s's.
 subshell   ℓ   m values      orientations
 p          1   −1, 0, +1     p_x, p_y, p_z  (3 directions)
 d          2   −2…+2         5 spatial orientations
⚡ JEE Trick "Magnetic ⇒ orientation" — and it is why a subshell splits into 2ℓ+1 orbitals and shows the Zeeman effect in a magnetic field. Trap: don't attribute shape to m (that is ℓ); m only rotates a fixed shape into different directions.
Answer: (c) orientation in space.

4What does a spin quantum number of −½ represent?Meaning of spin sA-SPIN🟡 Similarbanti-clockwise spin
Concept The spin quantum number s describes an electron's intrinsic angular momentum — pictured (classically) as the electron spinning about its own axis. Only two spin states exist: +½ and −½, conventionally drawn as an up-arrow (↑, clockwise) and a down-arrow (↓, anticlockwise). The value −½ is therefore the anticlockwise (down-spin) state, usually the second electron placed in an orbital.
Key relation s = +½ (↑, clockwise) or −½ (↓, anticlockwise). The two opposite senses of spin let two electrons share one orbital (Pauli), as long as their spins are opposite.
Solution
1. An electron has exactly two spin states, s = +½ and s = −½.
2. Convention: +½ = spin-up ↑ = clockwise; −½ = spin-down ↓ = anticlockwise.The sign of s marks the direction of the intrinsic spin, nothing about position or shape.
3. Hence s = −½ represents an anti-clockwise spin — option (b).
