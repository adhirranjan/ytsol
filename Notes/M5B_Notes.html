L-1

Product ↔ Sum & Sum ↔ Product

  • Two mirror-image families of formulae: one turns a product of sines/cosines into a sum or difference, the other turns a sum/difference back into a product.
  • Both come straight from the compound-angle formulae for sin(A±B) and cos(A±B).
  • The link between them is the substitution C = A+B, D = A−B, i.e. A = (C+D)/2, B = (C−D)/2.
product → sum/difference2 sinA cosB = sin(A+B) + sin(A−B) 2 cosA sinB = sin(A+B) − sin(A−B) 2 cosA cosB = cos(A+B) + cos(A−B) 2 sinA sinB = cos(A−B) − cos(A+B)
sum/difference → productsinC + sinD = 2 sin((C+D)/2) cos((C−D)/2) sinC − sinD = 2 sin((C−D)/2) cos((C+D)/2) cosC + cosD = 2 cos((C+D)/2) cos((C−D)/2) cosC − cosD = −2 sin((C+D)/2) sin((C−D)/2)
Where the formulae come from
Write the two compound-angle sines: sin(A+B) = sinA cosB + cosA sinB and sin(A−B) = sinA cosB − cosA sinB. Adding gives 2 sinA cosB = sin(A+B) + sin(A−B); subtracting gives 2 cosA sinB = sin(A+B) − sin(A−B). The same trick on cos(A±B) = cosA cosB ∓ sinA sinB gives the two cosine products. For the reverse family, put C = A+B, D = A−B so that A = (C+D)/2 and B = (C−D)/2, and rename — that is exactly how sinC ± sinD and cosC ± cosD arise.
💡 The "½" trickTo collapse a bare product such as cos75°cos15°, multiply and divide by 2: cos75°cos15° = ½(2 cos75°cos15°) = ½{cos(75+15) + cos(75−15)}. Always create the leading 2 first.
⚠ Sign trap2 sinA sinB = cos(A−B) − cos(A+B) (difference first) and cosC − cosD = −2 sin((C+D)/2) sin((C−D)/2) — a lost minus sign here is the most common mistake in identity proofs.

Book Example · L-1
Prove that 2 cos(π/13) cos(9π/13) + cos(3π/13) + cos(5π/13) = 0.
2 cosA cosB = cos(A+B) + cos(A−B): the first term = cos(9π/13 + π/13) + cos(9π/13 − π/13) = cos(10π/13) + cos(8π/13).
LHS = cos(10π/13) + cos(8π/13) + cos(3π/13) + cos(5π/13) = cos(π − 3π/13) + cos(π − 5π/13) + cos(3π/13) + cos(5π/13).
Using cos(π − θ) = −cosθ: = −cos(3π/13) − cos(5π/13) + cos(3π/13) + cos(5π/13).
= 0 (proved)
Book Example · L-1
Prove that sin10° sin30° sin50° sin70° = 1/16.
Pull out sin30° = ½: LHS = ½ (sin10° sin50°) sin70° = ¼ (2 sin10° sin50°) sin70°.
2 sinA sinB = cos(A−B) − cos(A+B): = ¼[(cos40° − cos60°) sin70°] = ¼[sin70°cos40° − ½ sin70°].
= ⅛[2 sin70°cos40° − sin70°] = ⅛[sin110° + sin30° − sin70°] (using 2 sinA cosB = sin(A+B) + sin(A−B)).
sin110° = sin(180°−70°) = sin70°, so = ⅛[sin70° + ½ − sin70°] = ⅛ · ½.
= 1/16 (proved)
Book Example · L-1
Prove that 4 cos12° cos48° cos72° = cos36°.
Group as 2(2 cos12° cos48°) cos72° = 2{cos60° + cos36°} cos72° = 2 cos60° cos72° + 2 cos36° cos72°.
= 2·½·cos72° + {cos(36°+72°) + cos(72°−36°)} = cos72° + cos108° + cos36°.
cos108° = cos(180°−72°) = −cos72°, so = cos72° − cos72° + cos36°.

L-2

Applications & Conditional Identities

  • Same four formula families — now used to prove identities, evaluate awkward products, and handle conditional problems (e.g. given cotα, secβ find tan(α+β)).
  • Standard supporting tools: cos(π−θ) = −cosθ, sin(180°−θ) = sinθ, and the tangent/cotangent split of a single fraction.
key supporting identitysin(B−C)/(cosB·cosC) = (sinB cosC − cosB sinC)/(cosB cosC) = tanB − tanC
The tan-splitting trick
A fraction like sin(B−C)/(cosB cosC) expands the numerator with sin(B−C) = sinB cosC − cosB sinC and then cancels: each term becomes a single tangent, giving tanB − tanC. When three such cyclic terms are added they telescope to zero (see Example L-2 below) — this is the fastest route through most "sum-of-fractions = 0" proofs.
💡 Conditional tan(α+β)Use tan(α+β) = (tanα + tanβ)/(1 − tanα·tanβ). Fix the sign of each ratio from the quadrant first (e.g. β in Q2 ⇒ tanβ < 0), then read off the quadrant of α+β from the sum of the angle ranges.
★ Reduce, don't expandTo prove telescoping chains such as sinx + sin3x + sin5x + sin7x, pair the outer and inner terms — (sin7x+sinx) and (sin5x+sin3x) share the factor sin4x, which then factors out cleanly.
Worked examples from the module
Book Example · L-2
If cotα = ½, secβ = −5/3, where π < α < 3π/2 and π/2 < β < π, find tan(α+β) and the quadrant in which α+β lies.
cotα = ½ ⇒ tanα = 2. β is in Q2 so tanβ < 0: 1 + tan²β = sec²β ⇒ tanβ = −√(25/9 − 1) = −√(16/9) = −4/3.
tan(α+β) = (tanα + tanβ)/(1 − tanα tanβ) = (2 − 4/3)/(1 − 2·(−4/3)) = (2/3)/((3+8)/3) = (2/3)/(11/3).
Ranges add: π < α < 3π/2 and π/2 < β < π ⇒ 3π/2 < α+β < 5π/2; tan is +ve in Q1 & Q3, and 2/11 > 0.
tan(α+β) = 2/11; α+β lies in the first quadrant.
Book Example · L-2
Prove that tan75° + cot75° = 4.
tan75° = (√3+1)/(√3−1), so cot75° = 1/tan75° = (√3−1)/(√3+1).
Sum = [(√3+1)² + (√3−1)²]/[(√3−1)(√3+1)] = [(3+1+2√3) + (3+1−2√3)]/(3−1) = 8/2.
= 4 (proved)
Book Example · L-2
Prove that cos(3π/4 + x) − cos(3π/4 − x) = −√2 sinx.
Expand both: [cos(3π/4)cosx − sin(3π/4)sinx] − [cos(3π/4)cosx + sin(3π/4)sinx]. With cos(3π/4) = −1/√2, sin(3π/4) = 1/√2:
= (−1/√2 cosx − 1/√2 sinx) − (−1/√2 cosx + 1/√2 sinx) = −1/√2 sinx − 1/√2 sinx = −2/√2 sinx.
= −√2 sinx (proved)
Book Example · L-2
Prove that sin(B−C)/(cosB cosC) + sin(C−A)/(cosC cosA) + sin(A−B)/(cosA cosB) = 0.
Each fraction splits: sin(B−C)/(cosB cosC) = (sinB cosC − cosB sinC)/(cosB cosC) = tanB − tanC.
Summing cyclically: (tanB − tanC) + (tanC − tanA) + (tanA − tanB) — every tangent cancels.
= 0 (proved)
Book Example · L-2
Prove that cos18° − sin18° = √2 sin27°.
Write sin18° = cos(90°−18°) = cos72°, so LHS = cos18° − cos72°.
cosC − cosD = 2 sin((C+D)/2) sin((D−C)/2): = 2 sin((18°+72°)/2) sin((72°−18°)/2) = 2 sin45° sin27° = 2·(1/√2) sin27°.
= √2 sin27° (proved)
Book Example · L-2
Prove that sinx + sin3x + sin5x + sin7x = 4 cosx cos2x sin4x.
Pair outer + inner: (sin7x + sinx) + (sin5x + sin3x) = 2 sin4x cos3x + 2 sin4x cosx = 2 sin4x (cos3x + cosx).
cos3x + cosx = 2 cos((3x+x)/2) cos((3x−x)/2) = 2 cos2x cosx, so = 2 sin4x · 2 cos2x cosx.
= 4 cosx cos2x sin4x (proved)
