Concept For a triangle inscribed in a circle centred at the origin, the orthocenter is the vector sum of the vertices. As C moves on the circle, the orthocenter traces a translate of that circle.
Formula H = A + B + C (circumcentre O at the origin). Euler line: H = 3G and G = (A+B+C)/3 when the circumcentre is the origin.
Solution
1. Circumcentre of ABC is the centre of x2+y2=1, i.e. O(0,0), radius 1. All three vertices lie on this circle.
2. Write C = (cosθ, sinθ). Parametrise the moving vertex.
3. H = A + B + C = (1 + cosθ, 1 + sinθ). Vector-sum rule for the orthocenter when O is the origin.
4. Let H = (x, y): x − 1 = cosθ, y − 1 = sinθ. Isolate the trig terms.
5. Square and add: (x−1)2 + (y−1)2 = cos2θ + sin2θ = 1. Eliminate θ.
6. Expand: x2 + y2 − 2x − 2y + 2 = 1 ⇒ x2 + y2 − 2x − 2y + 1 = 0. The unit circle shifted to centre (1,1).
7. Sanity check: take C = (−1,0). Triangle A(1,0), B(0,1), C(−1,0): H = (1,0)+(0,1)+(−1,0) = (0,1), and (0−1)2 + (1−1)2 = 1 holds. Indeed the angle at B is 90° (BA ⊥ BC), so H = B = (0,1). A right-angled triangle has its orthocenter at the right-angle vertex, confirming the formula.

Concept The relation x3 + y3 + 3xy − 1 = 0 matches the identity for a3+b3+c3−3abc with a = x, b = y, c = −1.
Formula a3 + b3 + c3 − 3abc = (a+b+c)(a2+b2+c2−ab−bc−ca). The second bracket equals (1/2)[(a−b)2+(b−c)2+(c−a)2], a sum of squares.
Solution
1. Put a = x, b = y, c = −1: abc = −xy, so −3abc = +3xy and c3 = −1. Then a3+b3+c3−3abc = x3+y3−1+3xy.
2. So the given equation is (x + y − 1)(x2 + y2 + 1 − xy + x + y) = 0. Substitute into the identity.
3. Factor 1: x + y − 1 = 0 is a straight line. Real locus, infinitely many points.
4. Factor 2 = (1/2)[(x−y)2 + (y+1)2 + (x+1)2]. Write it as a sum of three squares.
5. A sum of squares is zero only if x = y, y = −1 and x = −1. Each square must vanish separately.
6. So factor 2 gives just the single point (−1, −1). It is not on the line, since −1−1−1 = −3 ≠ 0.
