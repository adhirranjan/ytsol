1Which statement about a function is TRUE?Function definitionA-RFN🟡 SimilarbA function assigns to every element of A exactly one element of B (each input has a unique image).
Concept A function f:A→B is a special kind of relation. Being a relation (any set of ordered pairs) is not enough — a function must satisfy two extra conditions: (i) every element of the domain A must be used (each input has an image), and (ii) each input has exactly one image (no input maps to two different outputs). Outputs may repeat (many-to-one is allowed), but inputs may never split.
Key relation f:A→B is a function ⇔ ∀ a∈A, ∃! b∈B with (a,b)∈f. "∃!" means "exists exactly one" — the uniqueness of the image is the heart of the definition. Equivalently: no two ordered pairs share the same first coordinate.
Solution
1. Test each candidate statement against the two rules — every input used, each input a single output.
2. Reject "one input may have two images" — that is the one thing a function forbids (it would be a one-to-many relation, not a function).e.g. {(1,a),(1,b)} fails: input 1 has two images.
3. Accept "two different inputs may share the same image" — this is many-to-one and is perfectly valid.e.g. a constant function f(x)=5 sends every input to one output.
4. So the TRUE statement is the one asserting: each element of A is assigned exactly one element of B.
 relation            input→output           function?
 {(1,a),(2,b),(3,a)} each input one image   YES (a repeats, fine)
 {(1,a),(1,b)}       1 has two images       NO  (input splits)
 {(1,a),(2,b)} on A={1,2,3}  3 unused       NO  (3 has no image)
⚡ JEE Trick Read a function left-to-right: each first-coordinate appears once and only once. Repeated outputs are legal; repeated inputs are fatal. Trap: a statement claiming "no two elements can have the same image" describes a one-one function, which is a stricter property — not the definition of a function itself.
Answer: A function assigns to every element of A exactly one element of B (each input has a unique image; outputs may repeat).
2A={a,e,i}, B={2,4,6}, f(a)=2,f(e)=4,f(i)=6 — domain & rangeDomain & rangeA-RFN🟡 SimilarbDomain = {a, e, i}; Range = {2, 4, 6} (= co-domain B, so f is onto).
Concept For a function given as an explicit list of arrows f:A→B, three sets must be told apart. The domain is the whole starting set A (every input actually used). The co-domain is the whole target set B (the pool of allowed outputs). The range is only the part of B that is genuinely hit — the set of images {f(a) : a∈A}. Range is always a subset of the co-domain; here they happen to coincide.
Key relation Domain = A ; Co-domain = B ; Range = {f(a) : a∈A} ⊆ B. Collect the outputs the mapping actually produces; that collection is the range.
Solution
1. Domain = the input set = A = {a, e, i} (all three inputs have an assigned image).
2. List the images produced: f(a)=2, f(e)=4, f(i)=6.Read each arrow and record its output.
3. Range = set of these images = {2, 4, 6}.
4. Compare with co-domain B = {2,4,6}: every element of B is used, so here Range = Co-domain (the function is onto).When range equals co-domain the function is surjective (onto).
 element   image        set membership
 a    →    2            domain {a,e,i}   range {2,4,6}
 e    →    4            co-domain B = {2,4,6}
 i    →    6            range = co-domain ⇒ onto
⚡ JEE Trick Domain = every first-coordinate; Range = every second-coordinate — just read the pairs off. Range ⊆ co-domain always; they are equal only when the map is onto. Trap: do not report B as the range by default — the range is only the outputs actually attained, which can be a strict subset of B.
Answer: Domain = {a, e, i}; Range = {2, 4, 6} (= co-domain B, so f is onto).
3Domain of f(x)=(2x+3)/(x−1)Domain (rational)A-DOMR🟡 SimilaraDomain = ℝ − {1}, i.e. (−∞, 1) ∪ (1, ∞).
Concept The domain of a real function is the set of all x for which the formula produces a genuine real number. For a rational function (a ratio of polynomials) the only thing that can go wrong is division by zero: the numerator is harmless, but wherever the denominator equals 0 the expression is undefined. So finding the domain reduces to "all reals except the zeros of the denominator."
Formula domain of P(x)/Q(x) = { x∈ℝ : Q(x) ≠ 0 }. A fraction is defined precisely when its denominator is non-zero; dividing by 0 has no meaning. So set the denominator equal to 0, solve, and remove those x.
Solution
1. Identify the denominator: Q(x) = x − 1.The numerator 2x+3 is a polynomial, defined for every real x, so it never restricts the domain.
2. Find where it vanishes: x − 1 = 0 ⇒ x = 1.
3. Exclude that point: the function is defined for every real x except x = 1.
4. Write the domain: ℝ − {1} = (−∞, 1) ∪ (1, ∞).A single point is removed, splitting the real line into two open rays.
 x        x − 1     f(x)=(2x+3)/(x−1)
 0        −1        3/−1 = −3      defined
 1         0        5/0            UNDEFINED  ✗
 2         1        7/1 = 7        defined
⚡ JEE Trick For any rational function, domain = ℝ minus the roots of the denominator — never touch the numerator. Set denominator = 0, solve, delete those points. Trap: don't cancel common factors before finding the domain — even a factor that cancels still forbids its x-value (a removable "hole" is still outside the domain).
Answer: Domain = ℝ − {1}, i.e. (−∞, 1) ∪ (1, ∞).
4Curve C: y=√(x−2) — function? domain?Domain (root) + VLTA-DOMS🟡 SimilarbYes, C is a function; domain = [2, ∞).
Concept Two separate questions are packed together. Is it a function? The radical sign √ denotes the principal (non-negative) square root, so each admissible x gives exactly one y — it passes the vertical-line test, hence it is a function. What is its domain? A real square root exists only when the thing under the root (the radicand) is ≥ 0, so we solve that inequality.
Formula √(g(x)) is real ⇔ g(x) ≥ 0; and the symbol √ returns a single non-negative value. Squaring can never give a negative, so a negative radicand has no real root; and choosing the +root makes the output unique.
Solution
1. Function test: for each x, √(x−2) gives one non-negative value only (principal root), so no vertical line meets the curve twice ⇒ yes, C is a function.y=±√ would fail, but the bare √ symbol takes only the + branch.
2. Domain condition: radicand ≥ 0 ⇒ x − 2 ≥ 0.
3. Solve: x ≥ 2.
4. Domain = [2, ∞); the range (outputs) is y ≥ 0, i.e. [0, ∞).At x=2, y=0; as x grows, √(x−2) grows without bound.
 x      x − 2     y = √(x−2)
 1       −1       √(−1)   undefined ✗
 2        0       0       defined  (start point)
 6        4       2       defined
 ⇒ domain: x ≥ 2  =  [2, ∞)
⚡ JEE Trick Plain √ (radical symbol) ⇒ single non-negative output ⇒ always a function; only "y² = …" or "y = ±√…" breaks the function property. For the domain, set radicand ≥ 0 — remember the boundary is included (≥, closed bracket) because √0 = 0 is perfectly valid. Trap: writing an open interval (2, ∞) wrongly drops the valid point x = 2.
Answer: Yes, C is a function; domain = [2, ∞) (with range [0, ∞)).
5Domain of f(x)=√(x−1)/(x²−4)Domain (root+fraction)A-DOMALL🟡 Similarcx > 1, x ≠ 2 ⚠
Concept When a formula mixes a square root and a denominator, each imposes its own restriction and the domain is the intersection of both. The root needs its radicand ≥ 0; the fraction needs its denominator ≠ 0. Handle them separately, then keep only the x that satisfy every condition simultaneously.
Formula √(x−1) real ⇔ x−1 ≥ 0 and x²−4 ≠ 0. The radical demands a non-negative inside; the denominator must avoid zero. Domain = (set from root) ∩ (set from denominator).
Solution
1. Root condition: x − 1 ≥ 0 ⇒ x ≥ 1, giving [1, ∞).
2. Denominator condition: x² − 4 ≠ 0 ⇒ (x−2)(x+2) ≠ 0 ⇒ x ≠ 2 and x ≠ −2.Factor the difference of squares; either factor being 0 makes the whole denominator 0.
3. Intersect: start with x ≥ 1. The value x = −2 is already excluded (it is < 1), so only x = 2 must be deleted from [1, ∞).
4. Domain = [1, ∞) with x = 2 removed = [1, 2) ∪ (2, ∞).
 condition        allowed set
 x − 1 >= 0       [1, infinity)
 x != 2, x != -2  R \ {-2, 2}
 --------------   ---------------------
 intersection     [1, 2) U (2, infinity)   (-2 is below 1, irrelevant)
⚡ JEE Trick Combine domain rules by intersection: list each condition's set, then overlap. A restriction that lands outside an already-tighter set (here x ≠ −2, but the root already forces x ≥ 1) can be ignored. Trap: don't forget x = 2 sits inside [1, ∞), so it genuinely punches a hole — the answer is two pieces, not one interval.
Answer: Domain = [1, 2) ∪ (2, ∞).
6If f(x)=x+1/x, prove [f(x)]³=f(x³)+3f(1/x)Function identitywatch?v=w4fCb0XVWqw🟢 Exact—
Concept A functional identity is proved by computing both sides in terms of x and showing they collapse to the same expression. Here f(x)=x+1/x has a special self-symmetry: replacing x by 1/x returns the same value, f(1/x)=1/x+x=f(x). The whole proof rests on the binomial cube of a two-term sum and on spotting that the "cross terms" of the cube are exactly 3(x+1/x). The trap is trying to expand f(x³) — it needs no expansion at all; it is simply x³+1/x³ by substitution.
Formula (a+b)³ = a³+b³+3ab(a+b) the grouped form of the binomial cube — it keeps a³+b³ together, which is precisely what f(x³) supplies. With a=x, b=1/x the product ab=x·(1/x)=1, so the cross term simplifies drastically.
Solution
1. Write down the three pieces by direct substitution: f(x)=x+1/x, f(x³)=x³+1/x³, f(1/x)=(1/x)+1/(1/x)=1/x+x. note f(1/x)=f(x) — the function is symmetric under x↔1/x.
2. Cube the left side with the grouped identity: [f(x)]³=(x+1/x)³=x³+(1/x)³+3·x·(1/x)·(x+1/x).
3. Simplify the product: x·(1/x)=1, so [f(x)]³=x³+1/x³+3(x+1/x). Cross term = 3(x+1/x).
4. Identify each cluster: x³+1/x³=f(x³) and x+1/x=f(1/x) (by step 1). Hence [f(x)]³=f(x³)+3f(1/x).
5. Sanity check with x=2: f(2)=2.5, LHS=2.5³=15.625; f(8)=8+1/8=8.125, f(1/2)=2.5, RHS=8.125+3(2.5)=15.625 ✓. a single numeric spot-check catches algebra slips instantly.
 piece        value
 f(x)         x + 1/x
 [f(x)]^3     x^3 + 1/x^3 + 3(x + 1/x)
 f(x^3)       x^3 + 1/x^3
 3 f(1/x)     3(x + 1/x)
 sum          x^3 + 1/x^3 + 3(x + 1/x)   <-- answer (LHS = RHS, proved)
⚡ JEE Trick For f(x)=x+1/x always use (a+b)³=a³+b³+3ab(a+b) with ab=1 — the cube of x+1/x is always x³+1/x³+3(x+1/x), no long expansion needed. Trap: students misread f(1/x) as 1/f(x); it is not — for this f, f(1/x)=f(x), which is exactly why the identity can also be written [f(x)]³=f(x³)+3f(x).
Answer: Proved — [f(x)]³ = x³+1/x³+3(x+1/x) = f(x³)+3f(1/x).
7f(x)=(x−1)/(x+1), prove f(2x)=(3f(x)+1)/(f(x)+3)Function identitywatch?v=XTUrbH7_Sxo🟢 Exact—
Concept To prove an identity of the form f(2x)=expression in f(x), the clean route is to compute the right-hand side symbolically: substitute t=f(x)=(x−1)/(x+1) into (3t+1)/(t+3), put everything over the common denominator (x+1), and watch the fraction telescope down to (2x−1)/(2x+1), which is exactly f(2x). The trap is trying to go the other way (start from f(2x) and force f(x) into it) — that direction needs inverting the function and is messier.
Formula f(2x) = (2x−1)/(2x+1) by direct substitution, and (3f(x)+1)/(f(x)+3) is the target. both numerator and denominator of the target pick up the same factor 1/(x+1), which cancels — that cancellation is the engine of the proof.
Solution
1. Set t=f(x)=(x−1)/(x+1), with x≠−1 so t is defined.
2. Build the numerator: 3t+1 = [3(x−1)+(x+1)]/(x+1) = (3x−3+x+1)/(x+1) = (4x−2)/(x+1) = 2(2x−1)/(x+1).
3. Build the denominator: t+3 = [(x−1)+3(x+1)]/(x+1) = (x−1+3x+3)/(x+1) = (4x+2)/(x+1) = 2(2x+1)/(x+1).
4. Divide: (3t+1)/(t+3) = [2(2x−1)/(x+1)] ÷ [2(2x+1)/(x+1)] = (2x−1)/(2x+1). the factor 2/(x+1) is common to top and bottom, so it cancels completely.
5. Compare with the left side: f(2x)=(2x−1)/(2x+1) — identical. Identity proved (valid for x≠−1, x≠−1/2, i.e. wherever both sides exist).
6. Numeric check, x=1: f(2)=(2−1)/(2+1)=1/3; f(1)=0, so RHS=(0+1)/(0+3)=1/3 ✓.
 t = f(x) = (x-1)/(x+1)
 3t+1 = 2(2x-1)/(x+1)
 t+3  = 2(2x+1)/(x+1)
 ratio = (2x-1)/(2x+1) = f(2x)   <-- answer (identity proved)
⚡ JEE Trick For any Möbius (linear-fractional) function, expressions like (af(x)+b)/(cf(x)+d) are again Möbius in x — so combine over one denominator and expect a clean cancellation. Trap: forgetting the common factor 2 in steps 2–3 and leaving the answer as (4x−2)/(4x+2); it is the same thing, but students then fail to "see" f(2x) and think the proof failed.
Answer: Proved — (3f(x)+1)/(f(x)+3) simplifies to (2x−1)/(2x+1) = f(2x).

Concept A set of ordered pairs is a function A→B only if it uses each element of A exactly once as a first coordinate, and every second coordinate lies in B. To pick the valid option you scan the first coordinates: they must be precisely 1, 2, 3, 4 — no element missing, none repeated with a different image.
Key relation valid f ⇔ first-coordinates = A exactly (each once) and all images ∈ B. Missing an element of A means an input with no image; repeating one means an input with two images — both disqualify.
Solution
1. For each candidate set, extract the first coordinates.
2. Reject any set that omits an element of A = {1,2,3,4} — that input has no image.
3. Reject any set that repeats a first coordinate with two different second coordinates — that input has two images.
4. Reject any set whose image falls outside B = {−1,0,1,2,3}.
5. The surviving set — first coordinates exactly {1,2,3,4}, each once, all images in B — is the function.

Answer: The set in which the first coordinates are exactly 1, 2, 3, 4 (each once) with every image in {−1,0,1,2,3} — e.g. {(1,0),(2,1),(3,2),(4,3)}.

3Does the equation give y as a function of x? (4 equations)Is-it-a-functionwatch?v=4GIXtz9q1yg🟡 Similar—
Concept An equation in x and y defines y as a function of x only if solving for y produces exactly one y-value for each allowed x. The tell-tale sign of failure is an even power of y (y², y⁴, …) or |y|, because taking a root introduces a ± and thus two y-values. Geometrically this is the vertical-line test: a vertical line must meet the graph at most once.
Key relation y is a function of x ⇔ each x gives a single y. If isolating y forces a ± (from √ of an even power), one x yields two y's — not a function. Linear-in-y equations (y appears only to the first power) always pass.
Solution
1. Solve each equation for y and count the y-values per x.
2. y = mx + c or any equation linear in y → one y per x → function.First-power y isolates uniquely, e.g. 2x+3y=6 ⇒ y=(6−2x)/3.
3. y² = (expression in x) → y = ±√(…) → two y's for most x → not a function.e.g. x²+y²=25 gives y=±√(25−x²); a vertical line hits the circle twice.
4. |y| = g(x) → y = ±g(x) → also not a function; whereas y = |x| (modulus on x) is fine — one output each.
5. Verdict: those linear or single-valued in y are functions; those with y², y⁴ or |y| are not.
 equation type          solve for y            function of x?
 3y = 6 - 2x            y = (6-2x)/3           YES (one value)
 y = |x| or y = x^2     single output          YES
 y^2 = x  (or x^2+y^2=r^2)  y = +/- sqrt(...)  NO  (two values)
 |y| = x                y = +/- x              NO  (two values)
⚡ JEE Trick Scan for an even power of y (or |y|) — if present, it is almost certainly not a function of x. If y appears only to the first power, it is a function. Trap: y=x² and y=|x| are fine (the square/modulus is on x, giving one y); the danger is y²=… and |y|=… where the ± sits on y.
Answer: The equations that are linear/single-valued in y define y as a function of x; those containing y², y⁴ or |y| (giving y = ±…) do not.

Concept The natural domain of a formula is every real x for which the expression outputs a real number. Only three things can go wrong: (i) a denominator becomes 0, (ii) a square-root radicand goes negative, (iii) both at once. Polynomials never fail, so their domain is all of ℝ. Treat each of the four given functions independently and impose only the restrictions its own formula forces.
Formula polynomial ⇒ ℝ; p(x)/q(x) ⇒ q(x)≠0; √g(x) ⇒ g(x) ≥ 0; √g(x)/h(x) ⇒ g(x) ≥ 0 AND h(x)≠0 when root and denominator share the same expression, the two conditions merge into a strict inequality > 0.
Solution
1. f₁(x)=7x²+4x−1 is a polynomial — no denominator, no root — so domain = ℝ = (−∞, ∞).
2. f₂(x)=(x+4)/(x−2): only restriction x−2≠0 ⇒ x≠2 ⇒ domain = (−∞, 2) ∪ (2, ∞). the numerator x+4 imposes nothing — it may be any real value including 0.
3. f₃(x)=√(x+5)/(5+x): root needs x+5 ≥ 0 and denominator needs 5+x ≠ 0. Same expression, so the pair collapses to x+5 > 0 ⇒ x > −5 ⇒ domain = (−5, ∞). the endpoint −5 makes the radicand 0 (fine) but the denominator 0 (fatal) — so it is excluded.
4. f₄(x)=√(16−x²): need 16−x² ≥ 0 ⇒ x² ≤ 16 ⇒ −4 ≤ x ≤ 4 ⇒ domain = [−4, 4]. here endpoints stay IN: radicand 0 gives √0 = 0, a perfectly good real number.
5. Collect: the four domains match the key exactly — ℝ; ℝ∖{2}; (−5, ∞); [−4, 4].

1What defines a function from set A to set B?Function definitionA-RFN🟡 SimilarbA function from A to B assigns to each element of A exactly one element of B.
Concept A function from A to B is a rule of correspondence that pairs each element of A with one element of B. The defining requirement has two halves: existence (no element of A is left without an image) and uniqueness (no element of A is given two images). Together they make f a well-defined "input → single output" machine.
