1The common difference of the A.P. a₁, a₂, ……, am is 13 more than the common difference of the A.P. b₁, b₂, ……, bn. Concept Two separate A.P.s tied together by one sentence: da = db + 13. Get db from the two given b-terms using the index-gap rule, then step across to the a-progression and walk back from a₇₈ to a₁.
Formula bm − bk = (m − k)db; a₁ = a₇₈ − 77 da
Solution
1. From the b-progression: b₂₁ − b₃₃ = (21 − 33)db = −12 db.
2. Numerically that is −277 − (−385) = 108, so −12 db = 108 ⇒ db = −9.
3. The link gives da = db + 13 = −9 + 13 = 4.
4. Now use a₇₈ = a₁ + 77 da: 327 = a₁ + 77(4) = a₁ + 308.
5. Therefore a₁ = 327 − 308 = 19 → option (d).
6. Consistency check on the b-side: b₃₃ = −385 ⇒ b₁ = −385 + 32(9) = −97, and then b₂₁ = −97 − 20(9) = −277 ✓.
   b21 - b33 = -12 d_b = -277 + 385 = 108
   d_b = -9
   d_a = d_b + 13 = 4

   a78 = a1 + 77(4) = 327   ->   a1 = 19

   check b1 = -97 :  b21 = -277 ok,  b33 = -385 ok

Also note the self-check available here: only da = 4 makes 327 − 77da land on one of the four printed options, which is how the misprinted subscript was caught.

2Consider an A.P. a₁, a₂, ……, an; a₁ > 0. Concept Three facts, two unknowns (a₁ and n) — so one equation is a consistency check. The relation an = ¼a₁ converts directly into a relation between n and a₁, and the given total then produces a quadratic.
Formula an = a₁ + (n−1)d with d = −3/4; Sn = (n/2)(a₁ + an)
Solution
1. d = a₂ − a₁ = −3/4. Impose an = ¼a₁: a₁ + (n−1)(−3/4) = a₁/4 ⇒ (n−1)(3/4) = (3/4)a₁ ⇒ n − 1 = a₁.
2. Ends-form for the whole sum: Sn = (n/2)(a₁ + a₁/4) = (n/2)(5a₁/4) = 5na₁/8.
3. Set equal to 525/2: 5na₁/8 = 525/2 ⇒ na₁ = 420.
4. Substitute n = a₁ + 1: a₁(a₁ + 1) = 420 ⇒ a₁² + a₁ − 420 = 0 ⇒ (a₁ + 21)(a₁ − 20) = 0.
5. Since a₁ > 0, a₁ = 20 and n = 21. (Check: a₂₁ = 20 − 20(3/4) = 5 = ¼(20) ✓.)
6. Finally Σi=117 ai = (17/2)[2(20) + 16(−3/4)] = (17/2)(40 − 12) = (17/2)(28) = 238 → option (d).
   d = -3/4
   an = a1/4  ->  n - 1 = a1
   Sn = 5 n a1 / 8 = 525/2   ->  n a1 = 420
   a1(a1+1) = 420  ->  a1 = 20,  n = 21

   S17 = (17/2)[40 - 12] = 17 x 14 = 238
⚡ JEE Trick Notice that 420 = 20 × 21 is a product of consecutive integers — spotting that instantly gives a₁ = 20 without touching the quadratic formula. Train yourself to recognise n(n+1) values (2, 6, 12, 20, 30, 42, 56, 72, 90, 110, 132, …, 420, 462); they appear constantly in sum problems because Σn = n(n+1)/2.

3Let a₁, a₂, a₃, a₄ be an A.P. of four terms such that each term of the A.P. and its common difference r are integers. If a₁ + a₂ + a₃ + a₄ = 48 and a₁a₂a₃a₄ + r⁴ = 361, then the largest term of the A.P. is equal to   (a) 24   (b) 21   (c) 23   (d) 27   [JEE Main 2026, 24 Jan Shift 2]Symmetric four terms with a product conditionJEE Main 2026: Let a1, a2, a3, a4 be an A.P. of four terms such that each term of the A.P. and its common difference are integers🟢 Exactd27
Concept The sum fixes the mean at 12, so write the four terms symmetrically about 12. The product then becomes a product of two differences of squares, and the integrality condition picks out the single valid common difference.
Formula terms 12 − 3t, 12 − t, 12 + t, 12 + 3t where r = 2t; product = (144 − 9t²)(144 − t²)
Solution
1. Sum = 48 ⇒ mean = 12. Write the four terms as 12 − 3t, 12 − t, 12 + t, 12 + 3t; the common difference is r = 2t.
2. Product: (12−3t)(12+3t)·(12−t)(12+t) = (144 − 9t²)(144 − t²).
3. Condition: (144 − 9t²)(144 − t²) + (2t)⁴ = 361, i.e. 20736 − 1440t² + 9t⁴ + 16t⁴ = 361.
4. Simplify: 25t⁴ − 1440t² + 20375 = 0. Trying t² = 25 gives 15625 − 36000 + 20375 = 0 ✓, so t = 5.
5. The other root is t² = 20375/(25·25) = 32.6, not a perfect square — so integrality forces t = 5 and r = 10.
6. The four terms are −3, 7, 17, 27 → option (d). Verify: sum = 48 ✓; product = (−3)(7)(17)(27) = −9639, and −9639 + 10⁴ = 361 ✓.
   mean = 12;  terms 12-3t, 12-t, 12+t, 12+3t;  r = 2t
   (144 - 9t^2)(144 - t^2) + 16 t^4 = 361
   25 t^4 - 1440 t^2 + 20375 = 0     ->  t^2 = 25

   terms : -3, 7, 17, 27      (r = 10)
   check : sum 48 ; -9639 + 10000 = 361
⚡ JEE Trick The tiny 361 next to a four-term product is the tell: the product must be large and negative so that r⁴ can cancel most of it. That immediately says the A.P. straddles zero — some terms negative, some positive — which is why −3, 7, 17, 27 works and why the "nice-looking" options 21, 23, 24 (all giving all-positive terms) cannot.
Answer: (d) 27  (the A.P. is −3, 7, 17, 27 with r = 10).
4Let Σk=1n ak = αn² + βn. If a₁₀ = 59 and a₆ = 7a₁, then α + β is equal to   (a) 12   (b) 3   (c) 5   (d) 7   [JEE Main 2026, 23 Jan Shift 1]Quadratic Sₙ, two term conditionsJEE Main 2026: Let Σ(k=1 to n) aₖ = αn²+βn. If a₁₀=59 and a₆=7a₁, then α+β is equal to🟢 Exactc5
Concept Sn = αn² + βn is the standard quadratic form, so an = 2αn + (β − α) — linear, with d = 2α and a₁ = α + β. Notice that α + β is exactly a₁, so the question is really asking for the first term.
Formula Sn = αn² + βn ⇒ an = 2αn + (β − α), a₁ = α + β, d = 2α
Solution
1. From the quadratic form: an = 2αn + (β − α).
2. a₁₀ = 20α + β − α = 19α + β = 59.
3. a₆ = 12α + β − α = 11α + β, and a₁ = α + β. The condition a₆ = 7a₁ gives 11α + β = 7α + 7β ⇒ 4α = 6β ⇒ β = 2α/3.
4. Substitute into step 2: 19α + 2α/3 = 59 ⇒ 59α/3 = 59 ⇒ α = 3, hence β = 2.
5. Therefore α + β = 5 → option (c).
6. Verify: an = 6n − 1, so a₁ = 5, a₆ = 35 = 7 × 5 ✓ and a₁₀ = 59 ✓.
   Sn = a n^2 + b n   ->   a_n = 2*alpha*n + (beta - alpha)
   a10 = 19 alpha + beta = 59
   a6 = 7 a1 : 11a + b = 7(a + b)  ->  beta = 2 alpha/3
   59 alpha / 3 = 59  ->  alpha = 3, beta = 2

   alpha + beta = 5   (= a1)
   check : an = 6n - 1 ;  a1=5, a6=35, a10=59
⚡ JEE Trick Recognise that α + β = S₁ = a₁ before doing anything else — it converts "find α + β" into "find the first term", which is often reachable in one step. The same shortcut turns L-3 LEVEL-3 Q5 (Sn = nA + n²B) into a one-liner: d = 2B and a₁ = A + B.
Answer: (c) 5  (α = 3, β = 2; an = 6n − 1).
5If the sum of the first four terms of an A.P. is 6 and the sum of its first six terms is 4, then the sum of its first twelve is   (a) −20   (b) −22   (c) −26   (d) −24   [JEE Main 2026, 22 Jan Shift 1]Two sums → a and d → a third sumJEE Main 2026 (22 Jan Shift 1): If the sum of the first four terms of an A.P. is 6 and the sum of its first six terms is 4🟢 Exactb−22
Concept Two sum equations in the unknowns a and d. Reduce each to the bracket form 2a + kd, subtract to isolate d, then evaluate S₁₂. The fractions are unpleasant but the structure is completely routine.
Formula S₄ = 2(2a + 3d), S₆ = 3(2a + 5d), S₁₂ = 6(2a + 11d)
Solution
1. S₄ = (4/2)[2a + 3d] = 2(2a + 3d) = 6 ⇒ 2a + 3d = 3.
2. S₆ = (6/2)[2a + 5d] = 3(2a + 5d) = 4 ⇒ 2a + 5d = 4/3.
3. Subtract: 2d = 4/3 − 3 = −5/3 ⇒ d = −5/6.
4. Back-substitute: 2a = 3 − 3(−5/6) = 3 + 5/2 = 11/2, so a = 11/4.
5. S₁₂ = (12/2)[2a + 11d] = 6[11/2 + 11(−5/6)] = 6[11/2 − 55/6] = 6 × (33 − 55)/6 = −22 → option (b).
6. Sanity: the terms are falling fast (d < 0) and S₆ < S₄ already, so a large negative S₁₂ is exactly what you should expect.
   2a + 3d = 3
   2a + 5d = 4/3
   ------------- subtract
        2d = -5/3   ->  d = -5/6,  a = 11/4

   S12 = 6[11/2 - 55/6] = 6 x (-22/6) = -22
⚡ JEE Trick Reduce every sum to its bracket form 2a + kd before doing anything else — S₄ → 2a + 3d, S₆ → 2a + 5d, S₁₂ → 2a + 11d. The brackets differ only in the coefficient of d, so subtracting any two of them isolates d immediately, and you never carry the outer n/2 factor through the algebra.
Answer: (b) −22  (a = 11/4, d = −5/6).
6Let a₁ = 1 and for n ≥ 1, an+1 = ½an + (n² − 2n − 1)/[n²(n+1)²]. Then |Σn=1∞ (an − 2/n²)| is equal to ______   [JEE Main 2026, 21 Jan Shift 1]Recursion that hides a geometric sequenceLet a₁ = 1 and for n ≥ 1, aₙ₊₁ = (1/2)aₙ + (n² − 2n − 1) / [n²(n+1)²] | JEE Main 2026🟢 Exact2
Concept The expression whose sum is wanted, bn = an − 2/n², is a huge hint: substitute it into the recursion and watch the messy fraction collapse. What survives is a clean geometric recursion bn+1 = ½bn.
Formula set bn = an − 2/n²; then bn+1 = ½bn, so Σbn = b₁/(1 − ½)
Solution
1. Subtract 2/(n+1)² from both sides of the recursion: an+1 − 2/(n+1)² = ½an + (n² − 2n − 1)/[n²(n+1)²] − 2/(n+1)².
2. Put the last two terms over the common denominator n²(n+1)²: numerator = (n² − 2n − 1) − 2n² = −(n² + 2n + 1) = −(n+1)².
3. So that pair equals −(n+1)²/[n²(n+1)²] = −1/n².
4. Hence an+1 − 2/(n+1)² = ½an − 1/n² = ½(an − 2/n²), i.e. bn+1 = ½bn.
5. Initial value: b₁ = a₁ − 2/1² = 1 − 2 = −1. So bn = −(1/2)n−1, a G.P. with ratio ½.
6. Σn=1∞ bn = −1/(1 − ½) = −2, and the modulus is 2.
   b_n = a_n - 2/n^2

   a(n+1) - 2/(n+1)^2
     = (1/2)a_n + [n^2-2n-1 - 2n^2] / [n^2 (n+1)^2]
     = (1/2)a_n - (n+1)^2 / [n^2 (n+1)^2]
     = (1/2)a_n - 1/n^2
     = (1/2)(a_n - 2/n^2)

   b1 = -1 ;  b_n = -(1/2)^(n-1)
   sum = -1/(1 - 1/2) = -2   ->  |sum| = 2
⚡ JEE Trick When a question asks for Σ of some specific combination like an − 2/n², that combination is almost always the substitution the setter intends. Define it as bn, rewrite the recursion in terms of bn, and the ugly rational term is designed to vanish. Never try to solve for an explicitly first.
Answer: 2.
7Let a₁, a₂, ……, a₂₀₂₄ be an Arithmetic Progression such that a₁ + (a₅ + a₁₀ + a₁₅ + …… + a₂₀₂₀) + a₂₀₂₄ = 2233. Then a₁ + a₂ + a₃ + …… + a₂₀₂₄ is equal to ______   [JEE Main 2025, 29 Jan Shift 2]Equidistant pairing across a huge A.P.Let a₁, a₂, …, a₂₀₂₄ be an A.P. such that a₁ + (a₅ + a₁₀ + … + a₂₀₂₀) + a₂₀₂₄ = 2233🟢 Exact11132
Concept The bracket looks intimidating but every term in it pairs off symmetrically. Since 5 + 2020 = 2025 and 1 + 2024 = 2025, all these index-pairs share the same sum — so every pair contributes the same amount, namely a₁ + a₂₀₂₄.
Formula ap + aq depends only on p + q; S₂₀₂₄ = 1012(a₁ + a₂₀₂₄)
Solution
1. The bracketed terms are a₅, a₁₀, …, a₂₀₂₀ — indices in steps of 5, so there are 2020/5 = 404 of them.
2. Pair them from the outside in: (a₅, a₂₀₂₀), (a₁₀, a₂₀₁₅), … Every pair's indices add to 2025, giving 202 pairs.
3. In an A.P., ap + aq = 2a + (p + q − 2)d depends only on p + q. Since 1 + 2024 = 2025 too, each pair equals T = a₁ + a₂₀₂₄.
4. So the bracket totals 202T, and the whole given expression is T + 202T = 203T = 2233.
5. Therefore T = 2233/203 = 11.
6. Finally S₂₀₂₄ = (2024/2)(a₁ + a₂₀₂₄) = 1012 × 11 = 11132.
   bracket : a5, a10, ..., a2020    ->  404 terms, 202 pairs
   5 + 2020 = 2025 = 1 + 2024
   every pair  =  T = a1 + a2024

   T + 202 T = 203 T = 2233   ->  T = 11
   S2024 = 1012 x 11 = 11132
⚡ JEE Trick The moment you see a strange list of indices, add the first and last index and check whether it matches 1 + n. Here 5 + 2020 = 2025 = 1 + 2024, which is the whole design of the question — the outer a₁ and a₂₀₂₄ are there precisely so that all 203 pairs are identical. Also note 2233 = 203 × 11, a deliberately clean division.
Answer: 11132  (a₁ + a₂₀₂₄ = 11).
8Consider an A.P. of positive integers, whose sum of the first three terms is 54 and the sum of the first twenty terms lies between 1600 and 1800. Then its 11th term is   (a) 90   (b) 84   (c) 122   (d) 108   [JEE Main 2025, 29 Jan Shift 1]Inequality + integrality pins down dSum of the first three terms is 54 and the sum of the first twenty terms lies between 1600 and 1800🟢 Exacta90
Concept The first condition is an equation, the second only an inequality — so on its own it cannot fix d. The extra hypothesis "positive integers" is what closes the gap: only one integer d falls inside the allowed band.
Formula S₃ = 3(a + d) = 54 ⇒ a + d = 18; S₂₀ = 20a + 190d
Solution
1. Sum of the first three terms: 3a + 3d = 54 ⇒ a + d = 18 (i.e. the middle term a₂ is 18).
2. So a = 18 − d, and S₂₀ = (20/2)[2a + 19d] = 20a + 190d = 20(18 − d) + 190d = 360 + 170d.
3. Impose the band: 1600 < 360 + 170d < 1800 ⇒ 1240 < 170d < 1440.
4. Divide: 7.29… < d < 8.47…, so the only integer is d = 8.
5. Then a = 18 − 8 = 10 — a positive integer, as required, and every term 10, 18, 26, … is a positive integer ✓.
6. The 11th term: a₁₁ = 10 + 10(8) = 90 → option (a). (Check S₂₀ = 360 + 1360 = 1720, indeed between 1600 and 1800 ✓.)
   3(a + d) = 54       ->  a = 18 - d
   S20 = 360 + 170 d

   1600 < 360 + 170d < 1800
   1240 < 170 d < 1440
   7.29 < d < 8.47     ->  d = 8 (integer)

   a = 10 ;  a11 = 10 + 80 = 90 ;  S20 = 1720
⚡ JEE Trick When a problem supplies an inequality instead of an equation, the missing constraint is almost always an integrality or positivity condition stated in words. Read the stem for "positive integers", "natural numbers" or "consecutive integers" — that phrase is doing real mathematical work, not scene-setting.
Answer: (a) 90  (a = 10, d = 8).

4. Then a₁₅ = a + 14d = a + 56a = 57a.
5. Impose 110 < 57a < 120: 1.93 < a < 2.10, and a must be a natural number ⇒ a = 2, so d = 8. (Check a₁₅ = 114 ✓.)
6. S₁₀ = (10/2)[2(2) + 9(8)] = 5[4 + 72] = 5 × 76 = 380 → option (b).
   S5 = 5(a+2d),  S9 = 9(a+4d)
   5(a+2d) / 9(a+4d) = 5/17
   17a + 34d = 9a + 36d   ->  d = 4a

   a15 = a + 14d = 57a

   S10 = 5[4 + 72] = 380

11Let ℓ₁, ℓ₂, ……, ℓ₁₀₀ be consecutive terms of an arithmetic progression with common difference d₁, and let w₁, w₂, ……, w₁₀₀ be consecutive terms of another arithmetic progression with common difference d₂, where d₁d₂ = 10. For each i = 1, 2, ……, 100, let Ri be a rectangle with length ℓi, width wi and area Ai. If A₅₁ − A₅₀ = 1000, then the value of A₁₀₀ − A₉₀ is ______   [JEE Advanced 2022, Paper 1]Product of two A.P.s — second differencesLet l₁, l₂, ..., l₁₀₀ be consecutive terms of an arithmetic progression with common difference d₁🟢 Exact18900  ⚠
Concept Ai = ℓiwi is the product of two linear functions of i, hence quadratic in i with leading coefficient d₁d₂ = 10. The consecutive differences of a quadratic form an A.P., and its common difference is twice the leading coefficient — that single fact solves the whole problem.
Formula Ai = [ℓ₁ + (i−1)d₁][w₁ + (i−1)d₂] ⇒ Di = Ai+1 − Ai is an A.P. with common difference 2d₁d₂ = 20
Solution
1. Since ℓi and wi are both linear in i, Ai is quadratic in i with i²-coefficient d₁d₂ = 10.
2. For any quadratic with leading coefficient c, the first-difference sequence is an A.P. with common difference 2c. Here Di = Ai+1 − Ai is an A.P. with common difference 2(10) = 20.
3. Given A₅₁ − A₅₀ = D₅₀ = 1000, so Di = 1000 + 20(i − 50).
4. The target telescopes: A₁₀₀ − A₉₀ = D₉₀ + D₉₁ + … + D₉₉, a block of 10 consecutive D's.
5. Those run from D₉₀ = 1000 + 20(40) = 1800 up to D₉₉ = 1000 + 20(49) = 1980, so their sum is (10/2)(1800 + 1980) = 5 × 3780 = 18900.
6. Direct check with d₁ = 10, d₂ = 1: A₅₁ − A₅₀ = ℓ₁ + 10w₁ + 990 = 1000 ⇒ ℓ₁ + 10w₁ = 10; then A₁₀₀ − A₉₀ = 10(ℓ₁ + 10w₁) + 18800 = 100 + 18800 = 18900 ✓.
   A_i quadratic in i, leading coefficient d1 d2 = 10
   D_i = A_(i+1) - A_i  is an AP with c.d. = 2(10) = 20

   D50 = 1000   ->   D_i = 1000 + 20(i - 50)

   A100 - A90 = D90 + ... + D99      (10 terms)
              = 10(1000) + 20(40+41+...+49)
              = 10000 + 20(445)
              = 10000 + 8900 = 18900
⚡ JEE Trick Memorise the ladder: the term-by-term product of two A.P.s is quadratic, its first differences form an A.P. with common difference 2d₁d₂, and its second differences are the constant 2d₁d₂. That converts this JEE Advanced question into two lines. The same ladder explains why Sn+3 − 3Sn+2 + 3Sn+1 − Sn = 0 (L-2, LEVEL-6 Q3): third differences of a quadratic vanish.
