Concept Every term is built so the squared exponent is just the given exponent applied twice. Concept A nested logarithm equal to a number is unwrapped one shell at a time, always from the outside in. Each step uses the single fact that log_b N = c ⟺ N = b^c. The only thing to stay alert to is that the two chains have their bases in different orders — x sits inside log₂(log₂(log₃x)) while y sits inside log₂(log₃(log₂y)) — so the two answers are not the same number even though both outer equations read "= 0".
Formula log_b N = c ⟺ N = b^c. Two constants do all the work here: b⁰ = 1 and b¹ = b. An outer log equal to 0 forces its argument to be 1; an inner log equal to 1 forces its argument to equal the base.
Solution
1. Take the x-chain: log₂(log₂(log₃x)) = 0.Peel the outermost log₂ first — it is the last operation applied, so it is the first to undo.
2. Outer log₂(·) = 0 ⇒ its argument = 2⁰ = 1, so log₂(log₃x) = 1.
3. Now log₂(·) = 1 ⇒ its argument = 2¹ = 2, so log₃x = 2.
4. Finally log₃x = 2 ⇒ x = 3² = 9.
5. Take the y-chain: log₂(log₃(log₂y)) = 0 ⇒ log₃(log₂y) = 2⁰ = 1.Same first move — an outer log₂ equal to 0 forces the argument to 1.
6. log₃(·) = 1 ⇒ its argument = 3¹ = 3, so log₂y = 3.Here the middle base is 3, not 2 — this is where the two chains diverge.
7. log₂y = 3 ⇒ y = 2³ = 8.
8. Add: x + y = 9 + 8 = 17. Sanity check: x = 9 > 0 and log₃9 = 2 > 0, y = 8 > 0 and log₂8 = 3 > 0, so every nested argument is legal.

Concept Every number in sight — 2, 4, 0.125, 4·∛2 — is a power of 2. So the strategy is to force both sides into the single form 2^(something), then equate exponents, because 2^u = 2^v ⟺ u = v (the exponential is one-to-one). Radicals are just fractional powers: a square root halves an exponent, a cube root divides it by 3. The equation then becomes a plain algebraic one in x, and the question wants the product of its roots — which Vieta's formula hands over without solving.
Reading the stem The scan prints the small 3 between the two radical signs. It is the index of the inner radical (a cube root), not a cube on x. The equation is √( 2^x · ∛(4^x·(0.125)^(1/x)) ) = 4·∛2. Confirmation: this reading makes the four printed options exactly the roots 3 and −1/5, their sum 14/5 and their product −3/5 — a self-consistent option set that no other reading produces.
Formula 4 = 2², 0.125 = 1/8 = 2⁻³; (2^a)^b = 2^(ab); 2^a·2^b = 2^(a+b); ⁿ√(2^a) = 2^(a/n); and Vieta: for ax² + bx + c = 0, product of roots = c/a.
Solution
1. Rewrite each base as a power of 2: 4^x = (2²)^x = 2^(2x), and (0.125)^(1/x) = (2⁻³)^(1/x) = 2^(−3/x).
2. Multiply them inside the cube root: 2^(2x)·2^(−3/x) = 2^(2x − 3/x).Same base ⇒ add exponents.
3. Apply the cube root — divide that exponent by 3: ∛(2^(2x − 3/x)) = 2^((2x − 3/x)/3) = 2^(2x/3 − 1/x).

Then the value of log₂(m³)+log₂(M²) is ___ [JEE Advanced 2020, Paper-1]AM-GM minimum and maximum of logsJEE Advanced 2020 — min log₃(3^y₁+3^y₂+3^y₃), find log₂m³+log₂M²🟢 Exact8
Concept Two AM-GM extremes. For m, a sum of exponentials with fixed exponent-sum is minimised when the exponents are equal; for M, a product with fixed sum is maximised when the factors are equal. Both extremes land on the "all equal to 3" point, giving m = 4 and M = 3.
Reading the stem The final expression is printed as log₂(m³) + log₂(M²); the JEE Advanced 2020 problem — and the key value 8 — use log₂(m³) + log₃(M²) (second log base 3). Book stem defect; with base 3 the value is exactly 8.
Solution
1. m: by AM-GM, 3^y₁ + 3^y₂ + 3^y₃ ≥ 3·(3^(y₁+y₂+y₃))^(1/3) = 3·(3⁹)^(1/3) = 3·27 = 81.
2. So the minimum of log₃(sum) is log₃81 = m = 4 (attained at y₁ = y₂ = y₃ = 3).
3. M: log₃x₁ + log₃x₂ + log₃x₃ = log₃(x₁x₂x₃); with x₁+x₂+x₃ = 9, AM-GM gives x₁x₂x₃ ≤ 3³ = 27.
4. So the maximum is log₃27 = M = 3 (at x₁ = x₂ = x₃ = 3).
5. m³ = 64, M² = 9. Then log₂(m³) = log₂64 = 6 and log₃(M²) = log₃9 = 2.
6. Sum = 6 + 2 = 8.
 min Σ3^yᵢ = 81 ⇒ m = log₃81 = 4
 max ∏xᵢ  = 27 ⇒ M = log₃27 = 3
 log₂(m³) = log₂64 = 6
 log₃(M²) = log₃9  = 2
 6 + 2 = 8                         <-- answer
⚡ JEE Trick "Sum of exponentials, fixed exponent-sum" minimises at equal exponents; "product, fixed sum" maximises at equal factors — both give the symmetric point x = 3. Trap: reading the outer log's base wrong; log₂(m³) + log₃(M²) = 6 + 2 = 8, whereas the misprinted log₂(M²) = log₂9 would spoil the clean integer.
Answer: 8.
13Let (x₀,y₀) be the solution of the following equations (2x)^(ln 2)=(3y)^(ln 3), 3^(ln x)=2^(ln y), then x₀ is equal to [JEE Advanced 2011, Paper-1]Simultaneous equations with ln exponentsIf (2x)^log2=(3y)^log3, 3^logx=2^logy, find x — IIT JEE 2011🟢 Exact1/2
Concept Take ln of both equations to linearise the ln-in-the-exponent structure. The second equation gives ln y in terms of ln x; substituting into the first leaves a single equation whose common factor (ln 3)² − (ln 2)² cancels, forcing ln x = −ln 2 and hence x₀ = 1/2.
Formula ln(u^v) = v·ln u; then eliminate ln y between the two linear relations in ln x, ln y.
Solution
1. From 3^(ln x) = 2^(ln y): ln x·ln 3 = ln y·ln 2 ⇒ ln y = ln x·(ln 3/ln 2).
2. From (2x)^(ln 2) = (3y)^(ln 3): ln 2·(ln 2 + ln x) = ln 3·(ln 3 + ln y).
3. Expand: (ln 2)² + ln 2·ln x = (ln 3)² + ln 3·ln y.
4. Substitute ln y: (ln 2)² + ln 2·ln x = (ln 3)² + (ln 3)²·ln x/ln 2.ln 3·ln y = ln 3·ln x·ln 3/ln 2.
5. Group: (ln 2)² − (ln 3)² = ln x·[(ln 3)² − (ln 2)²]/ln 2 ⇒ −1 = ln x/ln 2 (dividing by the common factor (ln 3)² − (ln 2)²).
6. So ln x = −ln 2 ⇒ x₀ = 1/2.
 3^(ln x)=2^(ln y) ⇒ ln y = ln x·(ln3/ln2)
 (2x)^(ln2)=(3y)^(ln3):
   (ln2)² + ln2·lnx = (ln3)² + ln3·lny
 ⇒ (ln2)²−(ln3)² = lnx·[(ln3)²−(ln2)²]/ln2
 ⇒ lnx/ln2 = −1 ⇒ lnx = −ln2 ⇒ x₀ = 1/2   <-- answer
⚡ JEE Trick Logs sitting in exponents ⇒ take ln to make everything linear in ln x, ln y, then eliminate. The factor (ln 3)² − (ln 2)² divides out cleanly, so you never need numerical values of ln 2 or ln 3. Trap: cancelling that factor requires 3 ≠ 2 (it is nonzero) — students often expand it numerically and lose the exact 1/2.
Answer: 1/2.
