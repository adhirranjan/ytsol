Concept Writing out a₁, a₂, a₃, … every time is clumsy, so a whole sequence is abbreviated by naming its general term once and wrapping it in angle brackets or braces. The symbol stands for the entire ordered list, not for any single term.
Formula <aₙ> or {aₙ} denotes the sequence a₁, a₂, a₃, …; aₙ alone denotes only its nth member. Both notations are standard and interchangeable.
Solution
1. A sequence is an ordered list whose entries are indexed by 1, 2, 3, …
2. Once the rule for the nth entry is known, the whole list is determined, so the list is named after that rule.
3. The two conventional wrappers are the angle bracket <aₙ> and the brace {aₙ}.The module uses <aₙ> in its Suggested Problems and {aₙ} in the theory.
4. Example: <2n + 1> is the sequence 3, 5, 7, 9, … while a₄ = 9 is a single number.

   <a_n>   or   {a_n}         the same list, abbreviated
   a_n                        ONE term of it
⚡ JEE Trick Keep the distinction sharp: <aₙ> is a sequence, aₙ is a number. Questions that say "the sequence <aₙ> is defined by aₙ = …" are handing you the rule and asking you to generate terms — substitute n = 1, 2, 3 immediately.

1 (iii)Those sequences whose terms follow certain patterns are called ______.Definition of a progressionSequence & Series L-1 — Arithmetic Progression🟡 SimilarProgressions
Concept Every progression is a sequence, but not every sequence is a progression. A progression is a sequence whose terms obey a definite rule that lets you write down a formula for the nth term. The three studied progressions are A.P., G.P. and H.P.
Formula A.P.: a + (n−1)d · G.P.: arn−1 · H.P.: 1/[a + (n−1)d]. Each has a closed nth-term formula — that is what makes it a progression.
Solution
1. The blank names sequences that follow a definite pattern.
2. Those are called progressions.
3. Counter-example to keep in mind: the list of prime numbers 2, 3, 5, 7, 11, … is a genuine sequence but not a progression — no formula gives its nth term.Pattern-following is a real restriction, not a formality.
4. The three progressions on the syllabus are the arithmetic, geometric and harmonic progressions.

     |__ progressions  (have an n-th term formula)
           |__ A.P.   a + (n-1)d
           |__ G.P.   a r^(n-1)
           |__ H.P.   1/[a + (n-1)d]

1 (iv)If a₁, a₂, a₃, …, aₙ is a sequence then the expression a₁ + a₂ + a₃ + … + aₙ is a series; on the basis of the number of terms it may be ______ or ______.Finite and infinite seriesSequence and Series Class 11 — JEE Main & Advanced🟡 SimilarFinite or infinite
Concept A series is classified by how many terms it has, not by what those terms are. A definite last term makes it finite; terms continuing forever make it infinite. The distinction decides whether a "sum to infinity" question even makes sense.
Formula Finite: a₁ + … + aₙ with n fixed · Infinite: a₁ + a₂ + a₃ + … continuing without end. Only an infinite G.P. with |r| < 1 has a finite sum to infinity.
Solution
1. The classification asked for is by number of terms.
2. A series with a last term is finite; one that never terminates is infinite.
3. Example: 2 + 4 + 6 + 8 is finite (four terms); 1 + 1/2 + 1/4 + … is infinite.The second happens to converge, to 2 — but convergence is a separate question from being infinite.
4. An infinite A.P. never has a finite sum (its terms do not shrink to 0), which is why Sₙ formulas in L-2 always carry a definite n.
   finite   :  a1 + a2 + ... + an        n is a fixed number
   infinite :  a1 + a2 + a3 + ...        no last term
⚡ JEE Trick An infinite A.P. can never be summed — only a G.P. with |r| < 1 can. If a question offers a finite "sum to infinity" of an arithmetic-looking series, the series is secretly geometric or the answer is "does not exist".
Answer: finite or infinite.

Concept The sequence is not an A.P. — its gaps grow. But the gaps themselves form an A.P., and that is the signature of a quadratic nth term. Once the shape n² + qn + r is assumed, two substitutions pin the constants.
Formula First differences constant ⇒ linear aₙ; second differences constant ⇒ quadratic aₙ, with leading coefficient = (second difference)/2. Here the second difference is 2, so the leading coefficient is 1 — matching np with p = 2.
Solution
1. First differences: 3−1 = 2, 7−3 = 4, 13−7 = 6, 21−13 = 8 — not constant, so not an A.P.
2. Second differences: 4−2 = 2, 6−4 = 2, 8−6 = 2 — constant, so aₙ is a quadratic in n.
3. Leading coefficient = 2/2 = 1, so aₙ = n² + qn + r, matching the required np + qn + r with p = 2.
4. n = 1: 1 + q + r = 1 ⇒ q + r = 0. n = 2: 4 + 2q + r = 3 ⇒ 2q + r = −1.
5. Subtracting: q = −1, hence r = 1.
6. So aₙ = n² − n + 1. Check n = 5: 25 − 5 + 1 = 21 ✓

   1st df :    2    4    6    8         not constant  =>  not an A.P.
   2nd df :      2    2    2            constant      =>  quadratic

⚡ JEE Trick The difference table identifies the degree instantly: k constant differences at level k means aₙ is a degree-k polynomial. Note that aₙ = n² − n + 1 reappears as Level-3 Q1 on this same sheet, where its 5th term 21 is asked for directly.
Answer: p = 2, q = −1, r = 1 (aₙ = n² − n + 1).

Concept An A.P. read backwards is still an A.P. — the terms are the same numbers in the opposite order. Each backward step undoes a forward step, so the common difference keeps its size and flips its sign. That single fact is the whole justification for the "from the end" formula.
Formula Forward: tₙ = a + (n−1)d · Backward: Tₙ = ℓ + (n−1)(−d) = ℓ − (n−1)d. ℓ becomes the new first term and −d the new common difference.
Solution
1. Take a concrete A.P.: 3, 7, 11, 15 with d = 4.
2. Reverse it: 15, 11, 7, 3. Its gaps are 11 − 15 = −4, 7 − 11 = −4, 3 − 7 = −4.Still constant, so the reversed list is genuinely an A.P.
3. The new common difference is −4 = −d — same magnitude, opposite sign.
4. Hence option (b). It is not zero (the list still changes), not doubled, and square-rooting a difference is meaningless.
   forward :  3 ->  7 -> 11 -> 15      d = +4
   reverse : 15 -> 11 ->  7 ->  3      d = -4
   so  T_n (from end) = l - (n-1)d
⚡ JEE Trick This is why you never need the total number of terms to find "the kth term from the end" — just start at ℓ and step with −d. Suggested Problem 4 and Level-3 Q5 below both use it.
Answer: (b) the common difference is reversed, becoming −d.

5If the pth term of an A.P. is q and the qth term is p, then show that the (p + q)th term will be zero. (Level-4)Symmetric term conditions in an A.P.If p times the pth term of an AP is q times the qth term, find the (p+q)th term🟡 Similar— (proof question, no printed key)
Concept The two conditions are mirror images of each other, and subtracting them makes the common difference come out as exactly −1. From there the first term is forced, and the (p+q)th term collapses to zero. This is one of the two or three A.P. results the exam expects you to know by heart.
Formula a + (p−1)d = q … (i) and a + (q−1)d = p … (ii). Subtracting eliminates a and leaves (p − q)d on the left.
Solution
1. Write the two conditions: a + (p−1)d = q … (i), a + (q−1)d = p … (ii).
2. (i) − (ii): (p − q)d = q − p = −(p − q).
3. Since p ≠ q we may cancel (p − q), giving d = −1.
4. Substitute into (i): a − (p − 1) = q ⇒ a = p + q − 1.
5. Now the (p+q)th term is a + (p + q − 1)d = (p + q − 1) + (p + q − 1)(−1).
6. = (p + q − 1) − (p + q − 1) = 0 ∎
7. Check with p = 2, q = 5: d = −1, a = 6, so the A.P. is 6, 5, 4, 3, 2, 1, 0, … Its 2nd term is 5 = q ✓, its 5th is 2 = p ✓, and its 7th is 0 ✓
   a + (p-1)d = q
   a + (q-1)d = p     subtract  ->  (p-q)d = -(p-q)  ->  d = -1
   then a = p + q - 1
   T_(p+q) = (p+q-1) - (p+q-1) = 0

Answer: proved — d = −1 and a = p + q − 1, so T₍ₚ₊q₎ = 0. ∎
6If the nth term of a sequence is given by aₙ = n² − n − 2, show that it is not an A.P. (Level-4)Disproving that a sequence is an A.P.Arithmetic Progression Class 11 — important questions, JEE Mains🟡 Similar— (proof question, no printed key)
Concept To disprove an A.P. you need only exhibit two unequal gaps — one counter-example finishes the job. The cleaner argument is structural: compute aₙ − aₙ₋₁ in general and show it still contains n, so it cannot be constant.
Formula aₙ − aₙ₋₁ must be independent of n for an A.P. Here aₙ = n² − n − 2. A quadratic nth term always gives a linear (hence non-constant) difference.
Solution
1. Compute the general gap: aₙ − aₙ₋₁ = (n² − n − 2) − [(n−1)² − (n−1) − 2].
2. Expand the bracket: (n² − 2n + 1) − n + 1 − 2 = n² − 3n.
3. So aₙ − aₙ₋₁ = (n² − n − 2) − (n² − 3n) = 2n − 2.
4. This still depends on n, so the gap is not constant — the sequence is not an A.P. ∎2n − 2 is 2, 4, 6, … for n = 2, 3, 4 — an A.P. of gaps, which is the hallmark of a quadratic.

Concept The general statement of the property used numerically in Level-4 Q3. Positions m − k and m + k straddle m symmetrically, so their ±kd contributions cancel and their average is exactly aₘ.
Formula aₘ = (aₘ₋ₖ + aₘ₊ₖ)/2 for every valid k. The A.P. analogue of the G.P. relation aₘ² = aₘ₋ₖ·aₘ₊ₖ.
Solution
1. Write the two flanking terms: aₘ₊ₖ = a + (m + k − 1)d and aₘ₋ₖ = a + (m − k − 1)d.
2. Add them: aₘ₊ₖ + aₘ₋ₖ = 2a + (2m − 2)d = 2[a + (m − 1)d] = 2aₘ.The +kd and −kd cancel exactly — this is the whole content of the property.

5. Numerical check on 3, 7, 11, 15, 19 with m = 3, k = 2: (a₁ + a₅)/2 = (3 + 19)/2 = 11 = a₃ ✓

Concept A constrained optimisation. Use the given a₆ = 2 to express everything in terms of the single variable d; the product then turns out to be a quadratic in d, whose minimum sits at the vertex — no calculus strictly needed.
Formula a₆ = a + 5d = 2 ⇒ a = 2 − 5d; the vertex of Ad² + Bd + C is at d = −B/(2A). A > 0 here, so the vertex is a minimum.
Solution
1. From a₆ = 2: a + 5d = 2, so a₁ = a = 2 − 5d.
2. Also a₄ = a + 3d = (2 − 5d) + 3d = 2 − 2d, and a₆ = 2 (given).
3. Product P = a₁a₄a₆ = (2 − 5d)(2 − 2d)(2) = 2(2 − 5d)(2 − 2d).
4. Expand: (2 − 5d)(2 − 2d) = 4 − 4d − 10d + 10d² = 10d² − 14d + 4, so P = 20d² − 28d + 8.

9If 1, log_y x, log_z y, −15 log_x z are in A.P., then   (a) z³ = x   (b) x = y⁻¹   (c) z⁻³ = y   (d) all of theseA.P. of logarithms with a product constraintIf a, b, c are in G.P., prove log aⁿ, log bⁿ, log cⁿ are in A.P.🟡 Similardall of these
Concept The four terms are in A.P., so write them as 1, 1+D, 1+2D, 1+3D. The extra ingredient is the chain identity log_y x · log_z y · log_x z = 1, which converts the A.P. structure into a single cubic in D.
Formula log_y x · log_z y · log_x z = 1 (the logarithms form a closed cycle) and log_b a = 1/log_a b. The cycle identity is what makes the product of the three middle quantities equal 1.
Solution
1. Let the four terms be 1, A, B, C in A.P. with common difference D: A = 1 + D, B = 1 + 2D, C = 1 + 3D.
2. Here A = log_y x, B = log_z y and C = −15 log_x z, so log_x z = −C/15.
3. The chain identity gives A · B · log_x z = 1, i.e. A·B·(−C/15) = 1 ⇒ A·B·C = −15.
4. Substitute: (1 + D)(1 + 2D)(1 + 3D) = −15 ⇒ 6D³ + 11D² + 6D + 1 = −15 ⇒ 6D³ + 11D² + 6D + 16 = 0.
5. Test D = −2: 6(−8) + 11(4) + 6(−2) + 16 = −48 + 44 − 12 + 16 = 0 ✓ So D = −2.
6. Then A = −1, B = −3, C = −5. Read each off: log_y x = −1 ⇒ x = y⁻¹ ✓ (b); log_z y = −3 ⇒ y = z⁻³ ✓ (c); and −15 log_x z = −5 ⇒ log_x z = 1/3 ⇒ z = x^(1/3) ⇒ z³ = x ✓ (a).
7. All three hold, so the answer is (d).
   terms : 1 , 1+D , 1+2D , 1+3D
   chain : (log_y x)(log_z y)(log_x z) = 1  ->  A B C = -15
   (1+D)(1+2D)(1+3D) = -15   ->  D = -2
   A = -1  ->  x = y^-1        B = -3  ->  y = z^-3
   C = -5  ->  log_x z = 1/3   ->  z^3 = x
⚡ JEE Trick The identity log_a b · log_b c · log_c a = 1 is the key to every "cyclic logarithms in A.P./G.P." question — spot the closed cycle x → y → z → x and the product collapses to 1. And when an option list ends in "all of these", check each candidate: setters use it when a single value of D makes several statements true at once.
Answer: (d) all of these (D = −2 gives x = y⁻¹, y = z⁻³ and z³ = x).
10The value of x satisfying log_a x + log_√a x + log_∛a x + … + log_(a^(1/a)) x = (a + 1)/2 will be   (a) x = a   (b) x = aa   (c) x = a−1/a   (d) x = a1/aSum of logarithms with roots as basesIf a, b, c are in G.P., prove log aⁿ, log bⁿ, log cⁿ are in A.P.🟡 Similardx = a1/a
Concept Each base is a successive root of a, and taking the kth root of the base multiplies the logarithm by k. The sum therefore becomes (1 + 2 + 3 + … + a)·log_a x — an ordinary A.P. sum multiplying a single unknown.
Formula log_{a^(1/k)} x = k·log_a x and 1 + 2 + … + a = a(a+1)/2. The bases run a, a^(1/2), a^(1/3), …, a^(1/a), so k runs 1 to a.
Solution
1. Change each base: log_{a^(1/k)} x = log_a x / log_a a^(1/k) = log_a x / (1/k) = k·log_a x.
2. The bases are a¹, a^(1/2), a^(1/3), …, a^(1/a), so k takes the values 1, 2, 3, …, a.
3. The left side is therefore (1 + 2 + 3 + … + a)·log_a x = [a(a+1)/2]·log_a x.The sum of the first a natural numbers — an A.P. sum, which is why this question sits in this chapter.
4. Set equal to the right side: [a(a+1)/2]·log_a x = (a + 1)/2.
5. Cancel (a + 1)/2 from both sides: a·log_a x = 1 ⇒ log_a x = 1/a.
6. Therefore x = a1/a ⇒ option (d).
   log_(a^(1/k)) x = k log_a x
   sum over k = 1..a  ->  [a(a+1)/2] log_a x = (a+1)/2
   cancel (a+1)/2     ->  a log_a x = 1
   log_a x = 1/a      ->  x = a^(1/a)
⚡ JEE Trick A root in the base multiplies the log: log_{a^(1/k)} x = k log_a x. Spot that and the whole chain becomes 1 + 2 + … + a times a single logarithm. The (a+1)/2 on the right is deliberately shaped to cancel with the a(a+1)/2 on the left — a strong hint you are on the right track.
Answer: (d) x = a1/a.
