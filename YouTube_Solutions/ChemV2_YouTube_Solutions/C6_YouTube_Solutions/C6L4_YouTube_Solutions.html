Concept For an ideal gas, internal energy U is a function of temperature alone — it depends on the kinetic energy of the molecules, which is fixed once T is fixed, and has nothing to do with how far apart the molecules are (no intermolecular forces to store potential energy in). So any process that starts and ends at the same temperature must start and end at the same internal energy, no matter what happens to volume or pressure in between. This is exactly Joule's law: U = U(T) only for an ideal gas.
Key relation ΔU = nC_v ΔT for an ideal gas. If ΔT = 0, then ΔU = 0 automatically — the formula has no P or V term at all, so expansion or compression is irrelevant to U as long as T doesn't change.
Solution
1. The gas expands at constant temperature (isothermal) and incidentally at constant pressure too — but the temperature clause is the only one that matters for U.
2. Apply ΔU = nC_v ΔT with ΔT = 0 (initial T = final T): ΔU = nC_v × 0 = 0.Physically: the average kinetic energy of the molecules, ½mv²_rms, depends only on T via (3/2)RT per mole — same T means same average KE means same U.
3. Reject (a) and (c): both assume U changes during expansion, but that would require a temperature change, which contradicts the given "constant temperature."
4. Reject (d): the question asks specifically about internal energy, not entropy — entropy does rise on isothermal expansion (more microstates available), but that is a different state function entirely and isn't what's being asked.
5. Contrast with a real gas: intermolecular attractions store potential energy, so even at constant T, expansion (increasing average separation) can change U slightly — but ICAD-level problems assume ideal gas behaviour unless stated otherwise.

Concept The First Law of Thermodynamics splits energy exchange into heat (q) and work (w): ΔU = q + w, where w is work done on the system. The only kind of work a simple gas system normally does is pressure–volume (expansion) work, w = −PΔV (work done on the system is negative when the system expands). So the fate of the heat you put in depends entirely on whether the system is allowed to change volume — that single switch (constant V vs constant P) decides whether q equals ΔU or ΔH.
Key relation ΔU = q + w = q − PΔV (work done BY system convention: q = ΔU + PΔV). At constant volume, ΔV = 0, so the PΔV term simply vanishes — no work is possible without a volume change.

Concept For gaseous reactions the bridge between enthalpy and internal energy is the extra PΔV term, and that term is entirely controlled by how the total number of moles of gas changes across the reaction. More gas molecules leaving than entering means the system must physically push back the atmosphere to make room — that pushing costs (positive) work, and enthalpy is defined to already include it, so ΔH ends up numerically larger than ΔU whenever gas moles increase.
Key relation ΔH = ΔU + ΔnRT, where Δn = (moles of gaseous products) − (moles of gaseous reactants). R and T are always positive, so the sign of ΔnRT — and hence whether ΔH is bigger or smaller than ΔU — is decided purely by the sign of Δn.
Solution
1. Given: moles of gaseous products > moles of gaseous reactants, i.e. n_p > n_r, so Δn = n_p − n_r > 0.
2. Plug into the relation: ΔH − ΔU = ΔnRT. Since Δn > 0 and R, T > 0, the right side is positive.
3. Therefore ΔH − ΔU > 0, i.e. ΔH > ΔU — option (c).
4. Physical picture: with more gas moles produced, the system expands against the constant external pressure, doing positive work on the surroundings; this work must be supplied on top of the internal-energy change, inflating the heat absorbed at constant pressure (ΔH) above ΔU.
5. Worked example from this very lecture: PCl₅(g) ⇌ PCl₃(g) + Cl₂(g), Δn = 2 − 1 = +1 > 0 ⇒ ΔH > ΔU, exactly this case.
6. Eliminate the rest: (a) ΔH = ΔU needs Δn = 0 exactly (not given here); (b) ΔH < ΔU needs Δn < 0, the reverse case; (d) ΔH = −ΔU has no physical basis — it isn't implied by any value of Δn.

 example: PCl5(g) -> PCl3(g)+Cl2(g), Δn=+1, ΔH>ΔU
⚡ JEE Trick Reduce the whole question to a one-line sign check: gas moles increase → ΔH > ΔU; gas moles decrease → ΔH < ΔU; gas moles unchanged → ΔH = ΔU. Never compute Δn from the total balanced equation coefficients including solids/liquids — only gaseous species count towards Δn, a very common trap when a reaction mixes phases (e.g. C(s) + O₂(g) → CO₂(g) has Δn = 1 − 1 = 0, not "products − reactants" of all species).

Concept A state function is any property whose value depends only on the current condition of the system (its state — defined by variables like T, P, composition) and not on the sequence of steps used to reach that state. Since H = U + PV is built entirely out of state functions (U, P, V), H itself must be a state function. This is the single deepest reason path-independence holds: it is a mathematical consequence of how enthalpy is constructed, not an experimental accident.
Key relation ΔH = H_final − H_initial, always — regardless of the route taken between the two states. This is exactly the logic Hess's Law is built on: you can add up ΔH values along ANY convenient path (real or hypothetical) and get the same total, because only the endpoints matter.
Solution
1. Definition check: a quantity X is a state function ⟺ ΔX for any process equals X_final − X_initial, with no dependence on intermediate steps.
2. H = U + PV. U is a state function (postulate of the First Law), and P, V are both state variables — a sum/combination of state functions is itself a state function.Contrast with q and w individually: neither is a state function (they depend on the path — e.g. reversible vs irreversible expansion gives different w for the same ΔU), yet their SUM q+w = ΔU always comes out the same.
3. Reject (a): enthalpy depends on U, P, and V together, not on pressure alone — a change in V at fixed P still changes H via the PV term.
4. Reject (b): being extensive (scales with the amount of substance, like mass) is a true property of H, but it explains why H depends on quantity, not why ΔH is path-independent — a red herring that sounds related but answers a different question.
5. Reject (d): ΔH happens to equal q_p only under the special constraint of constant pressure, but H itself is perfectly well-defined at any pressure — being "measured at constant pressure" is a measurement convenience, not the reason for path-independence.

1Define and explain the term enthalpy. OR What is meant by enthalpy of a system?Definition of enthalpyEnthalpy (ΔH) Explained - the total heat content of a System🟢 Exact—
Concept Internal energy U alone is not the most convenient bookkeeping variable for chemistry, because almost every reaction happens open to the atmosphere at constant pressure, where the system also does PΔV work on the air around it. Enthalpy is the thermodynamic property invented precisely to absorb that unavoidable work term into a single new state function, so that at constant pressure the heat exchanged equals a clean, directly measurable quantity.
Definition H = U + PV, where U is the internal energy, P the pressure, and V the volume of the system. H is also called the heat content, because at constant pressure the heat absorbed or released by a process equals exactly ΔH — nothing is "lost" bookkeeping-wise to expansion work.
Solution
1. Build-up: start from the First Law, q = ΔU + w, with w = PΔV (work done BY the system at constant pressure).
2. Substitute: q_p = ΔU + PΔV = (U₂ − U₁) + P(V₂ − V₁) = (U₂ + PV₂) − (U₁ + PV₁).
3. Define H ≡ U + PV for any state. Then the bracket above is simply H₂ − H₁ = ΔH, so q_p = ΔH — the heat at constant pressure is precisely the enthalpy change.
4. Properties: H is a state function (built from state functions U, P, V) and an extensive property (doubling the amount of substance doubles H). Its absolute value can never be measured — only ΔH between two states is experimentally accessible, exactly like U.
5. Sign convention: ΔH is negative for an exothermic process (heat leaves the system, H falls) and positive for an endothermic process (heat enters, H rises).
6. Standard enthalpy: when all substances are in their standard states (1 atm, usually 298 K), the change is written ΔH° or ΔH°₂₉₈ₖ, giving a common reference point for tabulated data.

⚡ JEE Trick Board answers on "define enthalpy" score full marks with four beats: the formula H=U+PV → the derivation q_p=ΔH → why it's called heat content → its two properties (state function, extensive). Trap: writing "enthalpy is the total heat of a system" without the PV correction term — that description belongs to internal energy loosely, not to the precise H = U + PV definition examiners expect.
Key point: enthalpy H = U + PV is the state function whose change at constant pressure equals the heat absorbed or released, q_p = ΔH — which is why it is called the heat content of the system.

4What are the conditions under which ΔH = ΔU?Conditions for ΔH = ΔUMOST IMPORTANT QUESTION ANSWER | CHEMICAL THERMODYNAMIC | RELATION BETWEEN DELTA H AND DELTA U🟡 Similar—
Concept ΔH and ΔU differ only by the ΔnRT correction term, so listing the conditions for ΔH = ΔU is really just listing every distinct way that term can be forced to zero. There are three structurally different routes to the same numerical outcome: no volume change at all, no gas phase at all, or a gas phase whose total mole count happens not to change — each is worth stating separately because they cover different reaction types.
Key relation ΔH = ΔU + ΔnRT. ΔH = ΔU exactly when ΔnRT = 0; since R and T are never zero in a real process, this always comes down to forcing Δn = 0.
Solution — the conditions
1. Reaction carried out in a closed, rigid vessel (constant volume): ΔV = 0 directly, so PΔV = 0 and hence ΔH = ΔU regardless of what the reaction produces.
2. Reaction involves only solids, liquids, or solutions — no gaseous species anywhere: Δn ≡ 0 automatically since there are no gas moles to count on either side, and the volume change of condensed phases is negligible.Example: CH₃COOC₂H₅(l) + H₂O(l) ⇌ CH₃COOH(l) + C₂H₅OH(l) — every species is a liquid, so ΔH = ΔU here.

4. Textbook examples of condition 3: H₂(g) + Cl₂(g) → 2HCl(g) (n_r = 2, n_p = 2); C(s) + O₂(g) → CO₂(g) (gaseous moles: 1 → 1); N₂(g) + O₂(g) → 2NO(g) (2 → 2).

Concept This question is Hess's Law asked as a "which is irrelevant" filter. Because H is a state function (row 4 of this section proved this), ΔH depends ONLY on the identity/state of the initial reactants and the identity/state of the final products — the actual mechanism, catalyst, number of steps, or route taken between them has zero effect on the final ΔH tally, even though those same details absolutely DO affect physical states, initial reactant choice, and temperature.
