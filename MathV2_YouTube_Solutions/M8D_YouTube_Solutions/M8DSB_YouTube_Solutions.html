1If S₁, S₂ and S₃ are the sums of first n natural numbers, their squares and their cubes respectively, then (S₁⁴S₂² − S₂²S₃²)/(S₁² + S₃²) =   (a) 4   (b) 2   (c) 1   (d) 0The identity S₃ = S₁²S1, S2, S3 are the sums of the first n natural numbers, their squares and their cubes respectively🟡 Similard0
Concept This looks like a monstrous algebraic fraction, but it is a one-line trap. The whole question rests on the single most famous identity of the three standard sums: the sum of the cubes is the square of the sum. Once you write S₃ = S₁², the numerator annihilates itself and nothing else in the problem matters.
Formula S₁ = n(n+1)/2, S₂ = n(n+1)(2n+1)/6, S₃ = [n(n+1)/2]² = S₁². Never evaluate S₂ here — it cancels as a common factor.
Solution
1. Write the three standard sums: S₁ = n(n+1)/2, S₂ = n(n+1)(2n+1)/6, S₃ = n²(n+1)²/4.
2. Compare S₃ with S₁: S₁² = [n(n+1)/2]² = n²(n+1)²/4 = S₃. So S₃ = S₁².This is the identity 1³+2³+…+n³ = (1+2+…+n)².
3. Therefore S₃² = (S₁²)² = S₁⁴.
4. Numerator = S₁⁴S₂² − S₂²S₃² = S₂²(S₁⁴ − S₃²) = S₂²(S₁⁴ − S₁⁴) = 0.
5. Denominator = S₁² + S₃² = S₁² + S₁⁴ = S₁²(1 + S₁²), which is strictly positive for every n ≥ 1, so the fraction is genuinely 0/(non-zero) and not 0/0.
6. Hence the expression equals 0 ⇒ option (d).
7. Numeric sanity check at n = 3: S₁ = 6, S₂ = 14, S₃ = 36 = 6² ✓. Numerator = 6⁴·14² − 14²·36² = 1296·196 − 196·1296 = 0 ✓, denominator = 36 + 1296 = 1332 ≠ 0. Value = 0 ✓.
  S1 = n(n+1)/2
  S3 = n^2(n+1)^2/4 = S1^2      <-- the key identity
  =>  S3^2 = S1^4

  numerator = S2^2 ( S1^4 - S3^2 ) = S2^2 ( S1^4 - S1^4 ) = 0
  denominator = S1^2 + S1^4 = S1^2 (1 + S1^2)  > 0
  value = 0
⚡ JEE Trick Whenever S₁, S₂, S₃ appear together, immediately write S₃ = S₁² and look for a cancellation before you expand anything. Setters love burying this identity under a heavy fraction. The presence of the pair S₁⁴ and S₃² in one numerator is the tell — those are the same number. Plugging n = 1 (S₁ = S₂ = S₃ = 1) also kills the numerator in three seconds.
Answer: (d) 0.
2If tan(π/12 − x), tan(π/12), tan(π/12 + x) in order are three consecutive terms of a G.P., then the sum of all the solutions in [0, 314] is kπ. The value of k is:   (a) 4950   (b) 5050   (c) 2525   (d) 5010G.P. condition + counting solutions in a long interval—a4950
Concept Two ideas are welded together. First, "three terms in G.P." means the middle term squared equals the product of the outer two — and the product tan(A−x)·tan(A+x) has a clean closed form. That collapses the trigonometry to tan x = 0. Second, you must then count how many multiples of π fit inside [0, 314] and add them, which is an A.P. sum in disguise. The number 314 is chosen because 314/π ≈ 99.95.
Formula G.P. ⇒ t₂² = t₁t₃; and tan(A−x)tan(A+x) = (tan²A − tan²x)/(1 − tan²A·tan²x); sum of an A.P. 0 + 1 + … + 99 = 99·100/2 = 4950. The product formula comes from expanding tan(A±x) and multiplying.
Solution
1. Let A = π/12, t = tan A and T = tan x. The G.P. condition is tan²A = tan(A−x)·tan(A+x), i.e. t² = (t − T)(t + T)/[(1 + tT)(1 − tT)].tan(A−x) = (t−T)/(1+tT) and tan(A+x) = (t+T)/(1−tT); multiply them.
2. So t² = (t² − T²)/(1 − t²T²). Cross-multiplying: t²(1 − t²T²) = t² − T² ⇒ t² − t⁴T² = t² − T².
3. Cancel t² from both sides: −t⁴T² = −T² ⇒ T²(1 − t⁴) = 0.
4. Now t = tan(π/12) = 2 − √3 ≈ 0.268, so t⁴ ≠ 1 and the bracket cannot vanish. Hence T² = 0, i.e. tan x = 0 ⇒ x = nπ, n ∈ ℤ.Also check the three terms are then all equal to tan(π/12) — a valid G.P. with common ratio 1.
5. Restrict to [0, 314]: need 0 ≤ nπ ≤ 314 ⇒ 0 ≤ n ≤ 314/π = 99.95…, so n = 0, 1, 2, …, 99 — exactly 100 solutions.100π ≈ 314.159 > 314, so n = 100 just misses. That near-miss is the whole point of choosing 314.
6. Sum of solutions = π(0 + 1 + 2 + … + 99) = π·(99·100/2) = 4950π.
7. Comparing with kπ gives k = 4950 ⇒ option (a).
8. Sanity check on the count: option (b) 5050 = 1+2+…+100 would need n to run to 100, i.e. 100π ≤ 314, false since 100π = 314.159. That is precisely the decoy.
  GP:  tan^2(pi/12) = tan(pi/12 - x) tan(pi/12 + x)
       t^2 = (t^2 - T^2)/(1 - t^2 T^2),  T = tan x
       =>  T^2 (1 - t^4) = 0,   t = tan(pi/12) != +-1

Then the whole battle is the counting: 314 < 100π, so you get 0…99 and the sum 4950, not 5050. Whenever a JEE interval is a suspicious integer like 314 or 157, it is π-related and deliberately one step short of a round count.
Answer: (a) 4950.
3If α, β are roots of the equation 375x² − 25x − 2 = 0 and sₙ = αⁿ + βⁿ, then limn→∞ (Σr=1n sr) =   (a) 1/12   (b) 1/4   (c) 1/3   (d) 1Sum of two infinite G.P.s built from the roots—a1/12
Concept Do not find α and β. Σsᵣ = Σαʳ + Σβʳ is just two infinite geometric series, and the sum of each depends only on the root itself. Adding them and clearing denominators produces an expression purely in α+β and αβ — which Vieta hands you straight off the quadratic. This is the standard "symmetric functions beat explicit roots" move.
Formula Vieta: α+β = 25/375 = 1/15, αβ = −2/375. Infinite G.P.: Σr≥1 αʳ = α/(1−α) for |α| < 1. Combined: α/(1−α) + β/(1−β) = [(α+β) − 2αβ] / [1 − (α+β) + αβ]. Both roots must be inside (−1,1) for convergence — check before summing.
Solution
1. From 375x² − 25x − 2 = 0: α + β = 25/375 = 1/15 and αβ = −2/375.
2. Convergence check: the roots are x = [25 ± √(625 + 4·375·2)]/750 = [25 ± √3625]/750, and √3625 ≈ 60.208, so α ≈ 0.11361 and β ≈ −0.04694. Both have modulus < 1, so each geometric series converges.You never need these decimals for the answer — only to certify that the infinite-G.P. formula is legal.
3. Σr=1∞ sᵣ = Σαʳ + Σβʳ = α/(1−α) + β/(1−β).
4. Put over a common denominator: [α(1−β) + β(1−α)] / [(1−α)(1−β)] = [α + β − 2αβ] / [1 − (α+β) + αβ].
5. Numerator = 1/15 − 2(−2/375) = 25/375 + 4/375 = 29/375.
6. Denominator = 1 − 25/375 − 2/375 = (375 − 25 − 2)/375 = 348/375.
7. Ratio = 29/348. Since 348 = 12 × 29, this is 1/12 ⇒ option (a).
8. Numeric sanity check with the decimal roots from step 2: α/(1−α) ≈ 0.11361/0.88639 ≈ 0.128172 and β/(1−β) ≈ (−0.04694)/1.04694 ≈ −0.044838. Their sum ≈ 0.083334, and 1/12 = 0.083333 ✓ — while 1/4, 1/3 and 1 are nowhere near.

    = [ (a+b) - 2ab ] / [ 1 - (a+b) + ab ]

⚡ JEE Trick Memorise the compressed form Σ(αʳ + βʳ) = [(α+β) − 2αβ] / [1 − (α+β) + αβ]. It converts any "roots of a quadratic, sum the power sums" question into two Vieta substitutions. The denominator 1 − (α+β) + αβ is just the quadratic evaluated at x = 1 divided by its leading coefficient — here (375 − 25 − 2)/375 — which is an even faster route. 4Find the sum of the infinite series 1/9 + 1/18 + 1/30 + 1/45 + 1/63 + ……   (a) 1/3   (b) 1/4   (c) 1/5   (d) 2/3Triangular-number denominators → telescopingFind the sum of the infinite series 1/9+1/18+1/30+1/45+1/63+…… (a) 1/3 (b) 1/4 (c) 1/5 (d) 2/3🟢 Exacta1/3
Concept The numerators are all 1, so everything lives in the denominators 9, 18, 30, 45, 63. Their differences are 9, 12, 15, 18 — an A.P. with common difference 3 — which is the signature of a quadratic (second-degree) denominator. Once you factor that quadratic into two consecutive integers, partial fractions telescope the whole series.
Formula Denominator dₙ = 3(n+1)(n+2)/2, so Tₙ = 2/[3(n+1)(n+2)] = (2/3)[1/(n+1) − 1/(n+2)]. 1/[(k)(k+1)] = 1/k − 1/(k+1) is the workhorse partial fraction of this whole chapter.
Solution
1. List denominators: 9, 18, 30, 45, 63. First differences: 9, 12, 15, 18 → second differences constant at 3, so dₙ is a quadratic in n.
2. Pull out the common factor 3: dₙ/3 = 3, 6, 10, 15, 21 — these are exactly the triangular numbers (n+1)(n+2)/2 for n = 1, 2, 3, …Check n = 1: 2·3/2 = 3 ✓; n = 4: 5·6/2 = 15 ✓.
3. Hence dₙ = 3(n+1)(n+2)/2 and the general term is Tₙ = 1/dₙ = 2/[3(n+1)(n+2)].Verify n = 1: 2/(3·2·3) = 2/18 = 1/9 ✓.
4. Split by partial fractions: 1/[(n+1)(n+2)] = 1/(n+1) − 1/(n+2), so Tₙ = (2/3)[1/(n+1) − 1/(n+2)].
5. Add from n = 1 to N: SN = (2/3)[(1/2 − 1/3) + (1/3 − 1/4) + … + (1/(N+1) − 1/(N+2))]. Every interior fraction appears once positive and once negative.
6. Only the two ends survive: SN = (2/3)[1/2 − 1/(N+2)].
7. Let N → ∞: the tail 1/(N+2) → 0, so S∞ = (2/3)(1/2) = 1/3 ⇒ option (a).
8. Numeric sanity check on five terms: 1/9 + 1/18 + 1/30 + 1/45 + 1/63 = 0.11111 + 0.05556 + 0.03333 + 0.02222 + 0.01587 = 0.23809, and the formula gives (2/3)(1/2 − 1/7) = (2/3)(5/14) = 5/21 = 0.238095 ✓. The partial sums are climbing towards 0.3333, ruling out 1/4 and 1/5 (already exceeded is false — but the limit 1/3 is the only option above 0.238 that the increasing sums approach), and 2/3 is far too big.
  denominators: 9, 18, 30, 45, 63
  /3          : 3,  6, 10, 15, 21   = (n+1)(n+2)/2   (triangular)

  T_n = 2 / [3 (n+1)(n+2)] = (2/3)[ 1/(n+1) - 1/(n+2) ]

  S_N = (2/3)[ 1/2 - 1/(N+2) ]        <-- telescopes
  S_inf = (2/3)(1/2) = 1/3

  check 5 terms: 5/21 = 0.238095  (formula and direct sum agree)
⚡ JEE Trick When a series has constant numerators and denominators whose second differences are constant, the denominator is a quadratic — factor it into consecutive integers and telescope. Recognising 3, 6, 10, 15, 21 as triangular numbers on sight saves a minute of algebra. Also note the shortcut for the limit: a telescoping sum starting at n = 1 converges to (coefficient) × (first surviving term), here (2/3)(1/2).
Answer: (a) 1/3.
5If x + y = a and x² + y² = b, then the value of (x³ + y³) is:   (a) ab   (b) a² + b   (c) a + b²   (d) (3ab − a³)/2Symmetric functions: converting to e₁ and e₂—d(3ab − a³)/2
Concept Every symmetric expression in x and y can be written in terms of just two quantities: the sum s = x + y and the product p = xy. You are given s and the power sum x² + y²; from those you can extract p, and then x³ + y³ follows from the standard cube identity. This "reduce to s and p" habit is the backbone of every A.P./G.P.–roots question.
Formula x² + y² = (x+y)² − 2xy and x³ + y³ = (x+y)³ − 3xy(x+y). The second is the compact form of (x+y)(x²−xy+y²) after substituting x²+y².
Solution
1. Write s = x + y = a and p = xy (unknown for now).
2. From x² + y² = s² − 2p we get b = a² − 2p, hence p = (a² − b)/2.
3. Use the cube identity x³ + y³ = s³ − 3ps.
4. Substitute: x³ + y³ = a³ − 3·[(a² − b)/2]·a = a³ − (3a³ − 3ab)/2.
5. Put over the denominator 2: = (2a³ − 3a³ + 3ab)/2 = (3ab − a³)/2 ⇒ option (d).
6. Dimensional check: x and y have "degree 1", so a has degree 1 and b degree 2. Then x³+y³ must have degree 3. Option (a) ab has degree 3 ✓ (survives this test), (b) a²+b has mixed degree 2 — inconsistent, (c) a + b² has degrees 1 and 4 — inconsistent. Only (a) and (d) are dimensionally possible.
7. Numeric sanity check with x = 1, y = 2: a = 3, b = 5, and x³+y³ = 1 + 8 = 9. Option (d): (3·3·5 − 27)/2 = (45 − 27)/2 = 18/2 = 9 ✓. Option (a): ab = 15 ✗.
  s = x+y = a,   p = xy
  x^2+y^2 = s^2 - 2p = b     =>  p = (a^2 - b)/2

  x^3+y^3 = s^3 - 3ps
          = a^3 - 3a(a^2-b)/2
          = (2a^3 - 3a^3 + 3ab)/2
          = (3ab - a^3)/2

  check x=1,y=2 : a=3, b=5 ;  (45-27)/2 = 9 = 1+8   ok
⚡ JEE Trick Two moves settle almost every question of this shape. (i) Degree check — a and b carry degrees 1 and 2, so any candidate answer must come out to degree 3; that alone kills two options in five seconds. (ii) Plug tiny numbers — x = 1, y = 2 gives a = 3, b = 5 and finishes it. Never expand (x+y)(x²−xy+y²) by hand under time pressure; go straight to s³ − 3ps.
Answer: (d) (3ab − a³)/2.
6The minimum value of (A² + A + 1)(B² + B + 1)(C² + C + 1)(D² + D + 1)/(ABCD), where A, B, C, D > 0, is:   (a) 1/3⁴   (b) 1/2⁴   (c) 2⁴   (d) 3⁴AM–GM factor by factorThe minimum value of ((A²+A+1)(B²+B+1)(C²+C+1))/(ABCD) where A,B,C,D > 0 is :🟢 Exactd3⁴ = 81
Concept The expression separates: the denominator ABCD splits one variable into each bracket, so the whole thing is a product of four independent copies of the same one-variable function. Minimise one copy and raise the result to the fourth power. The one-variable minimisation is the most basic AM–GM fact there is: t + 1/t ≥ 2.
Formula (A² + A + 1)/A = A + 1 + 1/A and by AM–GM A + 1/A ≥ 2√(A·1/A) = 2, so each factor ≥ 3. Equality in AM–GM needs A = 1/A, i.e. A = 1 — and A > 0 makes that attainable.
Solution
1. Split the single fraction into four: the expression equals [(A²+A+1)/A]·[(B²+B+1)/B]·[(C²+C+1)/C]·[(D²+D+1)/D].This is legal because ABCD in the denominator is just A·B·C·D.
2. Simplify a typical factor: (A² + A + 1)/A = A + 1 + 1/A.
3. Apply AM–GM to the two positive numbers A and 1/A: (A + 1/A)/2 ≥ √(A · 1/A) = 1, so A + 1/A ≥ 2.
4. Therefore each factor A + 1 + 1/A ≥ 2 + 1 = 3, and the same bound holds for B, C, D.
5. All four factors are positive, so multiplying the four inequalities is valid: the product ≥ 3 × 3 × 3 × 3 = 3⁴ = 81.
6. Equality is achieved, not merely approached: take A = B = C = D = 1. Then each bracket is 1 + 1 + 1 = 3 and ABCD = 1, giving 3·3·3·3/1 = 81 exactly.Always confirm attainability — a bound you cannot reach is not a minimum.
7. Hence the minimum value is 3⁴ ⇒ option (d).
8. Sanity check that the value really does rise away from A = 1: take A = 2, B = C = D = 1. First factor = 2 + 1 + 0.5 = 3.5, product = 3.5 × 27 = 94.5 > 81 ✓. And with A = 1/2: 0.5 + 1 + 2 = 3.5 again — the function is symmetric under A → 1/A.
  E = (A^2+A+1)(B^2+B+1)(C^2+C+1)(D^2+D+1) / (ABCD)
    = prod over X in {A,B,C,D} of (X + 1 + 1/X)

  AM-GM:  X + 1/X >= 2      (equality at X = 1)
  =>      X + 1 + 1/X >= 3
  =>      E >= 3^4 = 81,  attained at A=B=C=D=1

  check A=2, rest 1 : 3.5 * 27 = 94.5 > 81   ok
⚡ JEE Trick The instant you see a denominator that is the product of exactly the variables appearing one per bracket, split the fraction and minimise a single bracket — the answer is always (single minimum)number of brackets. Memorise (t² + t + 1)/t ≥ 3 for t > 0; it recurs constantly. Note the options 1/3⁴ and 1/2⁴ are traps for students who minimise the reciprocal, and 2⁴ traps those who stop at A + 1/A ≥ 2 and forget the middle "+1".
Answer: (d) 3⁴ = 81.
7If Σr=1n Tr = n(n+1)(n+2)/3, then limn→∞ Σr=1n (2008/Tr) =   (a) 2008   (b) 3012   (c) 4016   (d) 8032Recovering Tr from Sn, then telescopingHow to Find the Sum of a Telescoping Series🟡 Similara2008
Concept Two standard moves back to back. First, Tn = Sn − Sn−1 recovers the individual term from the running total. Here the answer is beautifully simple, Tn = n(n+1), because the cubic difference collapses. Second, 1/[n(n+1)] telescopes, so the infinite sum is just the first surviving fraction times the constant 2008.
Formula Tn = Sn − Sn−1; 1/[r(r+1)] = 1/r − 1/(r+1); hence Σr=1n 1/[r(r+1)] = 1 − 1/(n+1) → 1. The whole limit is therefore 2008 × 1.
Solution
1. Given Sn = n(n+1)(n+2)/3, so Sn−1 = (n−1)n(n+1)/3.
2. Tn = Sn − Sn−1 = [n(n+1)(n+2) − (n−1)n(n+1)]/3.
3. Factor out the common n(n+1): = n(n+1)[(n+2) − (n−1)]/3 = n(n+1)·3/3 = n(n+1).The bracket is (n+2) − (n−1) = 3, which cancels the 3 in the denominator exactly — that is why the term comes out so clean.
4. Check T₁: S₁ = 1·2·3/3 = 2 and formula gives 1·2 = 2 ✓. Check T₂: S₂ = 2·3·4/3 = 8, so T₂ = 8 − 2 = 6 and formula gives 2·3 = 6 ✓.
5. Now 2008/Tr = 2008/[r(r+1)] = 2008[1/r − 1/(r+1)].
6. Sum r = 1 to n: 2008[(1 − 1/2) + (1/2 − 1/3) + … + (1/n − 1/(n+1))] = 2008[1 − 1/(n+1)].
7. Let n → ∞: 1/(n+1) → 0, so the limit is 2008 × 1 = 2008 ⇒ option (a).
8. Numeric sanity check at n = 3: terms are 2008/2 + 2008/6 + 2008/12 = 1004 + 334.67 + 167.33 = 1506, and the formula gives 2008(1 − 1/4) = 2008 × 0.75 = 1506 ✓ — the partial sums creep up towards 2008 from below, never reaching 3012 or 4016.

  T_n = S_n - S_(n-1) = n(n+1)[(n+2)-(n-1)]/3 = n(n+1)

  2008/T_r = 2008 [ 1/r - 1/(r+1) ]
  sum r=1..n = 2008 [ 1 - 1/(n+1) ]   ->   2008   as n -> inf

  check n=3 : 1004 + 334.67 + 167.33 = 1506 = 2008 * 3/4   ok
⚡ JEE Trick When Sn is given as a product of consecutive integers over a constant, the difference Sn − Sn−1 always factors — pull out the terms common to both products and only a tiny bracket is left. Second reflex: a Σ 1/Tr with Tr = r(r+1) telescopes to exactly 1 in the limit, so the answer is simply the constant in the numerator. 8If Tk denotes the kth term of an H.P. from the beginning and T₂/T₆ = 9, then T₁₀/T₄ equals:   (a) 17/5   (b) 5/17   (c) 7/19   (d) 19/7H.P. ratios via the reciprocal A.P.If T(k) denotes the k-th term of an H.P. from the beginning and T2/T6 = 9, then T10/T4 equals🟢 Exactb5/17
Concept An H.P. has no formula of its own — you always flip to the reciprocal A.P. and work there. The one thing to be careful about is that flipping inverts the ratio: T₂/T₆ = 9 becomes (1/T₆)/(1/T₂) = 9, not the other way round. Get that right and the rest is one linear equation.
Formula If T₁, T₂, … are in H.P. then 1/Tk = A + (k−1)D is an A.P. Ratio conversion: Ti/Tj = (1/Tj)/(1/Ti). Because dividing by a reciprocal flips numerator and denominator.
Solution
1. Let bk = 1/Tk, so bk = A + (k−1)D is an A.P. Then b₂ = A + D, b₄ = A + 3D, b₆ = A + 5D, b₁₀ = A + 9D.
2. Translate the given ratio: T₂/T₆ = (1/b₂)/(1/b₆) = b₆/b₂. So b₆/b₂ = 9, i.e. A + 5D = 9(A + D).
3. Expand: A + 5D = 9A + 9D ⇒ −8A = 4D ⇒ D = −2A.Equivalently A = −D/2. The A.P. must therefore change sign somewhere — perfectly normal for an H.P.
4. Pick a convenient scaling: take A = −1, so D = 2 and bk = −1 + (k−1)·2 = 2k − 3.Scaling A and D by the same constant leaves every ratio unchanged, so this loses no generality.
5. Verify the hypothesis: b₂ = 1, b₆ = 9, so T₂/T₆ = b₆/b₂ = 9 ✓.
6. Now T₁₀/T₄ = b₄/b₁₀ = (2·4 − 3)/(2·10 − 3) = 5/17 ⇒ option (b).
7. Numeric sanity check in actual H.P. terms: T₄ = 1/5 = 0.2 and T₁₀ = 1/17 ≈ 0.0588, so T₁₀/T₄ = 0.0588/0.2 = 0.294 = 5/17 ✓ — while the decoy 17/5 = 3.4 is the reciprocal error.

     A + 5D = 9(A + D)  =>  D = -2A

10Paragraph. Let A₁, G₁, H₁ denote the arithmetic, geometric and harmonic means respectively, of two distinct positive numbers. For n ≥ 2, let An−1 and Hn−1 have arithmetic, geometric and harmonic means as An, Gn, Hn respectively.  Question: Which one of the following statements is correct?   (a) G₁ < G₂ < G₃ < ….   (b) G₁ = G₂ = G₃ = ….   (c) G₁ > G₂ > G₃ > ….   (d) G₁ < G₃ < G₅ < ….. and G₂ > G₄ > G₆ > ….   [JEE Advanced 2007 (Paper-2)] (Level-8)The invariant AnHn = AH of the AM–HM iterationLet A1, G1 and H1 denote the arithmetic, geometric and harmonic means respectively of two distinct…🟢 ExactbG₁ = G₂ = G₃ = ….
Concept The whole three-question paragraph rests on one invariant: for any two positive numbers, (A.M.) × (H.M.) = (the original product), because A = (a+b)/2 and H = 2ab/(a+b) multiply to ab. So each iteration preserves the product, and since G is the square root of the product, G never changes. That is the answer to this part and the engine for the other two.
Formula For positives a, b: A = (a+b)/2, G = √(ab), H = 2ab/(a+b), hence A·H = ab = G². This identity is the reason G is the "geometric mean" of A and H as well.
Solution
1. Let the two starting numbers be a and b (distinct positives). Then A₁ = (a+b)/2, G₁ = √(ab), H₁ = 2ab/(a+b).
2. Key identity: A₁H₁ = [(a+b)/2]·[2ab/(a+b)] = ab. So A₁H₁ = ab = G₁².
3. At the next stage A₂, G₂, H₂ are the means of the pair (A₁, H₁). Therefore G₂ = √(A₁H₁) = √(ab) = G₁.
4. Moreover A₂H₂ = A₁H₁ = ab, by the same identity applied to the pair (A₁, H₁) — so the product is invariant under the whole iteration.
5. By induction, AnHn = ab for every n, and hence Gn+1 = √(AnHn) = √(ab) = G₁.
6. Therefore G₁ = G₂ = G₃ = … — the geometric mean is constant ⇒ option (b).
7. Numeric sanity check with a = 1, b = 9: A₁ = 5, G₁ = 3, H₁ = 2(9)/10 = 1.8. Next: A₂ = (5 + 1.8)/2 = 3.4, H₂ = 2(5)(1.8)/6.8 = 18/6.8 ≈ 2.6471, G₂ = √(5 × 1.8) = √9 = 3 ✓.
8. One more step: A₃ = (3.4 + 2.6471)/2 ≈ 3.0235, H₃ = 2(3.4)(2.6471)/6.0471 ≈ 2.9767, G₃ = √(3.4 × 2.6471) = √9 = 3 ✓. The A's fall and the H's rise, both squeezing towards 3 — but G is pinned at 3 throughout.
  A H = [(a+b)/2][2ab/(a+b)] = ab = G^2       <-- the invariant

  G_(n+1) = sqrt(A_n H_n) = sqrt(ab) = G_1    for every n
  =>  G_1 = G_2 = G_3 = ...                          (b)

  a = 1, b = 9 :
     A: 5,      3.4,     3.0235,  ...  (decreasing)
     H: 1.8,    2.6471,  2.9767,  ...  (increasing)
     G: 3,      3,       3,       ...  (constant)
⚡ JEE Trick Commit A·H = G² to memory — it says G is the geometric mean of A and H, which is exactly why this iteration freezes G. The whole 2007 paragraph (three questions across three papers' worth of marks) is one identity. Once you know G is constant and A ≥ G ≥ H always holds, you can also predict the other two answers instantly: A must decrease monotonically to G and H must increase monotonically to G.
Answer: (b) G₁ = G₂ = G₃ = ….
11(Same paragraph.) Which of the following statements is correct?   (a) A₁ > A₂ > A₃ > …   (b) A₁ < A₃ < A₅ < ….. and A₂ > A₄ > A₆ > …..   (c) A₁ > A₃ > A₅ > ….. and A₂ < A₄ < A₆ < …..   (d) A₁ < A₂ < A₃ < …..   [JEE Advanced 2007 (Paper-2)] (Level-7)Monotone decrease of the arithmetic meansLet A_1, G_1, H_1 denote the arithmetic, geometric and harmonic means, respectively, of two disti...🟢 ExactaA₁ > A₂ > A₃ > …
Concept An is the average of An−1 and Hn−1, and we always have Hn−1 < An−1 (AM > HM for distinct positives). The average of a number and something strictly smaller is strictly smaller than the original — so each A is less than the one before. The sequence is monotonically decreasing, not oscillating, which rules out the alternating options.
Formula An = (An−1 + Hn−1)/2, and AM–GM–HM gives An−1 > Gn−1 > Hn−1 whenever the two numbers are distinct. The strictness is preserved at every stage because An−1 ≠ Hn−1 for all n.
Solution
1. By definition An is the arithmetic mean of the pair (An−1, Hn−1), i.e. An = (An−1 + Hn−1)/2.
2. For any two distinct positive numbers, AM > HM. Applying this at every stage: Hn−1 < An−1.An−1 and Hn−1 remain distinct forever, since their product is fixed at G² while they are not both equal to G.
3. Hence An = (An−1 + Hn−1)/2 < (An−1 + An−1)/2 = An−1.
4. Therefore the A-sequence is strictly decreasing: A₁ > A₂ > A₃ > … ⇒ option (a).
5. Also An > Gn = G₁ for every n (by AM ≥ GM), so the decreasing sequence is bounded below by G₁ — it converges down to G₁ rather than falling forever.
6. Options (b) and (c) describe oscillation, which cannot happen because each step is a strict one-directional average; option (d) claims increase, contradicting step 3.
7. Numeric sanity check with a = 1, b = 9 (from Q10): A₁ = 5, A₂ = 3.4, A₃ ≈ 3.0235, A₄ ≈ 3.00009 — strictly decreasing and converging to G = 3 ✓.
  A_n = (A_(n-1) + H_(n-1))/2   and   H_(n-1) < A_(n-1)

  =>  A_n < A_(n-1)      for every n     =>  A_1 > A_2 > A_3 > ...   (a)

  bounded below:  A_n > G_n = G_1   =>  A_n decreases to G_1

  a=1, b=9 :  A = 5, 3.4, 3.0235, 3.00009, ...  -> 3
⚡ JEE Trick Averaging a number with something strictly smaller always moves it down — no algebra needed. Pair that with the invariant Gn = G₁ from the previous part and you get the complete picture in one sentence: A decreases to G, H increases to G, G stands still. Whenever a JEE paragraph offers "monotone" versus "alternating" options, check whether one step is a plain average of the current value with a value on one fixed side; if so, monotone wins.
Answer: (a) A₁ > A₂ > A₃ > ….
12(Same paragraph.) Which of the following statements is correct?   (a) H₁ < H₃ < H₅ < ….. and H₂ > H₄ > H₆ > …..   (b) H₁ > H₂ > H₃ > …..   (c) H₁ < H₂ < H₃ < …..   (d) H₁ > H₃ > H₅ > ….. and H₂ < H₄ < H₆ < …..   [JEE Advanced 2007 (Paper-2)] (Level-6)Monotone increase of the harmonic meansLet A₁, G₁, H₁ denote the arithmetic, geometric and harmonic means, respectively,... | Doubtify JEE🟢 ExactcH₁ < H₂ < H₃ < ….
Concept The mirror image of the previous part — and the invariant makes it immediate. Since AnHn = G² is constant and we have just shown An is strictly decreasing, the partner Hn = G²/An must be strictly increasing. No new inequality work is needed at all.
Formula AnHn = G² (constant) ⇒ Hn = G²/An. Dividing a fixed positive constant by a decreasing positive sequence gives an increasing sequence.
Solution
1. From Q10, the product is invariant: AnHn = A₁H₁ = ab = G², the same constant for every n.
2. Hence Hn = G²/An.
3. From Q11, A₁ > A₂ > A₃ > … with every An > 0.
4. Taking reciprocals reverses the inequalities: 1/A₁ < 1/A₂ < 1/A₃ < …
5. Multiplying by the positive constant G² preserves the direction: H₁ < H₂ < H₃ < … ⇒ option (c).
6. Alternative direct argument: Hn is the harmonic mean of An−1 and Hn−1, and HM of two distinct numbers always lies strictly between them, so Hn > Hn−1 — the same conclusion without using the invariant.
7. The H-sequence is bounded above by G₁ (since Hn < Gn = G₁), so it increases up to G₁ — the exact mirror of A decreasing down to G₁.
8. Numeric sanity check with a = 1, b = 9: H₁ = 1.8, H₂ ≈ 2.6471, H₃ ≈ 2.9767, H₄ ≈ 2.99991 — strictly increasing towards 3 = G ✓, and at every stage AnHn = 5 × 1.8 = 3.4 × 2.6471 = 3.0235 × 2.9767 = 9 ✓.

  A_n strictly decreasing (Q11)  =>  1/A_n strictly increasing
                                 =>  H_n strictly increasing      (c)

  bounded above:  H_n < G_n = G_1   =>  H_n increases up to G_1

  a=1, b=9 :  H = 1.8, 2.6471, 2.9767, 2.99991, ...  -> 3
              A_n H_n = 9 at every stage

Store the three-line summary for the AM–HM iteration: A ↓, H ↑, G fixed, all converging to G₁. This construction is the classical arithmetic–harmonic mean iteration, and JEE has mined it for three separate questions from a single passage.
Answer: (c) H₁ < H₂ < H₃ < ….
