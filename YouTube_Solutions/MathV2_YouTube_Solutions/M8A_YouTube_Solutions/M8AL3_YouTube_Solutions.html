M8AL3VRecapQ1iAdding a constant to every term
🟢 ExactProperties of an Ari…
AP (an A.P., with the same d)
Concept The defining feature of an A.P. is the gap between neighbouring terms. Shifting every term by the same amount slides the whole progression along the number line without changing any gap — so the sequence is still an A.P. and its common difference is untouched.
Formula (an+1 ± k) − (an ± k) = an+1 − an = d the ±k cancels between consecutive terms
Solution
1. Let the new sequence be bn = an ± k.
2. Test the difference of consecutive new terms: bn+1 − bn = (an+1 ± k) − (an ± k).
3. The ±k appears once with each sign and cancels: bn+1 − bn = an+1 − an = d, a constant.
4. A constant difference is exactly the definition of an A.P., so the new sequence is an A.P. with the same common difference d.Only the first term moves: it becomes a₁ ± k.
5. Concrete check: 2, 5, 8, 11 (d = 3). Add 7: 9, 12, 15, 18 — still d = 3 ✓.
6. Consequence for sums: Snnew = Sn ± nk, because each of the n terms picked up the same ±k.
⚡ JEE Trick Learn the four transformations as a block, because papers combine them: +k keeps d, ×k scales d to kd, ÷k scales d to d/k, adding two A.P.s adds the d's. Everything in this Quick Recap is one of those four, and Level-1 tests all four again as MCQs.
Answer: an AP — with the same common difference d.

M8AL3VRecapQ1iiMultiplying every term by a constant
🟢 ExactSome important Prope…
Multiplied (new d = kd)
Concept Scaling every term by k stretches the whole number line by a factor k. The gaps stretch too — each gap becomes k times as wide — so the sequence stays an A.P. but its common difference is multiplied by k.
Formula (an+1k) − (ank) = k(an+1 − an) = kd
Solution
1. Let bn = k·an.
2. Consecutive difference: bn+1 − bn = k·an+1 − k·an = k(an+1 − an).
3. That equals kd — still a constant, so the new sequence is an A.P.
4. The blank therefore reads multiplied by k.k must be non-zero; if k = 0 every term collapses to 0, which is a trivial A.P. with d = 0 and the statement loses its content.
5. Concrete check: 2, 5, 8 (d = 3), times 4 gives 8, 20, 32 with d = 12 = 4 × 3 ✓.
6. Sum consequence: Snnew = k·Sn, since a common factor pulls straight out of a sum.
⚡ JEE Trick This is the property behind the surd A.P. √3, √12, √27, √48 (= √3 × 1, 2, 3, 4) and behind every "pull the common factor out" shortcut: 5 + 10 + … + 200 = 5 × (1 + 2 + … + 40). Recognising a scaled copy of a familiar A.P. is usually faster than applying the sum formula directly.
Answer: Multiplied by k — the new common difference is kd.

Concept Dividing by k is the same as multiplying by 1/k, so this is property (ii) with the reciprocal. The gaps shrink by the factor k and the sequence remains an A.P. — which is exactly why k must be non-zero.
Formula (an+1/k) − (an/k) = (an+1 − an)/k = d/k
Solution
1. Let bn = an/k = (1/k)·an.
2. By the scaling rule of part (ii) with constant 1/k, the new common difference is (1/k)·d.
3. So the new common difference is d/k — the blank reads divided.
4. Non-zero k is essential: dividing by 0 is undefined, so the hypothesis is not decoration.Note that k may be negative — then the A.P. simply reverses direction, since d/k flips sign.
5. Concrete check: 8, 20, 32 (d = 12) divided by 4 gives 2, 5, 8 with d = 3 = 12/4 ✓.
6. Warning: this is division of the terms by a constant, not taking reciprocals. 1/a₁, 1/a₂, 1/a₃ is an H.P., not an A.P. — a completely different chapter (M-8C).
⚡ JEE Trick The dangerous confusion is between an/k (still an A.P.) and k/an (an H.P.). Questions exploit the visual similarity constantly. Ask yourself where the variable sits: variable on top ⇒ A.P. survives; variable on the bottom ⇒ you are in harmonic territory.
Answer: divided by k — the new common difference is d/k.
1 (iv)
If a₁, a₂, a₃, …… and b₁, b₂, b₃, …… are two AP then a₁ ± b₁, a₂ ± b₂, a₃ ± b₃, ……… will also be an ______.
M8AL3VRecapQ1ivAdding two A.P.s term by term
🟡 SimilarSequence and Series…
AP (with d = d₁ ± d₂)
Concept Two constant step-sizes added together give another constant step-size. Formally, the general term of each A.P. is linear in n, and the sum of two linear functions is linear — so the combined sequence is an A.P.
Formula (an+1 ± bn+1) − (an ± bn) = d₁ ± d₂ d₁, d₂ are the two common differences
Solution
1. Let cn = an ± bn.
2. cn+1 − cn = (an+1 − an) ± (bn+1 − bn) = d₁ ± d₂.
3. Both d₁ and d₂ are constants, so their sum (or difference) is a constant — hence cn is an A.P.
4. Linear-function view: an = a + (n−1)d₁ and bn = b + (n−1)d₂ are both linear in n; adding gives (a ± b) + (n−1)(d₁ ± d₂), again linear ⇒ A.P.
5. Concrete check: 2, 5, 8 (d = 3) plus 1, 3, 5 (d = 2) gives 3, 8, 13 with d = 5 = 3 + 2 ✓.
6. Note the edge case: if d₁ = d₂ then the difference sequence has d = 0 — a constant sequence, which is still (trivially) an A.P.
⚡ JEE Trick A.P.s are closed under addition and scaling but not under multiplication: anbn is quadratic in n, so it is generally not an A.P. (2,5,8 times 1,3,5 gives 2, 15, 40 — differences 13 and 25). Options that claim the product stays an A.P. are always wrong.
Answer: an AP — with common difference d₁ ± d₂.

M8AL3VRecapQ2Four independent A.P. results
🟡 SimilarColumn - II
A→q, B→r, C→p, D→s
Concept Four unrelated techniques: an inequality from the outer-vs-inner product rule, common terms of two A.P.s (new d = lcm), maximising a decreasing A.P.'s sum, and matching Σn against Σn².
Formula a + d = b + c but ad < bc; common-term d = lcm(d₁, d₂); Σn = n(n+1)/2, Σn² = n(n+1)(2n+1)/6
Solution
1. (A) For a, b, c, d in A.P. the outer pair and inner pair have the same sum: a + d = b + c. But the inner product is larger: bc − ad = 2δ² > 0 where δ is the common difference. So 1/a + 1/d = (a+d)/(ad) > (b+c)/(bc) = 1/b + 1/c → (q).
2. (B) First A.P.: 2, 5, 8, … (d = 3), 100 terms, last = 299. Second: 3, 5, 7, … (d = 2), 100 terms, last = 201.
3. Common terms step by lcm(3, 2) = 6 and start at 5, so they are 5, 11, 17, …, capped by the smaller last term 201: 5 + 6(k−1) ≤ 201 ⇒ k ≤ 33.67 ⇒ 33 terms → (r).
4. (C) 50, 48, 46, …: a = 50, d = −2. Terms stay non-negative while 50 − 2(n−1) ≥ 0 ⇒ n ≤ 26, and a₂₆ = 0. Max sum at n = 25 (or 26, identical): S₂₅ = (25/2)(100 − 48) = 25 × 26 = 650 → (p).
5. (D) n(n+1)/2 = (1/5)·n(n+1)(2n+1)/6. Cancel n(n+1): 1/2 = (2n+1)/30 ⇒ 2n + 1 = 15 ⇒ n = 7 → (s).
6. Check (D): Σ₁..₇ = 28 and Σ₁..₇ squares = 140, and 28 = 140/5 ✓.
⚡ JEE Trick For (C), the rule for maximising the sum of a decreasing A.P. is: keep adding while the terms are positive, and stop at the last non-negative one. Solve an ≥ 0 for n and take the integer part. If some term is exactly zero, two consecutive n both give the maximum — the same "double answer" phenomenon as in L-2's 54, 51, 48 problem.
Answer: A→q, B→r (33), C→p (650), D→s (7).

Find the value of p, q, r: if the ratio of the sum of m and n terms of an AP is m² : n², then the ratio of its mth and nth term is (pm + q) : (pn − r).
M8AL3VRecapQ3iSum ratio m²:n² ⇒ odd-number A.P.
🟢 ExactThe ratio of the sum…
p = 2, q = −1, r = 1
Concept Sm/Sn = m²/n² for all m, n forces Sn ∝ n². The only A.P. with a perfectly square sum is a multiple of the odd numbers 1, 3, 5, 7, … — whose nth term is proportional to 2n − 1.
Formula Sn = kn² ⇒ an = k[n² − (n−1)²] = k(2n − 1)
Solution
Given the ratio of the sums of m and n terms of an A.P. is m² : n²
Find the values of p, q and r where the ratio of the mth and nth terms is (pm + q) : (pn − r)
1. From Sm/Sn = m²/n² holding for every pair, Sn must be kn² for a fixed constant k.
2. Recover the term: an = Sn − Sn−1 = k[n² − (n−1)²] = k(2n − 1).
3. So am : an = (2m − 1) : (2n − 1).
4. Compare with the printed shape (pm + q) : (pn − r). Matching the first slot: pm + q = 2m − 1 ⇒ p = 2, q = −1.
5. Matching the second slot: pn − r = 2n − 1 ⇒ 2n − r = 2n − 1 ⇒ r = 1.
6. Sanity check with the model A.P. 1, 3, 5, 7 (Sn = n²): a₃ : a₂ = 5 : 3 = (2·3 − 1) : (2·2 − 1) ✓.
⚡ JEE Trick Watch the signs in the template. Both slots encode 2x − 1, but one is written "+q" and the other "−r", so the same −1 must be reported once as q = −1 and once as r = +1. Papers use this to check whether you are reading the printed form or reciting a memorised answer.
Answer: p = 2, q = −1, r = 1  ⇒  am : an = (2m − 1) : (2n − 1).

Find the value of p, q, r: if the first, second and last term of an AP are a, b and 2a respectively, then its sum is pab / [q(b + ra)].
M8AL3VRecapQ3iiSum from three symbolic terms
🟢 ExactIf the first, second…
p = 3, q = 2, r = −1
Concept First and second term give d = b − a. First and last give the count via the nth-term formula. Then the ends-form S = (n/2)(first + last) finishes it — and the algebra is all symbolic, so care with the final rearrangement is what matters.
Formula d = b − a, ℓ = a + (n−1)d ⇒ n = (ℓ − a)/d + 1, S = (n/2)(a + ℓ)
Solution
Given the first, second and last terms of an A.P. are a, b and 2a
Find the values of p, q and r in its sum pab / [q(b + ra)]
1. Common difference: d = b − a.
2. Last term is 2a: 2a = a + (n − 1)(b − a) ⇒ (n − 1)(b − a) = a ⇒ n − 1 = a/(b − a).
3. So n = a/(b−a) + 1 = [a + b − a]/(b − a) = b/(b − a).
4. Ends-form: S = (n/2)(a + 2a) = (n/2)(3a) = (3a/2)·b/(b − a).
5. Therefore S = 3ab / [2(b − a)].
6. Compare with pab/[q(b + ra)]: p = 3, q = 2, and b + ra = b − a forces r = −1.
⚡ JEE Trick Test symbolic answers on a concrete A.P. Take a = 2, b = 3 (so d = 1): the progression is 2, 3, 4 and S = 9. The formula gives 3(2)(3)/[2(3−2)] = 18/2 = 9 ✓. Thirty seconds of arithmetic confirms a page of symbol-pushing — and would catch a sign slip on r instantly.
Answer: p = 3, q = 2, r = −1  ⇒  S = 3ab / [2(b − a)].
3 (iii)
Find the value of p, q, r: if S₁ is the sum of an AP of 'n' odd number of terms and S₂ the sum of the terms of the series in odd places, then S₁/S₂ = pn/(rn − q).
M8AL3VRecapQ3iiiWhole sum vs the odd-placed sub-A.P.
🟢 ExactIf S1 is sum of AP o…
p = 2, q = −1, r = 1
Concept Picking out every second term of an A.P. gives another A.P. — same first term, but double the common difference. Both sums have the same mean (the central term), so the ratio is just the ratio of the two term-counts.
Formula odd-place terms: a₁, a₃, a₅, … with common difference 2d; S = (count) × (middle term)
Solution
Given S₁ is the sum of an A.P. of n (odd) terms and S₂ is the sum of the terms in odd places
Find the values of p, q and r where S₁/S₂ = pn/(rn − q)
1. Write n = 2m + 1 (odd). The full A.P. has 2m + 1 terms.
2. Odd places are positions 1, 3, 5, …, 2m+1 — that is m + 1 terms, forming an A.P. with first term a and common difference 2d.
3. Both progressions are symmetric about the same centre term a + md, so each sum equals its count times that centre: S₁ = (2m+1)(a + md) and S₂ = (m+1)(a + md).
4. Ratio: S₁/S₂ = (2m + 1)/(m + 1). Now substitute m = (n − 1)/2, so m + 1 = (n + 1)/2.
5. S₁/S₂ = n / [(n+1)/2] = 2n/(n + 1).
6. Compare with pn/(rn − q): p = 2 and rn − q = n + 1 ⇒ r = 1, q = −1. Check n = 5 (terms 1..5, d = 1, a = 1): S₁ = 15, odd places 1, 3, 5 sum to 9, and 15/9 = 5/3 = 2(5)/6 ✓.
⚡ JEE Trick "Sum = count × middle term" is the cleanest tool for any odd-length A.P., and here it makes the whole question collapse to counting: 2m+1 terms versus m+1 terms. This exact result reappears as LEVEL-6 Q2 of this lecture as a four-option MCQ, so the work is reusable.
Answer: p = 2, q = −1, r = 1  ⇒  S₁/S₂ = 2n/(n + 1).

M8AL3VRecapQ4Rationalising, residue sums, Sₙ→aₙ, finite differences
🟢 ExactColumn - II
A→r, B→s, C→p, D→q
Concept Four separate techniques. (A) rationalise the surd denominators. (B) sum a residue class. (C) the standard Sn → an subtraction. (D) recognise a second finite difference.
Formula 1/(√x+√y) = (√x−√y)/(x−y); S = (n/2)(a+ℓ); an = Sn − Sn−1
Solution
1. (A) Let the common difference of a, b, c be δ, so b − c = −δ and a − b = −δ, c − a = 2δ. Rationalising, 1/(√b+√c) = (√c−√b)/δ, 1/(√c+√a) = (√c−√a)/(2δ), 1/(√a+√b) = (√b−√a)/δ.
2. Test the A.P. condition 2×middle = first + third: 2(√c−√a)/(2δ) = (√c−√a)/δ, and (√c−√b)/δ + (√b−√a)/δ = (√c−√a)/δ ✓. So they are in AP → (r).
3. (B) Two-digit numbers of the form 4k + 1: 13, 17, …, 97, with n = 22 terms. S = (22/2)(13 + 97) = 11 × 110 = 1210 → (s).
4. (C) Sn = 2n² + 5n ⇒ an = 2An + (B − A) with A = 2, B = 5 ⇒ an = 4n + 3 → (p).
5. (D) Write Sn − kSn−1 + Sn−2 with k = 2: it becomes (Sn − Sn−1) − (Sn−1 − Sn−2) = an − an−1 = d ✓.
6. So k = 2 → (q). Any other k leaves a stray multiple of Sn−1 that does not reduce to a constant.
⚡ JEE Trick Part (D) is the second finite difference in disguise: coefficients 1, −2, 1. Since Sn is quadratic in n, Δ² Sn is a constant, and that constant is d. The pattern continues — coefficients 1, −3, 3, −1 (the third difference) give 0, which is exactly LEVEL-6 Q3 of the previous lecture.
Answer: A→r (AP), B→s (1210), C→p (4n+3), D→q (2).

4
If a, b, c are in A.P. then show that (a − c)² = 4(b² − ac). (Level-4)
M8AL3VSuggQ4Algebraic identity from 2b = a + c
🟢 ExactIf a, b, c are in A.…
— (proof; no printed key)
Concept Every "a, b, c in A.P." proof starts by converting the hypothesis into the algebraic statement 2b = a + c. From there it is pure manipulation — here, recognising that (a − c)² and (a + c)² differ by 4ac.
Formula 2b = a + c; (a − c)² = (a + c)² − 4ac
Solution
1. Hypothesis: a, b, c in A.P. ⇒ b − a = c − b ⇒ 2b = a + c.
2. Start from the left side and use the difference-of-squares identity: (a − c)² = (a + c)² − 4ac.
3. Substitute a + c = 2b: (a − c)² = (2b)² − 4ac = 4b² − 4ac.
4. Factor 4: (a − c)² = 4(b² − ac). Proved.
5. Numerical check with 1, 4, 7 (an A.P.): LHS = (1 − 7)² = 36; RHS = 4(16 − 7) = 4(9) = 36 ✓.
6. Interpretation: b² − ac ≥ 0 always, and it equals (d)² where d is the common difference — so the identity says (a − c)² = 4d², which is obvious since a − c = −2d.
⚡ JEE Trick Keep the pair of identities (x+y)² − (x−y)² = 4xy and 2b = a + c together — almost every A.P. identity proof is one substitution away once you spot which square to expand. Also note b² − ac = d²: the quantity b² − ac measures the square of the common difference, which is why it can never be negative for a real A.P.
Answer: Proved — (a − c)² = 4(b² − ac), and both sides equal 4d².

Given the series 20 + 19 (1/3) + 18 (2/3) + …
Find its maximum sum (choose from the options)
1. Common difference: 19 (1/3) − 20 = 58/3 − 60/3 = −2/3. Confirm: 18 (2/3) − 19 (1/3) = 56/3 − 58/3 = −2/3 ✓.
2. Term condition: an = 20 − (2/3)(n − 1) ≥ 0 ⇒ (n − 1) ≤ 30 ⇒ n ≤ 31.
3. So a₃₁ = 20 − 20 = 0 exactly, and a₃₂ is negative. The maximum sum occurs at n = 30 or n = 31 (they are equal, since the 31st term adds nothing).
4. Compute S₃₀ = (30/2)[40 + 29(−2/3)] = 15[40 − 58/3] = 15 × (120 − 58)/3 = 15 × 62/3.
5. S₃₀ = 5 × 62 = 310 → option (a).
6. Cross-check via the ends-form: a₃₀ = 20 − 29(2/3) = 20 − 58/3 = 2/3, so S₃₀ = (30/2)(20 + 2/3) = 15 × 62/3 = 310 ✓.
⚡ JEE Trick The maximum-sum rule for a decreasing A.P.: solve an ≥ 0 and take the largest integer n. If a term is exactly zero, two consecutive n give the same maximum — precisely the "double answer" phenomenon of the 54, 51, 48 problem in Lecture L-2. Never differentiate the quadratic; the term-sign test is faster and exact.
Answer: (a) 310.

Concept Apply 2×middle = first + third, then split into cases at the points where the moduli change sign, namely x = −1 and x = 1. Each case gives a linear equation; keep only the roots that lie inside their own case's range.
Formula 2|x + 1| = x/2 + |x − 1| critical points x = −1 and x = 1
Solution
Given (1/2)x, |x + 1|, |x − 1| are in A.P.
Find the number of values of x
1. Case x ≥ 1: both moduli open positively: 2(x + 1) = x/2 + (x − 1) ⇒ 2x + 2 = 1.5x − 1 ⇒ 0.5x = −3 ⇒ x = −6. Not in x ≥ 1 — rejected.
2. Case −1 ≤ x < 1: |x+1| = x + 1 and |x−1| = 1 − x: 2(x + 1) = x/2 + (1 − x) ⇒ 2x + 2 = 1 − x/2 ⇒ 2.5x = −1 ⇒ x = −2/5. This lies in [−1, 1) — accepted.
3. Case x < −1: both moduli flip: 2(−x − 1) = x/2 + (1 − x) ⇒ −2x − 2 = 1 − x/2 ⇒ −1.5x = 3 ⇒ x = −2. This lies in x < −1 — accepted.
4. So exactly two values survive: x = −2/5 and x = −2 → option (c).
5. Verify x = −2/5: terms are −1/5, 3/5, 7/5 with d = 4/5 ✓.
6. Verify x = −2: terms are −1, 1, 3 with d = 2 ✓.
⚡ JEE Trick With k moduli you get at most k + 1 cases, and every root must be validated against its own case's inequality. Solving all cases but forgetting to discard out-of-range roots is the standard error — here it would give three "solutions" instead of two. Write the range next to each case before you solve it.
Answer: (c) 2  (x = −2/5 and x = −2).

Concept Two phases: ten flat minutes at 150 notes, then a decreasing A.P. starting at a₁₁ = 148. Subtract the flat block from the target and solve a quadratic for the number of A.P. minutes — then remember to add the 10 back.
Formula 10(150) + (k/2)[2(148) + (k−1)(−2)] = 4500 k = minutes after the first ten

Given 4500 currency notes counted; a₁ = a₂ = … = a₁₀ = 150; a₁₀, a₁₁, … are in A.P. with common difference −2
Find the time taken to count all the notes (choose from the options)
1. First 10 minutes: 10 × 150 = 1500 notes. Remaining: 4500 − 1500 = 3000.
2. From minute 11 the counts are 148, 146, 144, … — an A.P. with first term 148 and d = −2.a₁₀ = 150 is the anchor of that A.P.; the first new term is a₁₁ = 148.
3. Sum of k such minutes: (k/2)[296 − 2(k − 1)] = (k/2)(298 − 2k) = k(149 − k).
4. Set equal to 3000: k² − 149k + 3000 = 0. Discriminant = 22201 − 12000 = 10201 = 101².

Concept The principal repaid is fixed at Rs. 1000 a year, but the interest is charged on the outstanding balance, which drops by 1000 each year. So the interest payments themselves form a decreasing A.P., and the yearly totals do too.
Formula yearly payment = 1000 + 10% of outstanding; the outstanding runs 10000, 9000, …, 1000
Solution
Given a house bought for Rs. 15000; Rs. 5000 paid at once; the balance is paid in annual instalments of Rs. 1000 with 10% per annum interest on the remaining amount
Find the total money paid (choose from the options)
1. Balance after the down payment: 15000 − 5000 = Rs. 10000, cleared in 10 instalments of Rs. 1000 principal each.
2. Year 1: interest = 10% of 10000 = 1000, so the payment is 1000 + 1000 = 2000.
3. Year 2: outstanding is 9000, interest = 900, payment = 1900. Year 3: 1800. The payments fall by 100 each year.
4. So the ten payments are 2000, 1900, 1800, …, 1100 — an A.P. with a = 2000, d = −100, n = 10.
5. Their sum: S₁₀ = (10/2)(2000 + 1100) = 5 × 3100 = 15500.
6. Total paid = 5000 (down payment) + 15500 = Rs. 20500 → option (c).
⚡ JEE Trick Track the outstanding balance, not the payment, when interest is involved. Once you see the balance falling 10000, 9000, …, 1000, the interest is automatically 1000, 900, …, 100 — an A.P. whose sum is 10% of (10000 + 9000 + … + 1000) = 10% of 55000 = 5500. Then total = 5000 + 10000 principal + 5500 interest = 20500, which is an even faster route.

Concept Apply 2×middle = first + third to the logarithms, then convert to a statement about the arguments. Substituting t = 2n turns it into an ordinary quadratic; the negative root is impossible because 2n > 0.
Formula 2 log X = log 2 + log Y ⇒ X² = 2Y; set t = 2n
Solution
Given log 2, log(2n − 1), log(2n + 3) are in A.P.
Find the value of n (choose from the options)
1. A.P. condition: 2 log(2n − 1) = log 2 + log(2n + 3).
2. Combine logs: log(2n − 1)² = log[2(2n + 3)], so (2n − 1)² = 2(2n + 3).
3. Put t = 2n: t² − 2t + 1 = 2t + 6 ⇒ t² − 4t − 5 = 0.
4. Factor: (t − 5)(t + 1) = 0 ⇒ t = 5 or t = −1. Reject t = −1 since 2n > 0 always.
5. So 2n = 5 ⇒ n = log₂5 → option (b).
6. Domain check: with 2n = 5, the arguments are 2, 4 and 8 — all positive ✓. And log 2, log 4, log 8 = log2, 2log2, 3log2 is indeed an A.P. with d = log 2 ✓.

That is the general principle behind every log-A.P. question: logs are in A.P. exactly when the arguments are in G.P. Spotting that lets you skip straight to (2n − 1)² = 2(2n + 3), which is just the G.P. mean condition.

M8AL3V6Q10Discriminant condition under an A.P. constraint
🟢 ExactIf p, q, r are posit…
a|r/p − 7| ≥ 4√3
Concept Real roots need D = q² − 4pr ≥ 0. The A.P. condition replaces q by (p + r)/2, turning the inequality into one in p and r only — and dividing by p² reduces it to a single-variable quadratic inequality in t = r/p.
Formula q = (p + r)/2; D = q² − 4pr ≥ 0
Solution
Given p, q, r are positive and in A.P.; the roots of px² + qx + r = 0 are all real
Find the condition on p and r (choose from the options)
1. p, q, r in A.P. ⇒ 2q = p + r ⇒ q = (p + r)/2.
2. Real roots require q² ≥ 4pr, i.e. (p + r)²/4 ≥ 4pr ⇒ (p + r)² ≥ 16pr.
3. Expand: p² + 2pr + r² ≥ 16pr ⇒ p² − 14pr + r² ≥ 0.
4. Divide by p² (positive) and set t = r/p: t² − 14t + 1 ≥ 0.
5. The roots of t² − 14t + 1 = 0 are t = (14 ± √192)/2 = 7 ± 4√3. So the inequality holds for t ≤ 7 − 4√3 or t ≥ 7 + 4√3.
6. Both branches together say the distance of t from 7 is at least 4√3, i.e. |r/p − 7| ≥ 4√3 → option (a).
⚡ JEE Trick "Outside the roots" for an upward parabola is exactly what an absolute-value inequality with ≥ encodes: t² − 14t + 1 ≥ 0 with roots 7 ± 4√3 becomes |t − 7| ≥ 4√3, where 7 is the midpoint of the roots and 4√3 is half their separation. Learn to read a quadratic inequality straight into that form — it converts to the printed option in one step. Note also that option (b) writes p/r instead of r/p and uses a strict <, so it is wrong on both counts.
Answer: (a) |r/p − 7| ≥ 4√3.
