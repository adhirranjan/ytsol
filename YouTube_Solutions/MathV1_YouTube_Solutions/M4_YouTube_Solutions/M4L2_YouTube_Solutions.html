1Which correctly defines the identity function on R?Identity functionA-IDN🟡 Similarcf(x) = x for every x ∈ R
Concept The identity function is the simplest possible function: it hands back exactly what it receives. Every input is mapped to itself, so its graph is the perfectly straight 45° line y = x through the origin. It is the "do-nothing" map — the reference against which all other transformations (shifts, stretches, reflections) are measured.
Definition f : R → R, f(x) = x for every x ∈ R. "For every x" is the crucial phrase — a rule that returns the input only on part of the line is not the identity. Domain = R, range = R, and it is both one-to-one and onto.
Solution
1. Read the defining property: output must equal input, i.e. image of x is x.This is the literal meaning of "identity" — nothing is changed.
2. Write it as a rule: f(x) = x, valid for all real x.
3. Check the graph: plotting (x, x) for several x gives the line through the origin at 45°.
4. Reject look-alikes: f(x) = x² (not linear), f(x) = |x| (folds negatives up), f(x) = k (constant) — none return the input unchanged.
 candidate rule     f(0)  f(1)  f(-2)   identity?
 f(x) = x            0     1     -2      ✓ input returned
 f(x) = x²           0     1      4      ✗ changes -2 → 4
 f(x) = |x|          0     1      2      ✗ changes -2 → 2
 f(x) = k            k     k      k      ✗ ignores input
⚡ JEE Trick The identity map is the only function that is its own inverse and leaves composition unchanged: f∘g = g∘f = g whenever f is the identity. Spot it instantly as the 45° line y = x. Trap: options like "f(x) = x for x ≥ 0" restrict the domain and are not the identity on all of R.
Answer: f(x) = x for every x ∈ R (domain = range = R; graph is the line y = x).
2Evaluate |−3.5| + [2.3]Modulus + GIFA-GIF🟡 Similarc5.5
Concept Two different standard functions appear here and must be handled separately. The modulus |x| strips the sign, returning the non-negative size of a number. The greatest-integer function (GIF / floor) [x] returns the largest integer that is not greater than x — i.e. it rounds down on the number line, which matters most for negatives.
Formulas |x| = x if x ≥ 0, −x if x < 0; and [x] = the greatest integer ≤ x. For a positive non-integer, [x] just drops the decimal part; here both pieces are straightforward once each function is applied on its own.
Solution
1. Modulus term: |−3.5| = −(−3.5) = 3.5.−3.5 is negative, so |x| = −x flips the sign.
2. Floor term: [2.3] = greatest integer ≤ 2.3 = 2.2 ≤ 2.3 < 3, so the floor is 2 — drop the decimal for a positive number.
3. Add the two results: 3.5 + 2 = 5.5.
 term        rule applied         value
 |-3.5|      -(-3.5)              3.5
 [2.3]       greatest int ≤ 2.3   2
                        sum       5.5
⚡ JEE Trick Floor "rounds toward −∞," never toward zero. For positives [2.3] = 2 (drop decimal), but for negatives [−2.3] = −3, not −2 — the classic trap. Modulus is always ≥ 0. Keep the two operations in separate columns so you never accidentally floor the modulus or vice-versa.
Answer: 5.5
3Domain of the reciprocal function f(x)=1/(x−3)Domain (rational)A-DOMR🟡 SimilaraR − {3}
Concept The domain is the set of inputs for which the rule produces a real number. For a rational (fraction) function the only threat is division by zero, which is undefined. So finding the domain reduces to one job: locate every x that makes the denominator zero and exclude it.
Rule domain = R − { x : denominator = 0 }. A numerator can be anything, but a zero denominator has no real value, so those inputs are forbidden. Here the denominator is x − 3.
Solution
1. Set the denominator to zero: x − 3 = 0.These are the only "bad" points to remove.
2. Solve: x = 3.
3. Exclude it: every other real number is allowed, so domain = R − {3}.
 x        x - 3     1/(x-3)        allowed?
 2        -1        -1             ✓
 3         0        undefined      ✗  ← excluded
 4         1         1             ✓
 domain = R − {3} = (−∞, 3) ∪ (3, ∞)
⚡ JEE Trick For any single-fraction function, domain = "all reals except the roots of the denominator." Set denominator = 0, solve, punch those out. Trap: don't also exclude the numerator's zero (x = ... makes f = 0, which is perfectly valid) — only the denominator kills the domain.
Answer: R − {3}, i.e. (−∞, 3) ∪ (3, ∞)
4Range of f(x)=[x] (greatest-integer)GIF rangeA-GIF🟡 SimilarcZ (the set of all integers)
Concept The range is the set of all outputs a function actually produces. The greatest-integer function [x] always spits out a whole number — never a fraction — so its outputs live entirely inside the integers. The question is which integers appear, and the answer is "every one of them."
Rule [x] = greatest integer ≤ x, so every output is an integer; and for any integer n, choosing x = n gives [n] = n. Because each integer n is itself hit (put x = n), no integer is missed, and no non-integer is ever produced.
Solution
1. Note that [x] is an integer for every real x — the output is always whole.Flooring lands you on an integer by definition.
2. Show every integer is achievable: for integer n, [n] = n, so n is in the range.
3. No fraction can appear (the floor is never, say, 2.5).
4. Therefore range = the set of all integers, Z.
 x-interval        [x]
 [0, 1)             0
 [1, 2)             1
 [-1, 0)           -1
 [-2, -1)          -2
 every integer output is realised ⇒ range = Z
⚡ JEE Trick Domain of [x] = R, range of [x] = Z — commit this pair to memory. The graph is a staircase of unit steps, each closed on the left, open on the right. Trap: don't confuse range (Z, all integers) with the output on a single interval (a single integer).
Answer: Z (the set of all integers)
5Domain of f(x)=(x−2)/(x²−1)Domain (rational)A-DOMR🟡 SimilarcR − {1, −1}
Concept Same domain principle as any rational function — exclude denominator zeros — but now the denominator is a quadratic, so it can vanish at two points. Factor it, find both roots, and remove both from R.
Rule domain = R − { roots of denominator }; here x² − 1 = (x − 1)(x + 1). A product is zero exactly when one of its factors is zero, so a difference of squares gives two forbidden points.
Solution
1. Set denominator zero: x² − 1 = 0.
2. Factor as a difference of squares: (x − 1)(x + 1) = 0.x² − 1 = x² − 1², the standard a² − b² pattern.
3. Solve each factor: x = 1 or x = −1.
4. Exclude both: domain = R − {1, −1}.The numerator's zero (x = 2) is fine — it only makes f = 0, not undefined.
 x        x² - 1      f(x)           allowed?
 -1        0          undefined      ✗ excluded
  0       -1           2             ✓
  1        0          undefined      ✗ excluded
  2        3           0             ✓ (numerator zero is OK)
 domain = R − {1, −1}
⚡ JEE Trick A quadratic denominator can knock out up to two points — always factor, don't stop at one root. x² − a² ⇒ x = ±a both excluded. Trap: the numerator (x − 2) tempts you to exclude x = 2, but that value is perfectly legal — only denominator roots leave the domain.
Answer: R − {1, −1}, i.e. (−∞, −1) ∪ (−1, 1) ∪ (1, ∞)

1f(x)=4[x]−3 — find f(7.2), f(0.5), f(−5/2)GIF evaluationA-GIF🟡 Similar(a) 25, (b) −3, (c) −15
Concept This is a "plug-in" exercise for the greatest-integer function. The trick is order of operations: first floor the input, then apply the linear wrapper 4[x] − 3. The only place students slip is the negative argument, where the floor rounds down (toward −∞), not toward zero.
Formula f(x) = 4[x] − 3, with [x] = greatest integer ≤ x. [x] must be evaluated before multiplying by 4, because [x] is the inner function.
Solution
1. f(7.2): [7.2] = 7 ⇒ 4(7) − 3 = 28 − 3 = 25.7 ≤ 7.2 < 8, so floor is 7.
2. f(0.5): [0.5] = 0 ⇒ 4(0) − 3 = −3.0 ≤ 0.5 < 1, so floor is 0.
3. f(−5/2) = f(−2.5): [−2.5] = −3 ⇒ 4(−3) − 3 = −12 − 3 = −15.The largest integer ≤ −2.5 is −3, NOT −2 — floor moves left on the line.
 x       [x]     4[x] - 3        f(x)
 7.2      7      28 - 3           25
 0.5      0       0 - 3           -3
 -2.5    -3     -12 - 3          -15
⚡ JEE Trick For a negative non-integer, [x] = (integer part) − 1: [−2.5] → −3, [−0.1] → −1. Floor then transform. Trap: writing [−2.5] = −2 (rounding toward zero) is the single most common GIF error and flips the whole answer.
Answer: f(7.2) = 25, f(0.5) = −3, f(−5/2) = −15
2Piecewise f: 4x−2 (x≤−3), 5 (−3<x<3), x² (x≥3) → f(−4),f(−3),f(1),f(5)Piecewise evalA-PW🟡 Similar(a) −18, (b) −14, (c) 5, (d) 25
Concept A piecewise function uses different rules on different stretches of the number line. Evaluating it is a two-stage job: (1) decide which interval the input falls in — paying close attention to whether each endpoint is ≤ or < — then (2) apply only that piece's formula. Endpoint inequalities decide borderline cases like x = −3.
Definition f(x) = 4x − 2 (x ≤ −3); 5 (−3 < x < 3); x² (x ≥ 3). x = −3 belongs to the FIRST piece (it uses ≤ −3), and x = 3 belongs to the LAST piece (≥ 3); the middle piece is strictly between.
Solution
1. f(−4): −4 ≤ −3 ⇒ use 4x − 2 = 4(−4) − 2 = −16 − 2 = −18.
2. f(−3): −3 ≤ −3 (equality) ⇒ first piece: 4(−3) − 2 = −12 − 2 = −14.The ≤ sign puts the endpoint −3 in the first branch, not the middle one.
3. f(1): −3 < 1 < 3 ⇒ middle piece: 5 (constant).
4. f(5): 5 ≥ 3 ⇒ last piece: x² = 5² = 25.
 x     interval test        piece used     value
 -4    -4 ≤ -3              4x - 2          -18
 -3    -3 ≤ -3 (=)          4x - 2          -14
  1    -3 < 1 < 3           5                 5
  5    5 ≥ 3                x²               25
⚡ JEE Trick Always check the endpoint inequality first. Here −3 lives with ≤ (first piece) and 3 lives with ≥ (last piece) — mis-assigning a boundary point is the top piecewise mistake. Circle the ≤/≥ signs before plugging in.
Answer: f(−4) = −18, f(−3) = −14, f(1) = 5, f(5) = 25

1Range of the identity function f(x)=xIdentity functionA-IDN🟡 SimilarcR (all real numbers)
Concept The identity function returns its input unchanged, so whatever real numbers you feed in are precisely the real numbers that come out. The set of outputs (range) therefore mirrors the set of inputs (domain) exactly.
Definition f(x) = x, f : R → R. Range = set of all f(x) values. Since output = input, every real y is reached by choosing x = y, and no non-real value ever appears.
Solution
1. Take any target value y ∈ R; is it an output? Set f(x) = y ⇒ x = y works.Every real y is hit, because the input y maps to y.
2. No output can lie outside R, since f just echoes a real input.
3. Hence the outputs sweep the entire real line: range = R.
 x      f(x)=x       output covers
 -2      -2          negatives ✓
  0       0          zero ✓
  3.7     3.7        positives & decimals ✓
 range = R = (−∞, ∞)
⚡ JEE Trick For the identity map, domain = range = R; the graph y = x is the diagonal that hits every horizontal level exactly once (so it's also bijective). Trap: a restricted identity like f: [0,∞)→R, f(x)=x has range [0,∞), not R — always read the stated domain.
Answer: R (all real numbers)
2Which function has range {k}, k constant?Constant functionA-IDN🟡 Similarbthe constant function f(x) = k
Concept A range consisting of a single value {k} means the function produces the same output no matter what you put in. That is the defining behaviour of a constant function — a flat horizontal line at height k.
Definition f(x) = k for all x ∈ R, k a fixed real. Because the output never varies, the set of all outputs is just the one number k, written {k}. Domain = R, range = {k}.
Solution
1. Ask which function ignores its input entirely — output fixed at k.
2. That is f(x) = k (constant function); its graph is the horizontal line y = k.A horizontal line has the same height everywhere, so every input gives k.
3. Range = the single-element set {k}, exactly as required.
4. Contrast: identity f(x)=x has range R, |x| has range [0,∞) — none is a singleton.

 f(x)=k          k,  k,  k              {k}   ✓ singleton

⚡ JEE Trick Singleton range ⇔ constant function; horizontal-line graph. Note it is the extreme "many-to-one" map (every x → same k), so it is never injective. Trap: a constant function still has domain R — only the range collapses to one point.
Answer: the constant function f(x) = k (graph: horizontal line y = k)

4Range of f(x)=√xSquare-root functionA-SQRT🟡 Similarc[0, ∞)
Concept The symbol √ denotes the principal (non-negative) square root. By convention it returns only the non-negative root, so its outputs can never be negative. The range is therefore the set of non-negative reals, and every non-negative value is achievable.
Definition f(x) = √x, defined for x ≥ 0, with √x ≥ 0. To hit a target y ≥ 0, take x = y²; then √(y²) = y — so every non-negative y is produced, and none below 0.
Solution
1. Domain first: √x needs x ≥ 0 (can't take an even root of a negative real).
2. Output sign: the principal root is ≥ 0, so f(x) ≥ 0 always.
3. Every non-negative y is reached: √(y²) = y for y ≥ 0.Squaring a target and rooting it returns the target, proving nothing is missed.
4. Hence range = [0, ∞).

 1         1
 4         2
 9         3

⚡ JEE Trick √x: domain [0,∞), range [0,∞) — both start at 0 and go up. The graph is the top half of a sideways parabola. Trap: √x is never negative (that's why x² = 4 gives x = ±2 but √4 = +2 only); a "range = R" option is wrong.

1Domain of f(x)=√(x−1) is [a,∞) → a+5Root domainA-SQRT🟡 Similar6
Concept A two-step "find the parameter, then compute" problem. First get the domain of the root as an interval [a, ∞); the endpoint a is the value being extracted. Then substitute a into the requested expression a + 5.
Rule √(x − 1) real ⇔ x − 1 ≥ 0 ⇔ x ≥ 1, so domain = [1, ∞) ⇒ a = 1. Matching [a, ∞) to [1, ∞) identifies a as the left endpoint, 1.
Solution
1. Domain: x − 1 ≥ 0 ⇒ x ≥ 1 ⇒ domain = [1, ∞).
