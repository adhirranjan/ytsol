1If g(x) = 3x² + 2x − 3, f(0) = −3 and 4g(f(x)) = 3x² − 32x + 72, then f(g(2)) is equal to [JEE Main 2026, 28 Jan Shift-1] (Level-4) (a) 7/2 (b) −25/6 (c) −7/2 (d) 25/6Composition g(f(x)), recovering an unknown fIf g(x)=3x^2+2x-3, f(0)=-3 and 4g(f(x))=3x^2-32x+72, then f(g(2)) is equal to (JEE Main 2026)🟢 Exact⚠ c−7/2
Concept We are handed the outer function g and the composite 4g(f(x)), and asked to recover the hidden inner function f. The lever is a degree count: g is quadratic, so g(f(x)) has degree 2·deg(f). The composite is printed as a quadratic, so 2·deg(f) = 2 and deg(f) = 1 — f is forced to be linear. The condition f(0) = −3 then pins its constant term, leaving exactly one unknown to solve for by comparing coefficients.
Formula deg(g∘f) = deg(g) × deg(f); two polynomials are equal as functions iff every matching coefficient is equal.
Solution
1. Degree count: g is quadratic and 4g(f(x)) = 3x² − 32x + 72 is quadratic, so 2·deg(f) = 2, giving deg(f) = 1. Write f(x) = px + q.This is the step that makes the problem finite — without it f could be anything.
2. Use f(0) = −3: f(0) = p·0 + q = q = −3. So f(x) = px − 3, one unknown p left.
3. Build g(f(x)) from g(t) = 3t² + 2t − 3 with t = px − 3: g(f(x)) = 3(px−3)² + 2(px−3) − 3.
4. Multiply by 4: 4g(f(x)) = 12(px−3)² + 8(px−3) − 12.
5. Expand (px−3)² = p²x² − 6px + 9, so 12(px−3)² = 12p²x² − 72px + 108.Straight binomial expansion — keep the 12 outside until the end to avoid slips.
6. And 8(px−3) = 8px − 24. Add the three pieces: 4g(f(x)) = 12p²x² − 72px + 108 + 8px − 24 − 12.
7. Collect like terms: 4g(f(x)) = 12p²x² + (−72p + 8p)x + 72 = 12p²x² − 64p·x + 72.Note the constant already lands on 72 for every p — a free consistency check.
8. Compare with 3x² − 32x + 72. Constant: 72 = 72 ✓. x²: 12p² = 3 → p² = 1/4 → p = ±1/2.
9. The x-coefficient breaks the tie: −64p = −32 → p = 1/2. (p = −1/2 would give +32x, wrong sign.)Both conditions must hold at once; only p = 1/2 satisfies both.
10. So f(x) = x/2 − 3.
11. Evaluate the inner value: g(2) = 3(2)² + 2(2) − 3 = 12 + 4 − 3 = 13.g(2), not f(2) — the question asks for f(g(2)), outer f applied to g(2).
12. Finally f(g(2)) = f(13) = 13/2 − 3 = 13/2 − 6/2 = 7/2.
Matching coefficients, term by term:

  4 g(f(x)) = 12 p^2 x^2  -  64 p x  +  72
  target    =     3  x^2  -    32  x  +  72
              ---------------------------------
  x^2 :  12 p^2 = 3      ->  p = +1/2  or  -1/2
  x^1 :  -64 p  = -32    ->  p = +1/2          <-- breaks the tie
  x^0 :      72 = 72     ->  free check, holds

  f(x) = x/2 - 3
  g(2) = 3(4) + 2(2) - 3 = 13
  f(13) = 13/2 - 3 = 7/2
⚡ JEE Trick When a composite is given and one function is hidden, count degrees before doing any algebra — deg(g∘f) = deg(g)·deg(f) instantly tells you the shape of the unknown, turning an impossible functional problem into a two-line coefficient match. Second habit: after the leading coefficient gives p = ±k, always let the linear coefficient pick the sign; papers plant both ± answers in the options (here 7/2 and −7/2 are both printed) precisely to catch students who stop at p² = 1/4. Third: the constant term matching for free (72 = 72) confirms your expansion is clean.
Answer: (a) 7/2 — the printed key says (c); see the ⚠ note.
2Given below are two statements: Statement I: The function f : R → R defined by f(x) = x/(1 + |x|) is one-one. Statement II: The function f : R → R defined by f(x) = (x² + 4x − 30)/(x² − 8x + 18) is many-one. In the light of the above statements, choose the correct answer from the options given below [JEE Main 2026, 28 Jan Shift-2] (Level-4) (a) Both Statement I and Statement II are true (b) Statement I is false but Statement II is true (c) Statement I is true but Statement II is false (d) Both Statement I and Statement II are falseOne-one vs many-one, monotonicity and rangeStatement I: f(x)=x/(1+|x|) is one-one. Statement II: f(x)=(x^2+4x-30)/(x^2-8x+18) is many-one🟢 Exact⚠ bStatement I is false but Statement II is true
Concept Two independent injectivity questions. Statement I is settled by monotonicity: a function that is strictly increasing on the whole of R is automatically one-one. The modulus makes f piecewise, so check each piece and the joint at x = 0. Statement II is settled by finding one repeated value: a single pair x₁ ≠ x₂ with f(x₁) = f(x₂) proves many-one outright — no need to analyse the whole range.
Formula f strictly monotonic on R ⇒ f is one-one; conversely ∃ x₁ ≠ x₂ with f(x₁) = f(x₂) ⇒ f is many-one. Also ax²+bx+c > 0 ∀x when a > 0 and D = b²−4ac < 0.
Solution
1. Statement I. Split on the sign of x: for x ≥ 0, |x| = x so f(x) = x/(1+x); for x < 0, |x| = −x so f(x) = x/(1−x).The modulus is the only obstruction; removing it makes each branch a plain rational function.
2. Branch x > 0: f′(x) = [(1+x)·1 − x·1]/(1+x)² = 1/(1+x)² > 0. Strictly increasing.Quotient rule; the numerator collapses to 1.
3. Branch x < 0: f′(x) = [(1−x)·1 − x·(−1)]/(1−x)² = (1 − x + x)/(1−x)² = 1/(1−x)² > 0. Strictly increasing.
4. Joint at x = 0: both branches give f(0) = 0, and f is continuous there. So f is strictly increasing across the join, not just on each side.Without this check a function can increase on each piece yet still repeat a value across the join — here it cannot.
5. Strictly increasing on all of R ⇒ one-one. Statement I is TRUE. (Sanity: f maps R onto (−1, 1) — it is one-one but not onto R, which is a different matter and does not affect the claim.)
6. Statement II. First confirm the function is defined on all of R: the denominator x² − 8x + 18 has D = (−8)² − 4(1)(18) = 64 − 72 = −8 < 0 with leading coefficient 1 > 0, so it is strictly positive — never zero.If it vanished somewhere, f : R → R would not even be well defined and the statement would fail for a trivial reason.
7. Hunt for a repeated value. The cheapest target is the value 0: f(x) = 0 ⇔ numerator x² + 4x − 30 = 0.
8. Solve x² + 4x − 30 = 0: x = [−4 ± √(16 + 120)]/2 = [−4 ± √136]/2 = −2 ± √34.√136 = 2√34, so the 2 cancels cleanly.
9. Both roots are real and distinct (√34 ≠ 0), and both lie in R. So f(−2 + √34) = f(−2 − √34) = 0 with −2 + √34 ≠ −2 − √34.
10. Two distinct inputs, one output ⇒ f is not one-one. Statement II is TRUE.
11. Both statements true ⇒ the correct option is (a).
STATEMENT I : f(x) = x / (1 + |x|)

   x >= 0 :  f = x/(1+x),  f' = 1/(1+x)^2 > 0
   x <  0 :  f = x/(1-x),  f' = 1/(1-x)^2 > 0
   x  = 0 :  both branches give 0, f continuous
   ==> strictly increasing on all of R  ==> ONE-ONE   (TRUE)

STATEMENT II : f(x) = (x^2 + 4x - 30)/(x^2 - 8x + 18)

   denominator D = 64 - 72 = -8 < 0, a = 1 > 0  ==> never zero
   f(x) = 0  <=>  x^2 + 4x - 30 = 0  ->  x = -2 +/- sqrt(34)
   two distinct x, same output 0        ==> MANY-ONE  (TRUE)

   Both true  ==>  option (a)
⚡ JEE Trick For "is it one-one?" reach for monotonicity, not the f(a) = f(b) ⇒ a = b grind — and when a modulus appears, differentiate each branch and then check the join, which is the only place the argument can break. For "is it many-one?" you never need the full range: exhibit one repeated value. Pick the value that makes the algebra cheapest — for a rational function that is almost always y = 0, since it reduces to setting the numerator to zero. If that numerator is a quadratic with positive discriminant, you are done in one line. Finally, in Statement-I/II questions the two claims are independent: settle each on its own and only then read the options, or you will be led by the distractors.
Answer: (a) Both Statement I and Statement II are true — the printed key says (b); see the ⚠ note.
