1 (i)The sum of integers from 1 to 100 that are divisible by 2 or 5 is ______.Inclusion–exclusion on two A.P.sThe sum of the integers from 1 to 100 which are not divisible by 3 or 5🟡 Similar3050
Concept "Divisible by 2 or 5" is a set-union question wearing a series disguise. The multiples of 2 form an A.P., the multiples of 5 form an A.P., and the numbers counted twice are exactly the multiples of 10 = lcm(2, 5). So sum the two A.P.s and subtract the overlap once — that is inclusion–exclusion, the single most useful counting identity in this chapter.
Formula |A ∪ B| sum = ΣA + ΣB − Σ(A ∩ B) with each piece an A.P.: Sₙ = (n/2)(first + last). A ∩ B here is "divisible by both 2 and 5" = "divisible by 10", never "divisible by 2×5 terms".
Solution
1. Multiples of 2 in [1,100]: 2, 4, 6, …, 100. Count n = 100/2 = 50.
2. Their sum = (50/2)(2 + 100) = 25 × 102 = 2550.Equivalently 2(1+2+…+50) = 2·(50·51/2) = 2550.
3. Multiples of 5: 5, 10, …, 100. Count n = 20, sum = (20/2)(5 + 100) = 10 × 105 = 1050.
4. Multiples of 10 (counted in both lists): 10, 20, …, 100. Count n = 10, sum = (10/2)(10 + 100) = 5 × 110 = 550.
5. Inclusion–exclusion: total = 2550 + 1050 − 550 = 3050.
6. Sanity check by complement: 1+2+…+100 = 5050. Numbers divisible by neither 2 nor 5 are those coprime-ish to 10, i.e. ending in 1, 3, 7, 9 — ten decades × (1+3+7+9 + 4×offset). Decade k (offset 10k, k = 0..9) contributes 20 + 40k, so the total is 10·20 + 40(0+1+…+9) = 200 + 1800 = 2000. And 5050 − 2000 = 3050 ✓
  div by 2  :  2550
  div by 5  :  1050
  div by 10 :  -550    <-- subtract the double-counted block
  ----------------
  total     :  3050

Answer: 3050.
1 (ii)If a, b, c are in G.P., then the equations ax² + 2bx + c = 0 and dx² + 2ex + f = 0 have a common root if d/a, e/b, f/c are in ______.Common root + G.P. condition → A.P.SEQUENCE & SERIES in One Shot: All Concepts & PYQs Covered | JEE Main & Advanced🟡 SimilarA.P.
Concept The hypothesis "a, b, c in G.P." means b² = ac, and that is exactly the condition that makes the discriminant of ax² + 2bx + c vanish: (2b)² − 4ac = 4(b² − ac) = 0. So the first quadratic has a repeated root, which pins the common root down completely — no case work needed.
Formula Repeated root of ax² + 2bx + c = 0 is x = −b/a. Substituting into the second equation and dividing by a gives d/a − 2e/b + f/c = 0. Any relation of the shape 2·middle = first + last is an A.P. statement.
Solution
1. G.P. condition: b² = ac.
2. Discriminant of the first equation: (2b)² − 4ac = 4b² − 4ac = 4(b² − ac) = 0, so it has the double root x₀ = −2b/(2a) = −b/a.
3. The two quadratics share a root, and the first has only one root, so that shared root must be x₀ = −b/a.
4. Put x₀ into the second: d·(b²/a²) − 2e·(b/a) + f = 0.
5. Replace b² by ac in the first term: d·(ac/a²) − 2eb/a + f = 0 ⟹ dc/a − 2eb/a + f = 0.
6. Multiply by a/c: d − 2eb/c + fa/c = 0. Now use b² = ac once more in the form a/c = a²/(ac) = a²/b², giving d − 2e·a/b + f·a²/(ac) = d − 2ea/b + fa/c = 0.Every step is just "replace ac by b²" or "replace b² by ac" — nothing else happens.
7. Divide the last line by a: d/a − 2e/b + f/c = 0, i.e. 2(e/b) = d/a + f/c.
8. That is precisely the middle-term condition for an A.P., so d/a, e/b, f/c are in A.P.
9. Numerical check: take a, b, c = 1, 2, 4 (G.P.). Then x² + 4x + 4 = 0 has the double root −2. Choose d = 1, f = 4 and force −2 to be a root of x² + 2ex + 4 = 0: 4 − 4e + 4 = 0 ⟹ e = 2. Now d/a, e/b, f/c = 1, 1, 1 — an A.P. ✓
  b^2 = ac   =>  D of (ax^2+2bx+c) = 4(b^2-ac) = 0
             =>  double root x = -b/a
  put in 2nd :  d b^2/a^2 - 2eb/a + f = 0

⚡ JEE Trick Whenever a quadratic is written with a 2b middle coefficient and the data says "a, b, c in G.P.", stop and check the discriminant — it is always zero, and the double root −b/a turns a two-equation problem into a one-line substitution. Trap: hunting for the common root with the cross-multiplication formula; it works but takes five times longer.
Answer: A.P. — d/a, e/b, f/c form an arithmetic progression.
1 (iii)Sum of the first n terms of the series 1/2 + 3/4 + 7/8 + 15/16 + …… is equal to ______.Splitting Tₙ into "1 − (½)ⁿ"The sum to n terms of the series 1/2 + 3/4 + 7/8 + 15/16 + ..... is given by🟢 Exactn + 2−n − 1
Concept Neither an A.P. nor a G.P. — but the numerator of every term is exactly one less than its denominator. That single observation splits each term into a constant 1 minus a G.P. term, and the whole sum collapses into "n minus a geometric sum". This split-the-term move is the workhorse of the entire "special series" lesson.
Formula Tₖ = (2ᵏ − 1)/2ᵏ = 1 − (1/2)ᵏ, and Σ(1/2)ᵏ, k = 1…n = 1 − (1/2)ⁿ. The bracketed geometric sum has a = 1/2, r = 1/2, so it equals (1/2)(1 − (1/2)ⁿ)/(1 − 1/2) = 1 − 2⁻ⁿ.
Solution
1. Read the pattern of denominators: 2, 4, 8, 16, … = 2ᵏ. Numerators: 1, 3, 7, 15, … = 2ᵏ − 1.
2. So the general term is Tₖ = (2ᵏ − 1)/2ᵏ.
3. Split it: Tₖ = 2ᵏ/2ᵏ − 1/2ᵏ = 1 − 2⁻ᵏ.Do not try to sum (2ᵏ−1)/2ᵏ directly; the split is what makes it summable.
4. Add k = 1 to n: Sₙ = Σ1 − Σ2⁻ᵏ = n − (2⁻¹ + 2⁻² + … + 2⁻ⁿ).
5. The bracket is a G.P. with a = 1/2, r = 1/2: its sum = (1/2)·[1 − (1/2)ⁿ]/(1/2) = 1 − 2⁻ⁿ.
6. Therefore Sₙ = n − (1 − 2⁻ⁿ) = n + 2⁻ⁿ − 1.
7. Check n = 1: 1 + 1/2 − 1 = 1/2 ✓ (the first term). Check n = 2: 2 + 1/4 − 1 = 5/4, and 1/2 + 3/4 = 5/4 ✓. Check n = 3: 3 + 1/8 − 1 = 17/8, and 1/2 + 3/4 + 7/8 = 4/8 + 6/8 + 7/8 = 17/8 ✓
  T_k  =  (2^k - 1)/2^k  =  1 - 2^(-k)
  S_n  =  n - (2^-1 + 2^-2 + ... + 2^-n)
       =  n - (1 - 2^-n)
       =  n + 2^-n - 1
⚡ JEE Trick Whenever numerator = denominator − 1, write the term as 1 − (1/denominator). The same trick answers "sum of 1/2 + 3/4 + 7/8 + … to infinity" instantly: it diverges, because Sₙ → n. Trap: reading 1/2, 3/4, 7/8 as an A.P. of fractions — the differences 1/4, 1/8 are not equal.
Answer: Sₙ = n + 2−n − 1.
1 (iv)An infinite G.P. has first term 'x' and sum '5', then x belongs to ______.Convergence condition |r| < 1 turned into a range for the first termAn infinite G.P has first term x and sum 5 then x belongs to ?🟢 Exact0 < x < 10 ⚠
Concept An infinite G.P. only has a sum when |r| < 1. So a question that fixes the sum is really a question about r: solve for r in terms of the first term, then feed r into the convergence inequality. The answer is always an interval, never a single number.
Formula S∞ = a/(1 − r), valid only for |r| < 1. Here a = x and S∞ = 5, so r = 1 − x/5. Rearranged from 5(1 − r) = x.
Solution
1. Write the sum formula: 5 = x/(1 − r).
2. Cross-multiply: 5 − 5r = x ⟹ 5r = 5 − x ⟹ r = 1 − x/5.
3. Impose convergence: −1 < r < 1, i.e. −1 < 1 − x/5 < 1.
4. Subtract 1 throughout: −2 < −x/5 < 0.
5. Multiply by −5 and flip both inequality signs: 10 > x > 0, i.e. 0 < x < 10.Multiplying an inequality by a negative number reverses it — this is the step where marks are lost.
6. Reality check on the endpoints: x = 10 forces r = −1 (oscillating, no sum); x = 0 forces r = 1 and a zero first term (no G.P. at all). Both are correctly excluded.
7. Spot check inside the range: x = 5 gives r = 0 — degenerate but the sum 5 works; x = 2 gives r = 3/5 and S∞ = 2/(1 − 0.6) = 5 ✓; x = 9 gives r = −4/5 and S∞ = 9/(1 + 0.8) = 5 ✓
  5 = x/(1-r)   =>   r = 1 - x/5
  |r| < 1       =>   -1 < 1 - x/5 < 1
                =>   -2 < -x/5 < 0
                =>    0 <  x    < 10
⚡ JEE Trick Sum fixed and positive ⇒ the first term must be positive too, because a/(1−r) with |r| < 1 has 1 − r > 0. That one line kills every negative option instantly, without solving anything. Trap: forgetting to reverse the inequality when dividing by −5 (which is exactly how the answer −10 < x < 0 gets manufactured).
Answer: 0 < x < 10. ⚠ Flag: the printed key −10 < x < 0 is the sign-flip error; a negative first term cannot give a sum of +5 in a convergent G.P.

Concept When the first differences of a sequence are themselves an A.P., the general term is a quadratic in n. The second difference is constant and equals 2 × (leading coefficient), which hands you p in one line; the remaining two unknowns come from two easy substitutions.
Formula If Tₙ = pn² + qn + r then 2nd difference = 2p. Because T(n+1) − T(n) = p(2n+1) + q is linear in n with slope 2p.
Solution
1. Write the terms: 2, 7, 16, 29.
2. First differences: 7 − 2 = 5, 16 − 7 = 9, 29 − 16 = 13.
3. Second differences: 9 − 5 = 4, 13 − 9 = 4 — constant 4, so the general term is quadratic.
4. Constant 2nd difference = 2p ⟹ 2p = 4 ⟹ p = 2.
5. Use n = 1: T₁ = 2 ⟹ 2(1) + q + r = 2 ⟹ q + r = 0.
6. Use n = 2: T₂ = 7 ⟹ 2(4) + 2q + r = 7 ⟹ 2q + r = −1.
7. Subtract: (2q + r) − (q + r) = −1 − 0 ⟹ q = −1, and then r = 1.

9If a1 = ½; ak+1 = ak² + ak. Find the greatest integer less than or equal to 1/(a1+1) + 1/(a2+1) + 1/(a3+1) + … + 1/(a100+1).Recursive telescope from a quadratic recurrenceSuper 5 JEE Advanced Questions From Sequence & Series🟡 Similar1
Concept The recurrence factorises as ak+1 = ak(ak + 1), and that is precisely the shape of a telescoping partial fraction: 1/[a(a+1)] = 1/a − 1/(a+1). Rearranged, 1/(ak+1) = 1/ak − 1/ak+1, so the sum collapses to two boundary terms — you never compute a single ak.
Formula ak+1 = ak(ak+1) ⟹ 1/ak+1 = 1/ak − 1/(ak+1), hence 1/(ak+1) = 1/ak − 1/ak+1. Divide 1/[a(a+1)] = 1/a − 1/(a+1) and read it backwards.
Solution
1. Factorise the recurrence: ak+1 = ak² + ak = ak(ak + 1).
2. Take reciprocals: 1/ak+1 = 1/[ak(ak+1)] = 1/ak − 1/(ak+1).
3. Rearrange: 1/(ak+1) = 1/ak − 1/ak+1 — a perfect telescope.
4. Sum k = 1 to 100: S = (1/a₁ − 1/a₂) + (1/a₂ − 1/a₃) + … + (1/a₁₀₀ − 1/a₁₀₁) = 1/a₁ − 1/a₁₀₁.
5. With a₁ = ½: S = 2 − 1/a₁₀₁.
6. Now bound a₁₀₁. Compute the first few: a₁ = 0.5, a₂ = 0.25 + 0.5 = 0.75, a₃ = 0.5625 + 0.75 = 1.3125, a₄ = 1.7227 + 1.3125 = 3.035, a₅ ≈ 12.25, a₆ ≈ 162.4 — the sequence is increasing and explodes.Once ak > 1 the map a ↦ a² + a more than doubles each time, so a₁₀₁ is astronomically large.
7. Hence 1/a₁₀₁ is a tiny positive number, so S = 2 − (tiny positive) lies strictly between 1 and 2. In fact S > 2 − 1/162 > 1.99.
8. The greatest integer ≤ S is therefore 1.
9. Cross-check with a short sum: for just 5 terms, S₅ = 2 − 1/a₆ = 2 − 1/162.4 = 1.9938 — already floor 1 ✓, and adding more terms only pushes it closer to 2 without ever reaching it.
  a_(k+1) = a_k(a_k + 1)
  =>  1/(a_k + 1) = 1/a_k - 1/a_(k+1)

10Let Fn denote the Fibonacci sequence (F1 = 1, F2 = 1, Fn+1 = Fn + Fn−1). Hence evaluate (i) Σn=2∞ 1/(Fn−1 Fn+1).Fibonacci recurrence as a telescoping deviceSequence & Series Monster Question from JEE Advanced🟡 Similar1
Concept The Fibonacci recurrence written as Fn = Fn+1 − Fn−1 is exactly the "last minus first" numerator that the Vn-method wants. Insert it into the numerator of 1/(Fn−1Fn+1) and the term splits into a difference of two adjacent products — a telescope with no algebra at all.
Formula Fn+1 = Fn + Fn−1 ⟹ Fn = Fn+1 − Fn−1, hence 1/(Fn−1Fn+1) = 1/(Fn−1Fn) − 1/(FnFn+1). Multiply the identity by 1/(Fn−1FnFn+1).
Solution
1. Start from the recurrence in difference form: Fn = Fn+1 − Fn−1.
2. Divide both sides by Fn−1FnFn+1: Fn/(Fn−1FnFn+1) = (Fn+1 − Fn−1)/(Fn−1FnFn+1).
3. Left side simplifies to 1/(Fn−1Fn+1); right side splits into 1/(Fn−1Fn) − 1/(FnFn+1).
4. So 1/(Fn−1Fn+1) = 1/(Fn−1Fn) − 1/(FnFn+1), i.e. Gn − Gn+1 with Gn = 1/(Fn−1Fn).
5. Sum from n = 2 to N: the sum telescopes to G₂ − GN+1 = 1/(F₁F₂) − 1/(FNFN+1).
6. With F₁ = F₂ = 1, the first piece is 1/(1 × 1) = 1.
7. As N → ∞ the Fibonacci numbers grow without bound, so 1/(FNFN+1) → 0.
8. Therefore Σn=2∞ 1/(Fn−1Fn+1) = 1.
9. Numerical check with F = 1, 1, 2, 3, 5, 8, 13, 21: terms are 1/(F₁F₃) = 1/2, 1/(F₂F₄) = 1/3, 1/(F₃F₅) = 1/10, 1/(F₄F₆) = 1/24, 1/(F₅F₇) = 1/65, 1/(F₆F₈) = 1/168. Running total: 0.5, 0.8333, 0.9333, 0.9750, 0.9904, 0.9964 — converging to 1 ✓

  1/(F_(n-1) F_(n+1)) = 1/(F_(n-1) F_n) - 1/(F_n F_(n+1))

  Sum n=2..N  =  1/(F_1 F_2) - 1/(F_N F_(N+1))
