Concept The two core binary operations on sets are union and intersection, and each has its own dedicated symbol. Union collects every element that lies in A or B (or both) — it is the "combine everything" operation. Its symbol is the cup-shaped ∪; the similar-looking cap ∩ is the different operation, intersection.
Formula A ∪ B = { x : x ∈ A or x ∈ B }. The connecting word is the inclusive "or", so an element qualifies if it is in at least one of the sets. Contrast: A ∩ B = { x : x ∈ A and x ∈ B } uses "and".
Solution
1. Identify the operation named: "union" means gather all elements of both sets.Union is about inclusion — nothing is dropped.
2. Match it to its symbol: the union sign is the upward cup ∪.Mnemonic: ∪ looks like a cup that holds everything you pour in — union.
3. Reject the look-alike ∩ (cap), which is intersection ("and", overlap only).
 operation      meaning              symbol
 union          A or B (all)         ∪   ✓
 intersection   A and B (overlap)    ∩
⚡ JEE Trick Cup ∪ = Union (both start like "U"); cap ∩ = intersection. Trap: the symbols look nearly identical rotated — always read the opening direction (∪ opens up, ∩ opens down).
Answer: ∪ (the union symbol).

Concept When you simply add n(A) and n(B), every element sitting in the overlap A∩B is counted twice — once as part of A and once as part of B. The inclusion–exclusion principle corrects this by subtracting the overlap exactly once, giving the true size of the union.
Formula n(A∪B) = n(A) + n(B) − n(A∩B). The −n(A∩B) removes the double-count of the shared elements, leaving each element counted once.
Solution
1. Note the givens: n(A) = 20, n(B) = 15, n(A∩B) = 5.
2. Substitute into the formula: n(A∪B) = 20 + 15 − 5.
3. Add first: 20 + 15 = 35.
4. Subtract the overlap: 35 − 5 = 30.The 5 shared elements were counted twice in the 35, so one copy is removed.

 union total   15 + 10 + 5 = 30  ✓
⚡ JEE Trick Always subtract the overlap once — the single most-tested set formula. Cross-check by regions: (only A)+(only B)+(both) must equal n(A∪B). Trap: forgetting the minus sign gives 35, the classic wrong answer.

Concept A set formed from the letters of a word keeps only distinct letters (repeats collapse).
