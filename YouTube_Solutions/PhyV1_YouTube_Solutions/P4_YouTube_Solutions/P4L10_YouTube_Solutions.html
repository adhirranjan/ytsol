1What is a frame of reference? (a fixed object used to define motion)Frame of referenceWhat is Frame of reference | Physics Class 11🟢 ExactbA fixed object used to define motion
Concept Motion is never absolute — an object is said to move only when its position changes relative to some chosen reference. A frame of reference is exactly that reference: a rigid object (or point) together with a set of coordinate axes and a clock, against which we measure where something is and how fast it moves. Change the frame and the same object can be "at rest" (you seated in a moving train) or "moving" (that train seen from the platform). The trap is to imagine an object has one true velocity; it only has a velocity with respect to a stated frame.
Formula r = position measured from the origin O of the frame, and v = Δr/Δt in m s⁻¹. Both r and v are quoted relative to O, so a different origin/frame gives different numbers — which is the whole reason the definition matters. A frame needs: an origin (a fixed object), axes (directions) and a clock (time).
Solution
1. Ask what the measuring stick and clock are attached to: that anchor is the fixed object defining the origin.Without a fixed reference the words "at rest" and "moving" carry no meaning.
2. Option (b) "a fixed object used to define motion" names precisely this anchor ⇒ it is the frame of reference.
3. Test it: a passenger is at rest in the train frame yet moving in the ground frame — the fixed object (train vs ground) decides the answer.
4. Eliminate the distractors: a frame is not a force, not a unit of speed, and not the moving object itself — it is the reference we watch that object against.
5. Hence the correct description is option (b): a fixed object (with axes and a clock) used to define and measure motion.
 frame = fixed object + axes + clock
 --------------------------------------------------

 observer on TRAIN  :  passenger at rest (0 m/s)
 same passenger, two frames => two velocities   <-- answer: motion is frame-dependent
⚡ JEE Trick Whenever a problem says "velocity of X", silently append "with respect to which frame?" — ground, train, belt, water. Naming the frame first kills almost every relative-motion sign error. Trap: picking "the moving object" as the frame; the frame is the reference you measure from, not the thing being measured.
Answer: (b) A fixed object used to define motion.
2Relative velocity between two objects moving in the same direction with equal speeds? (zero)Relative velocity basicsWhen will the relative velocity of two moving objects be zero?🟢 ExactcZero
Concept Relative velocity is a vector subtraction: vAB = vA − vB is what an observer riding on B measures for A. Here both objects travel in the same direction with equal speeds, so their velocity vectors are identical — same magnitude, same direction. Subtracting a vector from itself must give the zero vector. Physically, if two bodies keep the same velocity, the gap between them never changes, so from either one the other appears frozen in place.
Formula vAB = vA − vB — velocity of A relative to B, in m s⁻¹. Two velocities (m s⁻¹) subtract to a velocity (m s⁻¹) — dimensionally sound. Given: same direction (same sign) and equal magnitude, |vA| = |vB| = v.
Solution
1. Take the common direction of travel as positive; the motion is 1-D.
2. Same direction, equal speed ⇒ vA = +v m s⁻¹ and vB = +v m s⁻¹ — the two velocities are equal.
3. Substitute: vAB = vA − vB = v − v = 0 m s⁻¹.Equal vectors cancel exactly, in both magnitude and direction.
4. Interpret: zero relative velocity means the separation between A and B stays constant in time — each sees the other as stationary.
5. Sanity check: v = 20 m s⁻¹ each ⇒ vAB = 20 − 20 = 0. So option (c) Zero. Contrast: opposite equal speeds would give vAB = v − (−v) = 2v, not zero.
 case (same line)              v_AB = v_A - v_B     result
 same dir, equal speed (this)  20 - 20 =  0         zero    <-- answer
 same dir, A faster            20 - 12 = +8         positive
 opposite, equal speed         20 - (-20) = 40      large
⚡ JEE Trick "Equal velocity ⇒ zero relative velocity ⇒ fixed gap" — recognise it instantly and skip the algebra. On an x–t graph the two paths are parallel straight lines. Trap: equal speed is not enough; the directions must also match. Opposite directions at equal speed give 2v, the maximum, not zero.
Answer: (c) Zero.
3Formula for the relative position vector between points A and B? (rB − rA)Relative position vectorRelative Position Vector🟢 ExactcrA – rB ⚠
Concept The relative position vector of B with respect to A is the arrow drawn from A to B. By the triangle rule of vectors, starting at the origin O: to go O→B directly equals O→A followed by A→B, so rA + rBA = rB, giving rBA = rB − rA. The order is the whole point: you always subtract the tail point's position from the head point's position. This same rule underlies relative velocity (differentiate it once) and relative displacement.
Formula rBA = rB − rA — position of B relative to A (vector from A to B). Head minus tail: the arrow points to B, so B's position vector comes first; both terms are position vectors (m), so the result is a displacement (m). This is the notation printed on the lesson's own theory page.
Solution
1. Place both points by their position vectors from a common origin O: A at rA, B at rB.
2. Apply the triangle law along O→A→B: rA + rBA = rB.The trip O→B must equal O→A then A→B — vectors add tip-to-tail.
3. Rearrange for the relative (A→B) vector: rBA = rB − rA.
4. Fix the direction by a check: if B is farther out than A along the same line, rB − rA points from A towards B, exactly as required.
5. This is printed option (b) rB − rA, which also matches this row's question stem and the book's theory page (r(B,A) = rB − rA). The reversed form rA − rB would be the position of A relative to B — the opposite arrow.

4What type of graph shows two objects moving with the same velocity? (two parallel lines)Position-time graph, zero relative velocityPosition-time graphs of two objects with equal velocities — special case of relative velocity🟢 ExactbTwo parallel lines
Concept On a position–time (x–t) graph the slope of each line is that object's velocity. "Two objects moving with the same velocity" therefore means two lines with the same slope — and lines of equal slope are, by definition, parallel. They need not coincide: the objects can start at different positions (different intercepts), so the lines stay a fixed distance apart, reflecting a constant separation (zero relative velocity).
Formula v = slope = Δx/Δt in m s⁻¹; equal velocity ⇒ slope1 = slope2. Two straight lines with identical slope never meet (unless identical) — the geometric meaning of "parallel". Different x-intercepts ⇒ a constant gap between them.
Solution
1. Translate the physics to geometry: on an x–t graph, velocity = slope.
2. "Same velocity" for both objects ⇒ their lines have the same slope.
3. Two lines of equal slope are parallel ⇒ the graph is two parallel lines — option (b).
4. Confirm with relative velocity: same slope ⇒ vrel = v1 − v2 = 0, so the separation is constant and the lines never converge.Parallel lines keep a fixed perpendicular gap — the visual signature of zero relative velocity.
5. Eliminate distractors: intersecting lines ⇒ different velocities (they meet, i.e. same position at one instant); a curved line ⇒ changing velocity (acceleration). Only parallel straight lines encode equal, constant velocities.

Trap: reading two intersecting lines as "same velocity" — an intersection means equal position at that instant, not equal velocity; only parallelism gives equal velocity.

5If object A moves faster than object B in the same direction, what is the nature of their relative velocity? (positive)Sign of relative velocityRelative velocity of a body moving in the same direction of another body🟡 SimilarcNegative ⚠
Concept Relative velocity is a vector subtraction, and its sign (in 1-D) carries physical meaning: it tells you whether the gap between the two bodies is opening or closing, and in which direction. Here A and B move along the same line in the same direction, with A the faster one. Asking for "the nature of vAB" means: is vA − vB positive, negative, or zero? Because both velocities point the same way, they carry the same sign, and the subtraction is a plain difference of magnitudes.
Formula vAB = vA − vB — velocity of A relative to B, in m s⁻¹. Both terms are velocities (m s⁻¹), so the difference is also m s⁻¹ — dimensionally consistent. Assumption: motion is along one straight line, and we take the common direction of travel as positive.
Solution
1. Fix a sign convention: take the direction in which both A and B move as positive.In 1-D a sign fully specifies a vector's direction, so one axis is enough.
2. Both move the same way ⇒ vA = +|vA| m s⁻¹ and vB = +|vB| m s⁻¹ — both positive.
3. "A moves faster than B" is given ⇒ |vA| > |vB| m s⁻¹.
4. Substitute into the formula: vAB = vA − vB = |vA| − |vB| m s⁻¹.A bigger positive number minus a smaller positive number is positive.
5. Since |vA| > |vB|, the difference is > 0 ⇒ vAB is positive, matching option (a).
6. Sanity check with numbers: vA = 20 m s⁻¹, vB = 12 m s⁻¹ ⇒ vAB = 20 − 12 = +8 m s⁻¹ — A pulls ahead of B by 8 m every second, which is exactly what "faster" means.

 v_A > v_B   (this question)    e.g. 20 - 12 = +8   positive  A pulls ahead   ✓
 v_A = v_B                      e.g. 15 - 15 =  0   zero      gap stays fixed

⚡ JEE Trick For 1-D relative velocity, same direction ⇒ subtract, opposite directions ⇒ add the magnitudes. The sign then reads off directly: positive = the gap opens in your chosen +direction (A gains on B). Trap: option (b) "Zero" is only true for equal speeds — the word "faster" rules it out; and (c) "Negative" would need B to be the faster one, so it is just the reversed convention.
Answer: (a) Positive.

1Train S moves north at 25 ms⁻¹; a monkey runs at 5 ms⁻¹ on the roof against the train's motion. Speed of the monkey as seen from the ground? (20 ms⁻¹ towards north)Relative velocity, train–monkey problemA train moves north at 54 km/hr and a monkey runs on the roof🟡 Similarc20ms−1 (towards north)
Concept The monkey's 5 m s⁻¹ is quoted with respect to the train, not the ground — it is what a passenger sitting on the train would measure. The ground observer sees the monkey carried along by the train and running backwards on top of it, so the two motions superpose. The bridge between the two observers is the relative-velocity addition rule; getting the signs right is the entire problem.
Formula vMG = vMT + vTG — velocity of Monkey w.r.t. Ground = (velocity of Monkey w.r.t. Train) + (velocity of Train w.r.t. Ground), all in m s⁻¹. The inner subscripts (T) cancel like a chain: M→T→G gives M→G, so the units and the direction bookkeeping both work out. Assumption: all motion is along the north–south line; take north as positive.
Solution
1. Set the convention: north = +, south = −. Motion is 1-D along this axis.
2. Train w.r.t. ground: it moves north at 25 m s⁻¹ ⇒ vTG = +25 m s⁻¹.
3. Monkey w.r.t. train: it runs at 5 m s⁻¹ against the train's motion, i.e. towards the south ⇒ vMT = −5 m s⁻¹."Against its motion" fixes the sign as opposite to the train's — this is the step the question is really testing.
4. Add them: vMG = vMT + vTG = (−5) + (+25) = +20 m s⁻¹.
5. Read the sign: the result is positive, so the monkey moves at 20 m s⁻¹ towards the north as seen from the ground — option (c).The train carries the monkey north faster than the monkey can run south, so it still drifts north — just more slowly than the train.

4Two balls A and B are projected vertically, one upward and one downward, from a height. What is the relative acceleration between them? (zero)Relative acceleration under gravityRelative Velocity and Relative Acceleration — Motion in a Straight Line (Hindi)🟡 Similara0
Concept The question deliberately contrasts velocity with acceleration. The two balls are thrown in opposite directions, so their relative velocity is large — but once released, the only force on either ball is gravity. Free fall is famously independent of mass and of initial velocity: every projectile near the Earth's surface accelerates at exactly g downward. Since both share the identical acceleration vector, the difference of the two vanishes.
Formula aAB = aA − aB — relative acceleration of A w.r.t. B, in m s⁻². Both terms are accelerations (m s⁻²), so their difference is m s⁻² — dimensionally consistent. Assumptions: air resistance is neglected, and both balls are in free flight near the Earth's surface, so aA = aB = g downward = 9.8 m s⁻².
Solution
1. Take downward as positive and note that after release the only force on each ball is its weight.The throw sets the initial velocity, but it exerts no force once the ball has left the hand.
2. Ball A (thrown upward): its velocity points up, but its acceleration is aA = +g = +9.8 m s⁻² (downward).Gravity always pulls down — it decelerates A on the way up, then speeds it up coming down. The acceleration never changes.
3. Ball B (thrown downward): its acceleration is also aB = +g = +9.8 m s⁻² (downward).
4. Subtract: aAB = aA − aB = (+9.8) − (+9.8) = 0 m s⁻².
5. So the relative acceleration is zero — option (a).Physically: in B's frame, A moves in a straight line at constant relative velocity. This is exactly why "in relative motion under gravity, gravity cancels" is such a powerful shortcut.
