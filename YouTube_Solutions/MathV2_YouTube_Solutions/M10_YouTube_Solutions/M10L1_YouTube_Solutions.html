1 (i)Fill in the blanks: Roots of quadratic equation 2x^2 + x - 1 = 0 ________Roots of quadratic equationHow to Solve 2x^2 + x - 1 = 0 by Factoring🟢 Exactx = -1, 1/2
Concept The roots of a quadratic are the values of x that make the polynomial vanish, and a degree-2 polynomial over the reals has exactly two of them counted with multiplicity. For 2x² + x - 1 = 0 all coefficients are small integers, so splitting the middle term is faster than the quadratic formula. Splitting is available precisely when the product ac factorises into two integers whose sum is b, which is the same as saying the discriminant is a perfect square.
Formula ax² + bx + c = 0 ⇒ x = (-b ± √(b² - 4ac))/2a. The formula is the fallback; when D is a perfect square, factorisation reaches the same two roots with less arithmetic.
Solution
1. Read off a = 2, b = 1, c = -1, so ac = 2(-1) = -2 and we need two integers with product -2 and sum b = +1; they are +2 and -1.
2. Split the middle term: 2x² + 2x - x - 1 = 0.
3. Group in pairs: 2x(x + 1) - 1(x + 1) = 0 ⇒ (x + 1)(2x - 1) = 0. The common bracket (x + 1) appearing in both groups is the check that the split was the correct one.
4. Zero-product rule: x + 1 = 0 or 2x - 1 = 0, giving x = -1 or x = 1/2. A product vanishes only when a factor vanishes, because the reals have no zero divisors.
5. Confirm by formula: D = b² - 4ac = 1² - 4(2)(-1) = 1 + 8 = 9, so x = (-1 ± 3)/4 = 1/2 or -1.
6. Confirm by Vieta: α + β = -1 + 1/2 = -1/2 = -b/a and αβ = (-1)(1/2) = -1/2 = c/a. Matching both relations validates the pair as a set, whereas checking one root only validates that root.
  a = 2,  b = 1,  c = -1
  D = b^2 - 4ac = 1 + 8 = 9    (perfect square)
  sqrt(D) = 3
  x1 = (-1 + 3)/4 =  1/2
  x2 = (-1 - 3)/4 = -1
  sum  = -1/2 = -b/a   OK
  prod = -1/2 =  c/a   OK
⚡ JEE Trick The trap is the sign of c: because c = -1 is negative, the two split integers must have opposite signs, and the mirror choice -2 and +1 sums to -1 instead of +1 and hands you the wrong pair x = 1, -1/2. One second on -b/a kills that error, since the true sum must be -1/2, not +1/2. Note also that D = 9 is a perfect square, so the roots are rational, which is the quickest way to predict that clean factors exist at all.
Answer: x = -1, 1/2.

Concept Dividing a polynomial P(x) by a linear divisor leaves a remainder of degree less than 1, i.e. a constant. Writing P(x) = (x - a)Q(x) + R and putting x = a collapses the quotient term entirely and leaves R = P(a). So the whole long division is replaced by one substitution. The only care needed is reading the correct value of a from the divisor: x + 1 means a = -1, not +1.
Formula P(x) ÷ (x - a) ⇒ R = P(a); here x + 1 = x - (-1) so a = -1. The divisor must be written in the exact form (x - a) before the sign of a is read off.
Solution
1. Identify P(x) = x³ + 5x² + 2x + 3 and the divisor x + 1, so the test value is x = -1.
2. Substitute term by term: R = P(-1) = (-1)³ + 5(-1)² + 2(-1) + 3.
3. Evaluate the powers first: (-1)³ = -1 and (-1)² = +1, so R = -1 + 5 - 2 + 3. Odd powers of -1 stay negative, even powers turn positive; this alternation is where most sign slips happen.
4. Add left to right: -1 + 5 = 4, 4 - 2 = 2, 2 + 3 = 5, hence R = 5.
5. Since R = 5 ≠ 0, x + 1 is not a factor of P(x). The factor theorem is just the remainder theorem with R = 0, so a non-zero remainder settles divisibility instantly.
6. Cross-check by synthetic division with -1: coefficients 1, 5, 2, 3 reduce to quotient 1, 4, -2 with last entry 5, matching R = 5. Synthetic division returns the quotient x² + 4x - 2 as a bonus, so P(x) = (x + 1)(x² + 4x - 2) + 5.
  P(x) = x^3 + 5x^2 + 2x + 3 ,  divisor x + 1  => a = -1

  synthetic division by -1:
    1     5     2     3
         -1    -4     2
    ------------------------
    1     4    -2  |  5   <- remainder
  quotient = x^2 + 4x - 2 ,  R = 5
⚡ JEE Trick The single classic error is substituting x = +1 for the divisor x + 1, which gives 1 + 5 + 2 + 3 = 11 and is the distractor most often printed. Force yourself to rewrite x + 1 as x - (-1) so the sign of a is read mechanically. Note the remainder is a plain constant here only because the divisor is linear; a quadratic divisor would leave a remainder of the form px + q.
Answer: Remainder = 5.
1 (iii)Fill in the blanks: Value of Discriminant for quadratic equation 5x^2 + 7x + 1 = 0 is ________Nature of roots / discriminantQuadratic Equation - Nature of Roots and Discriminant🟡 SimilarD = 29
Concept The discriminant D = b² - 4ac is the quantity sitting under the square root in the quadratic formula, so its sign alone decides the nature of the roots before any root is computed. D > 0 gives two distinct real roots, D = 0 a repeated real root, and D < 0 a conjugate pair of complex roots. When the coefficients are rational there is a second layer: D a perfect square makes the roots rational, otherwise they are irrational conjugates. Computing D is therefore always the first move on a nature-of-roots question.
Formula D = b² - 4ac for ax² + bx + c = 0, a ≠ 0. D is exactly the square of the difference of the roots times a², which is why its sign controls whether the roots separate on the real line.
Solution
1. Compare 5x² + 7x + 1 = 0 with ax² + bx + c = 0 to get a = 5, b = 7, c = 1; a ≠ 0 so it is genuinely quadratic.
2. Substitute directly: D = b² - 4ac = 7² - 4(5)(1) = 49 - 20 = 29.
3. Since 29 > 0, the roots are real and distinct. A positive D means √D is a real non-zero number, so the two formula branches land at different points.
4. 29 is not a perfect square (25 < 29 < 36), so with rational coefficients the roots are irrational and occur as the conjugate pair (-7 ± √29)/10. Irrational roots of a rational quadratic must pair as p ± √q, otherwise the sum or product would fail to be rational.
5. Sanity check by Vieta: sum = -7/5 and product = 1/5, both rational, consistent with a conjugate irrational pair.
6. Numerically √29 ≈ 5.385, so the roots are about -0.161 and -1.239, both negative, matching a negative sum and a positive product. Sign checking the numerical roots against Vieta catches any arithmetic slip in D.
  a = 5,  b = 7,  c = 1
  D = b^2 - 4ac = 49 - 20 = 29

  D > 0            -> real and distinct
  D not a square   -> irrational conjugates
  x = (-7 +/- sqrt(29)) / 10
  x ~= -0.161  and  -1.239
⚡ JEE Trick The two habitual slips are writing D = b² + 4ac and forgetting to square b, which would give 49 + 20 = 69 or 7 - 20 = -13 respectively; both appear as printed distractors in this style of question. Also remember that a mere D > 0 does not promise nice roots, only 29 being a perfect square would have done that.
Answer: D = 29.

Concept If a quadratic is written as a product of two linear factors, expanding that product must reproduce the original polynomial coefficient for coefficient, because two polynomials are equal only when every matching coefficient agrees. That gives a small system of equations in the unknown letter. Here the leading coefficients already match at 1, so only the x-coefficient and the constant carry information. Either equation alone determines p, and the second one then acts as a free consistency check.
Formula (x + m)(x + n) = x² + (m + n)x + mn. Comparing coefficients is legitimate because a polynomial identity holds for every x, not merely at a few points.
Solution
1. Expand the given factorisation: (x + 1)(x + p) = x² + px + x + p = x² + (p + 1)x + p.
2. Match this with x² + 8x + 7 term by term, so p + 1 = 8 and p = 7. Two conditions on one unknown is over-determined, so agreement between them confirms the factorisation is genuine.
3. From the constant term p = 7 directly, and from the x-term p = 8 - 1 = 7; the two agree, so p = 7.
4. Verify by the factor theorem instead: x + 1 a factor requires f(-1) = 1 - 8 + 7 = 0, which holds, so the other factor is genuine too. A factor of a monic quadratic forces the cofactor to be monic linear, so the form x + p is the only possibility.
5. Independently, split the middle term: x² + 8x + 7 = x² + 7x + x + 7 = (x + 7)(x + 1), again giving p = 7.
6. Hence the roots are x = -1 and x = -7, with sum -8 = -b/a and product 7 = c/a. Vieta closes the loop: any wrong p would break one of these two relations immediately.
  (x + 1)(x + p) = x^2 + (p + 1)x + p
  compare with     x^2 +    8x    + 7

  x  term : p + 1 = 8  -> p = 7
  const   : p     = 7  -> p = 7   (consistent)

  factors : (x + 1)(x + 7) ,  roots x = -1, -7
⚡ JEE Trick The trap is answering with the root instead of the parameter: the factor x + 7 corresponds to the root x = -7, so -7 is the tempting wrong entry while the question asks for p itself. Read whether the blank wants the letter in the factor or the zero of the polynomial. A second guard is that in (x + m)(x + n) the constant term is mn, not m + n, so with leading coefficient 1 the constant of the quadratic hands you p in one glance.
Answer: p = 7.

The degree is the largest exponent carrying a non-zero coefficient, the leading coefficient is the number multiplying that highest power, and the number of terms counts only the non-zero monomials actually present. Writing the polynomial in descending powers makes all three visible at once.
Formula P(x) = aₙxⁿ + … + a₁x + a₀, aₙ ≠ 0: degree = n, leading coefficient = aₙ. The condition aₙ ≠ 0 is what makes the degree well defined; a zero top coefficient would demote the polynomial.

Concept An equation containing only even powers of x is a quadratic in disguise: substituting t = x² turns it into a genuine quadratic, which is solved first and then unwound. Here the resulting quadratic is a perfect square, so the whole quartic is the square of a quadratic and its roots repeat. Degree counts the multiplicity, so a quartic always has four roots counted with multiplicity even when only two distinct values appear. The ordering condition p < q then fixes which distinct root is which.
Formula a² - 2ab + b² = (a - b)², and x² = k ⇒ x = ±√k for k ≥ 0. Recognising the perfect square avoids the quadratic formula entirely and exposes the repeated factor.

3. Bracket = 0 would force x − 2 = 0, x − 3 = 0 and x − 4 = 0 together, i.e. x = 2, 3 and 4 at once — impossible.
4. Confirm algebraically: bracket = 3x² − 18x + 29, with D = (−18)² − 4(3)(29) = 324 − 348 = −24 < 0 and leading coefficient 3 > 0.
5. So the bracket is positive definite; its least value is −D/4a = 24/12 = 2, attained at x = −b/2a = 3. A strictly positive minimum is a stronger statement than "no real zero" and settles the case outright.
6. The equation therefore reduces to (x − 1)² = 0, giving x = 1 as a repeated root.
7. Distinct real roots = {1}, so the required number is 1. Answering 2 by counting multiplicity is exactly what the word "distinct" forbids.

⚡ JEE Trick The whole design of the problem is to make you expand a quartic; resist it and read the common factor instead. Option (a) 4 is bait for someone who counts the four numbers 1, 2, 3, 4 appearing in the brackets and assumes each is a root — only x = 1 is, because it is the one that appears in every term. Option (c) 2 catches the student who counts the double root at x = 1 twice despite the word "distinct".
Answer: (d) 1.
9If ax^2 - (2a + 3)x + (3 + 5a) = 0 has no real roots then the complete interval of 'a' is given by (a) (-3/4, 3/4) (b) (-∞, -3/4) (c) (-3/4, ∞) (d) (-∞, -3/4) ∪ (3/4, ∞)Nature of roots / discriminantIf ax^2-(2a+3)x+(3+5a)=0 has no real roots, then a lies in the interval🟢 Exactd(-∞, -3/4) ∪ (3/4, ∞)
Concept "No real roots" for a quadratic is the strict condition D < 0, and it presumes the equation really is quadratic — the parameter sits in the leading coefficient here, so the case a = 0 must be examined separately. Computing D gives a second quadratic in 'a' with no linear term, which makes the inequality a clean comparison of squares. Because that expression opens downward in 'a', it is negative outside its two zeros, producing a union of two rays rather than an interval.
Formula No real roots ⇔ a ≠ 0 and D = b² − 4ac < 0. Drop the a ≠ 0 clause and you are quietly claiming a linear equation has no root, which is false unless its own coefficient vanishes.
Solution
1. Coefficients: leading a, middle −(2a + 3), constant (3 + 5a); require D < 0.
2. D = (2a + 3)² − 4a(3 + 5a) = 4a² + 12a + 9 − 12a − 20a² = 9 − 16a². The 12a terms cancel exactly — a designed simplification, so recheck the arithmetic if they do not.
3. Impose 9 − 16a² < 0, i.e. 16a² > 9, i.e. a² > 9/16.
4. Factor form: (3 − 4a)(3 + 4a) < 0 with zeros a = ±3/4, so 16a² − 9 > 0 outside those zeros.
5. Hence a < −3/4 or a > 3/4, i.e. a ∈ (−∞, −3/4) ∪ (3/4, ∞). a² > k² means |a| > k, never simply a > k — the negative branch is half the answer.
6. Degenerate check a = 0: the equation becomes −3x + 3 = 0 with the real root x = 1, so a = 0 is rightly not in the set.
7. Endpoints a = ±3/4 give D = 0, i.e. equal real roots, so both stay excluded and the intervals are open.

    = 4a^2 + 12a + 9 - 12a - 20a^2
    = 9 - 16a^2 = (3 - 4a)(3 + 4a)
  no real roots : D < 0  ==>  16a^2 > 9  ==>  |a| > 3/4
  sign of 16a^2 - 9 :

⚡ JEE Trick Option (a) (−3/4, 3/4) is the exact complement — the set where D > 0 and the roots are real — and it is what you write down if you solve D > 0 by reflex instead of reading "no real roots". Options (b) and (c) are each one half of the true answer, planted for the student who converts a² > 9/16 into a single-sided inequality and forgets the modulus.
Answer: (d) (−∞, −3/4) ∪ (3/4, ∞).
10The number of distinct real roots of the equation (x + 1)^2(x - 2)^2 + (x + 1)^2(x - 3)^2 + (x + 1)^2(x - 2)^2(x - 3)^2(x - 4)^2 = 0 is: (a) 4 (b) 0 (c) 2 (d) 1Number of real rootsThe number of real roots of the equation (x - 1)^(2) + (x -2)^(2) + (x - 3)^(2) = 0 is | CLASS...🟢 Exactd1
Concept The block (x + 1)² multiplies all three terms, so the degree-10 equation factors immediately and never needs expanding. What survives inside the bracket is a sum of even powers of real quantities, and such a sum vanishes only when every single term vanishes at the same value of x. Since (x − 2)² and (x − 3)² cannot both be zero, the bracket is strictly positive for every real x.
Formula A sum of squares of real numbers is zero ⇔ each square is zero; and Ax² + Bx + C > 0 for all real x ⇔ A > 0 and D < 0. The third term is [(x − 2)(x − 3)(x − 4)]², a perfect square, so it can only add to the bracket, never subtract.
Solution
1. Take out the common factor: (x + 1)²[(x − 2)² + (x − 3)² + (x − 2)²(x − 3)²(x − 4)²] = 0.
2. Every bracket term is a square of a real quantity, hence ≥ 0, so the bracket is zero only if all three are zero together.
3. That would need x = 2 and x = 3 simultaneously, which is impossible; the bracket can never reach 0.
4. Quantify it: (x − 2)² + (x − 3)² = 2x² − 10x + 13, with D = 100 − 4(2)(13) = 100 − 104 = −4 < 0 and leading coefficient 2 > 0.
5. Its least value is −D/4a = 4/8 = 1/2 at x = 5/2, so the whole bracket is ≥ 1/2 > 0 for every real x. A positive minimum is proof, not estimate — adding the non-negative third term can only raise it.
6. Hence the product vanishes only through (x + 1)² = 0, giving the repeated root x = −1.
7. Distinct real roots = {−1}, so the required number is 1. Counting the double root twice, or counting 2, 3, 4 as roots, is precisely the intended slip.
  E = (x+1)^2 [ (x-2)^2 + (x-3)^2
                + ((x-2)(x-3)(x-4))^2 ]
  third term is a perfect square : >= 0 always
  (x-2)^2 + (x-3)^2 = 2x^2 - 10x + 13
  D = 100 - 104 = -4 < 0 , lead 2 > 0
  min = -D/4a = 4/8 = 1/2   (at x = 5/2)
  ==> bracket >= 1/2 > 0 for every real x
  E = 0 <==> (x+1)^2 = 0 <==> x = -1 ,  count = 1
⚡ JEE Trick Degree ten looks terrifying and is meant to; the common factor (x + 1)² reduces it to a one-line argument, so scan for the repeated block before touching a single bracket. Option (a) 4 is bait for a student who reads off 2, 3, 4 and −1 as "the" roots, but 2, 3 and 4 each kill only some of the terms, never all of them at once. Option (c) 2 is for whoever counts x = −1 twice for its multiplicity, which the word "distinct" forbids.
Answer: (d) 1.
