Concept Distance is the length of the actual path traced, a scalar that never decreases. Displacement is the straight-line vector from start point to end point. On a semicircle the particle walks the curved arc but ends up straight across the diameter, so the two quantities differ by exactly the factor by which an arc exceeds its chord.

Solution

2. Displacement = diameter = 2r, drawn from the start of the arc straight to its end.The radius r never has to be found — it cancels in the ratio.
3. Ratio = πr : 2r = π : 2.r divides out, so the answer is independent of the size of the circle.
4. Put π = 22/7: ratio = (22/7) : 2 = 22 : 14 = 11 : 7.
  quantity        value
  distance        pi*r  = 5 m
  displacement    2*r
  ratio           pi/2 = (22/7)/2 = 11/7
⚡ JEE Trick The "5 m" is a decoy — a pure ratio question never needs the numbers. Recognise that π:2 with π = 22/7 always collapses to 11:7; this single ratio shows up in every semicircle problem.
