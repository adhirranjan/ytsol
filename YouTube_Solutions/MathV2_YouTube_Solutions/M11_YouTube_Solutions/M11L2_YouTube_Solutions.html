Concept sin2θ + cos2θ is a linear combination of a sine and a cosine of the same angle 2θ, so it can be compressed into a single sinusoid R sin(2θ + φ) with R = √(a2 + b2). That R is the largest value the expression can ever reach, so any target above R is unattainable and the equation has no solutions at all.
Formula a sinψ + b cosψ = R sin(ψ + φ), R = √(a2+b2); solvable ⇔ |c| ≤ R. The amplitude R is the single number that decides solvability, before any solving is attempted.
Solution
1. Here a = 1 and b = 1 with ψ = 2θ, so R = √(12 + 12) = √2 ≈ 1.414.
2. Hence −√2 ≤ sin2θ + cos2θ ≤ √2 for every real θ. The bound is attained, at 2θ + π/4 = ±π/2, so √2 really is the maximum and not merely an estimate.
3. The equation demands the value 2, and 2 > √2.
4. So the target lies strictly above the maximum and can never be reached: the solution set is empty.
5. Check the compressed form directly: sin2θ + cos2θ = √2 sin(2θ + π/4) = 2 would need sin(2θ + π/4) = 2/√2 = √2 > 1. Reducing to a bare sine makes the impossibility a range violation, which is the cleanest possible proof.
6. Therefore the number of values of θ is 0.

Formula a sin x + b cos x = R sin(x + φ), R = √(a2+b2), tanφ = b/a; solvable ⇔ |c| ≤ R. Both endpoints are attained, so the condition is an "if and only if", not merely a necessary test.

Concept Clear the reciprocal ratios by multiplying through by cos x, which is legitimate since tan x and sec x already require cos x ≠ 0. The result is a quadratic in sin x, and one of its roots must be rejected because it drives cos x to zero.
Formula tan x + sec x = (sin x + 1)/cos x; 2cos2x = 2(1 − sin2x). Converting the whole equation into sin x alone is what turns it into a factorisable quadratic.
Solution
1. Combine the left side: (sin x + 1)/cos x = 2cos x, so sin x + 1 = 2cos2x.
2. Replace cos2x: sin x + 1 = 2 − 2sin2x ⇒ 2sin2x + sin x − 1 = 0.
3. Factorise: (2sin x − 1)(sin x + 1) = 0, so sin x = 1/2 or sin x = −1.
4. Reject sin x = −1: it forces cos x = 0, at which tan x and sec x are undefined and the original equation cannot even be written. The rejected root is not merely extraneous — it lies outside the domain, so it must be discarded on principle rather than by checking.
5. So sin x = 1/2 ⇒ x = nπ + (−1)nπ/6 — option (b). A sine equation always produces the alternating (−1)n form, which is what distinguishes (b) from any ± option.
6. Verify x = π/6: tan30° + sec30° = 0.5774 + 1.1547 = 1.732 and 2cos30° = 1.732 ✓.
  tan x + sec x = 2 cos x        (cos x != 0)
  (sin x + 1)/cos x = 2 cos x
  sin x + 1 = 2 cos^2 x = 2 - 2 sin^2 x
  2 sin^2 x + sin x - 1 = 0
  (2 sin x - 1)(sin x + 1) = 0
  sin x = -1  ->  cos x = 0  ->  REJECT (undefined)
  sin x = 1/2 ->  x = n.pi + (-1)^n . pi/6
  check pi/6 : .5774 + 1.1547 = 1.732 = 2 cos30   OK
⚡ JEE Trick After multiplying by cos x, always test each root against cos x ≠ 0 — option (a) is built from the rejected root sin x = −1 and looks perfectly plausible otherwise. The pattern "quadratic in sin x with one root at ±1" recurs constantly in sec/tan problems, and that root is nearly always the one to throw away.
Answer: (b) x = nπ + (−1)nπ/6, n ∈ z.

Concept Solve the quadratic in sin x, discard the root outside [−1, 1], then count how many times the surviving horizontal line meets the sine curve over [0, 3π]. Counting by positive arches rather than by periods is what makes the count reliable.
Formula 2s2 + 5s − 3 = (2s − 1)(s + 3); sin x = c with 0 < c < 1 has 2 roots per positive arch. Each arch of the sine above the axis crosses a horizontal level twice, once rising and once falling.
Solution
1. Put s = sin x: 2s2 + 5s − 3 = 0 ⇒ (2s − 1)(s + 3) = 0.
2. Roots: s = 1/2 and s = −3.
3. Discard s = −3, which lies outside [−1, 1]; only sin x = 1/2 survives. Counting the discarded root would double the answer and produce the decoy (c) 6 or worse.
4. The positive arches inside [0, 3π] are [0, π] and [2π, 3π] — two of them.
5. Each contributes two roots: π/6 and 5π/6 in the first, 13π/6 and 17π/6 in the second. On (π, 2π) the sine is negative and never reaches +1/2, so that stretch contributes nothing.

Concept The identity tanA + tanB + tanC = tanA tanB tanC normally gives A + B + C = nπ, but here 2x + 3x = 5x, so C is the sum of A and B and the identity degenerates. Substituting the addition formula for tan5x reduces the equation much further.
Formula tan5x = (tan2x + tan3x)/(1 − tan2x tan3x), valid where all three tangents exist. Because 5x = 2x + 3x, the three tangents are not independent, and that dependence is what breaks the usual rule.
Solution
1. Write t1 = tan2x, t2 = tan3x, t3 = tan5x, so t3(1 − t1t2) = t1 + t2.
2. The equation t1+t2+t3 = t1t2t3 gives t1+t2 = t3(t1t2 − 1) = −(t1+t2).
3. Hence 2(t1+t2) = 0 ⇒ tan3x = −tan2x = tan(−2x) ⇒ 3x = nπ − 2x ⇒ x = nπ/5. The whole equation collapses to a two-term condition, so the answer is nπ/5, not the nπ/10 the naive sum rule predicts.
4. Test the naive family: at x = π/10, 5x = π/2 and tan5x is undefined, so that member is inadmissible — and every odd multiple of π/10 fails the same way.
