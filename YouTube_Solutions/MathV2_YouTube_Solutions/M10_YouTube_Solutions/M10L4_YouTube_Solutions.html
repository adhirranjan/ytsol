Concept A quadratic f(x) = ax² + bx + c with D < 0 has no real root, so its graph never meets the x-axis. A continuous curve that never crosses the axis must stay entirely on one side of it, and which side is decided by the leading coefficient alone. Here a > 0, so the parabola opens upward and the whole curve lies above the axis. The constant term c is nothing but the particular value f(0), so it inherits that sign.
Formula a > 0 and D < 0 ⇒ f(x) > 0 ∀ x ∈ R. This follows from the completed square f(x) = a(x + b/2a)² − D/4a, in which both a and −D are positive.
Solution
1. Complete the square: f(x) = a(x + b/2a)² − D/4a, where D = b² − 4ac.
2. Since a > 0, the term a(x + b/2a)² ≥ 0 for every real x, with equality only at x = −b/2a.
3. Since D < 0 and a > 0, −D/4a = (positive)/(positive) > 0. The minus sign flips the negative D into a positive numerator.
4. Adding the two, f(x) ≥ −D/4a > 0, so f is strictly positive everywhere — it never touches zero.
5. Evaluate at the y-intercept: f(0) = a(0)² + b(0) + c = c. The constant term is always the y-intercept of the graph.
6. Step 4 applies at x = 0 too, so c = f(0) > 0, i.e. c is positive. Equivalently D < 0 forces 4ac > b² ≥ 0, and a > 0 then gives c > 0.
        |    \           /
        |     \         /    a > 0, D < 0
      c *      \_______/     curve stays above axis
   -----+---------------------------> x
        |
  f(x) >= -D/(4a) > 0  for every real x
  put x = 0 :  f(0) = c > 0
⚡ JEE Trick The trap is treating D < 0 as if it decides the sign of c by itself — it does not. Flip the leading coefficient to a < 0 with the same D < 0 and the entire parabola sits below the axis, making c negative. Also note the implication runs one way only: c > 0 with a > 0 does not force D < 0, since x² − 5x + 6 has c = 6 > 0 yet D = 1 > 0. Always pair the sign of a with the sign of D before reading off any value of f.
Answer: Positive — c > 0.

Concept The discriminant D = b² − 4ac is the single number that classifies the roots of ax² + bx + c = 0. It is exactly the quantity under the square root in the quadratic formula, so its sign decides whether that root is real or imaginary. Here the expression is x² + 2x + 4, whose coefficients can be read straight off. All that is asked is the sign of D, so no root-finding is needed.
Formula D = b² − 4ac. D > 0 gives two distinct real roots, D = 0 a repeated real root, D < 0 a conjugate pair of complex roots.
Solution
1. Compare x² + 2x + 4 with ax² + bx + c: a = 1, b = 2, c = 4, and a ≠ 0 so it is genuinely quadratic.
2. D = b² − 4ac = (2)² − 4(1)(4) = 4 − 16 = −12 < 0, so D is negative.
3. Cross-check by completing the square: x² + 2x + 4 = (x + 1)² + 3. A sum of a square and 3 can never be 0, confirming no real root.
4. Minimum value = −D/4a = −(−12)/4 = 3, attained at x = −b/2a = −1, matching the completed square.
5. Roots are x = (−2 ± √−12)/2 = −1 ± i√3, a conjugate pair. Real coefficients force complex roots to occur in conjugate pairs.
6. Since a = 1 > 0 and D < 0, the graph lies wholly above the x-axis: f(x) ≥ 3 > 0 for all real x. This is the a > 0, D < 0 case of part (i).

⚡ JEE Trick The commonest slip is computing 4ac as 4c or forgetting the factor 4 entirely, which turns −12 into 0 and wrongly reports equal roots. A second trap is confusing the sign of D with the sign of f(x): here D is negative while f(x) is always positive, and that is not a contradiction. When a is 1 the fastest check is the completed square — if the leftover constant is positive, D is negative.
Answer: Negative — D = −12.

Concept The points where a graph meets the x-axis are precisely the real roots of f(x) = 0. So "does the curve cut the x-axis" is the same question as "does the equation have real roots", which is settled by the discriminant alone. The sign of a only decides whether the parabola opens up or down; it never affects how many real roots exist. With D > 0 there are two distinct real roots whatever the sign of a.
Formula x = (−b ± √D)/2a, D = b² − 4ac. D > 0 makes √D a nonzero real number, so the two values of x are real and different.
Solution
1. Given a < 0 (so a ≠ 0, genuinely quadratic) and D > 0 for f(x) = ax² + bx + c.
2. D > 0 ⇒ √D is real and √D ≠ 0, so x = (−b ± √D)/2a gives two distinct real roots α ≠ β.
3. Each real root is an x-intercept, so the graph meets the axis at (α, 0) and (β, 0): the answer is True.
4. Since a < 0 the parabola opens downward, and its turning point is a maximum of value −D/4a. With a < 0 and D > 0, −D/4a is positive, so the vertex sits above the axis.
5. Hence the arch rises above the axis between the roots and falls below outside them: f(x) > 0 for x ∈ (α, β), f(x) < 0 outside. This is the rule af(x) < 0 between the roots.
6. Concrete instance: f(x) = −x² + 4 has a = −1 < 0, D = 16 > 0, and it cuts the axis at x = ±2. One valid example is enough to settle a True/False claim that we have already proved in general.
  a < 0, D > 0  ->  two distinct real roots alpha, beta

            ___
           /   \        max = -D/(4a) > 0
  ---[beta]-----[alpha]---------> x
         /       \
  sign of f :  -  |  +  |  -
  cuts the x-axis at TWO points  =>  TRUE
⚡ JEE Trick The trap is thinking a downward parabola somehow "misses" the axis; the sign of a rotates the curve but cannot change the root count, which only D controls. Watch the boundary case too: D = 0 means the curve touches the axis at one point rather than cutting it, so a question phrased as "cuts" is false there while "has real roots" stays true. And remember that "real roots" allows D ≥ 0, whereas "distinct real roots" demands D > 0 strictly.
Answer: True — the graph cuts the x-axis at two distinct points.

Therefore knowing the sign of f at a single point pins down the sign at every other point. The information a + b + c > 0 is exactly that single sample.
Formula D < 0 ⇒ a·f(x) > 0 ∀ x ∈ R. With no real root the continuous function f can never change sign, so f(x) has the same sign as a everywhere.

Concept Asking f(x) ≥ 0 for every real x says the parabola never dips below the x-axis. Two things must then hold together: the curve must open upward, and it may at most touch the axis but never cross it. Opening upward is a > 0; touching-or-missing is D ≤ 0, where the equality is the touching case. The range then starts at the vertex value −D/4a and runs to infinity.
Formula f(x) ≥ 0 ∀ x ∈ R ⇔ a > 0 and D ≤ 0. Both conditions are needed: a > 0 alone still permits the curve to dip below the axis between two real roots.
Solution
1. If a < 0 the arm of the parabola falls to −∞, and a = 0 is not a quadratic, so f(x) ≥ 0 ∀ x forces a > 0, giving p = 0.
2. If D > 0 there are two distinct real roots α < β and f(x) < 0 on (α, β), which is barred; hence D ≤ 0, giving q = 0. D = 0 is allowed because a mere touch keeps f(x) = 0, not negative.
3. From the completed square f(x) = a(x + b/2a)² − D/4a, the least value is −D/4a, attained at x = −b/2a.
4. So the range is [−D/4a, ∞), and the question fixes this as [r, ∞) with a single number r. A parabola opening upward attains its minimum and then increases without bound on both arms, so the range is a closed ray.
5. Consistency with a fixed r forces the boundary case D = 0, whence r = −0/4a = 0 and range [0, ∞), so r = 0.
6. Model case: f(x) = (x + k)² has a = 1 > 0, D = 0 and range [0, ∞). Every perfect square is exactly the equality case of f(x) ≥ 0.

     needs   a > 0     ->  p = 0
     needs   D <= 0    ->  q = 0

  min value = -D/(4a) = 0  when D = 0
  range = [0, inf)          ->  r = 0
  model : f(x) = (x + k)^2 , touches axis at x = -k
⚡ JEE Trick The single most punished mistake here is writing D < 0 instead of D ≤ 0: "f(x) ≥ 0" permits equality, so the touching case must stay in. Use D < 0 only for the strict statement f(x) > 0 ∀ x. Mirror the whole result for the opposite inequality: f(x) ≤ 0 ∀ x needs a < 0 with D ≤ 0 and range (−∞, 0]. Also keep a > 0 strict — a = 0 leaves a line, which always takes negative values unless b = 0 as well.
Answer: p = 0, q = 0, r = 0.

Concept To find the range of a rational function, treat the output y as a parameter and ask for which y the equation y = f(x) actually has a real solution x. Here both numerator and denominator involve only x², so we can solve for x² explicitly instead of using a discriminant. A real x exists exactly when the resulting x² comes out non-negative. The set of admissible y is then the range.
Formula x ∈ R ⇔ x² ≥ 0. Every real square is non-negative, so any y forcing x² < 0 is unattainable and drops out of the range.
Solution
1. Put y = (x² − 1)/(x² + 1); the denominator x² + 1 ≥ 1 is never zero, so f is defined for all real x.
2. Cross-multiply: y(x² + 1) = x² − 1 ⇒ x²(y − 1) = −1 − y ⇒ x² = (1 + y)/(1 − y). Multiplying by x² + 1 is safe because it is strictly positive, so no extraneous root is created.
3. Require x² ≥ 0, i.e. (1 + y)/(1 − y) ≥ 0; the critical points are y = −1 (zero) and y = 1 (undefined).
4. Sign chart gives (1 + y)/(1 − y) ≥ 0 for −1 ≤ y < 1, so the range is [−1, 1). y = −1 is included since it gives x² = 0, but y = 1 is excluded as the expression blows up there.
5. Comparing with [p, q): p = −1 and q = 1; indeed f(0) = −1/1 = −1 is attained and f(x) → 1 only as x → ±∞.
6. Integers lying in [−1, 1) are −1 and 0, a count of two, so r = 2. 1 is not counted because the bracket at q is open.

  ---(-)---[-1]---(+)---(1)---(-)--->  y

⚡ JEE Trick A faster route is to rewrite f(x) = 1 − 2/(x² + 1); since x² + 1 ∈ [1, ∞), the term 2/(x² + 1) ∈ (0, 2] and f ∈ [−1, 1) falls out at once. The trap is the bracket type: examiners set the options so that [−1, 1] and (−1, 1) both appear, and only endpoint testing separates them. Remember the value y = 1 that makes the coefficient of x² vanish can never be attained, which is why q sits outside the range.
Answer: p = −1, q = 1, r = 2.

1What is the standard form of a quadratic expression? (Level-1) (a) ax + b (b) ax^2 + bx + c (c) x^2 + c (d) a + bxQuadratic expression basicsWhat is standard form of a quadratic equation🟢 Exactbax² + bx + c
Concept A polynomial expression is named by its degree, which is the highest power of the variable carrying a non-zero coefficient. "Quadratic" means degree exactly two, so the general form must contain an x² term with a non-zero coefficient and then all lower powers with arbitrary coefficients. Dropping any of the lower terms would describe a special case, not the general one. The standard form is therefore ax² + bx + c with a ≠ 0.
Formula f(x) = ax² + bx + c, a ≠ 0, a, b, c ∈ R. The clause a ≠ 0 is part of the definition; without it the expression can collapse to a linear one.
Solution
1. Degree two is required, so an x² term must be present with a non-zero coefficient.
2. The general degree-two polynomial in x carries all powers x², x¹, x⁰, i.e. ax² + bx + c.
3. Option (a) ax + b has highest power x¹, hence linear, not quadratic — rejected. Its graph is a straight line, never a parabola.
4. Option (c) x² + c is quadratic but not general: it has forced a = 1 and b = 0, so it misses expressions like 3x² + 5x — rejected.
5. Option (d) a + bx is again degree one, the same linear form as (a) rewritten — rejected. Reordering terms does not change the degree.
6. Only option (b) ax² + bx + c contains every degree-two polynomial, so it is the standard form. Choosing b = 0 recovers option (c) and a = 0 would give (a), which is why a ≠ 0 is stipulated.
  degree 2 general polynomial in x :
     a x^2  +  b x  +  c        with a =/= 0

  (a) ax + b    degree 1     no
  (b) ax^2+bx+c degree 2     YES
  (c) x^2 + c   special case (a=1, b=0)
  (d) a + bx    degree 1     no
⚡ JEE Trick The distractor worth understanding is (c): it is a quadratic, just not the standard general form, and questions like this always separate "is quadratic" from "is the general quadratic". Carry the condition a ≠ 0 with you, because later problems place a parameter on the leading coefficient and the a = 0 case is a deliberate trap that turns the equation linear with a single root. Nothing about b and c is restricted — either may be zero and the expression stays quadratic.
Answer: (b) ax² + bx + c.

Counting roots is the question here, so the domain work matters as much as the algebra: candidates outside the domain are simply not roots.
Formula √A = B ⇔ A = B² and B ≥ 0. Dropping the B ≥ 0 half is what manufactures extraneous roots, and this problem needs it twice.
Solution
1. Domain: x ≥ 0 and 1 − x ≥ 0 give 0 ≤ x ≤ 1; also x − √(1 − x) ≥ 0 ⇒ x² ≥ 1 − x ⇒ x² + x − 1 ≥ 0 ⇒ x ≥ (√5 − 1)/2 ≈ 0.618. So every root must lie in the narrow window [0.618, 1].
2. Isolate: √(x − √(1 − x)) = 1 − √x, which needs 1 − √x ≥ 0, i.e. x ≤ 1 — already true.
3. Square once: x − √(1 − x) = 1 − 2√x + x, so √(1 − x) = 2√x − 1, which now demands 2√x ≥ 1, i.e. x ≥ 1/4. The x terms cancel, which is the small miracle that keeps this equation tractable.
4. Square again: 1 − x = 4x − 4√x + 1 ⇒ 4√x = 5x ⇒ 16x = 25x² ⇒ x(25x − 16) = 0, giving x = 0 or x = 16/25.
5. Reject x = 0: it fails the step-3 condition (2√0 − 1 = −1 < 0) and lies outside the domain window of step 1. This is the extraneous root introduced by the second squaring.
6. Verify x = 16/25: √x = 4/5, √(1 − x) = 3/5, so x − √(1 − x) = 16/25 − 15/25 = 1/25 and the left side is 4/5 + 1/5 = 1. ✓ Exactly one real root.
  domain: 0.618 <= x <= 1

  sqrt(x - sqrt(1-x)) = 1 - sqrt(x)
  sqrt(1-x) = 2*sqrt(x) - 1      (needs x >= 1/4)
  1 - x = 4x - 4*sqrt(x) + 1  -> 25x^2 = 16x

  x = 0     : 2*0 - 1 = -1 < 0     REJECT
  x = 16/25 : 4/5 + 1/5 = 1        ACCEPT
⚡ JEE Trick Students who square blindly report 2 roots and pick option (c), because x = 0 does satisfy the twice-squared polynomial. It fails the original because √(0 − 1) is not real. A fast sanity argument: both √x and √(x − √(1 − x)) increase on the domain, so the left side is strictly increasing from about 0.786 at x ≈ 0.618 up to 2 at x = 1 — it crosses the level 1 exactly once. Monotonicity settles the count even before you know the root.
Answer: (b) 1.
8If x is real, then the values of (x + 2)/(2x^2 + 3x + 6) are in the interval bounded by (a) −1/3 and −1/13 (b) 1/13 and 1/3 (c) −1/3 and 1/13 (d) −1/13 and 1/3Range of rational expressionIf x is real, the expression (x+2)/(2x^2+3x+6) takes all value in the interval🟢 Exactd−1/13 and 1/3
Concept Set the expression equal to y and clear the denominator; the value y is achieved precisely when the resulting equation in x has a real solution. First confirm the denominator never vanishes. Then note that the cleared equation has leading coefficient 2y, so y = 0 is a degenerate linear case that must be checked on its own before applying D ≥ 0. The discriminant inequality then gives a closed interval of attainable values.
Formula 2yx² + (3y − 1)x + (6y − 2) = 0, real x ⇒ D = (3y − 1)² − 8y(6y − 2) ≥ 0. D ≥ 0 with equality allowed, so the two endpoint values are themselves attained.
Solution
1. Denominator 2x² + 3x + 6 has D = 9 − 48 = −39 < 0 with a = 2 > 0, so it is positive for all real x and the expression is defined everywhere.
2. Put y = (x + 2)/(2x² + 3x + 6) ⇒ 2yx² + 3yx + 6y = x + 2 ⇒ 2yx² + (3y − 1)x + (6y − 2) = 0.
3. Degenerate case y = 0: the equation becomes −x − 2 = 0, i.e. x = −2, which is real, so y = 0 is attained and belongs to the range. The a = 0 case must be settled separately — the discriminant test does not apply when the equation is not quadratic.
4. For y ≠ 0, D = (3y − 1)² − 8y(6y − 2) = 9y² − 6y + 1 − 48y² + 16y = −39y² + 10y + 1 ≥ 0, i.e. 39y² − 10y − 1 ≤ 0.
5. Roots: y = [10 ± √(100 + 156)]/78 = (10 ± 16)/78, giving y = 26/78 = 1/3 and y = −6/78 = −1/13. An upward parabola in y is ≤ 0 only between its zeros, so the range is the closed interval.
6. Hence −1/13 ≤ y ≤ 1/3, an interval that contains y = 0 as required — option (d). That containment is a free consistency check: any answer excluding 0 would contradict step 3.
  D = -39y^2 + 10y + 1 >= 0
   =>  39y^2 - 10y - 1 <= 0
   =>  (3y - 1)(13y + 1) <= 0

  ---(+)---[-1/13]---(-)---[1/3]---(+)--->

  range = [-1/13, 1/3] ;  y = 0 lies inside  OK
⚡ JEE Trick The distractors are all sign scrambles of the same two numbers, so the decisive check is a single sample value. At x = −2 the expression is 0, so 0 must be inside the interval — that instantly kills (a) (−1/3, −1/13) and (b) (1/13, 1/3), which lie wholly on one side of zero. Between (c) and (d), the larger magnitude 1/3 must be the positive end since the numerator is positive for x > −2. Note 39y² − 10y − 1 factors as (3y − 1)(13y + 1), sparing you the quadratic formula.
Answer: (d) −1/13 and 1/3.
9If x is real, then the greatest and least values of the expression (x^2 − 2x + 2)/(x^2 + 3x + 9) are respectively (a) 2 and −2/27 (b) 2 and 2/27 (c) 2 and 1/27 (d) 2 and 3Range of rational expressionIf x is real, find the greatest and the least value of (x^2-2x+2)/(x^2+3x+9)🟢 Exactb2 and 2/27
Concept For a ratio of two quadratics, put the expression equal to y, cross-multiply, and collect a quadratic in x whose coefficients depend on y. Since x is given real, the discriminant of that quadratic must be non-negative, and the resulting inequality in y describes exactly the set of attainable values. Two checks come first: the denominator must never vanish, and the y that kills the x² coefficient must be handled separately, since there the equation is linear.
Formula (y − 1)x² + (3y + 2)x + (9y − 2) = 0, real x ⇒ D = (3y + 2)² − 4(y − 1)(9y − 2) ≥ 0. Equality D = 0 is allowed, so the extreme values are attained and "greatest" and "least" genuinely exist.
Solution
1. Denominator x² + 3x + 9 has D = 9 − 36 = −27 < 0 with a = 1 > 0, so it is positive for every real x and never zero.
2. y(x² + 3x + 9) = x² − 2x + 2 ⇒ (y − 1)x² + (3y + 2)x + (9y − 2) = 0.
3. Degenerate case y = 1: it reduces to 5x + 7 = 0, i.e. x = −7/5, which is real, so y = 1 is in the range. Handling a = 0 separately is compulsory; 1 duly lies inside the interval found below.
4. For y ≠ 1, D = 9y² + 12y + 4 − 4(9y² − 11y + 2) = 9y² + 12y + 4 − 36y² + 44y − 8 = −27y² + 56y − 4 ≥ 0, i.e. 27y² − 56y + 4 ≤ 0.
5. Roots: y = [56 ± √(3136 − 432)]/54 = (56 ± √2704)/54 = (56 ± 52)/54, giving y = 108/54 = 2 and y = 4/54 = 2/27. The parabola 27y² − 56y + 4 opens upward, so it is ≤ 0 only between these zeros.
6. Hence 2/27 ≤ y ≤ 2: greatest value 2, least value 2/27 — option (b). Both are attained: D = 0 at y = 2 gives x² + 8x + 16 = 0, x = −4, and at y = 2/27 gives 25x² − 60x + 36 = 0, x = 6/5.
  D = -27y^2 + 56y - 4 >= 0
   =>  27y^2 - 56y + 4 <= 0

  roots: y = (56 +- 52)/54 = 2 and 2/27

  ---(+)---[2/27]---(-)---[2]---(+)--->
  range = [2/27, 2] ;  contains y = 1  OK
⚡ JEE Trick The whole expression is a ratio of two everywhere-positive quadratics, so every attainable value must be strictly positive — that alone eliminates option (a) with its negative least value −2/27. Option (c) 1/27 and (d) 3 come from arithmetic slips in D; the safest guard is that y = 1 must sit inside the answer interval, since x = −7/5 makes the expression exactly 1. Check √2704 = 52 carefully — a wrong surd here is what produces 1/27.
Answer: (b) 2 and 2/27.
10If the inequality (mx^2 + 3x + 4)/(x^2 + 2x + 2) < 5 is satisfied for all x ∈ R, then (a) m < 5 (b) m > 5 (c) m < 71/24 (d) m > 71/24Sign of a quadraticIf the inequality (mx^2+3x+4)/(x^2+2x+2) < 5 is satisfied for all x in R, then...🟢 Exactcm < 71/24
Concept An inequality between a fraction and a constant can only be cross-multiplied once the sign of the denominator is known. Here x² + 2x + 2 = (x + 1)² + 1 is strictly positive for every real x, so multiplying preserves the direction. The problem becomes "this quadratic in x is negative for all real x", i.e. leading coefficient negative and discriminant strictly negative. Since the parameter sits in the leading coefficient, the case where it vanishes needs a separate test.
Formula Ax² + Bx + C < 0 for all x ⇔ A < 0 and D = B² − 4AC < 0. D = 0 would let the quadratic touch zero at its vertex, which breaks the strict inequality.
Solution
1. x² + 2x + 2 = (x + 1)² + 1 ≥ 1 > 0 for all real x, so the denominator is never zero and never changes sign.
2. Multiply across: mx² + 3x + 4 < 5(x² + 2x + 2) ⇒ (m − 5)x² − 7x − 6 < 0 must hold for every real x.
3. Degenerate case m = 5: the condition becomes −7x − 6 < 0, i.e. x > −6/7, which fails for large negative x, so m = 5 is not allowed. A non-constant linear function always changes sign, so it can never be negative on all of R.
4. For m ≠ 5 we need m − 5 < 0 and D = (−7)² − 4(m − 5)(−6) = 49 + 24(m − 5) < 0.
5. 49 + 24m − 120 < 0 ⇒ 24m < 71 ⇒ m < 71/24 ≈ 2.96. Since 71/24 < 5, this automatically forces m − 5 < 0, so the leading-coefficient condition is already contained in the discriminant condition.
6. Hence the answer is m < 71/24, option (c); at m = 71/24 exactly, D = 0 and the quadratic touches zero, so the boundary is correctly excluded. Sample check m = 0: −5x² − 7x − 6 has D = 49 − 120 = −71 < 0, so it is negative everywhere. ✓
  (m - 5)x^2 - 7x - 6 < 0  for all real x

  need A = m - 5 < 0  and  D = 49 + 24(m - 5) < 0
  D < 0  =>  24m < 71  =>  m < 71/24

  ---(holds)---[71/24]---(fails)---[5]--->
  m = 5 : -7x - 6 < 0 only for x > -6/7  FAIL
⚡ JEE Trick Option (a) m < 5 is the bait: it is what you get from the leading-coefficient condition alone, forgetting that the discriminant must also be negative. Options (b) and (d) invert the inequality, which would make the quadratic positive somewhere. Confirm the denominator's sign before cross-multiplying; if it could be negative the whole direction flips.
Answer: (c) m < 71/24.
