Concept |x| is the distance of x from the origin on the number line, so |x| ≤ 5 collects every point lying within 5 units of 0. A distance is never negative, so the right side being positive guarantees the solution set is non-empty. Geometrically the answer is the closed segment centred at 0 of radius 5. The ≤ sign (rather than <) is exactly what allows the two end points themselves to qualify.
Formula |x| ≤ a (a ≥ 0) ⇔ −a ≤ x ≤ a, while |x| ≥ a ⇔ x ≤ −a or x ≥ a. The first is an AND-condition and collapses to one interval; the second is an OR-condition and gives a union of two rays — mixing them up is the classic slip.
Solution
1. By definition |x| = x for x ≥ 0 and |x| = −x for x < 0, so the single statement really carries two cases.
2. Case x ≥ 0: |x| = x ≤ 5 gives 0 ≤ x ≤ 5.
3. Case x < 0: |x| = −x ≤ 5 ⇒ x ≥ −5, giving −5 ≤ x < 0. Dividing by −1 reverses the inequality sign.
4. Union of the two cases = [−5, 0) ∪ [0, 5] = [−5, 5].
5. One-line check by squaring (legal since both sides are ≥ 0): x² ≤ 25 ⇒ x² − 25 ≤ 0 ⇒ (x − 5)(x + 5) ≤ 0 ⇒ −5 ≤ x ≤ 5.
6. End points: x = 5 gives |5| = 5 ≤ 5 ✓, and x = −5 gives |−5| = 5 ≤ 5 ✓. Both satisfy it, so the brackets are square, not round.
7. Hence x ∈ [−5, 5], a closed interval of length 10.

Concept The exponential function y = ex has domain R and range (0, ∞): it is defined for every real x and its value is strictly positive for every real x. So the condition ex > 0 is not a restriction at all — it is an identity, true automatically. A statement that every member of the domain already satisfies has the whole domain as its solution set. Hence the blank is the entire real line, and this item is really a test of whether you know the range of ex.
Formula ax > 0 for every x ∈ R whenever a > 0; in particular ex > 0 with ex → 0 as x → −∞ and ex → ∞ as x → +∞. Zero is a limiting value that is approached but never attained, which is why the range is open at 0.
Solution
1. Domain of ex: no radical, no denominator, no logarithm — it is defined for all x ∈ R.
2. For x > 0, ex > e0 = 1 > 0, so positivity is obvious there.
3. For x = 0, e0 = 1 > 0.
4. For x < 0, write x = −t with t > 0: ex = 1/et, a reciprocal of a positive number, hence positive. This is the case students doubt — e−5 = 1/e5 ≈ 0.0067, small but firmly positive.
5. So ex > 0 holds on all three pieces, i.e. for every real x, and ex = 0 has no solution.
6. Therefore the solution set is the whole domain: x ∈ (−∞, ∞) = R. No end points to test, because the interval has none.
7. Consistency check: taking logs of ex > 0 is illegal only because log 0 is undefined — the inequality is exactly the statement that the range of ex is (0, ∞).

Concept f(x) = (x − 2)(x − 3) is an upward parabola (leading coefficient a = 1 > 0) cutting the axis at the two distinct points x = 2 and x = 3. An upward parabola dips below the axis only in the strip between its roots and stays above outside them. So a strict < 0 picks the open interval between the roots, with the roots themselves excluded because there f(x) = 0, not negative. This is the whole content of the rule a·f(x) < 0 between the roots.
Formula For a > 0 with real roots α < β: f(x) < 0 ⇔ x ∈ (α, β) and f(x) > 0 ⇔ x ∈ (−∞, α) ∪ (β, ∞). Between the roots the two factors carry opposite signs, so their product is negative.
Solution
1. Critical points are where each factor vanishes: x − 2 = 0 ⇒ x = 2 and x − 3 = 0 ⇒ x = 3.
2. These split the line into three regions: (−∞, 2), (2, 3) and (3, ∞).
3. Test x = 0: (0 − 2)(0 − 3) = (−2)(−3) = 6 > 0, so the left region fails.
4. Test x = 2.5: (2.5 − 2)(2.5 − 3) = (0.5)(−0.5) = −0.25 < 0, so the middle region works. Product of a positive and a negative factor is negative — the only place that happens.
5. Test x = 4: (4 − 2)(4 − 3) = (2)(1) = 2 > 0, so the right region fails.
6. End points: at x = 2 and x = 3, f(x) = 0, which is not < 0, so both are excluded and the brackets are round. Had the question read ≤ 0 the answer would be the closed interval [2, 3].
7. Hence x ∈ (2, 3). Consistency check: the vertex sits at x = 2.5 with f = −0.25, the most negative value, comfortably inside the interval found.

Concept The wavy-curve (sign-scheme) method handles any product of linear factors at once. Mark all the roots on the number line in increasing order, note that for very large x every factor is positive so the far-right region is positive, then sweep leftwards flipping the sign each time you cross a root of odd multiplicity. Here all three factors are simple, so the signs alternate perfectly: + − + − from right to left. The regions carrying + are exactly the solution of the strict > 0 inequality.
Formula For f(x) = (x − a1)(x − a2)…(x − an) with a1 < a2 < … < an: f(x) > 0 on the rightmost interval, then signs alternate. Each simple factor changes sign once, so crossing exactly one root flips the sign of the product exactly once.
Solution
1. Roots in increasing order: x = 1, x = 2, x = 5, splitting R into four regions.
2. Far right, x = 6: (6−1)(6−2)(6−5) = (5)(4)(1) = 20 > 0, confirming the rightmost region is positive.

Concept x² ≤ 2 is a modulus statement in disguise, because √(x²) = |x| for every real x. Taking the (non-negative) square root of both sides therefore turns it into |x| ≤ √2, a band of radius √2 about the origin. Equivalently, x² − 2 = (x − √2)(x + √2) is an upward parabola which is ≤ 0 exactly between and at its two roots. Counting integers then only needs the decimal value √2 ≈ 1.414.
Formula x² ≤ a² ⇔ |x| ≤ a ⇔ −a ≤ x ≤ a (a ≥ 0). Writing x² ≤ 2 as x ≤ √2 alone is the classic error — it silently drops the entire negative half of the solution.
Solution
1. Rearrange: x² − 2 ≤ 0 ⇒ (x − √2)(x + √2) ≤ 0, with roots x = ±√2.
2. Leading coefficient a = 1 > 0, so the parabola is ≤ 0 between its roots: −√2 ≤ x ≤ √2.
3. End points: x = √2 gives x² = 2 ≤ 2 ✓, so both ends are included and the interval is closed. The ≤ sign is what makes it [p, q] and not (p, q).
4. Comparing with x ∈ [p, q] gives p = −√2 and q = √2.
5. Numerically √2 ≈ 1.414, so the interval is about [−1.414, 1.414].
6. Integers inside it: −1, 0, 1 — that is 3 values. ±2 fail because 2² = 4 > 2, and ±1.414 are not integers, so nothing extra sneaks in at the ends.

1Which of the following is the standard form of a quadratic expression? (Level-1) (a) bx + c (b) ax^2 + bx + c (c) a + bx^2 (d) x + ax^2Standard form of quadraticArithmetic Expressions Class 7 One Shot || Maths🟢 Exactbax² + bx + c
Concept A quadratic expression in one variable is a polynomial of degree exactly 2, so its highest power of x must be 2 and the coefficient of that term must be non-zero. Its standard form is the canonical way of writing it: all terms present, arranged in descending powers of x, as ax² + bx + c with a ≠ 0. The constraint a ≠ 0 is what keeps the degree at 2; if a were 0 the expression would collapse to the linear bx + c.
Formula Standard form: f(x) = ax² + bx + c, a, b, c ∈ R, a ≠ 0. The letters are positional: a always multiplies x², b always x, c is the constant — so any other ordering invites you to read the wrong coefficient into a formula.
Solution
1. Requirement: degree 2, descending powers, non-zero leading coefficient.
2. Option (a) bx + c has highest power 1, so it is a linear expression, not quadratic at all. ✗
3. Option (b) ax² + bx + c has degree 2 with the terms in descending order x², x, constant, and a ≠ 0 by convention. ✓
4. Option (c) a + bx² is a genuine quadratic in value, but it is written in ascending powers and its coefficients are mislabelled — b sits on x² where a should be, and the x-term is missing. ✗ It is a special case (b = 0 in standard notation), not the general standard form.
5. Option (d) x + ax² is again quadratic in value but out of order, and the coefficient of x² is a while the coefficient of x is 1 — not the general template. ✗
6. Only (b) satisfies all three requirements simultaneously. The other three are either the wrong degree or the right degree in the wrong arrangement.
7. Hence the standard form is ax² + bx + c, with the rider a ≠ 0.

2Find the minimum value of g(x) = 3x^2 - 12x + 10. (Level-2)Maximum & minimum valueQuadratic Equations 06 | Maximum & Minimum value of a Quadratic Polynomial | Class 11 | JEE | PACE🟡 Similar−2 (attained at x = 2)
Concept A quadratic ax² + bx + c traces a parabola whose axis of symmetry is the vertical line x = −b/2a, and its extreme value occurs precisely at that vertex. When a > 0 the parabola opens upward, so the vertex is the lowest point and the extreme value is a minimum; there is then no maximum, since the arms rise to +∞. Here a = 3 > 0, so a minimum exists and it is unique. Completing the square makes this visible without any calculus.
Formula extremum at x = −b/2a, extreme value = −D/4a where D = b² − 4ac. This is just the completed square a(x + b/2a)² − D/4a read off — the squared bracket contributes 0 at its own vertex and something positive everywhere else.
Solution
1. Identify a = 3, b = −12, c = 10; since a = 3 > 0 the parabola opens upward, so we are hunting a minimum.
2. Vertex abscissa: x = −b/2a = −(−12)/(2×3) = 12/6 = 2.
3. Direct substitution: g(2) = 3(2)² − 12(2) + 10 = 12 − 24 + 10 = −2.
4. Cross-check with the formula: D = b² − 4ac = (−12)² − 4(3)(10) = 144 − 120 = 24, so −D/4a = −24/12 = −2. ✓
5. Completing the square: g(x) = 3(x² − 4x) + 10 = 3(x − 2)² − 12 + 10 = 3(x − 2)² − 2. Since 3(x − 2)² ≥ 0 always, g(x) ≥ −2 always, with equality only at x = 2.

Concept Two independent claims, so each must be verified on its own before the option is chosen. An irrational inequality √A < B may be squared only after two guards are in place: A ≥ 0 so the root exists, and B > 0 because a square root is never negative — squaring without them manufactures extraneous roots. An exponential inequality is handled by writing both sides as powers of one base; since 3 > 1 the exponents may be compared with the sign unchanged. Each claim then reduces to a sign chart.
Formula √A < B ⇔ A ≥ 0, B > 0, A < B²; and 3p > 3q ⇔ p > q. The condition B > 0 does the real work — it alone kills the branch x < −5 that squaring lets in.
Solution
1. Statement I guards: x + 14 ≥ 0 gives x ≥ −14, and x + 2 > 0 gives x > −2, so the working domain is x > −2.
2. Square: x + 14 < (x + 2)² = x² + 4x + 4 ⇒ x² + 3x − 10 > 0 ⇒ (x + 5)(x − 2) > 0 ⇒ x < −5 or x > 2.
3. Intersect with x > −2: the branch x < −5 dies and only x > 2 survives, so the solution is (2, ∞) and Statement I is true. Check x = 3: √17 ≈ 4.12 < 5, and x = 2 gives 4 = 4, correctly excluded.
4. Statement II: write the right side to base 3 — (1/9)1/x = (3−2)1/x = 3−2/x, with x ≠ 0 forced by the exponent.
5. Base 3 > 1 is increasing, so 3x+2 > 3−2/x ⇔ x + 2 > −2/x ⇔ (x² + 2x + 2)/x > 0 after moving everything to one side.
6. The numerator is x² + 2x + 2 = (x + 1)² + 1 > 0 for every x, so the sign of the fraction is the sign of x, giving x > 0, i.e. (0, ∞), and Statement II is true. Its discriminant is 4 − 8 = −4 < 0, so the numerator never changes sign and never contributes a boundary point.
7. Both statements check out, so the correct option is (c).

Concept The key identity is alogaM = M, valid for any admissible base a and any M > 0. With a = 1/3 the entire left side collapses to the quadratic M = x² − 10x/3 + 1 itself, so the fearsome-looking inequality is just M ≤ 1. But the identity needs M > 0 for the logarithm to exist, and that constraint removes a whole stretch of the line. So the problem is the pair 0 < M ≤ 1, each solved by a sign chart and then intersected.
Formula alogaM = M for M > 0 ⇒ the inequality becomes 0 < x² − 10x/3 + 1 ≤ 1. Domain and inequality must be imposed together; solving M ≤ 1 alone silently admits points where the logarithm is undefined.
Solution
1. Write M = x² − 10x/3 + 1. The identity gives (1/3)log1/3M = M, so the inequality is simply M ≤ 1, subject to M > 0.
2. Condition M ≤ 1: x² − 10x/3 ≤ 0 ⇒ x(3x − 10) ≤ 0 ⇒ 0 ≤ x ≤ 10/3, endpoints included since the sign is ≤.
3. Condition M > 0: multiply by 3 to clear the fraction, 3x² − 10x + 3 > 0 ⇒ (3x − 1)(x − 3) > 0 ⇒ x < 1/3 or x > 3. Multiplying by the positive constant 3 is safe and never flips the inequality.
4. Intersect the two: [0, 10/3] ∩ ((−∞, 1/3) ∪ (3, ∞)) = [0, 1/3) ∪ (3, 10/3].

8If √(9x^2 + 6x + 1) < 2 - x then : (a) x ∈ (-3/2, 1/4) (b) x ∈ (-3/2, 1/4] (c) x ∈ [-3/2, 1/4) (d) x < 1/4Irrational inequalityfactor 9x^2 - 6x + 1🟢 Exactax ∈ (−3/2, 1/4)
Concept The radicand 9x² + 6x + 1 is a perfect square, (3x + 1)², and the square root of a square is the modulus, not the bracket itself: √(3x + 1)² = |3x + 1|. Writing it as 3x + 1 is wrong for every x < −1/3 and quietly loses half the answer. So the problem is really the modulus inequality |3x + 1| < 2 − x, which unfolds into a two-sided sandwich; the right side must be strictly positive, a guard the sandwich enforces by itself.
Formula √A² = |A|, and |A| < B ⇔ B > 0 and −B < A < B. The single condition |A| < B already forces B > 0, so no separate domain case is needed here.
Solution
1. Factor the radicand: 9x² + 6x + 1 = (3x)² + 2(3x)(1) + 1² = (3x + 1)², so the left side is |3x + 1|.
2. The inequality is |3x + 1| < 2 − x, which demands 2 − x > 0, i.e. x < 2. A modulus is ≥ 0, so it can only be under a strictly positive quantity.
3. Unfold the sandwich: −(2 − x) < 3x + 1 < 2 − x, giving two linear inequalities to solve separately.
4. Left half: x − 2 < 3x + 1 ⇒ −3 < 2x ⇒ x > −3/2.
5. Right half: 3x + 1 < 2 − x ⇒ 4x < 1 ⇒ x < 1/4. Intersecting with x < 2, which is now redundant, gives −3/2 < x < 1/4.
6. Both endpoints are excluded because the original inequality is strict: at x = −3/2, |3x + 1| = 3.5 and 2 − x = 3.5, equal; at x = 1/4, both sides equal 1.75. Equality at both ends is exactly why the answer is open-open, ruling out options (b) and (c).
7. Test an interior point x = 0: √1 = 1 < 2, true; and x = 1 lies outside, √16 = 4 is not < 1. So the answer is (−3/2, 1/4). Option (d) x < 1/4 wrongly keeps everything to the left of −3/2.

9Set of values of x which satisfies ((x^2 - 4)(x - 2))/((x - 1)(x - 6)) ≥ 0, is: (a) (-2, 1) ∪ {2} ∪ (6, ∞) (b) [-2, 1) ∪ {2} ∪ (6, ∞) (c) (-∞, -2] ∪ {2} ∪ (6, ∞) (d) [-2, 1) ∪ (1, 6)Wavy curve methodInequalities (Wavy Curve Method) | Basic to Advanced Class 11 | JEE Main and Advanced🟡 Similarb[−2, 1) ∪ {2} ∪ (6, ∞)
Concept For a rational inequality the sign is governed by the zeros of the numerator and the poles of the denominator together, so factor everything first and mark all four critical points on one line. The wavy-curve rule says the expression alternates sign as you cross a factor of odd multiplicity but keeps its sign across a factor of even multiplicity. Here x = 2 appears twice, from x² − 4 and from the standalone x − 2, so it is a double root and the graph touches zero without crossing. Since the inequality is ≥ 0 that touching point still qualifies, entering as an isolated element.
Formula (x² − 4)(x − 2) = (x − 2)(x + 2)(x − 2) = (x − 2)²(x + 2). Zeros of the numerator satisfy ≥ 0 and are included; zeros of the denominator make the fraction undefined and are always excluded.
Solution
1. Factor fully: E = (x − 2)²(x + 2) / ((x − 1)(x − 6)), with x = 1 and x = 6 struck out of the domain.
2. (x − 2)² ≥ 0 always, so for x ≠ 2 the sign of E equals the sign of (x + 2)/((x − 1)(x − 6)). An even-power factor can be dropped from a sign chart provided its own root is examined separately.
3. Odd-multiplicity critical points are −2, 1 and 6. For very large x all three brackets are positive, so E > 0 on (6, ∞), and the sign then alternates leftwards.
4. Chart: negative on (−∞, −2), positive on (−2, 1), negative on (1, 6), positive on (6, ∞).
5. Collect where E ≥ 0: [−2, 1) ∪ (6, ∞). Here −2 is kept because E(−2) = 0, while 1 and 6 are open because E blows up there. At x = −2 the denominator is (−3)(−8) = 24 ≠ 0, so 0/24 = 0 is a legitimate value.
6. Now recover x = 2, which sits inside the negative block (1, 6): E(2) = 0²·4/((1)(−4)) = 0, and 0 ≥ 0 is true, so x = 2 rejoins as an isolated point.
7. Hence the solution set is [−2, 1) ∪ {2} ∪ (6, ∞), which is option (b).

10If x satisfies |x - 1| + |x - 2| + |x - 3| ≥ 6 then: (a) 0 ≤ x ≤ 4 (b) x ≤ -2 (or) x ≥ 4 (c) x ≤ 0 (or) x ≥ 4 (d) RModulus inequalityIf x satisfies |x-1|+|x-2|+|x-3| ≥ 6 then (a) 0 ≤ x ≤ 4🟢 Exactcx ≤ 0 or x ≥ 4
Concept f(x) = |x − 1| + |x − 2| + |x − 3| is the total distance from x to the three points 1, 2 and 3, a piecewise-linear V-shaped function that is smallest at the median of those points. Its minimum is f(2) = 1 + 0 + 1 = 2, well below 6, so f(x) ≥ 6 cannot hold everywhere: there is a middle gap and the answer must be two outer rays. To locate them, break the line at the three critical points, open each modulus with its correct sign on each piece, and test every candidate against the region that produced it.
Formula |x − a| = x − a when x ≥ a, and a − x when x < a. The minimum of a sum of three such distances sits at the middle point 2, so f(2) = 2 already proves the solution set is not all of R.
Solution
1. Critical points 1, 2, 3 split the line into x < 1, 1 ≤ x < 2, 2 ≤ x < 3 and x ≥ 3.
2. For x < 1 all three brackets flip: (1 − x) + (2 − x) + (3 − x) = 6 − 3x ≥ 6 ⇒ −3x ≥ 0 ⇒ x ≤ 0, which is compatible with x < 1 and gives (−∞, 0].
3. For 1 ≤ x < 2: (x − 1) + (2 − x) + (3 − x) = 4 − x ≥ 6 ⇒ x ≤ −2, which contradicts x ≥ 1, so this strip contributes nothing. On this strip f ranges only over (2, 3], nowhere near 6.
4. For 2 ≤ x < 3: (x − 1) + (x − 2) + (3 − x) = x ≥ 6, again impossible inside [2, 3), so this strip is empty too.
5. For x ≥ 3 all brackets open positively: (x − 1) + (x − 2) + (x − 3) = 3x − 6 ≥ 6 ⇒ x ≥ 4, giving [4, ∞).
6. Both endpoints belong, because f(0) = 1 + 2 + 3 = 6 and f(4) = 3 + 2 + 1 = 6, and the inequality is ≥. Had it been a strict >, both brackets would open and the answer would change.
7. Taking the union of the four regions, the solution is x ≤ 0 or x ≥ 4, i.e. option (c).
