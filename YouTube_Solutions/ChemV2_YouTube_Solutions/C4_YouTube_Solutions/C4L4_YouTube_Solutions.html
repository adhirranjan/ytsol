1Generally, the first ionisation energy increases along a period. But there are some exceptions. One which is not an exception is:Exceptions in IE periodicityGenerally, the first ionisation energy increases along a period. But there are some exceptions🟢 ExactbNa and Mg
Concept Across a period the nuclear charge rises by one proton per step while the new electron enters the same shell, so it screens its neighbours very poorly. The effective nuclear charge Zeff therefore climbs steadily, the valence electron is held tighter, and IE₁ rises left → right. That is the rule. It is broken at exactly two kinds of step, and both breaks come from electronic configuration, not from nuclear charge: (i) group 2 → 13, where the electron being removed switches from a penetrating ns orbital to a higher-energy, less penetrating np orbital; and (ii) group 15 → 16, where a specially stable half-filled np³ set is replaced by np⁴, in which two electrons must now pair inside one orbital and repel each other. The question asks for the pair that is not an exception, i.e. the pair that behaves normally.
Key relation Rule: IE₁ increases as Zeff increases along a period. Zeff = Z − σ; along a period Z rises by 1 per element but σ rises by only ≈0.35, so Zeff gains ≈0.65 per step. Exceptions: gp 2 → 13 (ns² → ns²np¹, because energy of np > ns) and gp 15 → 16 (np³ → np⁴, because half-filled np³ is extra stable).
Solution
1. Test each pair against the book's own period-2 and period-3 IE₁ data (kJ mol⁻¹).
2. (a) N → O: 1402.3 → 1314.0. IE₁ falls, so this is an exception (group 15 → 16).N is 2s²2p³ (half-filled p, extra stable); O is 2s²2p⁴, where the fourth p-electron is forced to pair up and is pushed out by inter-electronic repulsion.
3. (c) Mg → Al: 737.7 → 577.6. IE₁ falls, so this is an exception (group 2 → 13).Mg loses a 3s electron; Al loses a 3p electron, and 3p lies higher in energy and is less penetrating than 3s, so it is easier to pull out.
4. (d) Be → B: 899.5 → 800.6. IE₁ falls, again a group 2 → 13 exception (2s² → 2s²2p¹).
5. (b) Na → Mg: 495.8 → 737.7. IE₁ rises, and it rises steeply — both electrons come from the same 3s subshell, so only Zeff changes. This is the ordinary trend, hence not an exception.

2The first ionisation enthalpy of the elements C, N, P, Si are in the order of:IE order across period & groupThe first ionisation enthalpy of the elements C, N, P, Si are in the order of🟢 ExactcSi < P < C < N
Concept Four elements, two periods, two groups — so you must combine both trends. C and N sit in period 2 (n = 2); Si and P sit directly below them in period 3 (n = 3). Down a group the valence shell number rises, the electron sits further out and is screened by a whole extra filled shell, so IE₁ falls sharply. Across a period Zeff rises, so IE₁ climbs. Because the shell-number effect (a change in n) is much stronger than the one-proton effect, every period-3 member here lies below every period-2 member. Then you only need to order within each period.
Key relation IE ∝ Zeff / n² (qualitatively). Going down a group n increases — the dominant, size-driven effect — so IE drops; going across a period n is fixed and Zeff rises, so IE climbs. Group 14 → 15 is not one of the exception steps, so C < N and Si < P both hold normally.
Solution
1. Place the four elements: C (Z = 6, gp 14, period 2), N (Z = 7, gp 15, period 2), Si (Z = 14, gp 14, period 3), P (Z = 15, gp 15, period 3).
2. Period 3 lies below period 2 in both groups, so Si < C and P < N.Si has its valence electrons in n = 3 and a full neon core (10 shielding electrons); C has them in n = 2 with only a 1s² core.
3. Within period 3: gp 14 → gp 15 is a normal rise, so Si < P (786.5 < 1011.8).
4. Within period 2: gp 14 → gp 15 is a normal rise, so C < N (1086.4 < 1402.3).
5. Now stitch the two chains together. The only quantity still in doubt is P vs C — and the real values settle it: P = 1011.8 while C = 1086.4, so P < C.Even though P is in group 15 (a half-filled-p bonus) it is one whole shell further out than C, and the extra shell wins.
6. Chain: Si (786.5) < P (1011.8) < C (1086.4) < N (1402.3) ⇒ option (c). (a) puts C lowest — impossible, C is period 2; (b) puts N lowest — N is the highest of all four; (d) puts N below C — reverses a normal period trend.

3Ionisation enthalpy of nitrogen is more than oxygen because of:Half-filled stability (N vs O)MCQ solved: "Ionisation energy of nitrogen is more than oxygen because…"🟢 Exactaextra stability of half filled orbitals
Concept Oxygen has one more proton than nitrogen, so by the Zeff rule alone O should be harder to ionise. It is not — IE₁(N) = 1402.3 > IE₁(O) = 1314.0 kJ mol⁻¹. The cause is configuration. Nitrogen is 1s²2s²2p³: all three 2p orbitals hold exactly one electron each, with parallel spins. That half-filled set is unusually stable for two reasons — the electrons are spread over three different orbitals so inter-electronic repulsion is minimal, and the parallel spins give maximum exchange energy. Oxygen is 1s²2s²2p⁴: its fourth p-electron is forced to pair up in an already-occupied orbital, where it suffers strong repulsion from its partner. Removing that crowded electron is easy, and it also converts O into O⁺ (2p³), itself a stable half-filled species — a double incentive.
Key relation ₇N = 1s² 2s² 2px¹ 2py¹ 2pz¹ — half filled, extra stable. ₈O = 1s² 2s² 2px² 2py¹ 2pz¹ — one paired orbital. Ionising O gives O⁺ = 2p³, a half-filled cation, so the products favour the ionisation; ionising N destroys a half-filled set, so the products oppose it.
Solution
1. Write both configurations and mark the p-subshell occupancy: N → 2p³ (half filled), O → 2p⁴ (one pair).
2. Identify what happens on ionisation: N (2p³) → N⁺ (2p²) destroys the stable arrangement; O (2p⁴) → O⁺ (2p³) creates one.
3. Therefore IE₁(N) > IE₁(O) despite O having the larger nuclear charge — option (a).
4. Eliminate the distractors:
  • (b) "more number of energy levels" — false; N and O are both period 2, both use n = 1 and 2. Identical shell count.
  • (c) "less number of valence electrons" — true as a statement (N has 5, O has 6) but it is the wrong cause: fewer valence electrons normally means lower IE, not higher.
  • (d) "smaller size" — false; along a period size decreases left → right, so N is larger than O, not smaller.
 element  config       2p boxes        on ionisation      IE₁ (kJ/mol)
 ₇N       2s² 2p³      ↑ | ↑ | ↑       loses half-fill      1402.3   HIGHER
 ₈O       2s² 2p⁴      ↑↓| ↑ | ↑       gains half-fill      1314.0   lower
 ⇒ cause = extra stability of the half-filled 2p³ set     <-- answer (a)
⚡ JEE Trick Any time the observed IE order contradicts Zeff, the answer is almost always "half-filled or fully-filled subshell". Only two dips exist per period (2→13 and 15→16); attribute the 15→16 dip to half-filled p³ and the 2→13 dip to ns vs np energy — never to size or shielding. Trap: option (d) "smaller size" is the reflex answer for higher IE, but here it is factually backwards, and the examiner is checking whether you know that atomic radius shrinks across a period.
Answer: (a) extra stability of half filled orbitals.

1How does ionization enthalpy vary along a period and along a group?IE trends: period & groupIonisation enthalpy — variation along a period and down a group🟡 Similar—
Concept Ionisation enthalpy measures how strongly the nucleus grips the outermost electron, so any trend in IE is really a trend in the net electrostatic pull on that electron. Two competing quantities control it: the effective nuclear charge Zeff pulling inward, and the distance of the electron from the nucleus (set by the shell number n, and enlarged by shielding from inner electrons) pushing the energy up. Across a period only Zeff changes appreciably; down a group it is n that changes, and n is by far the more powerful of the two. That single asymmetry is the whole answer.
Statement Along a period (left → right): IE increases. Each step adds one proton to the nucleus but adds the electron to the same shell, where it screens the others poorly (σ ≈ 0.35 per same-shell electron), so Zeff = Z − σ climbs by roughly 0.65 per element; the atom also contracts, so the valence electron is both more strongly attracted and closer in. Down a group (top → bottom): IE decreases. Each step adds a whole new shell: n rises, the valence electron sits far from the nucleus, and a complete inner shell (σ ≈ 1.0 per core electron) screens the added protons almost perfectly, so Zeff stays nearly constant while the distance grows.
Solution
1. Period trend with data (period 2, kJ mol⁻¹): Li 520.3 → Be 899.3 → B 800.6 → C 1086.4 → N 1402.3 → O 1314.0 → F 1681.0 → Ne 2080.7. Net rise from Li to Ne is roughly four-fold.Cause: rising Zeff with a constant shell number. Note the two dips (Be → B and N → O) — genuine exceptions caused by configuration, discussed below.
2. Group trend with data (group 1, kJ mol⁻¹): Li 520.3 → Na 495.8 → K 418.9 → Rb 403.0 → Cs 375.7 — a steady fall.Cause: the valence electron moves from 2s to 3s to 4s to 5s to 6s; each new shell puts it further out and adds a fully shielding inner shell.
3. Consequences worth quoting in a board answer: the noble gases (top-right, He 2372) have the highest IE in each period, the alkali metals (bottom-left, Cs 375.7) the lowest; overall IE is maximum for helium and minimum for caesium (francium excepted).
4. State the exceptions — a board answer is incomplete without them: IE dips at group 2 → 13 (Be→B 899.3→800.6; Mg→Al 737.7→577.6; Ca→Ga 589.8→578.8) because the electron leaves a higher-energy np instead of ns, and at group 15 → 16 (N→O 1402.3→1314.0; P→S 1011.8→999.6; As→Se 944.0→940.9) because a stable half-filled np³ set is being destroyed.

2Explain the factors affecting ionization enthalpy.Factors governing IEDefine ionisation enthalpy and discuss every factor that affects it🟢 Exact—
Concept Ionisation enthalpy is fixed by one physical quantity — the force of attraction between the nucleus and the electron being removed. Every "factor" in the syllabus is just a different way of changing that force through Coulomb's law: either you change the charge that pulls (nuclear charge, shielding), or you change the distance over which it pulls (atomic size, subshell type), or you change the intrinsic stability of the arrangement the electron is leaving (half-filled / fully-filled configurations). Presenting the five factors as one law with five handles is what earns full marks.
Key relation F ∝ Zeff × e / r², and IE ∝ F. Zeff = Z − σ, where σ is the screening constant; r is the distance of the valence electron from the nucleus. Anything that raises Zeff or lowers r raises IE.
Solution
1. (a) Effective nuclear charge. The greater the Zeff, the greater the nucleus–electron attraction and the more energy is needed. IE ∝ Zeff.This is why IE climbs across a period: Z rises by 1 while σ rises by only ≈0.35 per added same-shell electron.
2. (b) Size of the atom. As atomic size increases the nuclear force on the valence electron falls off as 1/r², so less energy is needed — larger atom ⇒ lower IE.This is the dominant factor down a group: Cs (r ≈ 265 pm, IE 375.7) versus Li (r ≈ 152 pm, IE 520.3).
3. (c) Subshell from which the electron is removed. Within a given shell the orbital energies run s < p < d < f, so the more penetrating, lower-energy s-electron is held closest and most tightly. Hence the energy needed follows s > p > d > f.Direct consequence: IE₁ of B (removes 2p) < IE₁ of Be (removes 2s), i.e. 800.6 < 899.5 kJ mol⁻¹.
4. (d) Nature of the configuration. Half-filled and completely-filled subshells are extra stable (minimum repulsion, maximum exchange energy), so removing an electron from them costs more.IE₁ of N (2p³) > IE₁ of O (2p⁴), but IE₂ of O > IE₂ of N, because the second removal is from O⁺ (2p³, half filled) versus N⁺ (2p²).
5. (e) Shielding / screening effect. Inner electrons repel the valence electron and mask part of the nuclear charge; the more shielding, the smaller the Zeff actually felt and the lower the IE.Shielding power runs s > p > d > f, which is why poorly-shielding d and f electrons let Ga, In and Tl keep unexpectedly high IE values.

 (b) atomic size               r increases           decreases      Li 520 → Cs 376
 (c) subshell (s<p<d<f)        remove from p not s   decreases      Be 899.5 > B 800.6

⚡ JEE Trick Remember the five factors as the mnemonic "Charge, Size, Subshell, Configuration, Shielding" — and note they split into two that raise IE (Zeff, stable configuration) and three that lower it (size, higher subshell, shielding). In an MCQ asking "which does NOT increase IE", the answer is always drawn from the second list — usually shielding. Trap: shielding and effective nuclear charge are not two independent factors but two sides of Zeff = Z − σ; say so and you look like you understand the physics rather than a memorised list.
Answer: IE is governed by the nucleus–electron attraction, IE ∝ Zeff/r². It rises with (a) effective nuclear charge and (d) half/fully-filled configurations, and falls with (b) atomic size, (c) removal from a higher subshell (s > p > d > f) and (e) shielding.
3Why is the second ionization enthalpy greater than the first ionization enthalpy?Successive IEWhy the second ionisation enthalpy is always higher than the first🟢 Exact—
Concept The first electron is pulled off a neutral atom; the second is pulled off a cation that already carries a +1 charge. Two things change, and both work in the same direction. First, electrostatics: you are now separating a negative electron from a net-positive ion instead of from a neutral species, so the attraction to be overcome is larger. Second — and this is the point examiners want — the proton count is unchanged while the electron count has dropped by one, so every remaining electron feels a larger effective nuclear charge, the ion contracts, and the electrons are held more tightly. The same argument repeats at every stage, which is why IE₃ > IE₂ > IE₁ for every element without exception.
Key relation M(g) → M⁺(g) + e⁻, ΔH = IE₁; M⁺(g) → M²⁺(g) + e⁻, ΔH = IE₂; M²⁺(g) → M³⁺(g) + e⁻, ΔH = IE₃. Always IE₃ > IE₂ > IE₁. Z is fixed but the electron count falls, so Zeff = Z − σ rises at each step and r shrinks; by IE ∝ Zeff/r² both changes push IE up.
Solution
1. Write the two processes explicitly so the charge difference is visible: IE₁ removes e⁻ from neutral M; IE₂ removes e⁻ from M⁺.
2. Electrostatic reason: work must be done against a net positive charge in the second step, which was absent in the first.
3. Zeff reason: after the first removal the nucleus still has all Z protons but one fewer electron to share them, so the surviving electrons are "more effectively pulled by the nucleus due to increased effective nuclear charge" — the book's own wording.
4. Size reason: the cation is smaller than the parent atom (M⁺ < M), so the remaining electrons sit closer in and are gripped harder.
5. Verify with the lecture's data (kJ mol⁻¹):Li: IE₁ 520.3, IE₂ 7298.1, IE₃ 11814.9. Be: IE₁ 899.5, IE₂ 1757.1, IE₃ 14848.7. The rise is never small, and it becomes enormous whenever the next electron must come out of a noble-gas core.
6. Note the size of the jumps: for Li the IE₁ → IE₂ ratio is 7298.1/520.3 ≈ 14, because Li⁺ is already 1s² (a helium core); for Be the big jump is at IE₂ → IE₃ (1757.1 → 14848.7, ≈ 8.5×), because Be²⁺ is the helium core. The position of the huge jump tells you the number of valence electrons.

Answer: because the second electron is removed from a positively charged, smaller cation in which the unchanged nuclear charge acts on fewer electrons — Zeff is larger and r is smaller, so IE₂ > IE₁ (and IE₃ > IE₂, always).
4First ionization enthalpy of oxygen is less than that of nitrogen. Explain.N vs O anomalyWhy nitrogen has a higher ionisation enthalpy than oxygen🟢 Exact—
Concept Oxygen follows nitrogen in period 2, so on the Zeff rule alone it should have the larger IE₁. The measured values say otherwise: N = 1402.3, O = 1314.0 kJ mol⁻¹. The explanation is electronic configuration, and it has two halves that should both be written out. (i) Nitrogen's 2p³ is exactly half filled: one electron in each of 2px, 2py, 2pz with parallel spins, giving minimum electron–electron repulsion and maximum exchange energy — an extra-stable arrangement that resists ionisation. (ii) Oxygen's 2p⁴ has one doubly occupied p-orbital; the two paired electrons crowd the same region of space and repel strongly, so one of them is already half-pushed out. Removing it also leaves O⁺ as 2p³ — the stable half-filled arrangement — so the products of the ionisation are favourable.

Concept Graph questions are decoded from the numbers on the axis labels, not from the shape. The five plotted values — 520, 496, 419, 403, 374 — are precisely the first ionisation enthalpies of Li, Na, K, Rb and Cs in kJ mol⁻¹, straight out of this lecture's group-1 table. The second half of the question links that to reactivity: an alkali metal reacts by losing its ns¹ electron, so the easier the loss (lower IE), the more reactive the metal. Key relation Li 520.3, Na 495.8, K 418.9, Rb 403.0, Cs 375.7 kJ mol⁻¹ — the lecture's own group-1 IE₁ data. For metals, chemical reactivity ∝ ease of forming M⁺ ∝ 1/IE. 1. Match the plotted numbers to data you know: 520 ≈ Li (520.3), 496 ≈ Na (495.8), 419 ≈ K (418.9), 403 ≈ Rb (403.0), 374 ≈ Cs (375.7). The property is ionisation enthalpy, and the elements form group 1.

Concept Two independent signals are available for each element, and using both makes the identification airtight. The absolute size of IE₁ says how tightly the outermost electron is held: a value above ~2000 kJ mol⁻¹ means a noble gas, ~500 means an alkali metal, ~900 means an alkaline earth. The ratio IE₂/IE₁ says how many valence electrons there are: a huge ratio means the cliff came at IE₂, i.e. one valence electron. Key relation He: 2372.3, 5250.5 (ratio 2.21); Li: 520.2, 7298.1 (ratio 14.03); Be: 899.5, 1757.1 (ratio 1.95). These are exactly the values in the question, and the middle two match this lecture's own successive-IE table for Li and Be.
Solution
1. X (2372, 5251): IE₁ is enormous — over 2300 kJ mol⁻¹ — which only a noble gas can manage, since only a closed shell holds its electrons that tightly. Ratio 5251/2372 = 2.21, modest, because helium's second electron is also a 1s electron. ⇒ X = noble gas (helium).
2. Y (520, 7297): IE₁ is very small (one loosely held ns¹ electron), and the ratio is 7297/520 = 14.0, an extreme cliff at the second ionisation. That combination — lowest IE₁, biggest jump at IE₂ — is the fingerprint of one valence electron. ⇒ Y = alkali metal (lithium; Li⁺ is already [He]).
3. Z (900, 1758): IE₁ is intermediate and the ratio is only 1758/900 = 1.95, so the second electron is still a valence electron. Two valence electrons ⇒ Z = alkaline earth metal (beryllium; the cliff would come at IE₃ = 14 848.7).
4. Assemble: X = noble gas, Y = alkali metal, Z = alkaline earth metal ⇒ option (a).
5. Eliminate the others: (b) and (d) call X an alkali metal, impossible with IE₁ = 2372 (five times a real alkali metal's value); (c) makes Z a noble gas, impossible with IE₁ = 900 and a ratio of only 1.95.
6. Cross-check the internal consistency: an alkali metal must have the lowest IE₁ of the three and a noble gas the highest, and here 520 < 900 < 2372 orders Y < Z < X exactly as the classification demands.
