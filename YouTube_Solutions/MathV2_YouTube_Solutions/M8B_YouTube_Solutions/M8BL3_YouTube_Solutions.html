Concept Multiplying every term by the same non-zero k rescales the whole progression but leaves the ratio of neighbours untouched, because k cancels top and bottom. Contrast the A.P., where scaling changes d to kd.
Formula (an+1k)/(ank) = an+1/an = r
Solution
1. Let bn = k·an.
2. Ratio test: bn+1/bn = (k an+1)/(k an) = an+1/an = r.
3. Constant ratio ⇒ the new sequence is a G.P., and its ratio is the same r.Only the first term changes, to ka₁.
4. k ≠ 0 is essential: k = 0 would collapse every term to 0 and the ratio would be undefined.
5. Example: 3, 6, 12 (r = 2) times 5 gives 15, 30, 60 — still r = 2 ✓.
6. Contrast: for an A.P., scaling multiplies d by k; for a G.P., scaling leaves r alone.
   b_n = k a_n
   b_(n+1)/b_n = r        (unchanged)

   3, 6, 12  (r=2)  x5 ->  15, 30, 60  (r=2)

Concept A logarithm converts multiplication into addition. Since consecutive G.P. terms differ by a factor r, their logarithms differ by a constant amount log r — which is exactly an A.P.
Formula log an+1 − log an = log(an+1/an) = log r
Solution
1. The terms are a, ar, ar², … so their logs are log a, log a + log r, log a + 2log r, …
2. Consecutive difference: log an+1 − log an = log r, a constant.
3. Constant difference ⇒ the logarithms form an A.P. with common difference log r.
4. "Positive numbers" is essential — logarithms of negative terms are undefined, so a G.P. with r < 0 is excluded.
5. Example: 1, 10, 100, 1000 (r = 10) gives logs 0, 1, 2, 3 — an A.P. with d = 1 ✓.
6. The converse also holds: if the logs are in A.P., the original numbers are in G.P.
   a, ar, ar^2, ...
   logs : log a, log a + log r, log a + 2 log r, ...
   difference = log r   (constant)  ->  A.P.

   1, 10, 100, 1000  ->  0, 1, 2, 3

Answer: an A.P., with common difference log r.

10If 0 < φ < π/2, and x = Σn=0∞cos2nφ, y = Σn=0∞sin2nφ and z = Σn=0∞cos2nφ·sin2nφ then   (a) xyz = xz + y   (b) xyz = xy + z   (c) xyz = yz + x   (d) xy = yz + zThree trigonometric infinite G.P.slet 0 lt phi lt pi/2, x = sum cos^(2n) phi, y = sum sin^(2n) phi and z = sum cos^(2n) phi sin^(2n) phi🟢 Exactbxyz = xy + z
Concept All three are infinite G.P.s with first term 1. Sum each, then express sin²φ and cos²φ in terms of x and y — the Pythagorean identity is not even needed, just the two reciprocal relations.
Formula Σn≥0tn = 1/(1 − t)
Solution
1. x = 1/(1 − cos²φ) = 1/sin²φ, so sin²φ = 1/x.
2. y = 1/(1 − sin²φ) = 1/cos²φ, so cos²φ = 1/y.
3. z = 1/(1 − cos²φ·sin²φ) — its ratio is the product cos²φ sin²φ.
4. Substitute: z = 1/(1 − (1/y)(1/x)) = 1/(1 − 1/(xy)) = xy/(xy − 1).
5. Cross-multiply: z(xy − 1) = xy ⇒ xyz − z = xy.
6. Therefore xyz = xy + z → option (b). (Check at φ = π/4: x = y = 2, z = 1/(1 − 1/4) = 4/3; then xyz = 16/3 and xy + z = 4 + 4/3 = 16/3 ✓.)
   x = 1/sin^2 phi   ->  sin^2 phi = 1/x
   y = 1/cos^2 phi   ->  cos^2 phi = 1/y
   z = 1/(1 - 1/(xy)) = xy/(xy - 1)

   z(xy - 1) = xy   ->   xyz - z = xy   ->   xyz = xy + z

⚡ JEE Trick Convert each sum into its reciprocal relation (sin²φ = 1/x, cos²φ = 1/y) rather than carrying trigonometric functions through the algebra — the third sum's ratio is then simply 1/(xy). Verifying at φ = π/4, where x = y = 2, is a two-second check that separates option (b) from its three near-identical rivals.
Answer: (b) xyz = xy + z.
