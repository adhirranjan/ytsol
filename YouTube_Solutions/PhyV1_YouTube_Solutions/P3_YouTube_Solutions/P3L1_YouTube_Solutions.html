Concept A scalar is fully specified by a magnitude plus a unit — one number carries all the information. A vector needs a magnitude and a direction, and it must obey the triangle/parallelogram law of addition. The physical test is simple: ask "does reversing or rotating the quantity in space change it?" If a direction has to be quoted for the quantity to mean anything, it is a vector; if not, it is a scalar.
Rule scalar = magnitude + unit ; vector = magnitude + unit + direction (and adds by the triangle law). Having a unit is not the deciding factor — both kinds carry units. The deciding factor is whether a direction is required and whether the quantity adds vectorially.
Solution
1. Test Force: quoting "10 N" is meaningless without saying which way it pushes; two forces add by the parallelogram law. Vector — rules out (a).10 N east and 10 N west give a resultant of 0 N, not 20 N — proof of vector addition.
2. Test Displacement: "5 m" is incomplete; you must say 5 m in which direction. Vector — rules out (b).
3. Test Temperature: "300 K" is complete on its own — there is no such thing as "300 K towards the north". Scalar ✓Temperature is a measure of average molecular kinetic energy, an energy-like quantity, and energy has no direction.
4. Test Momentum: p = m·v (kg m s⁻¹) — mass m is a scalar but velocity v is a vector, so p inherits v's direction. Vector — rules out (d).

⚡ JEE Trick Any quantity defined as (scalar) × (vector) is automatically a vector — momentum m·v, force m·a, impulse F·t. Trap: temperature and current are the two classic "looks directional but is scalar" traps — current has a direction of flow but adds algebraically at a junction (Kirchhoff), not by the parallelogram law, so it is a scalar.

Concept The magnitude of a vector is its length — the distance from tail to tip. When a vector is written in component form r = xî + yĵ, the components x and y are the two perpendicular legs of a right triangle and the vector itself is the hypotenuse. Concept The displacement vector from a point A to a point B is the straight arrow drawn from A to B; it records only the net change in position, ignoring the actual path taken. In terms of position vectors it is final minus initial — a subtraction that must be done separately on each of the three coordinates. Its magnitude is then the straight-line distance between the two points, obtained by the 3-D Pythagoras theorem.
Formula AB = r_B − r_A = (x_B − x_A)î + (y_B − y_A)ĵ + (z_B − z_A)k̂ and |AB| = √(Δx² + Δy² + Δz²). Subtracting position vectors component-by-component is legal because î, ĵ, k̂ are independent directions; each axis keeps its own book. Coordinates here are pure numbers, so the answer is a pure number (had they been in metres, AB would be in m).
Solution
1. Write the two position vectors from A(2, −1, 3) and B(5, 2, 7): r_A = 2î − 1ĵ + 3k̂ and r_B = 5î + 2ĵ + 7k̂.
2. Apply "final minus initial", one axis at a time — x: Δx = 5 − 2 = 3.
3. y: Δy = 2 − (−1) = 2 + 1 = 3.Watch the double negative — subtracting −1 ADDS 1. This is the step the wrong option (c) is built to catch.
4. z: Δz = 7 − 3 = 4.
5. Assemble the vector: AB = 3î + 3ĵ + 4k̂.
6. Magnitude — square each component: 3² = 9, 3² = 9, 4² = 16.
7. Sum the squares: 9 + 9 + 16 = 34.
8. Take the root: |AB| = √34 ≈ 5.83.34 is not a perfect square, so √34 is the exact answer — leave it in surd form.

Concept The zero (null) vector 0 is the vector of magnitude zero — it has no defined direction, and it plays exactly the role that the number 0 plays in ordinary arithmetic: it is the additive identity. Physically it is what you get when a body returns to its starting point (zero displacement) or when balanced forces cancel. This question checks whether you can keep vector algebra honest: every equation must have a vector on both sides, and adding 0 must never change a vector.
Rules A + 0 = A (identity) ; A − 0 = A ; n·0 = 0 for any scalar n ; A + 0 = 0 + A (commutative). Vector addition is commutative and associative just like scalar addition, and scaling a vector of zero length by any finite number still leaves zero length. Note |0| = 0 with the same units as the vectors it is added to.
Solution
1. Test (a) A + 0 = A: adding a vector of zero length shifts nothing, so the result is A itself. CORRECT ✓This is the very definition of the additive identity.
2. Test (b) A − 0 = 0: subtracting nothing from A must leave A unchanged, so A − 0 = A, not 0. WRONG ✗It would only equal 0 in the special case A = 0, which is not given. The statement confuses "subtract the zero vector" with "subtract A itself".
3. Test (c) 0 × n = 0 for nonzero scalar n: scaling multiplies the magnitude, n × 0 = 0, so the result still has zero length. CORRECT ✓Any finite multiple of a zero-length arrow is still a zero-length arrow.
4. Test (d) A + 0 = 0 + A: vector addition is commutative (the parallelogram is the same whichever side you start from). CORRECT ✓
5. Collect the correct statements: (a), (c) and (d).

 (a) A + 0 = A        A = A             ✓ identity
 (b) A − 0 = 0        A ≠ 0             ✗ should be A
 (c) 0 × n = 0        0 = 0             ✓ scaling zero

Statement (b) fails instantly because its left side is a general vector A while its right side is pinned at zero — an equation cannot force an arbitrary A to vanish. Trap: the zero vector has no direction (not "every direction"), yet it is still a vector — never call it a scalar, and never write A + 0 = 0.

Concept When several vectors are drawn on one set of axes with their inclinations marked, the cleanest way to find the angle between any two of them is to give every vector a single standard direction angle θ — measured anticlockwise from the +x axis. Once every arrow is reduced to one number, the angle between any pair is just the difference of those numbers. The whole difficulty of this question is reading the figure correctly: you must notice which axis each marked angle is measured from, and which way each arrowhead actually points.
Formula angle between two vectors = |θ₁ − θ₂| (in degrees), taking 360° − result if that exceeds 180°. The angle between two vectors is defined as the smaller angle formed when their tails are placed together, so it always lies in 0°–180°. Conversions used: a ray making angle φ with the +y axis on the left has θ = 90° + φ; reversing a ray changes θ by 180°.
Solution
1. Vector C — the figure marks 30° between the +x axis and C, with C's arrowhead up and to the right. So θ_C = 30°.
2. Vector A — the 40° is marked at the bottom, between the −y axis and A's tail. The tail points down-left at θ = −90° − 40° = −130°, so A itself (arrowhead up-right) is the reverse: θ_A = −130° + 180° = 50°.Equivalently: A makes 40° with the y-axis, so it makes 90° − 40° = 50° with the x-axis.
3. Vector B — the 70° arc sits above the x-axis on the left of B's line, and B's arrowhead leans slightly left of vertical. So B makes 70° with the negative x-direction: θ_B = 180° − 70° = 110°.
4. Vector D — the 60° is marked between the +y axis and the up-left half of D's line, so that ray is at 90° + 60° = 150°. D's arrowhead points the opposite way (down-right), so θ_D = 150° − 180° = −30°.
5. The question asks for ∠(B, D). Substitute: ∠(B,D) = |θ_B − θ_D| = |110° − (−30°)| = |110° + 30°|.
6. Evaluate: ∠(B, D) = 140°.140° < 180°, so this already is the smaller angle — no need to subtract from 360°.

1Define scalars and vectors. Give two examples of each.Scalar & vector — definitionsScalars and Vectors — definitions and examples · Classification of scalar and vector quantities (Class 11)🟢 Exact—
Concept A scalar is a physical quantity completely specified by a single number — its magnitude — together with a unit; no direction is attached. A vector requires both a magnitude and a direction, and it must combine by the triangle / parallelogram law instead of ordinary arithmetic. The direction is not decoration: reverse it and the physics changes (10 N up ≠ 10 N down), which is exactly why vectors cannot be added like plain numbers.
Rule scalar = magnitude + unit ; vector = magnitude + unit + direction (obeys triangle law). The presence of a unit does not decide the type — both carry units. The deciding test is whether a direction is needed and whether the quantity adds vectorially.
Solution
1. Scalar — definition: a quantity having magnitude only; it is fully stated by a number and a unit and obeys ordinary algebra (5 kg + 3 kg = 8 kg).
2. Two scalar examples: mass (e.g. 5 kg) and temperature (e.g. 300 K). Others: time, speed, energy, work.
3. Vector — definition: a quantity having both magnitude and direction that adds by the triangle/parallelogram law.Two 10 N forces can sum to anything from 0 to 20 N depending on their directions — proof they are not ordinary numbers.
4. Two vector examples: displacement (e.g. 5 m due east) and force (e.g. 10 N downward). Others: velocity, acceleration, momentum.
5. Quick test: ask "does the quantity need a direction to be meaningful?" — if yes it is a vector, if no it is a scalar.
 quantity        needs direction?   adds by            type
 mass 5 kg       NO                 ordinary algebra   scalar
 temperature     NO                 ordinary algebra   scalar
 displacement    YES                triangle law       vector  <-- example
 force 10 N      YES                triangle law       vector  <-- example
⚡ JEE Trick Do not use "has a unit" or even "has a direction" as the sole test — electric current has a direction of flow yet is a scalar because it adds algebraically at a junction (Kirchhoff), not by the parallelogram law. The real litmus test is the law of addition. Trap: writing "speed" and "velocity" as one example each — they are different quantities (speed scalar, velocity vector), so pick genuinely distinct examples.
Answer: Scalar = magnitude + unit only (e.g. mass, temperature); Vector = magnitude + direction, adds by triangle law (e.g. displacement, force).

Concept Two special vectors are being defined. An equal vector is about matching two vectors — they count as equal only when they agree in both magnitude and direction, no matter where their tails are drawn. A null (zero) vector is the additive identity of vector algebra: it has zero magnitude, so its direction is left undefined (arbitrary), and adding it changes nothing.
Rule A = B ⇔ |A| = |B| and same direction ; null vector 0: |0| = 0, direction indeterminate. Position is irrelevant for equality — vectors are "free", so two arrows anywhere in space are equal if they are parallel, same-sense and same-length.
Solution
1. Equal vectors — definition: two vectors are equal if they have the same magnitude and the same direction; their points of application (tails) do not matter.
2. Example of equal vectors: the velocity arrows of two cars both moving at 60 km/h due north are equal, even on different roads.
3. Null vector — definition: a vector of zero magnitude and arbitrary (undefined) direction, written 0.It arises naturally as A + (−A) = 0, or as the displacement of a body that returns to its start.
4. Properties of the null vector: A + 0 = A, A − A = 0, and λ·0 = 0 for any scalar λ.

4What are like vectors?Like vectorsLike and unlike vectors🟢 Exact—
Concept "Like" and "unlike" classify a pair of vectors purely by the angle between them, ignoring their sizes. Like vectors point the same way — they are parallel with a 0° angle between them — even if one is longer than the other. So likeness is a statement about direction (sense), not magnitude.
Rule Like (parallel, same sense) ⇒ θ = 0° ; magnitudes may differ. If B = kA with k > 0 the two are like vectors; the positive scalar k rescales length but keeps direction, so the enclosed angle stays 0°.
Solution
1. Definition: two (or more) vectors are like vectors if they act along the same direction — i.e. they are parallel and point the same way, giving an angle of 0° between them.
2. Magnitudes are free: like vectors need NOT be equal in size — 2î and 7î are like vectors, though one is 3.5× the other.
3. Algebraic test: A and B are like if B = kA with the scalar k > 0 (positive multiple).
4. Physical example: the weights of two different books both point vertically downward — same direction, different magnitudes — so they are like vectors.

⚡ JEE Trick Like ⇔ 0°, Unlike ⇔ 180° — both are collinear, so their cross product is zero in either case; only the sign of k (or of the dot product) separates "like" from "unlike". Trap: assuming like vectors must be equal — equality demands equal magnitude too, but likeness only demands the same direction.
Answer: Like vectors are vectors acting in the same direction (parallel, angle 0° between them); their magnitudes may be equal or unequal. e.g. 2î and 7î.

Concept Unlike vectors are the direction-opposites of like vectors: they act along the same line but point in opposite senses, so the angle between them is 180°. Like the "like" classification, this is entirely about direction — the two vectors may have any magnitudes at all. A vector and its negative (−A) are the archetype of unlike vectors.
Rule Unlike (antiparallel) ⇒ θ = 180° ; magnitudes may differ. If B = kA with k < 0, then A and B are unlike vectors — a negative scalar flips the direction while keeping the line of action, so the enclosed angle is 180°.
Solution
1. Definition: two vectors are unlike vectors if they act along opposite directions — parallel line, opposite sense — so the angle between them is 180°.
2. Magnitudes are free: they need not be equal; 3î and −8î are unlike vectors despite different lengths.
3. Algebraic test: A and B are unlike if B = kA with the scalar k < 0 (negative multiple); the simplest case is B = −A.
4. Physical example: for a body thrown up, its velocity (upward) and its weight (downward) act along the same vertical line in opposite senses — unlike vectors.
