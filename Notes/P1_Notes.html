L-1

Basic Trigonometric Ratios

  • An angle is formed by two rays (sides) sharing a common end point (vertex); it measures the change in direction.
  • Radian measure: θ = arc length / radius = AB/r. If r = 1, then θ = arc length AB.
  • An angle is in standard position if its vertex is at the origin and its initial ray lies along the positive x-axis. Counter-clockwise = positive; clockwise = negative.
radian ↔ degreeπ radians = 180° ⇒ 1° = π/180 rad (≈ 0.02 rad) · 1 rad ≈ 57°

Six trigonometric ratios (right triangle)

T-ratiossin θ = P/H cos θ = B/H tan θ = P/B cosec θ = H/P = 1/sin θ sec θ = H/B = 1/cos θ cot θ = B/P = 1/tan θ
★ CAST rulePositive ratios by quadrant: I All · II only sin & cosec · III only tan & cot · IV only cos & sec.

Angles greater than 90° & negative angles

  • For (nπ ± θ): the function stays the same; sign from CAST.
  • For [(2n+1)·π/2 ± θ]: the function changes to its complementary (sin↔cos, tan↔cot, sec↔cosec); sign from CAST.
  • Negative angles: sin(−θ) = −sin θ, cos(−θ) = cos θ, tan(−θ) = −tan θ.
How to reduce any angle
Step 1: find the quadrant of the angle. Step 2: write it as nπ ± θ (function unchanged) or (2n+1)π/2 ± θ (function becomes co-function). Step 3: attach the sign from CAST for that quadrant. Example: sin 150° = sin(180° − 30°) = +sin 30° = ½; cos 120° = cos(180° − 60°) = −cos 60° = −½.

Cartesian Coordinates, Slope & Straight Lines

  • A point's address is (x, y): x = signed distance from the y-axis, y = signed distance from the x-axis.
  • Axes split the plane into four quadrants, numbered I–IV going anti-clockwise. Signs: I (+,+), II (−,+), III (−,−), IV (+,−).
distance2D: d = √[(x₂−x₁)² + (y₂−y₁)²] 3D: d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]

Section, mid-point & centroid

section (ratio m:n)x = (mx₂ + nx₁)/(m+n) · y = (my₂ + ny₁)/(m+n)
mid-point (1:1) & centroidM = ( (x₁+x₂)/2 , (y₁+y₂)/2 ) · G = ( (x₁+x₂+x₃)/3 , (y₁+y₂+y₃)/3 )
Mid-point is section with m = n = 1
The mid-point simply divides AB in ratio 1:1, so putting m = n = 1 into the section formula gives ( (x₁+x₂)/2 , (y₁+y₂)/2 ). The centroid is the intersection of the three medians and averages all three vertices — a fact used constantly for "find the third vertex" problems.

Slope of a straight line

slope mm = tan θ (θ = angle with +x-axis) · two-point form: m = (y₂−y₁)/(x₂−x₁)
  • m > 0 → angle acute; m < 0 → angle obtuse; m = 0 → line parallel to x-axis; m = ∞ → line ⟂ x-axis (vertical).
⚠ TrapA line parallel to the x-axis has slope 0; a vertical line has slope ∞ / not defined — do not swap them.

Equations of a straight line

four standard formsPoint-slope: (y − y₁) = m(x − x₁) Two-point: (y − y₁)/(x − x₁) = (y₂ − y₁)/(x₂ − x₁) Slope-intercept: y = mx + c Intercept: x/a + y/b = 1
💡 TipFrom ax + by = c, solve for y to read off slope and y-intercept: e.g. 3x + 4y = 5 ⇒ y = −(3/4)x + 5/4, so m = −3/4, c = 5/4.

Circle, Parabola, Ellipse, Pascal's Triangle & Binomial

Circle

circleCentre (0,0): x² + y² = R² · Centre (h,k): (x−h)² + (y−k)² = R² Area = πR² · Circumference = 2πR

Parabola

  • A parabola is the locus of a point equidistant from a fixed focus and a fixed line (the directrix): PS = PM.
EquationOpensFocusDirectrixAxis
y² = 4axright(a, 0)x = −ay = 0
y² = −4axleft(−a, 0)x = ay = 0

parabola with vertex (h,k)(y−k)² = ±4a(x−h) (right/left) · (x−h)² = ±4a(y−k) (up/down)

Ellipse

  • Sum of distances from the two foci is constant: F₁P + F₂P = constant = 2a. Major axis = 2a, minor axis = 2b.
ellipsex²/a² + y²/b² = 1 · Area = πab · Circumference ≈ π√[2(a²+b²)]
★ a = b ⇒ circleA circle is the special case of an ellipse with equal semi-axes (a = b = R).

Pascal's triangle & binomial expansion

Pascal rows give (a+b)ⁿ coefficients(a+b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴ (coeffs 1 4 6 4 1)
binomial series (|x| < 1)(1+x)ⁿ = 1 + nx + n(n−1)x²/2! + n(n−1)(n−2)x³/3! + … For |x| ≪ 1: (1+x)ⁿ ≈ 1 + nx
Why (1+x)ⁿ ≈ 1 + nx is everywhere in physics
When x is tiny, x², x³, … are negligible, so only the first two terms of the binomial series survive. This linearises awkward roots and reciprocals — e.g. √11 = √(9+2) = 3√(1 + 2/9) ≈ 3(1 + ½·2/9) = 3(1 + 1/9) ≈ 3.34. To use it you must first factor out so the bracket reads (1 + small).
