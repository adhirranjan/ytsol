1(Level-1) Write the velocity constraint: string over a ceiling pulley to two blocks moving with v₁ (angle α) and v₂ (angle β). (a) v₁cosα = v₂cosβ (b) v₁sinα = v₂sinβ (c) v₁tanα = v₂tanβ (d) v₁/cosα = v₂/cosβVelocity constraint (angled strings)Pulley & wedge constraints (constrained motion)🟡 Similarav₁cosα = v₂cosβ
Concept A string that cannot stretch has a fixed length. Whatever a block at its end does, the string can only be paid out or drawn in along its own direction. So the only part of a block's velocity the string "feels" is the component along the string; the perpendicular component merely swings the string round and changes no length. Here one string runs over a ceiling pulley down to two blocks that slide horizontally, its two halves making angles α and β with the horizontal. Because the total length is constant, whatever length one half gains the other must lose — so the two along-string components must be equal.
Formula valong string = v cosθ — the component of a block's velocity v (m s⁻¹) resolved onto the string, where θ is the angle between the velocity and the string. Resolving a vector onto a direction is a dot product, which brings in the cosine of the included angle. Inextensibility then gives v₁ cosα = v₂ cosβ, with units m s⁻¹ on both sides.
Solution
1. Both blocks slide horizontally, and the string halves leave them at α and β to the horizontal.So the angle between each block's velocity and its own string is exactly that same angle — α for block 1, β for block 2.
2. Resolve block 1's velocity onto its string: component = v₁ cosα (m s⁻¹).This is the rate at which block 1 feeds string toward the pulley.
3. Resolve block 2's velocity onto its string: component = v₂ cosβ (m s⁻¹).
4. Apply inextensibility: L = (half 1) + (half 2) = constant, so dL/dt = 0 ⇒ v₁ cosα − v₂ cosβ = 0.One half can only grow at exactly the rate the other shrinks — there is no spare string anywhere.
5. Therefore v₁ cosα = v₂ cosβ — option (a). Dimension check: (m s⁻¹) × (pure number) = m s⁻¹ on both sides ✓

2(Level-2) A block m₁ resting on a smooth table is connected to a mass m₂ through a light pulley. Find the tension in the string.Tension: table + hanging massBlock A of mass m₁ on a table, string over a pulley to m₂🟢 Exactm₁m₂g/(m₁ + m₂)
Concept One light inextensible string over a light pulley links the two blocks, so they share a single magnitude of acceleration a and a single tension T. The table is smooth, so m1 is pulled only by T horizontally; the hanging block m2 is pulled down by its weight and up by the same T. The classic trap is to set T = m2g — that would only hold if m2 were in equilibrium, but here it is accelerating, so T is less than m2g.
Formula Newton's 2nd law ΣF = ma (N = kg·m s⁻²) on each block, giving system acceleration a = m2g/(m1+m2) and T = m1a. Because m1 is the only mass T has to accelerate, T = m1a is the quickest route to tension.
Solution
1. Block on table (horizontal): T = m1a.Smooth table ⇒ no friction; weight and normal cancel vertically.
2. Hanging block: m2g − T = m2a  ⇒  m2g − T = m2a.
3. Add the two equations to cancel T: m2g = (m1+m2)a  ⇒  a = m2g/(m1+m2).
4. Back-substitute: T = m1a = m1m2g/(m1+m2).
5. Sanity limits: if m2 → ∞, T → m1g (m1 is dragged in free fall); if m1 → ∞, T → m2g (m2 nearly static). Both make sense ✓

   T = m1 m2 g /(m1+m2)     <-- answer
⚡ JEE Trick Use the reduced mass μ = m1m2/(m1+m2): the tension in any such two-body string is simply T = μg. Trap: never write T = m2g for a moving hanging block — the string is always slacker than the free weight, T < m2g.
Answer: T = m1m2g/(m1+m2).
3(Level-3) Friction and pulley mass negligible. Find acceleration of m₂ if m₁ = 300 g, m₂ = 500 g and F = 1.50 N (F pulls m₂ horizontally).Pulley + applied forcePulley problem — acceleration & tension🟡 Similar(1.5/1.7) m/s² ≈ 0.88 m/s²
Concept Read the printed figure carefully: the string is tied to the wall, runs right to a pulley, and comes back to block m₁. That pulley is not fixed — it is carried by m₂, which F drags to the right. So this is a movable-pulley problem in disguise: m₂ has two strands wrapped round its pulley, so it feels 2T, while m₁ is tied to a single strand and feels only T — and in exchange m₁ must move twice as far and twice as fast as m₂. Getting that factor of 2 right in both the force and the constraint is the whole problem.
Formula Newton's second law ΣF = ma (N = kg × m s⁻²) on each body, plus the movable-pulley constraint a₁ = 2a₂ (m s⁻²). Two strands tie the pulley back toward the wall, so the pulley advances only half as fast as the free end m₁ is tied to. A massless pulley ⇒ both strands carry the same T and together pull it back with 2T. The table is frictionless and horizontal, so gravity does no work here.
Solution
1. Convert to SI: m₁ = 300 g = 0.300 kg, m₂ = 500 g = 0.500 kg, F = 1.50 N.Never mix grams with newtons — N = kg m s⁻² demands kilograms.
2. Constraint. Put the wall at x = 0, the pulley at p, block m₁ at q. String length L = p + (p − q) = 2p − q = constant.One strand runs wall→pulley (length p), the other pulley→m₁ (length p − q).
3. Differentiate twice with respect to time: 2ap − a₁ = 0, and the pulley rides on m₂ so ap = a₂ ⇒ a₁ = 2a₂ (m s⁻²).
4. Block m₁ (smooth table, only T acts horizontally): T = m₁a₁ = m₁(2a₂) = 0.300 × 2a₂ = 0.600 a₂ N.
5. Block m₂ with its pulley: F drives it right, the two strands drag back with 2T ⇒ F − 2T = m₂a₂.
6. Substitute T from step 4: 1.50 − 2(0.600 a₂) = 0.500 a₂ ⇒ 1.50 − 1.200 a₂ = 0.500 a₂.
7. Collect: 1.50 = 1.700 a₂ ⇒ a₂ = 1.50 / 1.70 = 0.88 m s⁻².Equivalently a₂ = F/(m₂ + 4m₁) = 1.50/(0.500 + 1.200) — the 4m₁ is the movable pulley's signature.
8. Cross-checks: a₁ = 2a₂ = 1.76 m s⁻²; T = 0.300 × 1.76 = 0.53 N; and F − 2T = 1.50 − 1.06 = 0.44 N = 0.500 × 0.88 ✓. Units: N/kg = m s⁻² ✓

Concept This is a movable-pulley system (HCV 5-E17). Block A sits on the surface and is attached to the axle of a movable pulley, so two strands pull it ⇒ it feels 2T but advances only half as fast as the hanging block. The hanging block hangs from the single free end, feels T, and moves twice as fast. Getting that factor of two into both force and constraint is the whole game.
Formula ΣF = ma on each body plus the constraint ahang = 2aA. Eliminating T gives aA = g(2mB − mAsinθ)/(mA+4mB), with θ = incline angle (θ=0 on a flat table). The surface block carries 2T, so its mass appears as mA against 4mB once the constraint is folded in.
Solution
1. Constraint: hanging block descends twice as fast ⇒ ahang = 2aA.
2. Surface block A: 2T − mAg sinθ = mAaA (sinθ=0 for the flat table).
3. Hanging block: mBg − T = mB(2aA). Eliminate T ⇒ aA = g(2mB−mAsinθ)/(mA+4mB).
4. (i) table, mA=2, mB=½: aA = g(1−0)/(2+2) = g/4, ahang = g/2.
5. (ii) 30° incline, mB=5/6: aA = g(5/3−1)/(2+10/3) = g(2/3)/(16/3) = g/8, ahang = g/4.

Concept A pulley system is an ideal machine: it cannot create energy, so every bit of force you save is repaid in distance. In the printed figure the two upper pulleys are each tied off to a fixed anchor, while the lower pulley is movable — and it is that one that carries the triangular block m. The string is threaded so two strands rise from the movable pulley (one to each fixed pulley), and the free end is finally turned through the top-right pulley, where F is applied. One massless string means one tension T everywhere, so the block is held by 2T while you pull with only T.
Formula Massless ideal string ⇒ T is the same in every strand (N). Massless movable pulley carrying a load on n strands: nT − mg = ma; on the verge of lifting a = 0, so nT = mg. A pulley that merely redirects a string changes its direction but not its tension, so F = T (N). Assumption: g = 10 m s⁻², pulleys and string massless and frictionless.
Solution
1. Count the strands rising from the movable pulley (the one holding m): one to the left fixed pulley, one to the right fixed pulley ⇒ n = 2.Only strands that wrap the pulley moving with the load share that load; the anchors merely hold the fixed pulleys still.
2. One continuous massless string on frictionless pulleys ⇒ every strand carries the same tension T (N).
3. The top-right pulley only turns the string so you can pull horizontally ⇒ F = T. It supplies no mechanical advantage.
4. Weight of the block: mg = 10 kg × 10 m s⁻² = 100 N.kg × m s⁻² = N ✓
5. Condition to just lift it (a = 0): 2T = mg ⇒ 2T = 100 N ⇒ T = 50 N.
6. Since F = T: F = 50 N. Any F greater than 50 N gives the block an upward acceleration.
7. Energy cross-check: raising m by 1 m needs 2 m of string pulled, so work in = 50 N × 2 m = 100 J, and work out = 100 N × 1 m = 100 J ✓Force halved, distance doubled — energy conserved, exactly as an ideal machine demands.

1A 35 kg block rests on a rough table (self-adjusting resistive force = 10% of the block's weight). A 20 kg wt load hangs on the left; on the right a 2 kg wt pan. 1 kg wt weights are added to the pan. Find the minimum and maximum number of weights so the block does not slide.Friction range for no slidingFriction on a table — tensions in two strings (HCV 6-E4)🟡 Similar—
Concept The block is asked to stay at rest, so this is a statics problem with a twist: the resistive force is self-adjusting. It is not a fixed 3.5 kg wt push — it takes whatever value (up to its ceiling) is needed to balance the block, and only when the demand exceeds that ceiling does the block slide. So the answer is not a single number but a range: the pan load may be light enough that the 20 kg side almost wins, or heavy enough that the pan side almost wins, and friction covers the mismatch in between.
Formula Because every load hangs freely and nothing moves, each string simply carries the weight hung on it: Tleft = 20 kg wt, Tright = (2 + n) kg wt where n = number of 1 kg wt weights. Block equilibrium along the table: |Tleft − Tright| ≤ fmax, with fmax = 10% of the block's weight = 0.10 × 35 = 3.5 kg wt. Working in "kg wt" throughout is legitimate here because g cancels from every term — it is a common unit on both sides.
Solution
1. Maximum resistive force the table can supply: fmax = 0.10 × 35 kg wt = 3.5 kg wt.The problem states it is 10% of the block's weight — the hanging loads do not press on the table, so they do not change it.
2. Pull to the left on the block: 20 kg wt (the freely hanging load).
3. Pull to the right on the block: pan + weights = (2 + n) kg wt.
4. Net unbalanced pull that friction must cancel: |20 − (2 + n)| = |18 − n| kg wt.
5. No sliding requires this to be within friction's ceiling: |18 − n| ≤ 3.5.
6. Unfold the modulus: −3.5 ≤ 18 − n ≤ 3.5 ⇒ 14.5 ≤ n ≤ 21.5.
7. n must be a whole number of 1 kg wt weights, so round inward: nmin = 15, nmax = 21.n = 14 leaves an unbalanced 4 kg wt > 3.5, so the block slides left; n = 22 leaves 4 kg wt the other way and it slides right.
8. Check the two edges: n = 15 ⇒ |18 − 15| = 3.0 ≤ 3.5 ✓; n = 21 ⇒ |18 − 21| = 3.0 ≤ 3.5 ✓

1What is the main purpose of constraint equations in pulley systems? (a) calculate mass (b) find distance (c) relate velocities & accelerations of blocks (d) calculate energyPurpose of constraint equationsComplete constraint motion — string, pulley & wedge🟡 SimilarcTo relate velocities and accelerations of blocks
Concept When blocks are tied by an inextensible string, they are no longer free to move independently — the string's fixed length silently forbids most motions. Newton's second law alone cannot see this: it gives you one equation per body but leaves you with an extra unknown acceleration for each one. The constraint equation is the missing relation that geometry (not force) supplies, linking those accelerations so the equations finally close. Without it a two-block pulley problem has 3 unknowns (a₁, a₂, T) but only 2 force equations — unsolvable.
Key relation length of string = constant (m). Differentiate once with respect to time to relate velocities (m s⁻¹): Σ (±vi) = 0; differentiate again to relate accelerations (m s⁻²): Σ (±ai) = 0. A constraint is pure geometry — it involves no masses and no forces, only how the string is threaded.
Solution
1. Count the unknowns in a simple two-block pulley system: a₁, a₂ and T ⇒ 3 unknowns.
2. Count the equations Newton's second law supplies: one per block ⇒ 2 equations. The system is underdetermined.2 equations can never pin down 3 unknowns — something non-dynamical is missing.
3. The string supplies the third: its length is fixed, so the blocks' displacements are locked together. Differentiating that length relation twice yields a relation between a₁ and a₂.
4. That is precisely what the options describe as "relating velocities and accelerations of blocks" — option (c).
5. Rule out the rest by asking what a constraint equation contains: it has no mass term, so it cannot give mass (a); it gives a relation, not an absolute distance (b); and it carries no force or energy term (d).A constraint is geometry, so it can only ever speak about displacement, velocity and acceleration.
   two blocks over a pulley
   ------------------------------------------------
   unknowns          : a1 , a2 , T          -> 3
   Newton's 2nd law  : one per block        -> 2   (not enough!)
   constraint (geom) : a1 related to a2     -> 1
                                              ---
                                    total     3 = 3  solvable
⚡ JEE Trick Remember the division of labour: Newton's laws give forces, constraints give geometry — you always need both. Fast audit for any pulley problem: if unknowns outnumber force equations, the shortfall is exactly the number of inextensible strings, and each one hands you one constraint equation. Trap: constraint equations never contain m or F, so any option mentioning mass or energy is wrong on sight.

2In a pulley system, what is assumed about the mass of pulleys and strings? (a) very heavy (b) only pulleys massless (c) only strings massless (d) both masslessMassless pulley/string assumptionComplete constraint motion — string, pulley & wedge🟡 SimilardBoth are massless
Concept The standard idealisation in this whole chapter is that both the pulleys and the strings are massless. Each assumption buys one specific simplification. A massless string has the same tension at every point: if a segment of string had mass ms and acceleration a, the tensions at its two ends would have to differ by msa — set ms = 0 and that difference vanishes. A massless pulley has zero moment of inertia, so no net torque is needed to spin it up, which means the tension is the same on both sides of the pulley. Together they give the single most-used fact in pulley problems: one string, one tension.
Key relation Massless string: T₂ − T₁ = msa = 0 ⇒ T₁ = T₂ (N). Massless pulley: (T₁ − T₂)R = Iα = 0 ⇒ T₁ = T₂, since I = 0 for a massless pulley (kg m²). Both statements are just ΣF = ma and Στ = Iα applied to an object whose mass — and hence inertia — is zero.
Solution
1. Apply ΣF = ma to a small element of string of mass ms: T₂ − T₁ = msa (N).
2. Set ms = 0 ⇒ T₂ = T₁: tension is uniform along the string.This is why we can write a single symbol T for a whole string.
3. Apply Στ = Iα to the pulley: (T₁ − T₂)R = Iα (N m).
4. A massless pulley has I = 0 ⇒ T₁ = T₂: tension is the same across the pulley.With no rotational inertia, no torque — and hence no tension difference — is needed to angularly accelerate it.
5. Both idealisations are needed for the usual "one string ⇒ one T" shortcut, so the assumption is that both are massless — option (d).
   assumption          what it buys                      if violated
   ------------------------------------------------------------------
   massless string     same T all along the string       T varies with height
   massless pulley     same T on both sides (I = 0)      T_left != T_right
   both massless (d)   ONE tension for the whole string  <-- what we use
⚡ JEE Trick "Light", "ideal" and "massless" are all the same instruction: use one T for the entire string. The moment a problem says "pulley of mass m" or "rotating pulley of moment of inertia I", that licence is revoked — the two sides then carry different tensions and you must add the torque equation (T₁ − T₂)R = Iα. Trap: options (b) and (c) each grant only half the idealisation, which is not enough for uniform tension.
Answer: (d) Both are massless

4If the displacement relation between blocks is given, the analogous acceleration relation is obtained by (a) double derivating (b) single derivating (c) same as displacement (d) cannot be obtainedDisplacement → accelerationAcceleration constraint — pulley formula🟡 Similarcsame as the displacement relation ⚠
Concept Displacement, velocity and acceleration are linked by differentiation with respect to time: velocity is the first derivative of displacement, and acceleration is the derivative of velocity — hence the second derivative of displacement. So to convert a constraint written in displacements into one written in accelerations you differentiate twice. The lovely feature of string constraints is that they are linear with constant coefficients, so differentiating changes nothing except the symbols: the very same numbers reappear in front of the accelerations.
Key relation v = dx/dt (m s⁻¹) and a = dv/dt = d²x/dt² (m s⁻²). Applied to a constraint Σ cixi = constant (m), one differentiation gives Σ civi = 0 and a second gives Σ ciai = 0. The ci are fixed integers set by how the string is threaded, so they survive both derivatives untouched; the constant on the right differentiates to zero.
Solution
1. Start from the displacement constraint, e.g. 2x₁ − x₂ = constant (m).
2. Differentiate once with respect to t: 2v₁ − v₂ = 0 (m s⁻¹) — this is only the velocity relation, one step short.The constant on the right side has zero derivative, which is why these relations equal 0.
3. Differentiate a second time: 2a₁ − a₂ = 0 (m s⁻²) — now it is the acceleration relation.
4. So the acceleration relation is reached by double differentiation of the displacement relation — option (a).
5. Note the coefficients (2 and −1) never changed.They are pure geometry, fixed by the threading of the string, so they cannot depend on time.
6. Rule out the others: single differentiation (b) stops at velocity; "same as displacement" (c) confuses a relation among values with a relation among units — the coefficients match but the quantities do not; and (d) is plainly false.

Concept Two ideas must be combined here, and each is worth a factor. Second, that string reaches block B at an angle, and only the component of B's velocity along the string can feed it. Formula Movable pulley: vstring = 2vA (m s⁻¹). Angled end: vB cosθ = vstring ⇒ vB = 2vA/cosθ (m s⁻¹), where θ is the angle between B's velocity and the string.
