1What is the derivative of tan(x)? (sec²x) — (Level-1)Derivative of tan xProof: d/dx tan(x) = sec²(x) — Corbettmaths · Derivative of tan x (proof)🟢 Exactbsec²(x) ⚠
Concept The tangent is a ratio of the two basic trig functions, tan x = sin x / cos x, so its derivative is not a new rule at all — it drops straight out of the quotient rule. The result sec²x is never less than 1, which tells you tan x always rises at least as steeply as a 45° line and shoots to infinity as x → π/2, exactly where cos x → 0. A subtle feature of THIS question: the identity 1 + tan²x ≡ sec²x makes two of the printed options the same function.
Formula Quotient rule (u/v)′ = (v·u′ − u·v′)/v², with d/dx(sin x) = cos x and d/dx(cos x) = −sin x. Both trig derivatives are valid only when x is measured in radians. The Pythagorean identity sin²x + cos²x = 1 and sec x = 1/cos x collapse the answer to one term.
Solution
1. Write tan x as a quotient: u = sin x, v = cos x.
2. Differentiate each piece: u′ = cos x, v′ = −sin x.The minus sign on v′ is what later builds the +sin²x term.
3. Apply the rule: d/dx(tan x) = [cos x·cos x − sin x·(−sin x)]/cos²x = (cos²x + sin²x)/cos²x.
4. Use sin²x + cos²x = 1 in the numerator: = 1/cos²x = sec²x.
5. Split the same fraction the other way: (cos²x + sin²x)/cos²x = 1 + tan²x, so sec²x = 1 + tan²x — options (b) and (d) are one and the same.

             = 1 + sin²x/cos²x  = 1 + tan²x   (option d, identical)
 check x = 0:  sec²0 = 1   (tan x has slope 1 at the origin)
⚡ JEE Trick Memorise the pair d/dx(tan x) = sec²x and d/dx(cot x) = −cosec²x outright rather than re-deriving under time pressure. The named trap on THIS question is the double-correct option set: (b) sec²x and (d) 1 + tan²x are the identical function, so a student who knows only one form may wrongly reject the other. Both are valid.
Answer: (b) d/dx(tan x) = sec²x. ⚠ Option (d) 1 + tan²x is the identical function (1 + tan²x ≡ sec²x) — the printed option set offers two equally correct answers.
2d/dx (sin x) at x = π/2 is? (0) — (Level-2)Trig derivative at a pointDerivative of sin x at x = π/2🟢 Exacta0
Concept "Derivative at a point" means: first find the slope function, then substitute the number — never the other way round. The slope of sin x is cos x, and at x = π/2 the sine curve is sitting on its crest (its maximum value 1), where the tangent line is perfectly horizontal. A horizontal tangent means zero slope, so the answer must be 0. In physics this is the SHM fact that a particle at maximum displacement has zero velocity.
Formula d/dx(sin x) = cos x, valid in radian measure. This rests on lim(h→0) sin h/h = 1, which only holds when h is in radians. Then evaluate the slope function at the point: cos(π/2). π/2 rad = 90°, the angle where cosine crosses zero.
Solution
1. Differentiate first: y = sin x ⇒ dy/dx = cos x.Get the whole slope function before touching the number.
2. Substitute the point last: dy/dx at x = π/2 equals cos(π/2).
3. Evaluate: cos(π/2) = cos 90° = 0.
4. Interpret geometrically: at x = π/2 the sine curve reaches its peak value 1, so its tangent is flat — slope 0, confirming the algebra.

⚡ JEE Trick Read a "derivative at a point" as differentiate first, plug in last. Shortcut: the slope of sin x is zero wherever sin x is at a max or min (x = π/2, 3π/2, …) and ±1 wherever sin x crosses zero. Trap: substituting x = π/2 into sin x first gives 1, a constant, whose derivative is 0 for the wrong reason — you would get the right number by a completely invalid route and lose it on a harder variant.
Answer: (a) d/dx(sin x) at x = π/2 = cos(π/2) = 0.
3y = ln(2x), find dy/dx at x = 1 (1) — (Level-3)Log + chain ruleDerivative of ln(2x) with chain rule🟢 Exact (evaluate at x = 1)a1
Concept A constant multiplier inside a logarithm has no effect on its derivative — d/dx of ln(2x) is the same 1/x as d/dx of ln x. The cleanest way to see this is the log law ln(2x) = ln 2 + ln x: the ln 2 is just a number, and a number has zero slope, so only the ln x survives. The chain rule gives the same result and is worth practising here as a warm-up for genuinely nested logs.
Formula d/dx(ln x) = 1/x for x > 0, and the chain rule d/dx(ln u) = (1/u)·(du/dx). Here u = 2x, so du/dx = 2, and the 2's cancel. Log law used: ln(ab) = ln a + ln b. Turns a product inside the log into a sum, separating the constant.
Solution
1. Method A (log law): ln(2x) = ln 2 + ln x. Differentiate: d/dx = 0 + 1/x = 1/x.ln 2 is a constant, slope 0; the coefficient 2 simply vanishes.
2. Method B (chain rule): with u = 2x, d/dx(ln 2x) = (1/2x)·2 = 1/x — the 2 on top cancels the 2 on the bottom.
3. Both routes give the slope function 1/x. Now substitute the point x = 1: dy/dx = 1/1 = 1.
4. Interpretation: at x = 1 the curve y = ln(2x) rises at 45°, a slope of exactly 1.
 route A:  ln 2x = ln 2 + ln x  ->  d/dx = 0 + 1/x = 1/x
 route B:  d/dx ln 2x = (1/2x)(2) = 1/x
 at x = 1:  1/x = 1/1 = 1                      <- answer
 note: ln 2x differs from ln x by a constant, so SAME slope everywhere.
⚡ JEE Trick For any constant k, d/dx ln(kx) = 1/x — the k is invisible to differentiation. More generally d/dx ln(f(x)) = f′(x)/f(x) (the "logarithmic derivative"). Trap: writing d/dx ln(2x) = 1/(2x) by forgetting the chain-rule factor 2 — that would wrongly give ½ at x = 1 instead of 1.
Answer: (a) dy/dx = 1/x, so at x = 1 the derivative equals 1.
4If y = sinx + 8cosx + 2tanx, then dy/dx? (cosx − 8sinx + 2sec²x) — (Level-4)Sum rule with trigTrig derivatives — product, quotient & chain · Sum, product and quotient rules🟡 Similarccosx − 8sinx + 2sec²x
Concept Differentiation is a linear operation: the derivative of a sum is the sum of the derivatives, and any constant multiplier simply rides along untouched. That means a three-term expression like this is never one hard problem — it is three easy standard derivatives added back together. The only knowledge actually needed is the standard trig derivative table; the sum and constant-multiple rules do the rest of the assembly.
Formula Linearity: d/dx [a·f(x) + b·g(x)] = a·f′(x) + b·g′(x) for constants a, b. Constants scale a function vertically, so they scale its slope by the same factor; sums stack independently, so their slopes add. Standard table: d/dx (sin x) = cos x, d/dx (cos x) = −sin x, d/dx (tan x) = sec²x. x here is an angle in radians — these formulas are only valid in radian measure, since they rest on lim(h→0) sin h/h = 1.
Solution
1. Split the function by the sum rule: y = sin x + 8 cos x + 2 tan x, so dy/dx = d/dx(sin x) + d/dx(8 cos x) + d/dx(2 tan x).Each term is differentiated on its own; no product or chain rule is involved because the terms are added, not multiplied.
2. First term: d/dx (sin x) = cos x.Straight from the standard table.
3. Second term: pull the constant 8 out, then differentiate — d/dx (8 cos x) = 8 · d/dx(cos x) = 8 · (−sin x) = −8 sin x.The minus sign comes from the derivative of cos, and is the single most-missed sign in this problem.
4. Third term: pull the constant 2 out — d/dx (2 tan x) = 2 · d/dx(tan x) = 2 · sec²x = 2 sec²x.
5. Add the three results back together: dy/dx = cos x − 8 sin x + 2 sec²x.
 term        y-part      derivative        contribution
 1st         sin x       cos x             + cos x
 2nd         8 cos x     8·(−sin x)        − 8 sin x
 3rd         2 tan x     2·(sec²x)         + 2 sec²x
                                           ─────────────────────────
 dy/dx  =  cos x − 8 sin x + 2 sec²x
6. Sanity check at x = 0: dy/dx = cos 0 − 8 sin 0 + 2 sec²0 = 1 − 0 + 2 = 3.Finite and well defined, as expected — tan x and sec x only blow up at x = π/2, not at 0.
⚡ JEE Trick Treat every "+" as a wall: differentiate each term in isolation and never let a rule leak across it. Memorise the sign pattern of the trig table as "co- functions carry the minus" — cos, cot and cosec all differentiate to something negative, while sin, tan and sec stay positive. Trap: dropping the minus on 8 cos x (writing +8 sin x) — this single sign error is the most common way to lose the mark here.
Answer: dy/dx = cos x − 8 sin x + 2 sec²x.
5Differentiate by Quotient Rule: (i) (x²+1)/(x+1) (ii) (2x−1)/(x²+1) — (Level-5)Quotient ruleDerivative of (x²−2)/(2x+1) · Derivative of (x²+1)/(x²−1)🟡 Similar(i) (x² + 2x − 1)/(x+1)² · (ii) 2[(−x² + x + 1)/(x² + 1)²]
Concept When one function is divided by another, the slope depends on how both the numerator and the denominator are changing at once — if the bottom grows, the fraction shrinks even when the top is constant. The quotient rule packages that competition into one formula. The order of the two terms in its numerator matters (unlike the product rule), because subtraction is not commutative, so the mnemonic must be memorised in the right direction.
Formula For y = u/v: dy/dx = (v·u′ − u·v′) / v², valid wherever v ≠ 0. Mnemonic "low·d-high minus high·d-low, over low squared" — the denominator's own derivative enters with a MINUS sign, and the whole thing is divided by v², never by v. Power rule used throughout: d/dx (xⁿ) = n·xⁿ⁻¹, and d/dx (constant) = 0.
Solution — part (i): y = (x²+1)/(x+1)
1. Identify the pieces: u = x² + 1 and v = x + 1.
2. Differentiate each separately: u′ = d/dx(x²+1) = 2x + 0 = 2x; v′ = d/dx(x+1) = 1 + 0 = 1.The constants 1 differentiate to 0 — a constant has zero slope.
3. Substitute into the rule: dy/dx = [ (x+1)·(2x) − (x²+1)·(1) ] / (x+1)².
4. Expand the numerator: (x+1)(2x) = 2x² + 2x, so numerator = 2x² + 2x − x² − 1.Distribute the minus sign across the whole of (x²+1) — forgetting this on the "+1" is the classic slip.
5. Collect like terms: 2x² − x² = x², leaving numerator = x² + 2x − 1.
6. Result: dy/dx = (x² + 2x − 1)/(x+1)², valid for x ≠ −1.
Solution — part (ii): y = (2x−1)/(x²+1)
7. Identify: u = 2x − 1 and v = x² + 1.
8. Differentiate: u′ = 2; v′ = 2x.
9. Substitute: dy/dx = [ (x²+1)·(2) − (2x−1)·(2x) ] / (x²+1)².
10. Expand: (x²+1)(2) = 2x² + 2; (2x−1)(2x) = 4x² − 2x. Numerator = 2x² + 2 − (4x² − 2x) = 2x² + 2 − 4x² + 2x.Both signs inside the bracket flip: −4x² and +2x.
11. Collect: 2x² − 4x² = −2x², giving numerator = −2x² + 2x + 2.
12. Result: dy/dx = (−2x² + 2x + 2)/(x²+1)² = −2(x² − x − 1)/(x²+1)², valid for all real x since x²+1 is never 0.
 part   u        v        u′    v′     (v·u′ − u·v′)                 dy/dx
 (i)    x²+1     x+1      2x    1      2x²+2x − (x²+1) = x²+2x−1     (x²+2x−1)/(x+1)²
 (ii)   2x−1     x²+1     2     2x     2x²+2 − (4x²−2x) = −2x²+2x+2  (−2x²+2x+2)/(x²+1)²
13. Check (ii) at x = 0: direct formula gives (−0 + 0 + 2)/(0+1)² = 2. From first principles near 0, y = (2x−1)/(x²+1) ≈ (2x−1)(1−x²) ≈ −1 + 2x, whose slope is 2. ✓
⚡ JEE Trick Before reaching for the quotient rule, check whether the fraction simplifies or splits — e.g. (x²−1)/(x+1) is just x−1, giving derivative 1 in one line. Here (i) does not factor, so the rule is genuinely needed. Also note the denominator of the answer is always v², so you can write it down before touching the numerator. Trap: reversing the numerator to (u·v′ − v·u′) flips the sign of the entire answer — memorise "low d-high FIRST."
Answer: (i) dy/dx = (x² + 2x − 1)/(x + 1)²  ·  (ii) dy/dx = (−2x² + 2x + 2)/(x² + 1)².

1What is the derivative of sin(x)? (cos x)Derivative of sin xProof: d/dx sin(x) = cos(x) by first principles🟢 Exactacos(x)
Concept That d/dx(sin x) = cos x is a result to be proved, not just memorised, and the proof is a classic first-principles limit. The idea: expand sin(x + h) with the addition formula, subtract sin x, divide by h, and let h → 0. Two standard small-angle limits do all the work. The physical meaning is that the rate of change of a sine wave is another wave shifted a quarter-cycle ahead — displacement peaks where velocity is zero.
Formula Definition f′(x) = lim(h→0) [f(x+h) − f(x)]/h; addition formula sin(x+h) = sin x cos h + cos x sin h. Standard limits lim(h→0) sin h/h = 1 and lim(h→0) (cos h − 1)/h = 0. Both hold only for h in radians — the whole result is a radian statement.
Solution
1. Set up the difference quotient: f′ = lim(h→0) [sin(x+h) − sin x]/h.
2. Expand sin(x+h): = lim [sin x cos h + cos x sin h − sin x]/h.
3. Group the sin x terms: = lim [ sin x(cos h − 1) + cos x·sin h ]/h.
4. Split into two limits: = sin x·lim(cos h − 1)/h + cos x·lim(sin h/h).sin x and cos x are constants with respect to h, so they factor out.
5. Insert the standard limits 0 and 1: = sin x·(0) + cos x·(1) = cos x.
 f′ = lim (sin(x+h) - sin x)/h
    = sin x·lim(cos h - 1)/h  +  cos x·lim(sin h/h)
    = sin x·(0)               +  cos x·(1)
    = cos x                                        <- answer
 quarter-cycle shift: slope of sin peaks where sin = 0.
⚡ JEE Trick Lock in the small-angle pair sin h/h → 1 and (cos h − 1)/h → 0; every trig first-principles proof reduces to them. Shortcut sanity check: the derivative of sin is the graph shifted left by π/2, which is exactly cos. Trap: working in degrees — then sin h/h → π/180, not 1, and the whole answer is scaled wrongly; trig derivatives demand radians.
Answer: (a) d/dx(sin x) = cos x.
2What is the second derivative of position function s(t)? (Acceleration)s → v → aPosition, velocity, acceleration using derivatives · Velocity, acceleration & second derivatives🟢 ExactdAcceleration
Concept Position, velocity and acceleration form a derivative ladder. Velocity is how fast position changes, so v = ds/dt is the first derivative. Acceleration is how fast velocity changes, so a = dv/dt — but since v is itself ds/dt, acceleration is the derivative of a derivative, i.e. the second derivative of position. Each differentiation step answers the same question ("rate of change of…") applied to the previous quantity.
Formula v = ds/dt (1st derivative), a = dv/dt = d²s/dt² (2nd derivative). d²s/dt² is shorthand for differentiating s twice with respect to t. Test case s(t) = ut + ½at² gives a constant-acceleration motion. The very kinematics equation whose second derivative returns the constant a.
Solution
1. First derivative of position gives velocity: v = ds/dt.
2. Differentiate velocity to get acceleration: a = dv/dt = d(ds/dt)/dt = d²s/dt².A derivative of a derivative is by definition the second derivative.
3. Concrete check with s(t) = ut + ½at²: v = ds/dt = u + at.
4. Differentiate again: a = dv/dt = 0 + a = a, a constant — the second derivative of s recovers the acceleration.
 quantity        operation          result
 position s(t)   ---                ut + ½at²
 velocity v      ds/dt (1st)        u + at
 accel.   a      d²s/dt² (2nd)      a           <- answer
 so: 2nd derivative of position = acceleration
⚡ JEE Trick Climb the ladder in order — s → v → a — each rung one derivative in time; going the other way (a → v → s) is integration. Extra fact for MCQs: the third derivative of position is called "jerk." Trap: confusing velocity (first derivative) with acceleration (second derivative); the question asks for the second, which is acceleration, not velocity.
Answer: (d) The second derivative of position s(t) is acceleration.
3Which rule provides the derivative of a product of two functions? (Product Rule)Product ruleProduct rule for derivatives — basic introduction🟢 ExactcProduct Rule
Concept When two functions are multiplied, their combined rate of change is not the product of the individual rates — that is the single most common misconception in calculus. The correct tool is the product rule: differentiate the first factor while holding the second, then hold the first while differentiating the second, and add. Each term captures the change contributed by one factor at a time.
Formula Product rule d/dx(u·v) = u′v + uv′. Two terms because either factor can vary while the other is momentarily frozen; you sum both contributions. Contrast the WRONG statement (uv)′ ≠ u′·v′. The product of derivatives misses the cross-effect entirely and fails even simple tests.
Solution
1. Name the rule: the derivative of a product uses the product rule, (uv)′ = u′v + uv′.
2. See why the naive guess fails — test u = v = x, so uv = x²: product rule gives 1·x + x·1 = 2x (correct), but u′·v′ = 1·1 = 1 (wrong).One counterexample is enough to kill the "product of derivatives" idea.
3. Worked example u = x, v = sin x: (x sin x)′ = 1·sin x + x·cos x = sin x + x cos x.
4. Reading the options, the rule for a product of two functions is the Product Rule, choice (c).
 rule            formula              on x·x = x²
 product rule    u′v + uv′            1·x + x·1 = 2x   ✓
 (naive) u′·v′   product of slopes    1·1     = 1      ✗
 so: product of two functions -> PRODUCT RULE       <- answer
⚡ JEE Trick Chant "first times derivative-of-second, plus second times derivative-of-first." For three factors it extends term-by-term: (uvw)′ = u′vw + uv′w + uvw′. Trap: the reflex (uv)′ = u′v′ — always false; verify instantly on x·x = x² where it gives 1 instead of 2x.
Answer: (c) The Product Rule gives the derivative of a product of two functions.
4What is the second derivative of f(x) called? (Second derivative or f″(x))Higher-order derivativesHigher order derivatives · Second derivative: f″(x) = d²y/dx²🟢 ExactdSecond derivative or f″(x)
Concept Differentiating a function once gives a new function; differentiating that again gives the second derivative, written f″(x) or d²y/dx². It measures how the slope itself is changing — the curvature of the graph, and in physics the acceleration of a motion. The little double-prime and the "²" placed on the d's are pure notation for "apply the derivative operation twice," nothing more.
Formula f″(x) = d/dx[ f′(x) ] = d²y/dx². The 2 sits up top on the d and at the bottom on the dx — it is an operator count, not an algebraic power. Sign meaning: f″ > 0 ⇒ concave up, f″ < 0 ⇒ concave down. Curvature is exactly what the second derivative reports.
Solution
1. Differentiate once to get the first derivative f′(x) — the slope function.
2. Differentiate the first derivative again: f″(x) = d/dx[f′(x)] — this is the second derivative, also written d²y/dx².
3. Worked example f(x) = x³: f′(x) = 3x², then f″(x) = 6x.Two successive power-rule steps.
4. Reading the options, the name for this quantity is "second derivative or f″(x)," choice (d).
 f(x)   = x³
 f′(x)  = 3x²        (1st derivative  = slope)
 f″(x)  = 6x         (2nd derivative  = curvature)   <- answer
 notation: f″(x)  ==  d²y/dx²
⚡ JEE Trick Count the primes: f′ is first, f″ second, f‴ third; equivalently the exponent on d in d^n y/dx^n. Physics hook: x(t) → f′ velocity → f″ acceleration. Trap: reading d²y/dx² as (dy/dx)² — it is NOT the square of the first derivative but a second differentiation; for f = x³ the two give 6x versus 9x⁴, wildly different.
Answer: (d) It is called the second derivative, written f″(x) or d²y/dx².

1Find d/dx of x² using power rule (2x)Power ruleDifferentiation rules — power, product, quotient, chain · The power rule for derivatives🟢 Exactb2x
Concept The power rule is the workhorse of differentiation: bring the exponent down as a multiplier and drop it by one. For x² it gives 2x, meaning the parabola's slope grows linearly — flat at the origin, steeper as you move out. It is worth seeing once that this is not magic but a first-principles limit: expand (x+h)², cancel, and let h → 0.
Formula Power rule d/dx(xⁿ) = n·xⁿ⁻¹. The exponent becomes the coefficient and then decreases by 1. First-principles definition f′(x) = lim(h→0)[(x+h)² − x²]/h and the expansion (x+h)² = x² + 2xh + h². The x² terms cancel, leaving a factor of h to divide out.
Solution
1. Power rule directly: with n = 2, d/dx(x²) = 2·x²⁻¹ = 2·x¹ = 2x.
2. Confirm from first principles — set up f′ = lim(h→0)[(x+h)² − x²]/h.
3. Expand and cancel: (x+h)² − x² = x² + 2xh + h² − x² = 2xh + h².The x² pieces cancel, which is why a lone h can be factored next.
4. Divide by h: (2xh + h²)/h = 2x + h.
5. Let h → 0: 2x + h → 2x, matching the power rule exactly.
 power rule:  x²  ->  2·x^(2-1) = 2x            <- answer

   ((x+h)² - x²)/h = (2xh + h²)/h = 2x + h  --(h->0)-->  2x
 slope check:  at x=1 slope=2,  at x=3 slope=6
⚡ JEE Trick "Drop and reduce": exponent to the front, then subtract 1. Works for every real power — d/dx(x^½) = ½x^(−½), d/dx(x⁻¹) = −x⁻². Trap: forgetting to reduce the exponent and writing 2x² instead of 2x, or applying the rule to a constant base (2ˣ), where the power rule does not apply at all.
Answer: (b) d/dx(x²) = 2x.
2Find derivative of log(x) at x = 1 (1)Derivative of log xProof: d/dx ln(x) = 1/x — Khan Academy🟡 Similar (evaluate at x = 1)c1
Concept The natural logarithm grows ever more slowly as x increases, and its derivative 1/x captures exactly that: the slope is large for small x and fades toward zero for large x. In physics notation "log" in a differentiation problem almost always means the natural log (base e), because only ln has the clean derivative 1/x. Concept Attacking this head-on with the product rule works but is punishing. The intended insight is that tan x + cot x simplifies dramatically: it equals 1/(sin x·cos x). Once that is seen, the whole product collapses to sec x + cosec x, and the derivative becomes two standard results. Formula Identity: tan x + cot x = sin x/cos x + cos x/sin x = (sin²x + cos²x)/(sin x·cos x) = 1/(sin x·cos x), using sin²x + cos²x = 1. Standard derivatives: d/dx (sec x) = sec x·tan x and d/dx (cosec x) = −cosec x·cot x. Again the co-function carries the minus. Solution
1. Simplify the second bracket over a common denominator: tan x + cot x = (sin²x + cos²x)/(sin x·cos x).
2. Apply the Pythagorean identity — the numerator is exactly 1: tan x + cot x = 1/(sin x·cos x).
3. Multiply by the first bracket: y = (sin x + cos x) · 1/(sin x·cos x) = (sin x + cos x)/(sin x·cos x).
4. Split the single fraction into two: = sin x/(sin x·cos x) + cos x/(sin x·cos x) = 1/cos x + 1/sin x.In the first fraction sin x cancels; in the second cos x cancels.
5. So y simplifies all the way down to y = sec x + cosec x — no product rule needed at all.
6. Differentiate using the standard table: dy/dx = sec x·tan x − cosec x·cot x.
7. Substitute x = π/4. Evaluate each piece: sin(π/4) = cos(π/4) = 1/√2, so sec(π/4) = √2, cosec(π/4) = √2, tan(π/4) = 1, cot(π/4) = 1.
8. Compute: dy/dx = (√2)(1) − (√2)(1) = √2 − √2 = 0.

Concept A ratio of two linear functions — a Möbius (bilinear) function. These have a special and very useful property: the x-terms in the quotient-rule numerator always cancel, leaving a bare constant on top. So the derivative of any (ax+b)/(cx+d) is simply (ad − bc)/(cx+d)², whose sign never changes. Recognising this saves the whole expansion and makes such problems near-instant.
Formula Quotient rule: d/dx (u/v) = (v·u′ − u·v′)/v². General Möbius result: d/dx [(ax+b)/(cx+d)] = (ad − bc)/(cx+d)². Since the numerator ad − bc is a constant, the derivative's sign is fixed for all x — the function is monotonic on each side of its vertical asymptote. Here a = 3, b = 4, c = 4, d = 5. Domain: x ≠ −5/4 (asymptote).
Solution
1. Identify the parts: u = 3x + 4 and v = 4x + 5.
2. Differentiate each: u′ = 3 and v′ = 4.Both are linear, so their derivatives are just the coefficients of x.
3. Apply the quotient rule: dy/dx = [ (4x+5)(3) − (3x+4)(4) ] / (4x+5)².
4. Expand the first product: (4x+5)(3) = 12x + 15.
5. Expand the second product: (3x+4)(4) = 12x + 16.
6. Subtract, distributing the minus across both terms: (12x + 15) − (12x + 16) = 12x + 15 − 12x − 16 = −1.The 12x terms cancel exactly — the hallmark of a Möbius function. Cross-check with ad − bc = (3)(5) − (4)(4) = 15 − 16 = −1. ✓
7. So the general derivative is dy/dx = −1/(4x+5)².
8. Substitute x = −1 into the denominator first: 4x + 5 = 4(−1) + 5 = −4 + 5 = 1.
9. Square it: (1)² = 1.
10. Finish: dy/dx |ₓ₌₋₁ = −1/1 = −1.

Concept A quadratic over a linear function — the numerator and denominator cannot be cancelled (2x+3 is not a factor of x²+1), so the quotient rule is genuinely required. Unlike the linear-over-linear case, here the x² terms do not fully cancel, and the result stays quadratic on top. The care needed is in expanding both products and then distributing the subtraction across every term of the second one.
Formula Quotient rule: dy/dx = (v·u′ − u·v′)/v², "low d-high minus high d-low, all over low squared." The order matters: the denominator's derivative always enters with the minus sign. Power rule: d/dx(xⁿ) = n·xⁿ⁻¹; constants differentiate to 0. Domain: x ≠ −3/2, where the denominator vanishes.
Solution
1. Identify the parts: u = x² + 1 and v = 2x + 3.
2. Differentiate each: u′ = d/dx(x² + 1) = 2x + 0 = 2x; v′ = d/dx(2x + 3) = 2 + 0 = 2.
3. Substitute into the rule: dy/dx = [ (2x+3)(2x) − (x²+1)(2) ] / (2x+3)².
4. Expand the first product: (2x+3)(2x) = 4x² + 6x.Distribute 2x over both terms.
5. Expand the second product: (x²+1)(2) = 2x² + 2.
6. Subtract, flipping both signs inside the bracket: (4x² + 6x) − (2x² + 2) = 4x² + 6x − 2x² − 2.The minus applies to the whole of 2x² + 2, not just the first term — the classic slip.
7. Collect like terms: 4x² − 2x² = 2x², leaving numerator = 2x² + 6x − 2.
8. Write the result, optionally factoring 2 from the top: dy/dx = (2x² + 6x − 2)/(2x+3)² = 2(x² + 3x − 1)/(2x+3)², for x ≠ −3/2.
