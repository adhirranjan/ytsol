1 (i)Fill in the blanks: tan((A − B)/2) = ______Napier's analogy statementProve the tangent rule: Napier's analogy `tan((A-B)/2)=(a-b)/(a+b) cot(C/2)`🟢 Exacttan((A − B)/2) = ((a − b)/(a + b)) cot(C/2)
Concept This is Napier's analogy (the law of tangents in half-angle form). It links the half-difference of two angles to the ratio (difference of sides)/(sum of sides) and the cotangent of half the third angle. The trap is writing cot(A/2) or tan(C/2) instead of cot(C/2): the angle on the right is always the one NOT appearing on the left.
Formula a = 2R sin A, b = 2R sin B and A + B = π − C. The sine rule turns the side ratio into a sine ratio; the angle sum turns tan((A + B)/2) into cot(C/2).
Solution
1. Sine rule: (a − b)/(a + b) = (2R sin A − 2R sin B)/(2R sin A + 2R sin B) = (sin A − sin B)/(sin A + sin B).
2. Sum-to-product on top: sin A − sin B = 2 cos((A + B)/2) sin((A − B)/2).
3. Sum-to-product below: sin A + sin B = 2 sin((A + B)/2) cos((A − B)/2).
4. Divide: (a − b)/(a + b) = tan((A − B)/2) · cot((A + B)/2) = tan((A − B)/2)/tan((A + B)/2).
5. Since A + B = π − C, (A + B)/2 = π/2 − C/2 ⇒ tan((A + B)/2) = cot(C/2). Co-function identity.
6. Rearrange: tan((A − B)/2) = ((a − b)/(a + b)) · tan((A + B)/2) = ((a − b)/(a + b)) cot(C/2).
7. Check on the 3-4-5 triangle (a = 5, b = 4, A = 90°, B = 53.13°, C = 36.87°): LHS = tan(18.43°) = 1/3; RHS = (1/9)·cot(18.43°) = (1/9)·3 = 1/3. ✓

             = tan((A-B)/2) / tan((A+B)/2)
 tan((A+B)/2) = cot(C/2)        (A+B = pi - C)
 -----------------------------------------
 tan((A-B)/2) = ((a-b)/(a+b)) cot(C/2)   <-- answer
⚡ JEE Trick Read it as a cyclic pattern: the letters on the left (A, B) match the sides (a, b) in the same order, and the leftover angle C sits in cot(C/2). Swapping a and b just flips the sign on both sides, so the formula is consistent. Trap: using tan(C/2) gives the wrong value (1/27 instead of 1/3 on the 3-4-5 test).
Answer: tan((A − B)/2) = ((a − b)/(a + b)) cot(C/2).

Solution

2. Sum-to-product: (sin C − sin A)/(sin C + sin A) = [2 cos((C + A)/2) sin((C − A)/2)]/[2 sin((C + A)/2) cos((C − A)/2)].
3. Simplify: (c − a)/(c + a) = tan((C − A)/2) · cot((C + A)/2).
4. C + A = π − B ⇒ (C + A)/2 = π/2 − B/2 ⇒ cot((C + A)/2) = tan(B/2). Co-function identity.

6. Equivalent form: (c − a)/(c + a) = tan((C − A)/2)/cot(B/2); both are the same statement, the product form is the one the blank expects. Dividing by cot is multiplying by tan.

 (a+b+c)(a+b-c) = 3ab       ((2R)² cancels)
 (a+b)² - c² = 3ab
 a² + b² - c² = ab
 cos C = ab/(2ab) = 1/2
 check 3,8,7: 18 x 4 = 72 = 3 x 3 x 8
 -----------------------------------------
 C = 60°                         <-- answer
⚡ JEE Trick Memorise the pattern: (a + b + c)(a + b − c) = k·ab ⇒ cos C = (k − 2)/2. Here k = 3 gives 1/2, C = 60°; k = 1 would give −1/2, C = 120°; k = 2 gives 90°. Trap: the 3 in "3 sin A sin B" tempts 30° or a 3-related answer, but the 2ab from expanding (a + b)² must be subtracted first.
