Concept For any non-zero real t, |t|/t is the signum of t: it equals +1 when t>0 and −1 when t<0 — the magnitude cancels completely, so only the sign survives. Concept An equation mixing |x| with a polynomial cannot be attacked in one piece, because |x| has two different algebraic formulas either side of 0. The standard move is to split the number line at x = 0 (the corner of |x|), solve a plain quadratic on each side, and then discard any root that falls outside the side it came from — that last filter is where most marks are lost. "Algebraic sum" simply means add the surviving roots with their own signs.
Formula |x| = x for x ≥ 0 and |x| = −x for x < 0. This is the definition of modulus, and it is exact on each side — no approximation. Quadratics are then closed by x = (−b ± √(b² − 4ac)) / 2a.
Solution
1. Split at the corner x = 0 into the branches x ≥ 0 and x < 0.x = 0 itself fails: |0| = 0 but 0² − 1 = −1, so no root there.
2. Branch x ≥ 0: |x| = x, so x = x² − 1 ⇒ x² − x − 1 = 0.Rearranged so the quadratic has RHS zero.
3. Solve: x = (1 ± √(1 + 4))/2 = (1 ± √5)/2, i.e. x ≈ 1.618 or x ≈ −0.618.Discriminant = 1 − 4(1)(−1) = 5.
4. Filter by the branch condition x ≥ 0: keep x = (1 + √5)/2, reject (1 − √5)/2 ≈ −0.618.The rejected value is negative, so it never belonged to this branch — it is extraneous.

Concept A rational inequality with a non-zero right-hand side. The one non-negotiable rule is: never cross-multiply by (3x−5), because its sign is unknown and multiplying by a negative silently flips ≥ into ≤. Instead move the 3 across, combine into a single fraction, and read off the answer from a sign scheme built on the zeros of numerator and denominator.

1. Shift the 3 to the left: (2x−3)/(3x−5) − 3 ≥ 0.This is the "make RHS zero" first step — it is what makes a sign scheme valid.

Concept A pure definition check. A rational expression is a ratio of two polynomials, P(x)/Q(x) with Q(x) not identically zero. An inequality is a statement joined by <, >, ≤ or ≥ — not by "=". Put the two together and a rational inequality is any statement comparing a rational expression to something using an inequality sign. The four options each break exactly one half of that definition, so eliminating them is mechanical.
Formula P(x)/Q(x) < 0, > 0, ≤ 0 or ≥ 0 with P, Q polynomials and Q(x) ≠ 0. Both ingredients are needed: a rational expression (the ratio) and an inequality sign (the comparison). A polynomial is itself rational (take Q = 1), but the term "rational inequality" is reserved for the case where a genuine variable denominator is present.
Solution
1. Fix the two defining requirements: (1) the expression must be a ratio of polynomials, (2) the relation must be an inequality, not an equality.Miss either requirement and the name does not apply.
2. Test (a) "involving a linear expression": too narrow — that describes a linear inequality such as 2x+1 > 0, with no denominator. ✗Linear is a special case, not the definition.
3. Test (b) "involving a polynomial only": that is a polynomial inequality like x²−4 < 0. The word only rules out a variable denominator. ✗Requirement (1) fails — no ratio.
4. Test (c) "involving a rational expression": ratio of polynomials ✓ plus an inequality ✓. Both requirements met. ✓This is precisely the definition, e.g. (x−1)/(x+2) > 0.

9Solve the inequation x(x + 1)(x + 2)(x + 3) < 48.Product of four linear factorsPolynomial inequalities — wavy-curve method🟡 Similar(−(3+√33)/2, (√33−3)/2)
Concept A product of four consecutive-style linear factors against a constant. Pairing the factors symmetrically — outer with outer, inner with inner — makes both pairs produce the same quadratic block x² + 3x, and the quartic collapses to a quadratic in u. The delightful twist: one of the two resulting conditions turns out to be vacuously true, because u = x² + 3x has a minimum of −2.25 and so can never dip below −8.
Formula Pair symmetrically: [x(x+3)][(x+1)(x+2)] = (x² + 3x)(x² + 3x + 2). x·(x+3) = x²+3x and (x+1)(x+2) = x²+3x+2 — the same block, shifted by 2. Then with u = x² + 3x the problem is u(u+2) < 48. Minimum of u: u = (x + 3/2)² − 9/4 ≥ −9/4.
Solution
1. Pair the outer two and the inner two factors: [x(x+3)] · [(x+1)(x+2)].Pairing outer-with-outer is the key — pairing adjacent factors would not produce a common block.
2. Expand each pair: x(x+3) = x² + 3x; (x+1)(x+2) = x² + 3x + 2.Both contain the identical block x² + 3x, differing only by the constant 2.
3. Substitute u = x² + 3x: the inequality becomes u(u + 2) < 48.The quartic in x is now a quadratic in u.
4. Expand and rearrange: u² + 2u − 48 < 0.Bringing 48 across.
5. Factor: u² + 2u − 48 = (u + 8)(u − 6) ⇒ (u+8)(u−6) < 0 ⇒ −8 < u < 6.+8 and −6 multiply to −48 and add to +2. Negative between the roots.
6. Check the left half: is u > −8 ever restrictive? Complete the square: u = x² + 3x = (x + 3/2)² − 9/4, so u ≥ −2.25 for every real x.The minimum of u is −2.25, comfortably above −8.
7. Since −2.25 > −8, the condition u > −8 is automatically satisfied for all x — it is vacuous and can be discarded entirely.This is the elegant twist: half the work evaporates.
8. So only u < 6 bites: x² + 3x < 6 ⇒ x² + 3x − 6 < 0.A single ordinary quadratic inequality remains.
9. Solve: discriminant = 9 + 24 = 33, so x = (−3 ± √33)/2.√33 ≈ 5.745, so the roots are approximately −4.372 and 1.372.
10. An upward parabola is negative between its roots ⇒ x ∈ ((−3 − √33)/2, (−3 + √33)/2) ≈ (−4.372, 1.372).Both ends open, since the inequality is strict.
11. Verify inside — x = 0: 0·1·2·3 = 0 < 48 ✓; x = 1: 1·2·3·4 = 24 < 48 ✓; x = −4: (−4)(−3)(−2)(−1) = 24 < 48 ✓.All three sample points fall inside the interval and satisfy the inequality.
12. Verify outside — x = 2: 2·3·4·5 = 120, not < 48 ✓ (and 2 > 1.372); x = −5: (−5)(−4)(−3)(−2) = 120, not < 48 ✓ (and −5 < −4.372).The boundaries are confirmed on both sides.
   x(x + 1)(x + 2)(x + 3)  &lt;  48

        [ x(x+3) ] . [ (x+1)(x+2) ]
        (x^2 + 3x) . (x^2 + 3x + 2)          &lt;- same block!

   substitute  u = x^2 + 3x :
        u(u + 2)  &lt;  48

        (u + 8)(u - 6) &lt;  0

   only  u &lt; 6  bites:

Then test whether each half of the resulting range is actually attainable: since x² + 3x ≥ −9/4, the condition u > −8 is free, and half the problem vanishes. 10Solve the inequation x⁴ − x³ − 10x² + 2x + 4 < 0.Quartic inequality via factorisationSolving Polynomial Inequalities🟡 Similar(−1−√3, (3−√17)/2) ∪ (√3−1, (3+√17)/2)
Concept A genuine quartic with no rational roots — the rational-root theorem fails outright, so the only way through is to factor into two quadratics with undetermined coefficients and match. Once split as (x² + 2x − 2)(x² − 3x − 2), each quadratic surrenders two irrational roots, and the four roots interlace into an ordinary alternating sign chart.
Formula Ansatz: x⁴ − x³ − 10x² + 2x + 4 = (x² + ax + b)(x² + cx + d). Expanding and matching coefficients gives a + c = −1, b + d + ac = −10, ad + bc = 2, bd = 4. Two polynomials are equal iff every coefficient matches — four equations for four unknowns.
Solution
1. Test for rational roots first: candidates are ±1, ±2, ±4. f(1) = 1−1−10+2+4 = −4; f(−1) = 1+1−10−2+4 = −6; f(2) = 16−8−40+4+4 = −24; f(−2) = 16+8−40−4+4 = −16. None is zero.So there is no linear factor with integer coefficients — we must split into two quadratics.
2. Set up the ansatz (x² + ax + b)(x² + cx + d) and match coefficients: a + c = −1; b + d + ac = −10; ad + bc = 2; bd = 4.Expanding the product and equating x³, x², x¹, x⁰ terms.
3. Try the integer factor pair b = d = −2 (so bd = 4 ✓). Then ad + bc = −2a − 2c = −2(a + c) = −2(−1) = 2 ✓ — the x-coefficient matches automatically.The pair b = d = 2 fails: it would give ad + bc = 2(a+c) = −2 ≠ 2.
4. Use the remaining equation: b + d + ac = −10 ⇒ −2 − 2 + ac = −10 ⇒ ac = −6.Combined with a + c = −1.
5. Solve a + c = −1, ac = −6: a and c are roots of t² + t − 6 = 0 = (t+3)(t−2) ⇒ a = 2, c = −3.Either assignment works — it just swaps the two brackets.
6. So x⁴ − x³ − 10x² + 2x + 4 = (x² + 2x − 2)(x² − 3x − 2).Verify by expanding: x⁴−3x³−2x² + 2x³−6x²−4x −2x²+6x+4 = x⁴ − x³ − 10x² + 2x + 4 ✓.
7. Roots of x² + 2x − 2 = 0: discriminant = 4 + 8 = 12, x = (−2 ± 2√3)/2 = −1 ± √3 ≈ −2.732 and 0.732.√12 = 2√3, and √3 ≈ 1.732.
8. Roots of x² − 3x − 2 = 0: discriminant = 9 + 8 = 17, x = (3 ± √17)/2 ≈ −0.562 and 3.562.√17 ≈ 4.123.
9. Order all four roots: −1−√3 ≈ −2.732 < (3−√17)/2 ≈ −0.562 < −1+√3 ≈ 0.732 < (3+√17)/2 ≈ 3.562.The two quadratics' roots interlace — they do not come in separate blocks.
10. All four are simple, the leading coefficient is +1, so the far right is + and the signs alternate: + , − , + , − , + reading right to left.Strict < 0, so all four roots are excluded.
11. Keep the − regions: (−1−√3, (3−√17)/2) ∪ (−1+√3, (3+√17)/2).Approximately (−2.732, −0.562) ∪ (0.732, 3.562).
12. Verify inside — x = −2: 16 + 8 − 40 − 4 + 4 = −16 < 0 ✓; x = 1: 1 − 1 − 10 + 2 + 4 = −4 < 0 ✓.Both kept intervals confirmed.
13. Verify outside — x = 0: 0 − 0 − 0 + 0 + 4 = 4 > 0 ✓ (0 sits in the excluded middle gap); x = 4: 256 − 64 − 160 + 8 + 4 = 44 > 0 ✓; x = −3: 81 + 27 − 90 − 6 + 4 = 16 > 0 ✓.All three rejected regions confirmed — the constant term 4 gives the sign at x = 0 for free.
   x^4 - x^3 - 10x^2 + 2x + 4  &lt;  0

        NONE is zero  ->  no linear factor  ->  split into 2 quadratics
