Concept A quadratic ax² + bx + c = 0 with a ≠ 0 has exactly two roots α and β, and those roots are tied to the coefficients without ever being computed. Factorising the left side as a(x − α)(x − β) and comparing coefficients produces Vieta's two relations. Here 5x² + 10x + 2 = 0 gives a = 5, b = 10, c = 2, and a ≠ 0 so the equation really is quadratic. The blank asks only for the sum, so one relation finishes it.
Formula α + β = −b/a,   αβ = c/a. Because a(x−α)(x−β) = ax² − a(α+β)x + aαβ must match ax² + bx + c term by term.
Solution
1. Read the coefficients straight off: a = 5, b = 10, c = 2, with a ≠ 0. Always confirm a ≠ 0 before quoting Vieta — a linear equation has no second root.
2. α + β = −b/a = −10/5 = −2.
3. αβ = c/a = 2/5, which is not asked but pins the pair completely.
4. D = b² − 4ac = 10² − 4(5)(2) = 100 − 40 = 60 > 0, so the roots are real and distinct. The sum formula holds even when D < 0, so this only tells us the pair is real.
5. Explicitly, x = (−10 ± √60)/10 = −1 ± √15/5, and these two add to −2 exactly.
6. Hence α + β = −2. Notice the answer never used c — changing 2 to any other number leaves the sum at −2.

1 (iii)Fill in the blanks: If ax^2 + bx + c = 0 is an identity then value of a ____Identity in quadraticQuadratic Equations L-1| Relation Between Roots & Coefficients, Nature of Root, Identity | V Enthuse🟡 Similar0
Concept There is a sharp difference between an equation and an identity. An equation ax² + bx + c = 0 is a demand satisfied by at most two special values of x; an identity is a statement true for every real x without exception. A polynomial of degree n can vanish at most n times, so a polynomial that vanishes at infinitely many points cannot have any degree at all — every one of its coefficients must be zero. Applying that to ax² + bx + c ≡ 0 kills a, b and c simultaneously, and the blank asks for a.
Formula ax² + bx + c ≡ 0 for all x ⟺ a = b = c = 0. A non-zero quadratic or linear polynomial has at most 2 roots, so infinitely many roots forces every coefficient to vanish.
Solution
1. "Identity" means the statement holds for every x, so pick convenient values instead of solving. Substituting chosen values is the fastest legitimate route, since the claim is true for all of them.
2. Put x = 0: a(0) + b(0) + c = c = 0, so c = 0.
3. Put x = 1: a + b + c = a + b = 0, and x = −1: a − b + c = a − b = 0.
4. Adding and subtracting those two: 2a = 0 and 2b = 0, hence a = 0 and b = 0. Three well-chosen substitutions pin down all three coefficients with no algebra beyond addition.
5. So a = b = c = 0 and the required value is a = 0.
6. Consistency check: with a = 0 the expression is no longer a quadratic at all, and 0 = 0 is satisfied by every x — infinitely many roots. This is exactly why such an equation is said to have infinitely many roots rather than two.
  claim:  a x^2 + b x + c = 0   for ALL x
  ------------------------------------------------
  x =  0  ->            c = 0
  x =  1  ->  a + b + c = 0  =>  a + b = 0
  x = -1  ->  a - b + c = 0  =>  a - b = 0
  ------------------------------------------------
  add / subtract -> 2a = 0, 2b = 0 -> a = 0, b = 0
  result: a = b = c = 0   (identity, not equation)
⚡ JEE Trick The trap is reading the word "quadratic" and assuming a ≠ 0, which would make the identity impossible. In an identity question the degree assumption is exactly what gets destroyed: a must be 0, and so must b and c. Remember the contrast — "equation" gives at most two roots, "identity" gives every coefficient zero and infinitely many roots — because ICAD sets both versions side by side in this exercise.
Answer: a = 0.

Concept Every quadratic factorises over its own roots: ax² + bx + c = a(x − α)(x − β), where a is the leading coefficient and α, β are the roots. The statement x² − 7x + 10 = p(x − q)(x − r) is an identity in x, so p must be the leading coefficient and q, r must be precisely the roots. Since the left side is monic, p = 1 immediately, and the remaining job is to factor 10 into two numbers adding to 7. The condition q < r then removes the labelling ambiguity between the two roots.
Formula ax² + bx + c = a(x − α)(x − β), with α + β = −b/a and αβ = c/a. Expanding the right side and comparing coefficients with the left reproduces exactly Vieta's two relations.
Solution
1. Expand the right side: p(x − q)(x − r) = px² − p(q + r)x + pqr.
2. Compare the x² terms: p = 1, since the left side x² − 7x + 10 is monic. Fix p first — the other two comparisons are only clean once p is known.
3. Compare the x terms: −p(q + r) = −7 ⇒ q + r = 7; compare constants: pqr = 10 ⇒ qr = 10.
4. Two numbers with sum 7 and product 10 are 2 and 5, since 2 + 5 = 7 and 2 × 5 = 10. Equivalently x² − 7x + 10 = (x − 2)(x − 5) by splitting the middle term as −2x − 5x.
5. The condition q < r orders them: q = 2 and r = 5.
6. Verify: 1·(x − 2)(x − 5) = x² − 7x + 10 ✓, and D = (−7)² − 4(1)(10) = 49 − 40 = 9 > 0 with √9 = 3 = 5 − 2. √D equals the gap between the roots when a = 1, a fast structural check.

  RHS = p x^2 - p(q+r) x + p q r
  ------------------------------------------------
  x^2 :  p          = 1
  x   :  -p(q+r)    = -7   ->  q + r = 7
  1   :  p q r      = 10   ->  q r   = 10
  ------------------------------------------------
  {q, r} = {2, 5};  ordered  ->  q = 2, r = 5
⚡ JEE Trick The factorisation is p(x − q)(x − r), so q and r are the roots themselves, not their negatives — writing (x + q)(x + r) would flip both signs and give q = −2, r = −5. Note also that the constraint q < r exists only to make the answer unique; without it the pair {2, 5} could be labelled either way. Fix the leading coefficient first, then match sum and product, and read the ordering condition before writing the final line.
Answer: p = 1, q = 2, r = 5.

Concept A symmetric function of the roots is one unchanged when α and β swap places, and every such function can be written using only the sum and the product. That is why Vieta's relations are so powerful: α + β and αβ are read straight off the coefficients, and everything symmetric is built from them. Here p and q are literally the sum and product, while r = α² + β² is the first genuinely composite symmetric function. The correct move is to express α² + β² through the sum and product rather than solving x² + 3x + 2 = 0 first.
Formula α + β = −b/a, αβ = c/a, α² + β² = (α+β)² − 2αβ. Because (α+β)² = α² + 2αβ + β², subtracting 2αβ removes the cross term and leaves the sum of squares.
Solution

2. p = α + β = −b/a = −3/1 = −3.
3. q = αβ = c/a = 2/1 = 2.
4. r = α² + β² = (α+β)² − 2αβ = (−3)² − 2(2) = 9 − 4 = 5. Squaring −3 gives +9, so the minus sign in p never reaches r — a frequent slip is writing −9.
5. Direct confirmation: x² + 3x + 2 = (x + 1)(x + 2), so α = −1, β = −2, giving α + β = −3, αβ = 2 and 1 + 4 = 5 ✓.
6. Hence p = −3, q = 2, r = 5. The identity route works even when D < 0 and the roots are complex, which is why it is the method to internalise.

3If p, q, r be in H.P. and p and r be different having same sign, then the roots of the equation px^2 + qx + r = 0 will be : (a) Real (b) Equal (c) Imaginary (d) Real and EqualNature of roots / discriminantIf p,q,r are in H.P. and p&r be different having same sign then roots of the equation px^2+qx+r=0🟢 ExactcImaginary
Concept Being in H.P. means the reciprocals 1/p, 1/q, 1/r are in A.P., which converts into q being the harmonic mean of p and r. That single relation expresses q in terms of p and r, so the discriminant of px² + qx + r = 0 becomes a function of p and r alone. Since p and r share a sign, pr > 0, and that sign is what decides everything. The extra clue p ≠ r rules out nothing here but signals that the answer should not be the equal-roots option.
Formula p, q, r in H.P. ⇒ q = 2pr/(p + r); nature of roots is decided by D = q² − 4pr. 1/p, 1/q, 1/r in A.P. means 2/q = 1/p + 1/r = (p + r)/pr, which inverts to the harmonic mean.
Solution
1. From the H.P. condition, q = 2pr/(p + r), with p + r ≠ 0 since p and r have the same sign.
2. D = q² − 4pr = 4p²r²/(p + r)² − 4pr = 4pr[ pr − (p + r)² ]/(p + r)².
3. Expand the bracket: pr − (p² + 2pr + r²) = −(p² + pr + r²), so D = −4pr(p² + pr + r²)/(p + r)².
4. Same sign for p and r gives pr > 0, hence p² + pr + r² > 0 as a sum of three positives. In fact p² + pr + r² = (p + r/2)² + 3r²/4 is positive for all real p, r not both zero.
5. The denominator (p + r)² is positive, so D is −4 × positive × positive / positive, i.e. D < 0. Every factor's sign is forced, so no case-splitting on p > 0 versus p < 0 is needed.
6. A strictly negative discriminant means the roots are imaginary — option (c). Test p = 1, r = 2: q = 4/3, D = 16/9 − 8 = −56/9 < 0, confirming the general result.

Concept Clear the denominators first so the relation becomes a genuine quadratic, then read off the sum and product by Vieta. Concept Two separate quadratics are linked only by the statement that their four roots, taken in the order α, β, γ, δ, form a single arithmetic progression. That single sentence lets you parametrise all four numbers by just two unknowns, the first term and the common difference. Vieta then gives two equations for those two unknowns, because each quadratic hands you the sum of its own pair. Once the four roots are pinned down, λ₁ and λ₂ are simply the two products, and no root-finding by discriminant is ever needed.

2. First equation: α + β = 7 gives (a) + (a + d) = 2a + d = 7. The coefficient of x is −7, and for a monic quadratic the sum of roots is the negative of that.

10If the arithmetic mean of the roots of a quadratic equation is 8/5 and the arithmetic mean of their reciprocal is 8/7 then the equation is : (a) 5x^2 + 16x + 7 = 0 (b) 5x^2 - 16x + 7 = 0 (c) 7x^2 + 16x + 5 = 0 (d) 7x^2 - 16x + 5 = 0Sum & product of rootsIf A.M. of the roots of a quadratic equation is 8/5 and A.M. of their reciprocals is 8/7🟢 Exactb5x² − 16x + 7 = 0
Concept A quadratic is reconstructed from just two numbers — the sum and the product of its roots — so the entire job is to convert the two given means into those two symmetric functions. The arithmetic mean of the roots is half their sum, which gives α + β at once. The mean of the reciprocals is half of 1/α + 1/β, which collapses to (α + β)/(αβ), so once the sum is known the product falls out. No individual root need ever be computed, and the equation is fixed only up to a common multiple, so scaling clears the fractions.
Formula x² − (α + β)x + αβ = 0, with 1/α + 1/β = (α + β)/(αβ). Adding reciprocals over a common denominator is the one identity that links the second mean back to the first.

2. Second condition: (1/α + 1/β)/2 = 8/7 ⇒ 1/α + 1/β = 16/7. Both roots must be non-zero for the reciprocals to exist, so αβ ≠ 0 is guaranteed by the question.
3. Combine the reciprocals: (α + β)/(αβ) = 16/7 ⇒ (16/5)/(αβ) = 16/7.
4. Solve for the product: αβ = (16/5) × (7/16) = 7/5.
5. Build the equation: x² − (16/5)x + 7/5 = 0, and multiplying throughout by 5 gives 5x² − 16x + 7 = 0. Multiplying by a non-zero constant never changes the roots, so the integer form is the same equation.
6. Check the means back on 5x² − 16x + 7 = 0 : sum = 16/5 so A.M. = 8/5, and (16/5)÷(7/5) = 16/7 so the reciprocal A.M. = 8/7. Both hold. D = (−16)² − 4(5)(7) = 256 − 140 = 116 > 0, so the roots are real and the means are meaningful.
