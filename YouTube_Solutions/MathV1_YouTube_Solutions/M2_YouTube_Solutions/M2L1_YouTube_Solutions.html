1Correct definition of a setDefinition of a setSets — definition, roster & set-builder🟡 SimilarbA well-defined collection of distinct objects
Concept A set is the most basic object in this chapter, so its definition must be precise. Two words carry all the weight: well-defined and distinct. "Well-defined" means there is an unambiguous rule that decides, for any object, whether it belongs or not — no opinion or vagueness allowed. "Distinct" means each member is counted once; repetition is ignored. A loose collection like "the tall students of a class" is not a set, because "tall" has no sharp boundary.
Formula A set = a well-defined collection of distinct objects. Notation: capital letters for the set (A, B, X), lower-case for elements; x ∈ A means "x belongs to A", x ∉ A means it does not. The membership symbol ∈ only makes sense because "well-defined" guarantees a yes/no answer for every x.
Solution
1. Test the "well-defined" clause: "the collection of vowels in English" → the rule (is it a vowel?) gives a clean yes/no, so it is a set = {a, e, i, o, u}.Every letter can be checked against a fixed list, so membership is never in doubt.
2. Reject vague collections: "the good cricketers of India" is not a set — "good" is subjective, so membership is undecidable.
3. Apply the "distinct" clause: {a, a, b} is written {a, b} — a repeated element adds nothing.A set records only which objects are present, not how many times.
4. Order is irrelevant too: {1, 2, 3} = {3, 1, 2}, since both contain exactly the same members.
 candidate collection            well-defined?   a set?
 vowels of the alphabet          yes             ✓ {a,e,i,o,u}
 rivers of India                 yes             ✓
 tall boys of a class            no (vague)      ✗
 good football players           no (opinion)    ✗
⚡ JEE Trick Scan every option for a subjective adjective (tall, good, beautiful, rich) — such a collection is never a set because membership is not well-defined. The right definition must contain both keywords "well-defined" and "distinct/collection of objects". Trap: options that drop "well-defined" or allow repeated elements are incomplete.
Answer: (a) A set is a well-defined collection of distinct objects.

3Classify as empty / singleton / finite / infiniteTypes of setsSets — types of sets🟡 Similar(i) Infinite (ii) Infinite (iii) Singleton (iv) empty
Concept Sets are sorted by how many elements they contain. The four labels form a ladder: empty (zero elements), singleton (exactly one), finite (a countable, terminating number), and infinite (unending). To classify any set, first find its cardinality n(A) — the count of its members — then read off the matching label. Note that empty and singleton are just special cases of "finite".
Formula n(A) = 0 ⇒ empty (∅); n(A) = 1 ⇒ singleton; n(A) = finite k ⇒ finite; counting never ends ⇒ infinite. The single deciding quantity is the element count; every label follows from it.
Solution
1. {x : x∈N, x<1} → no natural number is less than 1, so it has 0 elements → empty set.
2. {x : x∈N, x²=9} → only x=3 works (x=−3 is not natural), 1 element → singleton.
3. {x : x is a letter of "MATH"} = {M,A,T,H}, 4 elements → finite.
4. {x : x∈N} = {1,2,3,…} → counting never stops → infinite.There is no largest natural number, so no final element to reach.
 set                         n(A)      classification
 {x∈N : x < 1}               0         empty (∅)
 {x∈N : x² = 9}              1         singleton
 letters of "MATH"           4         finite
 {x : x ∈ N}                 ∞         infinite
⚡ JEE Trick Compute n(A) first, then the label is automatic. Watch the classic trap: {0} and {∅} are singletons (one element each — the number 0, or the empty set as an element), not empty sets. Only a set with genuinely zero members is empty.
Answer: empty — {x∈N:x<1};  singleton — {x∈N:x²=9};  finite — {M,A,T,H};  infinite — {x:x∈N}.
4Which of the given sets are finiteFinite vs infiniteSets — finite & infinite sets🟡 SimilarAll (i), (ii), (iii), (iv) are finite sets
Concept A set is finite if its counting process terminates — you can list its members and eventually reach a last one — and infinite if the listing never ends. The deciding factor is whether the defining condition puts an upper bound on how many objects qualify. Bounded regions of the integers give finite sets; the whole of N, Z, Q, R, or any unbounded region gives infinite sets.
Formula finite ⇔ n(A) is a fixed whole number; infinite ⇔ n(A) is unbounded. A bounded range of discrete values ends; a full number line or an unbounded discrete range does not.
Solution
1. {x∈N : x<100} = {1,…,99}, exactly 99 elements → finite.The bound x<100 caps the count.
2. {days in a week} = 7 elements → finite.
3. {x∈Z : x is even} = {…,−2,0,2,4,…} → unbounded both ways → infinite.
4. {x∈R : 0<x<1} → a continuous interval holds uncountably many reals → infinite.Between any two reals lies another, so no finite list exhausts them.
5. {prime numbers} → primes never run out (Euclid) → infinite.
 set                          bounded count?   type
 {x∈N : x < 100}              yes (99)         finite
 days of the week             yes (7)          finite
 even integers                no               infinite
 reals in (0,1)               no               infinite
 all prime numbers            no               infinite
⚡ JEE Trick Ask "does the listing stop?" A range inside R (any interval) is always infinite, even a tiny one like (0, 0.001), because reals are dense. Only a bounded set of discrete/integer values is finite. Trap: "x < 100" over N is finite (99 items) but over R is infinite — the number system matters as much as the bound.
Answer: finite — {x∈N:x<100} and {days of a week}; the rest (even integers, reals in an interval, primes) are infinite.
5A = {1,2,3,4}; all subsets with exactly 3 elementsSubsetsSubsets, proper/improper & power set🟡 Similar{1,2,3}, {1,2,4}, {1,3,4}, {2,3,4}
Concept A 3-element subset is formed by choosing which 3 of the 4 members to keep — equivalently, by deciding which single element to leave out. That one-to-one link (each 3-subset ↔ the one omitted element) is the fastest way to both count and list them: there are as many 3-element subsets as there are elements to drop, namely 4.
Formula number of r-element subsets of an n-set = C(n, r) = n! / (r!(n−r)!). Here n=4, r=3: C(4,3) = 4!/(3!·1!) = 4. C(4,3)=C(4,1)=4 because choosing 3 to include is the same as choosing 1 to exclude.
Solution
1. Count first: C(4,3) = 4!/(3!·1!) = 24/(6·1) = 4 subsets.
2. List by omitting one element at a time from {1,2,3,4}:
  • omit 4 → {1,2,3}
  • omit 3 → {1,2,4}
  • omit 2 → {1,3,4}
  • omit 1 → {2,3,4}
3. That exhausts all ways to leave out exactly one element, so these 4 are complete.
 element omitted   3-element subset
 4                 {1, 2, 3}
 3                 {1, 2, 4}
 2                 {1, 3, 4}
 1                 {2, 3, 4}
 count = C(4,3) = C(4,1) = 4
⚡ JEE Trick To list all (n−1)-element subsets, just drop one element at a time — there are exactly n of them, so C(n, n−1) = n. Use the symmetry C(n,r)=C(n,n−r) to turn an awkward choose into an easy one. Trap: don't double-count reorderings — {1,2,3} and {3,2,1} are the same subset.
Answer: {1,2,3}, {1,2,4}, {1,3,4}, {2,3,4} — 4 subsets in all.
6Cardinal number n(A) of {1,3,5}CardinalitySets — cardinal number🟡 Similarbn(A) = 3
Concept The cardinal number n(A) of a finite set is simply the number of distinct elements it contains. It is the single most-used quantity in set theory — every subset-counting and Venn formula depends on it. The only subtlety is that repeated or nested elements are each counted once, and a bracketed group counts as a single element.
Formula n(A) = number of distinct elements of A. "Distinct" enforces the set rule that duplicates are ignored; nesting like {a,{b,c}} counts {b,c} as one element.
Solution
1. Write the set: A = {1, 3, 5}.
2. Tick off each distinct element: 1 (one), 3 (two), 5 (three).All three are different, so none is discarded as a duplicate.
3. Count = 3, so n(A) = 3.
 set        distinct elements   n(A)
 {1, 3, 5}  1, 3, 5             3
⚡ JEE Trick Count distinct members only — {1,1,3,5} still has n = 3. And a nested set counts as one: n({1,{2,3}}) = 2, not 3. Trap: don't add up the numbers themselves (1+3+5) — cardinality counts elements, not their values.
Answer: n(A) = 3.
7Set B has 4 elements; number of subsetsNumber of subsets 2ⁿHow many subsets? (2ⁿ rule)🟡 Similard2⁴ = 16 subsets
Concept To build a subset of B you make one independent yes/no decision per element: "include it or not." With 4 elements that is 4 independent binary choices, and by the multiplication principle the total number of distinct subsets is 2×2×2×2. This counts everything from the empty set (all "no") to B itself (all "yes"), which is why the formula is 2ⁿ.
Formula number of subsets = 2ⁿ, where n = n(B). Each of the n elements contributes a factor of 2 (in or out); multiplying gives 2ⁿ. Related: proper subsets = 2ⁿ−1, and n(P(B)) = 2ⁿ.
Solution
1. Identify n: B has 4 elements, so n = 4.
2. Apply the rule: subsets = 2ⁿ = 2⁴.
3. Evaluate: 2⁴ = 2×2×2×2 = 16.Four factors of 2: 2→4→8→16.
4. Sanity check by type: 1 empty + 4 singletons + 6 pairs + 4 triples + 1 full = 1+4+6+4+1 = 16 ✓.These are the binomial coefficients C(4,0..4), which sum to 2⁴.

⚡ JEE Trick Memorise the small powers of two: 2⁴ = 16, 2⁵ = 32, 2⁶ = 64. Subsets = 2ⁿ (includes ∅ and B); proper subsets = 2ⁿ−1; subsets excluding both ∅ and B = 2ⁿ−2. Trap: read whether the question wants all subsets or only proper ones — they differ by 1.
Answer: 2⁴ = 16 subsets.
8C = {a,b,c}; which is NOT a proper subsetProper subsetSubsets & proper subsets🟡 Similarc{a, b, c} — the set itself
Concept A proper subset S of C must satisfy two things at once: every element of S is in C (S ⊆ C) and S is strictly smaller than C (S ≠ C). The whole set C = {a,b,c} passes the first test but fails the second — it equals C — so C is a subset of itself but not a proper subset. That is exactly the option the question is fishing for.
Formula S ⊂ C (proper) ⇔ S ⊆ C and S ≠ C. The strict symbol ⊂ forbids equality; every subset except C itself qualifies, and ∅ always qualifies. C has 2³ = 8 subsets, of which 8−1 = 7 are proper.
Solution
1. Test each candidate for S ⊆ C and S ≠ C:
  • ∅ : subset of every set, and ≠ C → proper ✓
  • {a} : all elements in C, ≠ C → proper ✓
  • {a,b} : all elements in C, ≠ C → proper ✓
  • {a,b,c} : all elements in C, but equals C → NOT proper ✗
2. The only failing candidate is the full set itself, {a,b,c}.It is a subset (improper), just not a proper one, because proper requires strict inequality.
 candidate    ⊆ C?   ≠ C?   proper subset?
 ∅            yes    yes    ✓
 {a}          yes    yes    ✓
 {a, b}       yes    yes    ✓
 {a, b, c}    yes    NO     ✗  ← the set itself
⚡ JEE Trick The set that is "NOT a proper subset" of C is C itself — every other subset (including ∅) is proper. Count: an n-set has 2ⁿ subsets and 2ⁿ−1 proper subsets. Trap: ∅ is a proper subset of any non-empty set, so don't pick it as the odd one out.
Answer: (the set itself) {a, b, c} is not a proper subset of C.

Concept The power set P(D) is the set whose elements are all the subsets of D. The mental hurdle is that its members are themselves sets, so the membership symbol ∈ is used with them: {1} ∈ P(D) is true (because {1} is a subset of D), whereas 1 ∈ P(D) is false (1 is an element of D, not a subset). Getting ∈ vs ⊆ straight is what these "true statement" questions test.
Formula P(D) = { S : S ⊆ D }, and n(P(D)) = 2^{n(D)}. For D = {1,2}, n(D)=2 so n(P(D)) = 2² = 4. Each subset of D is one element of P(D); ∅ and D are always included.
Solution
1. List all subsets of D = {1,2}: ∅, {1}, {2}, {1,2}.
2. So P(D) = { ∅, {1}, {2}, {1,2} }, giving n(P(D)) = 4.
3. Evaluate candidate statements:
  • ∅ ∈ P(D) → true (empty set is a subset of D)
  • {1} ∈ P(D) → true ({1} is a subset of D)
  • {1,2} ∈ P(D) → true (D itself is a subset)
  • 1 ∈ P(D) → false (1 is an element of D, not a subset)
  • n(P(D)) = 4 → true

 ∅ ∈ P(D)           ✓         ∅ ⊆ D
 {1} ∈ P(D)         ✓         {1} ⊆ D
 {1,2} ∈ P(D)       ✓         D ⊆ D

⚡ JEE Trick Elements of P(D) are sets, so "{1} ∈ P(D)" is correct but "1 ∈ P(D)" is wrong. Also ∅ ∈ P(D) and D ∈ P(D) are always true. Trap: mixing ∈ and ⊆ — "{1} ⊆ P(D)" is false, but "{{1}} ⊆ P(D)" is true.
Answer: (true) n(P(D)) = 4 and P(D) = {∅, {1}, {2}, {1,2}}, so ∅∈P(D), {1}∈P(D), {2}∈P(D), {1,2}∈P(D).
10True/false + prove (subset relations)Subset propertiesSubset relations & properties🟡 Similar(i) F (ii) F (iii) T (iv) F (v) F (vi) T
Concept These true/false items all rest on one definition: A ⊆ B means "every element of A is also in B." To prove a subset claim, take an arbitrary x∈A and show x∈B; to disprove one, exhibit a single counterexample element in A but not in B. Three standard facts follow directly and are worth memorising: ∅⊆A always, A⊆A always, and (A⊆B and B⊆A) ⇒ A=B.
Formula A ⊆ B ⇔ (∀x)(x∈A ⇒ x∈B); transitivity: A⊆B and B⊆C ⇒ A⊆C; antisymmetry: A⊆B and B⊆A ⇒ A=B. The universal "for all x" is why one counterexample is enough to break a subset claim.
Solution
1. "∅ ⊆ A" → TRUE. Proof: the statement "x∈∅ ⇒ x∈A" is vacuously true since no x∈∅ exists.A conditional with a false premise is automatically true.
2. "A ⊆ A" → TRUE. Proof: every x∈A is trivially in A.
3. "{1,2} ⊆ {1,2,3}" → TRUE. Proof: 1∈{1,2,3} and 2∈{1,2,3}, so both elements carry over.
4. "{1,2,3} ⊆ {1,2}" → FALSE. Counterexample: 3∈{1,2,3} but 3∉{1,2}.One stray element is enough to destroy the subset relation.
5. "a ∈ {a,b}" is TRUE, but "a ⊆ {a,b}" is FALSE — a is an element, not a set, so ⊆ does not apply.
 claim                proof / counterexample                 T/F
 ∅ ⊆ A                vacuously true (no x in ∅)             T
 A ⊆ A                every x∈A is in A                      T
 {1,2} ⊆ {1,2,3}      1,2 both in {1,2,3}                    T
 {1,2,3} ⊆ {1,2}      3 ∈ LHS but 3 ∉ RHS                    F
 A ⊆ B and B ⊆ A  ⇒  A = B (antisymmetry)                   T
⚡ JEE Trick To prove A⊆B, chase a generic element; to disprove it, find one element in A missing from B. Reflex facts: ∅⊆A, A⊆A, and "⊆ both ways ⇒ equal." Trap: ∅⊆A (subset, always true) versus ∅∈A (membership, usually false) are different claims — keep ⊆ and ∈ apart.
Answer: ∅⊆A, A⊆A, {1,2}⊆{1,2,3} are TRUE; {1,2,3}⊆{1,2} is FALSE (3 is a counterexample).

Concept Set-builder form replaces a list with a rule: {x : property of x}. Going from roster to set-builder means spotting the pattern that generates exactly those elements and no others. The skill is to read the structure — a single value, a symmetric ±-spread, or a signed sequence — and encode it as a condition on an index variable drawn from a known number system (N, W, or Z).
Formula {x : P(x)} = "the set of all x for which statement P(x) is true." Choose the base set (Z, W, N) and a defining equation/inequality so that substituting the allowed index values regenerates the roster.
Solution

2. {0, ±1, ±2, ±3} = {−3,−2,−1,0,1,2,3}: all integers whose absolute value is at most 3 → {x : x∈Z, |x| ≤ 3} (equivalently −3 ≤ x ≤ 3).|x|≤3 captures both the positive and negative arms plus 0 in one condition.

 {0}                    x is 0                   {x : x = 0}
 {0,±1,±2,±3}           |x| ≤ 3, integers        {x∈Z : |x| ≤ 3}

5Which power-set identities hold: P(A∩B), P(A∪B), P(A\B)Power-set identitiesShow P(A∩B) = P(A) ∩ P(B)🟢 (I) 🟡aOnly II ⚠
Concept The question asks over which operations the power-set map distributes. The answer is: over intersection only. The reason is a single asymmetry — "S ⊆ A∩B" really does mean "S ⊆ A and S ⊆ B", but "S ⊆ A∪B" does not mean "S ⊆ A or S ⊆ B", because S may draw elements from both. The difference statement III fails for an even simpler reason: ∅ belongs to every power set, so it can never be removed by a set difference.
Formula I: P(A) ∩ P(B) = P(A ∩ B) ✓. II: P(A) ∪ P(B) ⊆ P(A ∪ B), equality only if A⊆B or B⊆A. III: P(A) \ P(B) ≠ P(A \ B) in general, since ∅ ∈ P(A\B) but ∅ ∉ P(A) \ P(B). ∅ is a subset of every set, so it lies in both P(A) and P(B) and is therefore always removed by P(A)\P(B).
Solution
1. Statement I, forward: if S ∈ P(A)∩P(B) then S ⊆ A and S ⊆ B, so each x∈S lies in A and in B ⇒ S ⊆ A∩B ⇒ S ∈ P(A∩B).
2. Statement I, backward: if S ∈ P(A∩B) then S ⊆ A∩B, which is contained in both A and B ⇒ S ∈ P(A) and S ∈ P(B) ⇒ S ∈ P(A)∩P(B). Both directions hold ⇒ I is TRUE.
3. Statement II: take A = {1}, B = {2}. Then P(A)∪P(B) = {∅, {1}, {2}} but P(A∪B) = P({1,2}) = {∅, {1}, {2}, {1,2}}.

5. Statement III: take A = {1}, B = {2} again. Then A \ B = {1}, so P(A\B) = {∅, {1}}.
6. But P(A) \ P(B) = {∅, {1}} \ {∅, {2}} = {{1}} — the empty set has been stripped out because ∅ ∈ P(B).∅ ⊆ B always, so ∅ is a member of P(B) and gets subtracted every time.
7. {∅, {1}} ≠ {{1}} ⇒ III is FALSE. (Indeed ∅ ∈ P(A\B) always, while ∅ ∉ P(A)\P(B) always — the two can never be equal.)
8. Only Statement I is correct ⇒ option (b).

Concept Each set is defined by a trig equation; solve both by converting to tan θ, then union the solutions.
