1 (i)nth term of AGP is ______.General term of an arithmetico-geometric progressionArithmetico Geometric Progression, AGP | PART-15 | Sequence & Series Class-11 CBSE/JEE🟢 Exacttn = [a + (n − 1)d]·rn−1
Concept An A.G.P. is manufactured, not discovered: you take an A.P. a, a+d, a+2d, … and a G.P. 1, r, r², … and multiply them position by position. Term number n of the product is therefore term number n of the A.P. times term number n of the G.P. — nothing more subtle than that. Everything else in this lecture (the sum formula, the infinite sum, the whole "multiply by r and subtract" ritual) is built on this one product.
Formula A.P. term = a + (n − 1)d, G.P. term = rn−1, so tn = [a + (n − 1)d]·rn−1. Both exponents/multipliers use (n − 1), never n — check with n = 1, which must return a.
Solution
1. Write the A.P. that supplies the "arithmetic" factor: a, a + d, a + 2d, …, a + (n − 1)d.
2. Write the G.P. that supplies the "geometric" factor, taken with first term 1: 1, r, r², …, rn−1.Taking the G.P.'s first term as 1 is a convention; if it were A, that A would simply be absorbed into a and d.
3. Multiply corresponding entries: a·1, (a+d)r, (a+2d)r², …
4. The nth entry is therefore tn = [a + (n − 1)d]·rn−1.
5. Sanity check on the module's own example 2x + 4x² + 6x³ + 8x⁴ + …: here a = 2, d = 2, r = x, so tn = [2 + (n−1)2]·x·xn−1 = 2n·xn ✓ (t₃ = 6x³ ✓).
  A.P. :  a    a+d    a+2d   ...  a+(n-1)d
  G.P. :  1     r      r^2   ...    r^(n-1)
          x     x       x            x        <-- multiply columnwise
  AGP  :  a  (a+d)r (a+2d)r^2 ... [a+(n-1)d]r^(n-1)
⚡ JEE Trick Given a printed A.G.P., recover a, d and r by inspection: a = first coefficient, d = (second coefficient − first), r = ratio of consecutive powers. Trap: writing rn instead of rn−1 — always test n = 1.
Answer: tn = [a + (n − 1)d]·rn−1.

Concept There is only one trick for summing an A.G.P., and you should be able to perform it half-asleep: write S, write rS shifted one place right, subtract. The subtraction destroys the arithmetic part (every d appears once instead of growing) and leaves a plain G.P. plus one leftover last term. This is the same manoeuvre used to sum a G.P., applied one level up.
Formula Sn = a/(1−r) − [a+(n−1)d]rn/(1−r) + dr(1 − rn−1)/(1−r)², valid for r ≠ 1. Three pieces: a "head" term, a "tail" term carrying rn, and a G.P. middle carrying d.
Solution
1. Sn = a + (a+d)r + (a+2d)r² + … + [a+(n−1)d]rn−1 … (i)
2. Multiply (i) throughout by r: rSn = ar + (a+d)r² + … + [a+(n−2)d]rn−1 + [a+(n−1)d]rn … (ii)Every term slides one place to the right, so the powers of r line up with those in (i).
3. Subtract (ii) from (i). The first column leaves a; each middle column leaves the constant difference d·rk; the last column leaves −[a+(n−1)d]rn:
Sn(1 − r) = a + d(r + r² + … + rn−1) − [a+(n−1)d]rn.
4. The bracket is a G.P. with first term r, ratio r and (n − 1) terms, so it equals r(1 − rn−1)/(1 − r).
5. Therefore Sn(1 − r) = a + dr(1 − rn−1)/(1 − r) − [a+(n−1)d]rn.
6. Divide by (1 − r): Sn = {a − [a+(n−1)d]rn}/(1 − r) + dr(1 − rn−1)/(1 − r)².
7. Numeric check, a = 1, d = 1, r = ½, n = 2 (series ½·… i.e. 1 + 2·½ = 2): formula gives {1 − 2·¼}/½ + (½)(1 − ½)/¼ = 1 + 1 = 2 ✓
   S   =  a + (a+d)r + (a+2d)r^2 + ... + [a+(n-1)d]r^(n-1)
   rS  =       ar    + (a+d)r^2  + ... + [a+(n-2)d]r^(n-1) + [a+(n-1)d]r^n
  ------------------------------------------------------------------------
 S(1-r)=  a +   dr   +   dr^2    + ... +      dr^(n-1)     - [a+(n-1)d]r^n
                \________________  G.P.  ______________/

Answer: Sn = {a − [a + (n−1)d]rn}/(1 − r) + dr(1 − rn−1)/(1 − r)², r ≠ 1.

Concept The denominator r⁴ + r² + 1 looks hostile until you remember the standard factorisation r⁴ + r² + 1 = (r² + r + 1)(r² − r + 1). Once factored, the term splits into a difference of two reciprocals whose second half is the first half shifted by one — a textbook telescope. Nothing here is an A.G.P.; this is the "method of difference" half of the lecture.
Formula r⁴ + r² + 1 = (r² + r + 1)(r² − r + 1) and r/(r⁴+r²+1) = ½[1/(r² − r + 1) − 1/(r² + r + 1)]. Add and subtract r² : r⁴ + 2r² + 1 − r² = (r²+1)² − r².
Solution
1. Factor: r⁴ + r² + 1 = (r² + 1)² − r² = (r² + r + 1)(r² − r + 1).
2. Note that (r² + r + 1) − (r² − r + 1) = 2r, i.e. exactly twice the numerator. So
r/(r⁴+r²+1) = ½·[(r²+r+1) − (r²−r+1)]/[(r²+r+1)(r²−r+1)] = ½[1/(r²−r+1) − 1/(r²+r+1)].
3. Now observe the shift: replacing r by r + 1 turns (r² − r + 1) into (r² + r + 1). So writing f(r) = 1/(r² − r + 1), the term is ½[f(r) − f(r+1)] — a perfect telescope.Check: f(1) = 1/1 = 1, f(2) = 1/3, f(3) = 1/7 — and indeed term 1 = ½(1 − 1/3) = 1/3 = 1/(1+1+1) ✓
