Exponents, Laws of Indices & Exponential Inequalities

  • An exponent (index / power) is a value a base is raised to: am = a × a × … × a (m times).
  • An exponential equation has the variable in the exponent (or part of it).
the eight index lawsa0=1 · a−p=1/ap · apaq=ap+q · ap/aq=ap−q · (ap)q=apq · apbp=(ab)p · ap/bp=(a/b)p · ap/q=q√(ap)

Solving exponential equations

  • Make the bases equal, then equate exponents: if bx = by (b > 0, b ≠ 1) then x = y.
  • Rewrite numbers as powers of a common base (e.g. 27 = 3³, 81 = 3⁴, 25 = 5²) before comparing.

Exponential inequalities

key factIf a > 1 and x > y then ax > ay ; if 0 < a < 1 and x < y then ax > ay
The five inequality situations from the module
(1) Same base > 1: 22x+3 > 23x ⇒ 2x+3 > 3x ⇒ x < 3. (2) Same base < 1: (½)3x > (½)2x+3 ⇒ 3x < 2x+3 ⇒ x < 3 (sign flips). (3) Rewritable to one base: 4x+2 > 82x ⇒ 22x+4 > 26x ⇒ x < 1. (4) Unrelated bases → take logs: 25x > 58−5x ⇒ x > (8/5)·log 5. (5) Multiple terms → substitute y = ax: 2x+4x > 6 ⇒ y²+y−6 > 0 ⇒ y > 2 ⇒ x > 1.
⚠ TrapWhen the common base is less than 1, comparing the exponents reverses the inequality sign.
💡 SubstitutionFor a sum like a2x+ax put y = ax (> 0), solve the quadratic, then reject any non-positive y.

Logarithms — Definition, Graphs & Log Rules

definitionaN = b ⇔ N = logₐb (a > 0, a ≠ 1, b > 0)
  • logₐb is the exponent to which base a must be raised to give b. Example: log₂16 = 4 since 2⁴ = 16.
  • The log function y = logₐx is the inverse of the exponential y = ax.
  • log x = base-10 (common) log; ln x = base-e (natural) log.

Interconversion (log ⇄ exponential)

formslogₐM = x ⇔ M = ax · logeM = x ⇔ M = ex

Product, quotient & exponent rules

the three log lawslogb(mn) = logbm + logbn · logb(m/n) = logbm − logbn · logb(mn) = n·logbm
Shape of the log graph y = logₐx
The curve always passes through (1, 0) and is defined only for x > 0. If a > 1 it rises (increasing) — e.g. y = log₂x through (1,0),(2,1),(4,2). If 0 < a < 1 it falls (decreasing) — e.g. y = log1/2x through (1,0),(2,−1),(4,−2). Horizontal shifts: y = log₂(x+3) is the log₂ curve moved left 3, valid only for x > −3.
★ Sign factslogₐ1 = 0, logₐa = 1, and log5(1/25) = −2 (a fraction < 1 gives a negative log when base > 1).
⚠ Traplogb(m + n) ≠ logbm + logbn. The product rule applies to a product inside the log, never a sum.

Change of Base Formulae

change of baselogbx = logₐx / logₐb
useful consequenceslogba = 1 / logₐb · (logₐb)(logbx) = logₐx · blog_b x = x
coefficient formslogaᵏxM = (M/k)·logₐx · alog_b x = xlog_b a
  • Change of base lets you convert any log to base-10 (log) or base-e (ln) for a calculator, or to a convenient common base to combine terms.
  • Chaining: (logba)(logcb) = logca — the “inner” bases cancel like fractions.
Why logba = 1 / logₐb
Put x = a in logbx = logₐx / logₐb : logba = logₐa / logₐb = 1 / logₐb, since logₐa = 1. So swapping base and argument inverts the value — e.g. log1255 = 1 / log5125 = 1/3.
💡 Speed trickWrite both numbers as powers of one prime: log3216 = log(2⁴)/log(2⁵) = 4/5 — no calculator needed.

Properties of Exponential & Log Inequalities

exponential factFor every real x : ax > 0 (a > 0). So ax = negative has no solution.
log inequalities, base a > 1logₐx < α ⇒ 0 < x < aα · logₐx < logₐy ⇒ 0 < x < y
log inequalities, 0 < a < 1logₐx < α ⇒ x > aα · logₐx < logₐy ⇒ x > y > 0 (sign flips)
Standard method for log/exp inequalities
Step 1 — Domain: for ln(expression) or logₐ(expression) demand the inside > 0 first. Step 2: take logs / exponentiate. Dividing (or multiplying) by ln 0.4 or ln 0.8 — which are negative — reverses the inequality. Step 3: intersect the Step-2 answer with the domain from Step 1.
⚠ Trap — negative log factorln(0.4) < 0 and ln(0.8) < 0. Dividing by them flips ≤ to ≥. Forgetting this is the #1 sign error.
★ Instant answersax > 0 for all x (solution ℝ); ax < 0 never (∅); logₐx ≥ 0 ⇒ x ≥ 1 (a > 1); logₐx < 0 ⇒ 0 < x < 1 (a > 1).

Book Example · L-4
Solve the inequality : 6(3 − 0.4x) ≤ 3.
÷6: 3 − 0.4x ≤ ½ ⇒ −0.4x ≤ −5/2 ⇒ 0.4x ≥ 5/2 (÷ by −1 flips).
Take ln: x·ln(0.4) ≥ ln(5/2) ⇒ x ≤ ln(5/2)/ln(0.4) (÷ by ln 0.4 < 0 flips) = [ln5 − ln2]/[ln2 − ln5] = −1.
x ≤ −1, i.e. (−∞, −1]
Book Example · L-4
Solve the inequality : ln(5 − 3x) ≤ 1.
Domain: 5 − 3x > 0 ⇒ x < 5/3.
Exponentiate: 5 − 3x ≤ e ⇒ −3x ≤ e − 5 ⇒ x ≥ (5 − e)/3 (÷ by −3 flips).
(5 − e)/3 ≤ x < 5/3, i.e. [(5 − e)/3, 5/3]
Book Example · L-4
Solve : (a) 6x > 0 (b) log6x ≥ 0 (c) 5x < 0 (d) log3x < 0.
(a) ax > 0 for every real x ⇒ solution (−∞, ∞).
(b) a > 1, logₐx ≥ 0 ⇔ x ≥ 1 ⇒ [1, ∞).
(c) 5x > 0 always ⇒ 5x < 0 impossible ⇒ ∅.
(d) a > 1, logₐx < 0 ⇔ 0 < x < 1 ⇒ (0, 1).
(a) ℝ (b) [1, ∞) (c) ∅ (d) (0, 1)
Book Example · L-4
Solve : (½)x²−2x < ¼.
¼ = (½)² ⇒ (½)x²−2x < (½)². Base ½ < 1 ⇒ compare flips: x² − 2x > 2.
x² − 2x − 2 > 0 ⇒ (x − (1+√3))(x − (1−√3)) > 0 ⇒ x > 1+√3 or x < 1−√3.
x ∈ (−∞, 1 − √3) ∪ (1 + √3, ∞)
Book Example · L-4
Solve the equation : log7 log5(√(x+5) + √x) = 0.
Domain: x ≥ 0 (and x ≥ −5) ⇒ x ≥ 0. Outer log = 0 ⇒ log5(√(x+5) + √x) = 1.
⇒ √(x+5) + √x = 5 ⇒ √(x+5) = 5 − √x ⇒ x + 5 = 25 + x − 10√x ⇒ 10√x = 20 ⇒ √x = 2.
