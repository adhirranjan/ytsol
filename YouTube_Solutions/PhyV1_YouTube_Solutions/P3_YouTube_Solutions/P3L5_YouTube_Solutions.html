1The formula to resolve a force F inclined at angle θ to the horizontal is: (F·cosθ and F·sinθ)Resolving a force into perpendicular componentsHow To Find The Components of a Vector Given Magnitude and Direction · How to Find X and Y Components of Vectors🟡 SimilarbF·cosθ and F·sinθ
Concept Resolving a force means replacing one force F by two mutually perpendicular forces that, added vectorially, reproduce it exactly. The force is the hypotenuse of a right triangle whose legs are the components. The angle θ is measured from the horizontal, so the horizontal leg sits adjacent to θ (→ cosine) and the vertical leg sits opposite to θ (→ sine). Getting which function goes with which axis is decided entirely by where θ is measured from.
Formula Fx = F·cosθ and Fy = F·sinθ, with F in N, θ in degrees, and Fx, Fy in N. cosθ and sinθ are pure numbers (dimensionless ratios of sides), so N × (number) = N — the components carry the same unit as the force, as they must. Recombination check: √(Fx² + Fy²) = F and tanθ = Fy/Fx.
Solution
1. Draw F from the origin at angle θ above the horizontal; drop a perpendicular from its tip onto the x-axis.This builds a right triangle in which F is the hypotenuse and the two components are the legs.
2. Horizontal leg = side adjacent to θ, so cosθ = Fx/F ⇒ Fx = F·cosθ (N).cos = adjacent ÷ hypotenuse; multiply both sides by F to isolate Fx.
3. Vertical leg = side opposite to θ, so sinθ = Fy/F ⇒ Fy = F·sinθ (N).sin = opposite ÷ hypotenuse; multiply both sides by F to isolate Fy.
4. Verify the pair really rebuilds F: √(F²cos²θ + F²sin²θ) = F·√(cos²θ + sin²θ) = F·√1 = F (N).The Pythagorean identity cos²θ + sin²θ = 1 guarantees the components are consistent — this is the check that kills wrong option pairs.
5. Test the options at θ = 0° (F should be fully horizontal): F·cosθ = F·1 = F ✓ horizontal, F·sinθ = F·0 = 0 ✓ vertical. Option (a) F·tanθ, F·cotθ gives cot0° = ∞ ✗; option (c) F/cosθ = F but F/sinθ = ∞ ✗. Only (b) survives.

                   / |
              F   /  |  F·sinθ  (vertical, opposite θ)
                 /   |
                /θ   |
               +-----+
               F·cosθ  (horizontal, adjacent θ)

  check:  (F·cosθ)² + (F·sinθ)² = F²(cos²θ + sin²θ) = F²   ✓
  units:  N × (dimensionless) = N                          ✓
⚡ JEE Trick The component along the axis the angle is measured from gets the cosine; the other gets the sine. So if a problem instead measures θ from the vertical, the roles flip (vertical = F·cosθ). Fastest elimination: plug in θ = 0° — the whole force must lie along the reference axis and the perpendicular component must vanish; only F·cosθ, F·sinθ does that. Trap: options with tan/cot blow up at 0° or 90° and can never be components of a finite force.
Answer: (b) F·cosθ (horizontal) and F·sinθ (vertical), both in newton.

4A body constrained to move along the z-axis is subjected to a constant force F=−î+2ĵ+3k̂ N. Calculate the work done displacing the body 4m along the z-axis. (12 J)Work done = F·d (dot product)Work is Dot product of Force and Displacement · PHYSICS MADE EASY – Work Done, Force and Displacement vectors – solved problem🟡 Similar12 joule
Concept Work is the scalar (dot) product of force and displacement — it counts only the part of the force that lies along the motion. Here the body is constrained to the z-axis, so no matter what the x- and y-components of F do, the body cannot move sideways; those components are cancelled by the constraint (the rails/track) and do zero work. Only Fz is left to do work. This is why the dot product automatically discards perpendicular components.
Formula W = F·d = Fxdx + Fydy + Fzdz, with F in N, d in m, W in J. N × m = J by definition of the joule, so a force-times-displacement product is guaranteed to come out in joule. Given: F = (−1)î + 2ĵ + 3k̂ N; motion is 4 m along z, so d = 0î + 0ĵ + 4k̂ m. Assumption: F is constant over the path (stated), so no integration is needed.
Solution
1. Write the displacement as a vector. "4 m along the z-axis" means d = 4k̂ m, i.e. dx = 0 m, dy = 0 m, dz = 4 m.The constraint forbids any x or y motion, so those displacement components are exactly zero.
2. List the force components: Fx = −1 N, Fy = +2 N, Fz = +3 N.
3. Substitute into W = Fxdx + Fydy + Fzdz, keeping every unit:
  • Fxdx = (−1 N)(0 m) = 0 JThe body never moves in x, so the x-force does no work — the constraint absorbs it.
  • Fydy = (+2 N)(0 m) = 0 J
  • Fzdz = (+3 N)(4 m) = 12 J
4. Add the three contributions: W = 0 J + 0 J + 12 J = 12 J.
5. Dimensional check: [F][d] = (M L T⁻²)(L) = M L² T⁻² = the dimensions of energy ✓, and N·m = J ✓. Sign is positive, so the force aids the motion.
  F = ( -1 ,  2 ,  3 ) N
  d = (  0 ,  0 ,  4 ) m        (constrained: only z can change)
      ----------------
  W = (-1)(0) + (2)(0) + (3)(4)
    =    0    +    0    +   12   =  12 J
⚡ JEE Trick When a body is constrained to one axis, don't compute the whole dot product — just read off that one component and multiply: W = Fz × dz = 3 × 4 = 12 J on sight. Perpendicular forces (and normal/constraint forces generally) never do work. Trap: the −1 N and +2 N are decoys designed to tempt you into adding them (−1+2+3 = 4, then ×4 = 16 J) — they multiply zero displacement, so they contribute nothing.
Answer: W = 12 J.
5A 2D vector with orthogonal components (P,Q) along x,y is replaced by another orthogonal pair (P′,Q′). Which statement is correct? (For a fixed resultant vector, its orthogonal rectangular components along fixed axes are unique)Uniqueness of rectangular resolutionHow To Find The Resultant of Two Vectors🟡 SimilarcFor a fixed resultant vector, its orthogonal rectangular components along fixed axes are unique.
Concept A vector can be split into components in infinitely many ways — but once you fix the two axes and demand the components be orthogonal and along those axes, the split becomes unique. Geometrically, dropping perpendiculars from the tip of the vector onto two fixed perpendicular axes lands on exactly one point on each axis; there is no freedom left. This uniqueness is the whole reason rectangular resolution is the standard tool in physics — every solver gets the same P and Q.
Formula For a resultant R = Pî + Qĵ along fixed axes: P = R·î = R·cosθ and Q = R·ĵ = R·sinθ, all in the same units as R (e.g. N for a force). The dot product with a fixed unit vector returns one definite number — a projection is single-valued, so P and Q cannot be anything else. Magnitude and direction: R = √(P² + Q²), θ = tan⁻¹(Q/P).
Solution
1. Fix the axes x and y, and let the vector be R with magnitude R at angle θ from +x.
2. Project onto each axis: P = R·î = R cosθ and Q = R·ĵ = R sinθ.A projection is computed by a dot product, and a dot product of two given vectors returns exactly one number — hence no ambiguity.
3. Since R and θ are fixed and the axes are fixed, cosθ and sinθ are fixed ⇒ P and Q are uniquely determined. This is option (c).
4. Kill option (a): P′² + Q′² = P² + Q² only fixes the magnitude √(P²+Q²), not the direction — e.g. (P,Q) = (3,4) N and (P′,Q′) = (4,3) N both give R = 5 N but point differently (53° vs 37°). So "guaranteed identical" is false.
5. Kill option (b): P′ = P, Q′ = −Q reflects the vector in the x-axis; it does not reverse it. Reversal needs both signs flipped: (3,4) → (3,−4) is a mirror image, whereas the reverse of (3,4) is (−3,−4). False.
6. Kill option (d): P′ = Q, Q′ = P swaps the components, which mirrors the vector about the 45° line — (3,4) N becomes (4,3) N, a genuinely different vector (unless P = Q). False.

⚡ JEE Trick A vector is fixed only when both magnitude AND direction match — any option that argues from magnitude alone (like P²+Q² being equal) is a trap. Test such statements instantly with the (3,4) → (4,3) counterexample: same magnitude 5, different direction. Answer: (c) For a fixed resultant vector, its orthogonal rectangular components along fixed axes are unique.

1Define scalar product of two vectors. State the characteristics of scalar product.Scalar (dot) product — definition & propertiesProperties of scalar or dot product | class 11th physics vector🟢 Exact—
Concept The scalar (dot) product multiplies two vectors to give a single number (a scalar), not a vector. It measures how much the two vectors point the same way: maximum when parallel, zero when perpendicular, negative when they oppose. This is the operation behind work (W = F·s), power, and flux. Trap in board answers: forgetting to state that the result is a scalar, or omitting the angle's role.
Formula A·B = |A||B|cosθ, where θ (0° ≤ θ ≤ 180°) is the angle between A and B when drawn tail-to-tail. |B|cosθ is the projection of B on A, so A·B = |A| × (projection of B on A) — a magnitude times a shadow, hence a pure number. Component form: A·B = AxBx + AyBy + AzBz.
Solution
1. Definition. The scalar product of A and B is A·B = |A||B|cosθ — the product of their magnitudes and the cosine of the angle between them.
2. Scalar result. The output is a scalar (a number with a unit but no direction), even though the inputs are vectors.
3. Commutative: A·B = B·A. cosθ is symmetric in the two vectors, so order does not matter.
4. Distributive over addition: A·(B+C) = A·B + A·C. And scalar-associative: (mA)·B = m(A·B).
5. Sign / special angles: positive for θ < 90°, zero for θ = 90° (perpendicular), negative for θ > 90°; A·A = |A|² (θ = 0°). Also î·î = ĵ·ĵ = k̂·k̂ = 1 and î·ĵ = ĵ·k̂ = k̂·î = 0.
  A.B = |A||B| cos t          (t = angle between them)
    t = 0    -> A.B = +|A||B|   (max, parallel)
    t = 90   -> A.B = 0         (perpendicular)     <-- key property
    t = 180  -> A.B = -|A||B|   (min, anti-parallel)
  Properties: commutative, distributive, scalar output, A.A = |A|^2
⚡ JEE Trick Remember the dot product by its physics job: work = force dotted with displacement, W = Fs cosθ — only the part of F along the motion counts. That single picture regenerates every property: it is a number (work is a scalar), it is zero when force ⊥ motion (no work), and it is order-free. Trap: writing the answer as a vector, or quoting A×B = |A||B|sinθ (that is the cross product) instead of cosθ.
Answer: A·B = |A||B|cosθ, a scalar; characteristics — commutative, distributive, scalar-valued, A·A = |A|², zero for perpendicular vectors, sign follows cosθ.
2Derive the expression for scalar product of two vectors in terms of their scalar components.Scalar product in component formDot Product Explained | Meaning and Formula (Class 11, NEET, JEE)🟢 Exact—
Concept To turn A·B = |A||B|cosθ into a component formula, write each vector in the î, ĵ, k̂ basis and expand the product term by term using the dot products of the unit vectors. Because the axes are mutually perpendicular, all the "cross" terms (î·ĵ, etc.) die and only the "like" terms survive. Trap: forgetting that î·ĵ = 0 and keeping mixed terms.
Formula Basis rules: î·î = ĵ·ĵ = k̂·k̂ = 1 (parallel, cos0° = 1) and î·ĵ = ĵ·k̂ = k̂·î = 0 (perpendicular, cos90° = 0). These nine dot products form an identity matrix — 1 on the diagonal, 0 off it — which is what collapses the expansion. Take A = Axî+Ayĵ+Azk̂, B = Bxî+Byĵ+Bzk̂.
Solution
1. Write the product: A·B = (Axî+Ayĵ+Azk̂)·(Bxî+Byĵ+Bzk̂).
2. Expand by distributivity into 9 terms: AxBx(î·î) + AxBy(î·ĵ) + AxBz(î·k̂) + AyBx(ĵ·î) + ... + AzBz(k̂·k̂).
3. Apply î·ĵ = ĵ·k̂ = k̂·î = 0 — the six mixed terms vanish.Each mixed unit-vector pair is perpendicular, so its dot product is cos90° = 0.
4. Apply î·î = ĵ·ĵ = k̂·k̂ = 1 to the three surviving diagonal terms: A·B = AxBx + AyBy + AzBz.
5. Consequence: |A| = √(A·A) = √(Ax²+Ay²+Az²), and cosθ = (AxBx+AyBy+AzBz)/(|A||B|).Setting B = A recovers the Pythagorean magnitude.
  A.B = sum over 9 unit-vector products
        i.i=j.j=k.k = 1   (diagonal, survive)
        i.j=j.k=k.i = 0   (mixed, vanish)
  =>  A.B = Ax Bx + Ay By + Az Bz         <-- component form
  and cos t = (Ax Bx + Ay By + Az Bz)/(|A||B|)
⚡ JEE Trick Memorise the collapse, not the 9-term expansion: perpendicular unit vectors kill their cross terms, so the dot product is just "multiply matching components and add." This is why A·B is computed in one line in every numerical problem. Trap: in a non-orthogonal or rotated basis the mixed terms do not vanish — the tidy sum AxBx+AyBy+AzBz relies on the axes being mutually perpendicular.
Answer: A·B = AxBx + AyBy + AzBz, obtained because î·î = ĵ·ĵ = k̂·k̂ = 1 and all mixed unit-vector dot products are 0.
3Write all the properties of dot product of two vectors.Properties of dot productProperties of dot product or scalar product of two vectors for class 11🟢 Exact—
Concept The dot product's properties all flow from one defining equation, A·B = |A||B|cosθ. Knowing them lets you simplify expressions, test perpendicularity, and extract magnitudes without geometry. A board answer should list the algebraic rules (commutative, distributive) and the geometric consequences (perpendicular ⇒ 0, self-dot ⇒ magnitude²). Trap: mixing in cross-product properties (anticommutativity, vector output).
Formula A·B = |A||B|cosθ = AxBx+AyBy+AzBz. The geometric form gives the angle-based properties; the component form gives the algebraic ones — together they cover every property below.
Solution
1. Scalar output: A·B is a number, not a vector.
2. Commutative: A·B = B·A. cosθ and componentwise multiplication are both symmetric.
3. Distributive over addition: A·(B+C) = A·B + A·C.
4. Scalar multiplication: (mA)·(nB) = mn(A·B) for scalars m, n.
5. Self-dot: A·A = |A|² (θ = 0°) ⇒ |A| = √(A·A).
6. Perpendicularity: A·B = 0 ⇔ A ⊥ B (for non-zero A, B), since cos90° = 0. Parallel: A·B = +|A||B|; anti-parallel: −|A||B|.
7. Unit vectors: î·î = ĵ·ĵ = k̂·k̂ = 1; î·ĵ = ĵ·k̂ = k̂·î = 0.
  1. scalar result           A.B = number
  2. commutative             A.B = B.A
  3. distributive            A.(B+C) = A.B + A.C
  4. scalar factors          (mA).(nB) = mn (A.B)
  5. self-dot                A.A = |A|^2
  6. perpendicular           A.B = 0  <=> A _|_ B     <-- key test
  7. basis                   i.i=1, i.j=0, ...
⚡ JEE Trick Two of these properties do the heavy lifting in exams: A·A = |A|² (find a magnitude or the angle-expansion |A+B|² = |A|² + |B|² + 2A·B) and A·B = 0 for perpendicular (solve for an unknown component). Trap: the dot product is commutative, but the cross product is anti-commutative (A×B = −B×A) and returns a vector — don't cross-contaminate the two lists on a board paper.
Answer: scalar-valued, commutative, distributive, scalar-factorable, A·A = |A|², A·B = 0 ⇔ A ⊥ B, and the standard î·ĵ = 0, î·î = 1 basis relations.
4What is the dot product of a vector with itself? (A·A = |A|²)Dot product of a vector with itselfDot Product of a Vector with Itself🟢 Exact—
Concept Dotting a vector with itself is the special case θ = 0° of A·B = |A||B|cosθ: a vector is perfectly parallel to itself, so the cosine is 1 and the product collapses to the square of the length. This is the bridge between the dot product and magnitude, used constantly to find |A| or to expand |A±B|². Trap: writing A·A = |A| (missing the square) or = A (a vector).
Formula A·A = |A||A|cos0° = |A|², and in components A·A = Ax²+Ay²+Az². cos0° = 1 because the angle a vector makes with itself is zero; the component form is just the Pythagorean sum of squares, i.e. the length squared.
Solution

2. cos0° = 1, so A·A = |A|·|A| = |A|².A vector is parallel to itself, hence zero angle, hence maximal (full) overlap.
3. Component check: A·A = AxAx+AyAy+AzAz = Ax²+Ay²+Az², which is exactly (√(Ax²+Ay²+Az²))² = |A|² ✓.
4. Therefore the magnitude is recovered as |A| = √(A·A) — the dot product's most-used side effect.
5. Worked example: A = 3î+4k̂ ⇒ A·A = 9+0+16 = 25 ⇒ |A| = √25 = 5. Also î·î = 1 (unit vector, |î|² = 1).

  component: A.A = Ax^2+Ay^2+Az^2 = |A|^2

Answer: A·A = |A|² (= Ax²+Ay²+Az²); it is the square of the vector's magnitude, so |A| = √(A·A).
5What is the dot product of two perpendicular vectors? (Zero)Perpendicular vectors → dot product = 0The Dot Product is Equal to Zero for Perpendicular Vectors🟢 Exact—
Concept Two non-zero vectors at right angles have no shared direction — neither casts any shadow on the other — so their dot product is exactly zero. This is the single most useful dot-product fact: it converts the geometric statement "perpendicular" into the algebraic equation A·B = 0, which you can solve. Trap: assuming the converse fails — for non-zero vectors, A·B = 0 guarantees perpendicularity, it is an if-and-only-if.
Formula A·B = |A||B|cos90° = 0. The projection of B on A is |B|cos90° = 0 — a perpendicular vector has zero component along the other, so the product of magnitude and (zero) projection is zero. Component test: AxBx+AyBy+AzBz = 0.
Solution
1. Perpendicular means θ = 90° between A and B drawn tail-to-tail.
2. Substitute into the definition: A·B = |A||B|cos90°.
3. cos90° = 0, so A·B = |A||B|·0 = 0, regardless of how big A and B are.The magnitudes are finite; it is the cosine that annihilates the product.
4. Converse (the useful direction): if A·B = 0 with A ≠ 0 and B ≠ 0, then cosθ = 0 ⇒ θ = 90° ⇒ A ⊥ B.
5. Worked test: A = 2î+3ĵ+8k̂, B = −4î+4ĵ+αk̂ are perpendicular ⇒ A·B = −8+12+8α = 0 ⇒ α = −½. Also basis check: î·ĵ = 0 ✓ (axes are perpendicular).
