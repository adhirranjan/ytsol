Concept An exponential equation whose right side is not a pure power of the base. 490 is 72×10, and the leftover factor 10 can never be written as a power of 7 — so the "make the bases equal" trick only takes us part of the way. The rest must be finished with a logarithm, which is exactly why the required answer has a log in it.
Formula ap/aq = ap−q to strip the 72, then ak = N ⟺ k·log a = log N. Taking log of both sides converts an unknown in the exponent into an unknown multiplied by a number. Also log 10 = 1 (base 10).
Solution
1. Factor the right side into a power of 7 times something else: 490 = 49 × 10 = 72 × 10.Pull out every factor of 7 you can — 490 = 2×5×7², so exactly two 7s come out.
2. Substitute: 73x+7 = 72 × 10.
3. Divide both sides by 72 and use the quotient law: 7(3x+7)−2 = 10 ⇒ 73x+5 = 10.
4. Take log (base 10) of both sides: (3x+5)·log 7 = log 10 = 1.log 10 = 1 because 101 = 10 — this is why base 10 is the convenient choice here.
5. Divide by log 7: 3x + 5 = 1/log 7.
6. Isolate 3x: 3x = (1/log 7) − 5.
7. Divide by 3: x = −5/3 + 1/(3 log 7).
8. Compare with the required shape x = p/3 + q/(3 log r): the first term −5/3 gives p = −5; the second term 1/(3 log 7) gives q = 1 and r = 7.Matching term by term — the constant fraction fixes p, the log term fixes q and r.
   7^(3x+7) = 490 = 7^2 . 10
   7^(3x+5) = 10
   (3x+5) log7 = log10 = 1
   3x + 5 = 1/log7
   x = -5/3 + 1/(3 log7)      ==>  p = -5,  q = 1,  r = 7
   numeric check: log7 = 0.8451 -> x = -1.6667 + 0.3944 = -1.2723
⚡ JEE Trick Always strip out the largest power of the base first, then log only the stubborn leftover. Choosing base-10 logs here is deliberate: it turns log 10 into the clean 1. Trap: jumping straight to logs on 73x+7 = 490 gives x = (log490/log7 − 7)/3 — correct, but it will not sit in the p, q, r template the question demands.
Answer: p = −5, q = 1, r = 7  (x = −5/3 + 1/(3 log 7) ≈ −1.272).

2. Rewrite the left side: 3·4x + (81·9x)/3 = 3·4x + 27·9x.
3. Rewrite the right side: 6·(4·4x) − (9·9x)/2 = 24·4x − 4.5·9x.
4. Bring all 9x terms left and all 4x terms right: 27·9x + 4.5·9x = 24·4x − 3·4x.

6. Divide both sides by 4x and by 31.5: 9x/4x = 21/31.5 = 2/3.21/31.5 = 42/63 = 2/3 on clearing the decimal.

4Match Column-I (4^(3x+2) < 64; (x+1)/(x−1) ≤ 1; 2^(x+1) ≥ 4^(2x−1); 2(1−x)+5 ≤ 3(2x−1)) with Column-II.Matching inequations with solution setsSolving exponential inequalities🟡 Similar(A)→(r), (B)→(p), (C)→(s), (D)→(q)
Concept Four one-line inequalities of three different flavours: two exponential ones (rewrite both sides to a common base, then compare indices — legal because the bases here exceed 1, so the direction of the inequality is preserved), one rational one (never cross-multiply by a variable of unknown sign — shift everything to one side instead), and one plain linear one.
Formula For a > 1: am < an ⟺ m < n (direction kept). For rational inequalities: move all terms to one side and combine into a single fraction. Cross-multiplying by (x−1) is invalid because its sign is unknown — it would flip the inequality when x < 1.
Solution
1. (A) 43x+2 < 64. Write 64 as a power of 4: 64 = 43.
2. So 43x+2 < 43; since base 4 > 1, compare indices directly: 3x + 2 < 3 ⇒ 3x < 1 ⇒ x < 1/3 ⇒ matches (r).
3. (B) (x+1)/(x−1) ≤ 1. Subtract 1 from both sides rather than cross-multiplying: (x+1)/(x−1) − 1 ≤ 0.
4. Combine over the common denominator: [(x+1) − (x−1)]/(x−1) ≤ 0 ⇒ 2/(x−1) ≤ 0 ⇒ matches (p).The numerator simplifies to x+1−x+1 = 2. (For the record this needs x−1 < 0, i.e. x < 1.)
5. (C) 2x+1 ≥ 42x−1. Put the right side in base 2: 42x−1 = (22)2x−1 = 24x−2.
6. Base 2 > 1, so compare indices: x + 1 ≥ 4x − 2 ⇒ 3 ≥ 3x ⇒ x ≤ 1 ⇒ matches (s).
7. (D) 2(1−x) + 5 ≤ 3(2x−1). Expand both sides: 2 − 2x + 5 ≤ 6x − 3 ⇒ 7 − 2x ≤ 6x − 3.
8. Collect x on one side and constants on the other: 7 + 3 ≤ 6x + 2x ⇒ 10 ≤ 8x ⇒ 5/4 ≤ x ⇒ matches (q).
 (A) 4^(3x+2) < 4^3      -> 3x+2 < 3     -> x < 1/3      -> (r)
 (B) (x+1)/(x-1) - 1 <= 0 -> 2/(x-1) <= 0                 -> (p)
 (C) 2^(x+1) >= 2^(4x-2) -> x+1 >= 4x-2  -> x <= 1        -> (s)
 (D) 7 - 2x <= 6x - 3    -> 10 <= 8x     -> x >= 5/4      -> (q)
⚡ JEE Trick Two reflexes worth burning in: (1) for am vs an, the inequality keeps its direction when a > 1 and flips when 0 < a < 1 — every option here has base > 1, so nothing flips; (2) for a rational inequality, never multiply across by a variable expression — subtract and combine into one fraction, exactly as (B) is designed to teach.
Answer: (A) → (r) x < 1/3; (B) → (p) 2/(x−1) ≤ 0; (C) → (s) x ≤ 1; (D) → (q) 5/4 ≤ x.
