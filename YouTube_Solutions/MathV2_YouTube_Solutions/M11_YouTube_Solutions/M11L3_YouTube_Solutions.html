Concept The tangent function repeats every π and takes each value exactly once inside a period, so tan mθ = tan nθ forces the two angles to differ by a whole multiple of π — nothing weaker. Solving that linear condition for θ leaves one value per integer k, and those values are equally spaced.
Formula tan A = tan B ⇔ A = kπ + B, k ∈ Z. The period of tan is π (not 2π), which is exactly why the spacing below comes out as π/(m − n).
Solution
1. Apply the rule: tan mθ = tan nθ ⇒ mθ = kπ + nθ, k ∈ Z.
2. Collect θ: (m − n)θ = kπ ⇒ θ = kπ/(m − n). The condition m ≠ n given in the question is precisely what makes this division legal.
3. Write the values out for k = 0, 1, 2, 3: 0, π/(m−n), 2π/(m−n), 3π/(m−n).
4. Consecutive terms differ by the constant π/(m − n), independent of k — the defining property of an arithmetic progression.
5. Test m = 3, n = 1: θ = kπ/2 gives 0, π/2, π, 3π/2, …, an A.P. of common difference π/2 (with π/2 and 3π/2 discarded, where tan is undefined). Values that make either tangent undefined are dropped, which deletes terms but never changes the spacing.
6. Hence the different values of θ always form an arithmetic progression with common difference π/(m − n).
  tan m.t = tan n.t
  m.t = k.pi + n.t          (tan has period pi)
  (m - n) t = k.pi
  t = k.pi/(m - n) ,  k = 0, 1, 2, 3, ...
      0 ,  d ,  2d ,  3d ,  ...     d = pi/(m - n)
  common difference d is constant  ->  A.P.
⚡ JEE Trick Every "same ratio on both sides" equation gives an A.P.: tan mθ = tan nθ and cos mθ = cos nθ give one family each, while sin mθ = sin nθ gives two interleaved A.P.s (from mθ = 2kπ + nθ and mθ = (2k+1)π − nθ). Read the common difference straight off the denominator instead of listing roots.

Concept Two equations must hold together, so write the general family of each and keep only the angles common to both. The sine family alternates (the (−1)n tag) while the tangent family does not, and that mismatch is what kills half of the sine family.
Formula sin x = sinα ⇒ x = nπ + (−1)nα, tan x = tanα ⇒ x = mπ + α. Sine repeats over 2π but is symmetric about π/2, whereas tangent repeats over π; only the 2π-shifted copies of α survive both.
Solution

2. Sine family, n odd (n = 2k+1): x = (2k+1)π − α.
3. Tangent family: x = mπ + α, i.e. α shifted by any multiple of π.
4. The even branch 2kπ + α is contained in the tangent family (take m = 2k), so it survives. Both conditions hold at exactly the same angle as α itself, one full turn at a time.
5. The odd branch would need (2k+1)π − α = mπ + α, i.e. 2α = jπ — true only for special α, not in general, so it is rejected.
6. Hence the common solution is x = 2nπ + α, which is option (c).

5. Divide: tan((α+β)/2) = [2b/(a+c)] ÷ [2a/(a+c)] = b/a — option (d).
6. Numerical check with a = 3, b = 4, c = 0: 3cos x + 4 sin x = 0 gives tan x = −3/4, so α ≈ 143.13° and β ≈ 323.13°; then (α+β)/2 = 233.13° and tan233.13° = 1.333 = 4/3 = b/a ✓. Choosing c = 0 makes the two roots easy to compute and confirms that c really drops out.
