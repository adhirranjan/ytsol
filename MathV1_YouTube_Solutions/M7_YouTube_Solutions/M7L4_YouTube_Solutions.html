1 (i)Fill in the blank: If −3x > 9, then x ______ −3 (relation sign).Sign flip when dividing by negativeFlip inequality sign when multiplying/dividing by a negative🟡 Similar<  (x < −3)
Concept A linear inequality behaves exactly like an equation under addition and subtraction, but multiplying or dividing both sides by a negative number reverses the direction of the inequality sign. That single rule is the whole content of this blank.
Formula if a < b and k < 0 then ka > kb. Dividing by −3 is multiplying by k = −1/3 < 0, so > becomes <.
Solution
1. Start with −3x > 9.We want x alone, so divide both sides by the coefficient −3.
2. Divide by −3 and flip the sign: x < 9/(−3) = −3.−3 is negative, so the inequality reverses.
3. Test a value from the claimed set: x = −4 satisfies x < −3, and −3(−4) = 12 > 9 ✓.A value on the correct side must satisfy the original inequality.
4. Counter-check the other side: x = 0 gives −3(0) = 0 > 9, which is false — so x > −3 is wrong.
  -3x > 9
  divide by -3   (negative => FLIP)
  x < -3          solution: (-inf, -3)
⚡ JEE Trick Never divide an inequality by a negative without flipping — and the fastest safety net is a test value. Pick any number from your answer set, plug it into the original, and if it fails your sign is backwards. Trap: treating −3x > 9 like −3x = 9 and writing x > −3.
Answer: x < −3.
1 (ii)If a < b and c < 0, then a/c ______ b/c.Inequality direction under negative divisionWhy the inequality sign flips when dividing by a negative🟡 Similar>  (a/c > b/c)
Concept The same sign-flip rule, now stated with symbols instead of numbers. Dividing an inequality by the negative quantity c reverses the order of the two sides.
Formula a < b, c < 0 ⇒ a/c > b/c. Dividing by c is multiplying by 1/c, and c < 0 ⇒ 1/c < 0.
Solution
1. Given a < b, rewrite it as a positive difference: b − a > 0.A true inequality restated as “the difference is positive”.
2. Divide that positive difference by c < 0: (b − a)/c < 0.positive ÷ negative = negative.
3. Split the fraction: b/c − a/c < 0 ⇒ b/c < a/c, i.e. a/c > b/c.
4. Sanity-check with numbers: a = 2, b = 6, c = −2. Then a/c = −1 and b/c = −3, and indeed −1 > −3 ✓.
⚡ JEE Trick Anything you can prove with a sign rule you can confirm in two seconds with small numbers (2, 6, −2). In an exam, test-numbers beat re-deriving the rule. Note c < 0 also guarantees c ≠ 0, so the division is always legal here.
Answer: a/c > b/c.

Concept The logarithm logax is defined as the inverse of the exponential ay. For that inverse to exist and be single-valued, the base a is boxed in on three sides: it must be positive, it must not be 0, and it must not be 1. Equivalently a ∈ (0,1) ∪ (1, ∞); separately the argument x must be > 0.
Formula logax = y ⇔ ay = x. Whatever a must satisfy is read off from requiring ay to sweep through every positive x exactly once.
Solution
1. a > 0 is forced: if a < 0 then a1/2 = √a is not real, so ay is undefined for most exponents.A usable base must return a real power for every real y.
2. a ≠ 0: 0y equals 0 (and is undefined for y ≤ 0), so it can never match a general x > 0.
3. a ≠ 1: 1y = 1 for every y, so log1x cannot be pinned to one value — the inverse collapses.This is the clause students most often forget.
4. Since ay > 0 for a > 0, the argument is restricted to x > 0.
5. Collecting the conditions: a is any positive real number with a ≠ 1, i.e. a ∈ (0,1) ∪ (1, ∞).

Concept Reciprocal-log inequalities are treacherous: never cross-multiply by log₄(…) blindly, because its sign is unknown. Instead fix the domain, then read off the sign of each side on each allowed interval — a negative number is automatically ≤ a positive one.
