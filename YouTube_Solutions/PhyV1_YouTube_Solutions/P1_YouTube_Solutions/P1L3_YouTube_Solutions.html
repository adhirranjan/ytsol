1A parabola y = x² + x + k passes through (1, 1). Value of k? (−1) (Level-1)Unknown coefficient via pointFind an unknown coefficient using a point on the curve · Unknown coefficients in a quadratic🟡 Similarc−1
Concept A curve's equation is a statement that is true for every point lying on it. So if the problem tells you a specific point lies on the parabola, that point's coordinates must satisfy the equation. Substituting them turns the two-variable curve equation into a single ordinary equation in the one unknown constant k, which we then solve. This "point on curve ⇒ substitute" idea is the workhorse behind almost every "find the unknown coefficient" question.
Formula Curve: y = x² + x + k. Condition for a point (x₀, y₀) to lie on it: y₀ = x₀² + x₀ + k. Here x and y are pure numbers (this is a mathematical-tools lesson, so the coordinates are dimensionless); in a physics application x and y would carry units and k would take the same unit as y. Given point: (x₀, y₀) = (1, 1).
Solution
1. Write the condition that (1, 1) lies on the curve — substitute x = 1 and y = 1 into y = x² + x + k:Every point on the curve must satisfy its equation, so this substitution is legitimate.
2. 1 = (1)² + (1) + k
3. Evaluate the known terms on the right: (1)² = 1, so the right side is 1 + 1 + k = 2 + k.Simple arithmetic — square first, then add.
4. So 1 = 2 + k.
5. Isolate k by subtracting 2 from both sides: k = 1 − 2 = −1.
6. Verify by putting k = −1 back into the curve: y = x² + x − 1. At x = 1: y = 1 + 1 − 1 = 1 ✓ — the point (1, 1) is recovered.

       (1, 1) on curve   ⇒ substitute x=1, y=1

   1 = 1² + 1 + k
   1 = 2 + k
   k = 1 - 2 = -1        <-- answer

   check:  y = x² + x - 1  at x=1  ->  1+1-1 = 1  ✓

One point gives one equation, so it pins down exactly one unknown — if a question hides two unknowns, expect two points. Faster still: k is the constant term, so k = y₀ − x₀² − x₀ = 1 − 1 − 1 = −1 in a single line. Trap: sign slips — subtract the whole bracket (2), not just the 1.
Answer: k = −1 (matches the printed value).

Concept Every circle equation is the distance formula with the root squared away: "the point (x, y) lies exactly r from the centre (h, k)" becomes (x − h)² + (y − k)² = r². Writing the equation is therefore pure substitution — the real skill is bookkeeping. Two habits carry all three parts: the standard form has minus signs built in, so a centre coordinate of −3 surfaces as (y + 3); and the right-hand side is r², never r, so a radius containing a root must be squared as a whole. Parts (iii) and (iv) add a twist — their radius is rigged to equal the centre's distance from the origin, which makes both circles pass through O. Part (ii) is skipped here: the linked video solves it exactly.
Formula (x − h)² + (y − k)² = r² for centre (h, k) and radius r. From d = √[(x − h)² + (y − k)²] = r, squaring both sides — valid because both sides are non-negative. Sign rule: centre k = −c ⇒ (y − (−c))² = (y + c)². Root rule: (√w)² = w. Origin test: a circle passes through (0, 0) exactly when h² + k² = r². Assumption for (iii): a, b real and not both zero, so r = √(a²+b²) > 0 gives a genuine circle. (Coordinates are pure grid units.)
Solution — part (i) centre (2, −3), r = 8
1. Identify the substitutions: h = 2, k = −3, r = 8.
2. Substitute into (x − h)² + (y − k)² = r²: (x − 2)² + (y − (−3))² = (8)².
3. Resolve the double negative: y − (−3) = y + 3, so the y-term is (y + 3)².Subtracting a negative is adding — a centre below the x-axis always shows up as a plus inside the bracket.
4. Square the radius: (8)² = 64.
5. So (i) is (x − 2)² + (y + 3)² = 64.
6. Expand as a check: x² − 4x + 4 + y² + 6y + 9 = 64 ⇒ x² + y² − 4x + 6y − 51 = 0.The constant is 4 + 9 − 64 = −51; it does not vanish, so this circle misses the origin.
7. Graph: centre (2, −3), r = 8 ⇒ x spans 2 − 8 = −6 to 2 + 8 = 10; y spans −3 − 8 = −11 to −3 + 8 = 5. The origin is √(2² + (−3)²) = √13 ≈ 3.61 from the centre, and 3.61 < 8, so O lies inside the circle.
Solution — part (iii) centre (a, b), r = √(a² + b²)
1. Identify the substitutions: h = a, k = b, r = √(a² + b²). Both coordinates are positive as written, so no sign flips arise.
2. Substitute into the standard form: (x − a)² + (y − b)² = (√(a² + b²))².
3. Square the radius — the square undoes the root exactly: (√(a² + b²))² = a² + b².Square the whole radius. You cannot split a root over a sum: √(a²+b²) is not a + b.
4. So (iii) is (x − a)² + (y − b)² = a² + b².
5. Expand to expose the structure: x² − 2ax + a² + y² − 2by + b² = a² + b².
6. The a² and b² cancel from both sides, leaving x² + y² − 2ax − 2by = 0.No constant term survives — the hallmark of a circle through the origin.
7. Apply the origin test: h² + k² = a² + b² and r² = a² + b² are equal, so the circle passes through the origin.Check directly: substituting (0, 0) gives (0 − a)² + (0 − b)² = a² + b² ✓, a true statement for every a, b.
8. Graph: a circle centred at (a, b) that touches the origin whatever a and b are — O and the far point (2a, 2b) are the two ends of a diameter.
Solution — part (iv) centre (0, −1), r = 1
1. Identify the substitutions: h = 0, k = −1, r = 1.
2. Substitute: (x − 0)² + (y − (−1))² = (1)².
3. Simplify the x-bracket: (x − 0)² = x².h = 0 puts the centre on the y-axis, so the x-term loses its bracket entirely.
4. Resolve the y-bracket: y − (−1) = y + 1 ⇒ (y + 1)². Square the radius: (1)² = 1.
5. So (iv) is x² + (y + 1)² = 1.
6. Expand as a check: x² + y² + 2y + 1 = 1 ⇒ x² + y² + 2y = 0.The 1 cancels from both sides — again no constant term, so this circle also passes through the origin.
7. Confirm with the origin test: h² + k² = 0² + (−1)² = 1, and r² = 1. Equal ⇒ passes through (0, 0) ✓.
8. Graph: a unit circle centred one unit below the origin — x spans −1 to 1, y spans −1 − 1 = −2 to −1 + 1 = 0. It touches the x-axis at the origin, its highest point.

3Plot the graph of: (i) y = 2x² (ii) s = 5t² (iii) s = −5t² (Level-3)Graphing y = ax²Graphing basic parabola y = x² · Parabolas — opening up and down🟡 Similar—
Concept All three curves have the form y = a·x² — a parabola with its vertex at the origin and the vertical axis as its axis of symmetry. Only the constant a changes, and a controls just two things: the direction of opening (a > 0 opens upward, a < 0 opens downward) and the narrowness (larger |a| ⇒ steeper, narrower). Physically (ii) and (iii) are displacement–time graphs for motion starting from rest under constant acceleration, s = ½at², so the shape carries real meaning: 5t² is free fall downward taken as positive, −5t² the same fall with "up" as positive.
Formula y = a·x² (vertex at origin, symmetric about the y-axis). Compare with kinematics s = u·t + ½·a·t²; with u = 0 this is s = ½·a·t². For (ii) s = 5t² m, matching ½a = 5 m s⁻², so a = 10 m s⁻² — free-fall g, downward positive. Units: s in metres (m), t in seconds (s), coefficient 5 in m s⁻². Assumption: for (i) x and y are dimensionless; for (ii)/(iii) motion starts from rest (u = 0) at the origin.
Solution
1. (i) y = 2x²: a = +2 > 0 ⇒ opens upward, vertex (0, 0), symmetric about the y-axis.A positive coefficient makes y positive for every x ≠ 0, so the curve lies above the vertex.
2. Tabulate (i): x = 0 ⇒ y = 2(0)² = 0; x = ±1 ⇒ y = 2(1) = 2; x = ±2 ⇒ y = 2(4) = 8.Equal y at ±x confirms the y-axis symmetry.
3. (ii) s = 5t²: a = +5 > 0 ⇒ opens upward. Only t ≥ 0 is physical (time cannot be negative), so draw the right-hand half.s = ½at² with ½a = 5 m s⁻² ⇒ a = 10 m s⁻²: a body dropped from rest.
4. Tabulate (ii): t = 0 s ⇒ s = 0 m; t = 1 s ⇒ s = 5(1)² = 5 m; t = 2 s ⇒ s = 5(4) = 20 m; t = 3 s ⇒ s = 5(9) = 45 m.Doubling t quadruples s — the signature of a t² law.
5. (iii) s = −5t²: a = −5 < 0 ⇒ opens downward — the mirror image of (ii) in the t-axis.Same magnitudes, opposite sign: the same fall with the upward direction chosen as positive.
6. Tabulate (iii): t = 1 s ⇒ s = −5 m; t = 2 s ⇒ s = −20 m; t = 3 s ⇒ s = −45 m.

4Parabola y = Ax² + Bx + C passes through origin. Find C (C = 0) (Level-4)y-intercept of parabola (= C)Finding the y-intercept of a parabola · Y-intercept of a parabola — 3 examples🟡 Similar0
Concept In the general parabola y = Ax² + Bx + C, the constant term C is the y-intercept — the value of y where the curve crosses the y-axis (x = 0). The reason is that setting x = 0 annihilates both the Ax² and the Bx terms, leaving y = C and nothing else. So "passes through the origin (0, 0)" is a direct statement about the y-intercept: the curve meets the y-axis at height 0, hence C = 0. Note A and B stay completely undetermined — one point can only fix one constant.
Formula y = Ax² + Bx + C; y-intercept found by putting x = 0 ⇒ y = C. Any term carrying a factor of x vanishes at x = 0, so only the constant survives — C is literally the height of the curve on the y-axis. The origin is the point (x₀, y₀) = (0, 0). (x, y here are dimensionless coordinates; in a physical s–t parabola C would be the initial displacement s₀, in metres.)
Solution
1. "Passes through the origin" means the point (0, 0) lies on the curve, so its coordinates must satisfy the equation.Every point on a curve satisfies the curve's equation — that is what the equation means.
2. Substitute x = 0 and y = 0 into y = Ax² + Bx + C:
3. 0 = A(0)² + B(0) + C
4. Evaluate each term: A(0)² = A × 0 = 0, and B(0) = 0.Anything multiplied by zero is zero, whatever A and B are — this is why A and B drop out entirely.
5. The equation collapses to 0 = 0 + 0 + C, i.e. C = 0.
6. Note what is not determined: A and B remain arbitrary. One point ⇒ one equation ⇒ one constant fixed.Any parabola y = Ax² + Bx passes through the origin, no matter what A and B are.

⚡ JEE Trick Memorise the mapping in y = Ax² + Bx + C: C = y-intercept (value at x = 0), and the sign of A = direction of opening. So "through the origin" ⇒ C = 0 on sight, with no algebra at all. Same idea in kinematics: s = ut + ½at² has no constant term precisely because motion starts at s = 0. Trap: don't try to find A and B — a single point cannot fix three constants; you would need three points.

5Distance between centres of circles x² + y² = 4² and (x−2)² + (y+3)² = 16 (√13) (Level-5)Centres + distance formulaFind the center and radius of a circle · Distance between two points🟡 Similara√13
Concept This is a two-stage problem: first read each centre off the standard form of a circle, then apply the distance formula to those two centres. The standard form (x − h)² + (y − k)² = r² is built so that the centre (h, k) can be read directly — but you must respect the minus signs built into the form: (y + 3)² is really (y − (−3))², so the y-coordinate of the centre is −3, not +3. The radii (4 and 4) are given but are complete red herrings here: the distance between centres depends only on the centres.
Formula Standard circle: (x − h)² + (y − k)² = r² ⇒ centre (h, k), radius r. Distance between two points: d = √[(x₂ − x₁)² + (y₂ − y₁)²]. This is just Pythagoras' theorem on the right triangle whose legs are the horizontal and vertical separations — the distance is the hypotenuse. Coordinates here are plain numbers (unitless); if they were in metres, d would come out in metres.
Solution
1. Circle 1: x² + y² = 4². Write it in standard form: (x − 0)² + (y − 0)² = 4².No shift is subtracted from x or y, so the circle is centred at the origin.
2. Read off circle 1: centre C₁ = (0, 0), radius r₁ = 4.
3. Circle 2: (x − 2)² + (y + 3)² = 16. Rewrite the y-term with an explicit minus: (x − 2)² + (y − (−3))² = 4².Matching the form (y − k)² forces k = −3; the "+3" on the page means the centre sits below the x-axis.
4. Read off circle 2: centre C₂ = (2, −3), radius r₂ = √16 = 4.
5. Apply the distance formula to C₁(0, 0) and C₂(2, −3) — substitute x₁ = 0, y₁ = 0, x₂ = 2, y₂ = −3:
6. d = √[(2 − 0)² + (−3 − 0)²]
7. Evaluate the brackets: (2 − 0) = 2 and (−3 − 0) = −3, so d = √[(2)² + (−3)²].
8. Square each: (2)² = 4 and (−3)² = +9.Squaring kills the sign — a negative separation contributes just as much length as a positive one, which is why direction never matters for a distance.
9. Add: d = √(4 + 9) = √13.
10. Numerically d = √13 ≈ 3.61 units. Sanity check: 3.61 < r₁ + r₂ = 8, and 3.61 > |r₁ − r₂| = 0, so the two equal circles overlap — consistent with centres this close.

1Which is the general equation of parabola? (y = Ax² + Bx + C)Identifying conic equationsIdentify circle, parabola, ellipse & hyperbola · Parabola, circle, ellipse or hyperbola?🟡 Similaray = Ax² + Bx + C
Concept Conic sections are told apart by which variables are squared and how they combine. A parabola is the conic in which exactly one of the two variables is squared — the other appears to the first power only. That single squared variable is what bends the curve while the linear variable runs off without bound, giving the familiar open U shape. Recognising this pattern by inspection matters in physics, because s = ut + ½at² has exactly this form, so every uniformly-accelerated s–t graph is a parabola.
Formula General parabola (vertical axis): y = Ax² + Bx + C, with A ≠ 0 — x is squared, y is not. A ≠ 0 is essential: if A = 0 the x² term disappears and y = Bx + C is a straight line, not a parabola. Contrast: circle x² + y² = r² (both squared, equal coefficients, added); ellipse x²/a² + y²/b² = 1 (both squared, unequal coefficients, added); hyperbola x²/a² − y²/b² = 1 (both squared, subtracted).
Solution
1. Apply the identifying test — count the squared variables in each candidate form.The count and the sign pattern uniquely name every conic, so this one test settles the question.
2. y = Ax² + Bx + C: x appears squared, y appears only to the first power ⇒ exactly one squared variable ⇒ parabola ✓
3. Rule out x² + y² = r²: both x and y squared, added with equal coefficients ⇒ circle ✗
4. Rule out x²/a² + y²/b² = 1: both squared and added, but with unequal coefficients ⇒ ellipse ✗
5. Rule out x²/a² − y²/b² = 1: both squared but subtracted ⇒ hyperbola ✗
6. Confirm the shape: A ≠ 0 makes the curve bend; y is unbounded as x grows, so it opens without closing — the parabola's signature.Closed curves (circle, ellipse) need both variables squared and added, which bounds them.

Concept Classify a relation by which variables are squared, not by the letters used. In S = ut + ½at² the two variables are S (displacement) and t (time); the constants u and a are just fixed numbers for a given motion. Because t appears squared while S appears only to the first power, this is exactly the shape "one variable squared, the other linear" — the signature of a parabola. The kinematics dressing (u, a, t, S) is a disguise; strip it and the curve is the same y = Ax² + Bx + C you met in coordinate geometry.
Formula Standard parabola: y = Ax² + Bx + C (A ≠ 0) — one variable squared, one linear. Exactly one squared variable ⇒ parabola; both squared & added ⇒ circle/ellipse; both squared & subtracted ⇒ hyperbola. Map the physics onto it: S ↔ y, t ↔ x, A = ½a, B = u, C = 0. Data: u = initial velocity, a = constant acceleration (both fixed), motion starts at S = 0 when t = 0.
Solution
1. Treat u and a as constants and identify the variables: S and t. Rewrite S = (½a)t² + (u)t + 0 to expose the structure.Grouping the coefficients shows a quadratic in t — the same template as y = Ax² + Bx + C.
2. Compare term-by-term: coefficient of t² is A = ½a, of t is B = u, constant C = 0.

4. Count squared variables: t is squared, S is first-power ⇒ exactly one squared variable ⇒ the S–t graph is a parabola.
5. Sanity check with u = 0, a = 2: S = t² gives (t, S) = (0,0), (1,1), (2,4), (3,9) — the classic upward parabola, confirming the shape.
