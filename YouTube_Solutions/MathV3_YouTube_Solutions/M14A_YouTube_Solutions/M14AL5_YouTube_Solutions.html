Concept Every line that passes through the common point of two given lines L1 = 0 and L2 = 0 can be captured by a single equation with one free number in it. That number tunes the direction of the line while the point it passes through stays fixed, so the one equation stands for the whole bundle (the pencil) of lines through that corner.
Formula L1 + λL2 = 0, λ any real number. It is linear in x and y, so for each λ it is a straight line; and it is satisfied by the intersection point for every λ.
Solution
1. Let P be the point where L1 = 0 and L2 = 0 meet, so at P both L1 = 0 and L2 = 0.
2. Build the combination L1 + λL2 = 0. At P it reads 0 + λ·0 = 0, which is true. So P lies on it no matter what λ is.
3. For each fixed λ the equation is of first degree in x, y, hence a straight line through P.
4. As λ runs over all reals the slope changes, so the one formula sweeps every line through P.
5. The single missing member is L2 = 0 itself, recovered as the λ → ∞ limit.
6. Hence the family of lines through the intersection is L1 + λL2 = 0.
  at P:  L1 = 0  and  L2 = 0
  L1 + k*L2 = 0  ->  0 + k*0 = 0  (true for all k)
  each k -> one line through P
  k -> infinity recovers L2 = 0
⚡ JEE Trick Never solve for the intersection point first. Just write L1 + λL2 = 0 and pin λ from the one extra condition (a point, a slope, perpendicularity). It skips finding the corner entirely.

6If t1, t2 are roots of the equation t2 + λt + 1 = 0, where λ is an arbitrary constant, then the line joining the points (at12, 2at1) and (at22, 2at2) always passes through the fixed point: (a) (−a, 0) (b) (0, a) (c) (a, 0) (d) (0, −a)Chord of the parabola y2 = 4ax through a fixed pointEquation of the chord joining points t1 and t2 on the parabola y^2 = 4ax🟡 Similara(−a, 0)
Concept The points (at1², 2at1) and (at2², 2at2) are the standard parametric points of the parabola y² = 4ax. The chord joining two such parameters has a known equation in t1 + t2 and t1t2, and those two symmetric sums come straight from the quadratic the parameters satisfy — so λ disappears and a fixed point emerges.
Formula chord of y² = 4ax: 2x − (t1 + t2)y + 2a t1t2 = 0; for t² + λt + 1 = 0, t1 + t2 = −λ, t1t2 = 1. Sum and product of roots are read off a monic quadratic as −(coeff of t) and the constant.
Solution
1. The two points lie on y² = 4ax with parameters t1, t2.
2. Chord through them: 2x − (t1 + t2)y + 2a t1t2 = 0.
3. From t² + λt + 1 = 0: t1 + t2 = −λ and t1t2 = 1.
4. Substitute: 2x − (−λ)y + 2a(1) = 0 ⇒ 2x + λy + 2a = 0.
5. This must hold for every λ, so the coefficient of λ vanishes: y = 0.
6. With y = 0, 2x + 2a = 0 ⇒ x = −a. Fixed point (−a, 0), option (a).
  chord: 2x - (t1+t2)y + 2a t1 t2 = 0
  t1+t2 = -lambda ,  t1 t2 = 1
  2x + lambda y + 2a = 0  (all lambda)
  y = 0, x = -a  ->  (-a, 0)
⚡ JEE Trick A λ-family passing through a fixed point means grouping terms as (something) + λ(something) = 0 and setting each bracket to zero. Here recognising the two points as parabola parameters and using Vieta’s sum/product turns a hard “fixed point” question into reading off the coefficient of λ.
Answer: (−a, 0) (option a).
7If non-zero numbers a, b, c are in H.P., then the straight line x/a + y/b + 1/c = 0 always passes through a fixed point. That point is: (a) (−1, −2) (b) (−1, 2) (c) (1, −1/2) (d) (1, −2) [JEE Main 2005]
📝 PYQ: AIEEE 2005Solution ↗
Fixed point from an H.P. conditionIf a, b, c are in H.P. the line x/a + y/b + 1/c = 0 passes through a fixed point (JEE)🟢 Exactd(1, −2)
Concept If a, b, c are in harmonic progression then their reciprocals 1/a, 1/b, 1/c are in arithmetic progression. The AP condition ties the three reciprocals by a single linear relation, and comparing that relation with the given line x/a + y/b + 1/c = 0 reveals the (x, y) that satisfies it no matter what a, b, c are — the fixed point. [JEE Main 2005]
Formula HP ⇒ 1/a, 1/b, 1/c in AP ⇒ 2/b = 1/a + 1/c, i.e. 1/a − 2/b + 1/c = 0. The middle term of an AP is the average of its neighbours, so twice it equals their sum.
Solution
1. a, b, c in HP ⇒ 1/a, 1/b, 1/c in AP.
2. AP middle-term condition: 2/b = 1/a + 1/c.
3. Rearrange to zero: 1/a − 2/b + 1/c = 0.
4. Compare with the line x/a + y/b + 1/c = 0, matching coefficient by coefficient.
5. Coefficient of 1/a: x = 1. Coefficient of 1/b: y = −2. Constant 1/c matches 1/c.
6. These values satisfy the line for all HP triples, so the fixed point is (1, −2), option (d).
  HP -> 1/a,1/b,1/c in AP -> 2/b = 1/a + 1/c
  so  1/a - 2/b + 1/c = 0
  line x/a + y/b + 1/c = 0
  match: x = 1 , y = -2  ->  (1, -2)
⚡ JEE Trick Turn a progression condition into a linear identity in the reciprocals, then line it up term-by-term against the given equation. The coefficients that make the two identical are exactly the fixed point — no need to pick sample values of a, b, c. HP always means “flip to AP first”, and once in AP the single relation 2/b = 1/a + 1/c does all the work; this is why option (d) falls out with no arithmetic.
Answer: (1, −2) (option d).
8Let ax + by + c = 0 be a variable straight line, where a, b and c are the 1st, 3rd and 7th terms of an increasing A.P., respectively. Prove that the variable straight line always passes through a fixed point and find that point.Fixed point from an A.P. conditionVariable line with coefficients satisfying a condition passes through a fixed point🟡 Similar(2, −3)
Concept The coefficients a, b, c of the variable line are the 1st, 3rd and 7th terms of an increasing arithmetic progression, so each is a linear expression in the first term A and the common difference d. Substituting and regrouping the line by A and by d shows it is a combination of two fixed lines, and their intersection is the point every such line passes through.
Formula AP terms a = A, b = A + 2d, c = A + 6d (d > 0); group the line as A(·) + d(·) = 0. The n-th term of an AP is A + (n − 1)d, so the 3rd and 7th add 2d and 6d.
Solution
1. Write a = A, b = A + 2d, c = A + 6d with A the first term, d > 0 the common difference.
2. Line: A x + (A + 2d)y + (A + 6d) = 0.
3. Collect A and d: A(x + y + 1) + d(2y + 6) = 0.
4. This holds for every choice of A and d, so each bracket must vanish independently.
5. 2y + 6 = 0 ⇒ y = −3; then x + y + 1 = 0 ⇒ x = −y − 1 = 2.
6. Every line of the family passes through (2, −3). Hence the fixed point is proved and equals (2, −3).
  a=A, b=A+2d, c=A+6d
  Ax + (A+2d)y + (A+6d) = 0
  A(x+y+1) + d(2y+6) = 0  (all A, d)
  2y+6=0 -> y=-3 ; x+y+1=0 -> x=2
⚡ JEE Trick Two independent parameters (here A and d) means the line is a blend of two fixed lines; grouping by each parameter and setting both brackets to zero gives their common point. You never need the actual values of A or d — the increasing condition d > 0 only guarantees the terms are genuinely distinct and the line truly varies.
Answer: fixed point (2, −3).
9Lines L1: y − x = 0 and L2: 2x + y = 0 intersect the line L3: y + 2 = 0 at P and Q, respectively. The bisector of the acute angle between L1 and L2 intersects L3 at R. Statement-1: The ratio PR : RQ equals 2√2 : √5. Statement-2: In any triangle, the bisector of an angle divides the triangle into two similar triangles. (a) Statement-1 is true, Statement-2 is false (b) Statement-1 is false, Statement-2 is true (c) Statement-1 is true, Statement-2 is true; Statement-2 is a correct explanation for Statement-1 (d) Statement-1 is true, Statement-2 is true; Statement-2 is not a correct explanation for Statement-1
📝 PYQ: IIT-JEE 2007 · Paper 2Solution ↗
Angle-bisector theorem (assertion–reason)Angle bisector of a triangle divides the opposite side in the ratio of the adjacent sides🟡 SimilaraStatement-1 is true, Statement-2 is false
Concept Lines L1: y − x = 0 and L2: 2x + y = 0 both pass through the origin O, and they cut the line L3: y + 2 = 0 at P and Q. The bisector of the angle at O meets PQ at R. The angle-bisector theorem then fixes the ratio PR:RQ as OP:OQ, which we test against Statement-1; Statement-2 is a general geometric claim to judge on its own.
Formula angle-bisector theorem: PR/RQ = OP/OQ. The bisector from a vertex divides the opposite side in the ratio of the two sides enclosing that vertex.
Solution
1. P = L1 ∩ L3: y = x and y = −2 give P(−2, −2).
2. Q = L2 ∩ L3: 2x + y = 0 with y = −2 gives x = 1, so Q(1, −2).
3. L1 and L2 meet at O(0, 0); triangle OPQ has its vertex O bisected, with R on PQ.
4. OP = √(2² + 2²) = 2√2; OQ = √(1² + 2²) = √5.
5. By the bisector theorem PR:RQ = OP:OQ = 2√2 : √5, so Statement-1 is true.
6. Statement-2 claims a bisector splits a triangle into two similar triangles — false in general (the two sub-triangles share the bisector but are not similar). So S1 true, S2 false: option (a).
  P(-2,-2) , Q(1,-2) , O(0,0)
  OP = sqrt(4+4) = 2 sqrt2
  OQ = sqrt(1+4) = sqrt5
  PR:RQ = OP:OQ = 2 sqrt2 : sqrt5
⚡ JEE Trick In assertion-reason items, verify each statement separately before deciding if one explains the other. Statement-1 here is a direct angle-bisector-theorem ratio; Statement-2 is a sweeping “always similar” claim, and sweeping claims usually fail — a bisector gives equal angles but not the proportional sides similarity demands.
Answer: Statement-1 is true, Statement-2 is false (option a).
10A ray of light is sent along the line x − 2y − 3 = 0. Upon reaching the line 3x − 2y − 5 = 0, the ray is reflected from it. Then: (a) the equation of the reflected ray must be of the form x − 2y − 3 + λ(3x − 2y − 5) = 0 (b) the equation of the reflected ray must be 29x − 2y − 33 = 0 (c) the equation of the reflected ray must be 29x − 2y − 31 = 0 (d) the equation of the reflected ray must be x + 2y = 0 (Multiple Correct)Reflection of a ray; family of lines through the point of incidenceMirror image of a straight line with respect to another line (reflection, proof)🟡 Similar(a), (c)
Concept An incident ray along x − 2y − 3 = 0 strikes the mirror line 3x − 2y − 5 = 0. Both the incident and the reflected ray pass through the point of incidence M, where the two lines cross. Any line through M can be written in the family (incident) + λ(mirror) = 0, so the reflected ray belongs to that family; then we test which explicit option also passes through M.
Formula family through M: x − 2y − 3 + λ(3x − 2y − 5) = 0; a line fits only if M satisfies it. Every member of this pencil already passes through the intersection M, which is what both rays share.
Solution
1. Point of incidence M = intersection of x − 2y − 3 = 0 and 3x − 2y − 5 = 0.
2. Subtract the first from the second: 2x − 2 = 0 ⇒ x = 1; then y = (x − 3)/2 = −1, so M(1, −1).
3. The reflected ray passes through M, so it lies in the family x − 2y − 3 + λ(3x − 2y − 5) = 0: option (a) is true.
4. Test (c) 29x − 2y − 31 at M: 29(1) − 2(−1) − 31 = 29 + 2 − 31 = 0. ✓ passes.
5. Test (b) 29x − 2y − 33 at M: 29 + 2 − 33 = −2 ≠ 0; test (d) x + 2y at M: 1 − 2 = −1 ≠ 0. Both fail.
6. So the valid statements are the family form (a) and the explicit reflected ray (c).
  M: (3x-2y-5) - (x-2y-3) = 2x - 2 = 0 -> x=1
     y = (x-3)/2 = -1   ->  M(1,-1)
  (c): 29(1) -2(-1) -31 = 0  (pass)
  (b): -2 (fail) , (d): -1 (fail)
⚡ JEE Trick You rarely need the true reflection angle: the reflected ray must pass through the point where the incident ray hits the mirror, so test every candidate line at that single point M. The pencil (incident) + λ(mirror) = 0 captures all lines through M, which is why option (a) is automatically correct.
Answer: (a) and (c).
