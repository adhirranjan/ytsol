1In a G.P., if the product of the first three terms is 27 and the set of all possible values for the sum of its first three terms is R − (a, b), then a² + b² is equal to ______.   [JEE Main 2026, 28 Jan Shift-1]Range of a + 1/a excluded intervalThe sum of the first three terms of a G.P. is S and their product is 27 — then S lies in …🟢 Exact90
Concept Symmetric labelling turns the product condition into a single value for the middle term, and the sum into 3 + 3(r + 1/r). Since r + 1/r never lies strictly between −2 and 2, the sum misses an open interval — and that interval is (a, b).
Formula product = a³ = 27; r + 1/r ∈ (−∞, −2] ∪ [2, ∞)
Solution
1. Take the three terms as a/r, a, ar. Their product is a³ = 27 ⇒ the middle term is 3.
2. Their sum is S = 3(1/r + 1 + r) = 3 + 3(r + 1/r).
3. For real r ≠ 0, r + 1/r ≥ 2 (when r > 0) or ≤ −2 (when r < 0) — it never lands in (−2, 2).
4. So 3(r + 1/r) ∈ (−∞, −6] ∪ [6, ∞), and therefore S ∈ (−∞, −3] ∪ [9, ∞).
5. The set of attainable sums is R minus the open interval (−3, 9), so a = −3 and b = 9.
6. Hence a² + b² = 9 + 81 = 90.
   a/r, a, ar   ->   a^3 = 27  ->  a = 3
   S = 3 + 3(r + 1/r)

   r + 1/r  never in (-2, 2)
   =>  S never in (-3, 9)      ->  R - (-3, 9)

   a^2 + b^2 = 9 + 81 = 90
⚡ JEE Trick The fact that r + 1/r avoids (−2, 2) is the single most reused inequality in this chapter — it drives this question, LEVEL-6 Q8 and Q9 of M-8B L-1, and every "complete interval" G.P. problem. Endpoints are attained (at r = ±1), which is why the excluded interval here is open, not closed.
Answer: 90  (a = −3, b = 9).
2Let 729, 81, 9, 1, …… be a sequence and Pn denote the product of the first n terms of this sequence. If 2Σn=140(Pn)1/n = (3α − 1)/3β and gcd(α, β) = 1, then α + β is equal to   (a) 76   (b) 74   (c) 75   (d) 73   [JEE Main 2026, 24 Jan Shift-1]Product of a G.P., then a second G.P.JEE Main PYQ — sequence and series, Class 11🟡 Similard73
Concept Write every term as a power of 3. The product Pn then has an exponent that is a sum of an A.P., and taking the nth root divides it by n — leaving a clean linear exponent, so (Pn)1/n is itself a G.P.
Formula an = 38−2n; Pn = 37n−n² ⇒ (Pn)1/n = 37−n
Solution
1. The sequence 729, 81, 9, 1 is 3⁶, 3⁴, 3², 3⁰ — so an = 38−2n.
2. Product: Pn = 3Σ(8−2k) = 38n − n(n+1) = 37n − n².
3. Take the nth root: (Pn)1/n = 37−n — a G.P. with first term 3⁶ and ratio 1/3.
4. Sum 40 terms: Σ = 3⁶(1 − 3−40)/(1 − 1/3) = (3⁷/2)(1 − 3−40) = (3⁴⁰ − 1)/(2·3³³).
5. Doubling: 2Σ = (3⁴⁰ − 1)/3³³, so α = 40 and β = 33 (gcd = 1 ✓).
6. Therefore α + β = 73 → option (d).
   a_n = 3^(8-2n)
   P_n = 3^(8n - n(n+1)) = 3^(7n - n^2)
   (P_n)^(1/n) = 3^(7-n)          G.P., a = 3^6, r = 1/3

   Sum(40) = (3^7/2)(1 - 3^-40) = (3^40 - 1)/(2 * 3^33)
   2 x Sum = (3^40 - 1)/3^33      ->  alpha=40, beta=33
   alpha + beta = 73
⚡ JEE Trick The move that makes this tractable is taking the nth root of a product: the exponent 7n − n² divided by n becomes 7 − n, converting a quadratic exponent into a linear one — i.e. a product of a G.P. becomes another G.P. once you take the geometric mean. Expect that whenever "Pn" and "(·)1/n" appear together.
Answer: (d) 73  (α = 40, β = 33).
3Let a₁, a₂, a₃, … be a G.P. of increasing positive terms such that a₂·a₃·a₄ = 64 and a₁ + a₃ + a₅ = 813/7. Then a₃ + a₅ + a₇ is equal to:   (a) 3248   (b) 3244   (c) 3252   (d) 3256   [JEE Main 2026, 21 Jan Shift-1]Middle-term product, then scale by r²JEE Mains previous year questions — geometric progression problem🟡 Similarc3252  ⚠
Concept Three consecutive terms multiply to the cube of the middle one, so a₃ falls out at once. The two requested sums are separated by two positions, so the second is just r² times the first — no need to find a₇ individually.
Formula a₂a₃a₄ = a₃³; a₃ + a₅ + a₇ = r²(a₁ + a₃ + a₅)
Solution
1. a₂a₃a₄ = a₃³ = 64 ⇒ a₃ = 4.
2. a₁ + a₃ + a₅ = a₃(1/r² + 1 + r²) = 4(1/r² + 1 + r²) = 813/7.
3. So 1/r² + r² = 813/28 − 1 = 785/28. With u = r²: 28u² − 785u + 28 = 0.
4. Discriminant = 785² − 4(28²) = 616225 − 3136 = 613089 = 783². So u = (785 ± 783)/56 = 28 or 1/28. Increasing terms ⇒ r² = 28.
5. Now a₃ + a₅ + a₇ = r²(a₁ + a₃ + a₅) = 28 × 813/7 = 4 × 813 = 3252 → option (c).
6. Direct check: a₃ = 4, a₅ = 4(28) = 112, a₇ = 4(784) = 3136, and 4 + 112 + 3136 = 3252 ✓. The printed key (b) 3244 does not match.
   a3^3 = 64  ->  a3 = 4
   4(1/r^2 + 1 + r^2) = 813/7  ->  r^2 = 28

   a3 + a5 + a7 = r^2 (a1 + a3 + a5) = 28 x 813/7 = 3252
   direct : 4 + 112 + 3136 = 3252
⚡ JEE Trick Notice the shortcut: the requested sum is the given sum shifted by two positions, so it is simply r² times it — 28 × 813/7 cancels beautifully to 4 × 813. Spotting that saves computing a₇ = 3136 and makes the arithmetic exact rather than approximate.
Answer: (c) 3252. ⚠ (key prints (b) 3244)
4Let a₁, a₂, a₃, …… be a G.P. of increasing positive terms. If a₁a₅ = 28 and a₂ + a₄ = 29, then a₆ is equal to:   (a) 628   (b) 812   (c) 526   (d) 784   [JEE Main 2025, 22 Jan Shift-1]Equidistant products give a quadraticArithmetic and Geometric Progression — JEE Main/Advanced🟡 Similard784
Concept a₁a₅ and a₂a₄ are both equal to a₃², so the given product tells you a₂a₄ as well. Knowing a₂ + a₄ and a₂a₄ makes a₂ and a₄ the roots of a simple quadratic.
Formula a₁a₅ = a₂a₄ = a₃²; then t² − 29t + 28 = 0
Solution
1. Equidistant pairs about a₃: a₁a₅ = a₃² = 28, and a₂a₄ = a₃² = 28 too.
2. So a₂ and a₄ satisfy a₂ + a₄ = 29 and a₂a₄ = 28 — the roots of t² − 29t + 28 = 0.
3. Factor: (t − 1)(t − 28) = 0 ⇒ t = 1 or 28. Increasing terms ⇒ a₂ = 1, a₄ = 28.
4. Since a₄ = a₂r², r² = 28 ⇒ r = 2√7.
5. Then a₆ = a₄·r² = 28 × 28 = 784 → option (d).
6. Check: a₁ = a₂/r = 1/(2√7), a₅ = a₄r = 56√7, and a₁a₅ = 56√7/(2√7) = 28 ✓.
   a1 a5 = a2 a4 = a3^2 = 28
   a2 + a4 = 29 ,  a2 a4 = 28
   t^2 - 29t + 28 = 0  ->  t = 1, 28

   increasing : a2 = 1, a4 = 28  ->  r^2 = 28
   a6 = a4 r^2 = 28 x 28 = 784
⚡ JEE Trick When you know the sum and product of two terms, they are roots of t² − (sum)t + (product) = 0 — no need for simultaneous equations in a and r. And here the equidistant rule silently converts the given a₁a₅ into the a₂a₄ you actually need. Stepping a₄ → a₆ by r² then avoids ever computing r itself.
Answer: (d) 784.
5Let the first three terms 2, p and q, with q ≠ 2, of a G.P. be respectively the 7th, 8th and 13th terms of an A.P. If the 5th term of the G.P. is the nth term of the A.P., then n is equal to:   (a) 163   (b) 151   (c) 177   (d) 169   [JEE Main 2024, 4 Apr Shift-1]A G.P. embedded in an A.P.JEE One Shot — Arithmetic & Geometric Progression, complete revision🟡 Similara163
Concept Express p and q through the A.P.'s common difference D, then impose the single G.P. condition p² = 2q. The condition q ≠ 2 exists precisely to discard the degenerate root D = 0.
Formula t₇ = 2, t₈ = 2 + D, t₁₃ = 2 + 6D; G.P. condition p² = 2q
Solution
1. Let the A.P. have common difference D. From t₇ = 2: p = t₈ = 2 + D and q = t₁₃ = 2 + 6D.
2. G.P. condition: p² = 2q ⇒ (2 + D)² = 2(2 + 6D) ⇒ 4 + 4D + D² = 4 + 12D.
3. So D² − 8D = 0 ⇒ D = 0 or D = 8. D = 0 gives q = 2, excluded ⇒ D = 8.
4. Then p = 10, q = 50, and the G.P. 2, 10, 50 has ratio 5. Its 5th term is 2 × 5⁴ = 1250.
5. The A.P.'s first term: A + 6(8) = 2 ⇒ A = −46. Setting −46 + (n−1)(8) = 1250 gives 8(n−1) = 1296.
6. So n − 1 = 162 ⇒ n = 163 → option (a).
   p = 2 + D ,  q = 2 + 6D
   p^2 = 2q :  D^2 - 8D = 0  ->  D = 8  (D = 0 excluded by q != 2)

   G.P. 2, 10, 50  (r = 5) ;  5th term = 2 x 5^4 = 1250
   A.P. : A = -46 ;  -46 + 8(n-1) = 1250  ->  n = 163
⚡ JEE Trick The stray-looking condition q ≠ 2 is doing real work — it eliminates the degenerate constant progression D = 0. Whenever a question adds an odd-looking exclusion, expect it to kill exactly one root of the quadratic you are about to form.
Answer: (a) 163.
6Let a and b be two distinct positive real numbers. Let 11th term of a GP, whose first term is a and third term is b, is equal to pth term of another GP, whose first term is a and fifth term is b. Then p is equal to   (a) 20   (b) 25   (c) 21   (d) 24   [JEE Main 2024, 30 Jan Shift-2]Two G.P.s sharing endpointsSequence and Series Class 11, Lecture 3 — JEE Main & Advanced🟡 Similarc21
Concept Both progressions start at a and reach b, but after different numbers of steps — so their ratios are different roots of b/a. Writing both terms as a·(b/a)something lets you equate exponents directly.
Formula r₁² = b/a, r₂⁴ = b/a
Solution
1. First G.P.: third term is b, so ar₁² = b ⇒ r₁² = b/a ⇒ r₁ = (b/a)1/2.
2. Its 11th term: a·r₁¹⁰ = a(b/a)⁵.
3. Second G.P.: fifth term is b, so ar₂⁴ = b ⇒ r₂ = (b/a)1/4.
4. Its pth term: a·r₂p−1 = a(b/a)(p−1)/4.
5. Equate: (b/a)⁵ = (b/a)(p−1)/4. Since a ≠ b, the base b/a ≠ 1, so the exponents must match: (p − 1)/4 = 5.
6. Therefore p − 1 = 20 ⇒ p = 21 → option (c).
   GP1 : r1^2 = b/a  ->  11th term = a (b/a)^5
   GP2 : r2^4 = b/a  ->  p-th term = a (b/a)^((p-1)/4)

   (p-1)/4 = 5   ->   p = 21

   ("distinct" ensures b/a != 1, so exponents may be equated)
⚡ JEE Trick Write every term as a·(b/a)k and the whole problem becomes bookkeeping on the exponent k: the nth term of a G.P. reaching b at position m has k = (n−1)/(m−1). Here 10/2 = 5 and (p−1)/4 = 5. The hypothesis "distinct positive reals" is what guarantees the base is not 1 and licenses comparing exponents.
Answer: (c) 21.
7If the range of f(θ) = (sin⁴θ + 3cos²θ)/(sin⁴θ + cos²θ), θ ∈ R is [α, β], then the sum of the infinite G.P., whose first term is 64 and the common ratio is α/β, is equal to ______.   [JEE Main 2024, 8 Apr Shift-1]Find a range, then an infinite sumSum to infinity of a geometric progression — Class 11🟡 Similar96
Concept Substitute t = cos²θ ∈ [0, 1] to turn f into a rational function of one variable. Showing it is increasing on [0,1] gives the range from the endpoints alone; then one application of a/(1 − r).
Formula f = (t² + t + 1)/(t² − t + 1) with t = cos²θ; S∞ = 64/(1 − α/β)
Solution
1. Put t = cos²θ, so sin⁴θ = (1 − t)². Then f = [(1−t)² + 3t]/[(1−t)² + t] = (t² + t + 1)/(t² − t + 1).
2. At the endpoints: f(0) = 1/1 = 1 and f(1) = 3/1 = 3.
3. Differentiating, the numerator of f′ is 2(1 − t²) ≥ 0 on [0, 1], so f is increasing there.
4. Hence the range is [1, 3], giving α = 1 and β = 3, so the common ratio is α/β = 1/3.
5. Sum: S∞ = 64/(1 − 1/3) = 64/(2/3) = 64 × 3/2.
6. So the sum is 96.
   t = cos^2 theta in [0,1]
   f = (t^2 + t + 1)/(t^2 - t + 1)

   f(0) = 1 ,  f(1) = 3 ,  f increasing   ->  range [1, 3]
   ratio = 1/3

   S = 64/(1 - 1/3) = 96
⚡ JEE Trick A useful alternative for f = (t²+t+1)/(t²−t+1): divide top and bottom by t to get (t + 1/t + 1)/(t + 1/t − 1), which is a decreasing function of u = t + 1/t — the same r + 1/r object that runs through this whole chapter. Either route gives the range without heavy calculus.
Answer: 96  (α = 1, β = 3, ratio 1/3).
8Let 3, a, b, c be in A.P. and 3, a − 1, b + 1, c + 9 be in G.P. Then, the arithmetic mean of a, b and c is:   (a) −4   (b) −1   (c) 13   (d) 11   [JEE Main 2024, 1 Feb Shift-1]A.P. shifted into a G.P.How to find the geometric means — geometric sequence🟡 Similard11
Concept Parametrise the A.P. with one unknown difference d, then impose the G.P. condition on the shifted quadruple. Two roots appear, and one is rejected because it makes a G.P. term zero.
Formula a = 3+d, b = 3+2d, c = 3+3d; G.P. condition (a−1)² = 3(b+1)
Solution
1. A.P.: a = 3 + d, b = 3 + 2d, c = 3 + 3d. The shifted quadruple is 3, 2 + d, 4 + 2d, 12 + 3d.
2. G.P. condition on the first three: (2 + d)² = 3(4 + 2d) ⇒ 4 + 4d + d² = 12 + 6d.
3. So d² − 2d − 8 = 0 ⇒ (d − 4)(d + 2) = 0 ⇒ d = 4 or d = −2.
4. Reject d = −2: it makes the second G.P. term 2 + d = 0, and a G.P. cannot contain zero.
5. So d = 4, giving a = 7, b = 11, c = 15. (Check the fourth term: 3, 6, 12, 24 — ratio 2 throughout ✓.)
6. Arithmetic mean = (7 + 11 + 15)/3 = 33/3 = 11 → option (d).
   A.P. : 3, 3+d, 3+2d, 3+3d
   shifted : 3, 2+d, 4+2d, 12+3d

   (2+d)^2 = 3(4+2d)  ->  d^2 - 2d - 8 = 0  ->  d = 4 or -2
   d = -2 gives a zero term  ->  rejected

   a,b,c = 7, 11, 15 ;  G.P. 3, 6, 12, 24
   AM = 33/3 = 11
⚡ JEE Trick For an A.P. of three numbers the mean is the middle term, so once you know b = 11 you can answer without adding anything. And always check a candidate root against the requirement that no G.P. term may be zero — that is what kills d = −2 here even though it satisfies the algebra.
Answer: (d) 11  (a, b, c = 7, 11, 15).
9Let the first term a and the common ratio r of a geometric progression be positive integers. If the sum of squares of its first three terms is 33033, then the sum of these three terms is equal to   (a) 241   (b) 231   (c) 210   (d) 220   [JEE Main 2023, 10 Apr Shift-1]Integer factorisation of a²(1 + r² + r⁴)How to solve geometric progression problems — step-by-step guide🟡 Similarb231  ⚠
Concept The sum of squares factors as a²(1 + r² + r⁴). Since a and r are positive integers, factor 33033 and search the small values of r for which 33033/(1 + r² + r⁴) is a perfect square.
Formula a² + a²r² + a²r⁴ = a²(1 + r² + r⁴) = 33033
Solution
1. Factor: 33033 = 33 × 1001 = (3 × 11)(7 × 11 × 13) = 3 × 7 × 11² × 13.
2. Test r = 2: 1 + 4 + 16 = 21, and 33033/21 = 1573 = 11² × 13 — not a perfect square ✗.
3. Test r = 3: 1 + 9 + 81 = 91, and 33033/91 = 363 = 3 × 11² — not a perfect square ✗.
4. Test r = 4: 1 + 16 + 256 = 273, and 33033/273 = 121 = 11² ✓. So a = 11 and r = 4.
5. (r ≥ 14 already gives 1 + r² + r⁴ > 33033, and r = 5…13 all fail, so this is the only solution.)
6. The terms are 11, 44, 176 — squares 121 + 1936 + 30976 = 33033 ✓ — and their sum is 231 → option (b), not the printed (d).
   a^2 (1 + r^2 + r^4) = 33033 = 3 x 7 x 11^2 x 13

   r=2 : 21  -> 1573   not a square
   r=3 : 91  ->  363   not a square
   r=4 : 273 ->  121 = 11^2      a = 11

   terms 11, 44, 176 ;  squares 121+1936+30976 = 33033
   sum = 231
⚡ JEE Trick When a and r are restricted to integers, stop doing algebra and start factoring — 1 + r² + r⁴ takes only the values 3, 21, 91, 273, 651, … so a short trial over r is faster and completely rigorous. Note 1 + r² + r⁴ = (r² + r + 1)(r² − r + 1), which helps you recognise those numbers quickly.
Answer: (b) 231  (a = 11, r = 4). ⚠ (key prints (d) 220)
10The 4th term of GP is 500 and its common ratio is 1/m, m ∈ N. Let Sn denote the sum of the first n terms of this GP. If S₆ > S₅ + 1 and S₇ < S₆ + ½, then the number of possible values of m is ______.   [JEE Main 2023, 24 Jan Shift-1]Consecutive-sum differences are single termsSum of Infinite GP — important questions on Geometric Progression🟡 Similar12
Concept Sn − Sn−1 is just the nth term, so both inequalities are statements about single terms — no sum formula needed at all. Each gives a bound on m, and the integers between them are counted.
Formula S₆ − S₅ = a₆, S₇ − S₆ = a₇; with a = 500m³
Solution
1. a₄ = ar³ = a/m³ = 500 ⇒ a = 500m³.
2. Sixth term: a₆ = ar⁵ = 500m³/m⁵ = 500/m². The condition S₆ > S₅ + 1 says a₆ > 1.
3. So 500/m² > 1 ⇒ m² < 500 ⇒ m ≤ 22 (since 22² = 484 < 500 < 529 = 23²).
4. Seventh term: a₇ = ar⁶ = 500m³/m⁶ = 500/m³. The condition S₇ < S₆ + ½ says a₇ < 1/2.
5. So 500/m³ < 1/2 ⇒ m³ > 1000 ⇒ m > 10, i.e. m ≥ 11.
6. Hence m ∈ {11, 12, …, 22}, which is 12 values.
   a/m^3 = 500  ->  a = 500 m^3

   a6 = 500/m^2 > 1     ->  m^2 < 500   ->  m <= 22
   a7 = 500/m^3 < 1/2   ->  m^3 > 1000  ->  m >= 11

   m = 11 ... 22   ->   12 values
⚡ JEE Trick Any condition comparing Sn with Sn−1 is secretly a condition on the single term an — subtract before you substitute and the sum formula never appears. The two bounds here land on the neat cubes and squares 10³ = 1000 and 22² = 484, which is the setter telling you the arithmetic is meant to be exact.
Answer: 12  (m = 11 to 22).
11Let a₁, a₂, a₃, …… be a GP of increasing positive numbers. If the product of fourth and sixth terms is 9 and the sum of fifth and seventh terms is 24, then a₁a₉ + a₂a₄a₉ + a₅ + a₇ is equal to ______.   [JEE Main 2023, 29 Jan Shift-1]Everything reduced to a₅ and r²Sequence and Series — Geometric Progression (GP), Class 11 JEE Main🟡 Similar60
Concept a₄ and a₆ are equidistant about a₅, so their product is a₅². Every requested piece then collapses to a power of a₅, because in each product the r-exponents cancel to zero.
Formula a₄a₆ = a₅²; a₁a₉ = a₅²; a₂a₄a₉ = a₅³
Solution
1. a₄a₆ = a₅² = 9 ⇒ a₅ = 3 (positive terms).
2. a₅ + a₇ = 24 is given directly — that is one of the four pieces, worth 24.
3. a₁ and a₉ are equidistant about a₅, so a₁a₉ = a₅² = 9.
4. For a₂a₄a₉: writing each as a₅rk with k = −3, −1, +4, the exponents sum to 0, so a₂a₄a₉ = a₅³ = 27.
5. Total: 9 + 27 + 24 = 60.
6. Consistency check: a₅ + a₇ = 3 + 3r² = 24 gives r² = 7, so the G.P. is increasing ✓ and a₄a₆ = (3/√7)(3√7) = 9 ✓.
   a4 a6 = a5^2 = 9   ->   a5 = 3
   a1 a9 = a5^2 = 9
   a2 a4 a9 : exponents -3, -1, +4  sum 0  ->  a5^3 = 27
   a5 + a7 = 24        (given)

   total = 9 + 27 + 24 = 60
⚡ JEE Trick For any product of G.P. terms, add the index offsets from a common centre — if they sum to zero, the whole product is a power of that centre term. Here 2, 4, 9 have offsets −3, −1, +4 about position 5, summing to 0, so a₂a₄a₉ = a₅³ without knowing r at all.
Answer: 60.
12If the sum and product of four positive consecutive terms of a G.P., are 126 and 1296, respectively, then the sum of common ratios of all such GPs is   (a) 7   (b) 9/2   (c) 3   (d) 14   [JEE Main 2023, 31 Jan Shift-1]Four-term symmetric selectionSequence & Series L-2 — Geometric Progression (GP), Class 11 JEE Main🟡 Similara7  ⚠
Concept Use the symmetric four-term labelling so the product is A⁴. The sum then reduces to an equation in R + 1/R. The crucial subtlety: in that labelling the common ratio of the G.P. is R², not R.
Formula A/R³, A/R, AR, AR³ — product A⁴, neighbours differ by R²
Solution
1. Product: A⁴ = 1296 ⇒ A = 6 (positive terms).
2. Sum: 6(1/R³ + 1/R + R + R³) = 126 ⇒ (R³ + 1/R³) + (R + 1/R) = 21.
3. With u = R + 1/R, we have R³ + 1/R³ = u³ − 3u, so u³ − 3u + u = 21 ⇒ u³ − 2u − 21 = 0.
4. Factor: (u − 3)(u² + 3u + 7) = 0. The quadratic has negative discriminant, so u = 3 uniquely ⇒ R + 1/R = 3 ⇒ R = (3 ± √5)/2.
5. The G.P.'s common ratio is r = R² = (7 ± 3√5)/2 — one for the increasing progression, one for the decreasing one.
6. Sum of those two ratios: (7 + 3√5)/2 + (7 − 3√5)/2 = 7 → option (a). (The printed key 3 is the value of R + 1/R, not of r₁ + r₂.)
   A^4 = 1296  ->  A = 6
   (R^3 + 1/R^3) + (R + 1/R) = 21
   u^3 - 2u - 21 = 0  ->  u = 3   ->  R = (3 +- sqrt5)/2

   common ratio r = R^2 = (7 +- 3 sqrt5)/2
   r1 + r2 = 7          (numerically 6.854 + 0.146)
⚡ JEE Trick In the symmetric four-term layout the neighbours step by R² — this is the same trap flagged at LEVEL: BOARD Q1 of M-8B L-3, where R = 3 but the progression 1/27, 1/3, 3, 27 steps by 9. Concept The G.P. data is a red herring for the final step: for any A.P. of 21 terms, the sum is 21 times the middle (11th) term. The answer follows from the structure alone, without ever evaluating a or r.
Formula S2k+1 = (2k+1) × (middle term) ⇒ S₂₁ = 21a₁₁
Solution
1. The A.P. has first term A = 10ar and common difference D = 10ar².
2. Sum of 21 terms: S₂₁ = (21/2)[2A + 20D] = 21(A + 10D).
3. But A + 10D is precisely the 11th term a₁₁.
4. Therefore S₂₁ = 21a₁₁ → option (a). This is an identity, valid for every A.P. of 21 terms.

14Let a₁, a₂, a₃, …… be a sequence of positive integers in arithmetic progression with common difference 2. Also, let b₁, b₂, b₃, …… be a sequence of positive integers in geometric progression with common ratio 2. If a₁ = b₁ = c, then the number of all possible values of c, for which the equality 2(a₁ + a₂ + …… + an) = b₁ + b₂ + …… + bn holds for some positive integer n, is ______.   [JEE Advanced 2020, Paper-1]A.P. sum vs G.P. sum — integer searchJEE Advanced 2020 question paper with solution — paper analysis🟡 Similar1
Concept Write both sums in closed form and solve for c. Because the G.P. side grows exponentially while the A.P. side grows quadratically, only small n can give a positive integer c — so a short search settles it.
Formula 2·Sn(A.P.) = 2n(c + n − 1); Sn(G.P.) = c(2ⁿ − 1)
Solution
1. A.P. side: 2(a₁ + … + an) = 2·(n/2)[2c + 2(n−1)] = 2n(c + n − 1).
2. G.P. side: b₁ + … + bn = c(2ⁿ − 1)/(2 − 1) = c(2ⁿ − 1).
3. Equate and collect the c terms: 2nc + 2n(n−1) = c·2ⁿ − c ⇒ 2n(n − 1) = c(2ⁿ − 2n − 1).
4. So c = 2n(n − 1)/(2ⁿ − 2n − 1).
5. Test small n: n = 1 gives c = 0 ✗; n = 2 gives 4/(−1) = −4 ✗; n = 3 gives 12/1 = 12 ✓; n = 4 gives 24/7 ✗; n = 5 gives 40/21 ✗; n = 6 gives 60/51 ✗; n = 7 gives 84/113 ✗.
6. From n = 4 onward the denominator 2ⁿ − 2n − 1 outgrows the numerator 2n(n−1), so no further integers arise. Exactly 1 value works, namely c = 12.
   2 x S(A.P.) = 2n(c + n - 1)
       S(G.P.) = c(2^n - 1)

   c = 2n(n-1) / (2^n - 2n - 1)

   n=1 :  0/-1  = 0    X      n=2 :  4/-1 = -4   X
   n=3 : 12/1   = 12   OK     n=4 : 24/7        X
   n=5 : 40/21  X             n=6 : 60/51       X
   exponential denominator wins from here  ->  exactly 1 value
⚡ JEE Trick Solve for the unknown constant as a ratio of two expressions in n, then let growth rates do the work: a numerator that is quadratic against a denominator that is exponential can only produce integers for a handful of small n. Checking n = 1 through 7 is genuinely sufficient here, and c = 12 with n = 3 is the unique hit (A.P. 12, 14, 16 doubles to 84; G.P. 12, 24, 48 sums to 84 ✓).
Answer: 1  (the only value is c = 12, at n = 3).
