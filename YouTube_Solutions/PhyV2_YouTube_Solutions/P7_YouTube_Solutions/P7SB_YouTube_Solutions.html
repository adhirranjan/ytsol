1Block A (5 kg) rests on block B (10 kg) which rests on the ground. μ between A and B = 0.5, μ′ between B and the ground = 0.5. A horizontal force of 200 N is applied to B. Find the acceleration of both blocks.Block-on-block, slipping check2 Block Problems | Friction | JEE Physics🟡 SimilaraA = 5 m/s², aB = 10 m/s²
Concept With a stack of blocks the first question is never "what is the acceleration" — it is "do they move together?" Assume they do, find the common acceleration, then ask whether the friction needed on the top block exceeds μN. If it does, the assumption dies and each block must be solved separately with kinetic friction at the interface.
Formula fmax = μN, applied twice: at the A–B interface (N = mAg) and at the B–ground interface (N = (mA+mB)g). The ground normal carries BOTH blocks — forgetting the top block's weight here is the single most common slip.
Solution
1. Friction limits: A–B → f1 = 0.5 × (5)(10) = 25 N; ground → f2 = 0.5 × (15)(10) = 75 N.
2. Test "move together": a = (200 − 75)/15 = 8.33 m/s². Friction needed on A = 5 × 8.33 = 41.7 N > 25 N.Not available, so A cannot keep up with B — they slip.
3. Block A alone: the only horizontal force on it is kinetic friction from B, 25 N forward. aA = 25/5 = 5 m/s².
4. Block B alone: 200 N forward, 25 N back (reaction from A), 75 N back (ground). aB = (200 − 25 − 75)/10 = 10 m/s².
        f=25N -->            A (5 kg)
  ==================================
  200N -->  B (10 kg)  <-- 25N (from A)
  ==================================   <-- 75 N (ground)
⚡ JEE Trick The 200 N acts on the lower block, so the top block is dragged only by friction — its acceleration can never exceed μg = 5 m/s². Compute μg first: if the "together" acceleration beats it, slipping is guaranteed and you can skip the algebra.
Answer: aA = 5 m/s², aB = 10 m/s² (both horizontal, in the direction of F)

Concept Sit in the frame of M and add a pseudo-force ma backwards on every small block. The block on the vertical face is pressed against it by that pseudo-force, so its normal force is N = ma — the faster M accelerates, the harder B is squeezed and the more friction B can generate. The block on the top face has N = mg, fixed. Two very different normals, one common a.
Formula Vertical face: NB = ma, |fB| ≤ μma. Top face: NA = mg, |fA| ≤ μmg. Same tension T in the string.
Solution
1. Block B (on the vertical face), vertical equilibrium in M's frame: T + fB = mg → T = mg − fB.At large a the block tends to be dragged UP by the string, so friction on B acts downward: fB = −μma, giving the largest tension T = mg + μma.
2. Block A (on the top face), horizontal equation in M's frame: T + fA = ma → fA = ma − T.
3. Substitute: fA = ma − mg − μma = ma(1−μ) − mg. Limiting value μmg:
ma(1−μ) − mg = μmg ⇒ amax = g(1+μ)/(1−μ)
4. The whole system has mass M + 2m and the floor is smooth, so Fmax = (M+2m)·amax.
   pseudo-force ma <-- on each small block (frame of M)
        [ A, m ]  N = mg  ------o pulley
   F--> |    M         |        |
        |______________|     [ B, m ]  N = ma
   ==================== smooth floor
⚡ JEE Trick The signature (1+μ)/(1−μ) is the fingerprint of "one block on a horizontal face + one on a vertical face, joined by a string". Spot the ratio in the options and you can pick the answer without the algebra. Note it blows up as μ → 1: with μ = 1 no finite force can make the pair slip.
Answer: Fmax = (1+μ)/(1−μ) × (M + 2m)g — option (c)
4A block of mass 1 kg lies on a 30° incline with μ = 0.5. A horizontal force of 10/√3 N is applied, pushing the block towards the incline. Find the frictional force acting on the block. (The figure labels the force 10√3 N — a misprint; see the solution.)Horizontal push on an inclineFriction on Inclined Plane | Angle of Repose | Numerical Problems🟡 Similarazero
Concept Static friction is a response, not a formula. Resolve everything along and perpendicular to the incline, find the net driving force along the slope, and only then compare it with μN. If the driving force is zero, friction is zero — no matter how big μN is.
Formula Along the incline: F cosθ − mg sinθ. Perpendicular: N = mg cosθ + F sinθ (a horizontal push into the slope increases N).
Solution
1. Component of F up the slope = F cos30° = (10/√3)(√3/2) = 5 N.
2. Component of weight down the slope = mg sin30° = (1)(10)(0.5) = 5 N.
3. Net driving force along the incline = 5 − 5 = 0. Static friction only has to supply the shortfall, and there is none.The block has no tendency to slide either way, so no friction is called for.
4. (Sanity check on the cap: N = mg cos30° + F sin30° = 5√3 + 5/√3 = 20/√3 N, so μN ≈ 5.8 N — plenty, but irrelevant since the requirement is 0.)
⚡ JEE Trick "F cosθ = mg sinθ" means F = mg tanθ — the horizontal force that holds a block on a frictionless incline. Whenever the given F equals mg tanθ, friction is instantly zero. Here mg tan30° = 10/√3 exactly. Book defect: the figure labels the force 10√3 N; with that value the block would slide up and friction would be 5√3 N. The text value 10/√3 N is the one the answer key uses.
Answer: friction = 0 N — option (a)

Concept "No slipping anywhere" in a stack that rests on the ground means nothing moves at all. The whole tower is held by one force: the static friction of the ground under C. Once that is exceeded, C slides on the floor and slipping has occurred.
Formula Tabulate every interface once: fmax = μ × (weight carried above that surface).
Solution
1. A–B: N = 20×10 = 200 N, μ = 0.1 → fmax = 20 N.
2. B–C: N = (20+30)×10 = 500 N, μ = 0.2 → fmax = 100 N.
3. C–ground: N = (20+30+40)×10 = 900 N, μ = 0.1 → fmax = 90 N.
4. With everything at rest, F is transmitted down through B and C to the floor. The floor can hold up to 90 N, so F ≤ 90 N.The weakest link is the ground here even though its μ is small, because it also has the smallest μ acting on the largest normal — always compute, never guess.

  B 30kg  <--F         mu=0.2 --> f_max = 100 N
  C 40kg  --- mu=0.1 --> f_max = 90 N  (ground)  <-- weakest
⚡ JEE Trick Build the "friction ladder" (20 / 100 / 90 N) once at the start of the passage; all three questions of the passage are then read straight off it.
Answer: Fmax = 90 N — option (a)
6Same three-block stack (A 20 kg on B 30 kg on C 40 kg; μAB = 0.1, μBC = 0.2, μCg = 0.1, F applied to B). Find the minimum value of F for which B slides on C. (a) 100 N (b) 112.5 N (c) 115 N (d) 117.5 NThree-block stack, interface slipMaximum Force for Two Blocks to Slide Together🟡 Similarb112.5 N
Concept Past F = 90 N the entire tower accelerates together. Now find the acceleration at which some interface runs out of friction. Each interface has its own ceiling; the smallest ceiling breaks first.
Formula Common acceleration a = (F − 90)/90 (total mass 90 kg, ground friction 90 N). Then apply Newton's second law to each block individually.
Solution
1. Block A (20 kg) is driven only by friction from B: 20a ≤ 20 N → a ≤ 1 m/s².
2. Block C (40 kg) is driven by friction from B and retarded by the ground's 90 N: fBC − 90 = 40a → fBC = 40a + 90 ≤ 100 N → a ≤ 0.25 m/s².C is the fussy one: it must be pushed hard enough to overcome its own ground friction, and only 100 N is on offer.
3. The B–C interface is the first to give way, at a = 0.25 m/s².
4. F = 90 + 90a = 90 + 90(0.25) = 112.5 N.
⚡ JEE Trick For a block below the driven one, always subtract its own ground friction before comparing with the interface limit. Candidates who write "fBC = 40a ≤ 100" get a ≤ 2.5 and pick a wrong option.
Answer: Fmin = 112.5 N — option (b)

1A man can just push a box up a 37° concrete slope. Where the slope steepens to 53° he can just hold it from sliding back. If μ between box and concrete is μ, find 1/μ. Assume he applies the same magnitude of force, tangential to the slope, in both cases.Two-condition friction on inclineFriction Force 02 | Angle of Repose | Friction on Inclined Plane🟡 Similar1/μ = 7  (μ = 1/7)
Concept Two different physical situations, one unknown force F and one unknown μ. "Just push up" means friction is at its maximum down the slope; "just hold from sliding down" means friction is at its maximum up the slope. Equating the same F kills F and leaves μ.
Formula Pushing up, impending motion up: F = mg sinθ₁ + μmg cosθ₁. Holding, impending motion down: F = mg sinθ₂ − μmg cosθ₂.
Solution
1. At 37°: F = mg(0.6 + 0.8μ).sin37° = 0.6, cos37° = 0.8. Friction opposes the impending upward motion, so it ADDS to what he must push.
2. At 53°: F = mg(0.8 − 0.6μ).sin53° = 0.8, cos53° = 0.6. Now the box tends to slide down, friction acts up, so it HELPS him and subtracts.
3. Same F ⇒ 0.6 + 0.8μ = 0.8 − 0.6μ ⇒ 1.4μ = 0.2 ⇒ μ = 1/7.
4. Therefore 1/μ = 7 (dimensionless).
  37 deg (pushing up)   :  F = mg(sin37 + mu cos37)
  53 deg (just holding) :  F = mg(sin53 - mu cos53)
  same F  =>  0.6 + 0.8mu = 0.8 - 0.6mu  =>  mu = 1/7
⚡ JEE Trick The sign in front of μ is the entire problem. Rule: friction sign = opposite to the direction of impending motion. Write "+μ" for pushing up, "−μ" for preventing slide-down, and these problems collapse to one line of algebra.
Answer: 1/μ = 7 (μ = 1/7 ≈ 0.143)

Concept The angle at which sliding begins is the angle of repose, fixed by the static coefficient: tanθ = μs. Once moving, friction drops to the kinetic value μk, so the block is no longer in equilibrium and accelerates. The whole trick is that θ is set by μs but the motion is governed by μk.

3. Once it moves, a = g sinθ − μk g cosθ = g[μs − μk]/√(1 + μs²).
