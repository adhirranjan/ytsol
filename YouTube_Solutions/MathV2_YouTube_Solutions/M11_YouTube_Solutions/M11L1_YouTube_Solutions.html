1 (i)Fill in the blanks: General solution of sinθ = k is θ = nπ + (−1)n sin−1k, then the value of k is ________.Admissible range of k in sinθ = kTRIGONOMETRIC EQUATION 01 | Principal Solutions & General Solutions | Math | Pure English | Class 11🟡 Similark ∈ [−1, 1]
Concept The formula θ = nπ + (−1)n sin−1k is only meaningful when sin−1k actually exists, so the question is really asking for the domain of the inverse sine. The sine of a real angle is the y-coordinate of a point on the unit circle, and that coordinate can never leave the interval from −1 to 1. Hence sinθ = k is solvable exactly when k lies in that closed interval, and unsolvable — no general solution at all — outside it.
Formula sinθ = k has a solution ⇔ −1 ≤ k ≤ 1, and then θ = nπ + (−1)nsin−1k, n ∈ Z. The endpoints are included because k = ±1 are attained, at θ = π/2 and −π/2.
Solution
1. On the unit circle a point is (cosθ, sinθ) with cos2θ + sin2θ = 1, so sin2θ = 1 − cos2θ ≤ 1.
2. Therefore |sinθ| ≤ 1, i.e. −1 ≤ sinθ ≤ 1 for every real θ. This is a range statement about the function, not about any one equation, so it holds before any solving begins.
3. If k > 1 or k < −1, sinθ = k demands a value the sine never takes, so the solution set is empty.
4. If −1 ≤ k ≤ 1 the horizontal line y = k does cut the sine graph, infinitely often, so solutions exist.
5. Both endpoints are attained: sin(π/2) = 1 and sin(−π/2) = −1, so the interval is closed at both ends. A half-open answer such as (−1, 1) would wrongly discard the two easiest cases.
6. Hence sin−1k, and with it the printed general solution, is defined precisely for k ∈ [−1, 1].
  -1 <= sin(theta) <= 1   for every real theta
  k = 1     -> theta = pi/2      (attained)
  k = -1    -> theta = -pi/2     (attained)
  k = 1/2   -> theta = n.pi + (-1)^n . pi/6
  k = 3     -> no solution  (3 is outside [-1,1])
  ==>  k belongs to  [ -1 , 1 ]

The trap is to answer with a set such as R or (−∞, ∞), which is the range of θ, not of k. The same bound run backwards is what makes Q 1(iv) below have zero solutions.

Concept A principal solution is a solution lying in the first rotation, [0, 2π). Since sine is positive in the first and second quadrants, sinθ = √3/2 > 0 puts θ in Q-I or Q-II, so exactly two principal solutions exist. The reference angle is the acute angle whose sine is √3/2, and the two principal solutions are built from it by the quadrant rules θ = α and θ = π − α.
Formula sinα = √3/2 ⇒ α = π/3; solutions in [0, 2π) are θ = α and θ = π − α. sin(π − α) = sinα is the supplementary identity, which is exactly why the second-quadrant partner appears.
Solution
1. Read the sign: √3/2 > 0, so θ lies in Q-I or Q-II and nowhere else in the first turn.
2. Reference angle: sinα = √3/2 with α acute gives α = 60° = π/3.
3. Q-I solution: θ = π/3, and indeed sin(π/3) = √3/2. Checking the value back in the equation is one second and kills sign slips.
4. Q-II solution: θ = π − π/3 = 2π/3, and sin(2π/3) = sin(π/3) = √3/2.
5. No other θ in [0, 2π) works, because in Q-III and Q-IV the sine is negative. This is why the count is two, not four — sine, unlike sin2, is not symmetric across the x-axis.
6. So the principal solutions are π/3 and 2π/3; the general solution stacking on top of them is θ = nπ + (−1)nπ/3.

  Q-I  :  theta = alpha       = pi/3    (60 deg)
  Q-II :  theta = pi - alpha  = 2pi/3   (120 deg)
  check: sin(pi/3) = sin(2pi/3) = 0.866 = sqrt(3)/2

The classic wrong answer here is π/3 and 4π/3, which pairs the reference angle with the wrong quadrant (4π/3 is where the sine is −√3/2). For cosine the partner is 2π − α, for tangent it is π + α; those three partner rules cover every principal-solution question in this lecture.

1 (iii)Fill in the blanks: The number of solutions of the trigonometric equation secθ = 0 is ________.Range of secθ — no solutionTrigonometric Equations Class 11 - The Basics (Principal and General Solutions)🟡 Similar0
Concept secθ is defined as 1/cosθ, and a reciprocal can never be zero: for 1/cosθ to equal 0 the denominator would have to be infinite, which no real cosine value is. So secθ = 0 is not a hard equation with a clever root, it is an equation with an empty solution set. The same argument gives the standard range |secθ| ≥ 1, which excludes 0 outright.
Formula secθ = 1/cosθ, |cosθ| ≤ 1 ⇒ |secθ| ≥ 1. Taking reciprocals of numbers with modulus at most 1 produces numbers with modulus at least 1, and reverses the inequality.
Solution
1. Suppose secθ = 0 for some real θ. Then 1/cosθ = 0.
2. Multiply both sides by cosθ (legal, since secθ only exists when cosθ ≠ 0) to get 1 = 0, a contradiction. The multiplication is safe precisely because the domain of sec already excludes cosθ = 0.
3. Alternatively use the range: 0 < |cosθ| ≤ 1 on the domain of sec, so |secθ| = 1/|cosθ| ≥ 1.
4. Since |secθ| ≥ 1 > 0, the value 0 is never taken by secθ. The graph of secθ lies entirely above y = 1 or below y = −1; the strip −1 < y < 1 is empty, and 0 sits in that strip.
5. So the solution set is φ and the number of solutions is 0.
6. The identical argument kills cosecθ = 0; only tan and cot, which are not reciprocals of a bounded function alone, can vanish.
  domain of sec :  cos(theta) != 0
  0 < |cos(theta)| <= 1
  |sec(theta)| = 1/|cos(theta)| >= 1
  strip  -1 < y < 1  is never reached  ->  0 not reached
  sec(theta) = 0  ==>  1/cos(theta) = 0  ==>  1 = 0  (absurd)
  number of solutions = 0
⚡ JEE Trick Before solving anything, test the target value against the range of the function: sin and cos live in [−1, 1], sec and cosec live outside (−1, 1), and tan and cot take every real value. Half the "number of solutions" MCQs in this chapter collapse to 0 or ∞ on that check alone. The bait answer here is 1, from students who "solve" cosθ = 1/0 and land on θ = π/2 — but at θ = π/2 the secant is undefined, not zero.
Answer: 0 (no solution).

Concept This is the previous bound used in the opposite direction. The sine function maps every real x into [−1, 1], so asking for sin x = 3 asks the sine to reach a height it can never reach. There is nothing to solve: the graph y = sin x and the line y = 3 never meet, so the solution set is empty and the count is zero.
Formula −1 ≤ sin x ≤ 1 for all x ∈ R. sin x is the y-coordinate of a point on the unit circle, whose distance from the origin is fixed at 1, so no coordinate can exceed 1 in modulus.
Solution
1. Compare the demanded value with the range: 3 > 1, so 3 ∉ [−1, 1].
2. Graphically, y = sin x oscillates between the lines y = −1 and y = 1, while y = 3 sits strictly above the upper one. Two curves that occupy disjoint horizontal strips cannot intersect anywhere.
3. Algebraically, sin x = 3 would force cos2x = 1 − 9 = −8, impossible for a real cosine.
4. So no real x satisfies the equation and the number of solutions is 0. Note "0", not "no answer": the equation is perfectly well posed, its solution set is simply φ.
5. Complex solutions do exist — sin z = 3 is solvable over C — but this chapter works entirely over R.
6. The same test settles cos x = 5, sec x = 1/2 and cosec x = 0 in one line each.
  range of sin :  [ -1 , 1 ]

  y = sin x  lives in the strip  -1 <= y <= 1

Concept The standard general solutions differ because sine, cosine and tangent repeat differently. Sine and cosine both have period 2π, but sine is symmetric about θ = π/2 while cosine is symmetric about θ = 0; tangent has period π. Those symmetries give exactly the shapes nπ + (−1)nα, 2nπ ± α and nπ + α, and sinθ = 0 is the case α = 0 of the first.
Formula sinθ = sinα ⇒ θ = nπ + (−1)nα; cosθ = cosα ⇒ θ = 2nπ ± α; tanθ = tanα ⇒ θ = nπ + α. The alternating (−1)n encodes the mirror π − α, while ± encodes the mirror −α.
Solution
1. (A) sinθ − sinα = 0 ⇒ 2cos((θ+α)/2)·sin((θ−α)/2) = 0 ⇒ θ = 2nπ + α or (2n+1)π − α, i.e. θ = nπ + (−1)nα, so (A) → (r).
2. (B) cosθ − cosα = 0 ⇒ −2sin((θ+α)/2)·sin((θ−α)/2) = 0 ⇒ θ = 2nπ ± α, so (B) → (q). Both factors are sines here, which is why the answer carries a clean ± and not an alternating sign.
3. (C) tanθ = tanα ⇒ sin(θ − α) = 0 ⇒ θ = nπ + α, so (C) → (p).
4. (D) sinθ = 0 is sinθ = sin0, so α = 0 in (r) gives θ = nπ, i.e. (D) → (s). (s) is not a fourth rule, it is entry (r) with α = 0.
5. Cross-check the periods: (p) repeats every π (tangent), (q) and (r) every 2π.
6. Every letter is used once, so the matching is forced.
  (A) sin@ = sin a  ->  @ = n.pi + (-1)^n . a      -> (r)
  (B) cos@ = cos a  ->  @ = 2n.pi +/- a            -> (q)
  (C) tan@ = tan a  ->  @ = n.pi + a               -> (p)
  (D) sin@ = 0      ->  a = 0 in (r) ->  @ = n.pi  -> (s)
  period check :  (p) pi     (q),(r) 2pi
⚡ JEE Trick Match by period before matching by shape: any option repeating every π must belong to tangent or cotangent, which instantly pins (C). The usual slip is sending (B) to (p) because both look "plus-shaped"; remember that only the tangent family has the bare nπ + α form. Also note that cosecθ = cosecα and secθ = secα reuse rows (r) and (q) untouched, since they are reciprocals of sine and cosine.
Answer: (A)→(r), (B)→(q), (C)→(p), (D)→(s).

1A trigonometric identity is: (a) Equation true for some angles (b) Always false (c) True for all angles (d) Has complex rootsIdentity versus equationTrigonometric Equations Class 11 - The Basics (Principal and General Solutions)🟡 SimilarcTrue for all angles
Concept The whole chapter rests on one distinction. An identity is a statement that holds for every admissible value of the variable, so it carries no information about the angle. An equation holds only for particular values, and solving it means hunting those values down. cos2x + sin2x = 1 is an identity; 2cosθ + 1 = 0 is an equation.
Formula Identity: true ∀x in the domain. Equation: true for some x only. "For all" versus "for some" is the only difference, and it is what decides whether you may cancel a factor or must solve for it.
Solution
1. Test (a) "true for some angles": that describes an equation, not an identity, so it is out.
2. Test (b) "always false": a false statement such as sin x = 3 is neither an identity nor a solvable equation, so it is out.
3. Test (c) "true for all angles": this is exactly the definition of an identity. The chapter's own example cos2x = 1 − sin2x is flagged as true ∀x ∈ R.
4. Test (d) "has complex roots": roots belong to equations, and this chapter works over R anyway, so it is out.
5. Sanity check with a concrete pair: 1 + tan2θ = sec2θ holds at θ = 0, π/6, π/4, … without exception, whereas tanθ = 1 holds only at θ = nπ + π/4. One counterexample is enough to demote a candidate identity to an equation.
6. Hence the correct description is (c).
  identity : holds for EVERY admissible angle
             e.g.  sin^2 x + cos^2 x = 1
  equation : holds for SOME angles only
             e.g.  2 cos(t) + 1 = 0 -> t = 2n.pi +/- 2pi/3
  (a) some angles   -> that is an equation      X
  (b) always false  -> neither                  X
  (c) all angles    -> IDENTITY                 OK
  (d) complex roots -> not relevant over R      X
⚡ JEE Trick The practical payoff: you may substitute an identity anywhere at any time, but you may never "cancel" an expression that is really an equation's factor — that is exactly how roots get lost. Level-5 Q3 in this very lecture punishes the mirror error, cancelling cos x from both sides when it is a genuine restriction on the domain.
Answer: (c) True for all angles.

⚡ JEE Trick Never convert sin A = cos B into a single equation — the ± is where the extra roots hide, and option (b) 5 is planted for whoever keeps only the plus branch. A fast structural count: the plus branch has period 2π/5 and so gives 5 roots per turn, the minus branch has period 2π and gives 1, total 6, before a single angle is written down.
Answer: (c) 6.
7The solution set of the equation cos5x = 1 + sin4x is (a) nπ (n ∈ I) (b) 2nπ (n ∈ I) (c) 4nπ (n ∈ I) (d) nπ/2Boundedness argumentThe solution set of `cos^5x = 1 + sin^4x` is🟢 Exactb2nπ (n ∈ I)
Concept A boundedness question. The right-hand side 1 + sin4x is at least 1, while the left-hand side cos5x is at most 1. Equality can therefore hold only when both sides equal 1 exactly, which forces cos x = 1 and sin x = 0 simultaneously — a much stronger conclusion than any algebra would give.
Formula cos5x ≤ 1 and 1 + sin4x ≥ 1 ⇒ both sides = 1 ⇒ cos x = 1 and sin x = 0. An odd power preserves sign, so cos5x = 1 forces cos x = +1 rather than ±1.
Solution
1. Upper bound on the left: |cos x| ≤ 1 ⇒ cos5x ≤ 1.
2. Lower bound on the right: sin4x ≥ 0 ⇒ 1 + sin4x ≥ 1.
3. So LHS ≤ 1 ≤ RHS, and equality demands cos5x = 1 and sin4x = 0 together. The two bounds squeeze from opposite sides, so any slack in either makes LHS strictly less than RHS.
4. cos5x = 1 ⇒ cos x = 1 (the fifth power is odd, so no negative root); sin4x = 0 ⇒ sin x = 0.
5. Both conditions hold exactly at x = 2nπ, n ∈ I. The condition cos x = 1 is already the stronger of the two — sin x = 0 follows automatically from it.
6. Reject (a) nπ: at x = π, cos5x = −1 while 1 + sin4x = 1, so −1 ≠ 1. Reject (c) 4nπ, which omits x = 2π, and (d) nπ/2, which fails at π/2. Hence (b).
  cos^5 x <= 1        (odd power, |cos| <= 1)
  1 + sin^4 x >= 1    (even power, sin^4 >= 0)
  equality  ==>  cos^5 x = 1  AND  sin^4 x = 0
            ==>  cos x = 1    AND  sin x = 0
            ==>  x = 2n.pi
  x = pi   : (-1) vs 1 + 0 = 1      X
  x = pi/2 :   0  vs 1 + 1 = 2      X
  x = 2pi  :   1  vs 1 + 0 = 1      OK
⚡ JEE Trick Watch the parity of the exponent: cos5x = 1 gives only cos x = 1 (family 2nπ), whereas cos4x = 1 would give cos x = ±1 (family nπ). Option (a) is bait for exactly that confusion. The same squeeze argument — maximum of one side meets minimum of the other — solves Level-4 Q8 and the next question too.
Answer: (b) 2nπ (n ∈ I).
8The roots of the equation cos7x + sin4x = 1 in the interval (−π, π) are: (a) {−π/2, 0, π/2} (b) {−π/2, π/2} (c) {π/2} (d) {−π/2}Factorising a high-power equationThe real roots of the equation cos^7x + sin^4x = 1 in the interval (-pi, pi) are ______🟢 Exacta{−π/2, 0, π/2}
Concept Here a bare boundedness argument is not enough, because cos7x can be negative. The clean route is to move everything to one side and factorise: writing 1 − sin4x as (1 − sin2x)(1 + sin2x) = cos2x(1 + sin2x) exposes a common factor cos2x, and the leftover bracket is then settled by bounds.
Formula 1 − sin4x = cos2x(1 + sin2x); a2 − b2 = (a−b)(a+b). Factorising first turns one hard equation into two easy ones, exactly as with any product-equals-zero problem.
Solution
1. Rearrange: cos7x = 1 − sin4x = (1 − sin2x)(1 + sin2x) = cos2x(1 + sin2x).
2. Bring together: cos2x[cos5x − (1 + sin2x)] = 0.
3. First factor: cos2x = 0 ⇒ cos x = 0 ⇒ x = ±π/2 inside (−π, π). Both signs qualify, since the interval is symmetric about 0 and cosine vanishes on either side.
4. Second factor: cos5x = 1 + sin2x. The left side is at most 1 and the right at least 1, so both must equal 1.
5. That forces cos x = 1 and sin x = 0, i.e. x = 2nπ; inside (−π, π) the only such value is x = 0. This is the same squeeze as the previous question, now applied to the surviving bracket rather than the whole equation.
6. Collecting: x = −π/2, 0, π/2. Verify x = π/2: 0 + 1 = 1 ✓; x = −π/2: 0 + 1 = 1 ✓; x = 0: 1 + 0 = 1 ✓. Hence (a).
  cos^7 x = 1 - sin^4 x = cos^2 x (1 + sin^2 x)
  cos^2 x [ cos^5 x - (1 + sin^2 x) ] = 0
  factor 1 : cos x = 0   ->  x = +/- pi/2
  factor 2 : cos^5 x = 1 + sin^2 x
             LHS <= 1 <= RHS  ->  both = 1
             cos x = 1 , sin x = 0  ->  x = 0
  roots in (-pi, pi) :  -pi/2 , 0 , pi/2
  check : 0+1 = 1 , 1+0 = 1 , 0+1 = 1     OK
⚡ JEE Trick Options (b), (c) and (d) are all subsets of (a), which is the examiner's signal that the question is really "did you find every root?". Factorise before bounding: the pure squeeze argument finds x = 0 but silently misses ±π/2, where cos7x = 0 and sin4x = 1 still sum to 1. Whenever both a factor and a bound are available, use the factor first.
Answer: (a) {−π/2, 0, π/2}.

Concept Convert cot2x to cosec2x − 1 so the equation becomes a quadratic in cosec x. One root is inadmissible because |cosec x| ≥ 1, leaving a single condition sin x = 1/3. Counting its solutions on [0, nπ] then reduces to counting how many positive humps of the sine that interval contains.
Formula cot2x = cosec2x − 1; 2c2 − 5c − 3 = (2c + 1)(c − 3). Rewriting in one ratio is the standard first move for any equation mixing cot and cosec.
Solution
1. With a = 1 the equation is 2cot2x − 5cosec x = 1. Substitute cot2x = cosec2x − 1: 2cosec2x − 2 − 5cosec x = 1.
2. So 2c2 − 5c − 3 = 0 with c = cosec x, giving (2c + 1)(c − 3) = 0 and c = −1/2 or c = 3.
3. Reject c = −1/2, since |cosec x| ≥ 1 always; so cosec x = 3, i.e. sin x = 1/3. The cosec range test is the trigonometric filter here, exactly as the sine range test was in Level-6 Q3.
4. sin x = 1/3 > 0 has two roots in each positive hump [2kπ, (2k+1)π] and none where the sine is negative.
5. Count on [0, nπ]: n = 1 or 2 gives 1 hump → 2 roots; n = 3 or 4 gives 2 humps → 4 roots; n = 5 or 6 gives 3 humps → 6 roots; n = 7 gives 4 humps → 8 roots. The count rises in steps of two, so it is always even — "exactly 7" is unattainable and the stem is defective as printed.
6. The largest n for which the number of roots does not exceed 7 is n = 6 (6 roots); at n = 7 it jumps to 8. So the greatest value of n is 6.

10If the equation x2 + 4x sinθ + tanθ = 0 (0 < θ < π/2) has repeated roots, then θ equals: (a) π/12 (b) π/6 (c) π/12 or 5π/12 (d) π/6 or π/12Discriminant = 0 with a trigonometric coefficientTRIGONOMETRIC EQUATIONS in ONE SHOT | All Concepts & PYQs Covered | Basic to Advanced | Class 11 JEE🟡 Similarcπ/12 or 5π/12
Concept A quadratic in x has repeated roots exactly when its discriminant vanishes. Setting D = 0 converts the algebra into a trigonometric equation in θ, which then factorises through the double-angle identity. The stated range 0 < θ < π/2 finally decides how many of the roots survive.
Formula ax2 + bx + c = 0 has equal roots ⇔ b2 − 4ac = 0; sin2θ = 2sinθcosθ. The double-angle identity is what turns the mixed product sinθcosθ into a single sine, which is directly solvable.
Solution
1. Here a = 1, b = 4sinθ, c = tanθ, so D = 16sin2θ − 4tanθ.
2. D = 0 ⇒ 16sin2θ = 4tanθ = 4sinθ/cosθ ⇒ 4sin2θcosθ = sinθ.
3. Factorise: sinθ(4sinθcosθ − 1) = 0. On 0 < θ < π/2 the factor sinθ is strictly positive, so it contributes nothing. Dividing by sinθ without first noting the range would be illegitimate; here the range makes it safe.
4. So 4sinθcosθ = 1 ⇒ 2sin2θ = 1 ⇒ sin2θ = 1/2.
5. With 0 < θ < π/2 we have 0 < 2θ < π, and sin2θ = 1/2 there gives 2θ = π/6 or 5π/6, hence θ = π/12 or 5π/12. Doubling the interval is the step that reveals the second solution; working directly in θ hides 5π/12 and produces option (a).
6. Check θ = π/12: D = 16(0.2588)2 − 4(0.2679) = 1.0718 − 1.0718 = 0 ✓. Hence (c).
  x^2 + 4x sin(t) + tan(t) = 0
  D = (4 sin t)^2 - 4 tan t = 16 sin^2 t - 4 tan t = 0
  16 sin^2 t = 4 sin t / cos t
  sin t (4 sin t cos t - 1) = 0 ;  sin t > 0 on (0,pi/2)
  4 sin t cos t = 1  ->  2 sin 2t = 1  ->  sin 2t = 1/2
  0 < 2t < pi :  2t = pi/6  or  5pi/6
  t = pi/12  or  5pi/12
  check t = pi/12 : 1.0718 - 1.0718 = 0     OK
⚡ JEE Trick After substituting 2θ, always widen the interval before solving — 0 < θ < π/2 becomes 0 < 2θ < π, which holds two solutions of sin2θ = 1/2, not one. Option (a) π/12 alone is precisely the answer you get by forgetting to double the range, and it is the most-chosen wrong option in this family of problems.
Answer: (c) π/12 or 5π/12.
