1In the definite integral ∫ₐᵇ f(x)dx, what is f(x) called? (integrand) (Level-1)Definite-integral terminologyDefinite Integral — basic introduction · Understanding integral notation🟡 Similarcintegrand
Concept A definite integral is a piece of notation with named parts, and every symbol has a job. ∫ₐᵇ f(x) dx is read as "sum up the strips f(x)·dx as x runs from a to b." The function sitting inside the integral sign — the thing actually being integrated — is called the integrand. Getting the vocabulary right matters in physics because you constantly build integrals from scratch (∫F dx, ∫v dt, ∫λ dx) and must identify which factor is the integrand and which is the differential.
Formula ∫ₐᵇ f(x) dx = [g(x)]ₐᵇ = g(b) − g(a), where g′(x) = f(x). Naming of parts: ∫ = integral sign (an elongated S for "sum"); f(x) = integrand; dx = variable/element of integration; a = lower limit, b = upper limit; the pair (a, b) = limits of integration. Units check: the integral inherits the units of f(x) × units of x — e.g. ∫F dx has N × m = J, so the integrand carries the "per unit x" quantity.
Solution
1. Write the integral and label each symbol: ∫ₐᵇ f(x) dx.Four distinct objects appear: the sign, the function, the differential, and the two limits.
2. The lower limit is a and the upper limit is b — these are the limits, not the integrand.
3. dx is the infinitesimal width of the strip — the variable of integration, not the integrand.
4. The function f(x), which is being multiplied by dx and summed, is by definition the integrand."Integrand" literally means "the thing to be integrated" — the height of each strip, while dx is its width.
5. Physics reading: strip area = height × width = f(x)·dx, so the integrand is always the height factor.

Concept "Area under a curve" is the geometric meaning of the definite integral, and it is built the same way every time: slice the region into vertical strips of width dx, note that each strip is a rectangle of height y = f(x), so its area is dA = y dx, then add all the strips with an integral. The three cases here are deliberately graded — a constant (rectangle), a straight line (triangle/trapezium), and a parabola — because the first two can be checked against school geometry, which proves the integral is doing the right thing before you trust it on the parabola, where geometry cannot help.
Formula A = ∫ₐᵇ y dx = ∫ₐᵇ f(x) dx. Antiderivatives needed: ∫c dx = cx, ∫kx dx = kx²/2, ∫x²dx = x³/3. Dimensions: A carries [units of y] × [units of x]. If y is a velocity in m s⁻¹ and x a time in s, the "area" is a displacement in m — this is why area-under-the-graph is a physics tool, not just a geometry exercise.
Solution
1. (i) y = c (a horizontal line), from x = a to x = b.

1Total area under a curve between x=a and x=b is expressed as: (∫ₐᵇ f(x)dx)Area = definite integralFinding area under the curve using definite integrals · Basic area under curve🟡 Similarc∫ₐᵇ f(x)dx
Concept The definite integral was invented to answer "what is the area under this curve?" for shapes that no geometry formula can handle. The construction: chop the region between x = a and x = b into n vertical strips, approximate each by a rectangle of height f(x) and width Δx, add them, then let Δx → 0 so the staircase of rectangles converges onto the true curved boundary. That limiting sum is the definite integral — the ∫ sign is literally a stretched "S" for "sum."
Formula A = ∫ₐᵇ f(x) dx = lim(Δx→0) Σ f(xᵢ)·Δx, built from the element dA = f(x) dx = y dx. Dimensionally A = [y]·[x]: with y in m s⁻¹ and x in s, A is in m (a displacement); with y in N and x in m, A is in J (work). The "area" always carries the product of the two axis units.
Solution
1. Take one representative strip at position x, of infinitesimal width dx.Because dx is vanishingly narrow, the curve does not bend appreciably across it — the strip is a true rectangle.
2. Its height is the value of the curve there, y = f(x), so its area is dA = f(x)·dx.
3. Total area = the sum of every such strip from x = a to x = b: A = Σ f(x)Δx.
4. Let the strip width shrink to zero — the sum becomes an integral: A = ∫ₐᵇ f(x) dx.The staircase error at each curved top is of order (Δx)², so summing n ≈ (b−a)/Δx of them leaves an error ∝ Δx, which vanishes as Δx → 0.
5. Evaluate it via the Fundamental Theorem: A = g(b) − g(a), where g′(x) = f(x).

1. Draw one vertical strip at abscissa x with width dx.

4The definite integral is always evaluated between: (two limits a and b)Limits of integrationDefinite Integral — basic introduction🟡 SimilarbTwo limits a and b
Concept The word "definite" is the whole point of the question: it means the integration is pinned down between two specified values of the variable — a lower limit a and an upper limit b. That is exactly what separates it from an indefinite integral, which has no limits, returns a function g(x) + C, and carries an unknown constant. Supplying limits kills the constant C and turns the answer into a single definite number — which is why physics uses it whenever a real, measurable total is wanted.
Formula Definite: ∫ₐᵇ f(x)dx = g(b) − g(a) ⇒ a number. Indefinite: ∫f(x)dx = g(x) + C ⇒ a function. Why C disappears: using g(x) + C in the definite form gives [g(b) + C] − [g(a) + C] = g(b) − g(a) — the constant cancels between the two limits, so it never affects a definite integral. Here a = lower limit, b = upper limit; both must be real values of the same variable, carrying the same units as x.
Solution
1. Look at the notation: ∫ₐᵇ carries a number written below the sign and one above it.
2. These are the limits of integration — a is where the summation of strips starts, b is where it stops.Without a start and stop there is nothing to add up over, so no numerical answer can exist.
3. Apply the Fundamental Theorem: the value is g(b) − g(a), i.e. the antiderivative evaluated at the upper limit minus at the lower limit.
4. Note the result is a single number, and the constant C cancels: [g(b) + C] − [g(a) + C] = g(b) − g(a).This is precisely the payoff of having limits.
5. Hence a definite integral is always evaluated between two limits, a and b.
6. Physics example: ∫₀^(2 s) v dt gives the actual displacement in metres over those 2 seconds — a measurable number, not a formula.

5The symbol ∫ in integration represents: (summation of infinitesimals)Meaning of ∫ notationUnderstanding integral notation🟡 SimilarbSummation of infinitesimals
Concept The integral sign ∫ is not an arbitrary squiggle — Leibniz drew it in 1675 as an elongated letter S, standing for "summa" (sum). It records the one idea behind all integration: take a quantity that varies, cut it into infinitely many infinitesimally small pieces over which it is effectively constant, and add every piece up. The ordinary Σ adds a finite list of finite terms; ∫ is its continuous cousin, adding an infinite list of infinitesimal terms.
Formula ∫ₐᵇ f(x)dx = lim(Δx→0) Σᵢ f(xᵢ)·Δx — the definition of the integral as the limit of a Riemann sum. Reading the symbols left to right: ∫ = "add up", f(x) = the value of one piece per unit x, dx = the infinitesimal size of one piece, a and b = where the adding starts and stops. The product f(x)·dx carries the units of the total.
Solution
1. Start from a finite sum of n strips: Σᵢ₌₁ⁿ f(xᵢ)·Δx.This is an approximation — each strip pretends f is constant across its width Δx.
2. Shrink the pieces: let Δx → 0 (equivalently n → ∞). The approximation becomes exact.
3. Rename the surviving symbols: Σ becomes ∫ and the finite Δx becomes the infinitesimal dx.Leibniz chose ∫ as a long S precisely because it is a sum — and d for "difference," now vanishingly small.
4. So ∫ literally means "the continuous sum of infinitesimal contributions," which is the required answer.
5. Sanity check with a case where the sum is obvious: ∫₀^L dx = L — adding infinitely many infinitesimal lengths dx from 0 to L reassembles the full length L.
6. Physics reading: total = Σ(each little bit) ⇒ charge q = ∫i dt (add up i·dt bits), work W = ∫F dx, mass m = ∫λ dx, impulse J = ∫F dt.
  DISCRETE                       CONTINUOUS
  Σ  f(xᵢ) · Δx        ── Δx→0 ──▶     ∫  f(x) · dx
  |    |       |                       |    |      |
  |    |       finite width            |    |      infinitesimal width
  |    value per strip                 |    value per unit x
  add a finite list                    add an infinite list   ( ∫ = long "S" = summa )
⚡ JEE Trick Whenever a physics quantity is uniform, you multiply (W = F·d, q = i·t, m = λ·L). The instant it varies, replace the multiplication with an integral of the same product (W = ∫F dx, q = ∫i dt, m = ∫λ dx). "∫ is just × for things that change" is the single most useful sentence in this chapter. Trap: ∫ is a sum, not a "reverse derivative machine" — the antiderivative is merely the fastest way to evaluate that sum.
Key point: ∫ is an elongated S for "sum" — it represents the summation of infinitesimal contributions f(x)·dx, the continuous limit of Σ f(xᵢ)Δx as Δx → 0.

Solution
1. Factorise the velocity to find where it vanishes: v(t) = t² − 4t + 3 = (t − 1)(t − 3) ⇒ roots at t = 1 s and t = 3 s.v = 0 marks the instants the particle is momentarily at rest — the candidate turning points.
2. Determine the sign of v on each sub-interval (an upward parabola is negative only between its roots):
  • 0 ≤ t < 1: e.g. v(0) = 3 m s⁻¹ > 0 ⇒ moving forward (+x)
  • 1 < t < 3: e.g. v(2) = 4 − 8 + 3 = −1 m s⁻¹ < 0 ⇒ moving backward (−x)
  • 3 < t ≤ 4: e.g. v(4) = 16 − 16 + 3 = 3 m s⁻¹ > 0 ⇒ moving forward again
3. So the particle reverses direction twice, at t = 1 s and at t = 3 s.A sign change of v — not merely v = 0 — is what constitutes a reversal.
4. Build the antiderivative once: g(t) = t³/3 − 2t² + 3t. Check: g′(t) = t² − 4t + 3 ✓
5. Evaluate g at each break-point:
  • g(0) = 0
  • g(1) = 1/3 − 2 + 3 = 4/3
  • g(3) = 27/3 − 18 + 9 = 9 − 18 + 9 = 0
  • g(4) = 64/3 − 32 + 12 = 64/3 − 20 = (64 − 60)/3 = 4/3
6. Displacement over the whole interval: Δx = ∫₀⁴ v dt = g(4) − g(0) = 4/3 − 0 = 4/3 m ≈ 1.33 m ✓ (matches the printed value).
7. Path length — integrate the three pieces separately and add their magnitudes:
  • ∫₀¹ v dt = g(1) − g(0) = 4/3 − 0 = +4/3 m ⇒ |·| = 4/3 m

  • ∫₃⁴ v dt = g(4) − g(3) = 4/3 − 0 = +4/3 m ⇒ |·| = 4/3 m
8. Total path length S = ∫₀⁴|v|dt = 4/3 + 4/3 + 4/3 = 4 m.Note S = 4 m ≠ |Δx| = 4/3 m — exactly because of the backward leg, which cancels in Δx but adds in S.
