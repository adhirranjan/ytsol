1Which symbol denotes the complement of set A?Complement (A′)watch?v=xZELQc11ACY🟡 SimilaraA′ (= Ac = U − A)
Concept The complement of a set A collects every element of the universal set U that is not in A. It is meaningful only relative to a fixed universe U — "everything else". The standard notations you must recognise are A′ (prime), Ac (superscript c), and U − A; all three denote the same set.
Formula A′ = { x ∈ U : x ∉ A }. Read: the set of all x in the universe such that x is not an element of A. The most common school symbol is the prime, A′.
Solution
1. The question asks for the symbol, not a computation.Complement is defined against U, so it needs a dedicated notation.
2. Accepted symbols: A′, Ac, and U − A — all equal.Textbooks (and this ICAD module) use the prime A′ as the primary form.
3. Distractors like A∪B or A∩B combine two sets and are not complements.
⚡ JEE Trick Complement always implies a universe — if U is not stated, the symbol is meaningless. Remember the identities A ∪ A′ = U and A ∩ A′ = φ; they instantly kill wrong options that violate them.
Answer: A′ (equivalently Ac or U − A).

Concept To take a complement you simply strike out from the universe U every element that appears in A; whatever survives is A′. There is no arithmetic — just set membership checking, element by element.
Formula A′ = U − A = { x ∈ U : x ∉ A }. Scan U; keep each element only if it is absent from A.
Solution
1. List the universe: U = {1, 2, 3, 4, 5}.
2. List A: A = {1, 2, 3}.
3. Remove A's elements from U: strike 1, 2, 3.These belong to A, so they are excluded from A′.
4. Survivors: A′ = {4, 5}.

⚡ JEE Trick Sanity check with counts: n(A) + n(A′) = n(U). Here 3 + 2 = 5 ✓. If your complement's size doesn't add up to n(U), you dropped or double-counted an element.

3n(A)=45, n(B)=30, n(A∩B)=15 → find n(A′∪B′)De Morgan / complementwatch?v=xZELQc11ACY🟡 Similarb65
Concept Never expand A′ and B′ separately here — that path needs the universe and invites double counting. Instead collapse the whole expression with De Morgan's law, which turns a union of complements into the complement of an intersection. That single step reduces everything to the one overlap you were given.
Formula De Morgan: A′ ∪ B′ = (A ∩ B)′, hence n(A′ ∪ B′) = n(U) − n(A ∩ B). A′∪B′ is "not in A OR not in B" = "not in both" = complement of A∩B.
Solution
1. Apply De Morgan: A′ ∪ B′ = (A ∩ B)′.This converts two complements into one, killing the need for n(A) and n(B) individually.
2. Count the complement: n((A ∩ B)′) = n(U) − n(A ∩ B) = n(U) − 15.
3. Substitute the given overlap n(A ∩ B) = 15.n(A)=45 and n(B)=30 are decoys — only the intersection enters the answer.
4. So n(A′ ∪ B′) = n(U) − 15. With the standard book universe n(U) = 60, this gives 45.The value is fully determined only once U is fixed; the reduction to n(U) − 15 is the key result the video teaches.
⚡ JEE Trick Whenever you see a union of complements (A′∪B′) or an intersection of complements (A′∩B′), reach for De Morgan first: A′∪B′ = (A∩B)′ and A′∩B′ = (A∪B)′. It collapses the problem to a single region. Trap: the large n(A), n(B) are there to tempt a longer, error-prone route.
Answer: n(A′ ∪ B′) = n(U) − 15 (= 45 when n(U) = 60).
4If A and B are disjoint, which is always true?Disjoint setswatch?v=xZELQc11ACY🟡 SimilarcA ∩ B = φ
Concept Two sets are disjoint when they share no element whatsoever. The defining property is an empty intersection, and a direct consequence is that counting their union involves no overlap subtraction — the sizes simply add.
Formula Disjoint ⇔ A ∩ B = φ, which forces n(A ∪ B) = n(A) + n(B). The general n(A∪B)=n(A)+n(B)−n(A∩B) loses its last term because n(A∩B)=0.
Solution
1. Definition of disjoint: no common elements → A ∩ B = φ.This is the statement that is always true and is the primary answer.
2. Equivalent count statement: n(A ∩ B) = 0, so n(A ∪ B) = n(A) + n(B).
3. Rule out traps: A ∪ B = φ is false (union can be large); A ⊆ B need not hold.
   ( A )   ( B )     ← two separate circles, no overlap
   A ∩ B = φ
   n(A∪B) = n(A) + n(B)
⚡ JEE Trick "Disjoint" = "mutually exclusive" = intersection empty. The instant giveaway in numeric problems: you may add the sizes with no subtraction. Trap: disjoint says nothing about the union being empty — only the intersection is empty.
Answer: A ∩ B = φ (equivalently n(A ∪ B) = n(A) + n(B)).

Concept 60 men received medals, yet 48 + 25 + 18 = 91 medals were given out — the surplus arises because a man who wins in two or three events is counted once per event. Split the 60 men into "exactly one / exactly two / exactly three" groups (e₁, e₂, e₃): the two given totals become two linear equations, and the exactly-two count falls out by a single subtraction. No individual pairwise overlap is ever needed — which is lucky, because none is given.
Formula n(A) + n(B) + n(C) = e₁ + 2e₂ + 3e₃ and n(A∪B∪C) = e₁ + e₂ + e₃. A man in exactly k events contributes k to the medal total but only 1 to the union of medal-winners. Data: event totals 48, 25, 18; total men = 60; e₃ = 5.
Solution
1. Medal-count equation: e₁ + 2e₂ + 3e₃ = 48 + 25 + 18 = 91.
2. Insert e₃ = 5: e₁ + 2e₂ = 91 − 15 = 76.
3. Every one of the 60 men holds at least one medal, so e₁ + e₂ + e₃ = 60 ⇒ e₁ + e₂ = 55.60 is the union count, not another medal total.
4. Subtract the equations: (e₁ + 2e₂) − (e₁ + e₂) = 76 − 55 ⇒ e₂ = 21.
5. Consistency check: e₁ = 55 − 21 = 34, and 34 + 2(21) + 3(5) = 34 + 42 + 15 = 91 ✓.

 (check: e1 = 34;  34 + 42 + 15 = 91 ok)
⚡ JEE Trick When a problem gives totals plus the triple but no pairwise counts, do not reach for full inclusion–exclusion — use the membership-count identity Σsingles = e₁ + 2e₂ + 3e₃ against the head-count e₁ + e₂ + e₃ and subtract. Trap: treating 91 as if it were n(A∪B∪C), or plugging 60 into the union formula and "solving" for a fictitious pair sum — both routes manufacture the wrong answer.

Concept A false-weight profit problem, not a sets problem. The seller quotes cost price, so he appears to make nothing — but he delivers only 450 g while charging for 500 g. His real gain is the 50 g he never handed over. Crucially, profit percentage is always measured on cost price, and his cost is the price of the 450 g he actually parted with.
Formula Profit% = (SP − CP)/CP × 100. For false weights: Gain% = (True weight − False weight)/(False weight) × 100. The denominator is the weight actually given away — that is what the goods cost him.
Solution
1. Let the cost price be ₹1 per gram (any convenient rate works, since the percentage is rate-independent).Choosing a unit rate turns weights straight into rupees.
2. The customer pays for 500 g at cost price ⇒ selling price received, SP = 500 × ₹1 = ₹500."Sells at cost price" fixes the rate he charges, not his honesty about quantity.
3. But he actually delivers only 450 g, so the goods that left his shop cost him CP = 450 × ₹1 = ₹450.He never bought the missing 50 g, so it must not enter his cost.
4. Profit = SP − CP = 500 − 450 = ₹50 on this transaction.
5. Profit% = (Profit / CP) × 100 = (50 / 450) × 100.Percentage is on cost 450, never on the 500 he collected.
