1The electronegativity of the following elements increases in the order (Level-1): (a) C, N, Si, P (b) N, Si, C, P (c) Si, P, C, N (d) P, Si, N, CElectronegativity orderThe electronegativity of the following elements increases in the order🟢 ExactcSi, P, C, N
Concept Electronegativity is fixed by two competing geometric facts: effective nuclear charge (pulls the bond pair in) and atomic size (pushes it away). Across a period Zeff rises while the shell number stays the same, so size shrinks and χ climbs; down a group a whole new shell is added, size jumps and χ falls. The four elements here straddle both directions — C and N sit in period 2, Si and P directly beneath them in period 3 — so you must apply both rules, not one.
Key relation χ increases left → right along a period and χ decreases top → bottom down a group. Consequence: any period-2 element beats the period-3 element directly below it, and within one period the one further right wins. Pauling values: C 2.55, N 3.04, Si 1.90, P 2.19.
Solution
1. Place the four elements on the table: C (grp 14, per 2), N (grp 15, per 2), Si (grp 14, per 3), P (grp 15, per 3).
2. Use the group rule on each vertical pair: C > Si and N > P.Si and P have one extra shell, so their bonding electrons are further from the nucleus and less strongly held.
3. Use the period rule on each horizontal pair: N > C and P > Si.N has one more proton than C at the same shell; same for P over Si.
4. Combine: Si is smallest of all four (lowest Zeff/size ratio), then P, then C, then N — i.e. Si < P < C < N.P (2.19) still loses to C (2.55) because C's period-2 shell is far more compact; the group effect outweighs one step along the period here.
5. The question asks for increasing order, so the answer is written smallest first: Si, P, C, N — option (c). (a) and (b) scramble the pairs, (d) is exactly reversed.

Concept The trap in this item is the Roman-numeral labelling: the elements are deliberately listed out of periodic order so that you must translate numerals → symbols → positions before ranking. Once translated, it is a routine two-rule problem: three of the four (Be, N, O) are period-2, only Mg is period-3, and Mg is also far to the left, so it must be last.
Key relation χ ∝ Zeff / (atomic size). Along period 2, Zeff grows Be(4) → N(7) → O(8) while the shell stays n = 2, so χ rises steadily. Pauling values: Be 1.57, N 3.04, O 3.44, Mg 1.31.
Solution
1. Decode the labels: I = Be (grp 2, per 2), II = O (grp 16, per 2), III = N (grp 15, per 2), IV = Mg (grp 2, per 3).
2. Rank the three period-2 elements by position along the period: Be (grp 2) < N (grp 15) < O (grp 16), so O > N > Be.
3. Place Mg: it sits directly below Be in group 2, so χ(Mg) < χ(Be) — Mg is last.Mg has three shells against Be's two; the added shell lowers the pull on a bond pair.
4. Full decreasing chain: O > N > Be > Mg = II > III > I > IV → option (a).

3Which is not correct order for the stated property? Concept Three of these four orders are plain applications of the smooth trends; one contains a famous anomaly. The anomaly to watch for in period 2 is the half-filled-subshell stability of nitrogen (2p³): removing an electron from a half-filled p-subshell costs extra energy, so N breaks the "IE rises left-to-right" rule and out-performs oxygen. Similarly, electron affinity has its own anomaly at fluorine (small size ⇒ inter-electron repulsion), which option (c) correctly reflects.
Key data Atomic radius down group 2: Mg < Ca < Sr < Ba. First IE (eV): N 14.53 > O 13.62, F 17.42. Electron affinity (eV, magnitude): Cl 3.6 > F 3.4 > Br 3.4 > I 3.1. Electronegativity down group 16: O 3.44 > S 2.58 > Se 2.55 > Te 2.10.
Solution
1. Test (a): Ba, Sr, Mg all belong to group 2 and radius increases down a group, so Ba > Sr > Mg is correct.
2. Test (b): the claimed order is F > O > N. The true first ionisation energies are F 17.42 > N 14.53 > O 13.62 eV, i.e. F > N > O.N is 1s²2s²2p³ — a stable, exactly half-filled 2p subshell — while O is 2p⁴ with one paired-up p orbital whose electron feels extra repulsion and leaves more easily. So (b) is the incorrect order.
3. Test (c): electron affinity Cl > F is the standard anomaly (F's 2p shell is tiny, so the incoming electron is strongly repelled), and I is largest and lowest — so Cl > F > I is correct.
4. Test (d): O, Se, Te go down group 16, so electronegativity falls — O > Se > Te is correct.
5. Exactly one option fails, and it is (b).

4Ionization potential and electron affinity of fluorine atom are 17.42 and 3.45 eV respectively. Calculate electronegativity of fluorine atom on Mulliken scale. (Level-4)Mulliken scaleIonisation potential and electron affinity of fluorine are 17.42 and 3.45 eV respectively🟢 ExactχM = 10.435
Concept Mulliken argued that an atom's pull on a shared pair should depend on both how reluctantly it gives an electron away (ionisation energy) and how eagerly it takes one in (electron affinity). An atom that is hard to ionise and loves extra electrons is exactly what "electronegative" means, so he simply took the arithmetic mean of the two. Unlike Pauling's scale, which is relative and thermochemical, the Mulliken scale is absolute — it comes straight from two measurable atomic energies.
Formula χM = (IE + EA) ÷ 2 with IE and EA in electron volts. Both quantities are entered as positive magnitudes; the value that comes out is on the Mulliken scale, which runs about 2.8 times larger than Pauling's. Conversion when needed: χP = χM ÷ 2.8.
Solution
1. Read off the data: IE = 17.42 eV, EA = 3.45 eV — already in eV, so no conversion is required.If the data had been in kJ mol⁻¹ you would divide by 96.48 first, since 1 eV/molecule = 96.48 kJ mol⁻¹.
2. Add: IE + EA = 17.42 + 3.45 = 20.87 eV.
3. Halve: χM = 20.87 ÷ 2 = 10.435.
4. Sanity-check the magnitude: dividing by 2.8 gives χP = 10.435 ÷ 2.8 ≈ 3.73, which is close to fluorine's accepted Pauling value of 4.0 — so the arithmetic is sound.Mulliken values always look "too big"; that is the scale, not an error.
5. Report the Mulliken value as asked: 10.435 (dimensionless on the Mulliken scale).

⚡ JEE Trick Keep three one-line versions of the same formula ready and pick by the unit given: eV → χM = (IE+EA)/2; eV → χP = (IE+EA)/5.6; kJ mol⁻¹ → χP = (IE+EA)/540. Trap: the question says "on Mulliken scale", so you must not divide by 2.8 — an answer of 3.73 is the Pauling value and scores zero here.

5Calculate the electronegativity of fluorine atom from the following data (Level-5): EH–H = 104.2 Kcal/mol, EF–F = 36.6 Kcal/mol, EH–F = 134.6 Kcal/mol, χH = 2.1Pauling scale numericalCalculate the electronegativity of fluorine on Pauling scale from the following data🟢 ExactχF ≈ 3.87
Concept Pauling's scale is thermochemical. He noticed that a real A–B bond is always stronger than the purely covalent bond you would predict, and attributed the excess to ionic resonance caused by unequal sharing. The "purely covalent" reference is taken as the geometric mean of the two homonuclear bond energies, and the excess energy Δ is converted into an electronegativity difference by a fixed constant. So the calculation is always: build the reference, subtract, take a square root, scale.
Formula Δ = EA–B − √(EA–A × EB–B) and χA − χB = 0.208 √Δ with Δ in kcal mol⁻¹. The 0.208 is the kcal constant; in kJ mol⁻¹ the same equation reads χA − χB = 0.1017 √Δ.
Solution
1. Build the 100 % covalent reference for H–F as the geometric mean:Ecov = √(EH–H × EF–F) = √(104.2 × 36.6) = √3813.7 = 61.75 kcal mol⁻¹.
2. Subtract it from the observed bond energy to get the extra ionic resonance energy:Δ = 134.6 − 61.75 = 72.85 kcal mol⁻¹ — a large Δ, which already tells you H–F is strongly polar.
3. Take the square root: √72.85 = 8.535.
4. Multiply by the Pauling constant: χF − χH = 0.208 × 8.535 = 1.775.
5. Add the known hydrogen value: χF = 2.1 + 1.775 = 3.875 ≈ 3.87, in good agreement with the standard 3.98/4.0 for fluorine.

1Define electronegativity.DefinitionDefine electronegativity — and how it differs from electron gain enthalpy🟢 Exact—
Concept Electronegativity is a property of a bonded atom, not a free one. When two atoms are joined by a covalent bond, the shared pair does not sit exactly midway unless the atoms are identical; the atom that pulls it closer is said to be more electronegative. Because it is defined by a tug-of-war rather than by an energy measurement on an isolated atom, electronegativity has no unit and only relative scales (Pauling, Mulliken, Allred–Rochow) exist.
Definition "Electronegativity is the power of an atom in a molecule to attract the shared pair of electrons towards itself." — Pauling, who used the term for the first time. The words "in a molecule" and "shared pair" are the mark-earning parts: they distinguish it from electron affinity, which is measured on an isolated gaseous atom.
Solution
1. State Pauling's definition exactly as above — the examiner looks for "power to attract the shared pair of electrons".
2. Add the crucial qualifier: it is the property of a bonded atom, so an isolated atom has no electronegativity.
3. Note that it has no unit — it is a comparative number on a chosen scale.On the Pauling scale F = 3.98 (taken as ≈ 4.0) and Cs = 0.7; noble gases are assigned 0 because they do not normally form bonds.
4. Give the mechanism: when two atoms are linked by a covalent bond, the bond pair is drawn towards the more electronegative atom, which develops a partial negative charge δ⁻ while the other becomes δ⁺.
5. Close with the scales available — Pauling (thermochemical), Mulliken (χ = (IE + EA)/2) and the note that most electronegative = F, least = Cs.

Concept These two quantities describe the same instinct — "this atom wants electrons" — but in two completely different physical situations. Electron gain enthalpy is a thermodynamic quantity: take one isolated gaseous atom, hand it an electron, and measure the heat change. Electronegativity is a bookkeeping number for an atom already inside a molecule sharing a pair. Because a real experiment can only be performed on the first situation, ΔHeg is measurable and electronegativity is not.

3. State the answer to the specific question: only electron gain enthalpy can be measured experimentally.Electronegativity cannot, because you cannot isolate the "pull of one atom" inside a bond; it must be derived — from bond energies (Pauling), or from IE and EA (Mulliken).

3Explain the trends or variation in electronegativity.Periodicity in χWhy electronegativity increases across a period and decreases down a group🟢 Exact—
Concept Every electronegativity trend reduces to one ratio: how strongly the nucleus grips an electron sitting at the bonding distance. That grip rises with effective nuclear charge and falls with atomic size and screening. Along a period, protons are added while the shell number is fixed → Zeff up, size down, χ up. Down a group, an entire new shell plus its screening is added → size up, grip down, χ down. Everything else (hybridisation, oxidation state) is a refinement of the same idea.
Key relation χ ∝ Zeff / r² qualitatively. Along period 2: Li 0.98, Be 1.57, B 2.04, C 2.55, N 3.04, O 3.44, F 3.98 — a near-linear climb. Down group 17: F 3.98, Cl 3.16, Br 2.96, I 2.66 — a steady fall.
Solution
1. Along a period (left → right): χ increases. Nuclear charge rises by one proton per step while electrons enter the same shell, so Zeff rises and the atom contracts; the bond pair is held more tightly.Period 2 values: Li 0.98 → Be 1.57 → B 2.04 → C 2.55 → N 3.04 → O 3.44 → F 3.98.
2. Down a group: χ decreases. Each step adds a new shell; the valence electrons are further out and better screened by the inner shells, so the nuclear pull on the shared pair weakens.Group 17: F 3.98 → Cl 3.16 → Br 2.96 → I 2.66.
3. Effective nuclear charge: the greater the Zeff experienced by the valence shell, the greater the χ — this is the master variable behind both trends above.
4. Screening (shielding) effect: more inner electrons ⇒ more repulsion felt by the bond pair ⇒ lower χ.
5. Oxidation state: an atom in a higher oxidation state has a higher effective nuclear charge and hence higher χ — e.g. χ(Fe³⁺) > χ(Fe²⁺), χ(Cu²⁺) > χ(Cu⁺).
6. Hybridisation: more s-character ⇒ the electron cloud lies closer to the nucleus ⇒ higher χ — sp (50 % s) 3.29 > sp² (33 %) 2.75 > sp³ (25 %) 2.48.
7. Extremes to quote: F is the most electronegative element, Cs the least; noble gases are assigned χ = 0 because of their inert nature.

4Explain : The elements Li, Be, B, C and N have the electronegativities 1.0, 1.5, 2.0, 2.5, and 3.0 respectively on the Pauling scale.Period-2 χ progressionElectronegativity — definition, trends and worked examples🟡 Similar—
Concept This is the period-2 trend shown with numbers, and the striking feature is that the values rise in an almost constant step of 0.5. That regularity is not an accident: from Li to N the nuclear charge climbs one unit at a time (Z = 3, 4, 5, 6, 7) while every added electron goes into the same second shell, where electrons of the same shell screen each other very poorly (screening constant ≈ 0.35 per electron only). So each extra proton contributes roughly 0.65 units of extra effective nuclear charge — a near-uniform increment, and χ rises in near-uniform steps.
Key relation Zeff = Z − σ and χ ↑ as Zeff ↑ and r ↓. Across period 2 the outer electrons enter n = 2 throughout, so σ grows only slowly while Z grows by 1 each step — the net pull therefore grows steadily and the atom simultaneously contracts (Li 152 pm → N 70 pm).
Solution
1. Write the electronic configurations to see that the shell never changes:Li 2,1 · Be 2,2 · B 2,3 · C 2,4 · N 2,5 — every valence electron is in the second shell.
2. Note the nuclear charge rising one step at a time: Z = 3, 4, 5, 6, 7 for Li, Be, B, C, N.
3. Because same-shell electrons shield each other poorly, each extra proton is only partly cancelled, so Zeff increases steadily from Li to N.
4. The rising Zeff pulls the whole shell inwards, so atomic radius decreases across the period (Li 152 pm → Be 111 → B 88 → C 77 → N 70 pm).
5. Higher Zeff acting over a shorter distance means a stronger grip on a shared pair, so electronegativity rises — and because the increments in Zeff are nearly equal, χ rises in nearly equal steps of 0.5: 1.0, 1.5, 2.0, 2.5, 3.0.
6. Chemical consequence worth adding: Li (χ 1.0) is a metal that loses electrons, N (χ 3.0) is a non-metal that pulls them in — the metallic character falls exactly as χ rises across the period.

Two clean paths exist: convert kcal mol⁻¹ → eV by dividing by 23.06 and then use the ÷5.6 rule, or convert kcal mol⁻¹ → kJ mol⁻¹ by multiplying by 4.184 and then use the ÷540 rule. Both must give the same number, which is a good way to check yourself under exam conditions.
Formula χP = (IE + EA) ÷ 5.6 with energies in eV, or χP = (IE + EA) ÷ 540 with energies in kJ mol⁻¹. Conversions: 1 eV/molecule = 23.06 kcal mol⁻¹ = 96.48 kJ mol⁻¹; and 2 × 96.48 × 2.8 ≈ 540, which is where the 540 comes from.
Solution
1. Add the two energies in the units given: IE + EA = 275 + 86 = 361 kcal mol⁻¹.
2. Route A (via eV): 361 ÷ 23.06 = 15.65 eV, then χP = 15.65 ÷ 5.6 = 2.795 ≈ 2.8.
3. Route B (via kJ): 361 × 4.184 = 1510.4 kJ mol⁻¹, then χP = 1510.4 ÷ 540 = 2.797 ≈ 2.8 — the two routes agree.
4. Therefore the Pauling electronegativity is 2.8 → option (a).A χ of 2.8 corresponds to an element such as bromine (2.96) or a carbon/sulphur-like non-metal — entirely plausible for IE ≈ 275 kcal mol⁻¹ (≈ 11.9 eV).
5. Eliminate: (c) 4.0 is fluorine's value and would need a much larger IE; (d) 2.6 comes from dividing by 5.8 or from sloppy rounding; (b) 0.0 is the noble-gas convention and is meaningless for an element with a real electron affinity.

Concept Going down group 17 the atoms get steadily bigger, and almost everything that depends on the nucleus's grip therefore weakens: electronegativity falls, ionisation energy falls, and oxidising power (the drive to grab an electron and become X⁻) falls. The one property that rises is any length: bigger atoms make longer X–X bonds and longer H–X bonds. So the question reduces to spotting the single "length" option among four.
Key data Atomic radius (Å): F 0.72 < Cl 0.99 < Br 1.14 < I 1.33 — increasing. χ: F 4 > Cl 3 > Br 2.8 > I 2.5. IE (eV): F 17.4 > Cl 13 > Br 11.8 > I 10.4. Solution
1. (a) Bond length — INCREASES, so it does not qualify. Atomic radius grows from 0.72 Å (F) to 1.33 Å (I), so both the X–X and H–X bond lengths grow. ✗
2. (b) Electronegativity — DECREASES. The bigger, better-screened atoms hold a shared pair less tightly: 4 → 3 → 2.8 → 2.5. ✓
3. (c) Ionisation energy — DECREASES. The outermost electron is further from the nucleus and more shielded, so less energy is needed to remove it: 17.4 → 13 → 11.8 → 10.4 eV. ✓
4. (d) Oxidising power — DECREASES. An oxidising agent must accept electrons; as the halogen grows, its attraction for an extra electron weakens, so F₂ > Cl₂ > Br₂ > I₂.Chemical proof: F₂ displaces Cl⁻, Br⁻ and I⁻ from their salts; I₂ displaces none of them.
