Concept A number is a 15ᵗḤ root of unity exactly when z¹⁵ = 1, and a 25ᵗḤ root exactly when z²⁵ = 1. Anything in both sets satisfies zᵈ = 1 for every integer combination d = 15m + 25n, and the smallest positive such d is gcd(15, 25). So the overlap is not a random handful of points — it is itself a complete set of roots of unity, of order gcd(15, 25) = 5. Counting the answer therefore reduces to counting the solutions of z⁵ = 1.
Formula {z : zⁿ = 1} ∩ {z : zᵐ = 1} = {z : zᵍ = 1}, g = gcd(n, m), so the count is gcd(n, m). Each set is a cyclic group of points on the unit circle, and two cyclic groups of orders n and m meet in one of order gcd(n, m).
Solution
1. Let z lie in both sets, so z¹⁵ = 1 and z²⁵ = 1 simultaneously.
2. Divide the two: z²⁵/z¹⁵ = z¹⁰ = 1, and then z¹⁵/z¹⁰ = z⁵ = 1. This is the Euclidean algorithm on the exponents 25 and 15, and it must stop at their gcd.
3. Conversely, if z⁵ = 1 then z¹⁵ = (z⁵)³ = 1 and z²⁵ = (z⁵)⁵ = 1, so every 5ᵗḤ root does belong to both families.
4. Hence the common set is exactly {z : z⁵ = 1} = {1, e^(2πi/5), e^(4πi/5), e^(6πi/5), e^(8πi/5)}, which has 5 members.
5. Index cross-check: with z = e^(2πik/15) the matches are k = 0, 3, 6, 9, 12; with z = e^(2πij/25) they are j = 0, 5, 10, 15, 20 — five points, listed twice. Both lists name the same five vertices of a regular pentagon.
6. So the required number is gcd(15, 25) = 5, which is option (b).

Formula |a + ib| = √(a² + b²), and |u| ≥ c ⇔ u ≥ c or u ≤ −c for c > 0. The modulus is a distance, so a lower bound on it means lying outside a disc, i.e. outside an interval once one coordinate is fixed.
Solution

Concept The coefficients 1+i, −(7+3i) and 6+8i are not real, so the familiar rule "complex roots occur in conjugate pairs" is simply unavailable here — that theorem needs real coefficients. What does survive is Vieta: for any quadratic ax² + bx + c = 0 over the complex numbers, the sum of the roots is −b/a and the product is c/a. Knowing one root, either relation delivers the other in a single division. The product route is cleanest because c/a simplifies to a tidy number.
Formula α + β = −b/a, αβ = c/a, valid for complex a, b, c with a ≠ 0. Vieta follows from comparing ax² + bx + c with a(x − α)(x − β), an identity that never used realness.
Solution

2. Product of roots: αβ = c/a = (6 + 8i)/(1 + i) = (6 + 8i)(1 − i)/2 = (14 + 2i)/2 = 7 + i. Multiplying by the conjugate 1 − i clears the denominator to |1 + i|² = 2.
3. Divide out α: β = (7 + i)/(4 − 3i) = (7 + i)(4 + 3i)/25 = (25 + 25i)/25 = 1 + i.
4. Confirm with the sum: −b/a = (7 + 3i)/(1 + i) = (7 + 3i)(1 − i)/2 = (10 − 4i)/2 = 5 − 2i.
5. Indeed (4 − 3i) + (1 + i) = 5 − 2i, so both Vieta relations agree on β = 1 + i. Two independent checks on the same root is the whole safety net when the coefficients are complex.
6. Therefore the other root is 1 + i, option (a). Note it is not 4 + 3i: with non-real coefficients the conjugate of a root need not be a root.

4. Take differences of the two lists: from arg z₁ = π/6 to 5π/6 gives 2π/3; from 0 to 5π/6 gives 5π/6; from −π/6 to 5π/6 gives π.
5. The remaining pairs repeat these three numbers only — the full set of attainable angles is {2π/3, 5π/6, π}. Symmetry about the real axis pairs each choice with its mirror image.
6. Of the options, 2π/3 (c) and 5π/6 (d) are attainable; π is attainable but not offered.
7. π/2 and π/6 are impossible: the two half-planes are separated by the strip |Re z| ≤ 1/2, which keeps every such angle at 2π/3 or more.
  w = e^(i pi/6);   P = 12th roots of unity
  Re > 1/2  : cos(n pi/6) > 1/2
      arg z1 in { -pi/6, 0, pi/6 }
  Re < -1/2 : cos(n pi/6) < -1/2
      arg z2 in { 5pi/6, pi, 7pi/6 }
  angle = |arg z1 - arg z2| folded to [0, pi]
  possible : 2pi/3, 5pi/6, pi
  offered  : (c) 2pi/3 and (d) 5pi/6
⚡ JEE Trick The strictness of the inequalities is the whole distractor design: if 2π/3 had been allowed in H₂, the pair (eiπ/6, e2iπ/3) would give exactly π/2, which is option (a). Option (b) π/6 is the gap between neighbouring points of P and can never occur across the forbidden strip. Also resist assuming z₁ and z₂ are unique — P ∩ H₁ and P ∩ H₂ have three elements each, which is why the question is multiple-correct.
Answer: (c) 2π/3 and (d) 5π/6.
18Let z = x + iy be a complex number where x and y are integers. Then the area of the rectangle whose vertices are the roots of the equation z z̄³ + z̄ z³ = 350 is (a) 48 (b) 32 (c) 40 (d) 80 (JEE Advanced 2009) (Level-10)Roots in Argand planeLet z=x+iy be a complex number where x and y are integers. Then area of rectangle zz'^3+z'z^3=350🟢 Exacta48
Concept The expression z z̄³ + z̄ z³ is symmetric in z and z̄, so it collapses to real quantities: pull out the common factor z z̄ = |z|² and what remains is z² + z̄² = 2(x² − y²). The equation therefore becomes a Diophantine one in x and y, and the restriction to integers is what makes it finite. Because only x², y² appear, the solutions come in the four sign combinations (±x, ±y), which are automatically the corners of an axis-parallel rectangle centred at the origin.
Formula z z̄ = x² + y² and z² + z̄² = 2(x² − y²). The imaginary parts of z² and z̄² are ±2xy and cancel, leaving a real sum.
Solution
1. Factor: z z̄³ + z̄ z³ = z z̄(z̄² + z²) = (x² + y²)·2(x² − y²) = 2(x⁴ − y⁴).
2. So 2(x⁴ − y⁴) = 350, i.e. x⁴ − y⁴ = 175 with x, y integers.
3. Put a = x² and b = y², both non-negative integers: (a − b)(a + b) = 175 = 5² × 7. 175 is odd, so both factors are odd and a, b come out as integers automatically.
4. The factor pairs with a − b < a + b are (1, 175) ⇒ a = 88, b = 87; (5, 35) ⇒ a = 20, b = 15; (7, 25) ⇒ a = 16, b = 9.
5. Only the third pair makes a and b perfect squares: x² = 16 and y² = 9, so x = ±4 and y = ±3. 88, 87, 20 and 15 are not squares, so those branches give no lattice point.
6. The roots are 4 + 3i, 4 − 3i, −4 + 3i, −4 − 3i — a rectangle centred at O with horizontal side 8 and vertical side 6. Each vertex has modulus 5, so all four lie on the circle |z| = 5, confirming a rectangle.
7. Area = 8 × 6 = 48.
  z zb^3 + zb z^3 = z zb (z^2 + zb^2)
         = (x^2 + y^2) * 2(x^2 - y^2) = 350
  ->  x^4 - y^4 = 175;   a = x^2,  b = y^2
  (a-b)(a+b) = 175 :
     (1,175) -> a=88, b=87   not squares
     (5, 35) -> a=20, b=15   not squares
     (7, 25) -> a=16, b= 9   x=+-4, y=+-3
  sides 8 and 6   ->   area = 48
⚡ JEE Trick The single decisive move is spotting the common factor z z̄, which turns a fourth-degree complex expression into x⁴ − y⁴ in one line. Then the integer condition is not decoration — it is the only reason the factor search terminates at (7, 25). Distractor (b) 32 is the area for sides 8 and 4, and (c) 40 comes from using the modulus 5 as a side instead of 6; (d) 80 doubles the rectangle by treating the full diagonals as sides.
Answer: (a) 48.
