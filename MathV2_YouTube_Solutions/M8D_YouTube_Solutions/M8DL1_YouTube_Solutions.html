1 (i)Sum of n natural number is ______.Σn — sum of the first n natural numbersSum of first n Natural, odd, even, Square & Cubes numbers | Maths Short Tricks🟢 Exactn(n + 1)/2
Concept The natural numbers 1, 2, 3, … are the simplest arithmetic progression there is: first term a = 1 and common difference d = 1. So the "sum of n natural numbers" is not a new formula at all — it is the A.P. sum formula with the easiest possible a and d. Every other result in this chapter (Σn², Σn³, telescoping sums) is eventually reduced back to this one.
Formula Sₙ = (n/2)(a + ℓ) with a = 1 and ℓ = n, giving Σn = 1 + 2 + 3 + … + n = n(n + 1)/2. The module derives it exactly this way on page 71: an arithmetic series with a = 1, d = 1, last term ℓ = n.
Solution
1. Write Sₙ = 1 + 2 + 3 + … + n. This is arithmetic: each term exceeds the previous by 1.
2. Identify a = 1 (first term), ℓ = n (last term), number of terms = n.
3. Apply Sₙ = (n/2)(a + ℓ) = (n/2)(1 + n).The "pair the ends" proof: 1 + n = 2 + (n−1) = 3 + (n−2) = … , and there are n/2 such pairs each summing to n + 1.
4. Hence Σn = n(n + 1)/2.
5. Numeric sanity check with n = 4: formula gives 4·5/2 = 10, and 1 + 2 + 3 + 4 = 10 ✓
6. Second check with n = 10: 10·11/2 = 55, matching Suggested Problem 2 of this very lecture ✓
   1  +  2  +  3  + ... + (n-1) +  n
   n  + (n-1)+ (n-2)+ ... +  2   +  1     <-- same sum, reversed
  ---------------------------------------
 (n+1)+(n+1) +(n+1) + ... +(n+1) +(n+1)   = n(n+1)

  so  2*S_n = n(n+1)   =>   S_n = n(n+1)/2
⚡ JEE Trick Store this as the "triangular number" Tₙ = n(n+1)/2. It shows up disguised everywhere: 1 + (1+2) + (1+2+3) + … is a sum of triangular numbers, and Σn³ is literally the square of this one. Trap: writing n(n−1)/2 — that counts pairs, not the sum.
Answer: Σn = n(n + 1)/2.
1 (ii)Sum of odd n natural number is ______.Sum of the first n odd natural numbersSum of first n Natural, odd, even, Square & Cubes numbers | Maths Short Tricks🟢 Exactn²
Concept The odd numbers 1, 3, 5, 7, … form an A.P. with a = 1 and d = 2, so their sum is again just the A.P. sum formula. What makes this one worth memorising is how astonishingly clean the answer is: the sum of the first n odd numbers is a perfect square, n². That single fact converts many "sum of an odd-indexed series" questions into one line.
Formula 1 + 3 + 5 + … + (2n − 1) = n², from Sₙ = (n/2)[2a + (n − 1)d] with a = 1, d = 2. The nth odd number is 2n − 1 — memorise that, it is the general term of half the questions in this lecture.
Solution
1. The odd numbers are 1, 3, 5, …; the nth one is Tₙ = 1 + (n − 1)·2 = 2n − 1.
2. Apply Sₙ = (n/2)[2a + (n − 1)d] with a = 1, d = 2: Sₙ = (n/2)[2 + 2(n − 1)].
3. Simplify inside the bracket: 2 + 2n − 2 = 2n.
4. So Sₙ = (n/2)(2n) = n².Equivalently: Σ(2k − 1) = 2·Σk − Σ1 = 2·n(n+1)/2 − n = n² + n − n = n².
5. Numeric sanity check, n = 5: 1 + 3 + 5 + 7 + 9 = 25 = 5² ✓
6. This same result is asked again as Level-3 Q5 of this lecture, where option (b) n² is the key.
  n = 1 :  1                  = 1  = 1^2
  n = 2 :  1+3                = 4  = 2^2
  n = 3 :  1+3+5              = 9  = 3^2
  n = 4 :  1+3+5+7            = 16 = 4^2
  n = 5 :  1+3+5+7+9          = 25 = 5^2
⚡ JEE Trick Two companion facts to lock in together: sum of first n odd numbers = n²; sum of first n even numbers = n(n+1) = n² + n — exactly n bigger. If you can only remember one, remember n² and add n for the even case.
Answer: 1 + 3 + 5 + … + (2n − 1) = n².

Concept The even numbers 2, 4, 6, … are just twice the natural numbers. So instead of running the A.P. machinery again, pull the 2 out of the sum: Σ(2k) = 2Σk. Recognising a constant multiple and factoring it out of a Σ is the single most-used move in this whole chapter.
Formula 2 + 4 + 6 + … + 2n = 2Σk = 2 · n(n + 1)/2 = n(n + 1). Σ(c·aₖ) = c·Σaₖ — constants slide straight through a summation sign.
Solution
1. The nth even number is 2n, so the sum required is Σk=1n 2k.
2. Factor the constant out: Σ 2k = 2 Σ k.
3. Substitute Σk = n(n + 1)/2 from part (i): 2 · n(n + 1)/2.
4. The 2's cancel, leaving n(n + 1) = n² + n.
5. Numeric sanity check, n = 4: 2 + 4 + 6 + 8 = 20, and 4·5 = 20 ✓
6. Cross-check against (ii): odd sum 16 + n = 4 gives 20 ✓ — the even sum always exceeds the odd sum by n.
  evens :  2   4   6  ...  2n
        =  2*(1 + 2 + 3 + ... + n)

Concept The general term is a sum of two completely different animals: a polynomial piece n² and a geometric piece 2n. Summation is linear, so you split at the plus sign and handle each piece with its own formula — never try to force one formula onto both.
Formula Σk² = n(n+1)(2n+1)/6 and Σ2k = 2(2n − 1)/(2 − 1) = 2(2n − 1). The second is the G.P. sum a(rn − 1)/(r − 1) with a = 2, r = 2.
Solution
1. Sₙ = Σk=1n (k² + 2k) = Σk² + Σ2k.Linearity of Σ — you may split a sum, never a product.
2. First piece: Σk=1n k² = n(n + 1)(2n + 1)/6 (standard).
3. Second piece: 21 + 22 + … + 2n is a G.P. with a = 2, r = 2, n terms.
4. Its sum = a(rn − 1)/(r − 1) = 2(2n − 1)/1 = 2(2n − 1) = 2n+1 − 2.
5. Add them: Sₙ = n(n + 1)(2n + 1)/6 + 2(2n − 1).
6. Numeric sanity check, n = 3: terms are 1+2 = 3, 4+4 = 8, 9+8 = 17, total 28. Formula: 3·4·7/6 + 2(8 − 1) = 14 + 14 = 28 ✓

  telescope : 3*k(k+1) = k(k+1)(k+2) - (k-1)k(k+1)
              => sum = n(n+1)(n+2)/3
⚡ JEE Trick Memorise the consecutive-product family in one go: Σk(k+1) = n(n+1)(n+2)/3 and Σk(k+1)(k+2) = n(n+1)(n+2)(n+3)/4. Pattern: append the next integer on top, divide by the number of factors in the term plus one. This one line answers Level-5 Q1's parent series and this question instantly.
Answer: (b) (1/3)n(n + 1)(n + 2).
9Find the sum to n terms of the series whose nth terms is n² + 2n.
(a) (n/6)(n+1)(2n+1) + 2(2n − 1)   (b) (n/5)(n+1)(n+2) + 2(2n + 1)   (c) (n/4)(n+1)(2n+1) + 2(2n + 1)   (d) (n/6)(n+1)(n+2) + 2(2n − 1)		Polynomial plus geometric general termClass 11 maths chapter-9 Sequences and series: Ex 9.4 intro with examples: sum of special series🟡 Similara(n/6)(n + 1)(2n + 1) + 2(2n − 1)
Concept Quick Recap 1(iv) returning as a four-option MCQ. Split at the plus sign: the n² piece is a power sum, the 2n piece is a G.P. Then match. Two features identify the answer at once — the polynomial factor must be (n+1)(2n+1) with a /6, and the geometric piece must be 2(2n − 1), since a G.P. sum always ends in "−1" after the first term is factored out.
Formula Σk² = n(n+1)(2n+1)/6; Σk=1n2k = 2(2n − 1)/(2 − 1) = 2(2n − 1). G.P. with a = 2, r = 2, n terms.
Solution
1. Sₙ = Σ(k² + 2k) = Σk² + Σ2k.
2. Polynomial piece: Σk² = n(n+1)(2n+1)/6 = (n/6)(n+1)(2n+1).
3. Geometric piece: 2 + 4 + 8 + … + 2n = 2(2n − 1)/(2 − 1) = 2(2n − 1).
4. Adding gives (n/6)(n+1)(2n+1) + 2(2n − 1) ⇒ option (a).
5. Numeric sanity check, n = 1: T₁ = 1 + 2 = 3; option (a) gives (1/6)(2)(3) + 2(2 − 1) = 1 + 2 = 3 ✓
6. Second check, n = 3: terms 3, 8, 17 → sum 28. Option (a): (3/6)(4)(7) + 2(8 − 1) = 14 + 14 = 28 ✓
7. Reject (b) and (c) at n = 1: (b) gives (1/5)(2)(3) + 2(3) = 1.2 + 6 = 7.2 ✗; (c) gives (1/4)(2)(3) + 6 = 7.5 ✗
8. Reject (d) at n = 3: (3/6)(4)(5) + 14 = 10 + 14 = 24 ✗ — it uses (n+2) instead of (2n+1).
  S_n = Sum k^2  +  Sum 2^k
      = n(n+1)(2n+1)/6  +  2(2^n - 1)

  n=1 : 1 + 2 = 3    ->  1 + 2 = 3      OK
  n=3 : 3+8+17 = 28  ->  14 + 14 = 28   OK
⚡ JEE Trick A finite G.P. sum with r = 2 always takes the form a(2n − 1); a "+1" inside the bracket is a giveaway that an option is fake. Combine that with the polynomial signature (2n+1)/6 for Σk² and you can pick option (a) by pattern recognition alone, before any computation.
Answer: (a) (n/6)(n + 1)(2n + 1) + 2(2n − 1).
10Find Σr=1n [(1² + 2² + 3² + …. + r²)/(2r + 1)]
(a) n(n−1)(n−2)/16   (b) n(n+1)(n+2)/18   (c) n(n+1)(2n+1)/18   (d) n(n−1)(2n−1)/16		Cancelling (2r+1) against the square-sum formulaVn Method | PART-19 | Sequence & Series Class-11 CBSE/JEE Maths🟡 Similarbn(n + 1)(n + 2)/18
Concept The denominator (2r + 1) is not decoration — it is precisely one of the three factors in the square-sum formula r(r+1)(2r+1)/6. Substitute the formula and the (2r+1) cancels outright, leaving r(r+1)/6. What remains is the familiar consecutive-product sum. Recognising this cancellation is the entire question.
Formula 1²+…+r² = r(r+1)(2r+1)/6, so the summand is r(r+1)/6, and Σr(r+1) = n(n+1)(n+2)/3. The two 6 and 3 combine into the 18 in the answer.
Solution
1. Inner sum: 1² + 2² + … + r² = r(r + 1)(2r + 1)/6.
2. Divide by (2r + 1): the factor cancels exactly, leaving r(r + 1)/6.This is why the setter chose 2r + 1 as the denominator rather than any other linear expression.
3. So the required sum is Σr=1n r(r+1)/6 = (1/6)Σr(r+1).
4. From Level-6 Q8, Σr(r+1) = n(n+1)(n+2)/3.
5. Therefore the answer = (1/6) · n(n+1)(n+2)/3 = n(n + 1)(n + 2)/18 ⇒ option (b).
6. Numeric sanity check, n = 1: the single term is (1)/(3) = 1/3; formula 1·2·3/18 = 6/18 = 1/3 ✓
7. Second check, n = 2: add (1+4)/5 = 1, so total 4/3; formula 2·3·4/18 = 24/18 = 4/3 ✓
8. Third check, n = 3: add (1+4+9)/7 = 2, so total 10/3; formula 3·4·5/18 = 60/18 = 10/3 ✓
9. Reject (a) and (d) on sight: both vanish at n = 1, but the sum there is 1/3 ≠ 0.
  (1^2+...+r^2)/(2r+1) = [r(r+1)(2r+1)/6] / (2r+1)
                       = r(r+1)/6

  Sum = (1/6) * Sum r(r+1)
      = (1/6) * n(n+1)(n+2)/3
      = n(n+1)(n+2)/18

  n=1 : 1/3    n=2 : 4/3    n=3 : 10/3    (all check)
⚡ JEE Trick When a summand has an awkward denominator, ask whether it is a factor of the numerator's closed form before doing anything else. Denominators of 2r+1, r, r+1 in a Σn² context almost always cancel. Options (a) and (d) can also be killed instantly by the n = 1 test: any correct sum must equal the first term, never 0.
Answer: (b) n(n + 1)(n + 2)/18.
