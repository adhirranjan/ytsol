1Find the equivalent spring constant: three springs in series (k₁ = 600, k₂ = 300, k₃ = 200 N/m) with a hanging mass (Level-1)Springs in seriesEquivalent spring constant of a system of springs🟡 Similar100 N/m
Concept Three springs hang one below the other from the ceiling, so they are in series. The defining feature of a series chain is that the same tension runs through every spring — each light spring simply passes the load mg down to the next one — while the stretches add up, because the block drops by the total of all three extensions. That combination (same force, added displacements) is what makes the reciprocals add, and it guarantees keq comes out smaller than the softest spring.
Formula 1/keq = 1/k₁ + 1/k₂ + 1/k₃, with every k in N m⁻¹. Each spring obeys Hooke's law x = F ÷ k (m = N ÷ N m⁻¹), so with a common F the total stretch is F(1/k₁+1/k₂+1/k₃) = F/keq — the F cancels and the reciprocals add. Data from the figure: k₁ = 600, k₂ = 300, k₃ = 200 N m⁻¹.
Solution
1. Confirm the arrangement: ceiling → k₁ → k₂ → k₃ → block, one below the other ⇒ series.The load has only one path to the ceiling, so every spring carries the identical tension mg.
2. Write the tension: each light spring carries T = mg (N).A massless spring transmits force unchanged — its own weight adds nothing.
3. Add the stretches: x = x₁ + x₂ + x₃ = mg/600 + mg/300 + mg/200 (m).The block's total drop is the sum of the three individual extensions.
4. Divide out mg: 1/keq = 1/600 + 1/300 + 1/200 (m N⁻¹).
5. Take LCM 600: 1/keq = (1 + 2 + 3)/600 = 6/600 = 1/100 m N⁻¹.1/300 = 2/600 and 1/200 = 3/600 — putting all three over 600 makes the sum trivial.
6. Invert: keq = 100 N m⁻¹.Units check: the reciprocal of m N⁻¹ is N m⁻¹ ✓ — a spring constant, as required.

2Find the equivalent spring constant: three springs (k₁ = 50, k₂ = 60, k₃ = 90 N/m) in parallel, force F applied (Level-2)Springs in parallelSeries & parallel spring combinations (Hooke's law)🟡 Similar200 N/m
Concept Here all three springs are anchored to the same fixed support on the left and all three grab the same block on the right, so they are in parallel. The signature of a parallel set is the mirror image of series: every spring suffers the same elongation x (they all span the same gap), while the forces add, because the block feels all three pulls at once. Hence the constants add directly, and keq is larger than the stiffest spring.
Formula keq = k₁ + k₂ + k₃, each in N m⁻¹. Common x gives Ftotal = k₁x + k₂x + k₃x = (k₁+k₂+k₃)x ≡ keqx — the x cancels, so the constants add. From the figure: k₁ = 50, k₂ = 60, k₃ = 90 N m⁻¹, with force F applied to the block.
Solution
1. Identify the geometry: all three springs run from the same wall to the same block ⇒ parallel.They share both end points, so they are forced to change length by the same amount.
2. Impose the common elongation: x₁ = x₂ = x₃ = x (m).The block is rigid and moves as one piece, dragging every spring by the identical x.
3. Add the forces the block feels: F = 50x + 60x + 90x (N).Each spring independently pulls back with kx; the block's equilibrium sums them.
4. Factor x: F = (50 + 60 + 90)x = 200x (N).
5. Compare with F = keqx ⇒ keq = 200 N m⁻¹.Units: N m⁻¹ ✓. And 200 > 90, the stiffest spring — correct for parallel.

The two springs 2K and 4K both run from the wall to the same junction, so they act together as one parallel block; that combined spring then sits end-to-end with K before reaching the block m, which is a series link. Reducing the innermost group first and then feeding it into the next rule is the only safe way through such a figure.
Formula Parallel: kP = k₁ + k₂; Series: 1/keq = 1/kP + 1/k₃, i.e. keq = kPk₃/(kP+k₃), all in N m⁻¹. Parallel members share the stretch so forces add; series members share the force so stretches add. From the figure: 2K and 4K are parallel; that pair is in series with K, which reaches block m on a smooth floor.
Solution
1. Spot the parallel pair: 2K and 4K both join the wall to the same point ⇒ same stretch ⇒ parallel.They span identical end points, so they must stretch equally.
2. Combine them: kP = 2K + 4K = 6K (N m⁻¹).Parallel constants add directly.

4. Apply the series rule: 1/keq = 1/6K + 1/K = 1/6K + 6/6K = 7/6K (m N⁻¹).Put both over the common denominator 6K.
5. Invert: keq = 6K/7 ≈ 0.857K (N m⁻¹).Sanity: 6K/7 < K, the softer member of the series pair ✓.

4Find the acceleration of all blocks just after the string is cut (3 kg — cut — 1 kg — spring — 2 kg, vertical) (Level-4)Acceleration after string cutAcceleration of blocks when string is cut🟡 Similar0 m/s², 3g, 0 m/s²
Concept This is the classic "laziness of a spring" problem. When a string is cut its tension vanishes instantly, because a string is inextensible and stores no length. A spring cannot do that: its force is set by its length, and a real block with mass cannot change position in zero time, so at t = 0⁺ every spring in the figure still has exactly the force it had a moment earlier. So the recipe is: compute the spring forces in the old equilibrium, delete only the cut member, and re-apply ΣF = ma with the spring forces frozen.
Formula Equilibrium first: ΣF = 0 (N); then just after the cut a = Fnet ÷ m (m s⁻²), with Fspring(0⁺) = Fspring(0⁻). A spring's force kx changes only when x changes, and x needs time to change — the block's inertia forbids a jump. Figure: ceiling → 3 kg → string (cut here) → 1 kg → spring → 2 kg. Take g = 10 m s⁻².
Solution
1. Spring force before the cut: the spring's only job is to hold the 2 kg block ⇒ Fs = 2 × 10 = 20 N.Isolate the bottom block: the spring must balance its 20 N weight exactly.
2. String tension before the cut: it carries 1 kg + 2 kg ⇒ T = 3 × 10 = 30 N (this is what disappears).
3. 3 kg block: it hangs from the ceiling directly; cutting the string below it merely removes a 30 N downward pull, and the rigid ceiling instantly adjusts. Weight 30 N down balanced by the ceiling ⇒ a = 0.A rigid ceiling supplies whatever force is needed, instantly — it is not a spring.
4. 1 kg block: the string above it is gone (T = 0). Remaining forces: weight 1×10 = 10 N down, and the spring below pulls it down with the frozen 20 N.The spring is stretched by the 2 kg hanging beneath, so it pulls its upper end downward.
5. Fnet = 10 + 20 = 30 N downward ⇒ a = 30 ÷ 1 = 30 m s⁻² downward = 3g.Both forces point the same way, so they add — this is why the answer is so large.
6. 2 kg block: spring still pulls up 20 N (frozen), weight 20 N down ⇒ Fnet = 0 ⇒ a = 0.Nothing that touches the 2 kg block changed at t = 0⁺, so its motion cannot change either.

1A marble of mass 2m at 6 cm/s is followed by a marble of mass m at double the speed; after collision the heavier one moves with the average of the two initial speeds. Find the coefficient of restitution.Coefficient of restitutionBall hits a stationary ball of double mass — restitution🟡 Similar—
Concept A one-dimensional collision needs two independent statements, and they play different roles. Momentum conservation always holds (no external horizontal force during the brief impact) and it fixes the unknown final velocity. The coefficient of restitution e is then a definition, not a conservation law: it measures how much of the approach speed survives as separation speed, so it grades the collision on the scale e = 1 (perfectly elastic) to e = 0 (perfectly inelastic). Note that both speeds are quoted in cm s⁻¹, and since e is a ratio of two speeds the unit cancels — no conversion is needed.
Formula Momentum: m₁u₁ + m₂u₂ = m₁v₁ + m₂v₂ (kg cm s⁻¹). Restitution: e = (speed of separation) ÷ (speed of approach) = (v₁ − v₂) ÷ (u₂ − u₁) — a dimensionless pure number. Both numerator and denominator are relative speeds in cm s⁻¹, so the units cancel and e carries none. Data: heavy marble 2m at uH = 6 cm s⁻¹; light marble m behind it at double speed uL = 12 cm s⁻¹; after impact the heavy one moves at the average of the two initial speeds.
Solution
1. Read the data: uH = 6 cm s⁻¹ (mass 2m), uL = 2 × 6 = 12 cm s⁻¹ (mass m), both moving the same way; the light one is behind and catches up.'Directly followed by ... with double speed' fixes uL = 12 cm s⁻¹ and guarantees a collision.
2. Final speed of the heavy marble = average of the two initial speeds = (6 + 12) ÷ 2 = 9 cm s⁻¹ = vH.This is given in the stem; it is the datum that makes the problem solvable.
3. Apply momentum conservation to get vL: 2m(6) + m(12) = 2m(9) + m·vL.No external horizontal force acts during the impact, so total momentum is unchanged.
4. Cancel m throughout: 12 + 12 = 18 + vL ⇒ 24 = 18 + vL ⇒ vL = 6 cm s⁻¹.m appears in every term, so it divides out — the actual mass is never needed.
5. Speed of approach (before) = uL − uH = 12 − 6 = 6 cm s⁻¹.The light marble closes the gap at 6 cm s⁻¹.
6. Speed of separation (after) = vH − vL = 9 − 6 = 3 cm s⁻¹.After impact the heavy one leads at 9 and the light one trails at 6, so the gap opens at 3 cm s⁻¹.
7. e = 3 ÷ 6 = 0.5 (dimensionless).0 < e < 1 ⇒ a partially elastic collision, which is physically sensible ✓.

  momentum: 2(6) + 1(12) = 2(9) + 1(v_L)

⚡ JEE Trick Always write e as separation ÷ approach of the relative velocities, and always take the differences in a consistent order (after: leader minus trailer; before: faster minus slower) — that guarantees a positive e. Because e is a ratio, never convert units: cm s⁻¹ works as well as m s⁻¹. Trap: using kinetic energy here. Energy is not conserved unless e = 1, and with e = 0.5 some is lost — only momentum plus the restitution definition may be used.

2Rotating an object / opening a door / a water tap — apply a force or a pair of forces. Under which conditions is it easy? Define the vector quantity; how does it differ for a single force vs two opposite forces on different lines of action?Torque / coupleMoment of force · Torque · Couple (Class 11)🟡 Similar—
Concept Opening a door, turning a tap or spinning an object are all rotational effects, and the physical quantity that produces rotation is not force but torque (moment of force). Experience already tells you the rule: a door opens easily when you push at the handle (far from the hinge) and perpendicular to the door, and refuses to budge when you push near the hinge or along the door's plane. Torque captures exactly that — it depends on the force, on how far from the axis it acts, and on its direction relative to the position vector.
Formula τ = r × F, magnitude τ = r F sinθ = F × (perpendicular distance), unit N m, a vector whose direction is given by the right-hand rule (along the axis). For a couple: τ = F × d (N m), where d is the perpendicular separation of the two lines of action. sinθ is maximum (= 1) at θ = 90°, which is why a perpendicular push is the most effective, and zero at θ = 0°, which is why pushing along the door does nothing.
Solution
1. The vector quantity concerned is the torque (moment of force), τ = r × F, measured in N m.It is the rotational analogue of force: force changes linear motion, torque changes rotational motion.
2. When is it easy? τ = rF sinθ is large when (i) F is large, (ii) r is large — push at the door handle, far from the hinge, and (iii) θ = 90° so sinθ = 1 — push perpendicular to the door.All three factors multiply, so improving any one of them increases the turning effect.
3. Why: pushing near the hinge (r → 0) or along the door's plane (θ → 0, so sinθ → 0) gives τ → 0 — the door will not turn however hard you push.A force whose line of action passes through the axis has zero perpendicular distance and hence zero moment.
4. Single force on a body: it gives a net force and generally a torque ⇒ the body both translates and rotates. Its torque depends on which axis you choose.With ΣF ≠ 0 the centre of mass must accelerate, so pure rotation is impossible.
5. Couple = two equal, opposite, parallel forces on different lines of action (as when both hands turn a tap). Net force = F − F = 0, so there is no translation.The two forces cancel vectorially, leaving the centre of mass at rest.
6. But their moments add: τ = F × d — a pure rotation. Crucially this is the same about every axis, so a couple's torque is independent of the reference point.Each force turns the body the same way, so the moments reinforce rather than cancel.

    o------------> F                =========  ] d
    |<---- r ---->|                     <-- F

  tau = r F sin(theta)           net force = F - F = 0  (no translation)
  net force = F (not zero)       tau = F x d   (pure rotation)

⚡ JEE Trick Reduce τ = rF sinθ to "force × perpendicular distance" — drop a perpendicular from the axis onto the force's line of action and multiply. That kills the sinθ bookkeeping. Remember the two-line contrast for the exam: a single force → net force ≠ 0, translation + rotation, torque depends on the axis; a couple → net force = 0, pure rotation, torque F×d is axis-independent. Trap: calling torque a scalar — it is a vector (N m), and its N m must never be written as joule.
Key point: the quantity is torque τ = r × F (τ = rF sinθ, in N m, a vector). Turning is easiest with a large force applied far from the axis and perpendicular to it (θ = 90°). A single force gives a non-zero net force, so it translates and rotates the body and its torque depends on the chosen axis; a couple (equal, opposite, different lines of action) has zero net force, so it produces pure rotation with torque τ = F×d, the same about every axis.
3Explain balancing / mechanical equilibrium. State and explain the conditions for equilibrium of a rigid body.Equilibrium of a rigid bodyEquilibrium of rigid bodies (Class 11)🟡 Similar—
Concept "Balancing" a rigid body means it has no tendency to change its state of motion — neither to move off, nor to spin up. Because a rigid body can do two independent things (translate as a whole and rotate about an axis), stopping it needs two separate conditions, and satisfying only one is not enough. This is why a couple can leave ΣF = 0 yet still spin a body: translational balance alone does not guarantee equilibrium.
Formula (i) Translational: ΣF⃗ = 0 (N) — in components ΣFx = ΣFy = ΣFz = 0. (ii) Rotational: Στ⃗ = 0 (N m) about any axis. From ΣF = Macm, ΣF = 0 ⇔ acm = 0; from Στ = Iα, Στ = 0 ⇔ α = 0. Both are needed because a and α are independent.
Solution
1. Mechanical equilibrium = the body's linear momentum and angular momentum are both constant — it neither accelerates nor angularly accelerates.Equilibrium means no change of motion; it does not mean 'at rest'.
2. Condition 1 — translational equilibrium: the vector sum of all external forces is zero, ΣF⃗ = 0.Newton's second law ΣF = Macm then forces acm = 0, so the centre of mass does not accelerate.
3. Resolve it into independent scalar equations: ΣFx = 0 and ΣFy = 0 (and ΣFz = 0 in 3-D).A vector is zero only if every component is zero.
4. Condition 2 — rotational equilibrium: the vector sum of all external torques about any axis is zero, Στ⃗ = 0.From Στ = Iα, this gives α = 0, so the body does not start or stop spinning.
5. Both are essential. A couple proves it: ΣF = 0 (condition 1 satisfied) yet τ = Fd ≠ 0, so the body spins — it is not in equilibrium.This single counter-example shows condition 1 alone is insufficient.
6. Useful fact: if ΣF = 0, then Στ has the same value about every axis — so you may take moments about the most convenient point (usually where an unknown acts, to eliminate it).Choosing the axis through an unknown force makes that force's moment zero, removing it from the equation.

⚡ JEE Trick Two conditions, always — write ΣF = 0 and Στ = 0 every time; most lost marks come from omitting the torque equation. When taking moments, choose the axis through an unknown force so its moment vanishes and it drops out of the algebra. Trap: thinking equilibrium = at rest. A body moving with constant velocity and constant angular velocity is in perfect mechanical equilibrium — equilibrium forbids acceleration, not motion.
Key point: a rigid body is in mechanical equilibrium only when both (i) ΣF⃗ = 0 (translational — no linear acceleration of the centre of mass) and (ii) Στ⃗ = 0 about any axis (rotational — no angular acceleration). A couple shows condition (i) alone is not sufficient.
4The linear velocity of a rotating fan as a whole is generally zero. Is it in mechanical equilibrium? Justify.Mechanical equilibriumEquilibrium of rigid bodies (Class 11)🟡 Similar—
Concept This question is a deliberate trap on the meaning of the word equilibrium. Students hear "the fan is spinning, so it is obviously not in equilibrium" — but equilibrium in mechanics forbids acceleration, not motion. The fan's centre of mass is genuinely at rest, so the translational condition is met. The decisive question is the second condition: is the fan's angular velocity constant? That single detail settles the answer, and it is why the question is worth asking.
Formula Both conditions must hold: ΣF⃗ = 0 (N) and Στ⃗ = 0 (N m). ΣF = Macm = 0 means the centre of mass does not accelerate; Στ = Iα = 0 means ω is constant. Equilibrium constrains a and α, not v and ω.
Solution
1. Translational check: the fan is bolted in place, its centre of mass stays put, so vcm = 0 and acm = 0 ⇒ ΣF = 0 ✓.Weight is exactly balanced by the support's reaction; the blades' momenta cancel by symmetry, which is why the linear velocity 'as a whole' is zero.
2. So condition (i) is satisfied — but that alone settles nothing, because a rigid body also rotates.The couple counter-example shows ΣF = 0 can coexist with spinning up.
3. Rotational check, case A — fan running at constant angular speed ω: α = 0, so Στ = Iα = 0 ✓.The motor's driving torque exactly balances the air drag and friction torque, leaving no net torque.
4. Both conditions hold ⇒ the fan is in mechanical equilibrium, even though it is visibly spinning.Its linear momentum and its angular momentum are both constant — that is precisely what equilibrium means.
5. Rotational check, case B — fan just switched on (or off), speeding up or slowing down: α ≠ 0 ⇒ Στ = Iα ≠ 0 ✗.An unbalanced torque is needed to change ω.
6. Then it satisfies only condition (i): it is in translational equilibrium but not in rotational equilibrium, hence not in complete mechanical equilibrium.Failing either condition disqualifies the body.
7. Note it is never in static equilibrium while running — static requires v = 0 and ω = 0.Static is a special case of mechanical equilibrium with everything at rest.

Key point: yes — provided it rotates at constant angular velocity. 1Tension in both springs when two light springs are in series and mass m is suspended at the end? (a) Zero (b) Different for each (c) Equal to mg (d) Half of mgTension in series springsSeries & parallel spring combinations (Hooke's law)🟡 SimilarcEqual to mg
Concept Two light springs hang end-to-end with mass m at the bottom — a series chain. The key word is light: a massless spring needs zero net force to satisfy F = ma = 0, so the pull at its top end must exactly equal the pull at its bottom end. The second idea is the load each spring carries: read the figure from the bottom up and count how many balls sit above each spring. Compression is then load ÷ stiffness, and the winner is the spring with a small load and a large k.
Formula Cut rule: k ∝ 1/L ⇒ if the parent length gives constant k for length l, then length 2l gives k/2 (N m⁻¹). Hooke: x = F ÷ k (m), where F is the load carried. A longer spring has more coils to share the same force, so it deforms more — stiffness falls in inverse proportion to length. Figure: left column = ground → B → ball → A → ball; right column = ground → C → ball. All balls identical (mass m), all surfaces smooth.
Solution
1. Assign the constants from the cut rule: A and B have natural length l ⇒ kA = kB = k. C has natural length 2l ⇒ kC = k/2.Both cut from the same parent spring, so kL is the same for every piece; double the length ⇒ half the stiffness.
2. Load on A (the top spring in the left column): it supports only the single ball resting on top of it ⇒ FA = mg (N).Count what sits above it: one ball only.
3. Load on B (the bottom spring in the left column): it supports the ball above it plus spring A plus the top ball ⇒ FB = 2mg (N).Springs are massless, so B carries the weight of two balls.
4. Load on C (right column): it supports its single ball ⇒ FC = mg (N).

6. Rank them: xA = mg/k < xB = xC = 2mg/k.A is compressed exactly half as much as the other two, which happen to tie.
7. ⇒ the smallest compression is A — option (a).A wins on both counts: it carries the least load and it has the larger stiffness.

Concept Two experiments on the same spring-and-string rig (A on the spring, the spring's far end running over a pulley to B). The key fact is spring laziness: the instant a hold is released the spring's length — hence its force — cannot change, so it stays at whatever equilibrium demanded. In experiment 1 A (m) is released while B (2m) rests in equilibrium, so the spring already carries B's weight 2mg. In experiment 2 the roles swap: B is released while A rests in equilibrium, so the spring carries only A's weight mg.
Formula Frozen spring force = weight of the block that stays in equilibrium. Released block: a = |Fspring − (its weight)| / (its mass). At t = 0 the spring force equals the equilibrium value set by the OTHER block; the released block then obeys Newton's second law with that fixed force. Data: masses m and 2m.
Solution
1. Exp 1 — release A. B (2m) is in equilibrium ⇒ string, hence spring, tension = 2mg (it supports B). Freeze it: the spring still pulls A up with 2mg at t = 0.
2. On A (m): spring 2mg up − weight mg down = mg up ⇒ a = mg/m = g.
3. Exp 2 — release B. Now A (m) is in equilibrium ⇒ spring tension = mg (it supports A). Freeze it: via the string the spring pulls up on B with mg.
4. On B (2m): weight 2mg down − spring mg up = mg down ⇒ b = mg/2m = g/2.
5. Ratio a/b = g ÷ (g/2) = 2. Check the rest: (a) 0, (b) ∞, (d) 1/2 — all wrong; (c) is correct.Swapping which block stays in equilibrium changes the frozen spring force from 2mg to mg, which is what makes the ratio finite.

Concept Four pulley-and-spring arrangements, each asking for the spring's extension — and each is really asking "what force does the spring actually carry?" Two tools do all the work: a massless pulley is in equilibrium, so the force on its axle equals the vector sum of the string forces on its rim (two vertical segments of tension T pull with 2T); and the tension is the same throughout one string. Work out the force on the spring, then divide by k.
Formula Massless pulley: ΣF = 0 ⇒ axle force = 2T for two parallel segments (N). One string ⇒ one tension T throughout. Extension: x = Fspring ÷ k (m). Every pulley here is massless, so it can neither absorb force nor store any — it simply redistributes it, giving the mechanical advantage.
Solution
1. (A) ceiling → spring k → a movable pulley; a string over it has one end anchored to the ground and the other holding m. The string holds m ⇒ T = mg; both its segments are vertical, so they pull the pulley down with 2T.The single string carries the same tension mg in both segments.
2. Pulley equilibrium (massless) ⇒ the spring must pull up with 2T = 2mg ⇒ xA = 2mg/k ⇒ A → R ✓.The spring here carries twice the load — no mechanical advantage, the reverse.
3. (B) a two-stage system: string 2 (tension T₂) wraps under the lower pulley, which carries m ⇒ 2T₂ = mg ⇒ T₂ = mg/2. String 2's other end pulls down on the upper pulley's axle with T₂.Each movable pulley halves the force — the classic 2:1 advantage.
4. The upper pulley is held by string 1 (tension T₁ = the spring's force) wrapping under it ⇒ 2T₁ = T₂ = mg/2 ⇒ T₁ = mg/4 ⇒ xB = mg/(4k) ⇒ B → S ✓.Two stages of halving: mg → mg/2 → mg/4 — the spring carries only a quarter of the weight.
5. (C) the spring holds pulley P₁'s axle; string 1 (tension T₁) runs over P₁ with one end on m and the other on P₂'s axle; string 2 (tension T₂) runs over P₂ with one end on m and the other anchored to the ground.Read the figure carefully: m is held by two string segments, one from each pulley.
6. P₂ is massless: string 2 pushes it with 2T₂, balanced by T₁ on its axle ⇒ T₁ = 2T₂. Block m is held by one segment of each string ⇒ T₁ + T₂ = mg.Two equations, two unknowns.
7. Solve: 2T₂ + T₂ = mg ⇒ T₂ = mg/3, T₁ = 2mg/3. The spring holds P₁, which carries two segments of string 1 ⇒ F = 2T₁ = 4mg/3 ⇒ xC = 4mg/(3k) ⇒ C → Q ✓.The 3 in the denominator is the signature of this three-segment arrangement.
8. (D) one continuous string: ceiling → down → under the movable pulley (which carries m) → up → over the spring's pulley → down → anchored to the ground. The movable pulley carries m ⇒ 2T = mg ⇒ T = mg/2.One string ⇒ one tension throughout its whole length.

10Two blocks m₁ and m₂ joined by a compressed spring (constant k) on a smooth surface, under forces F₁ and F₂, moving with common acceleration a₀. F₂ suddenly withdrawn. Mark the correct option (instantaneous accelerations).Two-block spring, force withdrawnTwo blocks m₁ and m₂ acted upon by forces F₁ and F₂🟡 SimilarbInstantaneous acceleration of m₂ is a₂ = a₀ + F₂/m₂
Concept Two blocks joined by a compressed spring on a smooth surface are driven by F₁ and F₂ with a common acceleration a₀; then F₂ is suddenly withdrawn. The whole question turns on one observation: the spring's force is frozen at the instant of withdrawal, and m₁ is touched by only F₁ and that spring — neither of which has changed. So m₁'s acceleration is completely unaltered: still a₀. Only m₂, which actually lost a force, changes.
Formula Frozen spring: S(0⁺) = S(0⁻) (N). Newton: ΣF = ma (N). A compressed spring pushes both blocks outward — it pushes m₁ backwards (against F₁) and m₂ forwards. Data: smooth surface; before withdrawal both blocks share the acceleration a₀.
Solution
1. Before — block m₁: F₁ drives it forward; the compressed spring pushes it back with S ⇒ F₁ − S = m₁a₀ ⇒ S = F₁ − m₁a₀ (N).A compressed spring pushes its ends apart, so on m₁ the push opposes F₁.
2. Before — block m₂: the spring pushes it forward with S while F₂ opposes ⇒ S − F₂ = m₂a₀ ⇒ S = m₂a₀ + F₂ (N).Two consistent expressions for the same S — either may be used.
3. Withdraw F₂. The spring's length cannot change in zero time ⇒ its force stays frozen at S.The blocks have mass and cannot move instantaneously, so the compression is unchanged at t = 0⁺.
4. Block m₁ — the key insight: the only forces on it are F₁ (unchanged) and the spring's S (frozen). Neither has changed, and F₂ never touched m₁ in the first place.F₂ acted on m₂, not on m₁ — and its influence reached m₁ only through the spring, which is frozen.
5. ⇒ m₁a₁ = F₁ − S = m₁a₀ ⇒ a₁ = a₀ — completely unchanged. So (a) a₀ − F₁/m₁ and (c) a₁ = 0 are both wrong ✗.Its force diagram is identical, so its acceleration must be identical.
6. Block m₂: it has genuinely lost F₂; the frozen spring still pushes it forward with S ⇒ m₂a₂ = S.Only one force remains on m₂ along the line of motion.
7. Substitute S = m₂a₀ + F₂: a₂ = (m₂a₀ + F₂)/m₂ = a₀ + F₂/m₂ ⇒ (b) is CORRECT ✓, and (d) a₂ = 0 is wrong ✗.Removing the opposing force F₂ makes m₂ accelerate more — by exactly F₂/m₂, as expected.
