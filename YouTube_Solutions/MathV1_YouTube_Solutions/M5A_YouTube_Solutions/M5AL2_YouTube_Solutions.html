Rewriting all three terms this way produces a telescoping (cyclic) sum in which every tangent appears once with + and once with −, so everything cancels.
Formula sin(A−B)/(cosA cosB) = tanA − tanB expand sin(A−B) = sinA cosB − cosA sinB and split the fraction.
Solution
1. First term: sin(A−B)/(cosA cosB) = (sinA cosB − cosA sinB)/(cosA cosB) = sinA/cosA − sinB/cosB = tanA − tanB.
2. Second term, same pattern: sin(B−C)/(cosB cosC) = tanB − tanC.
3. Third term: sin(C−A)/(cosC cosA) = tanC − tanA.
4. Add all three: (tanA − tanB) + (tanB − tanC) + (tanC − tanA) — each tangent enters once positively and once negatively.The indices A→B→C→A form a closed cycle, so the chain telescopes to zero.
5. Sum = 0 identically, for all A, B, C (wherever the cosines are nonzero).
6. Numeric spot-check A = 60°, B = 45°, C = 30°: terms = (√3 − 1) + (1 − 1/√3) + (1/√3 − √3) ≈ 0.732 + 0.423 − 1.155 = 0 ✓.Any random triple works — the identity holds unconditionally.

Any cyclic sum of such terms — indices marching A→B→C→A — telescopes to 0 without computing anything. Concept Each given relation looks asymmetric, but cross-multiplying regroups it into the sine-addition pattern: sinθ = x sin(θ + φ). Doing the same to the second relation gives sinφ = y sin(θ + φ) — the same combining factor sin(θ+φ) appears in both, so dividing eliminates it and yields x/y directly.

Solution
