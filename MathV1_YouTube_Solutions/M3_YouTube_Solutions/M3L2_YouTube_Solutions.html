1Which identity is correct for all θ? (sin(−θ), cos(−θ)…)Even/odd of ratioswatch?v=xiMDTiFTeE8🟡 Similarbcos(−θ) = cos θ
Concept Replacing θ by −θ reflects the terminal point of the angle across the x-axis. That flips the y-coordinate (which is sine) but leaves the x-coordinate (cosine) untouched. So each ratio is either even (unchanged) or odd (sign reversed), and the question just asks which sign rule holds for every θ.
Formula sin(−θ)=−sinθ, cos(−θ)=cosθ, tan(−θ)=−tanθ (and cosec odd, sec even, cot odd). Even = graph symmetric about the y-axis; odd = symmetric about the origin.
Solution
1. Take P(cosθ, sinθ) on the unit circle; the angle −θ lands on P′(cosθ, −sinθ).−θ is the same rotation measured clockwise, i.e. the mirror image of P in the x-axis.
2. Read off coordinates: cos(−θ) = x-coordinate = cosθ (unchanged); sin(−θ) = y-coordinate = −sinθ (sign flips).
3. Hence tan(−θ) = sin(−θ)/cos(−θ) = (−sinθ)/cosθ = −tanθ.
4. Only cos(−θ)=cosθ (and sec) keeps its sign for all θ; sine, tan, cot, cosec are odd.
⚡ JEE Trick Just two are even — cos and sec; the other four are odd and carry the minus straight out. Trap: writing cos(−θ)=−cosθ by pattern-matching the sine rule.
Answer: cos(−θ) = cos θ (cosine is even); equivalently sin(−θ) = −sin θ.

Concept 90°−θ is a complementary allied angle, so a co-ratio rule applies: the function changes to its co-function (cos↔sin), and since 90°−θ is in the first quadrant for acute θ the sign stays positive. This is the cofunction identity.
Formula cos(90°−θ)=sinθ. Rule for 90°±θ: name flips to the co-function; sign is fixed by the quadrant of the whole angle.

2. Substitute θ=30°: sin30° = 1/2.

⚡ JEE Trick For 90°±θ the function always switches (sin↔cos, tan↔cot, sec↔cosec); only the sign needs the ASTC check. Trap: for 180°±θ the name does not change — mixing the two rules is the classic error.
Answer: 1/2.

5Prove cos(3π/2+x)cos(2π+x)[cot(3π/2−x)+cot(2π+x)]=1Allied-angle identitywatch?v=xiMDTiFTeE8🟡 Similar—
Concept Reduce every allied angle to a plain function of x first (name changes only for the 3π/2 terms, which are odd multiples of 90°), then simplify the tan+cot combination — it always collapses via sin²+cos²=1.
Formula cos(3π/2+x)=sinx, cos(2π+x)=cosx, cot(3π/2−x)=tanx, cot(2π+x)=cotx, and tanx+cotx=1/(sinx·cosx).
Solution
1. cos(3π/2+x): 3π/2 is odd×90° so cos→sin; 3π/2+x is in Q4 where cos>0 ⇒ = +sinx.
2. cos(2π+x)=cosx (2π is a full turn, no change).
3. cot(3π/2−x): 3π/2 odd×90° so cot→tan; 3π/2−x is in Q3 where cot>0 ⇒ = +tanx.
4. cot(2π+x)=cotx.
5. Substitute: LHS = sinx·cosx·(tanx+cotx).
6. tanx+cotx = sinx/cosx + cosx/sinx = (sin²x+cos²x)/(sinx cosx) = 1/(sinx cosx).
7. LHS = sinx·cosx · 1/(sinx cosx) = 1 = RHS. ∎
⚡ JEE Trick The pattern sinθ·cosθ·(tanθ+cotθ) is a stock "= 1" trap — the sinθcosθ outside exactly cancels the 1/(sinθcosθ) that tan+cot produces. Trap: forgetting cot(3π/2−x) switches to tan, not cot.
Answer: Identity proved — expression = 1.
6Prove big allied-angle fraction = 2Allied-angle identitywatch?v=xiMDTiFTeE8🟡 Similar—
Concept Every "big allied-angle fraction" is proved by the same 3-step machine: reduce each factor to a bare function of the base angle, then cancel. No expansion or values are needed — only the two reduction rules and ASTC.
Formula (reduction rules) 180°±θ, 360°±θ, π±θ ⇒ name unchanged; 90°±θ, 270°±θ ⇒ name switches to co-function. Sign of each reduced term = sign of the original function in the quadrant of the whole angle (ASTC).
Solution (method)
1. Tag each factor: is its shift a multiple of 180° (name stays) or an odd multiple of 90° (name flips to co-function)?
2. Attach the sign from ASTC by locating the full angle's quadrant.
3. Rewrite the whole fraction in sinθ, cosθ only; a typical target-2 form pairs two equal reduced terms in the numerator against one in the denominator, e.g. (2 sinθ cosθ)/(sinθ cosθ) = 2.
4. Cancel the common sinθ / cosθ factors; the surviving constant is the required value 2.
⚡ JEE Trick Never expand sums-of-angles here — reduce factor-by-factor first, then cancel. A fraction that "= 2" almost always hides a doubled term (like 2sinθcosθ from a sin2θ, or two identical co-function reductions) over its single-term partner. Trap: switching names on a 180° term.
Answer: Identity proved — the reduced fraction simplifies to 2.
7Show allied-angle fraction = 1Allied-angle identitywatch?v=xiMDTiFTeE8🟡 Similar—
Concept A "= 1" allied-angle fraction is the cleanest case: after reducing every factor to sinθ/cosθ, the numerator and denominator become identical (up to sign), so the ratio is exactly 1. The whole task is bookkeeping of names and signs.
Formula (reduction rules) 180°±θ / 360°±θ ⇒ name unchanged; 90°±θ / 270°±θ ⇒ name flips to the co-function. Sign from ASTC on the whole angle. Also sin²θ+cos²θ=1 often finishes the cancel.
Solution (method)
1. Reduce each numerator factor: apply the name rule (flip only for 90°/270°) then the ASTC sign.
2. Reduce each denominator factor the same way.
3. Both sides now read in sinθ and cosθ; collect them — a "=1" problem leaves the same product top and bottom (e.g. sinθcosθ over sinθcosθ).
4. Cancel the common factors ⇒ ratio = 1. If a sum survives, apply sin²θ+cos²θ=1 to close it.
⚡ JEE Trick Track each factor's sign in a little ASTC table before multiplying — an even number of minus signs top and bottom must match for the result to be +1. Trap: an odd sign mismatch gives −1, not 1; count the negatives.
Answer: Identity proved — the reduced fraction simplifies to 1.

4. (ii) From x = 6cosecθ and y = 8cotθ: cosecθ = x/6, cotθ = y/8.

4Which function is periodic with period π?Periodic functionswatch?v=xiMDTiFTeE8🟡 Similarctan x
Concept The fundamental period is the smallest shift that reproduces the whole graph. sin, cos, sec, cosec repeat every 2π, but tan and cot repeat twice as fast — every π — because adding π sends a point to its diametric opposite, which has the same tangent.
Formula tan(θ+π)=tanθ, cot(θ+π)=cotθ; period = π. sin(θ+π)=−sinθ and cos(θ+π)=−cosθ, so their ratio tan is unchanged.
Solution
1. tan(θ+π) = sin(θ+π)/cos(θ+π) = (−sinθ)/(−cosθ) = tanθ.
2. The two minus signs cancel, so the value returns after just π ⇒ period π.
3. sin, cos, sec, cosec need a full 2π; hence the π-periodic functions are tan and cot.
⚡ JEE Trick Period π ⇔ tan or cot; period 2π ⇔ the other four. Trap: |sinθ| also has period π, but among the pure ratios only tan and cot do.
Answer: tan θ (and cot θ) — period π.
5Which is an even function?Even/odd functionswatch?v=xiMDTiFTeE8🟡 Similarccos x
Concept A function is even if f(−θ)=f(θ) (graph symmetric about the y-axis). Among the trig ratios only cosine and secant satisfy this; the rest reverse sign and are odd.
Formula cos(−θ)=cosθ, sec(−θ)=secθ (even); sin, tan, cot, cosec are odd. sec=1/cos inherits cosine's evenness.
Solution
1. Test cos: cos(−θ)=cosθ ⇒ even. ✓
2. Test sec: sec(−θ)=1/cos(−θ)=1/cosθ=secθ ⇒ even. ✓
3. Test sin/tan: sin(−θ)=−sinθ, tan(−θ)=−tanθ ⇒ odd, not even.
⚡ JEE Trick "Even = cos family (cos, sec)"; everything else is odd. Trap: a product of two odd functions (e.g. sinθ·tanθ) is even — evaluate the whole expression, not just single ratios, when the option is a product.
Answer: cos θ (cosine is even; sec θ is the other even ratio).

2. Multiply the sine conjugates: x·v = (√3 + 2sinA)(√3 − 2sinA) = 3 − 4sin²A.
