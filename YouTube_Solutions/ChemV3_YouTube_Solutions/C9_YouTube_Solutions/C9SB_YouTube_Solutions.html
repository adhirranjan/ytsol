(b) KMnO₄
Concept H2O2 liberates O2 only when it acts as a reducing agent: its oxygen goes from −1 to 0. So X must be an oxidant strong enough to oxidise H2O2 in acid. The trap is K3[Fe(CN)6], which also frees O2 from H2O2, but only in alkaline medium.
Key relation 2KMnO4 + 3H2SO4 + 5H2O2 → K2SO4 + 2MnSO4 + 8H2O + 5O2 Mn goes +7 → +2 (gains 5 e⁻), each O of H2O2 goes −1 → 0, so O2 is evolved.
Solution
1. For O2 to appear, H2O2 must lose electrons: H2O2 → O2 + 2H⁺ + 2e⁻. X is therefore an oxidising agent, and the medium is acidic.
2. (b) KMnO4: in acid MnO4⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H2O (E° = +1.51 V), far above the O2/H2O2 couple (+0.68 V). Fits.
3. (a) K3[Fe(CN)6]: 2K3[Fe(CN)6] + 2KOH + H2O2 → 2K4[Fe(CN)6] + 2H2O + O2. This needs KOH, i.e. alkaline medium, not acid.
4. (c) FeSO4: 2Fe²⁺ + H2O2 + 2H⁺ → 2Fe³⁺ + 2H2O. Here H2O2 is the oxidant; no O2 forms.
5. (d) H2S: H2S + H2O2 → S + 2H2O. Again H2O2 oxidises; no O2.
6. Only KMnO4 liberates O2 from H2O2 in acidic medium, so X = KMnO4.
⚡ JEE Trick Ask “who gets oxidised?” If X is a reducer (Fe²⁺, S²⁻, I⁻), H2O2 is the oxidant and gives water, never O2. Ferricyanide is the tempting distractor: it does release O2, but only with KOH present, so “acidic” rules it out.
Answer: (b) KMnO4.

Concept H2O2 reduces both oxidants and is itself oxidised to O2, giving up 2 e⁻ per molecule. The moles of H2O2 needed per mole of oxidant therefore equal (electrons the oxidant accepts)/2. The trap is using n-factors upside down or forgetting the two Cr atoms in dichromate.
Key relation mol H2O2 = (n-factor of oxidant × mol oxidant)/2 Equivalents of reductant = equivalents of oxidant; n-factor of H2O2 (O: −1 → 0, two O) = 2.
Solution
1. H2O2 → O2 + 2H⁺ + 2e⁻, so each mole of H2O2 supplies 2 mol e⁻.
2. KMnO4 in acid: Mn +7 → +2, n-factor 5, so mol H2O2 = 5 × 1/2 = 5/2. Check: 2MnO4⁻ + 5H2O2 + 6H⁺ → 2Mn²⁺ + 5O2 + 8H2O.
3. K2Cr2O7 in acid: 2Cr +6 → +3, n-factor 2 × 3 = 6, so mol H2O2 = 6 × 1/2 = 3. Check: Cr2O7²⁻ + 3H2O2 + 8H⁺ → 2Cr³⁺ + 3O2 + 7H2O.
4. Ratio (KMnO4 : K2Cr2O7) = (5/2) : 3 = 5 : 6, which is option (c).
5. The key prints (d) 5 : 4. That would need dichromate to accept only 4 e⁻ (Cr +6 → +4), which does not happen in acid; nor does reversing the ratio (6 : 5, option a) give 5 : 4.
6. So the working gives (c) 5 : 6; the key’s (d) is kept in the cell and flagged.
⚡ JEE Trick Moles of reductant scale directly with the oxidant’s n-factor, so the ratio is just 5 : 6, readable in one glance. Option (a) 6 : 5 is the inverted-ratio trap.

PbS + H2O2 → X + H2O. The change in oxidation state of metal is.
(a) −2 to +6   (b) 0 → +2   (c) −2 to 0   (d) no change
C9SBV7Q1iiiPbS + H2O2 oxidation state
🟡 SimilarIn the following rea…
(d) no change
Concept H2O2 oxidises black PbS to white PbSO4, which is how old oil paintings are restored. The electrons come from sulphur, not lead. The trap is option (a), which is the change for sulphur, not for the metal the question asks about.
Key relation PbS + 4H2O2 → PbSO4 + 4H2O S goes −2 → +6 (loses 8 e⁻); 4 H2O2 each gain 2 e⁻ (O −1 → −2), so 8 e⁻ balance.
Solution
1. Identify X: H2O2 acts as an oxidant here and converts the sulphide into the sulphate, so X = PbSO4.
2. Oxidation state of Pb in PbS: S is −2, so x + (−2) = 0 gives Pb = +2.
3. Oxidation state of Pb in PbSO4: SO4²⁻ carries −2, so x + (−2) = 0 gives Pb = +2.
4. Oxidation state of S: −2 in PbS and x + 4(−2) = −2 gives x = +6 in SO4²⁻. So S changes −2 → +6. That 8-electron loss is what H2O2 absorbs.
5. Electron check: 8 e⁻ lost by S = 4 × 2 e⁻ gained by 4 H2O2, which fixes the 1 : 4 stoichiometry.
6. The metal (Pb) stays at +2 throughout, so the change in oxidation state of the metal is no change.
⚡ JEE Trick Read the stem word “metal”. Option (a) −2 to +6 is the sulphur change and catches anyone who tracks only the atom being oxidised. Option (c) would mean S → elemental S, which H2O2 gives with H2S, not with PbS. Pb²⁺ is a spectator: black PbS turns to white PbSO4.
Answer: (d) no change.

25 ml of H2O2 solution was added to the excess of acidified KI solution. The iodine so liberated required 40 ml of 0.1 N Na2S2O3 solution. What is normality of H2O2 solution?
(a) 0.08   (b) 0.16   (c) 0.02   (d) 0.20
C9SBV7Q2iNormality of H2O2 (iodometry)
🟡 Similar, 25 ml of H_2O_2 so…
(b) 0.16
Concept This is an iodometric (back) titration. H2O2 oxidises excess I⁻ to I2, and the I2 is then titrated with thiosulphate. Since I2 is only a go-between, milliequivalents of H2O2 = meq of I2 = meq of Na2S2O3. Excess KI ensures all the H2O2 reacts.
Key relation N1V1(H2O2) = N2V2(hypo) The law of equivalence holds across the chain because each step transfers the same number of electrons.
Solution
Given 25 mL H₂O₂, excess acidified KI, I₂ needs 40 mL of 0.1 N Na₂S₂O₃
Find normality of the H₂O₂ solution
1. Step reactions: H2O2 + 2I⁻ + 2H⁺ → I2 + 2H2O, then I2 + 2S2O3²⁻ → 2I⁻ + S4O6²⁻.
2. Mole chain: 1 H2O2 ≡ 1 I2 ≡ 2 S2O3²⁻, i.e. 2 e⁻ per H2O2 and 1 e⁻ per thiosulphate. This is why normality, not molarity, transfers directly.
3. meq of thiosulphate = N × V = 0.1 × 40 = 4 meq.
4. meq of I2 liberated = 4 meq, so meq of H2O2 = 4 meq.
5. N(H2O2) = meq/V = 4/25 = 0.16 N.
6. Cross-check by moles: mol S2O3²⁻ = 4 mmol, so H2O2 = 2 mmol in 25 mL = 0.08 M, and N = M × 2 = 0.16 N. Consistent.
⚡ JEE Trick In any iodometric titration ignore the iodine: equivalents of the unknown = equivalents of hypo. The distractor 0.08 is the molarity (n-factor 2 forgotten); 0.20 would follow from a mis-read 50 mL of hypo, so re-read the burette volume before dividing.
Answer: (b) 0.16.

(b) 0.272
Concept Percentage strength of H2O2 means grams of H2O2 per 100 mL of solution (w/v). Convert the normality from part (i) to g/L using the equivalent mass, then divide by 10. The trap is using the molar mass 34 with the normality.
Key relation strength (g/L) = N × E = 0.16 × 17 = 2.72 g/L → % (w/v) = 2.72/10 = 0.272 E(H2O2) = M/n = 34/2 = 17, since H2O2 transfers 2 e⁻ with iodide.
Solution
Given 25 mL H₂O₂ ≡ 40 mL of 0.1 N Na₂S₂O₃ (from (i)), Eq. mass H₂O₂ = 17
Find percentage strength (w/v)
1. From part (i): N(H2O2) = 40 × 0.1/25 = 0.16 N.
2. Equivalent mass: H2O2 + 2H⁺ + 2e⁻ → 2H2O, so n-factor = 2 and E = 34/2 = 17 g/eq.
3. Strength in g/L = N × E = 0.16 × 17 = 2.72 g/L.
4. Percentage (w/v) = g per 100 mL = 2.72/1000 × 100 = 0.272 %.
5. Molar route as a check: M = N/2 = 0.08 M, so g/L = 0.08 × 34 = 2.72 g/L, the same. Both routes must agree; if they do not, an n-factor slipped.
6. Strictly this is a w/v percentage. Such a dilute solution has density ≈ 1.00 g/mL, so the w/w figure (2.72 g in about 1000 g of solution) is also ≈ 0.272 %; the distinction does not change the choice. Only for concentrated (30 %) H2O2, density 1.11 g/mL, would w/v and w/w differ noticeably.
7. Option (b) 0.272 matches.
⚡ JEE Trick Memorise “% strength = 1.7 × N” for H2O2 (17 g/eq per litre, divided by 10): 1.7 × 0.16 = 0.272 in one line. The distractor 0.544 is N × 34 (molar mass used with normality) and 0.136 is M × 17 (equivalent mass used with molarity), each off by a factor of 2.

The three known isotopes of hydrogen H, D and T have significant difference in physical and chemical properties than isotopes of any other element.
Which of the following process is not exothermic?
(a) H+(g) + Aq. → H+aq.   (b) H+ + H2O → H3O+   (c) H2(g) → 2H(g)   (d) H(g) → H−(g)
C9SBV7Q3iEnergetics of H processes
🟡 SimilarHydrogen 05 : Chemic…
(c) H₂(g) → 2H(g)
Concept Breaking a bond always costs energy, while forming a bond or attracting a charge to something releases it. So scan the four processes for the one that only breaks a bond. The trap is (d): adding an electron to H sounds like it should cost energy, but H has a negative electron gain enthalpy.
Key relation H2(g) → 2H(g), ΔH = +436 kJ mol⁻¹ The H–H bond enthalpy is one of the highest for a single bond, so atomisation is strongly endothermic.
Solution
1. (a) H⁺(g) + aq → H⁺(aq): hydration of the bare proton. The tiny ion has an enormous charge density, so ΔHhyd ≈ −1090 kJ mol⁻¹. Exothermic.
2. (b) H⁺ + H2O → H3O⁺: a new O–H coordinate bond forms (proton affinity of water ≈ 690 kJ mol⁻¹ released). Exothermic.
3. (c) H2(g) → 2H(g): only a bond is broken, nothing is formed. ΔH = +436 kJ mol⁻¹. Endothermic.
4. (d) H(g) + e⁻ → H⁻(g): electron gain enthalpy of hydrogen = −73 kJ mol⁻¹; the 1s orbital half-filled accepts one more electron to reach the He configuration. Exothermic. Unlike O⁻ → O²⁻, this is a first electron gain onto a neutral atom.
5. So the only process that is not exothermic is (c).
6. The high +436 kJ mol⁻¹ is also why H2 is fairly inert at room temperature and needs catalysts or heat to react.
⚡ JEE Trick “Bond breaking = endothermic” settles it without any numbers. Only second electron gains (O⁻ → O²⁻, S⁻ → S²⁻) and noble-gas or Be/N-type electron gains are positive; hydrogen’s first electron gain is negative, so (d) is the distractor.
Answer: (c) H2(g) → 2H(g).

C9SBV7Q3iiSize of H species
🟡 SimilarWhich of the followi…
(d) Radius of anion in CsH
Concept Hydrogen’s size swings wildly with its electron count. The bare proton H⁺ has no electrons and is about 10⁻⁵ Å across; neutral H in H2 has a covalent radius of 0.37 Å; the hydride ion H⁻ has two electrons on one proton, so its cloud swells to roughly 1.4–1.5 Å. The trap is (b): heavier D does not mean a bigger atom.
Key relation r(H⁺) ≪ rcov(H) ≈ rcov(D) ≪ r(H⁻) Size is set by the electrons and the nuclear charge (Z = 1 for all), not by the neutron count.
Solution
1. (a) H–H bond length = 0.74 Å, so half of it = 0.74/2 = 0.37 Å (covalent radius).
2. (b) D–D bond length = 0.741 Å, so half of it ≈ 0.37 Å. Isotopes share the same electronic structure, so bond lengths are practically equal. D2 has a lower zero-point energy, which shortens the bond only marginally.
3. (c) H⁺(g) is a bare proton: radius ≈ 1.5 × 10⁻⁵ Å, about 10⁵ times smaller than an ordinary atom.
4. (d) CsH is a saline (ionic) hydride, Cs⁺H⁻. The hydride ion has 2 electrons and only 1 proton, so the electrons repel and are weakly held; its radius is about 1.4–1.5 Å (1.3–2.1 Å over different lattices).
5. Comparing: 1.5 × 10⁻⁵ Å < 0.37 Å ≈ 0.37 Å < ~1.5 Å.
6. The largest magnitude is the radius of the anion in CsH, option (d).
⚡ JEE Trick Anion > atom > cation for the same element, and for hydrogen the gaps are extreme because Z = 1. H⁻ is about the size of F⁻ (1.33 Å), which is why ionic hydrides resemble halides.
Answer: (d) Radius of anion in CsH.

(b) 1 : 2 (ortho : para mixture)
(c) 1 : 3 (ortho : para mixture)

C9SBV7Q3iiiOrtho/para hydrogen ratio
🟢 ExactRatio of Ortho & Par…
(a) 3 : 1 (ortho : para)
Concept In H2 the two proton spins can be parallel (ortho, total nuclear spin I = 1) or antiparallel (para, I = 0). Ordinary hydrogen at room temperature is the high-temperature equilibrium mixture, whose ratio comes from counting spin states. The trap is reversing it: para dominates only near 0 K.
Key relation ortho : para = (2I + 1) for I = 1 : (2I + 1) for I = 0 = 3 : 1 When many rotational levels are populated (T ≳ 200 K), each nuclear-spin state is equally likely, so the ratio is just the spin degeneracy.
Solution
1. Each proton has spin (1/2). Two protons give total spin I = 1 (parallel) or I = 0 (antiparallel).
2. I = 1 has 2I + 1 = 3 spin states (ortho, a triplet); I = 0 has 2I + 1 = 1 state (para, a singlet).
3. At room temperature the rotational levels that each form can occupy are thickly populated, so the statistical weight of the spin states decides the mixture.
4. Ratio = 3 : 1, i.e. 75 % ortho and 25 % para. This is the maximum ortho fraction; it cannot be raised above 75 % even by heating.
5. On cooling, para (lowest rotational level J = 0) is favoured: near 20 K the equilibrium mixture is about 99.8 % para. Pure para-H2 can be made, pure ortho-H2 cannot.
6. Ordinary hydrogen is the room-temperature mixture, so the composition is 3 : 1 ortho : para, option (a).
⚡ JEE Trick “Ortho = 3 = triplet”: the name with more letters gets the bigger share. Option (c) 1 : 3 is the reversed ratio; (b) and (d) have no basis in spin counting. Ortho and para differ in physical properties (specific heat, thermal conductivity) but have identical chemistry.
Answer: (a) 3 : 1 (ortho : para mixture).

(b) Cu(s)
Concept Dihydrogen is a good reducing agent at high temperature. It reduces oxides of metals less reactive than iron (CuO, PbO, SnO2) all the way to the free metal, taking the oxygen as water. The trap is stopping at a lower oxide (Cu2O) or inventing a hydride.
Key relation CuO(s) + H2(g) →(Δ) Cu(s) + H2O(g) Cu2+ gains 2e−; H goes 0 → +1.
Solution
1. Oxidation states: Cu in CuO is +2; H in H2 is 0.
2. Electron balance: Cu +2 → 0 gains 2e−; H2 → 2H+ loses 2 × 1 = 2e−. 1 : 1 ratio, so one H2 per CuO.
3. Thermodynamics: ΔG = ΔGf(H2O) − ΔGf(CuO) ≈ (−229) − (−130) = −99 kJ, strongly favourable, so reduction goes to the metal. H2O is far more stable than CuO.
4. Observation: black CuO turns reddish-brown (metallic Cu) and water droplets condense; NCERT uses this as the standard example of H2 reducing metal oxides.
5. Why not the others: (a) Cu(OH)2 would need no change in oxidation state, so no reduction; (c) Cu2O is only a partial-reduction intermediate; (d) CuH2 is not a stable product, and Cu forms no such hydride here.
6. So H2 + CuO gives Cu(s), option (b).
⚡ JEE Trick H2 reduces oxides of metals less active than iron to the metal (NCERT: “It reduces some metal ions in aqueous solution and oxides of metals (less active than iron) into corresponding metals”). Cu2O (option c) is tempting, but excess H2 at red heat goes all the way to Cu.
Answer: (b) Cu(s).

🟢 ExactHydrogen has three i…
(d) Atomic mass
Concept Isotopes are atoms of the same element: same number of protons (atomic number) and therefore the same number of electrons and the same electronic configuration. They differ only in the number of neutrons, hence in atomic mass. Chemistry follows the electrons, so properties are nearly the same; physical properties follow mass, so they differ.
Key relation Mass number A = Z + n; for H isotopes Z = 1, n = 0, 1, 2 ⇒ A = 1, 2, 3 Only n changes, so only the mass changes.
Solution
1. Protium 1H: Z = 1, n = A − Z = 1 − 1 = 0; atomic mass 1.008 u.
2. Deuterium 2H: Z = 1, n = 2 − 1 = 1; atomic mass 2.014 u.
3. Tritium 3H: Z = 1, n = 3 − 1 = 2; atomic mass 3.016 u (radioactive, t1/2 ≈ 12.3 y).
4. (a) Number of protons and (b) atomic number are the same thing, Z = 1 for all three. Both fail.
5. (c) Neutral atoms have Z electrons, so all three are 1s1. Same configuration, which is exactly why chemical properties are nearly identical. Fails.
6. Atomic mass: 1.008 : 2.014 : 3.016, about 1 : 2 : 3. This mass ratio is the largest of any element’s isotopes, giving visible differences in density, boiling point and reaction rate. (d) is correct.
⚡ JEE Trick “Isotope” = same Z, different n, so anything tied to Z (protons, electrons, configuration, position in the periodic table) is identical. Options (a) and (b) are the same statement, so neither can be the unique answer; only mass is left.
Answer: (d) Atomic mass.

🟢 ExactHigh purity (> 99.95…
(b) electrolysis of warm aqueous Ba(OH)₂ between Ni electrodes
Concept NCERT, laboratory and commercial preparation of H2: “High purity (>99.95%) dihydrogen is obtained by electrolysing warm aqueous barium hydroxide solution between nickel electrodes.” Chemical routes from zinc carry impurities from commercial zinc; plain electrolysis of acidified water is a general method, not the high-purity one.
Key relation Cathode: 2H2O + 2e− → H2 + 2OH−  |  Anode: 4OH− → O2 + 2H2O + 4e− Ba(OH)2 only carries current; Ba2+ is never discharged, so the gas is pure H2.
Solution
1. (a) Zn + 2NaOH → Na2ZnO2 + H2: a lab method, but the gas carries spray and impurities from commercial zinc. Not >99.95 %.
2. (d) Zn + 2HCl → ZnCl2 + H2: the usual lab method; commercial Zn introduces H2S, PH3, AsH3 traces. Not high purity.
3. (c) Electrolysis of acidified water (Pt electrodes) gives H2, but acid spray is carried over with the gas, and NCERT lists it only as a general route, not the high-purity one.
4. (b) Warm Ba(OH)2(aq), Ni electrodes: Ni is stable in alkali, the electrolyte contributes no volatile species, and warming raises conductivity. NCERT quotes this as the >99.95 % method. (b) is correct.
5. Charge balance check: 4e− per O2 = 2 × 2e− per H2, so the gases form in a 2 : 1 H2 : O2 ratio, collected separately.
6. Book note: the scan prints “electrodes.” at the end of (d); it belongs to (c) (“using platinum electrodes”). It does not affect the answer.
⚡ JEE Trick The magic phrase “>99.95 %” maps to “warm Ba(OH)2, nickel electrodes” verbatim from NCERT. Tempting (c) is also electrolysis, but it is the generic method, not the purity one.
Answer: (b) electrolysis of warm aqueous barium hydroxide solution between nickel electrodes.
